## BarcodeParameters::set_ThrowExceptionWhenCodeTextIncorrect method


يخص فقط باركودات 1D. إذا كان نص الرمز غير صحيح وتم تعيين القيمة إلى true - سيتم إلقاء استثناء. وإلا سيتم تصحيح نص الرمز ليتطابق مع مواصفات الباركود. سيتم دائمًا إلقاء الاستثناء لـ: رموز Databar إذا كان نص الرمز غير صحيح. لن يتم إلقاء الاستثناء أبدًا لـ: AustraliaPost، SingapurePost، Code39FullASCII، Code93، Code16K، رموز Code128 إذا كان نص الرمز غير صحيح.
