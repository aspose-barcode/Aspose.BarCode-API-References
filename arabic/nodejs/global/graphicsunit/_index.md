## GraphicsUnit

يحدد وحدة القياس للبيانات المعطاة.

## القيم

| اسم | الوصف |
| --- | --- |
| WORLD | يحدد وحدة نظام الإحداثيات العالمي كوحدة قياس. |
| DISPLAY | يحدد وحدة قياس جهاز العرض. عادةً البكسلات لشاشات الفيديو، و1/100 بوصة للطابعات. |
| PIXEL | يحدد بكسل الجهاز كوحدة قياس. |
| POINT | يحدد نقطة الطابعة = 1/72 بوصة) كوحدة قياس. |
| INCH | يحدد البوصة كوحدة قياس. |
| DOCUMENT | يحدد وحدة المستند = 1/300 بوصة) كوحدة قياس. |
| MILLIMETER | يحدد المليمتر كوحدة قياس. |
