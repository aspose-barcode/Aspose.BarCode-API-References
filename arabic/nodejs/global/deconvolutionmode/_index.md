## DeconvolutionMode

وضع فك الالتفاف (استعادة الصورة) الذي يحدد مستوى تدهور الصورة. في الأصل، فك الالتفاف هو دالة يمكنها استعادة الصورة المتدهورة (المتشابكة) بسبب أي دالة طبيعية مثل الضبابية، أثناء التقاط الصورة بالكاميرا. نظرًا لعدم قدرتنا على اكتشاف دالة الصورة التي تفسد الصورة، يجب فحص أكثر الدوال المعروفة مثل الحدة أو التشكل الرياضي. يوضح هذا المثال كيفية استخدام وضع Deconvolution let reader = new BarCodeReader(\"test.png\", null, [DecodeType.CODE_39_FULL_ASCII, DecodeType.CODE_128]); reader.getQualitySettings().setDeconvolution(DeconvolutionMode.SLOW); let results = reader.readBarCodes(); for(let i = 0; i < results.length; i++) { let result = results[i]; console.log(\"BarCode CodeText: \" + result.getCodeText()); }
