## DataMatrixEccType

حدد نوع ECC للترميز.

## القيم

| اسم | الوصف |
| --- | --- |
| ECC_AUTO | يحدد أن نوع Ecc المشفر يُعرف بواسطة تصحيح الأخطاء Reed-Solomon الافتراضي أو ECC 200. |
| ECC_000 | يحدد أن نوع Ecc المشفر يُعرف ECC 000. |
| ECC_050 | يحدد أن نوع Ecc المشفر يُعرف ECC 050. |
| ECC_080 | يحدد أن نوع Ecc المشفر يُعرف ECC 080. |
| ECC_100 | يحدد أن نوع Ecc المشفر يُعرف ECC 100. |
| ECC_140 | يحدد أن نوع Ecc المشفر معرف ECC 140. |
| ECC_200 | يحدد أن نوع Ecc المشفر معرف ECC 200. يوصى باستخدامه. |
