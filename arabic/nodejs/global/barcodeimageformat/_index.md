## BarCodeImageFormat

يحدد تنسيق ملف الصورة.

## القيم

| اسم | الوصف |
| --- | --- |
| BMP | يحدد تنسيق صورة bitmap (BMP). |
| GIF | يحدد تنسيق صورة Graphics Interchange Format (GIF). |
| JPEG | يحدد تنسيق صورة Joint Photographic Experts Group (JPEG). |
| PNG | يحدد تنسيق صورة W3C Portable Network Graphics (PNG). |
| TIFF | يحدد تنسيق صورة Tagged Image File Format (TIFF). |
| TIFF_IN_CMYK | يحدد تنسيق صورة Tagged Image File Format (TIFF) بنموذج ألوان CMYK. |
| EMF | يحدد تنسيق صورة Enhanced Metafile (EMF). |
| SVG | يحدد تنسيق صورة Scalable Vector Graphics (SVG). |
| PDF | يحدد تنسيق صورة Portable Document Format (PDF). |
