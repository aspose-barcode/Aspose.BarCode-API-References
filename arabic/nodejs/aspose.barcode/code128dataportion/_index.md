## Code128DataPortion class

يحتوي على بيانات النوع الفرعي لباركود من نوع Code128

```js
new Code128DataPortion()
```

ينشئ مثيلاً جديداً من الفئة `Code128DataPortion` مع رمز البداية والنص المشفر المفكك.

## طرق

| اسم | الوصف |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | يحصل على نوع مجموعة Code128 الفرعية |
| [getData()](#getdata) | يحصل على الجزء من نص الشيفرة المتعلق بالنوع الفرعي. |
| [toString()](#tostring) | يرجع تمثيلاً نصياً قابلاً للقراءة للإنسان لهذا `Code128DataPortion`. |

### getCode128SubType() {#getcode128subtype}

يحصل على نوع مجموعة Code128 الفرعية

**Returns:** The type of Code128 subset

### getData() {#getdata}

يحصل على الجزء من نص الشيفرة المتعلق بالنوع الفرعي.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

يرجع تمثيلاً نصياً قابلاً للقراءة للإنسان لهذا `Code128DataPortion`.

**Returns:** A string that represents this `Code128DataPortion`.
