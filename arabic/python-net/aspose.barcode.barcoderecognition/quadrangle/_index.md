## Quadrangle class

| right_top | يحصل على الزاوية اليمنى العليا [Point](/barcode/python-net/aspose.drawing/point/) لمنطقة [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| right_bottom | يحصل على الزاوية اليمنى السفلية [Point](/barcode/python-net/aspose.drawing/point/) لمنطقة [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| left_bottom | يحصل على الزاوية اليسرى السفلية [Point](/barcode/python-net/aspose.drawing/point/) لمنطقة [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |

| EMPTY | يمثل فئة [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) مع خصائصها غير مهيأة. |
