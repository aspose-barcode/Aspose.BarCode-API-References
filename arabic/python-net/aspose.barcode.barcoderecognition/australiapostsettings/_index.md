## AustraliaPostSettings class

معلمات فك تشفير AustraliaPost. تحتوي على معلمات تؤثر على البيانات المعترف بها في ترميز AustraliaPost.

يعرض نوع AustraliaPostSettings الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| customer_information_interpreting_type | يحصل أو يعيّن نوع التفسير لمعلومات العميل في باركود AustralianPost. القيمة الافتراضية هي CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | العلم الذي يجبر محلل AustraliaPost على تجاهل أنماط التعبئة الأخيرة في حقل معلومات العميل أثناء فك الترميز كطريقة CTable.<br/>            طريقة ترميز CTable لا تحتوي على أي فجوات في جدول الترميز وتسلسل "333" لأنماط التعبئة يتم فك ترميزه كحرف "z". |
| customer_information_decoder | واجهة عامة لفك ترميز حقل معلومات العميل والتي تُستخدم في رموز AustraliaPost. |
