## Pdf417ExtendedParameters class

يخزن معلومات بيانات تعريفية من نوع MacroPdf417 للباركود المعترف به

يعرض نوع Pdf417ExtendedParameters الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_empty | يفحص ما إذا كانت جميع المعلمات تحتوي فقط على القيم الافتراضية |
| macro_pdf_417_file_id | يحصل على معرف الملف للباركود، متاح فقط مع MacroPdf417. |
| macro_pdf_417_segment_id | يحصل على معرف الجزء للباركود، متاح فقط مع MacroPdf417. |
| macro_pdf_417_segments_count | يحصل على عدد أجزاء باركود macro pdf417. القيمة الافتراضية هي -1. |
| macro_pdf_417_file_name | اسم ملف Macro PDF417 (اختياري). |
| macro_pdf_417_file_size | حجم ملف Macro PDF417 (اختياري). |
| macro_pdf_417_sender | اسم مرسل Macro PDF417 (اختياري). |
| macro_pdf_417_addressee | اسم المستلم Macro PDF417 (اختياري). |
| macro_pdf_417_time_stamp | الطابع الزمني لـ Macro PDF417 (اختياري). |
| macro_pdf_417_checksum | مجموع التحقق من Macro PDF417 (اختياري). |
| macro_pdf_417_terminator | يشير إلى ما إذا كان الجزء هو الجزء الأخير من ملف Macro PDF417. |
| is_reader_initialization | يُستخدم لإرشاد القارئ لتفسير البيانات الموجودة داخل الرمز كبرمجة لتهيئة القارئ. |
| is_linked | علامة تشير إلى أن الباركود يجب ربطه بباركود أحادي الأبعاد. |
| is_code_128_emulation | علامة تشير إلى أن باركود MicroPdf417 تم ترميزه باستخدام كلمات رمز محاكاة Code 128 908 أو 909 أو 910 أو 911. |
