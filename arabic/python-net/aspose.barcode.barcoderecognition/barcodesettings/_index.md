## BarcodeSettings class

معلمات فك تشفير BarCode الرئيسية. تحتوي على معلمات تؤثر على البيانات المعترف بها.

يُظهر نوع BarcodeSettings الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| checksum_validation |  |
| strip_fnc | إزالة أحرف FNC1 وFNC2 وFNC3 من النص المشفر. القيمة الافتراضية هي false. |
| only_requested_types | يعيد فقط أنواع الباركود المحددة صراحةً للتعرف. <br/>            عندما يكون مفعلاً، يتم تصفية الباركودات المعترف بها من الأنواع المتوافقة أو المكافئة الأخرى. <br/>            القيمة الافتراضية هي false. |
| detect_encoding | العلم الذي يجبر المحرك على اكتشاف ترميز النص المشفر لمجموعات Unicode. القيمة الافتراضية هي true. |
| australia_post | يحصل على معلمات فك ترميز AustraliaPost |
| calculate_symbol_quality | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب حساب جودة رمز الباركود أثناء التعرف. |
