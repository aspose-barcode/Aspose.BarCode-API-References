| الاسم | الوصف |
| :- | :- |
| reading_quality | يحصل على جودة القراءة. يعمل مع الباركود أحادي الأبعاد والبريدية. |

| code_text | يحصل على نص الكود |
| code_bytes | يحصل على بايتات الكود المشفرة |
| code_type | يحصل على نوع الباركود |

| ممتد | يحصل على المعلمات الموسعة للباركود المعترف به |
| iso_symbol_quality | يحصل على نتائج تقييم جودة الرمز وفق ISO/IEC للباركود المعترف به. |
