## CustomerInformationInterpretingType enumeration

يحدد نوع التفسير (CTable أو NTable أو Other) لمعلومات العميل لباركود AustralianPost.

## Members
| اسم العضو | الوصف |
| :- | :- |
| C_TABLE | استخدم CTable لتفسير معلومات العميل. يسمح بالحروف A..Z، a..z، الأرقام 1..9، المسافة وعلامة #. |
| N_TABLE | استخدم NTable لتفسير معلومات العميل. يسمح بالأرقام. |
| OTHER | لا تقم بتفسير معلومات العميل. يسمح بالرمز 0 أو 1 أو 2 أو 3 فقط. |
