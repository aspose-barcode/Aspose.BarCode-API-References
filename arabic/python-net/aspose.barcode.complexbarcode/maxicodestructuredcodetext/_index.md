## MaxiCodeStructuredCodetext class

الفئة الأساسية لتشفير وفك تشفير النص المضمن في رمز MaxiCode للأنماط 2 و3.

يُظهر نوع MaxiCodeStructuredCodetext الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| encode_mode | يحصل أو يعيّن وضع ترميز MaxiCode. <br/>            القيمة الافتراضية: Auto. |
| eci_encoding | يحصل أو يعيّن ترميز ECI. يُستخدم عندما يكون MaxiCodeEncodeMode هو Auto.<br/>            القيمة الافتراضية: ISO-8859-1 |
| postal_code | يحدد الرمز البريدي. يجب أن يكون 9 أرقام في الوضع 2 أو <br/>            6 رموز أبجدية رقمية في الوضع 3. |
| country_code | يحدد رمز الدولة المكوّن من 3 أرقام. |
| service_category | يحدد فئة الخدمة ذات الثلاث أرقام. |
| second_message | يحدد الرسالة الثانية للباركود. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| get_mode() | يحصل على وضع MaxiCode. |
| get_constructed_codetext() | ينشئ نص الكود |
| init_from_string(constructed_codetext) | يُهيئ المثيل من نص الكود المُنشأ. |
| get_barcode_type() | يحصل على نوع الباركود. |
