## MaxiCodeParameters class

معلمات MaxiCode.

يعرض نوع MaxiCodeParameters الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| الوضع | يحصل أو يضبط وضع تشفير MaxiCode. |
| encode_mode | يحصل أو يعيّن وضع ترميز MaxiCode. <br/>            القيمة الافتراضية: Auto. |
| eci_encoding | يحصل أو يعيّن ترميز ECI. يُستخدم عندما يكون MaxiCodeEncodeMode هو Auto.<br/>            القيمة الافتراضية: ISO-8859-1 |
| structured_append_mode_barcode_id | يحصل أو يضبط معرف الباركود MaxiCode في وضع الإلحاق المُنظم. <br/>            يجب أن تكون القيمة بين 1 و 8. <br/>            القيمة الافتراضية: 0 |
| structured_append_mode_barcodes_count | يحصل أو يضبط عدد الباركودات MaxiCode في وضع الإلحاق المُنظم. <br/>            يجب أن يكون عدد العد قيمة بين 2 و 8 (الحد الأقصى لعدد الباركودات).<br/>            القيمة الافتراضية: -1 |
| aspect_ratio | نسبة الارتفاع إلى العرض لوحدة باركود 2D. |
