## PatchFormat enumeration

تنسيق PatchCode. اختر PatchOnly لإنشاء PatchCode واحد. استخدم تنسيق الصفحة لإنشاء صفحة Patch مع PatchCodes كحدود.

## Members
| اسم العضو | الوصف |
| :- | :- |
| PATCH_ONLY | ينشئ PatchCode فقط |
| A4 | ينشئ صفحة بتنسيق A4 مع PatchCodes كحدود وQR اختياري في المركز |
| A4_LANDSCAPE | ينشئ صفحة بتنسيق A4 أفقي مع PatchCodes كحدود وQR اختياري في المركز |
| US_LETTER | ينشئ صفحة بتنسيق US letter مع PatchCodes كحدود وQR اختياري في المركز |
| US_LETTER_LANDSCAPE | ينشئ صفحة بتنسيق US letter أفقي مع PatchCodes كحدود وQR اختياري في المركز |
