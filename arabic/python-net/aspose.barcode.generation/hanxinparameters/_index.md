## HanXinParameters class

معلمات Han Xin.

يعرض نوع HanXinParameters الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| version | إصدار رمز HanXin.<br/>            من Version01 إلى Version84 لرمز Han Xin.<br/>            القيمة الافتراضية هي Version.Auto. |
| error_level | مستوى تصحيح الأخطاء Reed-Solomon لباركود Han Xin.<br/>             من منخفض إلى عالي: L1, L2, L3, L4. راجع ErrorLevel. |
| encode_mode | وضع الترميز HanXin.<br/>            القيمة الافتراضية: EncodeMode.Mixed. |
| eci_encoding | معرفات تفسير القناة الموسعة. تُستخدم لإبلاغ قارئ الباركود بالتفاصيل<br/>            حول المراجع المستخدمة لترميز البيانات في الرمز.<br/>            يحتوي التنفيذ الحالي على جميع ترميزات مجموعة الأحرف المعروفة. |
