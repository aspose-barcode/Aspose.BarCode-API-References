## Pdf417ErrorLevel enumeration

مستوى تصحيح الأخطاء لباركود pdf417، من المستوى 0 إلى المستوى 9، المستوى 0 يعني عدم وجود تصحيح أخطاء، المستوى 8 يعني أفضل تصحيح أخطاء.
