## ExtCodetextBuilder class

فئة المساعدة لتوليد codetext تلقائيًا في وضع Extended Codetext Mode

يعرض نوع ExtCodetextBuilder الأعضاء التالية:
## الطرق
| الاسم | الوصف |
| :- | :- |
| clear() | يمسح عناصر codetext الموسعة |
| add_plain_codetext(codetext) | يضيف codetext عاديًا إلى عناصر codetext الموسعة |
| add_eci_codetext(eci_encoding, codetext) | يضيف codetext مع معرف القناة الموسعة |
| get_extended_codetext() | إنشاء نص رمزي موسع من قائمة عناصر التوليد |
