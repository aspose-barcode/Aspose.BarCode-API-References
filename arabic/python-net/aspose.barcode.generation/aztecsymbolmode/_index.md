## AztecSymbolMode enumeration

يحدد وضع رمز Aztec.

## Members
| اسم العضو | الوصف |
| :- | :- |
| AUTO | يحدد اختيار الرمز الأفضل تلقائيًا (Compact أو Full-range) لـ Aztec.<br/>            هذه هي القيمة الافتراضية. |
| COMPACT | يحدد الرمز Compact لـ Aztec.<br/>            يسمح رمز Aztec Compact فقط بـ 1 أو 2 أو 3 أو 4 طبقات. |
| FULL_RANGE | يحدد الرمز Full-range لـ Aztec.<br/>            يسمح رمز Aztec Full-range من 1 إلى 32 طبقة. |
| RUNE | يحدد الرمز Rune لـ Aztec.<br/>            رموز Aztec Runes هي سلسلة من العلامات الصغيرة ولكن المميزة القابلة للقراءة آليًا. يسمح فقط بقيمة رقمية من 0 إلى 255. |
