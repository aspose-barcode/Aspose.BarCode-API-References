## BorderParameters class

معلمات حدود صورة الباركود

يعرض نوع BorderParameters الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| visible | ظهور الحدود. إذا كان false فإن معلمة Width تُهمل دائمًا (0).<br/>            القيمة الافتراضية: false. |
| العرض | عرض الحد.<br/>            القيمة الافتراضية: 0.<br/>            تُهمل إذا تم تعيين Visible إلى false. |
| dash_style | نمط الخط المتقطع للحد.<br/>            القيمة الافتراضية: BorderDashStyle.Solid. |
| اللون | لون الحد.<br/>            القيمة الافتراضية: Color.Black. |
