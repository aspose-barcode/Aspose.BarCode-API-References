## AutoSizeMode enumeration

يحدد الأنواع المختلفة لأوضاع التحجيم التلقائي.

## Members
| اسم العضو | الوصف |
| :- | :- |
| NONE | تم تعطيل إعادة التحجيم التلقائي. |
| NEAREST | يعيد تحجيم الباركود إلى أقرب حجم أدنى ممكن محدد بواسطة خصائص ImageWidth و ImageHeight.<br/>            يحافظ على نسبة العرض إلى الارتفاع الافتراضية. |
| INTERPOLATION | يعيد تحجيم الباركود إلى الحجم المحدد.<br/>            يمكن تحديد الحجم بواسطة خصائص ImageWidth و ImageHeight.<br/>            قد يصبح الباركود المُولد غير صالح (غير قابل للقراءة) بعد التحجيم. |
