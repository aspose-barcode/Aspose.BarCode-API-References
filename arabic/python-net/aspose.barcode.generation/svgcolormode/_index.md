## SvgColorMode enumeration

الوضعيات الممكنة لتعبئة اللون في ملف svg، RGB هو الافتراضي ومدعوم من SVG 1.1.<br/>            RGBA، HSL، HSLA مسموح بها في معيار SVG 2.0.<br/>            حتى في RGB سيتم ضبط الشفافية عبر معامل "fill-opacity".

## Members
| اسم العضو | الوصف |
| :- | :- |
| RGB | وضع RGB، مثال: fill="#ff5511" fill-opacity="0.73". الوضع الافتراضي. |
| RGBA | وضع RGBA، مثال: fill="rgba(255, 85, 17, 0.73)" |
| HSL | وضع HSL، مثال: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | وضع HSLA، مثال: fill="hsla(30, 50%, 70%, 0.8)" |
