## CaptionParameters class

معلمات التسمية.

يعرض نوع CaptionParameters الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| text | نص التسمية.<br/>            القيمة الافتراضية: سلسلة فارغة. |
| font | خط التسمية.<br/>            القيمة الافتراضية: Arial 8pt عادي. |
| visible | إظهار نص التسمية.<br/>            القيمة الافتراضية: false. |
| text_color | لون نص التسمية.<br/>            القيمة الافتراضية: Color.Black. |
| padding | هوامش التسمية.<br/>            القيمة الافتراضية لـ CaptionAbove: 5pt 5pt 0 5pt.<br/>            القيمة الافتراضية لـ CaptionBelow: 0 5pt 5pt 5pt. |
| المحاذاة | محاذاة النص الأفقي للتسمية.<br/>            القيمة الافتراضية: StringAlignment.Center. |
| no_wrap | حدد التفاف الكلمات (فواصل الأسطر) داخل النص.<br/>            القيمة الافتراضية: false. |
