## ITFParameters class

معلمات ITF.

يعرض نوع ITFParameters الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| border_thickness | يحصل أو يضبط سمك حد ITF (شريط الحامل) بوحدة القيمة.<br/>            القيمة الافتراضية: 12pt. |
| border_type | نوع الحد لباركود ITF.<br/>            القيمة الافتراضية: ITF14BorderType.Bar. |
| quiet_zone_coef | حجم المناطق الهادئة في xDimension.<br/>            القيمة الافتراضية: 10، مما يعني إذا كان xDimension = 2px فإن المناطق الهادئة ستكون 20px. |
