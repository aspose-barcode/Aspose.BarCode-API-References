## ProcessorSettings class

تسمح إعدادات ProcessorSettings بالتعرف على الباركودات مع تحسين الأداء عبر تعدد الخيوط.

يعرض نوع ProcessorSettings الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| use_all_cores | مطلوب لاستخدام جميع الأنوية. |
| use_only_this_cores_count | حدد عدد الأنوية التي سيتم استخدامها. <br/>            تحتاج إلى تغيير الخاصية "UseAllCores" إلى "false". |
| max_additional_allowed_threads | حدد الحد الأقصى لعدد الخيوط الإضافية لتشغيل الشيفرة بشكل متوازي |
