## QrExtCompactionMode

Specifies QR compaction mode for codetext added by QrExtCodetextBuilder.

## Values

| Name | Description |
| --- | --- |
| AUTO | The encoder selects the most efficient QR compaction mode automatically. |
| NUMERIC | Encodes codetext in QR Numeric mode. Only digits 0-9 are allowed. |
| ALPHA_NUMERIC | Encodes codetext in QR Alphanumeric mode. |
| BYTES | Encodes codetext in QR Byte mode. |
| KANJI | Encodes codetext in QR Kanji mode. |
