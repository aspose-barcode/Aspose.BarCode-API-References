## DataElement class

Represents a jurisdiction-specific data field used in documents, for example ElementID = "ZVA" with Value = "01".

```js
new DataElement()
```

## Methods

| Name | Description |
| --- | --- |
| [getElementID()](./getelementid/) | A 3-character code that identifies the jurisdiction-specific field, e.g., "ZVA". |
| [getValue()](./getvalue/) | The text value associated with the field, typically defined by jurisdiction rules. |
| [setElementID()](./setelementid/) | A 3-character code that identifies the jurisdiction-specific field, e.g., "ZVA". |
| [setValue()](./setvalue/) | The text value associated with the field, typically defined by jurisdiction rules. |
