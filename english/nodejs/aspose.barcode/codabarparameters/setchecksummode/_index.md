## setChecksumMode(value)

Set the checksum algorithm for Codabar barcodes. Default value: CodabarChecksumMode.Mod16. To enable checksum calculation set value EnableChecksum.Yes to property EnableChecksum. See `ChecksumMode`(#getChecksumMode/#setChecksumMode).

| Parameter | Description |
| --- | --- |
| value | the checksum algorithm for Codabar barcodes. |
