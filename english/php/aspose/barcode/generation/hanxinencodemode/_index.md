## HanXinEncodeMode enum

**Namespace:** `Aspose.Barcode.Generation`


Han Xin Code encoding mode. It is recommended to use Auto with ASCII / Chinese characters or Unicode for Unicode characters.


## Enum Values

| Name | Value | Description |
| --- | --- | --- |
| [AUTO](/php/aspose/barcode/generation/hanxinencodemode/auto/) | `0` | Sequence of Numeric, Text, ECI, Binary Bytes and 4 GB18030 modes changing automatically. |
| [BINARY](/php/aspose/barcode/generation/hanxinencodemode/binary/) | `1` | Binary byte mode encodes binary data in any form and encodes them in their binary byte. Every byte in Binary Byte mode is represented by 8 bits. |
| [ECI](/php/aspose/barcode/generation/hanxinencodemode/eci/) | `2` | Extended Channel Interpretation (ECI) mode |
| [EXTENDED](/php/aspose/barcode/generation/hanxinencodemode/extended/) | `5` | Extended mode will allow more flexible combinations of other modes, this mode is currently not implemented. |
| [UNICODE](/php/aspose/barcode/generation/hanxinencodemode/unicode/) | `3` | Unicode mode designs a way to represent any text data reference to UTF8 encoding/charset in Han Xin Code. |
| [URI](/php/aspose/barcode/generation/hanxinencodemode/uri/) | `4` | URI mode indicates the data represented in Han Xin Code is Uniform Resource Identifier (URI) reference to RFC 3986. |
