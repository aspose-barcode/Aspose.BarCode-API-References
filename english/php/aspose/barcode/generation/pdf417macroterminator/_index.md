## Pdf417MacroTerminator enum

**Namespace:** `Aspose.Barcode.Generation`


Used to tell the encoder whether to add Macro PDF417 Terminator (codeword 922) to the segment. Applied only for Macro PDF417.


## Enum Values

| Name | Value | Description |
| --- | --- | --- |
| [AUTO](/php/aspose/barcode/generation/pdf417macroterminator/auto/) | `0` | The terminator will be added automatically if the number of segments is provided and the current segment is the last one. In other cases, the terminator will not be added. |
| [NONE](/php/aspose/barcode/generation/pdf417macroterminator/none/) | `1` | The terminator will not be added. |
| [SET](/php/aspose/barcode/generation/pdf417macroterminator/set/) | `2` | The terminator will be added. |
