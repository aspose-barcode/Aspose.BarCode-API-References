## Aspose.BarCode for PHP via Java API Reference

The API lets you create, customize, and render barcodes, as well as detect and decode them from images, PDFs, or streams. It supports popular symbologies such as Code128, QR, DataMatrix, PDF417, Aztec, UPC/EAN, and many postal formats. Functionality is grouped into four namespaces: Aspose.Barcode for core types, Generation for encoding operations, Recognition for decoding, ComplexBarcode for composite barcode handling, and Internal for supporting utilities.
