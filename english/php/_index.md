## Aspose.BarCode for PHP via Java API Reference

The library supports a wide range of 1D symbologies such as Code128, Code39, EAN‑13, UPC, and 2D formats including QR, DataMatrix, PDF417, and Aztec. Functionality is divided into four namespaces: Aspose.Barcode.Generation for creating barcodes, Aspose.Barcode.Recognition for decoding them, Aspose.Barcode.ComplexBarcode for handling composite and stacked symbols, and Aspose.Barcode.Internal for low‑level utilities. Together they provide a comprehensive toolkit for barcode integration in PHP applications via Java.
