## Aspose.BarCode for PHP via Java API Reference

The API offers classes for barcode generation, recognition, complex barcode handling, and supporting utilities, organized into four namespaces: Aspose.Barcode.Generation, Aspose.Barcode.Recognition, Aspose.Barcode.ComplexBarcode, and Aspose.Barcode.Internal. Developers can create and decode 1D, 2D, postal and matrix codes such as Code128, QR, DataMatrix, PDF417, Aztec, and many others, using images, streams, or raw data. The namespace structure provides a clear separation of core functionality from internal components, simplifying integration and maintenance.

## Namespaces

| Namespace | Description |
| --- | --- |
| [Aspose.Barcode.ComplexBarcode](/php/aspose/barcode/complexbarcode/) | Provides classes and enums for generating and reading complex barcode formats, including HIBC LIC and combined codetext structures. |
| [Aspose.Barcode.Generation](/php/aspose/barcode/generation/) | The Aspose.Barcode.Generation namespace supplies classes and enums for configuring and creating barcodes in PHP via Java. |
| [Aspose.Barcode.Internal](/php/aspose/barcode/internal/) | The Aspose.Barcode.Internal namespace supplies core utility classes, licensing support, geometric types, and low‑level connection handling for barcode processing. |
| [Aspose.Barcode.Recognition](/php/aspose/barcode/recognition/) | Provides classes and enums for configuring and performing barcode recognition, including settings for specific symbologies and result handling. |
