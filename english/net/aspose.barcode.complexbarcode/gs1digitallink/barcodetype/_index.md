## GS1DigitalLink.BarcodeType property

Gets or sets the barcode type used to encode this GS1 Digital Link. Supported types are QR, DataMatrix, Aztec, Pdf417, MicroPdf417, DotCode, HanXin, CodablockF and Code128. The default value is QR.
