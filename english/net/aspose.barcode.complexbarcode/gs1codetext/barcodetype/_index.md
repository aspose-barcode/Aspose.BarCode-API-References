## GS1Codetext.BarcodeType property

Gets or sets the barcode type used to encode this GS1 codetext. Supported types are GS1Aztec, GS1CodablockF, GS1Code128, GS1DataMatrix, GS1DotCode, GS1HanXin, GS1MicroPdf417, GS1QR and GS1 DataBar types. The default value is GS1Code128.
