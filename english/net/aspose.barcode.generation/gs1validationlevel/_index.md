## GS1ValidationLevel enumeration

Specifies the level of GS1 data validation. Higher validation levels include all checks from lower levels.

```csharp
public enum GS1ValidationLevel
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Syntax | `0` | Validates GS1 syntax, including application identifiers, field lengths and required separators. |
| Content | `1` | Validates GS1 syntax and the content of application identifier values, including character sets, checksums and value-specific rules. |
