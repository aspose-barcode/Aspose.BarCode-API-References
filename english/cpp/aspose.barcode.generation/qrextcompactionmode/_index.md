## QrExtCompactionMode enum


Specifies QR compaction mode for codetext added by [QrExtCodetextBuilder](../qrextcodetextbuilder/).

```cpp
enum class QrExtCompactionMode
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Auto | 0 | The encoder selects the most efficient QR compaction mode automatically. |
| Numeric | 1 | Encodes codetext in QR Numeric mode. Only digits 0-9 are allowed. |
| AlphaNumeric | 2 | Encodes codetext in QR Alphanumeric mode. |
| Bytes | 3 | Encodes codetext in QR Byte mode. |
| Kanji | 4 | Encodes codetext in QR Kanji mode. |
