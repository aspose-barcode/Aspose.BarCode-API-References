## aspose_barcode.core module

The aspose_barcode.core namespace provides the foundational classes and interfaces used across the Aspose.BarCode for Python via Java library. It includes BarCodeException, License management, coordinate interfaces (HasXY, HasXYWH), and geometric structures such as PointXY, RectLTRB, and RectXYWH.
