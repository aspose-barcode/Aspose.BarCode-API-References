## aspose_barcode.generation module

The aspose_barcode.generation namespace groups all objects needed to define barcode appearance, encoding options, and output settings. Use these classes to customize parameters such as size, colors, captions, borders, and specific symbology settings before creating a BarcodeGenerator instance.
