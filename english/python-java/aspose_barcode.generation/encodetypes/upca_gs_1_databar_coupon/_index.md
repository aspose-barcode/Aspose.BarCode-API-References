## EncodeTypes.UPCA_GS_1_DATABAR_COUPON

**Type:** `int`


**Value:** `63`


Specifies that the data should be encoded with UPC coupon with GS1 DataBar addition barcode specification. An example of the input string: generator.setCodeText("514141100906(8110)106141416543213500110000310123196000", None), where UPCA part is "514141100906", DATABAR part is "(8110)106141416543213500110000310123196000". To change the caption, use generator.getParameters().getCaptionAbove().setText("company prefix + offer code")
