## GS1ValidationLevel enumeration

Specifies the level of GS1 data validation.<br/>            Higher validation levels include all checks from lower levels.

## Members
| Member name | Description |
| :- | :- |
|SYNTAX|Validates GS1 syntax, including application identifiers,<br/>            field lengths and required separators.|
|CONTENT|Validates GS1 syntax and the content of application identifier values,<br/>            including character sets, checksums and value-specific rules.|
