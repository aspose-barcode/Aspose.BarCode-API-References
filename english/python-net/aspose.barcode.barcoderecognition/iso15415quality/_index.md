## Iso15415Quality class

Represents barcode quality assessment results according to ISO/IEC 15415.

The Iso15415Quality type exposes the following members:
## Properties
| Name | Description |
| :- | :- |
|grade|Gets the overall barcode quality grade according to ISO/IEC 15415.|
|decode|Gets the decode grade indicating whether the barcode can be decoded using the reference decode algorithm.|
|symbol_contrast|Gets the symbol contrast grade based on the difference between maximum and minimum reflectance.|
|modulation|Gets the modulation grade based on variations in reflectance contrast between barcode modules.|
|fixed_pattern_damage|Gets the fixed pattern damage grade based on defects in the barcode's fixed patterns.|
|axial_nonuniformity|Gets the axial nonuniformity grade based on differences in module spacing along the two axes.|
|grid_nonuniformity|Gets the grid nonuniformity grade based on deviations of module positions from the ideal grid.|
|unused_error_correction|Gets the unused error correction grade based on the remaining error correction capacity.|
|print_growth_x|Gets the horizontal print growth quality grade.|
|print_growth_y|Gets the vertical print growth quality grade.|
