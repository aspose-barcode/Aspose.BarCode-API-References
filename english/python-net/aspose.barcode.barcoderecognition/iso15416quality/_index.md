## Iso15416Quality class

Stores barcode quality grades calculated according to the ISO/IEC 15416 standard for 1D barcodes.

The Iso15416Quality type exposes the following members:
## Properties
| Name | Description |
| :- | :- |
|grade|Gets the overall barcode quality grade according to ISO/IEC 15416.|
|decode|Gets the decode grade indicating whether the barcode can be decoded using the reference decode algorithm.|
|symbol_contrast|Gets the symbol contrast grade based on the difference between maximum and minimum reflectance.|
|minimum_reflectance|Gets the minimum reflectance grade based on the darkest bar reflectance.|
|minimum_edge_contrast|Gets the minimum edge contrast grade based on the smallest reflectance difference between adjacent bars and spaces.|
|modulation|Gets the modulation grade based on the uniformity of edge contrast throughout the barcode.|
|defects|Gets the defects grade based on reflectance irregularities within bars and spaces.|
|decodability|Gets the decodability grade based on the accuracy of bar and space widths.|
