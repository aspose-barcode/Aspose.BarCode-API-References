## IBarCodeGeneratorControl.RotationAngle property

BarCode-afbeeldingsrotatiehoek, gemeten in graden, bijv. RotationAngle = 0 of RotationAngle = 360 betekent geen rotatie. Als RotationAngle NIET gelijk is aan 90, 180, 270 of 0, kan dit de moeilijkheid voor de scanner om de afbeelding te lezen verhogen.

```csharp
public float RotationAngle { get; set; }
```
