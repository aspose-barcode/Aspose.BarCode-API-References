## BarCodeGeneratorControl.ThrowExceptionWhenCodeTextIncorrect property

Alleen voor 1D-barcodes. Als codetext onjuist is en de waarde is ingesteld op true - wordt er een uitzondering gegooid. Anders wordt codetext gecorrigeerd om te voldoen aan de specificatie van de barcode. Een uitzondering wordt altijd gegooid voor: Databar symbology als codetext onjuist is. Een uitzondering wordt nooit gegooid voor: AustraliaPost, SingapurePost, Code39Extended, Code93Extended, Code16K, Code128 symbology als codetext onjuist is.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
