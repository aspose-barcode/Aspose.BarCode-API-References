## Pdf417MacroTerminator enumeration

Wordt gebruikt om de encoder te vertellen of de Macro PDF417 Terminator (codewoord 922) aan het segment moet worden toegevoegd. Alleen van toepassing op Macro PDF417.

```csharp
public enum Pdf417MacroTerminator
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Auto | `0` | De terminator wordt automatisch toegevoegd als het aantal segmenten is opgegeven en het huidige segment het laatste is. In andere gevallen wordt de terminator niet toegevoegd. |
| None | `1` | De terminator wordt niet toegevoegd. |
| Set | `2` | De terminator wordt toegevoegd. |
