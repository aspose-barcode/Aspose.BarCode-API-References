## SvgColorMode enumeration

Mogelijke modi voor vulkleur in een svg-bestand, RGB is standaard en wordt ondersteund door SVG 1.1. RGBA, HSL, HSLA zijn toegestaan in de SVG 2.0-standaard. Zelfs bij RGB wordt de opacity ingesteld via de parameter "fill-opacity".

```csharp
public enum SvgColorMode
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| RGB | `0` | RGB-modus, voorbeeld: fill="#ff5511" fill-opacity="0.73". Standaardmodus. |
| RGBA | `1` | RGBA-modus, voorbeeld: fill="rgba(255, 85, 17, 0.73)" |
| HSL | `2` | HSL-modus, voorbeeld: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | `3` | HSLA-modus, voorbeeld: fill="hsla(30, 50%, 70%, 0.8)" |
