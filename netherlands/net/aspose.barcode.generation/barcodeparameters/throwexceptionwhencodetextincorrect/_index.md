## BarcodeParameters.ThrowExceptionWhenCodeTextIncorrect property

Alleen voor 1D-barcode. Als de codetekst onjuist is en de waarde is ingesteld op true - wordt een uitzondering gegooid. Anders wordt de codetekst gecorrigeerd om te voldoen aan de specificatie van de barcode. Een uitzondering wordt altijd gegooid voor: Databar-symbool als de codetekst onjuist is. Een uitzondering wordt nooit gegooid voor: AustraliaPost, SingapurePost, Code39FullASCII, Code93, Code16K, Code128-symbool als de codetekst onjuist is.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
