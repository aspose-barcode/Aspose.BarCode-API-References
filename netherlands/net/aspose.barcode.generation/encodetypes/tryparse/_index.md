## EncodeTypes.TryParse method

Converteert de tekenreeksrepresentatie van een BaseEncodeType naar de bijbehorende instantie. Een retourwaarde geeft aan of de conversie geslaagd of mislukt is.

```csharp
public static bool TryParse(string parsingType, out BaseEncodeType result)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| parsingType | String | Een tekenreeks in het formaat "Index:-1; Name:None" om te converteren. |
| result | BaseEncodeType& | Een daadwerkelijke SingleEncodeType retourneert, wanneer de conversie succesvol is voltooid; |

### Retourwaarde

**true** if s was converted successfully; otherwise, **false**.
