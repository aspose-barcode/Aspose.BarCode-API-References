## SwissQRBill.Reference property

Haalt op of stelt de betalingsreferentie van de crediteur in.

De referentie is verplicht voor SwissQR‑IBAN's, d.w.z. IBAN's in het bereik CHxx30000xxxxxx tot CHxx31999xxxxx.

Indien opgegeven, moet de referentie een geldige SwissQR‑referentie zijn (overeenkomend met ISR‑referentieformulier) of een geldige crediteur‑referentie volgens ISO 11649 ("RFxxxx"). Beide mogen spaties bevatten voor opmaak.

```csharp
public string Reference { get; set; }
```

### Property Value

De betalingsreferentie van de crediteur.
