## GS1DigitalLink.TryParse method

Pogt een niet-gecomprimeerde GS1 Digital Link URI te parseren en retourneert gestructureerde validatiefouten.

```csharp
public static bool TryParse(string value, out GS1DigitalLink result, 
    out GS1ValidationResult validationResult)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | String | GS1 Digital Link URI om te parseren. |
| result | GS1DigitalLink& | Wanneer deze methode true retourneert, bevat de geparseerde GS1 Digital Link; anders null. |
| validationResult | GS1ValidationResult& | Bevat het validatieresultaat, of null wanneer *value* null is. |

### Retourwaarde

True wanneer het parseren slaagt; anders false.
