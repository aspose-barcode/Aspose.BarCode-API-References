## Address.Street property

Haalt op of stelt de straat in.

De straat moet worden opgegeven zonder huisnummer.

Het instellen van dit veld zet het adrestype op Structured tenzij het al CombinedElements is, in welk geval het Conflicting wordt.

Dit veld wordt alleen gebruikt voor gestructureerde adressen en is optioneel.

```csharp
public string Street { get; set; }
```

### Property Value

De straat.
