## Address.Type property

Haalt het adrestype op.

Het adrestype wordt automatisch ingesteld door ofwel de straat / huisnummer of adresregel 1 en 2 in te stellen. Voordat de velden worden ingesteld, is het adrestype Undetermined. Als velden van beide typen worden ingesteld, wordt het adrestype Conflicting.

```csharp
public AddressType Type { get; }
```

### Property Value

Het adrestype.
