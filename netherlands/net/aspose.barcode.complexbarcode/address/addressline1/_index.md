## Address.AddressLine1 property

Haalt op of stelt adresregel 1 in.

Adresregel 1 bevat de straatnaam, huisnummer of postbus.

Het instellen van dit veld zet het adrestype op CombinedElements tenzij het al Structured is, in welk geval het Conflicting wordt.

Dit veld wordt alleen gebruikt voor adressen met gecombineerde elementen en is optioneel.

```csharp
public string AddressLine1 { get; set; }
```

### Property Value

De adresregel 1.
