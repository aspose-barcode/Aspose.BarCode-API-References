## AustraliaPostCustomerInformationDecoder class


Openbare interface voor het decoderen van Customer Information Field die wordt gebruikt in AustraliaPost-symbologie. Implementatie moet door de gebruiker worden geleverd.

```cpp
class AustraliaPostCustomerInformationDecoder : public virtual System::Object
```
