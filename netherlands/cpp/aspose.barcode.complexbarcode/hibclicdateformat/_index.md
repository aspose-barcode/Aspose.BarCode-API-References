## HIBCLICDateFormat enum


Specificeert de verschillende soorten datumformaten voor HIBC LIC.

```cpp
enum class HIBCLICDateFormat
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| YYYYMMDD | 0 | YYYYMMDD-formaat. Wordt gecodeerd in extra aanvullende gegevens. |
| MMYY | 1 | MMYY-formaat. |
| MMDDYY | 2 | MMDDYY-formaat. |
| YYMMDD | 3 | YYMMDD-formaat. |
| YYMMDDHH | 4 | YYMMDDHH-formaat. |
| YYJJJ | 5 | Juliaanse datumformaat. |
| YYJJJHH | 6 | Juliaanse datumformaat met uren. |
| Geen | 7 | Encodeer de vervaldatum niet. |
