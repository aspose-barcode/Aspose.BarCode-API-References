## Payments::IsValidQrReference method


Valideert of de tekenreeks een geldige QR-referentie is.

```cpp
static bool Aspose::BarCode::ComplexBarcode::Payments::IsValidQrReference(System::String reference)
```


| Parameter | Type | Beschrijving |
| --- | --- | --- |
| reference | System::String | Het QR-referentienummer om te valideren. |

### ReturnValue

**true** if the reference number is valid, **false** otherwise.
## Opmerkingen


Een geldige QR-referentie is een geldige ISR-referentie.

De string wordt gecontroleerd op geldige tekens, geldige lengte en een geldig controlecijfer. Witruimte wordt genegeerd.
