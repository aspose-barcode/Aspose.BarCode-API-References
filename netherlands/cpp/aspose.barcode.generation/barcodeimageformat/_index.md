## BarCodeImageFormat enum


Specificeert het bestandsformaat van de afbeelding.

```cpp
enum class BarCodeImageFormat
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Bmp | 0 | Specificeert het bitmap (BMP) afbeeldingsformaat. |
| Gif | 1 | Specificeert het Graphics Interchange Format (GIF) afbeeldingsformaat. |
| Jpeg | 2 | Specificeert het Joint Photographic Experts Group (JPEG) afbeeldingsformaat. |
| Png | 3 | Specificeert het W3C Portable Network Graphics (PNG) afbeeldingsformaat. |
| Tiff | 4 | Specificeert het Tagged Image File Format (TIFF) afbeeldingsformaat. |
| TiffInCmyk | 5 | Specificeert het Tagged Image File Format (TIFF) afbeeldingsformaat in CMYK-kleurmodel. (Alleen ondersteund op het [Windows](../../aspose.barcode.windows/) platform, op *nix-platforms wordt opgeslagen als Tiff) |
| Emf | 6 | Specificeert het Enhanced Metafile (EMF) afbeeldingsformaat. (Alleen ondersteund op het [Windows](../../aspose.barcode.windows/) platform, op *nix-platforms wordt opgeslagen als PNG) |
| Svg | 7 | Specificeert het Scalable Vector Graphics (SVG) afbeeldingsformaat. |
| Pdf | 8 | Specificeert het Portable Document Format (PDF) afbeeldingsformaat. |
