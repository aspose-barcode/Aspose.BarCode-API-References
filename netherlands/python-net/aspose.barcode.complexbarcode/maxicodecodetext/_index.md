## MaxiCodeCodetext class

Basisklasse voor het coderen en decoderen van de tekst die is ingebed in de MaxiCode‑code.

Het MaxiCodeCodetext-type biedt de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| encode_mode | Haalt of stelt een MaxiCode-codering modus in. <br/>            Standaardwaarde: Auto. |
| eci_encoding | Haalt of stelt ECI-codering in. Wordt gebruikt wanneer MaxiCodeEncodeMode Auto is.<br/>            Standaardwaarde: ISO-8859-1 |

| Name | Beschrijving |
| :- | :- |

| get_constructed_codetext() | Construeert codetext |
