## ProcessorSettings class

ProcessorSettings staan toe om barcodes te herkennen met multi-threaded prestatieverbetering.

Het type ProcessorSettings exposeert de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| use_all_cores | Is nodig om alle cores te gebruiken. |
| use_only_this_cores_count | Geef het aantal cores op dat gebruikt moet worden. <br/>            U moet de eigenschap "UseAllCores" wijzigen naar "false". |
| max_additional_allowed_threads | Geef het maximale aantal extra threads op om code parallel uit te voeren |
