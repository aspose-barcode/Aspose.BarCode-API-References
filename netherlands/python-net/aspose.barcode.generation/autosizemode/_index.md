## AutoSizeMode enumeration

Specificeert de verschillende typen automatische formaatmodi.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| NONE | Automatisch schalen is uitgeschakeld. |
| NEAREST | Wijzigt de grootte van de barcode naar de dichtstbijzijnde laagst mogelijke grootte die is opgegeven door de eigenschappen ImageWidth en ImageHeight.<br/>            Behoudt de standaard beeldverhouding. |
| INTERPOLATION | Wijzigt de grootte van de barcode naar de opgegeven grootte.<br/>            De grootte kan worden opgegeven door de eigenschappen ImageWidth en ImageHeight.<br/>            De gegenereerde barcode kan ongeldig (niet leesbaar) worden na het schalen. |
