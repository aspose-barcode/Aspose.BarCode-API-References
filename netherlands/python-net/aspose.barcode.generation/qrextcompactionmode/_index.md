## QrExtCompactionMode enumeration

Specificeert QR‑compactiemodus voor codetekst toegevoegd door QrExtCodetextBuilder.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| AUTO | De encoder selecteert automatisch de meest efficiënte QR-compressiemodus. |
| NUMERIC | Encodeert codetekst in QR-numerieke modus. Alleen cijfers 0-9 zijn toegestaan. |
| ALPHA_NUMERIC | Encodeert codetekst in QR-alphanumerieke modus. |
| BYTES | Encodeert codetekst in QR-byte modus. |
| KANJI | Encodeert codetekst in QR-Kanji modus. |
