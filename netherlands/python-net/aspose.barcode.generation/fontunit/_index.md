## FontUnit class

Definieert een specifiek formaat voor tekst, inclusief lettertype, grootte en stijlkenmerken<br/>            waarbij grootte in de eigenschap Unit-waarde staat.

Het FontUnit-type biedt de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| family_name | Haalt de naam van dit Lettertype op of stelt deze in. |
| style | Haalt stijlinformatie voor deze FontUnit op of stelt deze in. |
| size | Haalt de grootte van deze FontUnit op of stelt deze in, in eenheidswaarde. |
