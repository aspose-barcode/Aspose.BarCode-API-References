## BarCodeImageFormat enumeration

Specificeert het bestandsformaat van de afbeelding.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| BMP | Specificeert het bitmap (BMP) afbeeldingsformaat. |
| GIF | Specificeert het Graphics Interchange Format (GIF) afbeeldingsformaat. |
| JPEG | Specificeert het Joint Photographic Experts Group (JPEG) afbeeldingsformaat. |
| PNG | Specificeert het W3C Portable Network Graphics (PNG) afbeeldingsformaat. |
| TIFF | Specificeert het Tagged Image File Format (TIFF) afbeeldingsformaat. |
| TIFF_IN_CMYK | Specificeert het Tagged Image File Format (TIFF) afbeeldingsformaat in CMYK-kleurenmodel. <br/>            (Alleen ondersteund op Windows-platform, op *nix-platforms wordt opgeslagen als Tiff) |
| EMF | Specificeert het Enhanced Metafile (EMF) afbeeldingsformaat.<br/>            (Alleen ondersteund op Windows-platform, op *nix-platforms wordt opgeslagen als PNG) |
| SVG | Specificeert het Scalable Vector Graphics (SVG) afbeeldingsformaat. |
| PDF | Specificeert het Portable Document Format (PDF) afbeeldingsformaat. |
