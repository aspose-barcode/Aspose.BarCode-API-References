## Pdf417MacroTerminator enumeration

Wordt gebruikt om de encoder te vertellen of de Macro PDF417-terminator (codewoord 922) aan het segment moet worden toegevoegd. <br/>            Alleen toegepast voor Macro PDF417.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| AUTO | De terminator wordt automatisch toegevoegd als het aantal segmenten is opgegeven <br/>            en het huidige segment het laatste is. In andere gevallen wordt de terminator niet toegevoegd. |
| NONE | De terminator wordt niet toegevoegd. |
| SET | De terminator wordt toegevoegd. |
