## DotCodeParameters class

DotCode-parameters.

Het type DotCodeParameters bevat de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| aspect_ratio | Hoogte/breedteverhouding van de 2D BarCode-module. |
| encode_mode | Identificeert de DotCode‑codeermodus. <br/>            Standaardwaarde: Auto. |
| is_reader_initialization | Geeft aan of de code wordt gebruikt om de lezer te instrueren de volgende gegevens te interpreteren als instructies voor initialisatie of herprogrammering van de barcodelezer.<br/>            Standaardwaarde is false. |
| structured_append_mode_barcode_id | Identificeert de ID van de DotCode gestructureerde toevoegingsmodus‑barcode. ID begint bij 1 en moet kleiner of gelijk zijn aan het aantal barcodes. Standaardwaarde is -1. |
| structured_append_mode_barcodes_count | Identificeert het aantal barcodes in de DotCode gestructureerde toevoegingsmodus. Standaardwaarde is -1. Het aantal moet een waarde tussen 1 en 35 zijn. |
| eci_encoding | Identificeert de ECI‑codering. Wordt gebruikt wanneer DotCodeEncodeMode Auto is. <br/>            Standaardwaarde: ISO-8859-1 |
| rijen | Identificeert het aantal rijen. De som van het aantal rijen en het aantal kolommen van een DotCode‑symbool moet oneven zijn. Het aantal rijen moet minimaal 5 zijn. <br/>            Standaardwaarde: -1 |
| kolommen | Identificeert het aantal kolommen. De som van het aantal rijen en het aantal kolommen van een DotCode‑symbool moet oneven zijn. Het aantal kolommen moet minimaal 5 zijn. <br/>            Standaardwaarde: -1 |
