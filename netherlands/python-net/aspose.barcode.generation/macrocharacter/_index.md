## MacroCharacter enumeration

Macro‑tekens 05 en 06 worden gebruikt om een compactere codering te verkrijgen in speciale modi.<br/>            Macro‑teken 05 wordt vertaald naar "[)>\u001E05\u001D" als gedecodeerde gegevensheader en "\u001E\u0004" als gedecodeerde gegevenstrailer.<br/>            Macro‑teken 06 wordt vertaald naar "[)>\u001E06\u001D" als gedecodeerde gegevensheader en "\u001E\u0004" als gedecodeerde gegevenstrailer.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| NONE | Geen Macro Characters worden toegevoegd aan barcodegegevens. |
| MACRO05 | 05 Macro craracter wordt toegevoegd aan barcodegegevens op de eerste positie.<br/>            GS1 Data Identifier ISO 15434<br/>            Karakter wordt vertaald naar "[)>\u001E05\u001D" als gedecodeerde gegevensheader en "\u001E\u0004" als gedecodeerde gegevenstrailer. |
| MACRO06 | 06 Macro craracter wordt toegevoegd aan barcodegegevens op de eerste positie.<br/>            ASC MH10 Data Identifier ISO 15434<br/>            Karakter wordt vertaald naar "[)>\u001E06\u001D" als gedecodeerde gegevensheader en "\u001E\u0004" als gedecodeerde gegevenstrailer. |
