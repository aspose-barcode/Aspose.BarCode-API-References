## AztecParameters class

Aztec-parameters.

Het type AztecParameters bevat de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| encode_mode | Haalt de Aztec-coderingsmodus op of stelt deze in. <br/>            Standaardwaarde: Auto. |
| eci_encoding | Haalt de ECI-codering op of stelt deze in. Wordt gebruikt wanneer AztecEncodeMode Auto is.<br/>            Standaardwaarde: ISO-8859-1 |
| structured_append_barcode_id | Barcode-ID voor de Structured Append-modus van de Aztec-barcode. Barcode-ID moet liggen tussen 1 en het aantal barcodes.<br/>            Standaardwaarde: 0 |
| structured_append_barcodes_count | Aantal barcodes voor de Structured Append-modus van de Aztec-barcode. Het aantal barcodes moet in het bereik van 1 tot 26 liggen.<br/>            Standaardwaarde: 0 |
| structured_append_file_id | Bestands-ID voor de Structured Append-modus van de Aztec-barcode (optioneel veld). Bestands-ID mag geen spaties bevatten.<br/>            Standaardwaarde: lege tekenreeks |
| error_level | Niveau van foutcorrectie voor Aztec-typen barcode.<br/>            Waarde moet tussen 5 en 95 liggen. |
| symbol_mode | Haalt of stelt een Aztec Symbol-modus in.<br/>            Standaardwaarde: AztecSymbolMode.Auto. |
| layers_count | Haalt of stelt het aantal lagen van het Aztec-symbool in. Het aantal lagen moet in het bereik van 1 tot 3 liggen voor Compact-modus en<br/>            in het bereik van 1 tot 32 voor Full Range-modus.<br/>            Standaardwaarde: 0 (auto). |
| is_reader_initialization | Wordt gebruikt om de lezer te instrueren de gegevens binnen het symbool te interpreteren<br/>            als programmering voor lezerinitialisatie. |
| aspect_ratio | Hoogte/breedteverhouding van de 2D BarCode-module. |
