## SvgColorMode enumeration

Mogelijke modi voor het vullen van kleur in een svg‑bestand, RGB is standaard en wordt ondersteund door SVG 1.1.<br/>            RGBA, HSL, HSLA zijn toegestaan in de SVG 2.0‑standaard.<br/>            Zelfs in RGB wordt de dekking ingesteld via de parameter "fill-opacity"

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| RGB | RGB-modus, voorbeeld: fill="#ff5511" fill-opacity="0.73". Standaardmodus. |
| RGBA | RGBA-modus, voorbeeld: fill="rgba(255, 85, 17, 0.73)" |
| HSL | HSL-modus, voorbeeld: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | HSLA-modus, voorbeeld: fill="hsla(30, 50%, 70%, 0.8)" |
