## Iso15416Quality class

Slaat barcode-kwaliteitsklassen op die zijn berekend volgens de ISO/IEC 15416-standaard voor 1D-barcodes.

Het type Iso15416Quality geeft de volgende leden weer:
## Properties
| Name | Beschrijving |
| :- | :- |
| grade | Haalt de algehele barcode-kwaliteitscijfer op volgens ISO/IEC 15416. |
| decode | Haalt de decodeercijfer op die aangeeft of de barcode kan worden gedecodeerd met het referentie-decode-algoritme. |
| symbol_contrast | Haalt de symboolcontrastcijfer op op basis van het verschil tussen maximale en minimale reflectie. |
| minimum_reflectance | Haalt de minimum reflectantiegraad op basis van de donkerste balkreflectantie. |
| minimum_edge_contrast | Haalt de minimum randcontrastgraad op basis van het kleinste reflectantieverschil tussen aangrenzende balken en spaties. |
| modulation | Haalt de modulatiegraad op basis van de uniformiteit van randcontrast over de hele barcode. |
| defects | Haalt de defectengraad op basis van reflectantie‑irregulariteiten binnen balken en spaties. |
| decodability | Haalt de decodeerbaarheidsgraad op basis van de nauwkeurigheid van de breedtes van balken en spaties. |
