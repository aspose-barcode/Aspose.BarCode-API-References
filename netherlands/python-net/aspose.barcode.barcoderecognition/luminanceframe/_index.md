## LuminanceFrame class

Stelt een 8-bit grijswaardenbeeldframe voor. Elke pixel wordt weergegeven door één byte die de luminantiewaarde bevat.

Het type LuminanceFrame bevat de volgende leden:
## Constructors
| Name | Beschrijving |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Initialiseert een nieuw exemplaar van de LuminanceFrame-klasse |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Initialiseert een nieuw exemplaar van de LuminanceFrame-klasse |
## Properties
| Name | Beschrijving |
| :- | :- |
| data | Haalt de luminantiegegevens op. |
| width | Haalt de breedte van het frame op in pixels. |
| height | Haalt de hoogte van het frame op in pixels. |
| row_stride | Haalt de afstand in bytes op tussen de beginnen<br/>            van twee aangrenzende rijen. |
| rotation_degrees | Haalt het aantal graden op dat het frame met de klok mee moet worden gedraaid om de juiste oriëntatie te hebben. |
