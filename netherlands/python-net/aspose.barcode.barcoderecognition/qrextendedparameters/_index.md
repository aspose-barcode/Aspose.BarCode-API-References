## QRExtendedParameters class

Slaat QR Structured Append-informatie van een door QR Structured Append herkende barcode op.

Het type QRExtendedParameters bevat de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| is_empty | Test of alle parameters alleen standaardwaarden hebben |
| structured_append_mode_bar_codes_quantity | Haalt de hoeveelheid QR-gestructureerde append-modus barcodes op. Standaardwaarde is -1. |
| structured_append_mode_bar_code_index | Haalt de index van de QR-gestructureerde append-modus barcode op. Index begint bij 0. Standaardwaarde is -1. |
| structured_append_mode_parity_data | Haalt de QR-gestructureerde append-modus pariteitsgegevens op. Standaardwaarde is -1. |
| version | Versie van herkende QR-code. Van Versie1 tot Versie40. |
| micro_qr_version | Versie van herkende MicroQR-code. Van M1 tot M4. |
| rect_micro_qr_version | Versie van herkende RectMicroQR-code. Van R7x43 tot R17x139. |
| error_level | Reed-Solomon-foutcorrectieniveau van herkende barcode. Van laag naar hoog: LevelL, LevelM, LevelQ, LevelH. |
