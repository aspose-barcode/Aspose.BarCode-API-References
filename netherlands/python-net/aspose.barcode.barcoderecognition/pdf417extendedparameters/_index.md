## Pdf417ExtendedParameters class

Slaat metadata-informatie van een door MacroPdf417 herkende barcode op.

Het type Pdf417ExtendedParameters exposeert de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| is_empty | Test of alle parameters alleen standaardwaarden hebben |
| macro_pdf_417_file_id | Haalt de bestands-ID van de barcode op, alleen beschikbaar met MacroPdf417. |
| macro_pdf_417_segment_id | Haalt de segment-ID van de barcode op,alleen beschikbaar met MacroPdf417. |
| macro_pdf_417_segments_count | Haalt het aantal macro pdf417 barcode-segmenten op. Standaardwaarde is -1. |
| macro_pdf_417_file_name | Macro PDF417 bestandsnaam (optioneel). |
| macro_pdf_417_file_size | Macro PDF417 bestandsgrootte (optioneel). |
| macro_pdf_417_sender | Macro PDF417 afzendernaam (optioneel). |
| macro_pdf_417_addressee | Macro PDF417 geadresseerde naam (optioneel). |
| macro_pdf_417_time_stamp | Macro PDF417 tijdstempel (optioneel). |
| macro_pdf_417_checksum | Macro PDF417 controlesom (optioneel). |
| macro_pdf_417_terminator | Geeft aan of het segment het laatste segment van een Macro PDF417-bestand is. |
| is_reader_initialization | Wordt gebruikt om de lezer te instrueren de gegevens in het symbool te interpreteren als programmering voor lezerinitialisatie. |
| is_linked | Vlag die aangeeft dat de barcode moet worden gekoppeld aan een 1D-barcode. |
| is_code_128_emulation | Vlag die aangeeft dat de MicroPdf417-barcode is gecodeerd met 908, 909, 910 of 911 Code 128-emulatiecodewoorden. |
