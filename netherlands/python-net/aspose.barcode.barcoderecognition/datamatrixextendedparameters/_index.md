## DataMatrixExtendedParameters class

Slaat speciale gegevens van de herkende DataMatrix-barcode op.

Het type DataMatrixExtendedParameters exposeert de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| is_empty | Test of alle parameters alleen standaardwaarden hebben |
| structured_append_barcodes_count | Haalt het aantal barcodes in de DataMatrix structured append-modus op. Standaardwaarde is -1. Het aantal moet een waarde tussen 1 en 35 zijn. |
| structured_append_barcode_id | Haalt de ID van de DataMatrix structured append-modus barcode op. De ID begint bij 1 en moet kleiner of gelijk zijn aan het aantal barcodes. Standaardwaarde is -1. |
| structured_append_file_id | Haalt de ID van de DataMatrix structured append-modus barcode op. De ID begint bij 1 en moet kleiner of gelijk zijn aan het aantal barcodes. Standaardwaarde is -1. |
| is_reader_programming | Geeft aan of de code wordt gebruikt om de lezer te instrueren de volgende gegevens te interpreteren als instructies voor initialisatie of herprogrammering van de barcodelezer.<br/>            Standaardwaarde is false. |
