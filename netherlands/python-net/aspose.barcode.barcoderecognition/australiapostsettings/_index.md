## AustraliaPostSettings class

AustraliaPost-decoderingparameters. Bevat parameters die invloed hebben op de herkende gegevens van AustraliaPost-symbologie.

Het type AustraliaPostSettings exposeert de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| customer_information_interpreting_type | Haalt op of stelt het Interpreteertype in voor de klantinformatie van AustralianPost BarCode. Standaard is CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | De vlag die de AustraliaPost-decoder dwingt om de laatste vulpatronen in het Customer Information Field te negeren tijdens het decoderen met de CTable-methode.<br/>            De CTable-coderingsmethode heeft geen gaten in de coderingtabel en de reeks "333" van vulpatronen wordt gedecodeerd als de letter "z". |
| customer_information_decoder | Publieke interface voor het decoderen van het Customer Information Field die wordt gebruikt in de AustraliaPost-symbologie. |
