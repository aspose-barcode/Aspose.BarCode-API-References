## AustraliaPostCustomerInformationDecoder class

Publieke interface voor het decoderen van het Customer Information Field dat wordt gebruikt in AustraliaPost-symbologie. Implementatie moet door de gebruiker worden geleverd.

Het type AustraliaPostCustomerInformationDecoder bevat de volgende leden:
## Methods
| Name | Beschrijving |
| :- | :- |
| decode(customer_information_field) | Decodeer het Customer Information Field van de AustraliaPost-symbologie. <br/>            Kan worden gebruikt voor verschillende gegevensinterpretaties van NTable- en CTable-codering.<br/>            Gegevens worden geleverd als een rij balkwaarden: 0, 1, 2 of 3. |
