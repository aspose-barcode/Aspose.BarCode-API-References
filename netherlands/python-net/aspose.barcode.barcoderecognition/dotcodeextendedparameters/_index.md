## DotCodeExtendedParameters class

Slaat speciale gegevens op van een door DotCode herkende barcode.

Het type DotCodeExtendedParameters bevat de volgende leden:
## Properties
| Name | Beschrijving |
| :- | :- |
| is_empty | Test of alle parameters alleen standaardwaarden hebben |
| structured_append_mode_barcodes_count | Haalt het aantal barcodes in de gestructureerde append‑modus van DotCode op. Standaardwaarde is -1. Het aantal moet een waarde tussen 1 en 35 zijn. |
| structured_append_mode_barcode_id | Haalt de ID op van de barcode in de gestructureerde append‑modus van DotCode. De ID begint bij 1 en moet kleiner of gelijk zijn aan het aantal barcodes. Standaardwaarde is -1. |
| is_reader_initialization | Geeft aan of de code wordt gebruikt om de lezer te instrueren de volgende gegevens te interpreteren als instructies voor initialisatie of herprogrammering van de barcodelezer.<br/>            Standaardwaarde is false. |
