## GraphicsUnit

Specificeert de meeteenheid voor de gegeven gegevens.

## Waarden

| Naam | Beschrijving |
| --- | --- |
| WORLD | Specificeert de eenheid van het wereldcoördinatensysteem als de meeteenheid. |
| DISPLAY | Specificeert de meeteenheid van het weergaveapparaat. Meestal pixels voor videodisplays en 1/100 inch voor printers. |
| PIXEL | Specificeert een apparaatpixel als de meeteenheid. |
| POINT | Specificeert een printerpunt = 1/72 inch) als de meeteenheid. |
| INCH | Specificeert de inch als de meeteenheid. |
| DOCUMENT | Specificeert de documenteenheid = 1/300 inch) als de meeteenheid. |
| MILLIMETER | Specificeert de millimeter als de meeteenheid. |
