## BarCodeImageFormat

Specificeert het bestandsformaat van de afbeelding.

## Waarden

| Naam | Beschrijving |
| --- | --- |
| BMP | Specificeert het bitmap (BMP) afbeeldingformaat. |
| GIF | Specificeert het Graphics Interchange Format (GIF) afbeeldingformaat. |
| JPEG | Specificeert het Joint Photographic Experts Group (JPEG) afbeeldingformaat. |
| PNG | Specificeert het W3C Portable Network Graphics (PNG) afbeeldingformaat. |
| TIFF | Specificeert het Tagged Image File Format (TIFF) afbeeldingformaat. |
| TIFF_IN_CMYK | Specificeert het Tagged Image File Format (TIFF) afbeeldingformaat in het CMYK-kleermodel. |
| EMF | Specificeert het Enhanced Metafile (EMF) afbeeldingformaat. |
| SVG | Specificeert het Scalable Vector Graphics (SVG) afbeeldingformaat. |
| PDF | Specificeert het Portable Document Format (PDF) afbeeldingformaat. |
