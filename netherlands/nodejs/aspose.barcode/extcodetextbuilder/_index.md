## ExtCodetextBuilder class

Helperklasse voor automatische codetextgeneratie van de Extended Codetext Mode

```js
new ExtCodetextBuilder()
```

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [addECICodetext(ECIEncoding, codetext)](#addecicodetext) | Voegt codetekst toe met Extended Channel Identifier |
| [addPlainCodetext(codetext)](#addplaincodetext) | Voegt platte codetekst toe aan de uitgebreide codetekstitems |
| [clear()](#clear) | Wis de uitgebreide codetekstitems |
| [getExtendedCodetext()](#getextendedcodetext) | Genereer uitgebreide codetekst uit de lijst met generatie-items |

### addECICodetext(ECIEncoding, codetext) {#addecicodetext}

Voegt codetekst toe met Extended Channel Identifier

| Parameter | Beschrijving |
| --- | --- |
| ECIEncoding | Extended Channel Identifier |
| codetext | Codetekst in Unicode om toe te voegen als uitgebreid codetekstitem met Extended Channel Identifier |

### addPlainCodetext(codetext) {#addplaincodetext}

Voegt platte codetekst toe aan de uitgebreide codetekstitems

| Parameter | Beschrijving |
| --- | --- |
| codetext | Codetext in Unicode om toe te voegen als uitgebreid codetextitem |

### clear() {#clear}

### getExtendedCodetext() {#getextendedcodetext}

Genereer uitgebreide codetekst uit de lijst met generatie-items
