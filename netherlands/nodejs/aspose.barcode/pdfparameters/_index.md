## PdfParameters class

PDF-parameterswrapper. Verwacht een onderliggend `mwObject`-instance dat de overeenkomstige getter/setter‑methoden levert die CMYK‑strings retourneren/aanvaarden zoals "30_100_0_30" of `null`.

```js
new PdfParameters(mwObject)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| mwObject | object | – instantie van de Java PdfParameters‑klasse |
