## RecognitionAbortedException class

Stelt een herkenningsafbreek-exceptie voor die wordt gegooid bij het overschrijden van de time-out tijdens herkenning met BarCodeReader.

```js
new RecognitionAbortedException(message, executionTime)
```

Initialiseert een nieuwe instantie van de klasse met een opgegeven herkenningsafbrekingsbericht.

| Parameter | Beschrijving |
| --- | --- |
| message | Het foutbericht van de exceptie. |
| executionTime | De uitvoeringstijd van de huidige herkenningssessie. |
