## Code128DataPortion class

Bevat de gegevens van subtype voor Code128-type barcode

```js
new Code128DataPortion()
```

Maakt een nieuw exemplaar van de `Code128DataPortion`-klasse met startcode‑symbool en gedecodeerde codetekst.

## Methoden

| Naam | Beschrijving |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Haalt het type van de Code128-subset op |
| [getData()](#getdata) | Haalt het deel van de codetekst op dat gerelateerd is aan de subtype. |
| [toString()](#tostring) | Retourneert een menselijk leesbare tekenreeksrepresentatie van deze `Code128DataPortion`. |

### getCode128SubType() {#getcode128subtype}

Haalt het type van de Code128-subset op

**Returns:** The type of Code128 subset

### getData() {#getdata}

Haalt het deel van de codetekst op dat gerelateerd is aan de subtype.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Retourneert een menselijk leesbare tekenreeksrepresentatie van deze `Code128DataPortion`.

**Returns:** A string that represents this `Code128DataPortion`.
