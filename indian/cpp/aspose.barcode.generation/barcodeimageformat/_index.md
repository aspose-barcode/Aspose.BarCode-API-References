## BarCodeImageFormat enum

enum class BarCodeImageFormat

| नाम | मान | विवरण |
| --- | --- | --- |
| Bmp | 0 | बिटमैप (BMP) छवि फ़ॉर्मेट निर्दिष्ट करता है। |
| Gif | 1 | ग्राफ़िक्स इंटरचेंज फ़ॉर्मेट (GIF) छवि फ़ॉर्मेट निर्दिष्ट करता है। |
| Jpeg | 2 | जॉइंट फ़ोटोग्राफ़िक एक्सपर्ट्स ग्रुप (JPEG) छवि फ़ॉर्मेट निर्दिष्ट करता है। |
| Png | 3 | W3C पोर्टेबल नेटवर्क ग्राफ़िक्स (PNG) छवि फ़ॉर्मेट निर्दिष्ट करता है। |
| Tiff | 4 | टैग्ड इमेज फ़ाइल फ़ॉर्मेट (TIFF) छवि फ़ॉर्मेट निर्दिष्ट करता है। |
| TiffInCmyk | 5 | CMYK रंग मॉडल में Tagged Image File Format (TIFF) इमेज फ़ॉर्मेट को निर्दिष्ट करता है। (केवल [Windows](../../aspose.barcode.windows/) प्लेटफ़ॉर्म पर समर्थित है, *nix प्लेटफ़ॉर्म पर इसे Tiff के रूप में सहेजा जाता है) |
| Emf | 6 | Enhanced Metafile (EMF) इमेज फ़ॉर्मेट को निर्दिष्ट करता है। (केवल [Windows](../../aspose.barcode.windows/) प्लेटफ़ॉर्म पर समर्थित है, *nix प्लेटफ़ॉर्म पर इसे PNG के रूप में सहेजा जाता है) |
| Svg | 7 | Scalable Vector Graphics (SVG) इमेज फ़ॉर्मेट को निर्दिष्ट करता है। |
