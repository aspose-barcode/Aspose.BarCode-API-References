## BorderParameters class

बारकोड इमेज बॉर्डर पैरामीटर

```js
new BorderParameters()
```

### getColor() {#getcolor}

बॉर्डर रंग। डिफ़ॉल्ट मान: #000000

### getDashStyle() {#getdashstyle}

बॉर्डर डैश शैली। डिफ़ॉल्ट मान: BorderDashStyle.SOLID.

### getVisible() {#getvisible}

बॉर्डर दृश्यता। यदि false हो तो पैरामीटर Width हमेशा अनदेखा किया जाता है (0)। डिफ़ॉल्ट मान: false.

### getWidth() {#getwidth}

बॉर्डर चौड़ाई। डिफ़ॉल्ट मान: 0। यदि Visible को false सेट किया गया है तो इसे अनदेखा किया जाता है।

### setColor() {#setcolor}

बॉर्डर रंग। डिफ़ॉल्ट मान: #000000

### setDashStyle() {#setdashstyle}

बॉर्डर डैश शैली। डिफ़ॉल्ट मान: BorderDashStyle.SOLID.

### setVisible() {#setvisible}

बॉर्डर दृश्यता। यदि false हो तो पैरामीटर Width हमेशा अनदेखा किया जाता है (0)। डिफ़ॉल्ट मान: false.

### setWidth() {#setwidth}

बॉर्डर चौड़ाई। डिफ़ॉल्ट मान: 0। यदि Visible को false सेट किया गया है तो इसे अनदेखा किया जाता है।

### toString() {#tostring}

इस BorderParameters की मानव-पठनीय स्ट्रिंग प्रतिनिधित्व लौटाता है।

**Returns:** A string that represents this BorderParameters.
