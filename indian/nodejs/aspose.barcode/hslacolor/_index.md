## HslaColor class

HSLA रंग (ह्यू, सैचुरेशन, लाइटनेस, अल्फा) को दर्शाने के लिए क्लास।

```js
new HslaColor(h, s, l, a)
```

HslaColor का कंस्ट्रक्टर

| पैरामीटर | विवरण |
| --- | --- |
| h | ह्यू [0, 360] |
| s | सैचुरेशन [0, 100] |
| l | लाइटनेस [0, 100] |
| a | अल्फा (अपारदर्शिता) [0.0f, 1.0f] |
