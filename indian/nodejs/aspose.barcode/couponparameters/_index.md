## CouponParameters class

कूपन पैरामीटर। UpcaGs1DatabarCoupon, UpcaGs1Code128Coupon के लिए उपयोग किया जाता है।

```js
new CouponParameters()
```

## विधियाँ

| नाम | विवरण |
| --- | --- |
| [getSupplementSpace()](#getsupplementspace) | मुख्य BarCode और सप्लीमेंट BarCode के बीच यूनिट मान में अंतराल। |
| [setSupplementSpace()](#setsupplementspace) | मुख्य BarCode और सप्लीमेंट BarCode के बीच यूनिट मान में अंतराल। |
| [toString()](#tostring) | इस CouponParameters की मानव-पठनीय स्ट्रिंग प्रतिनिधित्व लौटाता है। |

### getSupplementSpace() {#getsupplementspace}

मुख्य BarCode और सप्लीमेंट BarCode के बीच यूनिट मान में अंतराल।

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementSpace() {#setsupplementspace}

मुख्य BarCode और सप्लीमेंट BarCode के बीच यूनिट मान में अंतराल।

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### toString() {#tostring}

इस CouponParameters की मानव-पठनीय स्ट्रिंग प्रतिनिधित्व लौटाता है।

**Returns:** A string that represents this CouponParameters.
