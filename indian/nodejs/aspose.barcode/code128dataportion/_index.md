## Code128DataPortion class

Code128 प्रकार के बारकोड के सबटाइप का डेटा शामिल करता है

```js
new Code128DataPortion()
```

स्टार्ट कोड सिंबल और डिकोडेड कोडटेक्स्ट के साथ `Code128DataPortion` क्लास का नया इंस्टेंस बनाता है।

## विधियाँ

| नाम | विवरण |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Code128 उपसमुच्चय का प्रकार प्राप्त करता है |
| [getData()](#getdata) | उपप्रकार से संबंधित कोड टेक्स्ट का भाग प्राप्त करता है। |
| [toString()](#tostring) | इस `Code128DataPortion` की मानव-पठनीय स्ट्रिंग प्रतिनिधित्व लौटाता है। |

### getCode128SubType() {#getcode128subtype}

Code128 उपसमुच्चय का प्रकार प्राप्त करता है

**Returns:** The type of Code128 subset

### getData() {#getdata}

उपप्रकार से संबंधित कोड टेक्स्ट का भाग प्राप्त करता है।

**Returns:** The part of code text related to subtype

### toString() {#tostring}

इस `Code128DataPortion` की मानव-पठनीय स्ट्रिंग प्रतिनिधित्व लौटाता है।

**Returns:** A string that represents this `Code128DataPortion`.
