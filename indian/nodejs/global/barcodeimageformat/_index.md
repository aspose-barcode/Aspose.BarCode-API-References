## BarCodeImageFormat

इमेज का फ़ाइल फ़ॉर्मेट निर्दिष्ट करता है।

## मान

| नाम | विवरण |
| --- | --- |
| BMP | बिटमैप (BMP) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| GIF | ग्राफ़िक्स इंटरचेंज फ़ॉर्मेट (GIF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| JPEG | जॉइंट फ़ोटोग्राफ़िक एक्सपर्ट्स ग्रुप (JPEG) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| PNG | W3C पोर्टेबल नेटवर्क ग्राफ़िक्स (PNG) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| TIFF | टैग्ड इमेज फ़ाइल फ़ॉर्मेट (TIFF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| TIFF_IN_CMYK | CMYK कलर मॉडल में टैग्ड इमेज फ़ाइल फ़ॉर्मेट (TIFF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| EMF | एन्हांस्ड मेटा फ़ाइल (EMF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| SVG | Scalable Vector Graphics (SVG) इमेज फ़ॉर्मेट को निर्दिष्ट करता है। |
| PDF | Portable Document Format (PDF) इमेज फ़ॉर्मेट को निर्दिष्ट करता है। |
