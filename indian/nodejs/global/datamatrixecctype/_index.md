## DataMatrixEccType

एन्कोड करने के लिए ECC का प्रकार निर्दिष्ट करें।

## मान

| नाम | विवरण |
| --- | --- |
| ECC_AUTO | निर्दिष्ट करता है कि एन्कोडेड Ecc प्रकार डिफ़ॉल्ट Reed-Solomon त्रुटि सुधार या ECC 200 द्वारा परिभाषित है। |
| ECC_000 | निर्दिष्ट करता है कि एन्कोडेड Ecc प्रकार ECC 000 द्वारा परिभाषित है। |
| ECC_050 | निर्दिष्ट करता है कि एन्कोडेड Ecc प्रकार ECC 050 द्वारा परिभाषित है। |
| ECC_080 | निर्दिष्ट करता है कि एन्कोडेड Ecc प्रकार ECC 080 द्वारा परिभाषित है। |
| ECC_100 | निर्दिष्ट करता है कि एन्कोडेड Ecc प्रकार ECC 100 द्वारा परिभाषित है। |
| ECC_140 | निर्दिष्ट करता है कि एन्कोडेड Ecc प्रकार ECC 140 के रूप में परिभाषित है। |
| ECC_200 | निर्दिष्ट करता है कि एन्कोडेड Ecc प्रकार ECC 200 के रूप में परिभाषित है। उपयोग करने की अनुशंसा की जाती है। |
