## ITF14BorderType

## मान

| नाम | विवरण |
| --- | --- |
| NONE | बारकोड को घेरने वाली कोई सीमा नहीं |
| FRAME | बारकोड को घेरने वाला FRAME |
| BAR | बारकोड को घेरने वाले दो क्षैतिज BAR |
| FRAME_OUT | बारकोड को घेरने वाला FRAME |
| BAR_OUT | बारकोड को घेरने वाले दो क्षैतिज BAR |
