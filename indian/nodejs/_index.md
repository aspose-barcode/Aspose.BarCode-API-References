API बारकोड निर्माण, पहचान और हेरफेर के लिए क्लासेज़ प्रदान करता है, जिससे Java इंटरऑप के माध्यम से Node.js अनुप्रयोगों में सहज एकीकरण संभव होता है। समर्थित सिम्बोलॉजीज़ में रैखिक, 2‑D, और पोस्टल कोड जैसे Code128, EAN‑13, QR, DataMatrix, Aztec, और PDF417 शामिल हैं। सभी कार्यक्षमता aspose.barcode नेमस्पेस के तहत व्यवस्थित है, जबकि सहायक उपयोगिताएँ Global नेमस्पेस में स्थित हैं।
