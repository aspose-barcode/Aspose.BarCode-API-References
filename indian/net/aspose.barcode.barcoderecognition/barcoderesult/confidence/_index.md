## BarCodeResult.Confidence property

पहचाने गए बारकोड का पहचान विश्वसनीयता स्तर प्राप्त करता है

```csharp
public BarCodeConfidence Confidence { get; }
```

### Property Value

Strong में नकली या गलत पहचान नहीं होती, Moderate में कभी‑कभी नकली या गलत कोडटेक्स्ट हो सकता है क्योंकि यह भरोसेमंद स्तर कमजोर चेकसम वाले या बिना चेकसम वाले बारकोड्स के लिए है, None में हमेशा गलत कोडटेक्स्ट होता है और यह नकली पहचान हो सकती है।
