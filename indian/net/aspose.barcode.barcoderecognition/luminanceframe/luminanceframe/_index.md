## LuminanceFrame(byte[], int, int, int) {#constructor}

पंक्तियों के बीच पैडिंग के बिना [`LuminanceFrame`](../) क्लास का नया इंस्टेंस प्रारंभ करता है। क्रमागत पंक्तियों के बीच की दूरी *width* के बराबर होती है।

```csharp
public LuminanceFrame(byte[] data, int width, int height, int rotationDegrees = 0)
```

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| data | Byte[] | प्रति पिक्सेल एक बाइट वाला ल्यूमिनेंस डेटा। |
| width | Int32 | फ़्रेम की चौड़ाई पिक्सेल में। |
| height | Int32 | फ़्रेम की ऊँचाई पिक्सेल में। |
| rotationDegrees | Int32 | फ़्रेम को सीधा दिखाने के लिए आवश्यक घड़ी की दिशा में घुमाव। समर्थित मान 0, 90, 180 और 270 हैं। डिफ़ॉल्ट मान 0 है। |
