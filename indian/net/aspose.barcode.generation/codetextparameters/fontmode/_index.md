## CodetextParameters.FontMode property

FontMode निर्दिष्ट करें। यदि FontMode को Auto पर सेट किया जाता है, तो फ़ॉन्ट आकार xDimension मान के आधार पर स्वचालित रूप से गणना किया जाएगा। AutoSizeMode.Nearest या AutoSizeMode.Interpolation में विशेष रूप से FontMode.Auto का उपयोग करने की सिफारिश की जाती है। डिफ़ॉल्ट मान: FontMode.Auto.

```csharp
public FontMode FontMode { get; set; }
```
