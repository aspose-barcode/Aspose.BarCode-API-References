## BarcodeParameters.ThrowExceptionWhenCodeTextIncorrect property

केवल 1D बारकोड्स के लिए। यदि codetext गलत है और मान true पर सेट किया गया है - अपवाद फेंका जाएगा। अन्यथा codetext को बारकोड की विशिष्टता के अनुसार सुधारा जाएगा। अपवाद हमेशा फेंका जाएगा: Databar सिम्बोलॉजी के लिए यदि codetext गलत है। अपवाद हमेशा नहीं फेंका जाएगा: AustraliaPost, SingapurePost, Code39FullASCII, Code93, Code16K, Code128 सिम्बोलॉजी के लिए यदि codetext गलत है।

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
