## SwissQRBill.Reference property

लेनदार भुगतान संदर्भ को प्राप्त करता है या सेट करता है।

SwissQR IBAN के लिए संदर्भ अनिवार्य है, अर्थात् CHxx30000xxxxxx से CHxx31999xxxxx तक की रेंज वाले IBAN।

यदि निर्दिष्ट किया गया है, तो संदर्भ या तो वैध SwissQR संदर्भ (ISR संदर्भ फ़ॉर्म के अनुरूप) या ISO 11649 ("RFxxxx") के अनुसार वैध लेनदार संदर्भ होना चाहिए। दोनों में फ़ॉर्मेटिंग के लिए स्पेस हो सकते हैं।

```csharp
public string Reference { get; set; }
```
