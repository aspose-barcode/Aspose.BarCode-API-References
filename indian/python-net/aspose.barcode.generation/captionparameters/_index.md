## CaptionParameters class

कैप्शन पैरामीटर।

CaptionParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| text | कैप्शन टेक्स्ट.<br/>            डिफ़ॉल्ट मान: खाली स्ट्रिंग। |
| font | कैप्शन फ़ॉन्ट.<br/>            डिफ़ॉल्ट मान: Arial 8pt regular. |
| visible | कैप्शन टेक्स्ट दृश्यता.<br/>            डिफ़ॉल्ट मान: false. |
| text_color | कैप्शन टेक्स्ट रंग.<br/>            डिफ़ॉल्ट मान: Color.Black. |
| padding | कैप्शन पैडिंग्स.<br/>            CaptionAbove के लिए डिफ़ॉल्ट मान: 5pt 5pt 0 5pt.<br/>            CaptionBelow के लिए डिफ़ॉल्ट मान: 0 5pt 5pt 5pt. |
| संरेखण | कैप्शन टेस्ट क्षैतिज संरेखण.<br/>            डिफ़ॉल्ट मान: StringAlignment.Center. |
| no_wrap | पाठ के भीतर शब्द रैप (लाइन ब्रेक) निर्दिष्ट करें।<br/>            डिफ़ॉल्ट मान: false. |
