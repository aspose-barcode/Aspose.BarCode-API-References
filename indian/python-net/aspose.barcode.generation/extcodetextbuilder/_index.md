## ExtCodetextBuilder class

Extended Codetext Mode की स्वचालित कोडटेक्स्ट जनरेशन के लिए हेल्पर क्लास।

ExtCodetextBuilder प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## विधियाँ
| नाम | विवरण |
| :- | :- |
| clear() | विस्तारित कोडटेक्स्ट आइटम साफ़ करता है |
| add_plain_codetext(codetext) | साधारण कोडटेक्स्ट को विस्तारित कोडटेक्स्ट आइटम में जोड़ता है |
| add_eci_codetext(eci_encoding, codetext) | विस्तारित चैनल पहचानकर्ता के साथ कोडटेक्स्ट जोड़ता है |
| get_extended_codetext() | जनरेशन आइटम सूची से विस्तारित कोडटेक्स्ट उत्पन्न करें |
