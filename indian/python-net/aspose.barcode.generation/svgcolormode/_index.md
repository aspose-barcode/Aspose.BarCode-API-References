## SvgColorMode enumeration

svg फ़ाइल में रंग भरने के संभावित मोड, RGB डिफ़ॉल्ट है और SVG 1.1 द्वारा समर्थित है।<br/>            RGBA, HSL, HSLA SVG 2.0 मानक में अनुमति हैं।<br/>            यहां तक कि RGB में अपारदर्शिता "fill-opacity" पैरामीटर के माध्यम से सेट की जाएगी।

## Members
| सदस्य नाम | विवरण |
| :- | :- |
| RGB | RGB मोड, उदाहरण: fill=\"#ff5511\" fill-opacity=\"0.73\"। डिफ़ॉल्ट मोड। |
| RGBA | RGBA मोड, उदाहरण: fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | HSL मोड, उदाहरण: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | HSLA मोड, उदाहरण: fill=\"hsla(30, 50%, 70%, 0.8)\" |
