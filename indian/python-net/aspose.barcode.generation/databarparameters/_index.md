## DataBarParameters class

Databar पैरामीटर।

DataBarParameters प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_2d_composite_component | DataBar बारकोड के साथ 2D संयुक्त घटक का फ़्लैग सक्षम करता है |
| allow_only_gs1_encoding | यदि यह फ़्लैग सेट किया जाता है, तो यह Databar बारकोड प्रकारों के लिए केवल GS1 एन्कोडिंग मानक की अनुमति देता है |
| स्तम्भ | स्तम्भों की गिनती। |
| पंक्तियाँ | पंक्तियों की गिनती। |
| aspect_ratio | 2D बारकोड मॉड्यूल का ऊँचाई/चौड़ाई अनुपात।<br/>            DataBar स्टैक्ड के लिए उपयोग किया जाता है। |
