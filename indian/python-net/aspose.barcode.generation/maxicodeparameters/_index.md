## MaxiCodeParameters class

मैक्सीकोड पैरामीटर।

MaxiCodeParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| मोड | MaxiCode एन्कोड मोड को प्राप्त करता है या सेट करता है। |
| encode_mode | MaxiCode एन्कोड मोड को प्राप्त करता है या सेट करता है। <br/>            डिफ़ॉल्ट मान: Auto. |
| eci_encoding | ECI एन्कोडिंग को प्राप्त करता है या सेट करता है। जब MaxiCodeEncodeMode Auto हो तब उपयोग किया जाता है।<br/>            डिफ़ॉल्ट मान: ISO-8859-1 |
| structured_append_mode_barcode_id | संरचित एपेंड मोड में MaxiCode बारकोड आईडी को प्राप्त करता है या सेट करता है। <br/>            आईडी 1 से 8 के बीच का मान होना चाहिए। <br/>            डिफ़ॉल्ट मान: 0 |
| structured_append_mode_barcodes_count | संरचित एपेंड मोड में MaxiCode बारकोड की गिनती को प्राप्त करता है या सेट करता है। <br/>            गिनती का मान 2 से 8 के बीच होना चाहिए (अधिकतम बारकोड गिनती)।<br/>            डिफ़ॉल्ट मान: -1 |
| aspect_ratio | 2D बारकोड मॉड्यूल का ऊँचाई/चौड़ाई अनुपात। |
