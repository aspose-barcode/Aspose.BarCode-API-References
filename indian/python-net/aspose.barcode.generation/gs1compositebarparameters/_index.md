## GS1CompositeBarParameters class

GS1 कॉम्पोज़िट बार पैरामीटर।

GS1CompositeBarParameters प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| linear_component_type | रैखिक घटक प्रकार: GS1Code128, UPCE, EAN8, UPCA, EAN13, DatabarStacked, DatabarStackedOmniDirectional, DatabarLimited, DatabarOmniDirectional, DatabarExpanded, DatabarExpandedStacked |
| two_d_component_type | 2D घटक प्रकार |
| allow_only_gs1_encoding | यदि यह फ़्लैग सेट किया गया है, तो यह GS1CompositeBar 2D घटक के लिए केवल GS1 एन्कोडिंग मानक की अनुमति देता है |
