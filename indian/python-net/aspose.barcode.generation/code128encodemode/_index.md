## Code128EncodeMode enumeration

Code128 बारकोड के लिए एन्कोडिंग मोड।

## Members
| सदस्य नाम | विवरण |
| :- | :- |
| AUTO | कोडटेक्स्ट को क्लासिक ISO 15417 मोड में एन्कोड करें। इस मोड का उपयोग सभी सामान्य मामलों में किया जाना चाहिए। |
| CODE_A | कोडटेक्स्ट को केवल 128A कोडसेट में एन्कोड करें। |
| CODE_B | कोडटेक्स्ट को केवल 128B कोडसेट में एन्कोड करें। |
| CODE_C | कोडटेक्स्ट को केवल 128C कोडसेट में एन्कोड करें। |
| CODE_AB | कोडटेक्स्ट को केवल 128A और 128B कोडसेट्स में एन्कोड करें। |
| CODE_AC | कोडटेक्स्ट को केवल 128A और 128C कोडसेट्स में एन्कोड करें। |
| CODE_BC | कोडटेक्स्ट को केवल 128B और 128C कोडसेट्स में एन्कोड करें। |
