## PdfParameters class

PDF पैरामीटर।

PdfParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| cmyk_bar_color | Nullable. बारकोड का CMYK रंग मान। Null का अर्थ है कि CMYK रंग उपयोग नहीं किया जाता, इसके बजाय सामान्य RGB रंग उपयोग किया जाता है. |
| cmyk_back_color | Nullable. बैक रंग का CMYK मान। Null का अर्थ है कि CMYK रंग उपयोग नहीं किया जाता, इसके बजाय सामान्य RGB रंग उपयोग किया जाता है. |
| cmyk_codetext_color | Nullable. कोडटेक्स्ट का CMYK रंग मान। Null का अर्थ है कि CMYK रंग उपयोग नहीं किया जाता, इसके बजाय सामान्य RGB रंग उपयोग किया जाता है. |
| cmyk_caption_above_color | Nullable. ऊपर के कैप्शन का CMYK रंग मान। Null का अर्थ है कि CMYK रंग उपयोग नहीं किया जाता, इसके बजाय सामान्य RGB रंग उपयोग किया जाता है. |
| cmyk_caption_below_color | Nullable. नीचे के कैप्शन का CMYK रंग मान। Null का अर्थ है कि CMYK रंग उपयोग नहीं किया जाता, इसके बजाय सामान्य RGB रंग उपयोग किया जाता है. |
| is_text_as_path | क्या पाथ्स का उपयोग टेक्स्ट के बजाय किया जाता है (यदि यूनिकोड अक्षर प्रदर्शित नहीं होते तो उपयोग करें)<br/>            डिफ़ॉल्ट मान: false. |
