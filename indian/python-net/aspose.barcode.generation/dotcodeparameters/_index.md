## DotCodeParameters class

DotCode पैरामीटर।

DotCodeParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| aspect_ratio | 2D बारकोड मॉड्यूल का ऊँचाई/चौड़ाई अनुपात। |
| encode_mode | DotCode एन्कोड मोड को पहचानता है। <br/>            डिफ़ॉल्ट मान: Auto. |
| is_reader_initialization | यह दर्शाता है कि क्या कोड का उपयोग रीडर को निम्न डेटा को प्रारंभिककरण या बारकोड रीडर के पुनःप्रोग्रामिंग के निर्देशों के रूप में व्याख्या करने के लिए किया जाता है।<br/>            डिफ़ॉल्ट मान false है। |
| structured_append_mode_barcode_id | DotCode संरचित जोड़ मोड बारकोड का ID पहचानता है। ID 1 से शुरू होती है और बारकोड की संख्या से कम या बराबर होनी चाहिए। डिफ़ॉल्ट मान -1 है। |
| structured_append_mode_barcodes_count | DotCode संरचित जोड़ मोड बारकोड की संख्या को पहचानता है। डिफ़ॉल्ट मान -1 है। संख्या 1 से 35 के बीच होनी चाहिए। |
| eci_encoding | ECI एन्कोडिंग को पहचानता है। जब DotCodeEncodeMode Auto हो तो उपयोग किया जाता है।<br/>            डिफ़ॉल्ट मान: ISO-8859-1 |
| पंक्तियाँ | पंक्तियों की संख्या को पहचानता है। DotCode प्रतीक की पंक्तियों और स्तंभों की संख्या का योग विषम होना चाहिए। पंक्तियों की संख्या कम से कम 5 होनी चाहिए।<br/>            डिफ़ॉल्ट मान: -1 |
| स्तम्भ | स्तंभों की संख्या को पहचानता है। DotCode प्रतीक की पंक्तियों और स्तंभों की संख्या का योग विषम होना चाहिए। स्तंभों की संख्या कम से कम 5 होनी चाहिए।<br/>            डिफ़ॉल्ट मान: -1 |
