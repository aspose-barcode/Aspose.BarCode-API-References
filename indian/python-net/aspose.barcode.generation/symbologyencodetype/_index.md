## SymbologyEncodeType class

सिम्बोलॉजी एन्कोड प्रकार। उदाहरण प्राप्त करने के लिए EncodeTypes देखें।

SymbologyEncodeType प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| type_index | एन्कोड प्रकार का सूचकांक प्राप्त करता है |
| type_name | एन्कोड प्रकार का नाम प्राप्त करता है |
| classification | इस प्रतीक की वर्गीकरण प्राप्त करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |

| equals(other) | एक मान लौटाता है जो दर्शाता है कि यह इंस्टेंस निर्दिष्ट [BaseEncodeType](/barcode/python-net/aspose.barcode.generation/baseencodetype/) मान के बराबर है या नहीं। |
