## FontUnit class

पाठ के लिए एक विशिष्ट फ़ॉर्मेट परिभाषित करता है, जिसमें फ़ॉन्ट फ़ेस, आकार, और शैली गुण शामिल हैं<br/>            जहाँ आकार यूनिट वैल्यू प्रॉपर्टी में है।

FontUnit प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| family_name | इस फ़ॉन्ट का फ़ेस नाम प्राप्त करता है या सेट करता है। |
| style | इस FontUnit के लिए शैली जानकारी प्राप्त करता है या सेट करता है। |
| size | इस FontUnit का आकार यूनिट मान में प्राप्त करता है या सेट करता है। |
