## CodabarParameters class

Codabar पैरामीटर।

CodabarParameters प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| checksum_mode | Codabar बारकोड के लिए चेकसम एल्गोरिद्म प्राप्त करें या सेट करें।<br/>            डिफ़ॉल्ट मान: CodabarChecksumMode.Mod16।<br/>            चेकसम गणना सक्षम करने के लिए EnableChecksum.Yes मान को EnableChecksum प्रॉपर्टी में सेट करें।<br/>            देखें [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Codabar सिम्बोलॉजी का प्रारंभिक प्रतीक (अक्षर)।<br/>            डिफ़ॉल्ट मान: CodabarSymbol.A |
| stop_symbol | Codabar सिम्बोलॉजी का समाप्ति प्रतीक (अक्षर)।<br/>            डिफ़ॉल्ट मान: CodabarSymbol.A |
