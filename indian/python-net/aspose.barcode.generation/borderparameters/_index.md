## BorderParameters class

बारकोड इमेज बॉर्डर पैरामीटर

BorderParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| visible | बॉर्डर दृश्यता। यदि false है तो पैरामीटर Width हमेशा अनदेखा किया जाता है (0).<br/>            डिफ़ॉल्ट मान: false. |
| width | बॉर्डर चौड़ाई।<br/>            डिफ़ॉल्ट मान: 0.<br/>            यदि Visible को false सेट किया गया है तो अनदेखा किया जाता है. |
| dash_style | बॉर्डर डैश शैली।<br/>            डिफ़ॉल्ट मान: BorderDashStyle.Solid. |
| रंग | बॉर्डर रंग।<br/>            डिफ़ॉल्ट मान: Color.Black. |
