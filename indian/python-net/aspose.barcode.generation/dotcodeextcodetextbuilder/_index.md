## DotCodeExtCodetextBuilder class



DotCodeExtCodetextBuilder प्रकार निम्नलिखित सदस्यों को उजागर करता है:

| :- | :- |
| DotCodeExtCodetextBuilder() | DotCodeExtCodetextBuilder वर्ग का एक नया उदाहरण प्रारंभ करता है |

| नाम | विवरण |
