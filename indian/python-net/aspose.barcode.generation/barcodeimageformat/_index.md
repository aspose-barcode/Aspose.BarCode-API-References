## BarCodeImageFormat enumeration

छवि के फ़ाइल स्वरूप को निर्दिष्ट करता है।

| सदस्य नाम | विवरण |
| :- | :- |
| BMP | बिटमैप (BMP) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| GIF | ग्राफ़िक्स इंटरचेंज फ़ॉर्मेट (GIF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| JPEG | जॉइंट फ़ोटोग्राफ़िक एक्सपर्ट्स ग्रुप (JPEG) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| PNG | W3C पोर्टेबल नेटवर्क ग्राफ़िक्स (PNG) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| TIFF | टैग्ड इमेज फ़ाइल फ़ॉर्मेट (TIFF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| TIFF_IN_CMYK | CMYK कलर मॉडल में टैग्ड इमेज फ़ाइल फ़ॉर्मेट (TIFF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। <br/>            (केवल Windows प्लेटफ़ॉर्म पर समर्थित, *nix प्लेटफ़ॉर्म पर इसे Tiff के रूप में सहेजा जाता है) |
| EMF | एन्हांस्ड मेटा फ़ाइल (EMF) इमेज फ़ॉर्मेट निर्दिष्ट करता है।<br/>            (केवल Windows प्लेटफ़ॉर्म पर समर्थित, *nix प्लेटफ़ॉर्म पर इसे PNG के रूप में सहेजा जाता है) |
| SVG | स्केलेबल वेक्टर ग्राफ़िक्स (SVG) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
| PDF | पोर्टेबल डॉक्यूमेंट फ़ॉर्मेट (PDF) इमेज फ़ॉर्मेट निर्दिष्ट करता है। |
