## PatchCodeParameters class

पैचकोड पैरामीटर।

PatchCodeParameters प्रकार निम्नलिखित सदस्य उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| extra_barcode_text | जब PatchCode पेज मोड में उत्पन्न किया जाता है, तब अतिरिक्त QR बारकोड के लिए कोडटेक्स्ट निर्दिष्ट करता है। |
| format | PatchCode फ़ॉर्मेट। एकल PatchCode उत्पन्न करने के लिए PatchOnly चुनें। बॉर्डर के रूप में PatchCodes के साथ Patch पेज उत्पन्न करने के लिए पेज फ़ॉर्मेट का उपयोग करें।<br/>            डिफ़ॉल्ट मान: PatchFormat.PatchOnly |
| patch_format | PatchCode फ़ॉर्मेट। एकल PatchCode उत्पन्न करने के लिए PatchOnly चुनें। बॉर्डर के रूप में PatchCodes के साथ Patch पेज उत्पन्न करने के लिए पेज फ़ॉर्मेट का उपयोग करें।<br/>            डिफ़ॉल्ट मान: PatchFormat.PatchOnly |
