## AztecParameters class

Aztec पैरामीटर।

AztecParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| encode_mode | Aztec एन्कोड मोड प्राप्त करता है या सेट करता है। <br/>            डिफ़ॉल्ट मान: Auto. |
| eci_encoding | ECI एन्कोडिंग प्राप्त करता है या सेट करता है। जब AztecEncodeMode Auto हो तो उपयोग किया जाता है।<br/>            डिफ़ॉल्ट मान: ISO-8859-1 |
| structured_append_barcode_id | Aztec बारकोड के Structured Append मोड के लिए बारकोड ID। बारकोड ID 1 से बारकोड की संख्या तक की सीमा में होनी चाहिए।<br/>            डिफ़ॉल्ट मान: 0 |
| structured_append_barcodes_count | Aztec बारकोड के Structured Append मोड के लिए बारकोड की गिनती। बारकोड की गिनती 1 से 26 की सीमा में होनी चाहिए।<br/>            डिफ़ॉल्ट मान: 0 |
| structured_append_file_id | Aztec बारकोड के Structured Append मोड के लिए फ़ाइल आईडी (वैकल्पिक फ़ील्ड)। फ़ाइल आईडी में स्पेस नहीं होना चाहिए।<br/>            डिफ़ॉल्ट मान: खाली स्ट्रिंग |
| error_level | Aztec प्रकार के बारकोड की त्रुटि सुधार स्तर।<br/>            मान 5 से 95 के बीच होना चाहिए। |
| symbol_mode | Aztec Symbol मोड को प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान: AztecSymbolMode.Auto. |
| layers_count | Aztec सिम्बल की लेयर गिनती को प्राप्त करता है या सेट करता है। लेयर गिनती कॉम्पैक्ट मोड के लिए 1 से 3 और फुल रेंज मोड के लिए 1 से 32 की सीमा में होनी चाहिए।<br/>            डिफ़ॉल्ट मान: 0 (ऑटो)। |
| is_reader_initialization | रीडर को यह निर्देश देने के लिए उपयोग किया जाता है कि वह सिम्बल में निहित डेटा को रीडर प्रारंभिककरण के लिए प्रोग्रामिंग के रूप में व्याख्या करे।<br/>             |
| aspect_ratio | 2D बारकोड मॉड्यूल का ऊँचाई/चौड़ाई अनुपात। |
