## BarcodeGenerator class

बैकएंड बारकोड इमेज जनरेशन के लिए BarcodeGenerator।

BarcodeGenerator प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| BarcodeGenerator(type) | BarcodeGenerator वर्ग की एक नई इंस्टेंस को प्रारंभ करता है |
| BarcodeGenerator(type, code_text) | BarcodeGenerator वर्ग की एक नई इंस्टेंस को प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| पैरामीटर | उत्पादन पैरामीटर। |
| barcode_type | बारकोड प्रतीक प्रकार। |
| code_text | एन्कोड करने के लिए पाठ। |

| नाम | विवरण |
| :- | :- |
| set_code_text(code_bytes) | कोडटेक्स्ट को बाइट्स की श्रृंखला के रूप में सेट करें। |
| set_code_text(code_text, encoding) |  |
| set_code_text(code_text, encoding, insert_bom) |  |
| save(stream, format) | बारकोड छवि को विशिष्ट प्रारूप में स्ट्रीम पर सहेजें। |
| save(filename, format) | बारकोड छवि को विशिष्ट फ़ाइल में विशिष्ट प्रारूप में सहेजें। |
| save(filename) | बारकोड छवि को विशिष्ट फ़ाइल में विशिष्ट प्रारूप में सहेजें। |
| export_to_xml(xml_file) | BarCode प्रॉपर्टीज़ को निर्दिष्ट xml-फ़ाइल में निर्यात करता है |

| generate_bar_code_image() | वर्तमान सेटिंग्स के तहत बारकोड छवि उत्पन्न करें। |
