## HslaColor class

HSLA रंग (Hue, Saturation, Lightness, Alpha) को दर्शाने के लिए क्लास।

HslaColor प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| HslaColor(h, s, l, a) | HslaColor क्लास का नया इंस्टेंस प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| H | ह्यू [0, 360] |
| S | संतृप्ति [0, 100] |
| L | प्रकाशता [0, 100] |
| a | अल्फा (अपारदर्शिता) [0.0f, 1.0f] |
