## Code16KParameters class

Code16K पैरामीटर।

Code16KParameters प्रकार निम्नलिखित सदस्य उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| aspect_ratio | 2D बारकोड मॉड्यूल का ऊँचाई/चौड़ाई अनुपात। |
| quiet_zone_left_coef | xDimension में बाएँ क्वाइट ज़ोन का आकार।<br/>            डिफ़ॉल्ट मान: 10, अर्थात यदि xDimension = 2px हो तो बाएँ क्वाइट ज़ोन 20px होगा। |
| quiet_zone_right_coef | xDimension में दाएँ क्वाइट ज़ोन का आकार।<br/>            डिफ़ॉल्ट मान: 1, अर्थात यदि xDimension = 2px हो तो दाएँ क्वाइट ज़ोन 2px होगा। |
