## HanXinParameters class

Han Xin पैरामीटर।

HanXinParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| version | HanXin कोड का संस्करण।<br/>            Version01 से Version84 तक Han Xin कोड के लिए।<br/>            डिफ़ॉल्ट मान Version.Auto है। |
| error_level | Han Xin बारकोड के लिए Reed-Solomon त्रुटि सुधार का स्तर।<br/>             कम से उच्च: L1, L2, L3, L4। देखें ErrorLevel। |
| encode_mode | HanXin एन्कोडिंग मोड।<br/>            डिफ़ॉल्ट मान: EncodeMode.Mixed। |
| eci_encoding | Extended Channel Interpretation Identifiers। यह बारकोड रीडर को विवरण बताने के लिए उपयोग किया जाता है<br/>            प्रतीक में डेटा एन्कोड करने के लिए उपयोग किए गए रेफ़रेंसेज़ के बारे में।<br/>            वर्तमान कार्यान्वयन में सभी ज्ञात कैरेक्टरसेट एन्कोडिंग शामिल हैं। |
