## SvgParameters class

SVG पैरामीटर।

SvgParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_explicit_size_in_pixels | क्या SVG छवि में पिक्सेल में स्पष्ट आकार है (सिफारिश किया गया)<br/>            डिफ़ॉल्ट मान: true. |
| is_text_drawn_in_text_element | क्या SVG छवि में पाठ पाथ के बजाय टेक्स्ट एलिमेंट के रूप में है (सिफारिश किया गया)<br/>            डिफ़ॉल्ट मान: true. |
| svg_color_mode | svg फ़ाइल में रंग भरने के संभावित मोड, RGB डिफ़ॉल्ट है और SVG 1.1 द्वारा समर्थित है।<br/>            RGBA, HSL, HSLA SVG 2.0 मानक में अनुमति हैं।<br/>            यहां तक कि RGB में अपारदर्शिता "fill-opacity" पैरामीटर के माध्यम से सेट की जाएगी। |
