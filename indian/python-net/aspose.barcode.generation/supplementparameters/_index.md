## SupplementParameters class

पूरक पैरामीटर। Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN के लिए उपयोग किया जाता है।

SupplementParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| supplement_data | BarCode के बाद अतिरिक्त डेटा। |
| supplement_space | मुख्य BarCode और सहायक BarCode के बीच का अंतराल [Unit](/barcode/python-net/aspose.barcode.generation/unit/) मान में। |
