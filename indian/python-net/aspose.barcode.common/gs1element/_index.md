## GS1Element class

एक अपरिवर्तनीय GS1 एप्लिकेशन आइडेंटिफ़ायर और मान जोड़ी का प्रतिनिधित्व करता है।

GS1Element प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| application_identifier | सटीक GS1 Application Identifier प्राप्त करता है। |
| मान | Application Identifier से संबंधित सत्यापित मान प्राप्त करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| validate(application_identifier, value) | सटीक GS1 Application Identifier के लिए मान को सत्यापित करता है। |
