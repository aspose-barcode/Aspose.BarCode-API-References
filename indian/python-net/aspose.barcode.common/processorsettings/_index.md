## ProcessorSettings class

ProcessorSettings बहु-थ्रेडेड प्रदर्शन वृद्धि के साथ बारकोड पहचान की अनुमति देते हैं।

ProcessorSettings प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| use_all_cores | सभी कोर का उपयोग करने के लिए आवश्यक है। |
| use_only_this_cores_count | उपयोग करने के लिए कोरों की संख्या निर्दिष्ट करें। <br/>            आपको प्रॉपर्टी "UseAllCores" को "false" में बदलना होगा। |
| max_additional_allowed_threads | कोड को समानांतर चलाने के लिए अतिरिक्त थ्रेड्स की अधिकतम संख्या निर्दिष्ट करें |
