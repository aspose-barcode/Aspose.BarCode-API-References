## GS1ValidationResult class

एक GS1 एलिमेंट स्ट्रिंग, डिजिटल लिंक URI या एक AI मान के लिए सभी स्वतंत्र रूप से पता लगाने योग्य त्रुटियों को शामिल करता है।

GS1ValidationResult प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_valid | एक मान प्राप्त करता है जो दर्शाता है कि सत्यापन बिना त्रुटियों के पूरा हुआ है। |
| समस्याएँ | निर्धारित क्रम में सत्यापन त्रुटियों को प्राप्त करता है। |
