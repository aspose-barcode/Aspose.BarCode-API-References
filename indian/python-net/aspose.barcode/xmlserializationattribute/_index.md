## XmlSerializationAttribute class

XML एंटिटी जेनरेटर के लिए एट्रिब्यूट का प्रतिनिधित्व करता है।

XmlSerializationAttribute प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| XmlSerializationAttribute() | XmlSerializationAttribute वर्ग का एक नया उदाहरण प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| type | सीरियलाइज़ेशन प्रकार प्राप्त करता है या सेट करता है। डिफ़ॉल्ट attribute है। |
| name | ओवरराइडेड प्रॉपर्टी नाम प्राप्त करता है या सेट करता है। |
| default_value | प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त करता है या सेट करता है। |
