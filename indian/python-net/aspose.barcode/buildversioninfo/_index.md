## BuildVersionInfo class

वर्तमान बिल्ड संस्करण जानकारी शामिल है।

BuildVersionInfo प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| ASSEMBLY_VERSION | असेंबली संस्करण। |
| FILE_VERSION | फ़ाइल संस्करण। |
| PRODUCT | उत्पाद शीर्षक। |
| PRODUCT_MAJOR | मुख्य उत्पाद संस्करण। |
| PRODUCT_MINOR | छोटा उत्पाद संस्करण। |
| RELEASE_DATE | उत्पाद रिलीज़ तिथि। |
