## Metered class

मीटर कुंजी सेट करने के लिए मेथड प्रदान करता है।

Metered प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Metered() | Metered वर्ग का नया उदाहरण आरंभ करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| set_metered_key(public_key, private_key) | मीटरड सार्वजनिक और निजी कुंजी सेट करता है.<br/>            यदि आप मीटरड लाइसेंस खरीदते हैं, तो एप्लिकेशन शुरू करने पर इस API को कॉल किया जाना चाहिए, सामान्यतः यह पर्याप्त होता है। <br/>            हालांकि, यदि उपभोग डेटा अपलोड करने में लगातार विफल होते हैं और 24 घंटे से अधिक हो जाता है, तो लाइसेंस को मूल्यांकन स्थिति में सेट कर दिया जाएगा, <br/>            ऐसे मामलों से बचने के लिए, आपको नियमित रूप से लाइसेंस स्थिति जांचनी चाहिए, यदि यह मूल्यांकन स्थिति में है, तो इस API को फिर से कॉल करें। |
| get_consumption_quantity() | उपभोग फ़ाइल आकार प्राप्त करता है |
| get_consumption_credit() | उपभोग क्रेडिट प्राप्त करता है |
| get_product_name() | लाइसेंस प्राप्त उत्पाद का नाम प्राप्त करता है |
| is_metered_licensed() | जाँचें कि मीटरड लाइसेंस प्राप्त है या नहीं |
