## QualitySettings class

QualitySettings आपको मान्यता गुणवत्ता और गति को मैन्युअल रूप से कॉन्फ़िगर करने की अनुमति देता है।<br/>            आप एम्बेडेड प्रीसेट्स: HighPerformance, NormalQuality, HighQuality, MaxQuality के साथ जल्दी से QualitySettings सेट कर सकते हैं या आप अलग-अलग विकल्पों को मैन्युअल रूप से कॉन्फ़िगर कर सकते हैं।<br/>            QualitySettings का डिफ़ॉल्ट मान NormalQuality है।

QualitySettings प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| high_performance | HighPerformance पहचान गुणवत्ता प्रीसेट। इस मोड में उच्च गुणवत्ता वाले बारकोड अच्छी तरह से पहचाने जाते हैं। |
| normal_quality | NormalQuality पहचान गुणवत्ता प्रीसेट। अधिकांश बारकोड के लिए उपयुक्त। |
| high_quality | HighQuality पहचान गुणवत्ता प्रीसेट। यह प्रीसेट कम गुणवत्ता वाले बारकोड के लिए विकसित किया गया है। अत्यधिक क्षतिग्रस्त बारकोड का पता लगाने की अनुमति देता है। |
| max_quality | MaxQuality पहचान गुणवत्ता प्रीसेट। यह प्रीसेट सभी संभावित बारकोड को पहचानने के लिए विकसित किया गया है, यहाँ तक कि गलत बारकोड को भी। |
| x_dimension | पहचान मोड जो बारकोड के न्यूनतम तत्व का आकार (1 से अनंत तक) निर्धारित करता है: मैट्रिक्स सेल या बार। |
| minimal_x_dimension | XDimension का न्यूनतम आकार पिक्सेल में, जो UseMinimalXDimension के साथ उपयोग किया जाता है। |
| barcode_quality | वह मोड जो चयनित गुणवत्ता के साथ बारकोड तत्वों को पहचानने की विधियों को सक्षम करता है। कम गुणवत्ता वाले बारकोड तत्व को अधिक कठिन विधियों की आवश्यकता होती है, जिससे पहचान धीमी हो जाती है। |
| deconvolution | Deconvolution (छवि पुनर्स्थापन) मोड जो छवि क्षय के स्तर को निर्धारित करता है। मूल रूप से deconvolution एक फ़ंक्शन है जो क्षतिग्रस्त छवि को पुनर्स्थापित कर सकता है <br/>            (संविलित) किसी भी प्राकृतिक फ़ंक्शन जैसे ब्लर द्वारा, कैमरा से छवि प्राप्त करने के दौरान। क्योंकि हम उस छवि फ़ंक्शन का पता नहीं लगा सकते जो छवि को भ्रष्ट करता है, <br/>            हमें सबसे ज्ञात फ़ंक्शन जैसे शार्प या गणितीय रूपविज्ञान की जाँच करनी पड़ती है। |
| inverse_image | वह मोड जो उल्टे रंगों (प्रकाशमानता) वाली छवियों पर बारकोड की अतिरिक्त पहचान को सक्षम या अक्षम करता है। |
| complex_background | वह मोड जो रंगीन छवियों पर रंगीन बारकोड की अतिरिक्त पहचान को सक्षम या अक्षम करता है। |
| allow_incorrect_barcodes | इंजन को उन बारकोड को पहचानने की अनुमति देता है जिनका चेकसम या मान गलत है। इस मोड का उपयोग गलत टेक्स्ट वाले क्षतिग्रस्त बारकोड को पहचानने के लिए किया जा सकता है। |
