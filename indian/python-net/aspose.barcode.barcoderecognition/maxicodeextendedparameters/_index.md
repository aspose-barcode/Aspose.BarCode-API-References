## MaxiCodeExtendedParameters class

पहचाने गए बारकोड की MaxiCode अतिरिक्त जानकारी संग्रहीत करता है

MaxiCodeExtendedParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_empty | परीक्षण करता है कि क्या सभी पैरामीटर केवल डिफ़ॉल्ट मान रखते हैं |
| मोड | MaxiCode एन्कोड मोड को प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान: Mode4 |
| structured_append_mode_barcode_id | संरचित अपेंड मोड में MaxiCode बारकोड आईडी को प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान: 0 |
| structured_append_mode_barcodes_count | संरचित अपेंड मोड में MaxiCode बारकोड की गिनती को प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान: -1 |
