## OneDExtendedParameters class

1D पहचाने गए बारकोड का विशेष डेटा जैसे अलग कोडटेक्स्ट और चेकसम संग्रहीत करता है

OneDExtendedParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_empty | परीक्षण करता है कि क्या सभी पैरामीटर केवल डिफ़ॉल्ट मान रखते हैं |
| मान | 1D बारकोड का कोडटेक्स्ट बिना चेकसम के प्राप्त करता है। |
