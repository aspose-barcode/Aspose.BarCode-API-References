## BarCodeResult class

पहचाने गए बारकोड डेटा को संग्रहीत करता है जैसे कि [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/) प्रकार, स्ट्रिंग codetext, <br/>            [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) क्षेत्र और अन्य पैरामीटर

BarCodeResult प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| BarCodeResult(result) | BarCodeResult क्लास की एक नई इंस्टेंस को प्रारंभ करता है। |
## गुण
| नाम | विवरण |
| :- | :- |
| reading_quality | पढ़ने की गुणवत्ता प्राप्त करता है। 1D और पोस्टल बारकोड के लिए काम करता है। |
| confidence | पहचाने गए बारकोड की पहचान विश्वास स्तर प्राप्त करता है। |
| code_text | कोड टेक्स्ट प्राप्त करता है। |
| code_bytes | एन्कोडेड कोड बाइट्स प्राप्त करता है। |
| code_type | बारकोड प्रकार प्राप्त करता है। |
| code_type_name | बारकोड प्रकार का नाम प्राप्त करता है। |
| क्षेत्र | बारकोड क्षेत्र प्राप्त करता है |
| विस्तारित | पहचाने गए बारकोड के विस्तारित पैरामीटर प्राप्त करता है |
| iso_symbol_quality | पहचाने गए बारकोड के लिए ISO/IEC प्रतीक गुणवत्ता मूल्यांकन परिणाम प्राप्त करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| get_code_text(encoding) | एन्कोडिंग के साथ कोड टेक्स्ट प्राप्त करता है। |
| equals(other) | एक मान लौटाता है जो यह दर्शाता है कि यह इंस्टेंस निर्दिष्ट [BarCodeResult](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderesult/) मान के बराबर है या नहीं। |
| clone() | [BarCodeResult](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderesult/) वर्ग की एक प्रति बनाता है। |
