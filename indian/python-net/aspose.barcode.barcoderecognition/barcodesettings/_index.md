## BarcodeSettings class

मुख्य BarCode डिकोडिंग पैरामीटर। इसमें ऐसे पैरामीटर शामिल हैं जो पहचाने गए डेटा पर प्रभाव डालते हैं।

BarcodeSettings प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| checksum_validation |  |
| strip_fnc | कोडटेक्स्ट से FNC1, FNC2, FNC3 अक्षरों को हटाएँ। डिफ़ॉल्ट मान false है। |
| only_requested_types | केवल उन बारकोड प्रकारों को लौटाता है जो स्पष्ट रूप से पहचान के लिए निर्दिष्ट किए गए हैं। <br/>            जब सक्षम किया जाता है, तो अन्य संगत या समकक्ष प्रकारों के पहचाने गए बारकोड फ़िल्टर कर दिए जाते हैं। <br/>            डिफ़ॉल्ट मान false है। |
| detect_encoding | फ़्लैग जो इंजन को यूनिकोड कोडसेट्स के लिए कोडटेक्स्ट एन्कोडिंग का पता लगाने के लिए मजबूर करता है। डिफ़ॉल्ट मान true है। |
| australia_post | AustraliaPost डिकोडिंग पैरामीटर प्राप्त करता है |
| calculate_symbol_quality | पहचान के दौरान बारकोड प्रतीक की गुणवत्ता की गणना करनी है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। |
