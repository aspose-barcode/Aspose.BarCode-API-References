## GS1CompositeBarExtendedParameters class

GS1 Composite Bar पहचाने गए बारकोड का विशेष डेटा संग्रहीत करता है

GS1CompositeBarExtendedParameters प्रकार निम्नलिखित सदस्य उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |

| one_d_type | GS1 Composite का 1D (रेखीय) बारकोड प्रकार प्राप्त करता है |

| two_d_type | GS1 Composite का 2D बारकोड प्रकार प्राप्त करता है |
