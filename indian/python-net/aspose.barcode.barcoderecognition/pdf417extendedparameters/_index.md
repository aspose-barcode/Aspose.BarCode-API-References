## Pdf417ExtendedParameters class

पहचाने गए बारकोड की MacroPdf417 मेटाडाटा जानकारी संग्रहीत करता है

Pdf417ExtendedParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_empty | परीक्षण करता है कि क्या सभी पैरामीटर केवल डिफ़ॉल्ट मान रखते हैं |
| macro_pdf_417_file_id | बारकोड का फ़ाइल आईडी प्राप्त करता है, केवल MacroPdf417 के साथ उपलब्ध। |
| macro_pdf_417_segment_id | बारकोड का सेगमेंट आईडी प्राप्त करता है, केवल MacroPdf417 के साथ उपलब्ध। |
| macro_pdf_417_segments_count | macro pdf417 बारकोड सेगमेंट्स की गिनती प्राप्त करता है। डिफ़ॉल्ट मान -1 है। |
| macro_pdf_417_file_name | Macro PDF417 फ़ाइल नाम (वैकल्पिक)। |
| macro_pdf_417_file_size | Macro PDF417 फ़ाइल आकार (वैकल्पिक)। |
| macro_pdf_417_sender | Macro PDF417 प्रेषक नाम (वैकल्पिक)। |
| macro_pdf_417_addressee | Macro PDF417 प्राप्तकर्ता नाम (वैकल्पिक)। |
| macro_pdf_417_time_stamp | Macro PDF417 टाइम स्टैम्प (वैकल्पिक)। |
| macro_pdf_417_checksum | Macro PDF417 चेकसम (वैकल्पिक)। |
| macro_pdf_417_terminator | यह दर्शाता है कि क्या यह खंड Macro PDF417 फ़ाइल का अंतिम खंड है। |
| is_reader_initialization | रीडर को यह निर्देश देने के लिए उपयोग किया जाता है कि वह प्रतीक में निहित डेटा को रीडर प्रारंभिककरण के लिए प्रोग्रामिंग के रूप में व्याख्या करे। |
| is_linked | फ़्लैग जो दर्शाता है कि बारकोड को 1D बारकोड से लिंक किया जाना चाहिए। |
| is_code_128_emulation | फ़्लैग जो दर्शाता है कि MicroPdf417 बारकोड 908, 909, 910 या 911 कोड 128 इम्यूलेशन कोडवर्ड्स के साथ एन्कोड किया गया है। |
