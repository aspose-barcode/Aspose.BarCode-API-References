## CodabarExtendedParameters class

पहचाने गए बारकोड की Codabar अतिरिक्त जानकारी संग्रहीत करता है।

यह CodabarExtendedParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_empty | परीक्षण करता है कि क्या सभी पैरामीटर केवल डिफ़ॉल्ट मान रखते हैं |
| start_symbol | एक Codabar प्रारंभ प्रतीक को प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान: CodabarSymbol.A |
| stop_symbol | एक Codabar समाप्ति प्रतीक को प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान: CodabarSymbol.A |
