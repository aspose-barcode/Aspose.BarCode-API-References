## BarCodeRegionParameters class

पहचाने गए बारकोड का क्षेत्र और बारकोड कोण दर्शाता है।

BarCodeRegionParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| quadrangle | बारकोड क्षेत्र को सीमित करने वाला [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) प्राप्त करता है |
| angle | बारकोड का कोण प्राप्त करता है (0-360)। |
| points | बारकोड क्षेत्र को सीमित करने वाले [Point](/barcode/python-net/aspose.drawing/point/)s एरे प्राप्त करता है |
| rectangle | बारकोड क्षेत्र को सीमित करने वाला प्राप्त करता है |
