## LuminanceFrame class

8-बिट ग्रेस्केल इमेज फ्रेम का प्रतिनिधित्व करता है। प्रत्येक पिक्सेल को एक बाइट द्वारा दर्शाया जाता है जिसमें उसकी चमक मान होती है।

LuminanceFrame प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | LuminanceFrame क्लास का एक नया उदाहरण प्रारंभ करता है। |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | LuminanceFrame क्लास का एक नया उदाहरण प्रारंभ करता है। |
## गुण
| नाम | विवरण |
| :- | :- |
| data | ल्यूमिनेंस डेटा प्राप्त करता है। |
| width | फ़्रेम की width पिक्सेल में प्राप्त करता है। |
| height | फ़्रेम की height पिक्सेल में प्राप्त करता है। |
| row_stride | शुरुआतों के बीच बाइट में दूरी प्राप्त करता है<br/>            दो क्रमागत पंक्तियों की। |
| rotation_degrees | फ़्रेम को सही अभिविन्यास प्राप्त करने के लिए घड़ी की दिशा में घुमाने के आवश्यक डिग्री की संख्या प्राप्त करता है। |
