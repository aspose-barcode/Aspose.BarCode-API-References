## Quadrangle class

चार [Point](/barcode/python-net/aspose.drawing/point/)s का सेट संग्रहीत करता है जो एक [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) क्षेत्र का प्रतिनिधित्व करता है।

Quadrangle प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Quadrangle() | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) वर्ग का एक नया खाली इंस्टेंस प्रारंभ करता है। |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Quadrangle वर्ग का एक नया इंस्टेंस प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| left_top | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) क्षेत्र के बाएँ-ऊपरी कोने का [Point](/barcode/python-net/aspose.drawing/point/) प्राप्त करता है |
| right_top | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) क्षेत्र के दाएँ-ऊपरी कोने का [Point](/barcode/python-net/aspose.drawing/point/) प्राप्त करता है |
| right_bottom | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) क्षेत्र के दाएँ-निचले कोने का [Point](/barcode/python-net/aspose.drawing/point/) प्राप्त करता है |
| left_bottom | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) क्षेत्र के बाएँ-निचले कोने का [Point](/barcode/python-net/aspose.drawing/point/) प्राप्त करता है |
| is_empty | जाँचता है कि इस [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) के सभी [Point](/barcode/python-net/aspose.drawing/point/) शून्य मान रखते हैं या नहीं। |
| bounding_rectangle | इस [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) को सीमित करने वाला [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) प्राप्त करता है |
| EMPTY | एक [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) वर्ग का प्रतिनिधित्व करता है जिसमें उसकी प्रॉपर्टीज़ अनइनिशियलाइज़्ड रहती हैं। |
