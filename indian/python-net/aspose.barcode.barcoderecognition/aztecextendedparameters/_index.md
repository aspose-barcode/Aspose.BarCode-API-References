## AztecExtendedParameters class

एज़टेक पहचाने गए बारकोड का विशेष डेटा संग्रहीत करता है।

AztecExtendedParameters प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| is_empty | परीक्षण करता है कि क्या सभी पैरामीटर केवल डिफ़ॉल्ट मान रखते हैं |
| structured_append_barcodes_count | Aztec संरचित जोड़ मोड बारकोड गिनती प्राप्त करता है। डिफ़ॉल्ट मान 0 है। गिनती 1 से 26 के बीच का मान होना चाहिए। |
| structured_append_barcode_id | Aztec संरचित जोड़ मोड बारकोड का ID प्राप्त करता है। ID 1 से शुरू होती है और बारकोड गिनती के बराबर या कम होनी चाहिए। डिफ़ॉल्ट मान 0 है। |
| structured_append_file_id | Aztec संरचित जोड़ मोड का फ़ाइल ID प्राप्त करता है। डिफ़ॉल्ट मान खाली स्ट्रिंग है। |
| is_reader_initialization | यह दर्शाता है कि क्या कोड का उपयोग रीडर को निम्न डेटा को प्रारंभिककरण या बारकोड रीडर के पुनःप्रोग्रामिंग के निर्देशों के रूप में व्याख्या करने के लिए किया जाता है।<br/>            डिफ़ॉल्ट मान false है। |
