## Address class

ऋणदाता या ऋणग्राहक का पता।

Address प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Address() | Address की एक इंस्टेंस बनाता है |
## गुण
| नाम | विवरण |
| :- | :- |
| type | पता प्रकार प्राप्त करता है। |
| name | नाम प्राप्त करता है या सेट करता है, चाहे वह एक प्राकृतिक व्यक्ति का पहला और अंतिम नाम हो या <br/>            कानूनी व्यक्ति का कंपनी नाम। |
| address_line1 | पता पंक्ति 1 को प्राप्त करता है या सेट करता है। |
| address_line2 | पता पंक्ति 2 को प्राप्त करता है या सेट करता है। |
| street | सड़क को प्राप्त करता है या सेट करता है। |
| house_no | घर संख्या को प्राप्त करता है या सेट करता है। |
| postal_code | डाक कोड को प्राप्त करता है या सेट करता है। |
| town | शहर या कस्बे को प्राप्त करता है या सेट करता है। |
| country_code | दो-अक्षरीय ISO देश कोड को प्राप्त करता है या सेट करता है। |
