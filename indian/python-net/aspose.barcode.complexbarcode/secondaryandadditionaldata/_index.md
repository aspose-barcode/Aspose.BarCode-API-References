## SecondaryAndAdditionalData class

HIBC LIC द्वितीयक और अतिरिक्त डेटा को संग्रहीत करने के लिए क्लास।

SecondaryAndAdditionalData प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| SecondaryAndAdditionalData() | SecondaryAndAdditionalData क्लास का एक नया इंस्टेंस प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| expiry_date_format | समाप्ति तिथि प्रारूप की पहचान करता है। |
| expiry_date | समाप्ति तिथि की पहचान करता है। यदि ExpiryDateFormat को None पर सेट नहीं किया गया है तो इसका उपयोग किया जाएगा। |
| lot_number | लॉट या बैच नंबर की पहचान करता है। लॉट/बैच नंबर को 18 तक के अल्फ़ान्यूमेरिक स्ट्रिंग होना चाहिए। |
| serial_number | सीरियल नंबर की पहचान करता है। सीरियल नंबर को 18 तक के अल्फ़ान्यूमेरिक स्ट्रिंग होना चाहिए। |
| date_of_manufacture | उत्पादन तिथि की पहचान करता है।<br/>            उत्पादन तिथि को इस फ़ील्ड का उपयोग न करने के लिए DateTime.MinValue पर सेट किया जा सकता है।<br/>            डिफ़ॉल्ट मान: DateTime.MinValue |
| quantity | मात्रा की पहचान करता है, 0 से 500 तक का पूर्णांक मान होना चाहिए। <br/>            मात्रा को इस फ़ील्ड का उपयोग न करने के लिए -1 पर सेट किया जा सकता है।<br/>            डिफ़ॉल्ट मान: -1 |
