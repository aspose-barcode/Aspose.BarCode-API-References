## MaxiCodeStructuredCodetext class

मोड 2 और 3 के लिए MaxiCode कोड में एम्बेडेड टेक्स्ट को एन्कोड और डिकोड करने के लिए बेस क्लास।

MaxiCodeStructuredCodetext प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुण
| नाम | विवरण |
| :- | :- |
| encode_mode | MaxiCode एन्कोड मोड को प्राप्त करता है या सेट करता है। <br/>            डिफ़ॉल्ट मान: Auto. |
| eci_encoding | ECI एन्कोडिंग को प्राप्त करता है या सेट करता है। जब MaxiCodeEncodeMode Auto हो तब उपयोग किया जाता है।<br/>            डिफ़ॉल्ट मान: ISO-8859-1 |
| postal_code | डाक कोड की पहचान करता है। मोड 2 में 9 अंक होने चाहिए या <br/>            मोड 3 में 6 अल्फ़ान्यूमेरिक प्रतीक। |
| country_code | 3 अंकों के देश कोड की पहचान करता है। |
| service_category | 3 अंकों की सेवा श्रेणी की पहचान करता है। |
| second_message | बारकोड के दूसरे संदेश की पहचान करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| get_mode() | MaxiCode मोड प्राप्त करता है। |
| get_constructed_codetext() | कोडटेक्स्ट बनाता है |
| init_from_string(constructed_codetext) | निर्मित कोडटेक्स्ट से इंस्टेंस को प्रारंभ करता है। |
| get_barcode_type() | बारकोड प्रकार प्राप्त करता है। |
