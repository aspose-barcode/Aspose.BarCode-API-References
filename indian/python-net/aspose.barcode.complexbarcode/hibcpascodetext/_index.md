## HIBCPASCodetext class

HIBC PAS कोड में एम्बेडेड टेक्स्ट को एन्कोड और डिकोड करने के लिए क्लास।

HIBCPASCodetext प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| HIBCPASCodetext() | HIBCPASCodetext क्लास का एक नया उदाहरण प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| barcode_type | बारकोड प्रकार को प्राप्त करता है या सेट करता है। HIBC PAS कोडटेक्स्ट को HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS और HIBCQRPAS एन्कोड प्रकारों का उपयोग करके एन्कोड किया जा सकता है।<br/>            डिफ़ॉल्ट मान: HIBCCode39PAS. |
| data_location | डेटा स्थान की पहचान करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| add_record(data_type, data) | नया रिकॉर्ड जोड़ता है |
| add_record(record) | नया रिकॉर्ड जोड़ता है |
| get_records() | रिकॉर्ड्स की सूची प्राप्त करता है |
| clear() | रिकॉर्ड्स की सूची साफ़ करता है |
| get_barcode_type() | बारकोड प्रकार प्राप्त करता है। |
| get_constructed_codetext() | कोडटेक्स्ट बनाता है |
| init_from_string(constructed_codetext) | निर्मित कोडटेक्स्ट से इंस्टेंस को प्रारंभ करता है। |
