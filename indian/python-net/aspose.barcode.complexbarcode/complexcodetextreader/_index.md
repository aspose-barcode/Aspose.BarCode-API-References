## ComplexCodetextReader class

ComplexCodetextReader कोडटेक्स्ट को निर्दिष्ट जटिल बारकोड प्रकार में डिकोड करता है।

ComplexCodetextReader प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## विधियाँ
| नाम | विवरण |
| :- | :- |
| try_decode_swiss_qr(encoded_codetext) | SwissQR कोडटेक्स्ट को डिकोड करता है। |
| try_decode_mailmark_2d(encoded_codetext) | Royal Mail Mailmark 2D कोडटेक्स्ट को डिकोड करता है। |
| try_decode_mailmark(encoded_codetext) | Royal Mail Mailmark 2D कोडटेक्स्ट को डिकोड करता है। |
| try_decode_maxi_code(maxi_code_mode, encoded_codetext) | MaxiCode कोडटेक्स्ट को डिकोड करता है। |
| try_decode_hibclic(encoded_codetext) | HIBC LIC कोडटेक्स्ट को डिकोड करता है। |
| try_decode_hibcpas(encoded_codetext) | HIBC PAS कोडटेक्स्ट को डिकोड करता है। |
| try_decode_usa_drive_id(encoded_codetext) | USADriveId कोडटेक्स्ट को डिकोड करता है। |
| try_decode_gs1_codetext(encoded_codetext) | GS1 कोडटेक्स्ट को डिकोड करता है। |
| try_decode_gs1_digital_link(encoded_codetext) | GS1 डिजिटल लिंक को डिकोड करता है। |
