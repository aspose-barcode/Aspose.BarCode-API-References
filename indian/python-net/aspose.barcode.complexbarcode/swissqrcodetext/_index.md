## SwissQRCodetext class

SwissQR कोड में एम्बेडेड टेक्स्ट को एन्कोड और डिकोड करने के लिए क्लास।

SwissQRCodetext प्रकार निम्नलिखित सदस्य उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| SwissQRCodetext(bill) | SwissQRCodetext वर्ग का एक नया उदाहरण प्रारंभ करता है |
| SwissQRCodetext() | SwissQRCodetext का एक उदाहरण बनाता है। |
## गुण
| नाम | विवरण |
| :- | :- |
| bill | SwissQR बिल डेटा |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| get_constructed_codetext() | SwissQR बिल डेटा से codetext बनाएं |
| init_from_string(constructed_codetext) | निर्मित codetext के साथ Bill को प्रारंभ करता है। |
| get_barcode_type() | बारकोड प्रकार प्राप्त करता है। |
