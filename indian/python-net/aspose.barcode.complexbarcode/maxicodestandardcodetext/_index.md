## MaxiCodeStandardCodetext class

मोड 4, 5 और 6 के लिए MaxiCode कोडटेक्स्ट को एन्कोड और डिकोड करने के लिए क्लास।

MaxiCodeStandardCodetext प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| MaxiCodeStandardCodetext() | MaxiCodeStandardCodetext क्लास का एक नया उदाहरण प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| encode_mode | MaxiCode एन्कोड मोड को प्राप्त करता है या सेट करता है। <br/>            डिफ़ॉल्ट मान: Auto. |
| eci_encoding | ECI एन्कोडिंग को प्राप्त करता है या सेट करता है। जब MaxiCodeEncodeMode Auto हो तब उपयोग किया जाता है।<br/>            डिफ़ॉल्ट मान: ISO-8859-1 |
| मोड | MaxiCode मोड को प्राप्त करता है या सेट करता है। मानक कोडटेक्स्ट केवल मोड 4, 5 और 6 के साथ उपयोग किया जा सकता है। |
| message | संदेश को प्राप्त करता है या सेट करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| get_mode() | MaxiCode मोड प्राप्त करता है। |
| get_constructed_codetext() | कोडटेक्स्ट बनाता है |
| init_from_string(constructed_codetext) | निर्मित कोडटेक्स्ट से इंस्टेंस को प्रारंभ करता है। |
| get_barcode_type() | बारकोड प्रकार प्राप्त करता है। |
