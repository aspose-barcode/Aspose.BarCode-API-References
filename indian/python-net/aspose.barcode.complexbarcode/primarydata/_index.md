## PrimaryData class

PrimaryData प्रकार निम्नलिखित सदस्यों को उजागर करता है:

| :- | :- |
| PrimaryData() | PrimaryData क्लास का नया इंस्टेंस प्रारंभ करता है |

| नाम | विवरण |
| :- | :- |
