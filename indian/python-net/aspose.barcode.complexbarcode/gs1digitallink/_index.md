## GS1DigitalLink class

GS1 डिजिटल लिंक कोडटेक्स्ट को एन्कोडिंग और डिकोडिंग के लिए क्रमबद्ध अनुक्रम के रूप में दर्शाता है<br/>            एप्लिकेशन आइडेंटिफ़ायर तत्वों की। स्रोत क्रम और दोहराए गए एप्लिकेशन आइडेंटिफ़ायर संरक्षित रहते हैं।<br/>            निर्मित कोडटेक्स्ट एक अनकम्प्रेस्ड GS1 डिजिटल लिंक URI है।<br/>            पार्सिंग के दौरान गैर‑GS1 क्वेरी पैरामीटर और URI फ्रैगमेंट को अनदेखा किया जाता है।

GS1DigitalLink प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| GS1DigitalLink(uri_stem) | GS1DigitalLink वर्ग की नई इंस्टेंस को प्रारंभ करता है |
| GS1DigitalLink(uri_stem, primary_application_identifier) | GS1DigitalLink वर्ग की नई इंस्टेंस को प्रारंभ करता है |
## गुण
| नाम | विवरण |
| :- | :- |
| uri_stem | GS1 प्राथमिक कुंजी पथ खंड से पहले पूर्ण URI उपसर्ग प्राप्त करता है।<br/> स्टेम में कोई क्वेरी स्ट्रिंग या फ्रैगमेंट नहीं होता। |
| primary_application_identifier | डिजिटल लिंक प्राथमिक कुंजी के रूप में उपयोग किए जाने वाले एप्लिकेशन आइडेंटिफायर को प्राप्त करता है।<br/> Null का अर्थ है कि URI निर्मित होने पर प्राथमिक कुंजी स्वचालित रूप से चयनित की जाती है। |
| barcode_type | इस GS1 Digital Link को एन्कोड करने के लिए उपयोग किए जाने वाले बारकोड प्रकार को प्राप्त करता है या सेट करता है।<br/> समर्थित प्रकार हैं QR, DataMatrix, Aztec, Pdf417, MicroPdf417, DotCode, HanXin, CodablockF और Code128।<br/> डिफ़ॉल्ट मान QR है। |
| गणना | एप्लिकेशन आइडेंटिफायर तत्वों की संख्या प्राप्त करता है। |
| तत्व | स्रोत क्रम में सभी तत्वों की एक प्रति प्राप्त करता है। |
