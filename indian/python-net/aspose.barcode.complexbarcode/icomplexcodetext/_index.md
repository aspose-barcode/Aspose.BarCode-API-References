## IComplexCodetext class

ComplexBarcodeGenerator के साथ उपयोग किए जाने वाले जटिल कोडटेक्स्ट के लिए इंटरफ़ेस।

IComplexCodetext प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## विधियाँ
| नाम | विवरण |
| :- | :- |
| get_constructed_codetext() | जटिल बारकोड के लिए कोडटेक्स्ट बनाएं |
| init_from_string(constructed_codetext) | निर्मित कोडटेक्स्ट के साथ उदाहरण को प्रारंभ करता है। |
| get_barcode_type() | बारकोड प्रकार प्राप्त करता है। |
