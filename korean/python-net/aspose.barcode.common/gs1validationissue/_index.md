## GS1ValidationIssue class

하나의 GS1 검증 오류를 설명합니다.

GS1ValidationIssue 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| code | 안정적인 기계 판독 오류 코드를 가져옵니다. |
| application_identifier | 오류와 관련된 애플리케이션 식별자를 가져오며, 입력에서 애플리케이션<br/>            식별자를 결정할 수 없을 경우 null을 반환합니다. |
| message | 인간이 읽을 수 있는 오류 메시지를 가져옵니다. |
