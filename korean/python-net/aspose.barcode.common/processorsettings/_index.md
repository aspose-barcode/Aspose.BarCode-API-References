## ProcessorSettings class

ProcessorSettings는 멀티스레드 성능 향상을 통해 바코드를 인식하도록 허용합니다.

ProcessorSettings 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| use_all_cores | 모든 코어를 사용하려면 필요합니다. |
| use_only_this_cores_count | 사용할 코어 수를 지정합니다. <br/>            속성 "UseAllCores"를 "false"로 변경해야 합니다. |
| max_additional_allowed_threads | 코드를 병렬로 실행하기 위한 추가 스레드의 최대 수를 지정합니다. |
