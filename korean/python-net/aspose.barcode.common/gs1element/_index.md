## GS1Element class

불변의 GS1 애플리케이션 식별자와 값 쌍을 나타냅니다.

GS1Element 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| application_identifier | 정확한 GS1 Application Identifier를 가져옵니다. |
| value | Application Identifier와 연결된 검증된 값을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| validate(application_identifier, value) | 정확한 GS1 Application Identifier에 대한 값을 검증합니다. |
