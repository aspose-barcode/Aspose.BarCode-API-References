## BuildVersionInfo class

현재 빌드 버전 정보를 포함합니다.

BuildVersionInfo 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| ASSEMBLY_VERSION | 어셈블리 버전입니다. |
| FILE_VERSION | The file version. |
| PRODUCT | 제품 제목. |
| PRODUCT_MAJOR | 주요 제품 버전. |
| PRODUCT_MINOR | 보조 제품 버전. |
| RELEASE_DATE | 제품 출시 날짜. |
