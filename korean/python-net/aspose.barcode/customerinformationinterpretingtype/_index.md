## CustomerInformationInterpretingType enumeration

AustralianPost BarCode에 대한 고객 정보의 해석 유형(CTable, NTable 또는 Other)을 정의합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| C_TABLE | CTable을 사용하여 고객 정보를 해석합니다. A..Z, a..z, 1..9, 공백 및 # 기호를 허용합니다. |
| N_TABLE | NTable을 사용하여 고객 정보를 해석합니다. 숫자를 허용합니다. |
| OTHER | 고객 정보를 해석하지 않습니다. 0, 1, 2 또는 3 기호만 허용합니다. |
