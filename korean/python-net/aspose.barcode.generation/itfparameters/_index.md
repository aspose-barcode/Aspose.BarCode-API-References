## ITFParameters class

ITF 매개변수.

ITFParameters 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| border_thickness | ITF 경계(베어러 바)의 두께를 단위 값으로 가져오거나 설정합니다.<br/>            기본값: 12pt. |
| border_type | ITF 바코드의 경계 유형입니다.<br/>            기본값: ITF14BorderType.Bar. |
| quiet_zone_coef | xDimension에서 조용한 구역의 크기입니다.<br/>            기본값: 10, 즉 xDimension = 2px이면 조용한 구역은 20px이 됩니다. |
