## FontUnit class

텍스트에 대한 특정 형식을 정의합니다. 여기에는 글꼴, 크기 및 스타일 속성이 포함됩니다<br/>            여기서 크기는 Unit 값 속성에 있습니다.

FontUnit 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| family_name | 이 Font의 글꼴 이름을 가져오거나 설정합니다. |
| style | 이 FontUnit에 대한 스타일 정보를 가져오거나 설정합니다. |
| size | 이 FontUnit의 크기를 Unit 값으로 가져오거나 설정합니다. |
