## QrExtCodetextBuilder class



QrExtCodetextBuilder 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| QrExtCodetextBuilder() | QrExtCodetextBuilder 클래스의 새 인스턴스를 초기화합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| clear() | 확장된 코드텍스트 항목을 지웁니다. |
| add_plain_codetext(codetext) | 평문 코드텍스트를 확장된 코드텍스트 항목에 추가합니다. |
| add_eci_codetext(eci_encoding, codetext) | 확장 채널 식별자가 포함된 코드텍스트를 추가합니다. |
| get_extended_codetext() | 확장된 코드텍스트 목록에서 확장 코드텍스트를 생성합니다. |
| add_fnc1_first_position() | 첫 번째 위치에 FNC1을 설정합니다. 이전에 다른 FNC1 모드가 설정되어 있었다면 교체됩니다. |
| add_fnc1_second_position(codetext) | 두 번째 위치에 FNC1을 설정합니다. 이전에 다른 FNC1 모드가 설정되어 있었다면 교체됩니다. |
| add_fnc1_group_separator() | 확장된 코드텍스트 항목에 그룹 구분자(GS - '\\u001D')를 추가합니다. |
| add_codetext_with_compaction_mode(mode, codetext) | 지정된 QR 압축 모드와 함께 코드텍스트를 확장된 코드텍스트 항목에 추가합니다. |
