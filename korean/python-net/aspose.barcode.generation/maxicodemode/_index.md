## MaxiCodeMode enumeration

MaxiCode 바코드의 인코딩 모드.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| MODE2 | Mode 2는 첫 번째 메시지에 우편 정보를 인코딩하고 두 번째 메시지에 데이터를 인코딩합니다. <br/>            미국에서만 사용되는 9자리 우편 번호가 있습니다. |
| MODE3 | 모드 3은 첫 번째 메시지에 우편 정보를, 두 번째 메시지에 데이터를 인코딩합니다. <br/>            6자리 알파벳-숫자 우편 코드를 가지고 있으며, 전 세계에서 사용됩니다. |
| MODE4 | 모드 4는 첫 번째와 두 번째 메시지에 데이터를 인코딩하며, 짧은 ECC 보정을 사용합니다. |
| MODE5 | 모드 5는 첫 번째와 두 번째 메시지에 데이터를 인코딩하며, 긴 ECC 보정을 사용합니다. |
| MODE6 | 모드 6은 첫 번째와 두 번째 메시지에 데이터를 인코딩하며, 짧은 ECC 보정을 사용합니다.<br/>            장치를 인코딩하는 데 사용됩니다. |
