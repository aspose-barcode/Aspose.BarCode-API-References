## HanXinParameters class

Han Xin 매개변수.

HanXinParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| version | HanXin 코드의 버전.<br/>            Han Xin 코드에 대해 Version01부터 Version84까지.<br/>            기본값은 Version.Auto입니다. |
| error_level | Han Xin 바코드의 Reed-Solomon 오류 정정 수준.<br/>             낮음에서 높음: L1, L2, L3, L4. ErrorLevel을 참조하십시오. |
| encode_mode | HanXin 인코딩 모드.<br/>            기본값: EncodeMode.Mixed. |
| eci_encoding | Extended Channel Interpretation Identifiers. 바코드 리더에게 기호에 데이터를 인코딩하기 위해 사용된 참조에 대한 자세한 정보를 전달하는 데 사용됩니다.<br/>            현재 구현은 모든 잘 알려진 문자 집합 인코딩을 포함합니다. |
