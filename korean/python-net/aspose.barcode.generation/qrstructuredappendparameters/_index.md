## QrStructuredAppendParameters class

QR 구조 추가 매개변수.

QrStructuredAppendParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| parity_byte | QR 구조 추가 모드 패리티 데이터를 가져오거나 설정합니다. |
| sequence_indicator | QR 구조 추가 모드 바코드의 인덱스를 가져오거나 설정합니다. 인덱스는 0부터 시작합니다. |
| total_count | QR 구조 추가 모드 바코드 수량을 가져오거나 설정합니다. 최대값은 16입니다. |
