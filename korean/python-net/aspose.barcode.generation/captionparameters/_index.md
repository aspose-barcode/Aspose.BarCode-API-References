## CaptionParameters class

캡션 매개변수.

CaptionParameters 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| text | 캡션 텍스트.<br/>            기본값: 빈 문자열. |
| font | 캡션 폰트.<br/>            기본값: Arial 8pt regular. |
| visible | 캡션 텍스트 가시성.<br/>            기본값: false. |
| text_color | 캡션 텍스트 색상.<br/>            기본값: Color.Black. |
| padding | 캡션 패딩.<br/>            CaptionAbove 기본값: 5pt 5pt 0 5pt.<br/>            CaptionBelow 기본값: 0 5pt 5pt 5pt. |
| 정렬 | 캡션 테스트 수평 정렬.<br/>            기본값: StringAlignment.Center. |
| no_wrap | 텍스트 내에서 단어 줄바꿈(줄 바꿈)을 지정합니다.<br/>            기본값: false. |
