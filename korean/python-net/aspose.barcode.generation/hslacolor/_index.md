## HslaColor class

HSLA 색상(Hue, Saturation, Lightness, Alpha)을 나타내는 클래스

HslaColor 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| HslaColor(h, s, l, a) | HslaColor 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| H | Hue [0, 360] |
| S | 채도 [0, 100] |
| L | 명도 [0, 100] |
| a | 알파 (불투명도) [0.0f, 1.0f] |
## 메서드
| 이름 | 설명 |
| :- | :- |
| convert_hsla_to_rgba(hsla_color) | 다음 URL을 사용합니다 https://en.wikipedia.org/wiki/HSL_and_HSV#HSL_to_RGB |
