## SvgParameters class

SVG 매개변수.

SvgParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_explicit_size_in_pixels | SVG 이미지에 픽셀 단위의 명시적 크기가 포함되어 있습니까 (권장)<br/>            기본값: true. |
| is_text_drawn_in_text_element | SVG 이미지에 경로 대신 텍스트 요소로 텍스트가 포함되어 있습니까 (권장)<br/>            기본값: true. |
| svg_color_mode | svg 파일에서 색을 채우는 가능한 모드, RGB가 기본이며 SVG 1.1에서 지원됩니다.<br/>            RGBA, HSL, HSLA는 SVG 2.0 표준에서 허용됩니다.<br/>            RGB에서도 불투명도는 "fill-opacity" 매개변수를 통해 설정됩니다. |
