## QrExtCompactionMode enumeration

QrExtCodetextBuilder에 의해 추가된 코드텍스트에 대한 QR 압축 모드를 지정합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| AUTO | 인코더가 가장 효율적인 QR 압축 모드를 자동으로 선택합니다. |
| NUMERIC | QR Numeric 모드로 코드 텍스트를 인코딩합니다. 0-9 숫자만 허용됩니다. |
| ALPHA_NUMERIC | QR Alphanumeric 모드로 코드 텍스트를 인코딩합니다. |
| BYTES | QR Byte 모드로 코드 텍스트를 인코딩합니다. |
| KANJI | QR Kanji 모드로 코드 텍스트를 인코딩합니다. |
