## AutoSizeMode enumeration

자동 크기 조정 모드의 다양한 유형을 지정합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| NONE | 자동 크기 조정이 비활성화되었습니다. |
| NEAREST | 바코드를 ImageWidth 및 ImageHeight 속성으로 지정된 가장 가까운 최소 크기로 조정합니다.<br/>            기본 종횡비를 유지합니다. |
| INTERPOLATION | 바코드를 지정된 크기로 조정합니다.<br/>            크기는 ImageWidth 및 ImageHeight 속성으로 지정할 수 있습니다.<br/>            스케일링 후 생성된 바코드가 유효하지 않을 수 있습니다 (읽을 수 없음). |
