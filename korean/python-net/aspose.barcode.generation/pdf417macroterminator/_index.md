## Pdf417MacroTerminator enumeration

인코더에게 세그먼트에 매크로 PDF417 종료자 (코드워드 922)를 추가할지 여부를 알려줍니다. <br/>            매크로 PDF417에만 적용됩니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| AUTO | 세그먼트 수가 제공되고 현재 세그먼트가 마지막인 경우 종료 문자가 자동으로 추가됩니다 <br/>            다른 경우에는 종료 문자가 추가되지 않습니다. |
| NONE | 종료 문자가 추가되지 않습니다. |
| SET | 종료 문자가 추가됩니다. |
