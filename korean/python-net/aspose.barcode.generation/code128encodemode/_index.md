## Code128EncodeMode enumeration

Code128 바코드의 인코딩 모드.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| AUTO | 코드 텍스트를 고전 ISO 15417 모드로 인코딩합니다. 이 모드는 모든 일반적인 경우에 사용해야 합니다. |
| CODE_A | 코드 텍스트를 128A 코드셋에만 인코딩합니다. |
| CODE_B | 코드 텍스트를 128B 코드셋에만 인코딩합니다. |
| CODE_C | 코드 텍스트를 128C 코드셋에만 인코딩합니다. |
| CODE_AB | 코드 텍스트를 128A 및 128B 코드셋에만 인코딩합니다. |
| CODE_AC | 코드 텍스트를 128A 및 128C 코드셋에만 인코딩합니다. |
| CODE_BC | 코드 텍스트를 128B 및 128C 코드셋에만 인코딩합니다. |
