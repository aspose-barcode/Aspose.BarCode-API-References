## CodabarParameters class

Codabar 매개변수.

CodabarParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| checksum_mode | Codabar 바코드의 체크섬 알고리즘을 가져오거나 설정합니다.<br/>            기본값: CodabarChecksumMode.Mod16.<br/>            체크섬 계산을 활성화하려면 EnableChecksum.Yes 값을 EnableChecksum 속성에 설정합니다.<br/>            보기 [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Codabar 심볼리즘의 시작 기호(문자).<br/>            기본값: CodabarSymbol.A |
| stop_symbol | Codabar 심볼리즘의 종료 기호(문자).<br/>            기본값: CodabarSymbol.A |
