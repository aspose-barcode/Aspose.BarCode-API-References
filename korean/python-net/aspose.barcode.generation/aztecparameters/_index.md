## AztecParameters class

Aztec 매개변수.

AztecParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| encode_mode | Aztec 인코드 모드를 가져오거나 설정합니다. <br/>            기본값: Auto. |
| eci_encoding | ECI 인코딩을 가져오거나 설정합니다. AztecEncodeMode가 Auto일 때 사용됩니다.<br/>            기본값: ISO-8859-1 |
| structured_append_barcode_id | Aztec 바코드의 Structured Append 모드에 대한 바코드 ID입니다. 바코드 ID는 1부터 바코드 수까지의 범위에 있어야 합니다.<br/>            기본값: 0 |
| structured_append_barcodes_count | Aztec 바코드의 Structured Append 모드에 대한 바코드 수. 바코드 수는 1에서 26 사이여야 합니다.<br/>            기본값: 0 |
| structured_append_file_id | Aztec 바코드의 Structured Append 모드에 대한 파일 ID(선택 필드). 파일 ID에는 공백이 포함될 수 없습니다.<br/>            기본값: 빈 문자열 |
| error_level | Aztec 유형 바코드의 오류 정정 수준.<br/>            값은 5에서 95 사이여야 합니다. |
| symbol_mode | Aztec Symbol 모드를 가져오거나 설정합니다.<br/>            기본값: AztecSymbolMode.Auto. |
| layers_count | Aztec 심볼의 레이어 수를 가져오거나 설정합니다. 레이어 수는 Compact 모드에서는 1에서 3 사이, Full Range 모드에서는 1에서 32 사이여야 합니다.<br/>            기본값: 0 (자동). |
| is_reader_initialization | 리더에게 심볼에 포함된 데이터를 리더 초기화를 위한 프로그래밍으로 해석하도록 지시하는 데 사용됩니다.<br/>             |
| aspect_ratio | 2D 바코드 모듈의 높이/너비 비율. |
