## MacroCharacter enumeration

특수 모드에서 더 압축된 인코딩을 얻기 위해 매크로 문자 05와 06 값을 사용합니다.<br/>            05 매크로 문자는 디코드된 데이터 헤더로 "[)>\u001E05\u001D"와 디코드된 데이터 트레일러로 "\u001E\u0004" 로 변환됩니다.<br/>            06 매크로 문자는 디코드된 데이터 헤더로 "[)>\u001E06\u001D"와 디코드된 데이터 트레일러로 "\u001E\u0004" 로 변환됩니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| NONE | 매크로 문자가 바코드 데이터에 추가되지 않습니다 |
| MACRO05 | 05 매크로 문자가 첫 번째 위치에 바코드 데이터에 추가됩니다.<br/>            GS1 데이터 식별자 ISO 15434<br/>            문자는 디코딩된 데이터 헤더인 "[)>\u001E05\u001D"와 디코딩된 데이터 트레일러인 "\u001E\u0004"로 변환됩니다. |
| MACRO06 | 06 매크로 문자가 첫 번째 위치에 바코드 데이터에 추가됩니다.<br/>            ASC MH10 데이터 식별자 ISO 15434<br/>            문자는 디코딩된 데이터 헤더인 "[)>\u001E06\u001D"와 디코딩된 데이터 트레일러인 "\u001E\u0004"로 변환됩니다. |
