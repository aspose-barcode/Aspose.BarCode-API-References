## GS1CompositeBarParameters class

GS1 Composite bar 매개변수.

GS1CompositeBarParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| linear_component_type | 선형 구성 요소 유형: GS1Code128, UPCE, EAN8, UPCA, EAN13, DatabarStacked, DatabarStackedOmniDirectional, DatabarLimited, DatabarOmniDirectional, DatabarExpanded, DatabarExpandedStacked |
| two_d_component_type | 2D 구성 요소 유형 |
| allow_only_gs1_encoding | 이 플래그가 설정되면 GS1CompositeBar 2D 구성 요소에 대해 GS1 인코딩 표준만 허용합니다. |
