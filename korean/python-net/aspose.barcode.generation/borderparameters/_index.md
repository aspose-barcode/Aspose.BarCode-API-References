## BorderParameters class

바코드 이미지 테두리 매개변수

BorderParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| visible | 테두리 가시성. false인 경우 매개변수 Width는 항상 무시됩니다 (0).<br/>            기본값: false. |
| width | 테두리 두께.<br/>            기본값: 0.<br/>            Visible가 false로 설정된 경우 무시됩니다. |
| dash_style | 테두리 대시 스타일.<br/>            기본값: BorderDashStyle.Solid. |
| 색상 | 테두리 색상.<br/>            기본값: Color.Black. |
