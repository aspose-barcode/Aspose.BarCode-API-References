## SupplementParameters class

보조 매개변수. Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN에 사용됩니다.

SupplementParameters 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| supplement_data | BarCode 뒤에 오는 보조 데이터. |
| supplement_space | [Unit](/barcode/python-net/aspose.barcode.generation/unit/) 값으로 메인 BarCode와 보조 BarCode 사이의 간격. |
