## Code16KParameters class

Code16K 매개변수.

Code16KParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| aspect_ratio | 2D 바코드 모듈의 높이/너비 비율. |
| quiet_zone_left_coef | xDimension에서 왼쪽 quiet zone의 크기.<br/>            기본값: 10, 즉 xDimension = 2px이면 왼쪽 quiet zone은 20px이 됩니다. |
| quiet_zone_right_coef | xDimension에서 오른쪽 quiet zone의 크기.<br/>            기본값: 1, 즉 xDimension = 2px이면 오른쪽 quiet zone은 2px이 됩니다. |
