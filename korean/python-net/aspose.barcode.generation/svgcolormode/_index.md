## SvgColorMode enumeration

svg 파일에서 색을 채우는 가능한 모드, RGB가 기본이며 SVG 1.1에서 지원됩니다.<br/>            RGBA, HSL, HSLA는 SVG 2.0 표준에서 허용됩니다.<br/>            RGB에서도 불투명도는 "fill-opacity" 매개변수를 통해 설정됩니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| RGB | RGB 모드, 예: fill=\"#ff5511\" fill-opacity=\"0.73\". 기본 모드. |
| RGBA | RGBA 모드, 예: fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | HSL 모드, 예: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | HSLA 모드, 예: fill=\"hsla(30, 50%, 70%, 0.8)\" |
