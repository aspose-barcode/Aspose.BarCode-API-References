## DataBarParameters class

Databar 매개변수.

DataBarParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_2d_composite_component | DataBar 바코드를 사용하는 2D 복합 구성 요소의 플래그를 활성화합니다 |
| allow_only_gs1_encoding | 이 플래그가 설정되면 Databar 바코드 유형에 대해 GS1 인코딩 표준만 허용합니다 |
| 열 | 열 수. |
| 행 | 행 수. |
| aspect_ratio | 2D 바코드 모듈의 높이/너비 비율.<br/>            DataBar 스택형에 사용됩니다. |
