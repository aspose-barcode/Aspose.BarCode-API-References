## PdfParameters class

PDF 매개변수.

PdfParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| cmyk_bar_color | Nullable. 바코드의 CMYK 색상 값입니다. Null은 CMYK 색상이 사용되지 않고 대신 일반 RGB 색상이 사용됨을 의미합니다. |
| cmyk_back_color | Nullable. 배경 색상의 CMYK 값입니다. Null은 CMYK 색상이 사용되지 않고 대신 일반 RGB 색상이 사용됨을 의미합니다. |
| cmyk_codetext_color | Nullable. 코드텍스트의 CMYK 색상 값입니다. Null은 CMYK 색상이 사용되지 않고 대신 일반 RGB 색상이 사용됨을 의미합니다. |
| cmyk_caption_above_color | Nullable. 위쪽 캡션의 CMYK 색상 값입니다. Null은 CMYK 색상이 사용되지 않고 대신 일반 RGB 색상이 사용됨을 의미합니다. |
| cmyk_caption_below_color | Nullable. 아래쪽 캡션의 CMYK 색상 값입니다. Null은 CMYK 색상이 사용되지 않고 대신 일반 RGB 색상이 사용됨을 의미합니다. |
| is_text_as_path | 텍스트 대신 경로를 사용하시겠습니까 (Unicode 문자가 표시되지 않을 경우 사용)<br/> 기본값: false. |
