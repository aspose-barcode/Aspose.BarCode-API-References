## PatchFormat enumeration

PatchCode 형식. 단일 PatchCode를 생성하려면 PatchOnly를 선택하십시오. 페이지 형식을 사용하면 PatchCode를 경계로 하는 Patch 페이지를 생성합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| PATCH_ONLY | PatchCode만 생성합니다. |
| A4 | A4 형식 페이지를 생성하며, 가장자리에 PatchCodes를 배치하고 중앙에 선택적 QR을 포함합니다. |
| A4_LANDSCAPE | A4 가로 형식 페이지를 생성하며, 가장자리에 PatchCodes를 배치하고 중앙에 선택적 QR을 포함합니다. |
| US_LETTER | US letter 형식 페이지를 생성하며, 가장자리에 PatchCodes를 배치하고 중앙에 선택적 QR을 포함합니다. |
| US_LETTER_LANDSCAPE | US letter 가로 형식 페이지를 생성하며, 가장자리에 PatchCodes를 배치하고 중앙에 선택적 QR을 포함합니다. |
