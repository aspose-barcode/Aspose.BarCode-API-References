## DotCodeParameters class

DotCode 매개변수.

DotCodeParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| aspect_ratio | 2D 바코드 모듈의 높이/너비 비율. |
| encode_mode | DotCode 인코드 모드를 식별합니다. <br/>            기본값: Auto. |
| is_reader_initialization | 코드가 바코드 리더기의 초기화 또는 재프로그램 지시로 해석하도록 리더에게 지시하는 데 사용되는지 여부를 나타냅니다.<br/>            기본값은 false입니다. |
| structured_append_mode_barcode_id | DotCode 구조화 추가 모드 바코드의 ID를 식별합니다. ID는 1부터 시작하며 바코드 수보다 작거나 같아야 합니다. 기본값은 -1입니다. |
| structured_append_mode_barcodes_count | DotCode 구조화 추가 모드 바코드 수를 식별합니다. 기본값은 -1입니다. 카운트는 1에서 35 사이의 값이어야 합니다. |
| eci_encoding | ECI 인코딩을 식별합니다. DotCodeEncodeMode가 Auto인 경우에 사용됩니다.<br/>            기본값: ISO-8859-1 |
| 행 | 행 수를 식별합니다. DotCode 기호의 행 수와 열 수의 합은 홀수여야 합니다. 행 수는 최소 5이어야 합니다.<br/>            기본값: -1 |
| 열 | 열 수를 식별합니다. DotCode 기호의 행 수와 열 수의 합은 홀수여야 합니다. 열 수는 최소 5이어야 합니다.<br/>            기본값: -1 |
