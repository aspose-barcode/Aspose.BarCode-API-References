## ExtCodetextBuilder class

Extended Codetext Mode의 자동 codetext 생성을 위한 도우미 클래스

ExtCodetextBuilder 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| clear() | 확장된 코드텍스트 항목을 지웁니다. |
| add_plain_codetext(codetext) | 평문 코드텍스트를 확장된 코드텍스트 항목에 추가합니다. |
| add_eci_codetext(eci_encoding, codetext) | 확장 채널 식별자가 포함된 코드텍스트를 추가합니다. |
| get_extended_codetext() | 생성 항목 목록에서 확장 코드텍스트를 생성합니다 |
