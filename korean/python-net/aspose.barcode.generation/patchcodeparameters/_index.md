## PatchCodeParameters class

PatchCode 매개변수.

PatchCodeParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| extra_barcode_text | PatchCode가 페이지 모드에서 생성될 때 추가 QR 바코드의 코드 텍스트를 지정합니다. |
| format | PatchCode 형식. 단일 PatchCode를 생성하려면 PatchOnly를 선택하십시오. PatchCodes를 테두리로 하는 Patch 페이지를 생성하려면 페이지 형식을 사용하십시오.<br/>            기본값: PatchFormat.PatchOnly |
| patch_format | PatchCode 형식. 단일 PatchCode를 생성하려면 PatchOnly를 선택하십시오. PatchCodes를 테두리로 하는 Patch 페이지를 생성하려면 페이지 형식을 사용하십시오.<br/>            기본값: PatchFormat.PatchOnly |
