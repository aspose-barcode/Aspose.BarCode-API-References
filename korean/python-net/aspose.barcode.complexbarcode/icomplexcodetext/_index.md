## IComplexCodetext class

ComplexBarcodeGenerator와 함께 사용되는 복합 코드텍스트를 위한 인터페이스.

IComplexCodetext 타입은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_constructed_codetext() | 복합 바코드용 코덱스트를 구성합니다. |
| init_from_string(constructed_codetext) | 구성된 코덱스트로 인스턴스를 초기화합니다. |
| get_barcode_type() | 바코드 유형을 가져옵니다. |
