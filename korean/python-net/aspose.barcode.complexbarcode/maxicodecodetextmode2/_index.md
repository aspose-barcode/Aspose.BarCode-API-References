## MaxiCodeCodetextMode2 class

모드 2용 MaxiCode 코드에 삽입된 텍스트를 인코딩 및 디코딩하기 위한 클래스.

MaxiCodeCodetextMode2 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| MaxiCodeCodetextMode2() | MaxiCodeCodetextMode2 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| encode_mode |  |
| eci_encoding |  |
| postal_code | 우편 번호를 식별합니다. 모드 2에서는 9자리 숫자여야 하며, <br/>            모드 3에서는 6개의 영숫자 기호여야 합니다. |
| country_code | 3자리 국가 코드를 식별합니다. |
| service_category | 3자리 서비스 카테고리를 식별합니다. |
| second_message | 바코드의 두 번째 메시지를 식별합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |

| init_from_string(constructed_codetext) | 구성된 코드 텍스트에서 인스턴스를 초기화합니다. |
| get_barcode_type() | 바코드 유형을 가져옵니다. |
