## Address class

채권자 또는 채무자의 주소.

이 Address 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Address() | Address의 인스턴스를 생성합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| type | 주소 유형을 가져옵니다. |
| name | 이름을 가져오거나 설정합니다, 자연인의 경우 이름과 성, 또는 <br/>            법인의 경우 회사명을 의미합니다. |
| address_line1 | 주소 라인 1을 가져오거나 설정합니다. |
| address_line2 | 주소 라인 2를 가져오거나 설정합니다. |
| street | 거리를 가져오거나 설정합니다. |
| house_no | 집 번호를 가져오거나 설정합니다. |
| postal_code | 우편 번호를 가져오거나 설정합니다. |
| town | 도시 또는 마을을 가져오거나 설정합니다. |
| country_code | 두 글자 ISO 국가 코드를 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| clear() | 모든 필드를 지우고 유형을 [UNDETERMINED](/barcode/python-net/aspose.barcode.complexbarcode/addresstype/)으로 설정합니다. |
| equals(other) | 지정된 객체가 현재 객체와 같은지 여부를 결정합니다. |
