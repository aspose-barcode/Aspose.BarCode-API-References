## SwissQRBill class

SwissQR 청구서 데이터

SwissQRBill 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| version | SwissQR 청구서 표준의 버전을 가져오거나 설정합니다. |
| amount | 결제 금액을 가져오거나 설정합니다. |
| currency | 결제 통화를 가져오거나 설정합니다. |
| account | 채권자의 계좌 번호를 가져오거나 설정합니다. |
| creditor | 채권자 주소를 가져오거나 설정합니다. |
| reference | 채권자 결제 참조를 가져오거나 설정합니다. |
| debtor | 채무자 주소를 가져오거나 설정합니다. |
| unstructured_message | 추가 비구조화 메시지를 가져오거나 설정합니다. |
| bill_information | 추가 구조화된 청구서 정보를 가져오거나 설정합니다. |
| alternative_schemes | 대체 결제 방식을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| create_and_set_creditor_reference(raw_reference) | 원시 문자열에 "RF"를 접두하고 modulo 97 체크섬을 적용하여 ISO11649 채권자 레퍼런스를 생성하고 설정합니다.<br/>            문자열을 "RF"와 modulo 97 체크섬으로 접두합니다. |
| equals(other) | 지정된 객체가 현재 객체와 같은지 여부를 결정합니다. |
