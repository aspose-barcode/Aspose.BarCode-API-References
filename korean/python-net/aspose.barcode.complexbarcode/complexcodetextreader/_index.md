## ComplexCodetextReader class

ComplexCodetextReader는 코드텍스트를 지정된 복합 바코드 유형으로 디코딩합니다.

ComplexCodetextReader 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| try_decode_swiss_qr(encoded_codetext) | SwissQR 코드 텍스트를 디코딩합니다. |
| try_decode_mailmark_2d(encoded_codetext) | Royal Mail Mailmark 2D 코드 텍스트를 디코딩합니다. |
| try_decode_mailmark(encoded_codetext) | Royal Mail Mailmark 2D 코드 텍스트를 디코딩합니다. |
| try_decode_maxi_code(maxi_code_mode, encoded_codetext) | MaxiCode 코드 텍스트를 디코딩합니다. |
| try_decode_hibclic(encoded_codetext) | HIBC LIC 코드 텍스트를 디코딩합니다. |
| try_decode_hibcpas(encoded_codetext) | HIBC PAS 코드 텍스트를 디코딩합니다. |
| try_decode_usa_drive_id(encoded_codetext) | USADriveId 코드 텍스트를 디코딩합니다. |
| try_decode_gs1_codetext(encoded_codetext) | GS1 코드 텍스트를 디코딩합니다. |
| try_decode_gs1_digital_link(encoded_codetext) | GS1 디지털 링크를 디코딩합니다. |
