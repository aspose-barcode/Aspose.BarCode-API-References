## HIBCLICCombinedCodetext class

주 데이터와 보조 데이터를 저장하는 HIBC LIC 코드에 삽입된 텍스트를 인코딩 및 디코딩하기 위한 클래스.

HIBCLICCombinedCodetext 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| HIBCLICCombinedCodetext() | HIBCLICCombinedCodetext 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| barcode_type | 바코드 유형을 가져오거나 설정합니다. HIBC LIC 코드텍스트는 HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC 및 HIBCQRLIC 인코드 유형을 사용하여 인코딩할 수 있습니다.<br/>            기본값: HIBCCode39LIC. |
| primary_data | 주 데이터임을 식별합니다. |
| secondary_and_additional_data | 보조 및 추가 보충 데이터를 식별합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_constructed_codetext() | 코드 텍스트를 구성합니다 |
| init_from_string(constructed_codetext) | 구성된 코드 텍스트에서 인스턴스를 초기화합니다. |
| get_barcode_type() | 바코드 유형을 가져옵니다. |
