## PrimaryData class

HIBC LIC 주 데이터를 저장하기 위한 클래스.

PrimaryData 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PrimaryData() | PrimaryData 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| labeler_identification_code | 라벨러 식별 코드의 날짜를 식별합니다.<br/>            라벨러 식별 코드는 4자리 영숫자 문자열이어야 하며, 첫 번째 문자는 항상 알파벳이어야 합니다. |
| product_or_catalog_number | 제품 또는 카탈로그 번호를 식별합니다. 제품 또는 카탈로그 번호는 최대 18자 길이의 영�숫자 문자열이어야 합니다. |
| unit_of_measure_id | 단위 측정 ID를 식별합니다. 단위 측정 ID는 0에서 9 사이의 정수값이어야 합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| parse_from_string(primary_data_codetext) | HIBC LIC 사양에 따라 문자열 형식에서 기본 데이터를 인스턴스화합니다. |
