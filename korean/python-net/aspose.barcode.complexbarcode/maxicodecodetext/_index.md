## MaxiCodeCodetext class

MaxiCode 코드에 삽입된 텍스트를 인코딩 및 디코딩하기 위한 기본 클래스.

MaxiCodeCodetext 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| encode_mode | MaxiCode 인코드 모드를 가져오거나 설정합니다. <br/>            기본값: Auto. |
| eci_encoding | ECI 인코딩을 가져오거나 설정합니다. MaxiCodeEncodeMode가 Auto인 경우에 사용됩니다.<br/>            기본값: ISO-8859-1 |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_mode() | MaxiCode 모드를 가져옵니다. |
| get_constructed_codetext() | 코드 텍스트를 구성합니다 |
| init_from_string(constructed_codetext) | 구성된 코드 텍스트에서 인스턴스를 초기화합니다. |
| get_barcode_type() | 바코드 유형을 가져옵니다. |
