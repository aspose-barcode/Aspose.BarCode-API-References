## DotCodeExtendedParameters class

DotCode 인식 바코드의 특수 데이터를 저장합니다.

DotCodeExtendedParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_empty | 모든 매개변수가 기본값만 가지고 있는지 테스트합니다. |
| structured_append_mode_barcodes_count | DotCode 구조화 추가 모드 바코드 수를 가져옵니다. 기본값은 -1입니다. 카운트는 1에서 35 사이의 값이어야 합니다. |
| structured_append_mode_barcode_id | DotCode 구조화 추가 모드 바코드의 ID를 가져옵니다. ID는 1부터 시작하며 바코드 수보다 작거나 같아야 합니다. 기본값은 -1입니다. |
| is_reader_initialization | 코드가 바코드 리더기의 초기화 또는 재프로그램 지시로 해석하도록 리더에게 지시하는 데 사용되는지 여부를 나타냅니다.<br/>            기본값은 false입니다. |
