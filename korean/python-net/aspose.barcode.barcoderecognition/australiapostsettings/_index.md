## AustraliaPostSettings class

AustraliaPost 디코딩 매개변수. AustraliaPost 심볼로지에서 인식된 데이터에 영향을 주는 매개변수를 포함합니다.

AustraliaPostSettings 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| customer_information_interpreting_type | AustralianPost 바코드의 고객 정보에 대한 해석 유형을 가져오거나 설정합니다. 기본값은 CustomerInformationInterpretingType.Other입니다. |
| ignore_ending_filling_patterns_for_c_table | 디코딩 시 CTable 방식으로 고객 정보 필드의 마지막 채우기 패턴을 무시하도록 AustraliaPost 디코더를 강제하는 플래그입니다.<br/>            CTable 인코딩 방식은 인코딩 테이블에 빈틈이 없으며, 채우기 패턴 "333" 시퀀스는 문자 "z"로 디코딩됩니다. |
| customer_information_decoder | AustraliaPost 심볼에서 사용되는 고객 정보 필드 디코딩을 위한 공개 인터페이스입니다. |
