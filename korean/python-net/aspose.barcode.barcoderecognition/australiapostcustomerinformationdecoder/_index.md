## AustraliaPostCustomerInformationDecoder class

AustraliaPost 심볼로지에서 사용되는 고객 정보 필드 디코딩을 위한 공개 인터페이스입니다. 구현은 사용자가 제공해야 합니다.

AustraliaPostCustomerInformationDecoder 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| decode(customer_information_field) | AustraliaPost 심볼을 사용하여 고객 정보 필드를 디코드합니다. <br/>            NTable 및 CTable 인코딩에서 다른 데이터 해석에 사용할 수 있습니다.<br/>            데이터는 0, 1, 2 또는 3의 바 값 행으로 제공됩니다. |
