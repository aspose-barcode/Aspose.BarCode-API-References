## BarcodeSettings class

주요 BarCode 디코딩 매개변수입니다. 인식된 데이터에 영향을 주는 매개변수를 포함합니다.

BarcodeSettings 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| checksum_validation |  |
| strip_fnc | 코드텍스트에서 FNC1, FNC2, FNC3 문자를 제거합니다. 기본값은 false입니다. |
| only_requested_types | 인식하도록 명시적으로 지정된 바코드 유형만 반환합니다. <br/>            활성화되면, 다른 호환 또는 동등한 유형의 인식된 바코드가 필터링됩니다. <br/>            기본값은 false입니다. |
| detect_encoding | 엔진이 유니코드 코드셋에 대한 코드텍스트 인코딩을 감지하도록 강제하는 플래그입니다. 기본값은 true입니다. |
| australia_post | AustraliaPost 디코딩 매개변수를 가져옵니다. |
| calculate_symbol_quality | 인식 중에 바코드 심볼 품질을 계산할지 여부를 나타내는 값을 가져오거나 설정합니다. |
