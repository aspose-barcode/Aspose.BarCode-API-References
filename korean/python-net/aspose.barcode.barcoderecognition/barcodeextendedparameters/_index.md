## BarCodeExtendedParameters class

BarCodeExtendedParameters 유형은 다음 멤버를 노출합니다:

| :- | :- |
| one_d | 1D 인식 바코드의 특수 데이터인 [OneDExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/onedextendedparameters/)를 가져옵니다 |
