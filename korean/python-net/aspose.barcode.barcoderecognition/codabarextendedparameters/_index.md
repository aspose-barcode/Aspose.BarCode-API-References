## CodabarExtendedParameters class

인식된 바코드의 Codabar 추가 정보를 저장합니다.

CodabarExtendedParameters 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_empty | 모든 매개변수가 기본값만 가지고 있는지 테스트합니다. |
| start_symbol | Codabar 시작 기호를 가져오거나 설정합니다.<br/>            기본값: CodabarSymbol.A |
| stop_symbol | Codabar 종료 기호를 가져오거나 설정합니다.<br/>            기본값: CodabarSymbol.A |
