## LuminanceFrame class

8비트 그레이스케일 이미지 프레임을 나타냅니다. 각 픽셀은 밝기 값을 포함하는 1바이트로 표현됩니다.

LuminanceFrame 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | LuminanceFrame 클래스의 새 인스턴스를 초기화합니다. |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | LuminanceFrame 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| 데이터 | 휘도 데이터를 가져옵니다. |
| width | 프레임 너비를 픽셀 단위로 가져옵니다. |
| height | 프레임 높이를 픽셀 단위로 가져옵니다. |
| row_stride | 두 인접 행의 시작 사이의 바이트 거리를 가져옵니다<br/>             |
| rotation_degrees | 프레임이 올바른 방향을 갖도록 시계 방향으로 회전해야 하는 각도를 가져옵니다. |
