## Quadrangle class

네 개의 [Point](/barcode/python-net/aspose.drawing/point/)을 저장하여 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 영역을 나타냅니다.

Quadrangle 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Quadrangle() | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 클래스의 새 빈 인스턴스를 초기화합니다. |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Quadrangle 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| left_top | 왼쪽 위 코너 [Point](/barcode/python-net/aspose.drawing/point/) 를 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 영역에서 가져옵니다. |
| right_top | 오른쪽 위 코너 [Point](/barcode/python-net/aspose.drawing/point/) 를 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 영역에서 가져옵니다. |
| right_bottom | 오른쪽 아래 코너 [Point](/barcode/python-net/aspose.drawing/point/) 를 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 영역에서 가져옵니다. |
| left_bottom | 왼쪽 아래 코너 [Point](/barcode/python-net/aspose.drawing/point/) 를 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 영역에서 가져옵니다. |
| is_empty | 이 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 의 모든 [Point](/barcode/python-net/aspose.drawing/point/) 가 0값인지 테스트합니다. |
| bounding_rectangle | 이 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 을 둘러싸는 [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) 를 가져옵니다. |
| EMPTY | 속성이 초기화되지 않은 [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 클래스를 나타냅니다. |
