## Pdf417ExtendedParameters class

인식된 바코드의 MacroPdf417 메타데이터 정보를 저장합니다.

Pdf417ExtendedParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_empty | 모든 매개변수가 기본값만 가지고 있는지 테스트합니다. |
| macro_pdf_417_file_id | 바코드의 파일 ID를 가져옵니다. MacroPdf417와 함께 사용할 때만 가능합니다. |
| macro_pdf_417_segment_id | 바코드의 세그먼트 ID를 가져옵니다. MacroPdf417와 함께 사용할 때만 가능합니다. |
| macro_pdf_417_segments_count | macro pdf417 바코드 세그먼트 수를 가져옵니다. 기본값은 -1입니다. |
| macro_pdf_417_file_name | Macro PDF417 파일 이름 (옵션). |
| macro_pdf_417_file_size | Macro PDF417 파일 크기 (옵션). |
| macro_pdf_417_sender | Macro PDF417 발신자 이름 (옵션). |
| macro_pdf_417_addressee | Macro PDF417 수신자 이름 (옵션). |
| macro_pdf_417_time_stamp | Macro PDF417 타임스탬프 (선택 사항). |
| macro_pdf_417_checksum | Macro PDF417 체크섬 (선택 사항). |
| macro_pdf_417_terminator | 세그먼트가 Macro PDF417 파일의 마지막 세그먼트인지 여부를 나타냅니다. |
| is_reader_initialization | 리더에게 심볼에 포함된 데이터를 리더 초기화를 위한 프로그래밍으로 해석하도록 지시하는 데 사용됩니다. |
| is_linked | 바코드가 1D 바코드와 연결되어야 함을 나타내는 플래그입니다. |
| is_code_128_emulation | MicroPdf417 바코드가 908, 909, 910 또는 911 Code 128 에뮬레이션 코드워드로 인코딩되었음을 나타내는 플래그입니다. |
