## Iso15416Quality class

1D 바코드에 대한 ISO/IEC 15416 표준에 따라 계산된 바코드 품질 등급을 저장합니다.

Iso15416Quality 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| grade | ISO/IEC 15416에 따라 전체 바코드 품질 등급을 가져옵니다. |
| decode | 바코드가 참조 디코드 알고리즘을 사용하여 디코딩될 수 있는지 여부를 나타내는 디코드 등급을 가져옵니다. |
| symbol_contrast | 최대 및 최소 반사율 차이를 기반으로 한 심볼 대비 등급을 가져옵니다. |
| minimum_reflectance | 가장 어두운 바의 반사율을 기반으로 최소 반사율 등급을 가져옵니다. |
| minimum_edge_contrast | 인접한 바와 공백 사이의 최소 반사율 차이를 기반으로 최소 에지 대비 등급을 가져옵니다. |
| modulation | 바코드 전체에 걸친 에지 대비의 균일성을 기반으로 변조 등급을 가져옵니다. |
| defects | 바와 공백 내의 반사율 불규칙성을 기반으로 결함 등급을 가져옵니다. |
| decodability | 바와 공백 너비의 정확성을 기반으로 디코더 가능 등급을 가져옵니다. |
