## MaxiCodeExtendedParameters class

인식된 바코드의 MaxiCode 추가 정보를 저장합니다.

MaxiCodeExtendedParameters 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_empty | 모든 매개변수가 기본값만 가지고 있는지 테스트합니다. |
| 모드 | MaxiCode 인코드 모드를 가져오거나 설정합니다.<br/>            기본값: Mode4 |
| structured_append_mode_barcode_id | 구조화된 추가 모드에서 MaxiCode 바코드 ID를 가져오거나 설정합니다.<br/>            기본값: 0 |
| structured_append_mode_barcodes_count | 구조화된 추가 모드에서 MaxiCode 바코드 개수를 가져오거나 설정합니다.<br/>            기본값: -1 |
