## BarCodeRegionParameters class

인식된 바코드의 영역 및 바코드 각도를 나타냅니다.

BarCodeRegionParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| quadrangle | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 바코드 영역 경계를 가져옵니다 |
| angle | 바코드의 각도(0-360)를 가져옵니다. |
| points | [Point](/barcode/python-net/aspose.drawing/point/) 배열으로 바코드 영역 경계를 가져옵니다 |
| rectangle | 바코드 영역 경계를 가져옵니다 |
