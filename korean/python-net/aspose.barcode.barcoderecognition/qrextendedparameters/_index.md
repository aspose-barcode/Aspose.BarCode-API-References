## QRExtendedParameters class

인식된 바코드의 QR 구조화 추가 정보를 저장합니다.

QRExtendedParameters 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_empty | 모든 매개변수가 기본값만 가지고 있는지 테스트합니다. |
| structured_append_mode_bar_codes_quantity | QR 구조 추가 모드 바코드 수량을 가져옵니다. 기본값은 -1입니다. |
| structured_append_mode_bar_code_index | QR 구조 추가 모드 바코드의 인덱스를 가져옵니다. 인덱스는 0부터 시작합니다. 기본값은 -1입니다. |
| structured_append_mode_parity_data | QR 구조 추가 모드 패리티 데이터를 가져옵니다. 기본값은 -1입니다. |
| version | 인식된 QR 코드의 버전입니다. Version1부터 Version40까지. |
| micro_qr_version | 인식된 MicroQR 코드의 버전입니다. M1부터 M4까지. |
| rect_micro_qr_version | 인식된 RectMicroQR 코드의 버전입니다. R7x43부터 R17x139까지. |
| error_level | 인식된 바코드의 Reed-Solomon 오류 정정 수준입니다. 낮음에서 높음 순: LevelL, LevelM, LevelQ, LevelH. |
