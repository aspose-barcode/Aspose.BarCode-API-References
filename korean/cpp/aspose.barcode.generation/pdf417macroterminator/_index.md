## Pdf417MacroTerminator enum


인코더에게 매크로 PDF417 종결자 (코드워드 922)를 세그먼트에 추가할지 여부를 알려주는 데 사용됩니다. 매크로 PDF417에만 적용됩니다.

```cpp
enum class Pdf417MacroTerminator
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| 자동 | 0 | 세그먼트 수가 제공되고 현재 세그먼트가 마지막인 경우 종결자가 자동으로 추가됩니다. 다른 경우에는 종결자가 추가되지 않습니다. |
| 없음 | 1 | 종결자는 추가되지 않습니다. |
| Set | 2 | 종결자가 추가됩니다. |
