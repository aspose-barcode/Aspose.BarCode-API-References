## PatchFormat enum


PatchCode 형식. 단일 PatchCode를 생성하려면 PatchOnly를 선택하십시오. 페이지 형식을 사용하면 PatchCode를 경계로 하는 Patch 페이지를 생성합니다.

```cpp
enum class PatchFormat
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| PatchOnly | 0 | PatchCode만 생성합니다. |
| A4 | 1 | A4 형식 페이지를 생성하고 가장자리를 PatchCodes로, 중앙에 선택적 QR을 배치합니다 |
| A4_LANDSCAPE | 2 | A4 가로 방향 형식 페이지를 생성하고 가장자리를 PatchCodes로, 중앙에 선택적 QR을 배치합니다 |
| US_Letter | 3 | US 레터 형식 페이지를 생성하고 가장자리를 PatchCodes로, 중앙에 선택적 QR을 배치합니다 |
| US_Letter_LANDSCAPE | 4 | US 레터 가로 방향 형식 페이지를 생성하고 가장자리를 PatchCodes로, 중앙에 선택적 QR을 배치합니다 |
