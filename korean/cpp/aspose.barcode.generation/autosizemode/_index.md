## AutoSizeMode enum


자동 크기 조정 모드의 다양한 유형을 지정합니다.

```cpp
enum class AutoSizeMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| 없음 | 0 | 자동 크기 조정이 비활성화되었습니다. |
| Nearest | 1 | 바코드를 ImageWidth 및 ImageHeight 속성으로 지정된 가장 낮은 가능한 크기로 가장 가깝게 조정합니다. 기본 종횡비를 유지합니다. |
| 보간 | 2 | 바코드를 지정된 크기로 크기 조정합니다. 크기는 ImageWidth 및 ImageHeight 속성을 통해 지정할 수 있습니다. 스케일링 후 생성된 바코드가 유효하지 않을 수 있습니다(읽을 수 없음). |
