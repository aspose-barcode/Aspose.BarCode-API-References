## HIBCLICDateFormat enum


HIBC LIC에 대한 다양한 날짜 형식 유형을 지정합니다.

```cpp
enum class HIBCLICDateFormat
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| YYYYMMDD | 0 | YYYYMMDD 형식. 추가 보조 데이터에 인코딩됩니다. |
| MMYY | 1 | MMYY 형식. |
| MMDDYY | 2 | MMDDYY 형식. |
| YYMMDD | 3 | YYMMDD 형식. |
| YYMMDDHH | 4 | YYMMDDHH 형식. |
| YYJJJ | 5 | 줄리안 날짜 형식. |
| YYJJJHH | 6 | 시간이 포함된 줄리안 날짜 형식. |
| 없음 | 7 | 만료 날짜를 인코딩하지 않습니다. |
