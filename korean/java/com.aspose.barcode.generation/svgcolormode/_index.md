public enum SvgColorMode extends Enum<SvgColorMode>

svg 파일에서 색상을 채우는 가능한 모드들. RGB가 기본이며 SVG 1.1에서 지원됩니다. RGBA, HSL, HSLA는 SVG 2.0 표준에서 허용됩니다. RGB에서도 불투명도는 "fill-opacity" 매개변수를 통해 설정됩니다.
## 필드

| 필드 | 설명 |
| --- | --- |
| [HSL](#HSL) | HSL 모드, 예시: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| [HSLA](#HSLA) | HSLA 모드, 예시: fill="hsla(30, 50%, 70%, 0.8)" |
| [RGB](#RGB) | RGB 모드, 예시: fill="\#ff5511" fill-opacity="0.73". |
| [RGBA](#RGBA) | RGBA 모드, 예시: fill="rgba(255, 85, 17, 0.73)" |
