PatchCode 형식. 단일 PatchCode를 생성하려면 PATCH\_ONLY를 선택하십시오. 페이지 형식을 사용하여 PatchCodes를 테두리로 하는 Patch 페이지를 생성합니다.
## 필드

| 필드 | 설명 |

| [A4_LANDSCAPE](#A4-LANDSCAPE) | PatchCodes를 테두리로 하고 중앙에 선택적 QR이 포함된 A4 가로 형식 페이지를 생성합니다. |
| [PATCH_ONLY](#PATCH-ONLY) | PatchCode만 생성합니다. |
| [US_LETTER](#US-LETTER) | PatchCodes를 테두리로 하고 중앙에 선택적 QR이 포함된 US 레터 형식 페이지를 생성합니다. |
| [US_LETTER_LANDSCAPE](#US-LETTER-LANDSCAPE) | PatchCodes를 테두리로 하고 중앙에 선택적 QR이 포함된 US 레터 가로 형식 페이지를 생성합니다. |
