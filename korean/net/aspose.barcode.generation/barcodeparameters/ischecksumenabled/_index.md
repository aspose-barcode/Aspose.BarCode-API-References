## BarcodeParameters.IsChecksumEnabled property

1D 바코드 생성 시 체크섬을 활성화합니다.

체크섬이 반드시 포함해야 하는 심볼에 대해서는 기본값이 Yes로 처리되고, 체크섬이 선택 가능한 경우에는 No로 처리됩니다.

체크섬을 사용할 수 있음: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN, Codabar

체크섬이 항상 사용됨: 나머지 심볼

```csharp
public EnableChecksum IsChecksumEnabled { get; set; }
```
