## BarcodeParameters.ThrowExceptionWhenCodeTextIncorrect property

1D 바코드에만 적용됩니다. 코드 텍스트가 올바르지 않고 값이 true로 설정된 경우 예외가 발생합니다. 그렇지 않으면 코드 텍스트가 바코드 사양에 맞게 자동으로 수정됩니다. 다음 경우에는 항상 예외가 발생합니다: Databar 심볼이 코드가 올바르지 않은 경우. 다음 경우에는 예외가 발생하지 않습니다: AustraliaPost, SingapurePost, Code39FullASCII, Code93, Code16K, Code128 심볼이 코드가 올바르지 않은 경우.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
