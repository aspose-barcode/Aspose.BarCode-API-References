## BarcodeParameters.XDimension property

x-dimension은 BarCode 바 또는 공백 단위의 최소 너비입니다. 이를 증가시키면 전체 바코드 이미지 너비가 증가합니다. [`AutoSizeMode`](../../basegenerationparameters/autosizemode/) 속성이 AutoSizeMode.Nearest 또는 AutoSizeMode.Interpolation으로 설정된 경우 무시됩니다.

public Unit XDimension { get; set; }
