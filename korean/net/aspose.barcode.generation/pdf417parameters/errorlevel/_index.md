## Pdf417Parameters.ErrorLevel property

BarCode의 오류 정정 수준에 대한 Pdf417 심볼 유형을 가져오거나 설정합니다. level0부터 level8까지이며, level0은 오류 정정 정보가 없음을, level8은 최상의 오류 정정으로 더 큰 이미지가 됨을 의미합니다.

```csharp
public Pdf417ErrorLevel ErrorLevel { get; set; }
```
