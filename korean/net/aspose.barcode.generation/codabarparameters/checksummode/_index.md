## CodabarParameters.ChecksumMode property

Codabar 바코드의 체크섬 알고리즘을 가져오거나 설정합니다. 기본값: CodabarChecksumMode.Mod16. 체크섬 계산을 활성화하려면 EnableChecksum.Yes 값을 EnableChecksum 속성에 설정하십시오. `ChecksumMode`를 참조하십시오.

```csharp
public CodabarChecksumMode ChecksumMode { get; set; }
```
