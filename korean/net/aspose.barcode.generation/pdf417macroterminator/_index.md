## Pdf417MacroTerminator enumeration

인코더에게 세그먼트에 Macro PDF417 Terminator(코드워드 922)를 추가할지 여부를 알려주는 데 사용됩니다. Macro PDF417에만 적용됩니다.

```csharp
public enum Pdf417MacroTerminator
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Auto | `0` | 세그먼트 수가 제공되고 현재 세그먼트가 마지막인 경우 Terminator가 자동으로 추가됩니다. 다른 경우에는 Terminator가 추가되지 않습니다. |
| None | `1` | 종결자는 추가되지 않습니다. |
| Set | `2` | 종결자는 추가됩니다. |
