## EncodeTypes.Parse method

```csharp
public static bool Parse(string parsingType, out BaseEncodeType result)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| parsingType | String | 변환할 BaseEncodeType 표현을 포함하는 문자열입니다. |
| 결과 | BaseEncodeType& | 변환이 성공적으로 완료되면 실제 BaseEncodeType이 반환됩니다; |

### 반환 값

**true** if s was converted successfully; otherwise, **false**.
