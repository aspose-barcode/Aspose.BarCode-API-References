## EncodeTypes.UpcaGs1DatabarCoupon field

데이터가 **UPC coupon with GS1 DataBar addition** 바코드 사양으로 인코딩되어야 함을 지정합니다. 입력 문자열의 예: BarcodeGenerator.Codetext = "514141100906(8110)106141416543213500110000310123196000", 여기서 UPCA 부분은 "514141100906", Databar 부분은 "(8110)106141416543213500110000310123196000" 입니다. 캡션을 변경하려면 Parameters.CaptionAbove.Text = "company prefix + offer code"; 를 사용하십시오.

```csharp
public static readonly SymbologyEncodeType UpcaGs1DatabarCoupon;
```
