## EncodeTypes.TryParse method

BaseEncodeType의 문자열 표현을 해당 인스턴스로 변환합니다. 반환값은 변환이 성공했는지 실패했는지를 나타냅니다.

```csharp
public static bool TryParse(string parsingType, out BaseEncodeType result)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| parsingType | String | \"Index:-1; Name:None\" 형식의 문자열을 변환합니다. |
| 결과 | BaseEncodeType& | 변환이 성공적으로 완료되면 실제 SingleEncodeType이 반환됩니다; |

### 반환 값

**true** if s was converted successfully; otherwise, **false**.
