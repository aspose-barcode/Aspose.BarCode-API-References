## GS1ValidationLevel enumeration

GS1 데이터 검증 수준을 지정합니다. 높은 검증 수준은 낮은 수준의 모든 검사를 포함합니다.

```csharp
public enum GS1ValidationLevel
```

### 값

| 이름 | 값 | 설명 |

| Content | `1` | GS1 구문과 애플리케이션 식별자 값의 내용을 검증합니다. 여기에는 문자 집합, 체크섬 및 값별 규칙이 포함됩니다. |
