## MailmarkCodetext.DestinationPostCodePlusDPS property

PC와 DP는 PAF 형식을 따라야 합니다. 국제 "XY11 "을 나타내는 9자 문자열(뒤에 공백 5개 포함) 또는 국내 정렬 코드를 나타내는 문자 패턴입니다. 국내 정렬 코드는 외부 우편번호, 내부 우편번호 및 Delivery Point Suffix로 구성됩니다.

public string DestinationPostCodePlusDPS { get; set; }
