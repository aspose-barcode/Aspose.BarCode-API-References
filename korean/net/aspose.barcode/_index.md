| 클래스 | 설명 |

| [BuildVersionInfo](./buildversioninfo/) | 현재 빌드 버전 정보를 포함합니다. |
| [InvalidCodeException](./invalidcodeexception/) | 코드 텍스트에 잘못된 문자가 포함된 경우 예외가 발생합니다. |
| [License](./license/) | 구성 요소에 대한 라이선스 부여 메서드를 제공합니다. |

| [XmlSerializationAttribute](./xmlserializationattribute/) | XML 엔터티 생성기에 대한 속성을 나타냅니다. |
