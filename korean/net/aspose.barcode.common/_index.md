**BarCode.Common**는 주요 기능을 유지하기 위한 공통 기능 및 도우미 도구를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [GS1Element](./gs1element/) | 불변의 GS1 애플리케이션 식별자와 값 쌍을 나타냅니다. |
| [GS1ValidationException](./gs1validationexception/) | 검증이 실패할 때 엄격한 GS1 작업에 의해 발생하는 예외입니다. |
| [GS1ValidationIssue](./gs1validationissue/) | 하나의 GS1 검증 오류를 설명합니다. |
| [GS1ValidationResult](./gs1validationresult/) | GS1 요소 문자열, Digital Link URI 또는 하나의 AI 값에 대해 독립적으로 감지 가능한 모든 오류를 포함합니다. |
| [ProcessorSettings](./processorsettings/) | ProcessorSettings는 멀티스레드 성능 향상을 통해 바코드를 인식하도록 허용합니다. |
## 열거형

| --- | --- |
