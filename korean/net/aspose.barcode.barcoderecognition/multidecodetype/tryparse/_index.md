## MultiDecodeType.TryParse method

MultiDecodeType의 문자열 표현을 해당 인스턴스로 변환합니다. 반환 값은 변환이 성공했는지 실패했는지를 나타냅니다.

```csharp
public static bool TryParse(string parsingType, out MultiDecodeType result)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| parsingType | String | 변환할 문자열은 "AllSupportedTypes" 또는 "EAN8,EAN13,CodaBar" 형식이어야 합니다. |
| 결과 | MultiDecodeType& | 변환이 성공적으로 완료되면 실제 MultiDecodeType이 반환됩니다. |

### 반환 값

**true** if s was converted successfully; otherwise, **false**.
