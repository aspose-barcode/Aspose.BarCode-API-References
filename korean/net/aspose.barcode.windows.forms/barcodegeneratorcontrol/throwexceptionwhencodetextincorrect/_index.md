## BarCodeGeneratorControl.ThrowExceptionWhenCodeTextIncorrect property

1D 바코드에만 적용됩니다. codetext가 올바르지 않고 값이 true로 설정된 경우 예외가 발생합니다. 그렇지 않으면 codetext가 바코드 사양에 맞게 수정됩니다. 예외는 항상 발생합니다: Databar 심볼로지에서 codetext가 올바르지 않은 경우. 예외는 발생하지 않습니다: AustraliaPost, SingapurePost, Code39Extended, Code93Extended, Code16K, Code128 심볼로지에서 codetext가 올바르지 않은 경우.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
