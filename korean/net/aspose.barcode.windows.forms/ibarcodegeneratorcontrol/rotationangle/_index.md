## IBarCodeGeneratorControl.RotationAngle property

BarCode 이미지 회전 각도, 단위는 도이며, 예: RotationAngle = 0 또는 RotationAngle = 360은 회전이 없음을 의미합니다. RotationAngle가 90, 180, 270 또는 0이 아니면 스캐너가 이미지를 읽는 데 어려움이 증가할 수 있습니다.

public float RotationAngle { get; set; }
