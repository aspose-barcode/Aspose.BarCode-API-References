## ITF14BorderType

ITF14 바코드의 테두리 유형

## 값

| 이름 | 설명 |
| --- | --- |
| NONE | 바코드를 둘러싼 경계가 없음 |
| FRAME | 바코드를 둘러싼 프레임 |
| BAR | 바코드를 둘러싸는 두 개의 수평 막대 |
| FRAME_OUT | 바코드를 둘러싼 프레임 |
| BAR_OUT | 바코드를 둘러싸는 두 개의 수평 막대 |
