## BorderDashStyle

점선 테두리 스타일을 지정합니다.

## 값

| 이름 | 설명 |
| --- | --- |
| SOLID | 실선(단선)을 지정합니다. |
| DASH | 대시(-)로 구성된 선을 지정합니다. |
| DOT | 점(.)으로 구성된 선을 지정합니다. |
| DASH_DOT | 대시-점 패턴이 반복되는 선을 지정합니다. |
| DASH_DOT_DOT | 대시-점-점 패턴이 반복되는 선을 지정합니다. |
