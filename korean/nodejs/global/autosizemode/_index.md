## AutoSizeMode

자동 크기 조정 모드의 다양한 유형을 지정합니다. 기본값은 AutoSizeMode.NONE입니다.

## 값

| 이름 | 설명 |
| --- | --- |
| NONE | 자동 크기 조정이 비활성화됩니다. 기본값. |
| NEAREST | 바코드는 BarCodeWidth 및 BarCodeHeight 속성으로 지정된 가장 가까운 최소 크기로 조정됩니다. |
| INTERPOLATION | 바코드를 지정된 크기로 약간 스케일링하여 조정하지만, 보간을 사용하기 때문에 경우에 따라 약간 손상될 수 있습니다. 크기는 BarcodeGenerator.BarCodeWidth 및 BarcodeGenerator.BarCodeHeight 속성으로 지정할 수 있습니다. |
