## EnableChecksum

1D 바코드 생성 시 체크섬을 활성화합니다. 기본값은 체크섬이 반드시 포함되어야 하는 심볼로지는 Yes로, 체크섬이 선택 가능한 경우는 No로 처리됩니다. 체크섬이 전혀 사용되지 않음: Codabar 체크섬이 가능한 경우: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN 체크섬이 항상 사용됨: 나머지 심볼로지

## 값

| 이름 | 설명 |
| --- | --- |
| DEFAULT | 사양에서 체크섬이 요구되는 경우 - 체크섬이 첨부됩니다. |
| YES | 가능하면 항상 체크섬을 사용합니다. |
| NO | 체크섬을 사용하지 마십시오. |
