## MacroCharacter

특수 모드에서 더 압축된 인코딩을 얻기 위해 매크로 문자 05와 06 값을 사용합니다. 05 매크로 문자는 디코드된 데이터 헤더를 "[)>\u001E05\u001D" 로, 트레일러를 "\u001E\u0004" 로 변환합니다. 06 매크로 문자는 디코드된 데이터 헤더를 "[)>\u001E06\u001D" 로, 트레일러를 "\u001E\u0004" 로 변환합니다. 이 샘플은 MicroPdf417 및 DataMatrix에서 매크로 문자를 인코딩하는 방법을 보여줍니다

## 값

| 이름 | 설명 |
| --- | --- |
| AUTO | 자동 결정 |
| TYPE_7 | 24 x 24 모듈 |
| TYPE_9 | 32 x 32 모듈 |
| TYPE_29 | 16 x 48 모듈 |
