## AztecEncodeMode

Aztec 바코드의 인코딩 모드.

## 값

| 이름 | 설명 |
| --- | --- |
| AUTO | Aztec에 대해 최적의 심볼 (COMPACT 또는 FULL-range)을 자동으로 선택하도록 지정합니다. 이것이 기본값입니다. |
| COMPACT | Aztec용 COMPACT 심볼을 지정합니다. Aztec COMPACT 심볼은 1, 2, 3 또는 4 레이어만 허용합니다. |
| FULL_RANGE | Aztec용 FULL-range 심볼을 지정합니다. Aztec FULL-range 심볼은 1에서 32 레이어까지 허용합니다. |
| RUNE | Aztec용 RUNE 심볼을 지정합니다. Aztec Runes는 작지만 구별되는 기계 판독 마크의 시리즈입니다. 0에서 255까지의 숫자 값만 허용합니다. |
