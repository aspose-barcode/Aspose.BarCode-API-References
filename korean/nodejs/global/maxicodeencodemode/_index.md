## MaxiCodeEncodeMode

MaxiCode 바코드의 인코딩 모드입니다.

## 값

| 이름 | 설명 |
| --- | --- |
| AUTO | MicroQR에 대해 최적의 버전을 자동으로 선택하도록 지정합니다. 기본값입니다. |
| M1 | 11 x 11 모듈을 가진 Micro QR의 M1 버전을 지정합니다. |
| M2 | 13 x 13 모듈을 가진 Micro QR의 버전 M2를 지정합니다. |
| M3 | 15 x 15 모듈을 가진 Micro QR의 버전 M3을 지정합니다. |
| M4 | 17 x 17 모듈을 가진 Micro QR의 버전 M4를 지정합니다. |
