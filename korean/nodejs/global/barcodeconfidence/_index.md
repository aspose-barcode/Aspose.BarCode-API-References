## BarCodeConfidence

인식 신뢰 수준을 포함합니다.

## 값

| 이름 | 설명 |
| --- | --- |
| NONE | 코드 텍스트가 올바르게 인식되지 않았거나 바코드가 가능한 가짜로 감지된 경우의 바코드 인식 신뢰도 |
| MODERATE | 체크섬이 약하거나 없을 경우(주로 1D 바코드) 바코드 인식 신뢰도. 신뢰도가 낮으면 코드 텍스트에 오인식이 있거나 가짜 인식이 발생할 수 있습니다. |
| STRONG | Reed–Solomon과 같은 BCH 코드를 통해 확인된 인식 신뢰도. 읽은 코드 텍스트에 오류나 가짜 인식이 없어야 합니다. |
