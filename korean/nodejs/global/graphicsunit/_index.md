## GraphicsUnit

주어진 데이터의 측정 단위를 지정합니다.

## 값

| 이름 | 설명 |
| --- | --- |
| WORLD | 세계 좌표계 단위를 측정 단위로 지정합니다. |
| DISPLAY | 디스플레이 장치의 측정 단위를 지정합니다. 일반적으로 비디오 디스플레이는 픽셀이며, 프린터는 1/100인치를 사용합니다. |
| PIXEL | 디바이스 픽셀을 측정 단위로 지정합니다. |
| POINT | 프린터의 포인트(1/72인치)를 측정 단위로 지정합니다. |
| INCH | 인치를 측정 단위로 지정합니다. |
| DOCUMENT | 문서 단위(1/300인치)를 측정 단위로 지정합니다. |
| MILLIMETER | 밀리미터를 측정 단위로 지정합니다. |
