## HanXinEncodeMode

Han Xin 코드 인코딩 모드. ASCII/중국어 문자 또는 유니코드 문자에 대해서는 Auto를 사용하는 것이 권장됩니다.

## 값

| 이름 | 설명 |
| --- | --- |
| NONE | 바코드를 둘러싼 경계가 없음 |
| FRAME | 바코드를 둘러싼 프레임 |
| BAR | 바코드를 둘러싸는 두 개의 수평 막대 |
| FRAME_OUT | 바코드를 둘러싼 프레임 |
| BAR_OUT | 바코드를 둘러싸는 두 개의 수평 막대 |
