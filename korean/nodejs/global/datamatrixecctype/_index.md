## DataMatrixEccType

인코딩할 ECC 유형을 지정합니다.

## 값

| 이름 | 설명 |
| --- | --- |
| ECC_AUTO | 인코딩된 ECC 유형이 기본 Reed-Solomon 오류 정정 또는 ECC 200에 의해 정의된다고 지정합니다. |
| ECC_000 | 인코딩된 ECC 유형이 ECC 000으로 정의된다고 지정합니다. |
| ECC_050 | 인코딩된 ECC 유형이 ECC 050으로 정의된다고 지정합니다. |
| ECC_080 | 인코딩된 ECC 유형이 ECC 080으로 정의된다고 지정합니다. |
| ECC_100 | 인코딩된 ECC 유형이 ECC 100으로 정의된다고 지정합니다. |
| ECC_140 | 인코딩된 ECC 유형이 ECC 140으로 정의된다고 지정합니다. |
| ECC_200 | 인코딩된 ECC 유형이 ECC 200으로 정의됩니다. 사용을 권장합니다. |
