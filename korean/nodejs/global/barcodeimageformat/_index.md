## BarCodeImageFormat

이미지의 파일 형식을 지정합니다.

## 값

| 이름 | 설명 |
| --- | --- |
| BMP | 비트맵 (BMP) 이미지 형식을 지정합니다. |
| GIF | 그래픽 교환 형식 (GIF) 이미지 형식을 지정합니다. |
| JPEG | 합동 사진 전문가 그룹 (JPEG) 이미지 형식을 지정합니다. |
| PNG | W3C 포터블 네트워크 그래픽스 (PNG) 이미지 형식을 지정합니다. |
| TIFF | 태그 이미지 파일 형식 (TIFF) 이미지 형식을 지정합니다. |
| TIFF_IN_CMYK | CMYK 색상 모델의 태그 이미지 파일 형식 (TIFF) 이미지 형식을 지정합니다. |
| EMF | 향상된 메타파일 (EMF) 이미지 형식을 지정합니다. |
| SVG | 확장 가능한 벡터 그래픽스 (SVG) 이미지 형식을 지정합니다. |
| PDF | 포터블 문서 형식 (PDF) 이미지 형식을 지정합니다. |
