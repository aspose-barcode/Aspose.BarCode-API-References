## Pdf417ErrorLevel

pdf417 바코드의 오류 정정 수준으로, 레벨 0부터 레벨 9까지 있습니다. 레벨 0은 오류 정정이 없음을 의미하고, 레벨 9는 최상의 오류 정정을 의미합니다.

| LEVEL_1 | 레벨 = 1. |
| LEVEL_2 | 레벨 = 2. |
| LEVEL_3 | 레벨 = 3. |
| LEVEL_4 | 레벨 = 4. |
| LEVEL_5 | 레벨 = 5. |
| LEVEL_6 | 레벨 = 6. |
| LEVEL_7 | level = 7. |
| LEVEL_8 | level = 8. |
