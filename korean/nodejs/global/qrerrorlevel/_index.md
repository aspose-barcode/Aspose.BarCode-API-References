## QRErrorLevel

Reed-Solomon 오류 정정 수준. 낮음에서 높음 순: LEVEL_L, LEVEL_M, LEVEL_Q, LEVEL_H.

## 값

| 이름 | 설명 |
| --- | --- |
| LEVEL_L | 코드 텍스트의 7% 복구를 허용합니다. |
| LEVEL_M | 코드 텍스트의 15% 복구를 허용합니다. |
| LEVEL_Q | 코드 텍스트의 25% 복구를 허용합니다. |
| LEVEL_H | 코드 텍스트의 30% 복구를 허용합니다. |
