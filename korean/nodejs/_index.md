API는 바코드 생성, 인식 및 조작을 위한 클래스를 제공하여 Java 인터옵을 통해 Node.js 애플리케이션에 원활하게 통합할 수 있게 합니다. 지원되는 심볼로지는 Code128, EAN‑13, QR, DataMatrix, Aztec 및 PDF417과 같은 선형, 2‑D 및 우편 코드까지 다양합니다. 모든 기능은 aspose.barcode 네임스페이스 아래에 구성되어 있으며, 보조 유틸리티는 Global 네임스페이스에 위치합니다.

## 네임스페이스

| 네임스페이스 | 설명 |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | aspose.barcode 네임스페이스는 Node.js via Java에서 다양한 바코드 유형을 생성, 사용자 정의 및 디코딩하기 위한 클래스와 열거형을 제공합니다. |
| [Global](./global/) | Global 네임스페이스는 Aspose.BarCode for Node.js via Java 전반에 걸쳐 사용되는 핵심 열거형 및 유틸리티 클래스를 그룹화합니다. |
