## Code128DataPortion class

Code128 유형 바코드의 서브타입 데이터를 포함합니다

```js
new Code128DataPortion()
```

시작 코드 기호와 디코딩된 코드 텍스트를 사용하여 `Code128DataPortion` 클래스의 새 인스턴스를 생성합니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Code128 하위 집합의 유형을 가져옵니다. |
| [getData()](#getdata) | 하위 유형과 관련된 코드 텍스트 부분을 가져옵니다. |
| [toString()](#tostring) | 이 `Code128DataPortion`의 사람이 읽을 수 있는 문자열 표현을 반환합니다. |

### getCode128SubType() {#getcode128subtype}

Code128 하위 집합의 유형을 가져옵니다.

**Returns:** The type of Code128 subset

### getData() {#getdata}

하위 유형과 관련된 코드 텍스트 부분을 가져옵니다.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

이 `Code128DataPortion`의 사람이 읽을 수 있는 문자열 표현을 반환합니다.

**Returns:** A string that represents this `Code128DataPortion`.
