## License class

구성 요소에 대한 라이선스를 부여하는 메서드를 제공합니다.

```js
new License()
```

이 클래스의 새 인스턴스를 초기화합니다.

## 메서드

| 이름 | 설명 |
| --- | --- |
| [setLicense(licensePath)](#setlicense) | 구성 요소에 라이선스를 적용합니다. |

### setLicense(licensePath) {#setlicense}

구성 요소에 라이선스를 적용합니다.

| 매개변수 | 설명 |
| --- | --- |
| licensePath | 라이선스 파일 경로 |
