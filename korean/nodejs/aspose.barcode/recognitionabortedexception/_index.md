## RecognitionAbortedException class

BarCodeReader를 사용한 인식 중 시간 초과가 발생하여 발생하는 인식 중단 예외를 나타냅니다.

```js
new RecognitionAbortedException(message, executionTime)
```

지정된 인식 중단 메시지를 사용하여 클래스의 새 인스턴스를 초기화합니다.

| 매개변수 | 설명 |
| --- | --- |
| message | 예외의 오류 메시지입니다. |
| executionTime | 현재 인식 세션의 실행 시간입니다. |

## 메서드

| [setExecutionTime(value)](#setexecutiontime) | 현재 인식 세션의 실행 시간을 설정합니다. |

### getExecutionTime() {#getexecutiontime}

현재 인식 세션의 실행 시간을 가져옵니다.

**Returns:** The execution time of current recognition session

### setExecutionTime(value) {#setexecutiontime}

현재 인식 세션의 실행 시간을 설정합니다.

| 매개변수 | 설명 |
| --- | --- |
| 값 | 현재 인식 세션의 실행 시간입니다. |
