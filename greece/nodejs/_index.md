Το API παρέχει κλάσεις για δημιουργία, αναγνώριση και επεξεργασία γραμμωτών κωδίκων, επιτρέποντας αδιάκοπη ενσωμάτωση σε εφαρμογές Node.js μέσω Java interop. Οι υποστηριζόμενοι συμβολισμοί καλύπτουν γραμμικούς, 2‑Δ και ταχυδρομικούς κώδικες όπως Code128, EAN‑13, QR, DataMatrix, Aztec και PDF417. Όλη η λειτουργικότητα οργανώνεται κάτω από το χώρο ονομάτων aspose.barcode, με βοηθητικά εργαλεία τοποθετημένα στο χώρο ονομάτων Global.

## Χώροι ονομάτων

| Χώρος ονομάτων | Περιγραφή |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | Ο χώρος ονομάτων aspose.barcode προσφέρει κλάσεις και enum για δημιουργία, προσαρμογή και αποκωδικοποίηση μιας μεγάλης ποικιλίας τύπων γραμμωτών κωδίκων σε Node.js μέσω Java. |
| [Global](./global/) | Ο χώρος ονομάτων Global ομαδοποιεί βασικές απαριθμήσεις και βοηθητικές κλάσεις που χρησιμοποιούνται σε όλο το Aspose.BarCode για Node.js μέσω Java. |
