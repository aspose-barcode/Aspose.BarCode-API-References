## GraphicsUnit

Καθορίζει τη μονάδα μέτρησης για τα δεδομένα που δόθηκαν.

## Τιμές

| Όνομα | Περιγραφή |
| --- | --- |
| WORLD | Καθορίζει τη μονάδα του παγκόσμιου συστήματος συντεταγμένων ως μονάδα μέτρησης. |
| DISPLAY | Καθορίζει τη μονάδα μέτρησης της συσκευής εμφάνισης. Συνήθως pixels για οθόνες βίντεο και 1/100 ίντσα για εκτυπωτές. |
| PIXEL | Καθορίζει ένα pixel συσκευής ως μονάδα μέτρησης. |
| POINT | Καθορίζει το σημείο του εκτυπωτή = 1/72 ίντσα) ως μονάδα μέτρησης. |
| INCH | Καθορίζει το ίντσα ως μονάδα μέτρησης. |
| DOCUMENT | Καθορίζει τη μονάδα εγγράφου = 1/300 ίντσα) ως μονάδα μέτρησης. |
| MILLIMETER | Καθορίζει το χιλιοστόμετρο ως μονάδα μέτρησης. |
