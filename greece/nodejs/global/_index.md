Το Global namespace παρέχει μια συλλογή θεμελιωδών απαριθμήσεων και βοηθητικών τύπων που ορίζουν ιδιότητες barcode όπως λειτουργίες κωδικοποίησης, μεγέθη συμβόλων, επίπεδα εμπιστοσύνης και μορφές εικόνας. Αυτές οι ορισμοί αναφέρονται σε όλο το Aspose.BarCode API για να διαμορφώσετε και να ερμηνεύσετε τη δημιουργία και την αναγνώριση barcode.
