## EnableChecksum

Ενεργοποίηση του checksum κατά τη δημιουργία για 1D barcode. Η προεπιλογή θεωρείται Yes για τις συμβολές που πρέπει να περιέχουν checksum, και No όπου το checksum είναι μόνο δυνατό. Checksum ποτέ δεν χρησιμοποιείται: Codabar Checksum είναι δυνατό: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN Checksum πάντα χρησιμοποιείται: Οι υπόλοιπες συμβολές

## Τιμές

| Όνομα | Περιγραφή |
| --- | --- |
| DEFAULT | Εάν το checksum απαιτείται από την προδιαγραφή - θα προσαρτηθεί. |
| ΝΑΙ | Χρησιμοποιήστε πάντα το checksum εάν είναι δυνατόν. |
| ΟΧΙ | Μην χρησιμοποιείτε checksum. |
