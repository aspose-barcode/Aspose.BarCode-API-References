## SupplementParameters class

Παράμετροι συμπλήρωσης. Χρησιμοποιείται για Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

```js
new SupplementParameters()
```
