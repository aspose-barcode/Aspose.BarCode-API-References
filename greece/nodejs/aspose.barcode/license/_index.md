## License class

Παρέχει μεθόδους για την αδειοδότηση του στοιχείου.

```js
new License()
```

Αρχικοποιεί ένα νέο αντικείμενο αυτής της κλάσης.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [setLicense(licensePath)](#setlicense) | Παρέχει άδεια στο στοιχείο. |

### setLicense(licensePath) {#setlicense}

Παρέχει άδεια στο στοιχείο.

| Παράμετρος | Περιγραφή |
| --- | --- |
| licensePath | διαδρομή προς το αρχείο άδειας |
