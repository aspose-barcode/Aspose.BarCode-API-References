## CouponParameters class

Παράμετροι Coupon. Χρησιμοποιείται για UpcaGs1DatabarCoupon, UpcaGs1Code128Coupon.

```js
new CouponParameters()
```

### getSupplementSpace() {#getsupplementspace}

Διάστημα μεταξύ του κύριου BarCode και του συμπληρωματικού BarCode σε μονάδες.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementSpace() {#setsupplementspace}

Διάστημα μεταξύ του κύριου BarCode και του συμπληρωματικού BarCode σε μονάδες.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### toString() {#tostring}

Επιστρέφει μια αναγνώσιμη από άνθρωπο αναπαράσταση συμβολοσειράς αυτού του CouponParameters.

**Returns:** A string that represents this CouponParameters.
