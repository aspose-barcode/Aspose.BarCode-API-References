## Code128DataPortion class

Περιέχει τα δεδομένα του υποτύπου για barcode τύπου Code128

```js
new Code128DataPortion()
```

Δημιουργεί μια νέα παρουσία της κλάσης `Code128DataPortion` με σύμβολο κώδικα έναρξης και αποκωδικοποιημένο κείμενο κώδικα.

## Μέθοδοι

| Όνομα | Περιγραφή |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Λαμβάνει τον τύπο του υποσυνόλου Code128 |
| [getData()](#getdata) | Λαμβάνει το τμήμα του κειμένου κώδικα που σχετίζεται με τον υποτύπο. |
| [toString()](#tostring) | Επιστρέφει μια αναγνώσιμη από άνθρωπο αναπαράσταση συμβολοσειράς αυτού του `Code128DataPortion`. |

### getCode128SubType() {#getcode128subtype}

Λαμβάνει τον τύπο του υποσυνόλου Code128

**Returns:** The type of Code128 subset

### getData() {#getdata}

Λαμβάνει το τμήμα του κειμένου κώδικα που σχετίζεται με τον υποτύπο.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Επιστρέφει μια αναγνώσιμη από άνθρωπο αναπαράσταση συμβολοσειράς αυτού του `Code128DataPortion`.

**Returns:** A string that represents this `Code128DataPortion`.
