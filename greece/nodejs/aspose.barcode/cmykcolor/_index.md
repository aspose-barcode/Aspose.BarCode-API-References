## CMYKColor class

Κλάση για χρώμα CMYK. Μια null παρουσία σημαίνει ότι το CMYK δεν χρησιμοποιείται, και το προεπιλεγμένο χρώμα RGB είναι σε χρήση.

```js
new CMYKColor(c, m, y, k)
```

Αρχικοποιεί μια νέα παρουσία της κλάσης CMYKColor από τιμές CMYK. Οι τιμές CMYK αναμένονται στο εύρος 0–100.

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| c | αριθμός | – Τιμή κυανού [0, 100] |
| m | αριθμός | – Τιμή ματζέντας [0, 100] |
| y | αριθμός | – Τιμή κίτρινου [0, 100] |
| k | αριθμός | – Τιμή μαύρου [0, 100] |

### parseCMYK(str) (static) {#parsecmyk}

Αναλύει μια συμβολοσειρά CMYK της μορφής "C_M_Y_K" σε μια παρουσία CMYKColor.

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| str | string | – μια συμβολοσειρά όπως "30_100_0_30" |

**Returns:** CMYKColor

### formatCMYK() {#formatcmyk}

Διαμορφώνει αυτό το CMYKColor σε μια συμβολοσειρά "C_M_Y_K", πολλαπλασιάζοντας κάθε εσωτερικό στοιχείο (0–1) με 100 και στρογγυλοποιώντας.

**Returns:** string — e.g. "30_100_0_30"
