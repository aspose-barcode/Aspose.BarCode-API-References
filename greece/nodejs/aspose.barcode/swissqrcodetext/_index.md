## SwissQRCodetext class

Κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου που ενσωματώνεται στον κωδικό SwissQR.

```js
new SwissQRCodetext(bill)
```

Δημιουργεί μια παρουσία του SwissQRCodetext.

| Παράμετρος | Περιγραφή |
| --- | --- |
| bill | Δεδομένα λογαριασμού SwissQR |

**Throws:** BarcodeException
