## HslaColor class

Κλάση για την αναπαράσταση χρώματος HSLA (Hue, Saturation, Lightness, Alpha)

```js
new HslaColor(h, s, l, a)
```

Κατασκευαστής για HslaColor

| Παράμετρος | Περιγραφή |
| --- | --- |
| h | Απόχρωση [0, 360] |
| s | Κορεσμός [0, 100] |
| l | Φωτεινότητα [0, 100] |
| a | Άλφα (διαφάνεια) [0.0f, 1.0f] |
