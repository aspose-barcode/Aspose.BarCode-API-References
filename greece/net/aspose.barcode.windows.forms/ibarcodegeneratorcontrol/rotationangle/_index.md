## IBarCodeGeneratorControl.RotationAngle property

Γωνία περιστροφής εικόνας BarCode, μετρημένη σε μοίρες, π.χ. RotationAngle = 0 ή RotationAngle = 360 σημαίνει χωρίς περιστροφή. Εάν το RotationAngle ΔΕΝ είναι ίσο με 90, 180, 270 ή 0, μπορεί να αυξήσει τη δυσκολία για τον σαρωτή να διαβάσει την εικόνα.

```csharp
public float RotationAngle { get; set; }
```
