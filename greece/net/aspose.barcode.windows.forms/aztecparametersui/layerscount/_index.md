## AztecParametersUI.LayersCount property

Λαμβάνει ή ορίζει τον αριθμό επιπέδων του συμβόλου Aztec. Ο αριθμός επιπέδων πρέπει να βρίσκεται στο εύρος από 1 έως 3 για τη λειτουργία Compact και στο εύρος από 1 έως 32 για τη λειτουργία Full Range. Προεπιλεγμένη τιμή: 0 (auto).

```csharp
public int LayersCount { get; set; }
```
