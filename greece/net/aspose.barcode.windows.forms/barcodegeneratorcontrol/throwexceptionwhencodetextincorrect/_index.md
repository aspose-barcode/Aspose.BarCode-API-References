## BarCodeGeneratorControl.ThrowExceptionWhenCodeTextIncorrect property

Μόνο για 1D barcode. Εάν το codetext είναι λανθασμένο και η τιμή οριστεί σε true - θα προκληθεί εξαίρεση. Διαφορετικά το codetext θα διορθωθεί ώστε να ταιριάζει με τις προδιαγραφές του barcode. Η εξαίρεση πάντα θα προκληθεί για: συμβολική Databar εάν το codetext είναι λανθασμένο. Η εξαίρεση ποτέ δεν θα προκληθεί για: AustraliaPost, SingapurePost, Code39Extended, Code93Extended, Code16K, Code128 εάν το codetext είναι λανθασμένο.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
