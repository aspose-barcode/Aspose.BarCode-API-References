## BarCodeGeneratorControl.XDimension property

Το X-dimension είναι το μικρότερο πλάτος της μονάδας των ραβδών ή κενών του BarCode. Η αύξηση αυτού θα αυξήσει το συνολικό πλάτος της εικόνας barcode. Αγνοείται εάν η ιδιότητα [`AutoSizeMode`](../../../aspose.barcode.generation/autosizemode/) οριστεί σε AutoSizeMode.Nearest ή AutoSizeMode.Interpolation.

```csharp
public Unit XDimension { get; }
```
