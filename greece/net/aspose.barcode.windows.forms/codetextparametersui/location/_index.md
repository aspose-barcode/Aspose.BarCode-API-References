## CodetextParametersUI.Location property

Καθορίστε τη θέση εμφάνισης του CodeText, ορίστε το σε CodeLocation.None για απόκρυψη του CodeText. Προεπιλεγμένη τιμή: CodeLocation.Below για 1D barcode και CodeLocation.None για 2D barcode.

public CodeLocation Location { get; set; }
