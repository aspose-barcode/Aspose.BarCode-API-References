Το **BarCode.Common** περιέχει κοινές λειτουργίες και βοηθητικά εργαλεία για τη διατήρηση της κύριας λειτουργικότητας.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [GS1Element](./gs1element/) | Αντιπροσωπεύει ένα αμετάβλητο ζεύγος Αναγνωριστικού Εφαρμογής GS1 και τιμής. |
| [GS1ValidationException](./gs1validationexception/) | Η εξαίρεση που ρίχνεται από αυστηρές λειτουργίες GS1 όταν η επικύρωση αποτυγχάνει. |
| [GS1ValidationIssue](./gs1validationissue/) | Περιγράφει ένα σφάλμα επικύρωσης GS1. |
| [GS1ValidationResult](./gs1validationresult/) | Περιέχει όλα τα ανεξάρτητα ανιχνεύσιμα σφάλματα για μια συμβολοσειρά στοιχείου GS1, URI Digital Link ή μια τιμή AI. |
| [ProcessorSettings](./processorsettings/) | Το ProcessorSettings επιτρέπει την αναγνώριση barcode με πολυνηματική βελτίωση της απόδοσης. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [GS1ValidationErrorCode](./gs1validationerrorcode/) | Αναγνωρίζει μια συμβολοσειρά στοιχείου GS1, URI Digital Link ή σφάλμα επικύρωσης τιμής. |
