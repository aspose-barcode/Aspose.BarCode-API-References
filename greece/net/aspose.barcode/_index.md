Το **Aspose.BarCode** περιέχει εργαλεία για τη δημιουργία και σχεδίαση γραμμωτών κωδίκων 1D/2D.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [BarCodeException](./barcodeexception/) | Αναπαριστά την εξαίρεση για τη δημιουργία εικόνας barcode. |
| [BuildVersionInfo](./buildversioninfo/) | Περιέχει τις τρέχουσες πληροφορίες έκδοσης της κατασκευής. |
| [InvalidCodeException](./invalidcodeexception/) | Η Exception θα εξαχθεί όταν περιέχονται μη έγκυροι χαρακτήρες στο κείμενο κώδικα. |
| [License](./license/) | Παρέχει μεθόδους για την άδεια του στοιχείου. |
| [Metered](./metered/) | Παρέχει μεθόδους για τον ορισμό του μετρημένου κλειδιού. |
| [XmlSerializationAttribute](./xmlserializationattribute/) | Αναπαριστά το χαρακτηριστικό για τον δημιουργό οντοτήτων xml. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [CustomerInformationInterpretingType](./customerinformationinterpretingtype/) | Ορίζει τον τύπο ερμηνείας (CTable, NTable ή Other) των πληροφοριών πελάτη για το AustralianPost BarCode. |
| [XmlSerializationType](./xmlserializationtype/) | Αναπαριστά τον τύπο της σειριοποίησης xml. |
