## BarcodeParameters.IsChecksumEnabled property

Ενεργοποίηση ελέγχου αθροίσματος κατά τη δημιουργία 1D barcodes.

Η προεπιλογή θεωρείται Yes για τη συμβολική γραφή που πρέπει να περιέχει checksum, όπως No όπου το checksum είναι μόνο δυνατόν.

Το checksum είναι δυνατό: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN, Codabar

Το checksum χρησιμοποιείται πάντα: Υπόλοιπες συμβολικές γραφές

```csharp
public EnableChecksum IsChecksumEnabled { get; set; }
```
