## BarcodeParameters.XDimension property

Το x-dimension είναι το μικρότερο πλάτος της μονάδας των γραμμών ή κενών του BarCode. Η αύξηση αυτής θα αυξήσει το συνολικό πλάτος της εικόνας του barcode. Αγνοείται εάν η ιδιότητα [`AutoSizeMode`](../../basegenerationparameters/autosizemode/) οριστεί σε AutoSizeMode.Nearest ή AutoSizeMode.Interpolation.

```csharp
public Unit XDimension { get; set; }
```
