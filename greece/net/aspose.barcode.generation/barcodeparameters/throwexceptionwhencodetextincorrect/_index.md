## BarcodeParameters.ThrowExceptionWhenCodeTextIncorrect property

Μόνο για 1D barcode. Εάν το codetext είναι εσφαλμένο και η τιμή οριστεί σε true - θα εξαχθεί εξαίρεση. Διαφορετικά το codetext θα διορθωθεί ώστε να ταιριάζει με τις προδιαγραφές του barcode. Η εξαίρεση θα εξαχθεί πάντα για: σύμβολο Databar εάν το codetext είναι εσφαλμένο. Η εξαίρεση δεν θα εξαχθεί ποτέ για: AustraliaPost, SingapurePost, Code39FullASCII, Code93, Code16K, Code128 εάν το codetext είναι εσφαλμένο.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
