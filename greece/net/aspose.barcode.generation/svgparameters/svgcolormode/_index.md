## SvgParameters.SvgColorMode property

Πιθανές λειτουργίες για γέμισμα χρώματος σε αρχείο svg, το RGB είναι προεπιλογή και υποστηρίζεται από SVG 1.1. Τα RGBA, HSL, HSLA επιτρέπονται στο πρότυπο SVG 2.0. Ακόμη και στο RGB η αδιαφάνεια ορίζεται μέσω της παραμέτρου "fill-opacity"

```csharp
public SvgColorMode SvgColorMode { get; set; }
```
