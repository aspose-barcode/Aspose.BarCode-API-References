## DotCodeParameters.StructuredAppendModeBarcodeId property

Καθορίζει το ID του κώδικα barcode λειτουργίας δομημένης προσθήκης DotCode. Το ID ξεκινά από 1 και πρέπει να είναι μικρότερο ή ίσο με τον αριθμό των barcode. Προεπιλεγμένη τιμή είναι -1.

public int StructuredAppendModeBarcodeId { get; set; }
