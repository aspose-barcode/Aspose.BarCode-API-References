## CodabarParameters.ChecksumMode property

Λάβετε ή ορίστε τον αλγόριθμο ελέγχου αθροίσματος για τους κωδικούς Codabar. Προεπιλεγμένη τιμή: CodabarChecksumMode.Mod16. Για να ενεργοποιήσετε τον υπολογισμό ελέγχου αθροίσματος ορίστε την τιμή EnableChecksum.Yes στην ιδιότητα EnableChecksum. Δείτε `ChecksumMode`.

```csharp
public CodabarChecksumMode ChecksumMode { get; set; }
```
