## EncodeTypes.TryParse method

Μετατρέπει την αναπαράσταση συμβολοσειράς ενός BaseEncodeType στην παρουσία του. Μια τιμή επιστροφής υποδεικνύει εάν η μετατροπή πέτυχε ή απέτυχε.

```csharp
public static bool TryParse(string parsingType, out BaseEncodeType result)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| parsingType | String | Μια συμβολοσειρά στη μορφή "Index:-1; Name:None" για μετατροπή. |
| αποτέλεσμα | BaseEncodeType& | Ένα πραγματικό SingleEncodeType επιστρέφει, όταν η μετατροπή ολοκληρωθεί επιτυχώς; |

### Τιμή Επιστροφής

**true** if s was converted successfully; otherwise, **false**.
