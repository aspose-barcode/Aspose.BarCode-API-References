## DataMatrixParameters.MacroCharacters property

Οι τιμές Macro Characters 05 και 06 χρησιμοποιούνται για την απόκτηση πιο συμπαγούς κωδικοποίησης σε ειδικές λειτουργίες. Μπορεί να χρησιμοποιηθεί μόνο με DataMatrixEccType.Ecc200 ή DataMatrixEccType.EccAuto. Δεν μπορεί να χρησιμοποιηθεί με EncodeTypes.GS1DataMatrix Προεπιλεγμένη τιμή: MacroCharacters.None.

```csharp
public MacroCharacter MacroCharacters { get; set; }
```
