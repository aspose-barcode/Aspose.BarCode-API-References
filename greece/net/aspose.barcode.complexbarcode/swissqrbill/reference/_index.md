## SwissQRBill.Reference property

Λαμβάνει ή ορίζει την αναφορά πληρωμής του πιστωτή.

Η αναφορά είναι υποχρεωτική για τα SwissQR IBAN, δηλαδή IBAN στην περιοχή CHxx30000xxxxxx έως CHxx31999xxxxx.

Εάν καθοριστεί, η αναφορά πρέπει να είναι είτε μια έγκυρη αναφορά SwissQR (σύμφωνη με τη φόρμα αναφοράς ISR) είτε μια έγκυρη αναφορά πιστωτή σύμφωνα με το ISO 11649 ("RFxxxx"). Και οι δύο μπορεί να περιέχουν κενά για μορφοποίηση.

```csharp
public string Reference { get; set; }
```

### Property Value

Η αναφορά πληρωμής του πιστωτή.
