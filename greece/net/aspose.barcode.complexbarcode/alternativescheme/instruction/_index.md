## AlternativeScheme.Instruction property

Λαμβάνει την οδηγία πληρωμής για ένα συγκεκριμένο λογαριασμό.

Η οδηγία αποτελείται από μια συντομογραφία δύο γραμμάτων για το σχήμα, χαρακτήρες διαχωρισμού και μια ακολουθία παραμέτρων (διαχωρισμένες με τον χαρακτήρα στη θέση 2).

```csharp
public string Instruction { get; set; }
```

### Property Value

Η οδηγία πληρωμής.
