## Address.AddressLine1 property

Ανακτά ή ορίζει τη γραμμή διεύθυνσης 1.

Η γραμμή διεύθυνσης 1 περιέχει το όνομα του δρόμου, τον αριθμό σπιτιού ή το ταχυδρομικό γραμματοκιβώτιο.

Ορίζοντας αυτό το πεδίο θέτει τον τύπο διεύθυνσης σε CombinedElements εκτός εάν είναι ήδη Structured, οπότε γίνεται Conflicting.

Αυτό το πεδίο χρησιμοποιείται μόνο για διευθύνσεις συνδυασμένων στοιχείων και είναι προαιρετικό.

```csharp
public string AddressLine1 { get; set; }
```

### Property Value

Η γραμμή διεύθυνσης 1.
