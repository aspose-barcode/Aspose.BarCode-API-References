## Address.Type property

Ανακτά τον τύπο διεύθυνσης.

Ο τύπος διεύθυνσης ορίζεται αυτόματα είτε με τον ορισμό του δρόμου / αριθμού σπιτιού είτε με τις γραμμές διεύθυνσης 1 και 2. Πριν οριστούν τα πεδία, ο τύπος διεύθυνσης είναι Undetermined. Εάν οριστούν πεδία και των δύο τύπων, ο τύπος διεύθυνσης γίνεται Conflicting.

```csharp
public AddressType Type { get; }
```

### Property Value

Ο τύπος διεύθυνσης.
