## Address.AddressLine2 property

Ανακτά ή ορίζει τη γραμμή διεύθυνσης 2.

Address line 2 περιέχει τον ταχυδρομικό κώδικα και την πόλη.

Ορίζοντας αυτό το πεδίο θέτει τον τύπο διεύθυνσης σε CombinedElements εκτός εάν είναι ήδη Structured, οπότε γίνεται Conflicting.

Αυτό το πεδίο χρησιμοποιείται μόνο για διευθύνσεις συνδυασμένων στοιχείων. Για αυτόν τον τύπο, είναι υποχρεωτικό.

```csharp
public string AddressLine2 { get; set; }
```
