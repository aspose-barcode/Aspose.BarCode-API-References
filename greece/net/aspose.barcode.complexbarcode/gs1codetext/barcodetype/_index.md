## GS1Codetext.BarcodeType property

Λαμβάνει ή ορίζει τον τύπο barcode που χρησιμοποιείται για την κωδικοποίηση αυτού του GS1 codetext. Οι υποστηριζόμενοι τύποι είναι GS1Aztec, GS1CodablockF, GS1Code128, GS1DataMatrix, GS1DotCode, GS1HanXin, GS1MicroPdf417, GS1QR και τύποι GS1 DataBar. Η προεπιλεγμένη τιμή είναι GS1Code128.

```csharp
public BaseEncodeType BarcodeType { get; set; }
```
