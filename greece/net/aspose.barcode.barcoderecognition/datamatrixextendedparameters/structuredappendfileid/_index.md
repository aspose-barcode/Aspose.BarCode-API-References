## DataMatrixExtendedParameters.StructuredAppendFileId property

Λαμβάνει το ID του barcode DataMatrix σε λειτουργία structured append. Το ID ξεκινά από 1 και πρέπει να είναι μικρότερο ή ίσο με τον αριθμό των barcode. Η προεπιλεγμένη τιμή είναι -1.

```csharp
public int StructuredAppendFileId { get; }
```

### Property Value

Το ID του barcode σε λειτουργία δομημένης προσθήκης DataMatrix.
