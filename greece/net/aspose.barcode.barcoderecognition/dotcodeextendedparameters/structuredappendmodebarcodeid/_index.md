## DotCodeExtendedParameters.StructuredAppendModeBarcodeId property

Λαμβάνει το ID του barcode σε λειτουργία δομημένης προσθήκης DotCode. Το ID ξεκινά από 1 και πρέπει να είναι μικρότερο ή ίσο με τον αριθμό των barcode. Η προεπιλεγμένη τιμή είναι -1.

```csharp
public int StructuredAppendModeBarcodeId { get; }
```

### Property Value

Το ID του barcode λειτουργίας δομημένης προσθήκης DotCode.
