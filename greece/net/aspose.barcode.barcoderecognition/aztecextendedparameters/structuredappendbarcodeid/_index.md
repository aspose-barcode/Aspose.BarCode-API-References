## AztecExtendedParameters.StructuredAppendBarcodeId property

Λαμβάνει το ID του barcode σε λειτουργία δομημένης προσθήκης Aztec. Το ID ξεκινά από 1 και πρέπει να είναι μικρότερο ή ίσο με τον αριθμό των barcode. Η προεπιλεγμένη τιμή είναι 0.

```csharp
public int StructuredAppendBarcodeId { get; }
```

### Property Value

Το ID του barcode σε λειτουργία προσάρτησης δομημένου Aztec.
