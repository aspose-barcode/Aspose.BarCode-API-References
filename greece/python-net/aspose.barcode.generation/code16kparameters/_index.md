## Code16KParameters class

Παράμετροι Code16K.

Ο τύπος Code16KParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| aspect_ratio | Αναλογία ύψους/πλάτους του μονάδας 2D BarCode. |
| quiet_zone_left_coef | Μέγεθος της αριστερής ζώνης ησυχίας σε xDimension.<br/>            Προεπιλεγμένη τιμή: 10, που σημαίνει ότι αν xDimension = 2px, η αριστερή ζώνη ησυχίας θα είναι 20px. |
| quiet_zone_right_coef | Μέγεθος της δεξιάς ζώνης ησυχίας σε xDimension.<br/>            Προεπιλεγμένη τιμή: 1, που σημαίνει ότι αν xDimension = 2px, η δεξιά ζώνη ησυχίας θα είναι 2px. |
