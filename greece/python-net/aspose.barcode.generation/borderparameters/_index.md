## BorderParameters class

Παράμετροι περιγράμματος εικόνας barcode

Ο τύπος BorderParameters εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| visible | Ορατότητα περιγράμματος. Εάν είναι false, τότε η παράμετρος Width αγνοείται πάντα (0).<br/>            Προεπιλεγμένη τιμή: false. |
| width | Πλάτος περιγράμματος.<br/>            Προεπιλεγμένη τιμή: 0.<br/>            Αγνοείται εάν Visible είναι ορισμένο σε false. |
| dash_style | Στυλ παύλας περιγράμματος.<br/>            Προεπιλεγμένη τιμή: BorderDashStyle.Solid. |
| color | Χρώμα περιγράμματος.<br/>            Προεπιλεγμένη τιμή: Color.Black. |
