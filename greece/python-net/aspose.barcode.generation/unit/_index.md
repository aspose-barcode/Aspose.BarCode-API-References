## Unit class

Καθορίζει την τιμή μεγέθους σε διαφορετικές μονάδες (Pixel, Inches κ.λπ.).

Ο τύπος Unit εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| pixel | Λαμβάνει ή ορίζει την τιμή του μεγέθους σε pixel. |
| ίντσες | Λαμβάνει ή ορίζει την τιμή του μεγέθους σε ίντσες. |
| χιλιοστά | Λαμβάνει ή ορίζει την τιμή του μεγέθους σε χιλιοστά. |
| σημείο | Λαμβάνει ή ορίζει την τιμή του μεγέθους σε σημείο. |
| έγγραφο | Λαμβάνει ή ορίζει την τιμή του μεγέθους σε μονάδες εγγράφου. |
| ανάλυση | Ανάλυση |
