## ITFParameters class

Παράμετροι ITF.

border_thickness
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| πάχος_περιγράμματος | Λαμβάνει ή ορίζει το πάχος του περιγράμματος ITF (γραμμή φορέα) σε τιμή Μονάδας.<br/>            Προεπιλεγμένη τιμή: 12pt. |
| border_type | Τύπος περιγράμματος του κώδικα ITF.<br/>            Προεπιλεγμένη τιμή: ITF14BorderType.Bar. |
| quiet_zone_coef | Μέγεθος των ήσυχων ζωνών στο xDimension.<br/>            Προεπιλεγμένη τιμή: 10, που σημαίνει ότι αν xDimension = 2px τότε οι ήσυχες ζώνες θα είναι 20px. |
