## SymbologyEncodeType class

Τύπος κωδικοποίησης συμβολισμού. Δείτε EncodeTypes για να λάβετε την παρουσία.

Ο τύπος SymbologyEncodeType εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| type_index | Λαμβάνει έναν δείκτη τύπου κωδικοποίησης |
| type_name | Λαμβάνει ένα όνομα τύπου κωδικοποίησης |
| classification | Λαμβάνει μια ταξινόμηση αυτής της συμβολής. |
