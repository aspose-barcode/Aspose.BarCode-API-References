## CodabarParameters class

Παράμετροι Codabar.

Ο τύπος CodabarParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| checksum_mode | Αποκτήστε ή ορίστε τον αλγόριθμο ελέγχου αθροίσματος για τους κώδικες γραμμής Codabar.<br/>            Προεπιλεγμένη τιμή: CodabarChecksumMode.Mod16.<br/>            Για να ενεργοποιήσετε τον υπολογισμό ελέγχου αθροίσματος, ορίστε την τιμή EnableChecksum.Yes στην ιδιότητα EnableChecksum.<br/>            Δείτε [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Σύμβολο έναρξης (χαρακτήρας) της συμβολιστικής Codabar.<br/>            Προεπιλεγμένη τιμή: CodabarSymbol.A |
| stop_symbol | Σύμβολο λήξης (χαρακτήρας) της συμβολιστικής Codabar.<br/>            Προεπιλεγμένη τιμή: CodabarSymbol.A |
