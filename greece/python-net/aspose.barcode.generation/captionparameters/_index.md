## CaptionParameters class

Παράμετροι λεζάντας.

Ο τύπος CaptionParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| text | Κείμενο λεζάντας.<br/>            Προεπιλεγμένη τιμή: κενή συμβολοσειρά. |
| font | Γραμματοσειρά λεζάντας.<br/>            Προεπιλεγμένη τιμή: Arial 8pt regular. |
| visible | Ορατότητα κειμένου λεζάντας.<br/>            Προεπιλεγμένη τιμή: false. |
| text_color | Χρώμα κειμένου λεζάντας.<br/>            Προεπιλεγμένη τιμή: Color.Black. |
| padding | Περιθώρια λεζάντας.<br/>            Προεπιλεγμένη τιμή για CaptionAbove: 5pt 5pt 0 5pt.<br/>            Προεπιλεγμένη τιμή για CaptionBelow: 0 5pt 5pt 5pt. |
| alignment | Οριζόντια στοίχιση κειμένου λεζάντας.<br/>            Προεπιλεγμένη τιμή: StringAlignment.Center. |
| no_wrap | Καθορίστε την αναδίπλωση λέξεων (αλλαγές γραμμής) μέσα στο κείμενο.<br/>            Προεπιλεγμένη τιμή: false. |
