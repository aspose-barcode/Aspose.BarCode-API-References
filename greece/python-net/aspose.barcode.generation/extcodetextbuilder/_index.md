## ExtCodetextBuilder class

Βοηθητική κλάση για αυτόματη δημιουργία codetext στη λειτουργία Extended Codetext Mode

Ο τύπος ExtCodetextBuilder εκθέτει τα παρακάτω μέλη:
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| clear() | Καθαρίζει τα στοιχεία εκτεταμένου κώδικα κειμένου |
| add_plain_codetext(codetext) | Προσθέτει απλό κείμενο κώδικα στα στοιχεία εκτεταμένου κώδικα κειμένου |
| add_eci_codetext(eci_encoding, codetext) | Προσθέτει κείμενο κώδικα με Αναγνωριστικό Εκτεταμένου Καναλιού |
| get_extended_codetext() | Δημιουργία εκτεταμένου κειμένου κώδικα από τη λίστα στοιχείων δημιουργίας |
