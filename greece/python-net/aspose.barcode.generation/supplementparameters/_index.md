## SupplementParameters class

Παράμετροι συμπληρώματος. Χρησιμοποιείται για Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

Ο τύπος SupplementParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| supplement_data | Συμπληρωματικά δεδομένα μετά το BarCode. |
| supplement_space | Διάστημα μεταξύ του κύριου BarCode και του συμπληρωματικού BarCode σε τιμή [Unit](/barcode/python-net/aspose.barcode.generation/unit/). |
