## PdfParameters class

Παράμετροι PDF.

Ο τύπος PdfParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| cmyk_bar_color | Προαιρετικό. Τιμή χρώματος CMYK του barcode. Null σημαίνει ότι το χρώμα CMYK δεν χρησιμοποιείται, αντίθετα χρησιμοποιείται το κανονικό χρώμα RGB. |
| cmyk_back_color | Προαιρετικό. Τιμή χρώματος CMYK φόντου. Null σημαίνει ότι το χρώμα CMYK δεν χρησιμοποιείται, αντίθετα χρησιμοποιείται το κανονικό χρώμα RGB. |
| cmyk_codetext_color | Προαιρετικό. Τιμή χρώματος CMYK του Codetext. Null σημαίνει ότι το χρώμα CMYK δεν χρησιμοποιείται, αντίθετα χρησιμοποιείται το κανονικό χρώμα RGB. |
| cmyk_caption_above_color | Προαιρετικό. Τιμή χρώματος CMYK της λεζάντας πάνω. Null σημαίνει ότι το χρώμα CMYK δεν χρησιμοποιείται, αντίθετα χρησιμοποιείται το κανονικό χρώμα RGB. |
| cmyk_caption_below_color | Προαιρετικό. Τιμή χρώματος CMYK της λεζάντας κάτω. Null σημαίνει ότι το χρώμα CMYK δεν χρησιμοποιείται, αντίθετα χρησιμοποιείται το κανονικό χρώμα RGB. |
| is_text_as_path | Χρησιμοποιούνται διαδρομές αντί για κείμενο (χρησιμοποιήστε εάν οι χαρακτήρες Unicode δεν εμφανίζονται)<br/>            Προεπιλεγμένη τιμή: false. |
