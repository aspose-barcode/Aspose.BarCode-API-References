## BarCodeImageFormat enumeration

Καθορίζει τη μορφή αρχείου της εικόνας.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| BMP | Καθορίζει τη μορφή εικόνας bitmap (BMP). |
| GIF | Καθορίζει τη μορφή εικόνας Graphics Interchange Format (GIF). |
| JPEG | Καθορίζει τη μορφή εικόνας Joint Photographic Experts Group (JPEG). |
| PNG | Καθορίζει τη μορφή εικόνας W3C Portable Network Graphics (PNG). |
| TIFF | Καθορίζει τη μορφή εικόνας Tagged Image File Format (TIFF). |
| TIFF_IN_CMYK | Καθορίζει τη μορφή εικόνας Tagged Image File Format (TIFF) σε χρωματικό μοντέλο CMYK. <br/>            (Υποστηρίζεται μόνο στην πλατφόρμα Windows, σε πλατφόρμες *nix αποθηκεύεται ως Tiff) |
| EMF | Καθορίζει τη μορφή εικόνας Enhanced Metafile (EMF).<br/>            (Υποστηρίζεται μόνο στην πλατφόρμα Windows, σε πλατφόρμες *nix αποθηκεύεται ως PNG) |
| SVG | Καθορίζει τη μορφή εικόνας Scalable Vector Graphics (SVG). |
| PDF | Καθορίζει τη μορφή εικόνας Portable Document Format (PDF). |
