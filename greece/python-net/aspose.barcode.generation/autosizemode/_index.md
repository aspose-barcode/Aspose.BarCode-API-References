## AutoSizeMode enumeration

Καθορίζει τους διαφορετικούς τύπους αυτόματων λειτουργιών μεγέθυνσης.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NONE | Η αυτόματη αλλαγή μεγέθους είναι απενεργοποιημένη. |
| NEAREST | Αλλάζει το μέγεθος του barcode στο πλησιέστερο χαμηλότερο δυνατό μέγεθος που καθορίζεται από τις ιδιότητες ImageWidth και ImageHeight.<br/>            Διατηρεί την προεπιλεγμένη αναλογία διαστάσεων. |
| INTERPOLATION | Αλλάζει το μέγεθος του barcode στο καθορισμένο μέγεθος.<br/>            Το μέγεθος μπορεί να καθοριστεί από τις ιδιότητες ImageWidth και ImageHeight.<br/>            Ο παραγόμενος barcode μπορεί να είναι μη έγκυρος (μη αναγνώσιμος) μετά την κλιμάκωση. |
