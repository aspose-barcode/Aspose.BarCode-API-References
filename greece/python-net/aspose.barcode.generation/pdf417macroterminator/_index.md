## Pdf417MacroTerminator enumeration

Χρησιμοποιείται για να ενημερώσει τον κωδικοποιητή αν θα προσθέσει τον Τερματικό Macro PDF417 (κωδικός 922) στο τμήμα. <br/>            Εφαρμόζεται μόνο για Macro PDF417.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| AUTO | Ο τερματιστής θα προστεθεί αυτόματα εάν παρέχεται ο αριθμός των τμημάτων <br/>            και το τρέχον τμήμα είναι το τελευταίο. Σε άλλες περιπτώσεις, ο τερματιστής δεν θα προστεθεί. |
| NONE | Ο τερματιστής δεν θα προστεθεί. |
| SET | Ο τερματιστής θα προστεθεί. |
