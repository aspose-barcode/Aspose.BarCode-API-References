## SvgColorMode enumeration

Πιθανές λειτουργίες για το γέμισμα χρώματος σε αρχείο svg, το RGB είναι προεπιλογή και υποστηρίζεται από SVG 1.1.<br/>            Το RGBA, HSL, HSLA επιτρέπονται στο πρότυπο SVG 2.0.<br/>            Ακόμη και στο RGB η αδιαφάνεια θα ορίζεται μέσω της παραμέτρου "fill-opacity"

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| RGB | Λειτουργία RGB, παράδειγμα: fill=\"#ff5511\" fill-opacity=\"0.73\". Προεπιλεγμένη λειτουργία. |
| RGBA | Λειτουργία RGBA, παράδειγμα: fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | Λειτουργία HSL, παράδειγμα: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | Λειτουργία HSLA, παράδειγμα: fill=\"hsla(30, 50%, 70%, 0.8)\" |
