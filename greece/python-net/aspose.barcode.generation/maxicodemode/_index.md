## MaxiCodeMode enumeration

Λειτουργία κωδικοποίησης για γραμμωτού κώδικα MaxiCode.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| MODE2 | Mode 2 κωδικοποιεί τις ταχυδρομικές πληροφορίες στο πρώτο μήνυμα και τα δεδομένα στο δεύτερο μήνυμα. <br/>            Έχει ταχυδρομικό κώδικα 9 ψηφίων (χρησιμοποιείται μόνο στις ΗΠΑ). |
| MODE3 | Λειτουργία 3 κωδικοποιεί πληροφορίες ταχυδρομείου στο πρώτο μήνυμα και δεδομένα στο δεύτερο μήνυμα. <br/>            Διαθέτει 6 αλφαριθμητικό ταχυδρομικό κώδικα, που χρησιμοποιείται παγκοσμίως. |
