## MaxiCodeParameters class

Παράμετροι MaxiCode.

Ο τύπος MaxiCodeParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| mode | Λαμβάνει ή ορίζει τη λειτουργία κωδικοποίησης MaxiCode. |
| encode_mode | Λαμβάνει ή ορίζει λειτουργία κωδικοποίησης MaxiCode. <br/>            Προεπιλεγμένη τιμή: Auto. |
| eci_encoding | Λαμβάνει ή ορίζει κωδικοποίηση ECI. Χρησιμοποιείται όταν η MaxiCodeEncodeMode είναι Auto.<br/>            Προεπιλεγμένη τιμή: ISO-8859-1 |
| structured_append_mode_barcode_id | Λαμβάνει ή ορίζει το αναγνωριστικό barcode του MaxiCode σε λειτουργία δομημένης προσάρτησης. <br/>            Το ID πρέπει να είναι τιμή μεταξύ 1 και 8. <br/>            Προεπιλεγμένη τιμή: 0 |
| structured_append_mode_barcodes_count | Λαμβάνει ή ορίζει τον αριθμό των barcode του MaxiCode σε λειτουργία δομημένης προσάρτησης. <br/>            Ο αριθμός πρέπει να είναι τιμή μεταξύ 2 και 8 (μέγιστος αριθμός barcode).<br/>            Προεπιλεγμένη τιμή: -1 |
| aspect_ratio | Αναλογία ύψους/πλάτους του μονάδας 2D BarCode. |
