## FontUnit class

Ορίζει μια συγκεκριμένη μορφή κειμένου, συμπεριλαμβανομένης της γραμματοσειράς, του μεγέθους και των χαρακτηριστικών στυλ<br/>            όπου το μέγεθος είναι στην ιδιότητα Unit value.

Ο τύπος FontUnit εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| family_name | Αποκτά ή ορίζει το όνομα γραμματοσειράς αυτού του Font. |
| style | Αποκτά ή ορίζει πληροφορίες στυλ για αυτό το FontUnit. |
| size | Αποκτά ή ορίζει το μέγεθος αυτού του FontUnit σε τιμή Unit. |
