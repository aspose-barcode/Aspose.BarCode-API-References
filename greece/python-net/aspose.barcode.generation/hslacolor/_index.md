## HslaColor class

Κλάση για την αναπαράσταση χρώματος HSLA (Hue, Saturation, Lightness, Alpha)

Ο τύπος HslaColor εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| HslaColor(h, s, l, a) | Αρχικοποιεί μια νέα παρουσία της κλάσης HslaColor |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| H | Απόχρωση [0, 360] |
| S | Κορεσμός [0, 100] |
| L | Φωτεινότητα [0, 100] |
| a | Άλφα (διαφάνεια) [0.0f, 1.0f] |
