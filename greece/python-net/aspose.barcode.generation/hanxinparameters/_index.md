## HanXinParameters class

Παράμετροι Han Xin.

Ο τύπος HanXinParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| version | Έκδοση του κώδικα HanXin.<br/>            Από Version01 έως Version84 για κώδικα Han Xin.<br/>            Η προεπιλεγμένη τιμή είναι Version.Auto. |
| error_level | Επίπεδο διόρθωσης σφαλμάτων Reed-Solomon για το barcode Han Xin.<br/>             Από χαμηλό έως υψηλό: L1, L2, L3, L4. δείτε ErrorLevel. |
| encode_mode | Λειτουργία κωδικοποίησης HanXin.<br/>            Προεπιλεγμένη τιμή: EncodeMode.Mixed. |
| eci_encoding | Αναγνωριστικά Επεκταμένης Ερμηνείας Καναλιού. Χρησιμοποιείται για να ενημερώσει τον αναγνώστη barcode λεπτομέρειες<br/>            σχετικά με τις χρησιμοποιημένες αναφορές για την κωδικοποίηση των δεδομένων στο σύμβολο.<br/>            Η τρέχουσα υλοποίηση περιλαμβάνει όλες τις γνωστές κωδικοποιήσεις συνόλων χαρακτήρων. |
