## SvgParameters class

Παράμετροι SVG.

Ο τύπος SvgParameters εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_explicit_size_in_pixels | Η εικόνα SVG περιέχει ρητό μέγεθος σε εικονοστοιχεία (συνιστάται)<br/>            Προεπιλεγμένη τιμή: true. |
| is_text_drawn_in_text_element | Η εικόνα SVG περιέχει κείμενο ως στοιχείο κειμένου αντί για μονοπάτια (συνιστάται)<br/>            Προεπιλεγμένη τιμή: true. |
| svg_color_mode | Πιθανές λειτουργίες για το γέμισμα χρώματος σε αρχείο svg, το RGB είναι προεπιλογή και υποστηρίζεται από SVG 1.1.<br/>            Το RGBA, HSL, HSLA επιτρέπονται στο πρότυπο SVG 2.0.<br/>            Ακόμη και στο RGB η αδιαφάνεια θα ορίζεται μέσω της παραμέτρου "fill-opacity" |
