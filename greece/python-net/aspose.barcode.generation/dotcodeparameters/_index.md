## DotCodeParameters class

Παράμετροι DotCode.

Ο τύπος DotCodeParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| aspect_ratio | Αναλογία ύψους/πλάτους του μονάδας 2D BarCode. |
| encode_mode | Καθορίζει τη λειτουργία κωδικοποίησης DotCode. <br/>            Προεπιλεγμένη τιμή: Auto. |
| is_reader_initialization | Δείχνει εάν ο κώδικας χρησιμοποιείται για να υποδείξει στον αναγνώστη να ερμηνεύσει τα παρακάτω δεδομένα ως οδηγίες για την εκκίνηση ή την επαναπρογραμματισμό του αναγνώστη barcode.<br/>            Η προεπιλεγμένη τιμή είναι false. |
| structured_append_mode_barcode_id | Καθορίζει το ID του barcode λειτουργίας δομημένης προσθήκης DotCode. Το ID ξεκινά από 1 και πρέπει να είναι μικρότερο ή ίσο με τον αριθμό των barcode. Η προεπιλεγμένη τιμή είναι -1. |
| structured_append_mode_barcodes_count | Καθορίζει τον αριθμό των barcode λειτουργίας δομημένης προσθήκης DotCode. Η προεπιλεγμένη τιμή είναι -1. Ο αριθμός πρέπει να είναι τιμή από 1 έως 35. |
| eci_encoding | Καθορίζει την κωδικοποίηση ECI. Χρησιμοποιείται όταν το DotCodeEncodeMode είναι Auto.<br/>            Προεπιλεγμένη τιμή: ISO-8859-1 |
| γραμμές | Καθορίζει τον αριθμό των σειρών. Το άθροισμα του αριθμού των σειρών και των στηλών ενός συμβόλου DotCode πρέπει να είναι περιττό. Ο αριθμός των σειρών πρέπει να είναι τουλάχιστον 5.<br/>            Προεπιλεγμένη τιμή: -1 |
| στήλες | Καθορίζει τον αριθμό των στηλών. Το άθροισμα του αριθμού των σειρών και των στηλών ενός συμβόλου DotCode πρέπει να είναι περιττό. Ο αριθμός των στηλών πρέπει να είναι τουλάχιστον 5.<br/>            Προεπιλεγμένη τιμή: -1 |
