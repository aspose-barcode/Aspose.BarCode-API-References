## DataBarParameters class

Παράμετροι Databar.

Ο τύπος DataBarParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_2d_composite_component | Ενεργοποιεί τη σημαία του σύνθετου στοιχείου 2D με το barcode DataBar |
| allow_only_gs1_encoding | Εάν αυτή η σημαία είναι ορισμένη, επιτρέπει μόνο το πρότυπο κωδικοποίησης GS1 για τύπους barcode Databar |
| στήλες | Αριθμός στηλών. |
| γραμμές | Αριθμός γραμμών. |
| aspect_ratio | Λόγος ύψους/πλάτους του μονάδας 2D BarCode.<br/>            Χρησιμοποιείται για DataBar stacked. |
