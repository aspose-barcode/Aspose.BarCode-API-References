## QrParameters class

Παράμετροι QR.

Ο τύπος QrParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| eci_encoding | Αναγνωριστικά Επεκταμένης Ερμηνείας Καναλιού. Χρησιμοποιείται για να παρέχει στον αναγνώστη barcode λεπτομέρειες<br/>            σχετικά με τις χρησιμοποιημένες αναφορές για την κωδικοποίηση των δεδομένων στο σύμβολο.<br/>            Η τρέχουσα υλοποίηση περιλαμβάνει όλες τις γνωστές κωδικοποιήσεις συνόλων χαρακτήρων.<br/>            Δεν υποστηρίζεται από το MicroQR. |
| encode_mode | Τύπος συμβολισμού QR της λειτουργίας κωδικοποίησης του BarCode.<br/>            Προεπιλεγμένη τιμή: QREncodeMode.Auto. |
| error_level | Επίπεδο διόρθωσης σφαλμάτων Reed-Solomon για τα barcode QR, MicroQR και RectMicroQR.<br/>             Από χαμηλό προς υψηλό: LevelL, LevelM, LevelQ, LevelH. Δείτε το QRErrorLevel. |
| version | Έκδοση του QR Code. Από Version1 έως Version40.<br/>            Η προεπιλεγμένη τιμή είναι QRVersion.Auto. |
| micro_qr_version | Έκδοση του MicroQR Code. Από την έκδοση M1 έως την έκδοση M4.<br/>            Η προεπιλεγμένη τιμή είναι MicroQRVersion.Auto. |
| rect_micro_qr_version | Έκδοση του RectMicroQR Code. Από την έκδοση R7x59 έως την έκδοση R17x139.<br/>            Η προεπιλεγμένη τιμή είναι RectMicroQRVersion.Auto. |
| aspect_ratio | Αναλογία ύψους/πλάτους του μονάδας 2D BarCode. |
| structured_append | Παράμετροι δομημένης προσθήκης QR.<br/>            Η λειτουργία δομημένης προσθήκης δεν υποστηρίζεται από τα barcode MicroQR και RectMicroQR. |
| encode_gs1_separator_in_byte_mode |  |
