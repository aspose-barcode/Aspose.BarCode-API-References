## PatchCodeParameters class

Παράμετροι PatchCode.

Ο τύπος PatchCodeParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| extra_barcode_text | Καθορίζει το κείμενο κώδικα για ένα επιπλέον QR barcode, όταν το PatchCode δημιουργείται σε λειτουργία σελίδας. |
| format | Μορφή PatchCode. Επιλέξτε PatchOnly για να δημιουργήσετε ένα μόνο PatchCode. Χρησιμοποιήστε τη μορφή σελίδας για να δημιουργήσετε μια σελίδα Patch με PatchCodes ως περιθώρια.<br/>            Προεπιλεγμένη τιμή: PatchFormat.PatchOnly |
| patch_format | Μορφή PatchCode. Επιλέξτε PatchOnly για να δημιουργήσετε ένα μόνο PatchCode. Χρησιμοποιήστε τη μορφή σελίδας για να δημιουργήσετε μια σελίδα Patch με PatchCodes ως περιθώρια.<br/>            Προεπιλεγμένη τιμή: PatchFormat.PatchOnly |
