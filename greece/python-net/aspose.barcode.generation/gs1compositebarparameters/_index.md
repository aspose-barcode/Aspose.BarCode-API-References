## GS1CompositeBarParameters class

Παράμετροι GS1 Composite bar.

Ο τύπος GS1CompositeBarParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| linear_component_type | Τύπος γραμμικού στοιχείου: GS1Code128, UPCE, EAN8, UPCA, EAN13, DatabarStacked, DatabarStackedOmniDirectional, DatabarLimited, DatabarOmniDirectional, DatabarExpanded, DatabarExpandedStacked |
| two_d_component_type | Τύπος στοιχείου 2D |
| allow_only_gs1_encoding | Εάν αυτή η σημαία είναι ενεργοποιημένη, επιτρέπει μόνο το πρότυπο κωδικοποίησης GS1 για το 2D στοιχείο GS1CompositeBar |
