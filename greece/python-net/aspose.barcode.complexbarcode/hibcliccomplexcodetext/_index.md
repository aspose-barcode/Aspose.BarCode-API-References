## HIBCLICComplexCodetext class

Βασική κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου που ενσωματώνεται στον κώδικα HIBC LIC.

Η HIBCLICComplexCodetext τύπος εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| barcode_type | Λαμβάνει ή ορίζει τον τύπο barcode. Το HIBC LIC codetext μπορεί να κωδικοποιηθεί χρησιμοποιώντας HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC και HIBCQRLIC τύπους κωδικοποίησης.<br/>            Προεπιλεγμένη τιμή: HIBCCode39LIC. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| get_constructed_codetext() | Δημιουργεί κείμενο κώδικα |
| init_from_string(constructed_codetext) | Αρχικοποιεί το αντικείμενο από το δημιουργημένο κείμενο κώδικα. |
| get_barcode_type() | Λαμβάνει τον τύπο barcode. |
