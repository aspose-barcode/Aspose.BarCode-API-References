## ComplexCodetextReader class

ComplexCodetextReader αποκωδικοποιεί το κείμενο κώδικα σε συγκεκριμένο τύπο σύνθετου barcode.

Ο τύπος ComplexCodetextReader εκθέτει τα ακόλουθα μέλη:
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| try_decode_swiss_qr(encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα SwissQR. |
| try_decode_mailmark_2d(encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα Royal Mail Mailmark 2D. |
| try_decode_mailmark(encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα Royal Mail Mailmark 2D. |
| try_decode_maxi_code(maxi_code_mode, encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα MaxiCode. |
| try_decode_hibclic(encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα HIBC LIC. |
| try_decode_hibcpas(encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα HIBC PAS. |
| try_decode_usa_drive_id(encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα USADriveId. |
| try_decode_gs1_codetext(encoded_codetext) | Αποκωδικοποιεί το κείμενο κώδικα GS1. |
| try_decode_gs1_digital_link(encoded_codetext) | Αποκωδικοποιεί το GS1 Digital Link. |
