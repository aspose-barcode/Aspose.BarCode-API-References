## HIBCLICCombinedCodetext class

Κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου που ενσωματώνεται στον κώδικα HIBC LIC ο οποίος αποθηκεύει πρωτεύοντα και δευτερεύοντα δεδομένα.

Ο τύπος HIBCLICCombinedCodetext εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| HIBCLICCombinedCodetext() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης HIBCLICCombinedCodetext |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| barcode_type | Λαμβάνει ή ορίζει τον τύπο barcode. Το HIBC LIC codetext μπορεί να κωδικοποιηθεί χρησιμοποιώντας HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC και HIBCQRLIC τύπους κωδικοποίησης.<br/>            Προεπιλεγμένη τιμή: HIBCCode39LIC. |
| primary_data | Αναγνωρίζει τα πρωτεύοντα δεδομένα. |
| secondary_and_additional_data | Αναγνωρίζει δευτερεύοντα και πρόσθετα συμπληρωματικά δεδομένα. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| get_constructed_codetext() | Δημιουργεί κείμενο κώδικα |
| init_from_string(constructed_codetext) | Αρχικοποιεί το αντικείμενο από το δημιουργημένο κείμενο κώδικα. |
| get_barcode_type() | Λαμβάνει τον τύπο barcode. |
