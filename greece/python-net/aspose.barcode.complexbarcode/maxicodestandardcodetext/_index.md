## MaxiCodeStandardCodetext class

Κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου κώδικα MaxiCode για λειτουργίες 4, 5 και 6.

Ο τύπος MaxiCodeStandardCodetext εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| MaxiCodeStandardCodetext() | Αρχικοποιεί μια νέα παρουσία της κλάσης MaxiCodeStandardCodetext. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| encode_mode | Λαμβάνει ή ορίζει λειτουργία κωδικοποίησης MaxiCode. <br/>            Προεπιλεγμένη τιμή: Auto. |
| eci_encoding | Λαμβάνει ή ορίζει κωδικοποίηση ECI. Χρησιμοποιείται όταν η MaxiCodeEncodeMode είναι Auto.<br/>            Προεπιλεγμένη τιμή: ISO-8859-1 |
| mode | Λαμβάνει ή ορίζει τη λειτουργία MaxiCode. Το τυπικό κείμενο κώδικα μπορεί να χρησιμοποιηθεί μόνο με τις λειτουργίες 4, 5 και 6. |
| message | Λαμβάνει ή ορίζει το μήνυμα. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| get_mode() | Λαμβάνει τη λειτουργία MaxiCode. |
| get_constructed_codetext() | Δημιουργεί κείμενο κώδικα |
| init_from_string(constructed_codetext) | Αρχικοποιεί το αντικείμενο από το δημιουργημένο κείμενο κώδικα. |
| get_barcode_type() | Λαμβάνει τον τύπο barcode. |
