## HIBCLICSecondaryAndAdditionalDataCodetext class

Κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου που ενσωματώνεται στον κώδικα HIBC LIC ο οποίος αποθηκεύει δευτερεύοντα δεδομένα.

Ο τύπος HIBCLICSecondaryAndAdditionalDataCodetext εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| HIBCLICSecondaryAndAdditionalDataCodetext() | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης HIBCLICSecondaryAndAdditionalDataCodetext |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| barcode_type | Λαμβάνει ή ορίζει τον τύπο barcode. Το HIBC LIC codetext μπορεί να κωδικοποιηθεί χρησιμοποιώντας HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC και HIBCQRLIC τύπους κωδικοποίησης.<br/>            Προεπιλεγμένη τιμή: HIBCCode39LIC. |
| δεδομένα | Αναγνωρίζει δευτερεύοντα και πρόσθετα συμπληρωματικά δεδομένα. |
| link_character | Αναγνωρίζει χαρακτήρα συνδέσμου. |
