## PrimaryData class

Κλάση για αποθήκευση των πρωτεύοντων δεδομένων HIBC LIC.

Ο τύπος PrimaryData εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PrimaryData() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης PrimaryData |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| labeler_identification_code | Αναγνωρίζει ημερομηνία κωδικού ταυτοποίησης του ετικετοποιητή.<br/>            Ο κωδικός ταυτοποίησης του ετικετοποιητή πρέπει να είναι αλφαριθμητικό 4 συμβόλων, με τον πρώτο χαρακτήρα πάντα να είναι αλφαβητικός. |
| product_or_catalog_number | Αναγνωρίζει αριθμό προϊόντος ή καταλόγου. Ο αριθμός προϊόντος ή καταλόγου πρέπει να είναι αλφαριθμητικό με μήκος έως 18 σύμβολα. |
| unit_of_measure_id | Αναγνωρίζει ταυτότητα μονάδας μέτρησης. Η ταυτότητα μονάδας μέτρησης πρέπει να είναι ακέραια τιμή από 0 έως 9. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| parse_from_string(primary_data_codetext) | Δημιουργεί τα πρωτεύοντα δεδομένα από μορφή συμβολοσειράς σύμφωνα με την προδιαγραφή HIBC LIC. |
