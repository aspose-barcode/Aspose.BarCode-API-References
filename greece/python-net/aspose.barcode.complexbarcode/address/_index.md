## Address class

Διεύθυνση του πιστωτή ή του οφειλέτη.

Ο τύπος Address εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Address() | Δημιουργεί παρουσία του Address |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| type | Λαμβάνει τον τύπο της διεύθυνσης. |
| name | Λαμβάνει ή ορίζει το όνομα, είτε το όνομα και επώνυμο ενός φυσικού προσώπου είτε το<br/>            όνομα της εταιρείας ενός νομικού προσώπου. |
| address_line1 | Λαμβάνει ή ορίζει τη γραμμή διεύθυνσης 1. |
| address_line2 | Λαμβάνει ή ορίζει τη γραμμή διεύθυνσης 2. |
| street | Λαμβάνει ή ορίζει το δρόμο. |
| house_no | Λαμβάνει ή ορίζει τον αριθμό σπιτιού. |
| postal_code | Λαμβάνει ή ορίζει τον ταχυδρομικό κώδικα. |
| town | Λαμβάνει ή ορίζει την κωμόπολη ή την πόλη. |
| country_code | Λαμβάνει ή ορίζει τον διψήφιο κωδικό χώρας ISO. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
