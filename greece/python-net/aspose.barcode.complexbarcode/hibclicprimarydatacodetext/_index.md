## HIBCLICPrimaryDataCodetext class

Κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου που ενσωματώνεται στον κώδικα HIBC LIC ο οποίος αποθηκεύει πρωτεύοντα δεδομένα.

Ο τύπος HIBCLICPrimaryDataCodetext εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| HIBCLICPrimaryDataCodetext() | Αρχικοποιεί μια νέα παρουσία της κλάσης HIBCLICPrimaryDataCodetext |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| barcode_type | Λαμβάνει ή ορίζει τον τύπο barcode. Το HIBC LIC codetext μπορεί να κωδικοποιηθεί χρησιμοποιώντας HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC και HIBCQRLIC τύπους κωδικοποίησης.<br/>            Προεπιλεγμένη τιμή: HIBCCode39LIC. |
| δεδομένα | Αναγνωρίζει τα πρωτεύοντα δεδομένα. |
