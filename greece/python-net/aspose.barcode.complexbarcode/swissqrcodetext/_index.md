## SwissQRCodetext class

Κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου που ενσωματώνεται στον κώδικα SwissQR.

Ο τύπος SwissQRCodetext εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| SwissQRCodetext(bill) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης SwissQRCodetext |
| SwissQRCodetext() | Δημιουργεί ένα αντικείμενο του SwissQRCodetext. |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| bill | Δεδομένα λογαριασμού SwissQR |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| get_constructed_codetext() | Δημιουργεί κωδικοκείμενο από τα δεδομένα λογαριασμού SwissQR |
| init_from_string(constructed_codetext) | Αρχικοποιεί το Bill με το κατασκευασμένο κωδικοκείμενο. |
| get_barcode_type() | Λαμβάνει τον τύπο barcode. |
