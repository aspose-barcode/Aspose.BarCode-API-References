## HIBCLICDateFormat enumeration

Καθορίζει τους διαφορετικούς τύπους μορφών ημερομηνίας για το HIBC LIC.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| YYYYMMDD | Μορφή YYYYMMDD. Θα κωδικοποιηθεί σε πρόσθετα συμπληρωματικά δεδομένα. |
| MMYY | Μορφή MMYY. |
| MMDDYY | Μορφή MMDDYY. |
| YYMMDD | Μορφή YYMMDD. |
| YYMMDDHH | Μορφή YYMMDDHH. |
| YYJJJ | Μορφή Ιουλιανής ημερομηνίας. |
| YYJJJHH | Μορφή ημερομηνίας Ιουλιανού με ώρες. |
| NONE | Μην κωδικοποιήσετε την ημερομηνία λήξης. |
