## HIBCPASCodetext class

Κλάση για κωδικοποίηση και αποκωδικοποίηση του κειμένου που ενσωματώνεται στον κώδικα HIBC PAS.

Ο τύπος HIBCPASCodetext εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| HIBCPASCodetext() | Αρχικοποιεί μια νέα παρουσία της κλάσης HIBCPASCodetext |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| barcode_type | Λαμβάνει ή ορίζει τον τύπο barcode. Το HIBC PAS codetext μπορεί να κωδικοποιηθεί χρησιμοποιώντας HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS και HIBCQRPAS τύπους κωδικοποίησης.<br/>            Προεπιλεγμένη τιμή: HIBCCode39PAS. |
| data_location | Καθορίζει τη θέση των δεδομένων. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| add_record(data_type, data) | Προσθέτει νέα εγγραφή |
| add_record(record) | Προσθέτει νέα εγγραφή |
| get_records() | Λαμβάνει τη λίστα των εγγραφών |
| clear() | Καθαρίζει τη λίστα εγγραφών |
| get_barcode_type() | Λαμβάνει τον τύπο barcode. |
| get_constructed_codetext() | Δημιουργεί κείμενο κώδικα |
| init_from_string(constructed_codetext) | Αρχικοποιεί το αντικείμενο από το δημιουργημένο κείμενο κώδικα. |
