## SwissQRBill class

Δεδομένα λογαριασμού SwissQR

Ο τύπος SwissQRBill εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| version | Λαμβάνει ή ορίζει την έκδοση του προτύπου SwissQR. |
| amount | Λαμβάνει ή ορίζει το ποσό πληρωμής. |
| currency | Λαμβάνει ή ορίζει το νόμισμα πληρωμής. |
| account | Λαμβάνει ή ορίζει τον αριθμό λογαριασμού του πιστωτή. |
| creditor | Λαμβάνει ή ορίζει τη διεύθυνση του πιστωτή. |
| reference | Λαμβάνει ή ορίζει την αναφορά πληρωμής του πιστωτή. |
| οφειλέτης | Λαμβάνει ή ορίζει τη διεύθυνση του οφειλέτη. |
| unstructured_message | Λαμβάνει ή ορίζει το πρόσθετο μη δομημένο μήνυμα. |
| bill_information | Λαμβάνει ή ορίζει τις πρόσθετες δομημένες πληροφορίες λογαριασμού. |
| alternative_schemes | Λαμβάνει ή ορίζει τα εναλλακτικά σχέδια πληρωμής. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| create_and_set_creditor_reference(raw_reference) | Δημιουργεί και ορίζει μια αναφορά πιστωτή ISO11649 από μια ακατέργαστη συμβολοσειρά προσθέτοντας<br/>            τη Συμβολοσειρά με το πρόθεμα "RF" και τον έλεγχο modulo 97. |
| equals(other) | Καθορίζει εάν το καθορισμένο αντικείμενο είναι ίσο με το τρέχον αντικείμενο. |
