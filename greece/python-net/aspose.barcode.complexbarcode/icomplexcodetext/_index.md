## IComplexCodetext class

Διεπαφή για σύνθετο κείμενο κώδικα που χρησιμοποιείται με το ComplexBarcodeGenerator.

Ο τύπος IComplexCodetext εκθέτει τα ακόλουθα μέλη:
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| get_constructed_codetext() | Δημιουργεί κείμενο κώδικα για σύνθετο barcode |
| init_from_string(constructed_codetext) | Αρχικοποιεί το στιγμιότυπο με το κατασκευασμένο κείμενο κώδικα. |
| get_barcode_type() | Λαμβάνει τον τύπο barcode. |
