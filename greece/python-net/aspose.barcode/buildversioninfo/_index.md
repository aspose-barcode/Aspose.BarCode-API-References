## BuildVersionInfo class

Περιέχει τις πληροφορίες της τρέχουσας έκδοσης build.

Ο τύπος BuildVersionInfo εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| ASSEMBLY_VERSION | Η έκδοση του assembly. |
| FILE_VERSION | Η έκδοση του αρχείου. |
| PRODUCT | Ο τίτλος του προϊόντος. |
| PRODUCT_MAJOR | Η κύρια έκδοση του προϊόντος. |
| PRODUCT_MINOR | Η δευτερεύουσα έκδοση του προϊόντος. |
| RELEASE_DATE | Η ημερομηνία κυκλοφορίας του προϊόντος. |
