## CustomerInformationInterpretingType enumeration

Ορίζει τον τύπο ερμηνείας (CTable, NTable ή Other) των πληροφοριών πελάτη για το AustralianPost BarCode.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| C_TABLE | Χρησιμοποιήστε το CTable για να ερμηνεύσετε τις πληροφορίες πελάτη. Επιτρέπει A..Z, a..z, 1..9, κενό και το σύμβολο #. |
| N_TABLE | Χρησιμοποιήστε το NTable για να ερμηνεύσετε τις πληροφορίες πελάτη. Επιτρέπει ψηφία. |
| OTHER | Μην ερμηνεύετε τις πληροφορίες πελάτη. Επιτρέπει μόνο το σύμβολο 0, 1, 2 ή 3. |
