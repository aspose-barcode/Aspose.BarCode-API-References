## BarcodeSettings class

Οι κύριες παραμέτρους αποκωδικοποίησης BarCode. Περιέχει παραμέτρους που επηρεάζουν τα αναγνωρισμένα δεδομένα.

Ο τύπος BarcodeSettings εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Αφαίρεση χαρακτήρων FNC1, FNC2, FNC3 από το κείμενο κώδικα. Η προεπιλεγμένη τιμή είναι ψευδής. |
| only_requested_types | Επιστρέφει μόνο τύπους barcode που καθορίζονται ρητά για αναγνώριση. <br/>            Όταν είναι ενεργό, οι αναγνωρισμένοι barcode άλλων συμβατών ή ισοδύναμων τύπων φιλτράρονται. <br/>            Η προεπιλεγμένη τιμή είναι ψευδής. |
| detect_encoding | Η σημαία που αναγκάζει τη μηχανή να εντοπίσει την κωδικοποίηση του κειμένου κώδικα για σύνολα χαρακτήρων Unicode. Η προεπιλεγμένη τιμή είναι αληθής. |
| australia_post | Λαμβάνει τις παραμέτρους αποκωδικοποίησης AustraliaPost |
| calculate_symbol_quality | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα υπολογίζεται η ποιότητα συμβόλου barcode κατά την αναγνώριση. |
