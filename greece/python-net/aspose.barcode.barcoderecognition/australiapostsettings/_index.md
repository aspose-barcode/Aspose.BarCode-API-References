## AustraliaPostSettings class

Παράμετροι αποκωδικοποίησης AustraliaPost. Περιέχει παραμέτρους που επηρεάζουν τα αναγνωρισμένα δεδομένα της συμβολικής γραφής AustraliaPost.

Ο τύπος AustraliaPostSettings εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| customer_information_interpreting_type | Ανακτά ή ορίζει τον Τύπο Ερμηνείας για τις Πληροφορίες Πελάτη του AustralianPost BarCode. Η προεπιλογή είναι CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | Η σημαία που αναγκάζει τον αποκωδικοποιητή AustraliaPost να αγνοεί τα τελευταία μοτίβα γεμίσματος στο Πεδίο Πληροφοριών Πελάτη κατά την αποκωδικοποίηση ως μέθοδο CTable.<br/>            Η μέθοδος κωδικοποίησης CTable δεν έχει κενά στον πίνακα κωδικοποίησης και η ακολουθία \"333\" των μοτίβων γεμίσματος αποκωδικοποιείται ως το γράμμα \"z\". |
| customer_information_decoder | Δημόσιο interface για την αποκωδικοποίηση του Πεδίου Πληροφοριών Πελάτη που χρησιμοποιείται στη συμβολική γραφή AustraliaPost. |
