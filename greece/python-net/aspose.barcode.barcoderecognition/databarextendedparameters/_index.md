## DataBarExtendedParameters class

Αποθηκεύει πρόσθετες πληροφορίες DataBar του αναγνωρισμένου barcode

Ο τύπος DataBarExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| is_2d_composite_component | Λαμβάνει τη σημαία του σύνθετου στοιχείου DataBar 2D. Default value is false. |
