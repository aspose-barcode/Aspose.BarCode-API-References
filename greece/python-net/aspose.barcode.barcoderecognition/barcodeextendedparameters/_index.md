## BarCodeExtendedParameters class

Αποθηκεύει επεκταμένες παραμέτρους του αναγνωρισμένου barcode

Ο τύπος BarCodeExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| one_d | Λαμβάνει ειδικά δεδομένα [OneDExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/onedextendedparameters/) του barcode 1D που αναγνωρίστηκε |
| code128 | Λαμβάνει ειδικά δεδομένα [Code128ExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/code128extendedparameters/) του barcode Code128 που αναγνωρίστηκε |
| qr | Λαμβάνει πληροφορίες QR Structured Append [QRExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/qrextendedparameters/) του barcode που αναγνωρίστηκε |
| pdf417 | Λαμβάνει μεταδεδομένα MacroPdf417 [Pdf417ExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/pdf417extendedparameters/) του barcode που αναγνωρίστηκε |
| data_bar | Λαμβάνει πρόσθετες πληροφορίες DataBar[DataBarExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/databarextendedparameters/) του barcode που αναγνωρίστηκε |
| maxi_code | Λαμβάνει πρόσθετες πληροφορίες MaxiCode[MaxiCodeExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/maxicodeextendedparameters/) του barcode που αναγνωρίστηκε |
| dot_code | Λαμβάνει πρόσθετες πληροφορίες DotCode[DotCodeExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/dotcodeextendedparameters/) του barcode που αναγνωρίστηκε |
| data_matrix | Λαμβάνει πρόσθετες πληροφορίες DataMatrix[DataMatrixExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/datamatrixextendedparameters/) του barcode που αναγνωρίστηκε |
| aztec | Λαμβάνει πρόσθετες πληροφορίες Aztec[AztecExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/aztecextendedparameters/) του barcode που αναγνωρίστηκε |
| gs1_composite_bar | Λαμβάνει πρόσθετες πληροφορίες GS1CompositeBar[GS1CompositeBarExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/gs1compositebarextendedparameters/) του barcode που αναγνωρίστηκε |
| codabar | Λαμβάνει πρόσθετες πληροφορίες Codabar[CodabarExtendedParameters](/barcode/python-net/aspose.barcode.barcoderecognition/codabarextendedparameters/) του barcode που αναγνωρίστηκε |
