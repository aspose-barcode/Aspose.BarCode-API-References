## DotCodeExtendedParameters class

Αποθηκεύει ειδικά δεδομένα του barcode DotCode που αναγνωρίστηκε.

Ο τύπος DotCodeExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| structured_append_mode_barcodes_count | Λαμβάνει τον αριθμό των barcode σε λειτουργία δομημένης προσθήκης DotCode. Η προεπιλεγμένη τιμή είναι -1. Ο αριθμός πρέπει να είναι τιμή από 1 έως 35. |
| structured_append_mode_barcode_id | Λαμβάνει το αναγνωριστικό (ID) του barcode σε λειτουργία δομημένης προσθήκης DotCode. Το ID ξεκινά από 1 και πρέπει να είναι μικρότερο ή ίσο με τον αριθμό των barcode. Η προεπιλεγμένη τιμή είναι -1. |
| is_reader_initialization | Δείχνει εάν ο κώδικας χρησιμοποιείται για να υποδείξει στον αναγνώστη να ερμηνεύσει τα παρακάτω δεδομένα ως οδηγίες για την εκκίνηση ή την επαναπρογραμματισμό του αναγνώστη barcode.<br/>            Η προεπιλεγμένη τιμή είναι false. |
