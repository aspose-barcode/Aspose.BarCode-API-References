## OneDExtendedParameters class

Αποθηκεύει ειδικά δεδομένα του 1D barcode που αναγνωρίστηκε, όπως ξεχωριστό κείμενο κώδικα και άθροισμα ελέγχου.

Ο τύπος OneDExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| value | Λαμβάνει το codetext των 1D barcode χωρίς έλεγχο αθροίσματος. |
| check_sum | Λαμβάνει το checksum για τα 1D barcode. |
