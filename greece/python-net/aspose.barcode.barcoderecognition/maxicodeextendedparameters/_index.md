## MaxiCodeExtendedParameters class

Αποθηκεύει πρόσθετες πληροφορίες MaxiCode του barcode που αναγνωρίστηκε.

Ο τύπος MaxiCodeExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| mode | Ανακτά ή ορίζει μια λειτουργία κωδικοποίησης MaxiCode.<br/>            Προεπιλεγμένη τιμή: Mode4 |
| structured_append_mode_barcode_id | Ανακτά ή ορίζει ένα αναγνωριστικό barcode MaxiCode σε λειτουργία δομημένης προσθήκης.<br/>            Προεπιλεγμένη τιμή: 0 |
| structured_append_mode_barcodes_count | Ανακτά ή ορίζει τον αριθμό των barcode MaxiCode σε λειτουργία δομημένης προσθήκης.<br/>            Προεπιλεγμένη τιμή: -1 |
