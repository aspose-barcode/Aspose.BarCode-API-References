## AustraliaPostCustomerInformationDecoder class

Δημόσιο interface για την αποκωδικοποίηση του Customer Information Field που χρησιμοποιείται στη συμβολική γραφή AustraliaPost. Η υλοποίηση πρέπει να παρέχεται από τον χρήστη.

Ο τύπος AustraliaPostCustomerInformationDecoder εκθέτει τα ακόλουθα μέλη:
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| decode(customer_information_field) | Αποκωδικοποιεί το πεδίο Πληροφοριών Πελάτη από τη συμβολή AustraliaPost. <br/>            Μπορεί να χρησιμοποιηθεί για διαφορετική ερμηνεία δεδομένων από την κωδικοποίηση NTable και CTable.<br/>            Τα δεδομένα παρέχονται ως σειρά τιμών μπαρ: 0, 1, 2 ή 3. |
