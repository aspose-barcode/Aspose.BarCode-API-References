## BarCodeResult class

Αποθηκεύει δεδομένα αναγνωρισμένου barcode όπως τύπο [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/), κείμενο κώδικα string, <br/>            περιοχή [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) και άλλες παραμέτρους

Ο τύπος BarCodeResult εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| BarCodeResult(result) | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης BarCodeResult |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| reading_quality | Αποκτά την ποιότητα ανάγνωσης. Λειτουργεί για 1D και ταχυδρομικούς κώδικες. |
| confidence | Αποκτά το επίπεδο εμπιστοσύνης αναγνώρισης του αναγνωρισμένου κώδικα |
| code_text | Αποκτά το κείμενο του κώδικα |
| code_bytes | Αποκτά τα κωδικοποιημένα bytes του κώδικα |
| code_type | Αποκτά τον τύπο του κώδικα |
| code_type_name | Αποκτά το όνομα του τύπου του κώδικα |
| περιοχή | Λαμβάνει την περιοχή του barcode |
| επεκταμένο | Λαμβάνει επεκταμένες παραμέτρους του αναγνωρισμένου barcode |
| iso_symbol_quality | Λαμβάνει τα αποτελέσματα αξιολόγησης ποιότητας συμβόλου ISO/IEC για το αναγνωρισμένο barcode. |
