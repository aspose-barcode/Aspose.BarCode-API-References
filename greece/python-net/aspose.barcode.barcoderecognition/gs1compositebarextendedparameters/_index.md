## GS1CompositeBarExtendedParameters class

Αποθηκεύει ειδικά δεδομένα του barcode GS1 Composite Bar που αναγνωρίστηκε.

Ο τύπος GS1CompositeBarExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| one_d_type | Λαμβάνει τον τύπο 1D (γραμμικού) barcode του GS1 Composite |
| one_d_code_text | Λαμβάνει την τιμή 1D (γραμμικού) barcode του GS1 Composite |
| two_d_type | Λαμβάνει τον τύπο 2D barcode του GS1 Composite |
| two_d_code_text | Λαμβάνει την τιμή 2D barcode του GS1 Composite |
