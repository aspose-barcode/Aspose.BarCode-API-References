## LuminanceFrame class

Αναπαριστά ένα πλαίσιο εικόνας 8-bit σε κλίμακα του γκρι. Κάθε pixel αναπαρίσταται από ένα byte που περιέχει την τιμή φωτεινότητάς του.

Ο τύπος LuminanceFrame εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Αρχικοποιεί μια νέα παρουσία της κλάσης LuminanceFrame |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Αρχικοποιεί μια νέα παρουσία της κλάσης LuminanceFrame |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| δεδομένα | Ανακτά τα δεδομένα φωτεινότητας. |
| width | Ανακτά το πλάτος του πλαισίου σε εικονοστοιχεία. |
| height | Ανακτά το ύψος του πλαισίου σε εικονοστοιχεία. |
| row_stride | Ανακτά την απόσταση σε bytes μεταξύ των αρχών<br/>            των δύο διαδοχικών γραμμών. |
| rotation_degrees | Ανακτά τον αριθμό των μοιρών που πρέπει να περιστραφεί το πλαίσιο δεξιόστροφα για να έχει τη σωστή προσανατολισμό. |
