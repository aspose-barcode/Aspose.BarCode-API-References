## Quadrangle class

Αποθηκεύει ένα σύνολο τεσσάρων [Point](/barcode/python-net/aspose.drawing/point/) που αντιπροσωπεύουν μια περιοχή [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/).

Ο τύπος Quadrangle εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Quadrangle() | Αρχικοποιεί μια νέα κενή παρουσία της κλάσης [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Αρχικοποιεί μια νέα παρουσία της κλάσης Quadrangle |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| left_top | Λαμβάνει την γωνία αριστερά-πάνω [Point](/barcode/python-net/aspose.drawing/point/) του [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) περιοχής. |
| right_top | Λαμβάνει την γωνία δεξιά-πάνω [Point](/barcode/python-net/aspose.drawing/point/) του [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) περιοχής. |
| right_bottom | Λαμβάνει την γωνία δεξιά-κάτω [Point](/barcode/python-net/aspose.drawing/point/) του [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) περιοχής. |
| left_bottom | Λαμβάνει την γωνία αριστερά-κάτω [Point](/barcode/python-net/aspose.drawing/point/) του [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) περιοχής. |
| is_empty | Δοκιμάζει εάν όλα τα [Point](/barcode/python-net/aspose.drawing/point/) της [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) έχουν τιμές μηδέν. |
| bounding_rectangle | Λαμβάνει το [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) που περιβάλλει αυτό το [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| EMPTY | Αντιπροσωπεύει μια κλάση [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) με τις ιδιότητές της μη αρχικοποιημένες. |
