## AztecExtendedParameters class

Αποθηκεύει ειδικά δεδομένα του αναγνωρισμένου barcode Aztec

Ο τύπος AztecExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| structured_append_barcodes_count | Λαμβάνει τον αριθμό των barcode της λειτουργίας structured append του Aztec. Η προεπιλεγμένη τιμή είναι 0. Ο αριθμός πρέπει να είναι τιμή από 1 έως 26. |
| structured_append_barcode_id | Λαμβάνει το ID του barcode της λειτουργίας structured append του Aztec. Το ID ξεκινά από 1 και πρέπει να είναι μικρότερο ή ίσο με τον αριθμό των barcode. Η προεπιλεγμένη τιμή είναι 0. |
| structured_append_file_id | Λαμβάνει το ID αρχείου της λειτουργίας structured append του Aztec. Η προεπιλεγμένη τιμή είναι κενή συμβολοσειρά. |
| is_reader_initialization | Δείχνει εάν ο κώδικας χρησιμοποιείται για να υποδείξει στον αναγνώστη να ερμηνεύσει τα παρακάτω δεδομένα ως οδηγίες για την εκκίνηση ή την επαναπρογραμματισμό του αναγνώστη barcode.<br/>            Η προεπιλεγμένη τιμή είναι false. |
