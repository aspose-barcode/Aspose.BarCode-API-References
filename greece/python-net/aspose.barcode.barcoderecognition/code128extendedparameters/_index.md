## Code128ExtendedParameters class

Αποθηκεύει ειδικά δεδομένα του αναγνωρισμένου barcode Code128

Ο τύπος Code128ExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| code_128_data_portions | Λαμβάνει τον πίνακα [Code128DataPortion](/barcode/python-net/aspose.barcode.barcoderecognition/code128dataportion/) των αναγνωρισμένων barcode Code128 |
