## Pdf417ExtendedParameters class

Αποθηκεύει μεταδεδομένα MacroPdf417 του barcode που αναγνωρίστηκε.

Ο τύπος Pdf417ExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| macro_pdf_417_file_id | Λαμβάνει το ID αρχείου του barcode, διαθέσιμο μόνο με MacroPdf417. |
| macro_pdf_417_segment_id | Λαμβάνει το ID τμήματος του barcode,μόνο διαθέσιμο με MacroPdf417. |
| macro_pdf_417_segments_count | Λαμβάνει τον αριθμό τμημάτων του macro pdf417 barcode. Η προεπιλεγμένη τιμή είναι -1. |
| macro_pdf_417_file_name | Όνομα αρχείου Macro PDF417 (προαιρετικό). |
| macro_pdf_417_file_size | Μέγεθος αρχείου Macro PDF417 (προαιρετικό). |
| macro_pdf_417_sender | Όνομα αποστολέα Macro PDF417 (προαιρετικό). |
| macro_pdf_417_addressee | Όνομα παραλήπτη Macro PDF417 (προαιρετικό). |
| macro_pdf_417_time_stamp | Macro PDF417 χρονική σήμανση (προαιρετικό). |
| macro_pdf_417_checksum | Macro PDF417 άθροισμα ελέγχου (προαιρετικό). |
| macro_pdf_417_terminator | Δείχνει εάν το τμήμα είναι το τελευταίο τμήμα ενός αρχείου Macro PDF417. |
| is_reader_initialization | Χρησιμοποιείται για να καθοδηγήσει τον αναγνώστη να ερμηνεύσει τα δεδομένα που περιέχονται στο σύμβολο ως προγραμματισμό για την εκκίνηση του αναγνώστη. |
| is_linked | Σημαία που υποδεικνύει ότι ο barcode πρέπει να συνδεθεί με barcode 1D. |
| is_code_128_emulation | Σημαία που υποδεικνύει ότι ο barcode MicroPdf417 κωδικοποιείται με τις λέξεις κώδικα 908, 909, 910 ή 911 προσομοίωσης Code 128. |
