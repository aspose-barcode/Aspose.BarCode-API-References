## CodabarExtendedParameters class

Αποθηκεύει πρόσθετες πληροφορίες Codabar του αναγνωρισμένου barcode

Ο τύπος CodabarExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| start_symbol | Λαμβάνει ή ορίζει ένα σύμβολο έναρξης Codabar.<br/>            Default value: CodabarSymbol.A |
| stop_symbol | Λαμβάνει ή ορίζει ένα σύμβολο τερματισμού Codabar.<br/>            Default value: CodabarSymbol.A |
