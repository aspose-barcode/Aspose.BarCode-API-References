## QRExtendedParameters class

Αποθηκεύει πληροφορίες QR Structured Append του barcode που αναγνωρίστηκε.

Ο τύπος QRExtendedParameters εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| is_empty | Δοκιμάζει αν όλες οι παράμετροι έχουν μόνο τις προεπιλεγμένες τιμές |
| structured_append_mode_bar_codes_quantity | Λαμβάνει την ποσότητα των barcode σε λειτουργία δομημένης προσθήκης QR. Η προεπιλεγμένη τιμή είναι -1. |
| structured_append_mode_bar_code_index | Λαμβάνει το ευρετήριο του barcode σε λειτουργία δομημένης προσθήκης QR. Το ευρετήριο ξεκινά από 0. Η προεπιλεγμένη τιμή είναι -1. |
| structured_append_mode_parity_data | Λαμβάνει τα parity δεδομένα της λειτουργίας δομημένης προσθήκης QR. Η προεπιλεγμένη τιμή είναι -1. |
| version | Έκδοση του αναγνωρισμένου QR Code. Από Version1 έως Version40. |
| micro_qr_version | Έκδοση του αναγνωρισμένου MicroQR Code. Από M1 έως M4. |
| rect_micro_qr_version | Έκδοση του αναγνωρισμένου RectMicroQR Code. Από R7x43 έως R17x139. |
| error_level | Επίπεδο διόρθωσης σφαλμάτων Reed-Solomon του αναγνωρισμένου barcode. Από χαμηλό προς υψηλό: LevelL, LevelM, LevelQ, LevelH. |
