## QualitySettings class

Το QualitySettings επιτρέπει τη διαμόρφωση της ποιότητας και της ταχύτητας αναγνώρισης χειροκίνητα.<br/>            Μπορείτε γρήγορα να ρυθμίσετε το QualitySettings με ενσωματωμένες προεπιλογές: HighPerformance, NormalQuality, HighQuality, MaxQuality ή μπορείτε να διαμορφώσετε χειροκίνητα ξεχωριστές επιλογές.<br/>            Η προεπιλεγμένη τιμή του QualitySettings είναι NormalQuality.

Ο τύπος QualitySettings εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| high_performance | Προεπιλογή ποιότητας αναγνώρισης HighPerformance. Τα barcode υψηλής ποιότητας αναγνωρίζονται καλά σε αυτή τη λειτουργία. |
| normal_quality | Προεπιλογή ποιότητας αναγνώρισης NormalQuality. Κατάλληλη για τις περισσότερες γραμμωτούς κώδικες |
| high_quality | Προεπιλογή ποιότητας αναγνώρισης HighQuality. Αυτή η προεπιλογή έχει αναπτυχθεί για γραμμωτούς κώδικες χαμηλής ποιότητας. Επιτρέπει την ανίχνευση πολύ κατεστραμμένων γραμμωτών κωδίκων. |
| max_quality | Προεπιλογή ποιότητας αναγνώρισης MaxQuality. Αυτή η προεπιλογή έχει αναπτυχθεί για την αναγνώριση όλων των πιθανών γραμμωτών κωδίκων, ακόμη και λανθασμένων γραμμωτών κωδίκων. |
| x_dimension | Λειτουργία αναγνώρισης που ορίζει το μέγεθος (από 1 έως άπειρο) του ελάχιστου στοιχείου του γραμμωτού κώδικα: κελί πλέγματος ή μπάρα. |
| minimal_x_dimension | Ελάχιστο μέγεθος του XDimension σε εικονοστοιχεία που χρησιμοποιείται με το UseMinimalXDimension. |
| barcode_quality | Λειτουργία που ενεργοποιεί μεθόδους για την αναγνώριση στοιχείων γραμμωτού κώδικα με την επιλεγμένη ποιότητα. Στοιχείο γραμμωτού κώδικα χαμηλότερης ποιότητας απαιτεί πιο απαιτητικές μεθόδους, γεγονός που επιβραδύνει την αναγνώριση. |
| deconvolution | Λειτουργία αποσύνθεσης (αποκατάσταση εικόνας) που ορίζει το επίπεδο υποβάθμισης της εικόνας. Αρχικά η αποσύνθεση είναι μια λειτουργία που μπορεί να αποκαταστήσει μια υποβαθμισμένη <br/>            (συνελικτική) εικόνα από οποιαδήποτε φυσική λειτουργία όπως η θόλωση, κατά τη λήψη της εικόνας με την κάμερα. Επειδή δεν μπορούμε να εντοπίσουμε τη λειτουργία της εικόνας που τη διαφθείρει, <br/>            πρέπει να ελέγξουμε τις πιο γνωστές λειτουργίες όπως η ευκρίνεια ή η μαθηματική μορφολογία. |
| inverse_image | Λειτουργία που ενεργοποιεί ή απενεργοποιεί την πρόσθετη αναγνώριση γραμμωτών κωδίκων σε εικόνες με αντιστροφή χρωμάτων (λαμπρότητα). |
| complex_background | Λειτουργία που ενεργοποιεί ή απενεργοποιεί την πρόσθετη αναγνώριση χρωματικών γραμμωτών κωδίκων σε χρωματικές εικόνες. |
| allow_incorrect_barcodes | Επιτρέπει στη μηχανή να αναγνωρίζει γραμμωτούς κώδικες που έχουν λανθασμένο άθροισμα ελέγχου ή λανθασμένες τιμές. Η λειτουργία μπορεί να χρησιμοποιηθεί για την αναγνώριση κατεστραμμένων γραμμωτών κωδίκων με λανθασμένο κείμενο. |
