## ProcessorSettings class

Το ProcessorSettings επιτρέπει την αναγνώριση barcode με πολυνηματική αύξηση της απόδοσης.

Ο τύπος ProcessorSettings εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| use_all_cores | Απαιτείται για τη χρήση όλων των πυρήνων. |
| use_only_this_cores_count | Καθορίστε τον αριθμό των πυρήνων που θα χρησιμοποιηθούν. <br/>            Πρέπει να αλλάξετε την ιδιότητα "UseAllCores" σε "false". |
| max_additional_allowed_threads | Καθορίστε τον μέγιστο αριθμό πρόσθετων νημάτων για την εκτέλεση κώδικα παράλληλα |
