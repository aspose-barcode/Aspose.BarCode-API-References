## GS1Element class

Αντιπροσωπεύει ένα αμετάβλητο ζεύγος Αναγνωριστικού Εφαρμογής GS1 και τιμής.

Ο τύπος GS1Element εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| application_identifier | Αποκτά το ακριβές Αναγνωριστικό Εφαρμογής GS1. |
| value | Αποκτά την επικυρωμένη τιμή που σχετίζεται με το Αναγνωριστικό Εφαρμογής. |
## Μέθοδοι
| Όνομα | Περιγραφή |
| :- | :- |
| validate(application_identifier, value) | Επικυρώνει μια τιμή για ένα ακριβές Αναγνωριστικό Εφαρμογής GS1. |
