## GS1ValidationIssue class

Περιγράφει ένα σφάλμα επικύρωσης GS1.

Ο τύπος GS1ValidationIssue εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| code | Λαμβάνει έναν σταθερό κωδικό σφάλματος αναγνώσιμο από μηχανή. |
| application_identifier | Λαμβάνει το Αναγνωριστικό Εφαρμογής που σχετίζεται με το σφάλμα, ή null όταν το Αναγνωριστικό<br/>            δεν μπορεί να προσδιοριστεί από την είσοδο. |
| message | Λαμβάνει το ανθρώπινα αναγνώσιμο μήνυμα σφάλματος. |
