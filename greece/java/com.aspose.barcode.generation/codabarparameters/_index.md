### getChecksumMode() {#getChecksumMode--}
```
public final CodabarChecksumMode getChecksumMode()
```


Αποκτήστε τον αλγόριθμο ελέγχου αθροίσματος για τα barcode Codabar. Προεπιλεγμένη τιμή: CodabarChecksumMode.Mod16. Για να ενεργοποιήσετε τον υπολογισμό ελέγχου αθροίσματος, ορίστε την τιμή EnableChecksum.Yes στην ιδιότητα EnableChecksum. Δείτε το ChecksumMode (\#getChecksumMode.getChecksumMode/\#setChecksumMode.setChecksumMode).

**Returns:**
[CodabarChecksumMode](../../com.aspose.barcode.generation/codabarchecksummode) - the checksum algorithm for Codabar barcodes.
