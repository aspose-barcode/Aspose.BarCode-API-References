Ενεργοποίηση αθροίσματος ελέγχου κατά τη δημιουργία για 1D γραμμικούς κώδικες.

Η προεπιλογή θεωρείται Yes για τις συμβολές που πρέπει να περιέχουν checksum, και No όπου το checksum είναι μόνο δυνατό.

Το checksum δεν χρησιμοποιείται ποτέ: Codabar

Το checksum είναι δυνατό: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN

Checksum πάντα χρησιμοποιείται: Υπόλοιπες συμβολές
## Πεδία

| Πεδίο | Περιγραφή |
| --- | --- |
| [DEFAULT](#DEFAULT) | Εάν το checksum απαιτείται από την προδιαγραφή - θα προσαρτηθεί. |
| [NO](#NO) | Μην χρησιμοποιείτε checksum. |
| [YES](#YES) | Χρησιμοποιήστε πάντα checksum εάν είναι δυνατό. |
