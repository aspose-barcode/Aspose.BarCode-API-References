## Metered::SetMeteredKey method


Ορίζει το δημόσιο και ιδιωτικό κλειδί metered. Εάν αγοράσετε άδεια metered, όταν ξεκινάτε την εφαρμογή, αυτό το API πρέπει να κληθεί· συνήθως αυτό είναι αρκετό. Ωστόσο, εάν αποτυγχάνει συνεχώς η μεταφόρτωση δεδομένων κατανάλωσης και υπερβαίνει τις 24 ώρες, η άδεια θα οριστεί σε κατάσταση αξιολόγησης· για να αποφύγετε αυτήν την περίπτωση, πρέπει να ελέγχετε τακτικά την κατάσταση της άδειας· εάν είναι σε κατάσταση αξιολόγησης, καλέστε ξανά αυτό το API.
