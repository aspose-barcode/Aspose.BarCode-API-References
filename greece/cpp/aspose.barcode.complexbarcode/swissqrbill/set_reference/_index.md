## SwissQRBill::set_Reference method


Ορίζει την αναφορά πληρωμής του πιστωτή.

```cpp
void Aspose::BarCode::ComplexBarcode::SwissQRBill::set_Reference(System::String value)
```

## Σχόλια


Η αναφορά είναι υποχρεωτική για τα SwissQR IBAN, δηλαδή IBAN στην περιοχή CHxx30000xxxxxx έως CHxx31999xxxxx.

Εάν καθοριστεί, η αναφορά πρέπει να είναι είτε μια έγκυρη αναφορά SwissQR (σύμφωνη με τη μορφή αναφοράς ISR) είτε μια έγκυρη αναφορά πιστωτή σύμφωνα με το ISO 11649 (\"RFxxxx\"). Και οι δύο μπορεί να περιέχουν κενά για μορφοποίηση.
