## BarcodeParameters::get_WideNarrowRatio method


Αναλογία πλατών γραμμών προς στενές γραμμές. Προεπιλεγμένη τιμή: 3, δηλαδή οι πλατές γραμμές είναι 3 φορές πιο πλατιές από τις στενές. Χρησιμοποιείται για ITF, PZN, PharmaCode, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, IATA2of5, VIN, DeutschePost, OPC, Code32, DataLogic2of5, PatchCode, Code39, Code39FullASCII.

```cpp
float Aspose::BarCode::Generation::BarcodeParameters::get_WideNarrowRatio() const
```
