## Σχόλια


Ενεργοποίηση ελέγχου αθροίσματος κατά τη δημιουργία 1D barcodes.

Η προεπιλογή θεωρείται ως Ναι για συμβολισμούς που πρέπει να περιέχουν έλεγχο αθροίσματος, ως Όχι όπου ο έλεγχος αθροίσματος είναι μόνο δυνατόν.

Ο έλεγχος αθροίσματος είναι δυνατός: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN, Codabar

Ο έλεγχος αθροίσματος χρησιμοποιείται πάντα: Υπόλοιποι συμβολισμοί
