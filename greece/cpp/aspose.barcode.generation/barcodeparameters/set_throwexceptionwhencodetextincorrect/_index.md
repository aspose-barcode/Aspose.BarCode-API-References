## BarcodeParameters::set_ThrowExceptionWhenCodeTextIncorrect method


Μόνο για 1D κωδικούς γραμμής. Εάν το codetext είναι εσφαλμένο και η τιμή οριστεί σε true - θα ριχθεί εξαίρεση. Διαφορετικά το codetext θα διορθωθεί ώστε να ταιριάζει με την προδιαγραφή του κωδικού γραμμής. Η εξαίρεση θα ριχθεί πάντα για: τη συμβολή Databar εάν το codetext είναι εσφαλμένο. Η εξαίρεση δεν θα ριχθεί ποτέ για: AustraliaPost, SingapurePost, Code39FullASCII, Code93, Code16K, τη συμβολή Code128 εάν το codetext είναι εσφαλμένο.
