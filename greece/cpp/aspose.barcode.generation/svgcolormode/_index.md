## SvgColorMode enum


Πιθανές λειτουργίες για το γέμισμα χρώματος σε αρχείο svg, το RGB είναι προεπιλογή και υποστηρίζεται από SVG 1.1. Τα RGBA, HSL, HSLA επιτρέπονται στο πρότυπο SVG 2.0. Ακόμη και στο RGB η αδιαφάνεια θα οριστεί μέσω της παραμέτρου "fill-opacity".

```cpp
enum class SvgColorMode
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| RGB | 0 | Λειτουργία RGB, παράδειγμα: fill="#ff5511" fill-opacity="0.73". Προεπιλεγμένη λειτουργία. |
| RGBA | 1 | Λειτουργία RGBA, παράδειγμα: fill="rgba(255, 85, 17, 0.73)" |
| HSL | 2 | Λειτουργία HSL, παράδειγμα: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | 3 | Λειτουργία HSLA, παράδειγμα: fill="hsla(30, 50%, 70%, 0.8)" |
