## EncodeTypes::TryParse method


Μετατρέπει την αναπαράσταση συμβολοσειράς ενός [BaseEncodeType](../../baseencodetype/) στην παρουσία του. Μια τιμή επιστροφής υποδεικνύει αν η μετατροπή πέτυχε ή απέτυχε.

```cpp
static bool Aspose::BarCode::Generation::EncodeTypes::TryParse(System::String parsingType, System::SharedPtr<BaseEncodeType> &result)
```


| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| parsingType | System::String | Μια συμβολοσειρά στη μορφή "Index:-1; Name:None" για μετατροπή. |
| result | System::SharedPtr\<BaseEncodeType\>\& | Ένα πραγματικό SingleEncodeType επιστρέφεται, όταν η μετατροπή ολοκληρωθεί επιτυχώς; |

### ReturnValue

**true** if s was converted successfully; otherwise, **false**.

διαφορετικά επιστρέφει null.
