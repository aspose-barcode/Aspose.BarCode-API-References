## AustraliaPostCustomerInformationDecoder class


Δημόσια διεπαφή για την αποκωδικοποίηση του πεδίου Πληροφορίες Πελάτη που χρησιμοποιείται στη συμβολική γραφή AustraliaPost. Η υλοποίηση πρέπει να παρέχεται από τον χρήστη.

```cpp
class AustraliaPostCustomerInformationDecoder : public virtual System::Object
```

## Methods

| Method | Περιγραφή |

| virtual [Decode](./decode/)(System::String) | Αποκωδικοποίηση του πεδίου Customer Information από τη συμβολή AustraliaPost. Μπορεί να χρησιμοποιηθεί για διαφορετική κωδικοποίηση **NTable** και **CTable**. Τα δεδομένα παρέχονται ως σειρά τιμών γραμμής: 0, 1, 2 ή 3. |
