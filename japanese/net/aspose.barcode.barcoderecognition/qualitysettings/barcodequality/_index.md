## QualitySettings.BarcodeQuality property

選択された品質でバーコード要素を認識するメソッドを有効にするモードです。品質が低いバーコード要素は、より多くの高度なメソッドを必要とし、認識が遅くなります。

```csharp
public BarcodeQualityMode BarcodeQuality { get; set; }
```
