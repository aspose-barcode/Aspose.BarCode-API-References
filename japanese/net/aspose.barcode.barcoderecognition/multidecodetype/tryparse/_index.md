## MultiDecodeType.TryParse method

MultiDecodeType の文字列表現をそのインスタンスに変換します。戻り値は変換が成功したか失敗したかを示します。

```csharp
public static bool TryParse(string parsingType, out MultiDecodeType result)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| parsingType | 文字列 | 変換するための、"AllSupportedTypes" または "EAN8,EAN13,CodaBar" の形式の文字列です。 |
| 結果 | MultiDecodeType& | 変換が正常に完了したとき、実際の MultiDecodeType が返されます; |

### 戻り値

**true** if s was converted successfully; otherwise, **false**.
