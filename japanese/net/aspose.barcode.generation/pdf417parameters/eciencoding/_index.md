## Pdf417Parameters.ECIEncoding property

拡張チャネル解釈識別子（ECI）。シンボル内のデータをエンコードする際に使用された参照情報をバーコードリーダーに伝えるために使用されます。Macro PDF417 のテキストフィールドには適用されません。現在の実装は、すべての一般的な文字セットエンコーディングを含みます。

public ECIEncodings ECIEncoding { get; set; }
