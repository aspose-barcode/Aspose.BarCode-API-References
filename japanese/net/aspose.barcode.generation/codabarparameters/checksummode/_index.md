## CodabarParameters.ChecksumMode property

Codabar バーコードのチェックサムアルゴリズムを取得または設定します。既定値: CodabarChecksumMode.Mod16。チェックサム計算を有効にするには、プロパティ EnableChecksum に値 EnableChecksum.Yes を設定します。`ChecksumMode` を参照してください。

```csharp
public CodabarChecksumMode ChecksumMode { get; set; }
```
