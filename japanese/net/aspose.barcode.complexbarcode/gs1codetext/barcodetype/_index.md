## GS1Codetext.BarcodeType property

この GS1 コードテキストのエンコードに使用されるバーコードタイプを取得または設定します。サポートされているタイプは GS1Aztec、GS1CodablockF、GS1Code128、GS1DataMatrix、GS1DotCode、GS1HanXin、GS1MicroPdf417、GS1QR および GS1 DataBar タイプです。既定値は GS1Code128 です。

public BaseEncodeType BarcodeType { get; set; }
