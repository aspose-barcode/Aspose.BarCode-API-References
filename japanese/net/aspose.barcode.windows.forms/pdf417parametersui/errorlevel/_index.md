## Pdf417ParametersUI.ErrorLevel property

Pdf417 シンボルタイプのバーコードの誤り訂正レベルを取得または設定します。レベル0 からレベル8 の範囲で、レベル0 は誤り訂正情報がなく、レベル8 は最高の誤り訂正で、画像が大きくなります。

```csharp
public Pdf417ErrorLevel ErrorLevel { get; set; }
```
