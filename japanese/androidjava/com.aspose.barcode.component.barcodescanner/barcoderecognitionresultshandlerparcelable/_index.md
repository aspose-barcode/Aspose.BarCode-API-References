com.aspose.barcode.component.barcodescanner.BarcodeRecognitionResultsHandler, android.os.Parcelable
```
public interface BarcodeRecognitionResultsHandlerParcelable extends BarcodeRecognitionResultsHandler, Parcelable
```

Parcelable インターフェイスを実装した OnScannerRecognitionFinishedListener の実装です。OnScannerRecognitionFinishedListener インターフェイスは BarcodeScanner.setOnScanFinishedHandler メソッドと共に使用する必要があります。Parcelable インターフェイスの実装により、データをアクティビティ間で送信できます。
