## フィールド

| フィールド | 説明 |
| --- | --- |
| [ECC_000](#ECC-000) | エンコードされたEccタイプがECC 000であることを指定します。 |
| [ECC_050](#ECC-050) | エンコードされたEccタイプがECC 050であることを指定します。 |
| [ECC_080](#ECC-080) | エンコードされたEccタイプがECC 080であることを指定します。 |
| [ECC_100](#ECC-100) | エンコードされたEccタイプがECC 100であることを指定します。 |
| [ECC_140](#ECC-140) | エンコードされたEccタイプがECC 140であることを指定します。 |
| [ECC_200](#ECC-200) | エンコードされたEccタイプがECC 200であることを指定します。 |
| [ECC_AUTO](#ECC-AUTO) | エンコードされたEccタイプがデフォルトのReed-Solomon誤り訂正またはECC 200であることを指定します。 |
