public enum SvgColorMode extends Enum<SvgColorMode>

SVG ファイルで色を塗りつぶす際の可能なモード。RGB がデフォルトであり、SVG 1.1 でサポートされています。RGBA、HSL、HSLA は SVG 2.0 標準で許可されています。RGB の場合でも、不透明度は \"fill-opacity\" パラメータで設定されます。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [HSL](#HSL) | HSL モード、例: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| [HSLA](#HSLA) | HSLA モード、例: fill=\"hsla(30, 50%, 70%, 0.8)\" |
| [RGB](#RGB) | RGB モード、例: fill=\"\\#ff5511\" fill-opacity=\"0.73\"。 |
| [RGBA](#RGBA) | RGBA モード、例: fill=\"rgba(255, 85, 17, 0.73)\" |
