## PenDashStyle enum


破線の枠線スタイルを指定します。

```cpp
enum class PenDashStyle
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Solid | 0 | 実線を指定します。 |
| Dash | 1 | 破線で構成された線を指定します。 |
| Dot | 2 | 点線で構成された線を指定します。 |
| DashDot | 3 | 破線と点線が交互に繰り返すパターンの線を指定します。 |
| DashDotDot | 4 | ダッシュ・ドット・ドットの繰り返しパターンで構成された行を指定します。 |
