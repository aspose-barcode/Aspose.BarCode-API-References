## Pdf417MacroTerminator enum


エンコーダにセグメントへ Macro PDF417 ターミネータ（コードワード 922）を追加するかどうかを指示するために使用します。Macro PDF417 にのみ適用されます。

```cpp
enum class Pdf417MacroTerminator
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| 自動 | 0 | セグメント数が指定され、現在のセグメントが最後である場合、ターミネータは自動的に追加されます。その他の場合、ターミネータは追加されません。 |
| なし | 1 | ターミネータは追加されません。 |
| 設定 | 2 | ターミネータが追加されます。 |
