## BarCodeImageFormat enum


画像のファイル形式を指定します。

```cpp
enum class BarCodeImageFormat
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Bmp | 0 | ビットマップ (BMP) 画像形式を指定します。 |
| Gif | 1 | Graphics Interchange Format (GIF) 画像形式を指定します。 |
| Jpeg | 2 | Joint Photographic Experts Group (JPEG) 画像形式を指定します。 |
| Png | 3 | W3C Portable Network Graphics (PNG) 画像形式を指定します。 |
| Tiff | 4 | Tagged Image File Format (TIFF) 画像形式を指定します。 |
| TiffInCmyk | 5 | CMYK カラーモデルで Tagged Image File Format (TIFF) 画像形式を指定します。(サポートは [Windows](../../aspose.barcode.windows/) プラットフォームのみで、*nix プラットフォームでは Tiff として保存されます) |
| Emf | 6 | Enhanced Metafile (EMF) 画像形式を指定します。(サポートは [Windows](../../aspose.barcode.windows/) プラットフォームのみで、*nix プラットフォームでは PNG として保存されます) |
| Svg | 7 | Scalable Vector Graphics (SVG) 画像形式を指定します。 |
| Pdf | 8 | Portable Document Format (PDF) 画像形式を指定します。 |
