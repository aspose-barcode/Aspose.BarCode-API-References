## CodetextParameters::set_FontMode method


FontMode を指定します。FontMode が Auto に設定されている場合、フォントサイズは xDimension の値に基づいて自動的に計算されます。特に [AutoSizeMode.Nearest](../../autosizemode/) または [AutoSizeMode.Interpolation](../../autosizemode/) で使用する場合は [FontMode.Auto](../../aztecencodemode/) の使用が推奨されます。デフォルト値: [FontMode.Auto](../../aztecencodemode/)。

void Aspose::BarCode::Generation::CodetextParameters::set_FontMode(Aspose::BarCode::Generation::FontMode value)
