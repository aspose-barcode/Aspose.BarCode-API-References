## DataMatrixEccType enum


エンコードする ECC のタイプを指定します。

```cpp
enum class DataMatrixEccType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| EccAuto | 0 | エンコードされた ECC タイプがデフォルトの Reed-Solomon 誤り訂正または ECC 200 によって定義されることを示します。 |
| Ecc000 | 1 | エンコードされた ECC タイプが ECC 000 によって定義されることを示します。 |
| Ecc050 | 2 | エンコードされた ECC タイプが ECC 050 によって定義されることを示します。 |
| Ecc080 | 3 | エンコードされた ECC タイプが ECC 080 によって定義されることを示します。 |
| Ecc100 | 4 | エンコードされた ECC タイプが ECC 100 によって定義されることを示します。 |
| Ecc140 | 5 | エンコードされた ECC タイプが ECC 140 によって定義されることを示します。 |
| Ecc200 | 6 | エンコードされた ECC タイプが ECC 200 によって定義されることを示します。使用が推奨されます。 |
