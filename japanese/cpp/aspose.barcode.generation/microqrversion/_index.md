## MicroQRVersion enum


MicroQRコードのバージョン。M1 から M4 まで。

```cpp
enum class MicroQRVersion
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| 自動 | 0 | MicroQRに最適なバージョンを自動的に選択することを指定します。これがデフォルト値です。 |
| M1 | 1 | 11×11モジュールのMicro QRのバージョンM1を指定します。 |
| M2 | 2 | 13×13モジュールのMicro QRのバージョンM2を指定します。 |
| M3 | 3 | 15×15モジュールのMicro QRのバージョンM3を指定します。 |
| M4 | 4 | 17×17モジュールのMicro QRのバージョンM4を指定します。 |
