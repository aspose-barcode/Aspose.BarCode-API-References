## HIBCLICDateFormat enum


HIBC LICのさまざまな日付形式のタイプを指定します。

```cpp
enum class HIBCLICDateFormat
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| YYYYMMDD | 0 | YYYYMMDD 形式。追加の補足データにエンコードされます。 |
| MMYY | 1 | MMYY 形式。 |
| MMDDYY | 2 | MMDDYY 形式。 |
| YYMMDD | 3 | YYMMDD 形式。 |
| YYMMDDHH | 4 | YYMMDDHH 形式。 |
| YYJJJ | 5 | ユリウス日付形式。 |
| YYJJJHH | 6 | 時間付きユリウス日付形式。 |
| なし | 7 | 有効期限をエンコードしません。 |
