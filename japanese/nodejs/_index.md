API はバーコードの作成、認識、操作のためのクラスを提供し、Java 相互運用を介して Node.js アプリケーションへのシームレスな統合を可能にします。サポートされるシンボルは、Code128、EAN‑13、QR、DataMatrix、Aztec、PDF417 などの線形、2‑D、郵便コードにわたります。すべての機能は aspose.barcode 名前空間に整理され、補助ユーティリティは Global 名前空間に配置されています。

## 名前空間

| 名前空間 | 説明 |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | aspose.barcode 名前空間は、Node.js via Java でさまざまなバーコードタイプを作成、カスタマイズ、デコードするためのクラスと列挙体を提供します。 |
| [Global](./global/) | Global 名前空間は、Aspose.BarCode for Node.js via Java 全体で使用されるコア列挙体とユーティリティクラスをまとめています。 |
