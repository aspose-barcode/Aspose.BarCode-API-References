## HanXinEncodeMode

Han Xin コードのエンコードモードです。ASCII / 中国語文字の場合は Auto を、Unicode 文字の場合は Unicode を使用することを推奨します。

## 値

| 名前 | 説明 |
| --- | --- |
| なし | バーコードを囲む境界がありません |
| FRAME | バーコードを囲むフレーム |
| バー | バーコードを囲む2本の水平バー |
| FRAME_OUT | バーコードを囲むフレーム |
| BAR_OUT | バーコードを囲む2本の水平バー |
