## Pdf417ErrorLevel

pdf417 バーコードの誤り訂正レベルで、レベル 0 からレベル 9 まであります。レベル 0 は誤り訂正なし、レベル 9 は最高の誤り訂正を意味します。

## 値

| 名前 | 説明 |
| --- | --- |
| LEVEL_0 | レベル = 0。 |
| LEVEL_1 | レベル = 1。 |
| LEVEL_2 | レベル = 2。 |
| LEVEL_3 | レベル = 3。 |
| LEVEL_4 | レベル = 4。 |
| LEVEL_5 | レベル = 5。 |
| LEVEL_6 | レベル = 6。 |
| LEVEL_7 | レベル = 7. |
| LEVEL_8 | レベル = 8. |
