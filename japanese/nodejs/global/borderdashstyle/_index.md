## BorderDashStyle

破線の境界線スタイルを指定します。

## 値

| 名前 | 説明 |
| --- | --- |
| SOLID | 実線を指定します。 |
| DASH | 破線で構成された線を指定します。 |
| DOT | 点線で構成された線を指定します。 |
| DASH_DOT | 破線と点の繰り返しパターンで構成された線を指定します。 |
| DASH_DOT_DOT | 破線と点点の繰り返しパターンで構成された線を指定します。 |
