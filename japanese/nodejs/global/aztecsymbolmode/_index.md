## AztecSymbolMode

Aztec シンボルモードを指定します。

## 値

| 名前 | 説明 |
| --- | --- |
| AUTO | Aztec 用に最適なシンボル（COMPACT または FULL-range）を自動的に選択することを指定します。これはデフォルト値です。 |
| COMPACT | Aztec 用の COMPACT シンボルを指定します。Aztec の COMPACT シンボルは 1、2、3、または 4 層のみを許可します。 |
| FULL_RANGE | Aztec 用の FULL-range シンボルを指定します。Aztec の FULL-range シンボルは 1 から 32 層まで許可します。 |
| RUNE | Aztec 用の RUNE シンボルを指定します。Aztec のルーンは小さくても明確な機械可読マークのシリーズです。0 から 255 までの数値のみが許可されます。 |
