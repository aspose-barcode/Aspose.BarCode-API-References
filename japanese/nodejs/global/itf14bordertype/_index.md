## ITF14BorderType

ITF14 バーコードのボーダータイプです。

## 値

| 名前 | 説明 |
| --- | --- |
| なし | バーコードを囲む境界がありません |
| FRAME | バーコードを囲むフレーム |
| バー | バーコードを囲む2本の水平バー |
| FRAME_OUT | バーコードを囲むフレーム |
| BAR_OUT | バーコードを囲む2本の水平バー |
