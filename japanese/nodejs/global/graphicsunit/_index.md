## GraphicsUnit

指定されたデータの測定単位を指定します。

## 値

| 名前 | 説明 |
| --- | --- |
| WORLD | 世界座標系の単位を測定単位として指定します。 |
| DISPLAY | ディスプレイデバイスの測定単位を指定します。通常、ビデオディスプレイはピクセル、プリンターは1/100インチです。 |
| PIXEL | デバイスピクセルを測定単位として指定します。 |
| POINT | プリンターのポイント（1/72インチ）を測定単位として指定します。 |
| INCH | インチを測定単位として指定します。 |
| DOCUMENT | 文書単位（1/300インチ）を測定単位として指定します。 |
| MILLIMETER | ミリメートルを測定単位として指定します。 |
