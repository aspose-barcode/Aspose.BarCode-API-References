## QrExtCompactionMode

QrExtCodetextBuilder によって追加されたコードテキストの QR 圧縮モードを指定します。

## 値

| 名前 | 説明 |
| --- | --- |
| AUTO | エンコーダは最も効率的なQR圧縮モードを自動的に選択します。 |
| 数値 | コードテキストをQR数値モードでエンコードします。0-9 の数字のみ使用可能です。 |
| ALPHA_NUMERIC | コードテキストをQR英数字モードでエンコードします。 |
| BYTES | コードテキストをQRバイトモードでエンコードします。 |
| KANJI | コードテキストをQR漢字モードでエンコードします。 |
