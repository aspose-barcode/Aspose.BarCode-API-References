## BarCodeImageFormat

画像のファイル形式を指定します。

## 値

| 名前 | 説明 |
| --- | --- |
| BMP | ビットマップ (BMP) 画像形式を指定します。 |
| GIF | Graphics Interchange Format (GIF) 画像形式を指定します。 |
| JPEG | Joint Photographic Experts Group (JPEG) 画像形式を指定します。 |
| PNG | W3C Portable Network Graphics (PNG) 画像形式を指定します。 |
| TIFF | Tagged Image File Format (TIFF) 画像形式を指定します。 |
| TIFF_IN_CMYK | Tagged Image File Format (TIFF) 画像形式を CMYK カラーモデルで指定します。 |
| EMF | Enhanced Metafile (EMF) 画像形式を指定します。 |
| SVG | Scalable Vector Graphics (SVG) 画像形式を指定します。 |
| PDF | Portable Document Format (PDF) 画像形式を指定します。 |
