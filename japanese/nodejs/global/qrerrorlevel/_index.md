## QRErrorLevel

Reed-Solomon 誤り訂正のレベル。低から高へ: LEVEL_L, LEVEL_M, LEVEL_Q, LEVEL_H。

## 値

| 名前 | 説明 |
| --- | --- |
| LEVEL_L | コードテキストの 7% の復元を可能にします |
| LEVEL_M | コードテキストの 15% の復元を可能にします |
| LEVEL_Q | コードテキストの 25% の復元を可能にします |
| LEVEL_H | コードテキストの 30% の復元を可能にします |
