## MacroCharacter

マクロ文字 05 と 06 の値は、特別なモードでよりコンパクトなエンコーディングを取得するために使用されます。 05 のマクロ文字は、デコードされたデータヘッダーとして "[)>\u001E05\u001D"、データトレーラーとして "\u001E\u0004" に変換されます。 06 のマクロ文字は、デコードされたデータヘッダーとして "[)>\u001E06\u001D"、データトレーラーとして "\u001E\u0004" に変換されます。 これらのサンプルは MicroPdf417 と DataMatrix でマクロ文字をエンコードする方法を示します

## 値

| 名前 | 説明 |
| --- | --- |
| AUTO | 自動判定 |
| TYPE_7 | 24 x 24 モジュール |
| TYPE_9 | 32 x 32 モジュール |
| TYPE_29 | 16 x 48 モジュール |
