## EncodeTypes

エンコードするバーコードのタイプを指定します。

## 値

| 名前 | 説明 |
| --- | --- |
| なし | データを CODABAR バーコード仕様でエンコードすることを指定します。 |
| CODABAR | データを CODE 11 バーコード仕様でエンコードすることを指定します。 |
| CODE_11 | データを `Code 39 ` の基本文字セット（バーコード仕様: ISO/IEC 16388）でエンコードすることを指定します。 |
| CODE_39 | データを `Code 39 ` のフル ASCII 文字セット（バーコード仕様: ISO/IEC 16388）でエンコードすることを指定します。 |
| CODE_39_FULL_ASCII | データを `CODE 93 ` バーコード仕様でエンコードすることを指定します。 |
| CODE_93 | データを CODE 128 バーコード仕様でエンコードすることを指定します。 |
| CODE_128 | データを GS1 Code 128 バーコード仕様でエンコードすることを指定します。コードテキストは AI 用に丸括弧を含む必要があります。 |
| GS_1_CODE_128 | データを EAN-8 バーコード仕様でエンコードすることを指定します。 |
| EAN_8 | データを EAN-13 バーコード仕様でエンコードすることを指定します。 |
| EAN_13 | データを EAN14 バーコード仕様でエンコードすることを指定します。 |
| EAN_14 | データを SCC14 バーコード仕様でエンコードすることを指定します。 |
| SCC_14 | データを SSCC18 バーコード仕様でエンコードすることを指定します。 |
| SSCC_18 | データは SSCC18 バーコード仕様でエンコードされるべきであることを指定します |
| UPCA | データを UPC-A バーコード仕様でエンコードすることを指定します |
| UPCE | データを UPC-E バーコード仕様でエンコードすることを指定します |
| ISBN | データを isBN バーコード仕様でエンコードすることを指定します |
| ISSN | データを ISSN バーコード仕様でエンコードすることを指定します |
| ISMN | データを ISMN バーコード仕様でエンコードすることを指定します |
| STANDARD_2_OF_5 | データを Standard 2 of 5 バーコード仕様でエンコードすることを指定します |
| INTERLEAVED_2_OF_5 | データを INTERLEAVED 2 of 5 バーコード仕様でエンコードすることを指定します |
| MATRIX_2_OF_5 | Matrix 2 of 5 バーコードを表します |
| ITALIAN_POST_25 | Italian Post 25 バーコードを表します。 |
| IATA_2_OF_5 | IATA 2 of 5 バーコードを表します。IATA（International Air Transport Association）は、このバーコードを航空貨物の管理に使用します。 |
| ITF_14 | データを ITF14 バーコード仕様でエンコードすることを指定します |
| ITF_6 | ITF-6 バーコードを表します。 |
| MSI | データを MSI Plessey バーコード仕様でエンコードすることを指定します |
| VIN | VIN（Vehicle Identification Number）バーコードを表します。 |
| DEUTSCHE_POST_IDENTCODE | Deutsch Post バーコードを表します。このエンコードタイプは、Identcode、CodeIdentcode、German Postal 2 of 5 Identcode、Deutsch Post AG Identcode、Deutsch Frachtpost Identcode、Deutsch Post AG（DHL）としても知られています。 |
| DEUTSCHE_POST_LEITCODE | Deutsch Post Leitcode バーコードを表します。これは、German Postal 2 of 5 Leitcode、CodeLeitcode、Leitcode、Deutsch Post AG（DHL）としても知られています。 |
| OPC | OPC（Optical Product Code）バーコードを表します。また、VCA Barcode VCA OPC、Vision Council of America OPC Barcodeとしても知られています。 |
| PZN | PZN バーコードを表します。このエンコードタイプは、Pharmacy central number、Pharmazentralnummerとしても知られています。 |
| CODE_16_K | Code 16K バーコードを表します。 |
| PHARMACODE | Pharmacode バーコードを表します。 |
| DATA_MATRIX | 2D バーコードシンボル DataMatrix |
| QR | データを QR Code バーコード仕様でエンコードすることを指定します |
| AZTEC | データを Aztec バーコード仕様でエンコードすることを指定します |
| GS_1_AZTEC | データを `GS1 Aztec ` バーコード仕様でエンコードすることを指定します。コードテキストは AI のために括弧を含む必要があります。 |
| PDF_417 | データを Pdf417 バーコード仕様でエンコードすることを指定します |
| MACRO_PDF_417 | データは MacroPdf417 バーコード仕様でエンコードされることを指定します |
| GS_1_DATA_MATRIX | GS1 文字列形式の 2D バーコードシンボル DataMatrix |
| MICRO_PDF_417 | データは MicroPdf417 バーコード仕様でエンコードされることを指定します |
| GS_1_MICRO_PDF_417 | データは GS1MicroPdf417 バーコード仕様でエンコードされることを指定します |
| GS_1_QR | GS1 文字列形式の 2D バーコードシンボル QR |
| MAXI_CODE | データは MaxiCode バーコード仕様でエンコードされることを指定します |
| DOT_CODE | データは DotCode バーコード仕様でエンコードされることを指定します |
| AUSTRALIA_POST | Australia Post Customer BarCode を表します |
| POSTNET | データは Postnet バーコード仕様でエンコードされることを指定します |
| PLANET | データは Planet バーコード仕様でエンコードされることを指定します |
| ONE_CODE | データは USPS OneCode バーコード仕様でエンコードされることを指定します |
| RM_4_SCC | RM4SCC バーコードを表します。RM4SCC（Royal Mail 4-state Customer Code）は、英国の自動郵便仕分けプロセスで使用されます。 |
| MAILMARK | Royal Mail Mailmark バーコードを表します。 |
| DATABAR_OMNI_DIRECTIONAL | データは GS1 Databar オムニディレクショナル バーコード仕様でエンコードされることを指定します。 |
| DATABAR_TRUNCATED | データは GS1 Databar トランケート バーコード仕様でエンコードされることを指定します。 |
| DATABAR_LIMITED | GS1 DATABAR リミテッド バーコードを表します。 |
| DATABAR_EXPANDED | GS1 Databar エクスパンド バーコードを表します。 |
| DATABAR_EXPANDED_STACKED | GS1 Databar エクスパンドスタックド バーコードを表します。 |
| DATABAR_STACKED | GS1 Databar スタックド バーコードを表します。 |
| DATABAR_STACKED_OMNI_DIRECTIONAL | GS1 Databar スタックドオムニディレクショナル バーコードを表します。 |
| SINGAPORE_POST | データは Singapore Post Barcode バーコード仕様でエンコードされることを指定します |
| AUSTRALIAN_POSTE_PARCEL | データは Australian Post Domestic eParcel Barcode バーコード仕様でエンコードされることを指定します |
| SWISS_POST_PARCEL | データは Swiss Post Parcel Barcode バーコード仕様でエンコードされることを指定します。サポートされるタイプ: 国内郵便、国際郵便、追加サービス（新規） |
| PATCH_CODE | Patch code バーコードを表します |
| CODE_32 | データは Code32 バーコード仕様でエンコードされることを指定します |
| DATA_LOGIC_2_OF_5 | データは DataLogic 2 of 5 バーコード仕様でエンコードされることを指定します |
| DUTCH_KIX | データは Dutch KIX バーコード仕様でエンコードされることを指定します |
| UPCA_GS_1_CODE_128_COUPON | データは GS1-128 拡張コードバーコード仕様の UPC クーポンでエンコードされることを指定します。 |
| UPCA_GS_1_DATABAR_COUPON | データは GS1 DataBar 追加バーコード仕様の UPC クーポンでエンコードされることを指定します。 |
| CODABLOCK_F | データは Codablock-F バーコード仕様でエンコードされることを指定します。 |
| GS_1_CODABLOCK_F | データは GS1 Codablock-F バーコード仕様でエンコードされることを指定します。コードテキストは AI 用に括弧を含む必要があります。 |
| GS_1_COMPOSITE_BAR | データは GS1 Composite Bar バーコード仕様でエンコードされることを指定します。コードテキストは AI 用に括弧を含む必要があります。1D コードテキストと 2D コードテキストは '/' 記号で区切る必要があります。 |
| HIBC_CODE_39_LIC | データは `HIBC LIC Code39Standart ` バーコード仕様でエンコードされることを指定します。 |
| HIBC_CODE_128_LIC | データは `HIBC LIC Code128 ` バーコード仕様でエンコードされることを指定します。 |
| HIBC_AZTEC_LIC | データは `HIBC LIC Aztec ` バーコード仕様でエンコードされることを指定します。 |
| HIBC_DATA_MATRIX_LIC | データは `HIBC LIC DataMatrix ` バーコード仕様でエンコードされることを指定します。 |
| HIBCQRLIC | データは `HIBC LIC QR ` バーコード仕様でエンコードされることを指定します。 |
