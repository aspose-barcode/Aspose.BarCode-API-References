## HanXinErrorLevel

Reed-Solomon 誤り訂正のレベルです。低から高へ: L1、L2、L3、L4。

## 値

| 名前 | 説明 |
| --- | --- |
| なし | バーコードを囲む境界がありません |
| FRAME | バーコードを囲むフレーム |
| バー | バーコードを囲む2本の水平バー |
| FRAME_OUT | バーコードを囲むフレーム |
| BAR_OUT | バーコードを囲む2本の水平バー |
