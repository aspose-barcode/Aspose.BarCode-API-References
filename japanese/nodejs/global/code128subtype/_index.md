## Code128SubType

Code128 のサブセットタイプを含みます

## 値

| 名前 | 説明 |
| --- | --- |
| CODE_SET_A | ASCII 文字 00 から 95（0–9、A–Z および制御コード）、特殊文字、そして FNC 1–4 /// |
| CODE_SET_B | ASCII 文字 32 から 127（0–9、A–Z、a–z）、特殊文字、そして FNC 1–4 /// |
| CODE_SET_C | 00–99（単一コードポイントで2桁をエンコード）と FNC1 /// |
