## DataMatrixEccType

エンコードする ECC のタイプを指定します。

## 値

| 名前 | 説明 |
| --- | --- |
| ECC_AUTO | エンコードされた ECC タイプは、デフォルトの Reed-Solomon 誤り訂正または ECC 200 によって定義されることを指定します。 |
| ECC_000 | エンコードされた ECC タイプが ECC 000 で定義されることを指定します。 |
| ECC_050 | エンコードされた ECC タイプが ECC 050 で定義されることを指定します。 |
| ECC_080 | エンコードされた ECC タイプが ECC 080 で定義されることを指定します。 |
| ECC_100 | エンコードされた ECC タイプが ECC 100で定義されることを指定します。 |
| ECC_140 | エンコードされた ECC タイプが ECC 140 で定義されることを指定します。 |
| ECC_200 | エンコードされた ECC タイプが ECC 200 で定義されます。使用が推奨されます。 |
