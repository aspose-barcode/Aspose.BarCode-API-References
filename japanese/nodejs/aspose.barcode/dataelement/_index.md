## DataElement class

文書で使用される管轄特有のデータフィールドを表します。例: ElementID = "ZVA"、Value = "01"。

```js
new DataElement()
```

## メソッド

| 名前 | 説明 |
| --- | --- |
| [getElementID()](#getelementid) | 管轄固有フィールドを識別する 3 文字のコードです。例: "ZVA"。 |
| [getValue()](#getvalue) | フィールドに関連付けられたテキスト値で、通常は管轄の規則で定義されます。 |
| [setElementID()](#setelementid) | 管轄固有フィールドを識別する 3 文字のコードです。例: "ZVA"。 |
| [setValue()](#setvalue) | フィールドに関連付けられたテキスト値で、通常は管轄の規則で定義されます。 |

### getElementID() {#getelementid}

### getValue() {#getvalue}
