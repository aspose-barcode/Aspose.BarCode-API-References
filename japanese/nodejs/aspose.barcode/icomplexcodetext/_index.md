## IComplexCodetext class

ComplexBarcodeGenerator と共に使用される複合コードテキスト用インターフェイス。

```js
new IComplexCodetext()
```

## メソッド

| 名前 | 説明 |
| --- | --- |
| [getBarcodeType()](#getbarcodetype) | バーコードのタイプを取得します。 |
| [getConstructedCodetext()](#getconstructedcodetext) | 複合バーコード用のコードテキストを構築します |
| [initFromString(constructedCodetext)](#initfromstring) | 構築されたコードテキストでインスタンスを初期化します。 |

### getBarcodeType() {#getbarcodetype}

バーコードのタイプを取得します。

**Returns:** Barcode type.

### getConstructedCodetext() {#getconstructedcodetext}

複合バーコード用のコードテキストを構築します

**Returns:** Constructed codetext

### initFromString(constructedCodetext) {#initfromstring}

構築されたコードテキストでインスタンスを初期化します。

| パラメータ | 説明 |
| --- | --- |
| constructedCodetext | 構築された codetext。 |
