## License class

コンポーネントをライセンスするためのメソッドを提供します。

```js
new License()
```

このクラスの新しいインスタンスを初期化します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [setLicense(licensePath)](#setlicense) | コンポーネントにライセンスを付与します。 |

### setLicense(licensePath) {#setlicense}

コンポーネントにライセンスを付与します。

| パラメータ | 説明 |
| --- | --- |
| licensePath | ライセンスファイルへのパス |
