## PdfParameters class

PDF パラメータ ラッパー。基礎となる `mwObject` インスタンスを期待し、対応する getter/setter メソッドを提供し、"30_100_0_30" のような CMYK 文字列や `null` を返したり受け取ったりします。

```js
new PdfParameters(mwObject)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| mwObject | オブジェクト | – Java の PdfParameters クラスのインスタンス |
