## Code128DataPortion class

Code128 タイプのバーコードのサブタイプデータを含みます

```js
new Code128DataPortion()
```

開始コードシンボルとデコードされたコードテキストを使用して `Code128DataPortion` クラスの新しいインスタンスを作成します。

## メソッド

| 名前 | 説明 |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Code128 サブセットのタイプを取得します |
| [getData()](#getdata) | サブタイプに関連するコードテキストの部分を取得します。 |
| [toString()](#tostring) | この `Code128DataPortion` の人間が読める文字列表現を返します。 |

### getCode128SubType() {#getcode128subtype}

Code128 サブセットのタイプを取得します

**Returns:** The type of Code128 subset

### getData() {#getdata}

サブタイプに関連するコードテキストの部分を取得します。

**Returns:** The part of code text related to subtype

### toString() {#tostring}

この `Code128DataPortion` の人間が読める文字列表現を返します。

**Returns:** A string that represents this `Code128DataPortion`.
