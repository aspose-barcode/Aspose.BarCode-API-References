## SupplementParameters class

サプリメント パラメータ。Interleaved2of5、Standard2of5、EAN13、EAN8、UPCA、UPCE、ISBN、ISSN、ISMN に使用されます。

```js
new SupplementParameters()
```

## メソッド

| 名前 | 説明 |
| --- | --- |
| [getSupplementData()](#getsupplementdata) | BarCodeに続く補足データ。 |
| [getSupplementSpace()](#getsupplementspace) | メインの BarCode と補助 BarCode の間のスペース（単位値）です。 |
| [setSupplementData()](#setsupplementdata) | BarCodeに続く補足データ。 |
| [toString()](#tostring) | このSupplementParametersの人間が読める文字列表現を返します。 |

### getSupplementData() {#getsupplementdata}

BarCodeに続く補足データ。

### getSupplementSpace() {#getsupplementspace}

メインの BarCode と補助 BarCode の間のスペース（単位値）です。

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementData() {#setsupplementdata}

BarCodeに続く補足データ。

### toString() {#tostring}

このSupplementParametersの人間が読める文字列表現を返します。

**Returns:** A string that represents this SupplementParameters.
