## RecognitionAbortedException class

BarCodeReader での認識中にタイムアウトが超過した際にスローされる認識中止例外を表します。

```js
new RecognitionAbortedException(message, executionTime)
```

指定された認識中止メッセージでクラスの新しいインスタンスを初期化します。

| パラメータ | 説明 |
| --- | --- |
| メッセージ | 例外のエラーメッセージです。 |
| executionTime | 現在の認識セッションの実行時間です。 |
