## BarcodeSettings class

主要な BarCode デコードパラメーター。認識されたデータに影響を与えるパラメーターを含みます。

BarcodeSettings 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| checksum_validation |  |
| strip_fnc | コードテキストから FNC1、FNC2、FNC3 文字を除去します。デフォルト値は false です。 |
| only_requested_types | 認識のために明示的に指定されたバーコードタイプのみを返します。 <br/>            有効にすると、他の互換または同等のタイプとして認識されたバーコードは除外されます。 <br/>            デフォルト値は false です。 |
| detect_encoding | Unicode コードセットのコードテキストエンコーディングをエンジンが検出するよう強制するフラグです。デフォルト値は true です。 |
| australia_post | AustraliaPost のデコードパラメータを取得します |
| calculate_symbol_quality | 認識中にバーコードシンボルの品質を計算するかどうかを示す値を取得または設定します。 |
