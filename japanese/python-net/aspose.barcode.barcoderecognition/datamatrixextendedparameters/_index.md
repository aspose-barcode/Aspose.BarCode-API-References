## DataMatrixExtendedParameters class

DataMatrix 認識バーコードの特別データを格納します。

DataMatrixExtendedParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_empty | すべてのパラメータがデフォルト値のみであるかどうかをテストします |
| structured_append_barcodes_count | 取得する DataMatrix 構造化付加モードのバーコード数。デフォルト値は -1 です。カウントは 1 から 35 の値でなければなりません。 |
| structured_append_barcode_id | 取得する DataMatrix 構造化付加モードのバーコードの ID。ID は 1 から開始し、バーコード数以下である必要があります。デフォルト値は -1 です。 |
| structured_append_file_id | 取得する DataMatrix 構造化付加モードのバーコードの ID。ID は 1 から開始し、バーコード数以下である必要があります。デフォルト値は -1 です。 |
| is_reader_programming | コードがバーコードリーダーの初期化または再プログラミングの指示としてデータを解釈させるために使用されるかどうかを示します。<br/>            デフォルト値は false です。 |
