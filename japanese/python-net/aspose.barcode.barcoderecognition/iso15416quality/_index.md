## Iso15416Quality class

1次元バーコードに対してISO/IEC 15416規格に基づいて計算されたバーコード品質等級を保存します。

Iso15416Quality 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| grade | ISO/IEC 15416 に従って、バーコード全体の品質グレードを取得します。 |
| decode | 参照デコードアルゴリズムを使用してバーコードをデコードできるかどうかを示すデコードグレードを取得します。 |
| symbol_contrast | 最大反射率と最小反射率の差に基づくシンボルコントラストグレードを取得します。 |
| minimum_reflectance | 最も暗いバーの反射率に基づいて、最小反射率グレードを取得します。 |
| minimum_edge_contrast | 隣接するバーとスペース間の最小の反射率差に基づいて、最小エッジコントラストグレードを取得します。 |
| modulation | バーコード全体のエッジコントラストの均一性に基づいて、変調グレードを取得します。 |
| defects | バーとスペース内の反射率の不規則性に基づいて、欠陥グレードを取得します。 |
| decodability | バーとスペースの幅の正確さに基づいて、デコード可能性グレードを取得します。 |
