## AztecExtendedParameters class

Aztec 認識バーコードの特別データを格納します。

AztecExtendedParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_empty | すべてのパラメータがデフォルト値のみであるかどうかをテストします |
| structured_append_barcodes_count | Aztec の構造化追加モードのバーコード数を取得します。デフォルト値は 0 です。カウントは 1 から 26 の範囲でなければなりません。 |
| structured_append_barcode_id | Aztec の構造化追加モードのバーコード ID を取得します。ID は 1 から開始し、バーコード数以下である必要があります。デフォルト値は 0 です。 |
| structured_append_file_id | Aztec の構造化追加モードのファイル ID を取得します。デフォルト値は空文字列です。 |
| is_reader_initialization | コードがバーコードリーダーの初期化または再プログラミングの指示としてデータを解釈させるために使用されるかどうかを示します。<br/>            デフォルト値は false です。 |
