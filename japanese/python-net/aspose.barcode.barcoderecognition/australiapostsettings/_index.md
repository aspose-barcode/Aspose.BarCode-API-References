## AustraliaPostSettings class

AustraliaPost デコードパラメーター。AustraliaPost シンボルで認識されたデータに影響を与えるパラメーターを含みます。

AustraliaPostSettings 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| customer_information_interpreting_type | AustralianPost バーコードの顧客情報の解釈タイプを取得または設定します。デフォルトは CustomerInformationInterpretingType.Other です。 |
| ignore_ending_filling_patterns_for_c_table | CTable方式でデコード中に Customer Information Field の最後のフィリングパターンを無視させるフラグです。<br/>            CTable エンコーディング方式はエンコーディングテーブルにギャップがなく、フィリングパターンのシーケンス "333" は文字 "z" としてデコードされます。 |
| customer_information_decoder | AustraliaPost シンボロジーで使用される Customer Information Field デコード用の公開インターフェイスです。 |
