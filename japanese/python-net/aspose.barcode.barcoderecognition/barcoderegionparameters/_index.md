## BarCodeRegionParameters class

認識されたバーコードの領域とバーコード角度を表します。

BarCodeRegionParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| quadrangle | バーコード領域を囲む [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) を取得します |
| angle | バーコードの角度 (0-360) を取得します。 |
| points | バーコード領域を囲む [Point](/barcode/python-net/aspose.drawing/point/) の配列を取得します |
| rectangle | バーコード領域を取得します |
