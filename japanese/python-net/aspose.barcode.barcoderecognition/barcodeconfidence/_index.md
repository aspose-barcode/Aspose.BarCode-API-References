## BarCodeConfidence enumeration

認識信頼度レベルを含みます

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | コードテキストが正しく認識されなかった、またはバーコードが偽の可能性があると検出された場合の認識信頼度 |
| MODERATE | チェックサムが弱い、または存在しないバーコード（主に1次元バーコード）の認識信頼度です。コードテキストに誤認識が含まれる可能性があり、<br/>            偽の認識が行われることもあります。 |
| STRONG | Reed–Solomon などの BCH コードで確認された認識信頼度です。読み取られたコードテキストにエラーや偽の認識があってはなりません。 |
