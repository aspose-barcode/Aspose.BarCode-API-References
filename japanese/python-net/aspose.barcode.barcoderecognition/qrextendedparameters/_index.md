## QRExtendedParameters class

認識されたバーコードのQR Structured Append情報を保存します

QRExtendedParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_empty | すべてのパラメータがデフォルト値のみであるかどうかをテストします |
| structured_append_mode_bar_codes_quantity | QR 構造化追加モードのバーコード数量を取得します。デフォルト値は -1 です。 |
| structured_append_mode_bar_code_index | QR 構造化追加モードのバーコードのインデックスを取得します。インデックスは 0 から始まります。デフォルト値は -1 です。 |
| structured_append_mode_parity_data | QR 構造化追加モードのパリティデータを取得します。デフォルト値は -1 です。 |
| version | 認識された QR コードのバージョン。Version1 から Version40 まで。 |
| micro_qr_version | 認識された MicroQR コードのバージョン。M1 から M4 まで。 |
| rect_micro_qr_version | 認識された RectMicroQR コードのバージョン。R7x43 から R17x139 まで。 |
| error_level | 認識されたバーコードの Reed-Solomon 誤り訂正レベル。低から高へ: LevelL, LevelM, LevelQ, LevelH。 |
