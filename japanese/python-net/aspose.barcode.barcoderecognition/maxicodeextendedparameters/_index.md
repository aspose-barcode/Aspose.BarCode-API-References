## MaxiCodeExtendedParameters class

認識されたバーコードのMaxiCode追加情報を保存します

MaxiCodeExtendedParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_empty | すべてのパラメータがデフォルト値のみであるかどうかをテストします |
| モード | MaxiCode エンコードモードを取得または設定します。<br/>            デフォルト値: Mode4 |
| structured_append_mode_barcode_id | 構造化付加モードでの MaxiCode バーコード ID を取得または設定します。<br/>            デフォルト値: 0 |
| structured_append_mode_barcodes_count | 構造化付加モードでの MaxiCode バーコード数を取得または設定します。<br/>            デフォルト値: -1 |
