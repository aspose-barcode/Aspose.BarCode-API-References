## Pdf417ExtendedParameters class

認識されたバーコードのMacroPdf417メタデータ情報を保存します

Pdf417ExtendedParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_empty | すべてのパラメータがデフォルト値のみであるかどうかをテストします |
| macro_pdf_417_file_id | バーコードのファイル ID を取得します（MacroPdf417 のみ利用可能）。 |
| macro_pdf_417_segment_id | バーコードのセグメント ID を取得します、MacroPdf417 のみ利用可能。 |
| macro_pdf_417_segments_count | macro pdf417 バーコードのセグメント数を取得します。デフォルト値は -1 です。 |
| macro_pdf_417_file_name | Macro PDF417 ファイル名（オプション）。 |
| macro_pdf_417_file_size | Macro PDF417 ファイルサイズ（オプション）。 |
| macro_pdf_417_sender | Macro PDF417 送信者名（オプション）。 |
| macro_pdf_417_addressee | Macro PDF417 受取人名（オプション）。 |
| macro_pdf_417_time_stamp | Macro PDF417 タイムスタンプ（オプション）。 |
| macro_pdf_417_checksum | Macro PDF417 チェックサム（オプション）。 |
| macro_pdf_417_terminator | セグメントが Macro PDF417 ファイルの最後のセグメントかどうかを示します。 |
| is_reader_initialization | シンボル内に含まれるデータをリーダーの初期化用プログラミングとして解釈するようリーダーに指示するために使用されます。 |
| is_linked | バーコードが 1D バーコードにリンクされる必要があることを示すフラグです。 |
| is_code_128_emulation | 908、909、910、または 911 の Code 128 エミュレーションコードワードでエンコードされた MicroPdf417 バーコードであることを示すフラグです。 |
