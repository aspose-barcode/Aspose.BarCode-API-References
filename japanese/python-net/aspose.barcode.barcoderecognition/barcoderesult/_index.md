## BarCodeResult class

認識されたバーコードデータを格納します。例として [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/) タイプ、文字列 codetext、<br/>            [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) 領域、その他のパラメーター

BarCodeResult 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| BarCodeResult(result) | BarCodeResult クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| reading_quality | 読み取り品質を取得します。1D および郵便バーコードで機能します。 |
| confidence | 認識されたバーコードの信頼度レベルを取得します |
| code_text | コードテキストを取得します |
| code_bytes | エンコードされたコードバイトを取得します |
| code_type | バーコードのタイプを取得します |
| code_type_name | バーコードタイプの名前を取得します |
| 領域 | バーコード領域を取得します |
| 拡張 | 認識されたバーコードの拡張パラメータを取得します |
| iso_symbol_quality | 認識されたバーコードの ISO/IEC シンボル品質評価結果を取得します。 |
## メソッド

| :- | :- |
| get_code_text(encoding) | エンコーディングを使用してコードテキストを取得します。 |
