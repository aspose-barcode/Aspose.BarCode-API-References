## XDimensionMode enumeration



## Members
| メンバー名 | 説明 |
| :- | :- |
| AUTO | XDimension の値は AI (SVM) によって検出されます。現在は Normal と同じです。 |
| SMALL | BarcodeQuality の品質で、1 ピクセル以上の小さな XDimension を持つバーコードを検出します。 |
| NORMAL | BarcodeQuality の品質、または高品質バーコードで、2 ピクセル以上の標準的な XDimension を持つバーコードを検出します。 |
| LARGE | 高解像度カメラで撮影された BarcodeQuality の品質で、大きな XDimension を持つバーコードを検出します。 |
| USE_MINIMAL_X_DIMENSION | BarcodeQuality の品質で、MinimalXDimension に設定されたサイズのバーコードを検出します。 |
