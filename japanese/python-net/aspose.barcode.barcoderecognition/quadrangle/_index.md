## Quadrangle class

4つの[Point](/barcode/python-net/aspose.drawing/point/)をセットで保存し、[Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/)領域を表します。

Quadrangle 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Quadrangle() | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) クラスの新しい空のインスタンスを初期化します。 |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Quadrangle クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| left_top | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 領域の左上隅の [Point](/barcode/python-net/aspose.drawing/point/) を取得します |
| right_top | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 領域の右上隅の [Point](/barcode/python-net/aspose.drawing/point/) を取得します |
| right_bottom | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 領域の右下隅の [Point](/barcode/python-net/aspose.drawing/point/) を取得します |
| left_bottom | [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) 領域の左下隅の [Point](/barcode/python-net/aspose.drawing/point/) を取得します |
| is_empty | この [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) のすべての [Point](/barcode/python-net/aspose.drawing/point/) がゼロの値かどうかをテストします。 |
| bounding_rectangle | この [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) を囲む [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) を取得します |
| EMPTY | プロパティが未初期化のままの [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) クラスを表します。 |
