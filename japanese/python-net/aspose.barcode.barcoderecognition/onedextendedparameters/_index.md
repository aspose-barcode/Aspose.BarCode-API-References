## OneDExtendedParameters class

1次元で認識されたバーコードのコードテキストやチェックサムなどの特殊データを保存します

OneDExtendedParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_empty | すべてのパラメータがデフォルト値のみであるかどうかをテストします |
| value | チェックサムなしで 1D バーコードのコードテキストを取得します。 |
| check_sum | 1D バーコードのチェックサムを取得します。 |
