## CodabarExtendedParameters class

認識されたバーコードの Codabar 追加情報を格納します。

CodabarExtendedParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_empty | すべてのパラメータがデフォルト値のみであるかどうかをテストします |
| start_symbol | Codabar の開始シンボルを取得または設定します。<br/>            デフォルト値: CodabarSymbol.A |
| stop_symbol | Codabar の停止シンボルを取得または設定します。<br/>            デフォルト値: CodabarSymbol.A |
