## AustraliaPostCustomerInformationDecoder class

AustraliaPost シンボルで使用される顧客情報フィールドのデコード用パブリックインターフェイス。実装はユーザーが提供する必要があります。

AustraliaPostCustomerInformationDecoder 型は次のメンバーを公開します：
## メソッド
| 名前 | 説明 |
| :- | :- |
| decode(customer_information_field) | AustraliaPost シンボルから顧客情報フィールドをデコードします。<br/>            NTable および CTable エンコーディングからの異なるデータ解釈に使用できます。<br/>            データは 0、1、2、または 3 のバー値の行として提供されます。 |
