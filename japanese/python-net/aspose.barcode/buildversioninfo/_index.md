## BuildVersionInfo class

現在のビルドバージョン情報を含みます。

BuildVersionInfo 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| ASSEMBLY_VERSION | アセンブリ バージョンです。 |
| FILE_VERSION | ファイル バージョン。 |
| PRODUCT | 製品のタイトル。 |
| PRODUCT_MAJOR | 主要な製品バージョン。 |
| PRODUCT_MINOR | 製品のマイナーバージョン。 |
| RELEASE_DATE | 製品のリリース日。 |
