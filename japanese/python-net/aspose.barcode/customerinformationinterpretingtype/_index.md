## CustomerInformationInterpretingType enumeration

AustralianPost BarCodeの顧客情報の解釈タイプ（CTable、NTable、またはOther）を定義します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| C_TABLE | CTable を使用して顧客情報を解釈します。A..Z、a..z、1..9、スペース、および # 記号が使用可能です。 |
| N_TABLE | NTable を使用して顧客情報を解釈します。数字のみ使用可能です。 |
| OTHER | 顧客情報を解釈しません。0、1、2、または 3 記号のみが使用可能です。 |
