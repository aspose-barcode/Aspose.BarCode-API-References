1D/2D バーコードの生成および描画のためのツールを含みます。

## クラス
| クラス | 説明 |
| :- | :- |
| [BuildVersionInfo](/barcode/python-net/aspose.barcode/buildversioninfo/) | 現在のビルドバージョン情報を含みます。 |
| [License](/barcode/python-net/aspose.barcode/license/) | コンポーネントをライセンスするためのメソッドを提供します。 |
| [Metered](/barcode/python-net/aspose.barcode/metered/) | メーターキーを設定するためのメソッドを提供します。 |
| [XmlSerializationAttribute](/barcode/python-net/aspose.barcode/xmlserializationattribute/) | XMLエンティティジェネレータ用の属性を表します。 |

| 列挙型 | 説明 |
