## ITFParameters class

ITF パラメータ。

ITFParameters型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| border_thickness | ITF のボーダー（ベアラーバー）の厚さを単位値で取得または設定します。<br/>            デフォルト値: 12pt. |
| border_type | ITF バーコードのボーダータイプです。<br/>            デフォルト値: ITF14BorderType.Bar. |
| quiet_zone_coef | xDimension における静寂領域のサイズです。<br/>            デフォルト値: 10。つまり、xDimension が 2px の場合、静寂領域は 20px になります。 |
