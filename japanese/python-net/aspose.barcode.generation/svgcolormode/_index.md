## SvgColorMode enumeration

svg ファイルの塗りつぶし色の可能なモードです。RGB がデフォルトで SVG 1.1 でサポートされています。<br/>            RGBA、HSL、HSLA は SVG 2.0 標準で許可されています。<br/>            RGB でも不透明度は "fill-opacity" パラメータで設定されます。

## Members
| メンバー名 | 説明 |
| :- | :- |
| RGB | RGBモード、例: fill="#ff5511" fill-opacity="0.73"。デフォルトモード。 |
| RGBA | RGBAモード、例: fill="rgba(255, 85, 17, 0.73)" |
| HSL | HSLモード、例: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | HSLAモード、例: fill="hsla(30, 50%, 70%, 0.8)" |
