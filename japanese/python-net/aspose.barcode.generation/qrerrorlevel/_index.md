## QRErrorLevel enumeration

Reed-Solomon 誤り訂正のレベルです。低から高へ: LevelL, LevelM, LevelQ, LevelH。

## Members
| メンバー名 | 説明 |
| :- | :- |
| LEVEL_L | エラー訂正レベル L は QR および MicroQR バーコードに適用できます。<br/>            コードテキストの 7% を復元できます。 |
| LEVEL_M | エラー訂正レベル M は QR バーコード、RectMicroQR バーコード、およびバージョン M2 から M4 の MicroQR バーコードに適用できます。<br/>            コードテキストの 15% を復元できます。 |
| LEVEL_Q | エラー訂正レベル Q は QR バーコードとバージョン M4 の MicroQR バーコードに適用できます。<br/>            コードテキストの 25% を復元できます。 |
| LEVEL_H | エラー訂正レベル H は QR および RectMicroQR バーコードに適用できます。<br/>            コードテキストの 30% を復元できます。 |
