## SupplementParameters class

補足パラメータ。Interleaved2of5、Standard2of5、EAN13、EAN8、UPCA、UPCE、ISBN、ISSN、ISMN 用です。

SupplementParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| supplement_data | BarCode の後に続く補足データ。 |
| supplement_space | メインの BarCode とサブの BarCode の間のスペース（[Unit](/barcode/python-net/aspose.barcode.generation/unit/) の値）。 |
