## PatchCodeParameters class

PatchCode パラメータ。

PatchCodeParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| extra_barcode_text | PatchCode がページモードで生成される際の、追加 QR バーコードのコードテキストを指定します。 |
| format | PatchCode の形式。単一の PatchCode を生成するには PatchOnly を選択します。PatchCodes を境界として持つ Patch ページを生成するにはページ形式を使用します。<br/>            デフォルト値: PatchFormat.PatchOnly |
| patch_format | PatchCode の形式。単一の PatchCode を生成するには PatchOnly を選択します。PatchCodes を境界として持つ Patch ページを生成するにはページ形式を使用します。<br/>            デフォルト値: PatchFormat.PatchOnly |
