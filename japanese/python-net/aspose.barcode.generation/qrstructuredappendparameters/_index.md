## QrStructuredAppendParameters class

QR 構造化追加パラメータ。

QrStructuredAppendParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| parity_byte | QR 構造付加モードのパリティデータを取得または設定します。 |
| sequence_indicator | QR 構造付加モードのバーコードのインデックスを取得または設定します。インデックスは 0 から開始します。 |
| total_count | QR 構造付加モードのバーコード数を取得または設定します。最大値は 16 です。 |
