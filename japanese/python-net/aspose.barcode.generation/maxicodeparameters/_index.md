## MaxiCodeParameters class

MaxiCode パラメータ。

MaxiCodeParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| モード | MaxiCode エンコードモードを取得または設定します。 |
| encode_mode | MaxiCode エンコードモードを取得または設定します。 <br/>            デフォルト値: Auto. |
| eci_encoding | ECI エンコーディングを取得または設定します。 MaxiCodeEncodeMode が Auto の場合に使用されます。<br/>            デフォルト値: ISO-8859-1 |
| structured_append_mode_barcode_id | 構造化追加モードでの MaxiCode バーコード ID を取得または設定します。 <br/>            ID は 1 から 8 の間の値でなければなりません。 <br/>            デフォルト値: 0 |
| structured_append_mode_barcodes_count | 構造化追加モードでの MaxiCode バーコード数を取得または設定します。 <br/>            カウント数は 2 から 8 の間の値でなければなりません（最大バーコード数）。<br/>            デフォルト値: -1 |
| aspect_ratio | 2D バーコードモジュールの高さ/幅比率。 |
