## AutoSizeMode enumeration

自動サイズモードのさまざまなタイプを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | 自動リサイズは無効です。 |
| NEAREST | バーコードを ImageWidth と ImageHeight プロパティで指定された最も近い最小サイズにリサイズします。<br/>            デフォルトのアスペクト比を保持します。 |
| INTERPOLATION | バーコードを指定されたサイズにリサイズします。<br/>            サイズは ImageWidth と ImageHeight プロパティで指定できます。<br/>            スケーリング後、生成されたバーコードが無効（読み取れない）になる可能性があります。 |
