## MaxiCodeMode enumeration

MaxiCode バーコードのエンコーディングモード。

## Members
| メンバー名 | 説明 |
| :- | :- |
| MODE2 | Mode 2 は最初のメッセージで郵便情報をエンコードし、2 番目のメッセージでデータをエンコードします。<br/>            郵便番号は 9 桁です（米国でのみ使用）。 |
| MODE3 | Mode 3は最初のメッセージに郵便情報を、2番目のメッセージにデータをエンコードします。 <br/>            6文字の英数字郵便コードを持ち、世界で使用されています。 |
| MODE4 | Mode 4は最初と2番目のメッセージにデータをエンコードし、短いECC訂正を行います。 |
| MODE5 | Mode 5は最初と2番目のメッセージにデータをエンコードし、長いECC訂正を行います。 |
| MODE6 | Mode 6は最初と2番目のメッセージにデータをエンコードし、短いECC訂正を行います。<br/>            デバイスのエンコードに使用されます。 |
