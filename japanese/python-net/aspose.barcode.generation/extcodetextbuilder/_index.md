## ExtCodetextBuilder class

| 名前 | 説明 |
| :- | :- |
| clear() | 拡張コードテキスト項目をクリアします |
| add_plain_codetext(codetext) | プレーンコードテキストを拡張コードテキスト項目に追加します |
| add_eci_codetext(eci_encoding, codetext) | 拡張チャネル識別子付きコードテキストを追加します |
| get_extended_codetext() | 生成項目リストから拡張コードテキストを生成する |
