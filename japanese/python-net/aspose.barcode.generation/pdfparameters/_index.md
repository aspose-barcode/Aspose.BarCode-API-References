## PdfParameters class

PDF パラメータ。

PdfParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| cmyk_bar_color | Nullable。バーコードのCMYKカラー値。null は CMYK カラーが使用されず、代わりに通常の RGB カラーが使用されます。 |
| cmyk_back_color | Nullable。バックカラーのCMYK値。null は CMYK カラーが使用されず、代わりに通常の RGB カラーが使用されます。 |
| cmyk_codetext_color | Nullable。コードテキストのCMYKカラー値。null は CMYK カラーが使用されず、代わりに通常の RGB カラーが使用されます。 |
| cmyk_caption_above_color | Nullable。上部キャプションのCMYKカラー値。null は CMYK カラーが使用されず、代わりに通常の RGB カラーが使用されます。 |
| cmyk_caption_below_color | Nullable。下部キャプションのCMYKカラー値。null は CMYK カラーが使用されず、代わりに通常の RGB カラーが使用されます。 |
| is_text_as_path | テキストの代わりにパスを使用しますか（Unicode文字が表示されない場合に使用）<br/>            デフォルト値: false. |
