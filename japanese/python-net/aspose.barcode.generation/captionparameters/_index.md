## CaptionParameters class

キャプションパラメータ。

CaptionParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| text | キャプションテキスト。<br/>            デフォルト値: 空文字列。 |
| font | キャプションフォント。<br/>            デフォルト値: Arial 8pt regular. |
| visible | キャプションテキストの表示可否。<br/>            デフォルト値: false. |
| text_color | キャプションテキストの色。<br/>            デフォルト値: Color.Black. |
| padding | キャプションの余白。<br/>            CaptionAbove のデフォルト値: 5pt 5pt 0 5pt.<br/>            CaptionBelow のデフォルト値: 0 5pt 5pt 5pt. |
| 配置 | キャプションテストの水平配置。<br/>            デフォルト値: StringAlignment.Center. |
| no_wrap | テキスト内の単語ラップ（改行）を指定します。<br/>            デフォルト値: false. |
