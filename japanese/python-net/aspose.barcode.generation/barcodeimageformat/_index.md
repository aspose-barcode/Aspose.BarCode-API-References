## BarCodeImageFormat enumeration

画像のファイル形式を指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| BMP | ビットマップ（BMP）画像フォーマットを指定します。 |
| GIF | Graphics Interchange Format（GIF）画像フォーマットを指定します。 |
| JPEG | Joint Photographic Experts Group（JPEG）画像フォーマットを指定します。 |
| PNG | W3C Portable Network Graphics（PNG）画像フォーマットを指定します。 |
| TIFF | Tagged Image File Format（TIFF）画像フォーマットを指定します。 |
| TIFF_IN_CMYK | CMYK カラーモデルの Tagged Image File Format（TIFF）画像フォーマットを指定します。 <br/>            (Windows プラットフォームでのみサポートされ、*nix プラットフォームでは Tiff として保存されます) |
| EMF | Enhanced Metafile（EMF）画像フォーマットを指定します。<br/>            (Windows プラットフォームでのみサポートされ、*nix プラットフォームでは PNG として保存されます) |
| SVG | Scalable Vector Graphics（SVG）画像フォーマットを指定します。 |
| PDF | Portable Document Format（PDF）画像フォーマットを指定します。 |
