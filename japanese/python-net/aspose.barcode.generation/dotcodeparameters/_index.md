## DotCodeParameters class

DotCode パラメータ。

DotCodeParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| aspect_ratio | 2D バーコードモジュールの高さ/幅比率。 |
| encode_mode | DotCode エンコードモードを識別します。 <br/>            デフォルト値: Auto. |
| is_reader_initialization | コードがバーコードリーダーの初期化または再プログラミングの指示としてデータを解釈させるために使用されるかどうかを示します。<br/>            デフォルト値は false です。 |
| structured_append_mode_barcode_id | DotCode 構造化付加モードバーコードの ID を識別します。ID は 1 から開始し、バーコード数以下である必要があります。デフォルト値は -1 です。 |
| structured_append_mode_barcodes_count | DotCode 構造化付加モードのバーコード数を識別します。デフォルト値は -1 です。カウントは 1 から 35 の範囲でなければなりません。 |
| eci_encoding | ECI エンコーディングを識別します。DotCodeEncodeMode が Auto のときに使用されます。<br/>            デフォルト値: ISO-8859-1 |
| 行 | 行数を識別します。DotCode シンボルの行数と列数の合計は奇数でなければなりません。行数は少なくとも 5 である必要があります。<br/>            デフォルト値: -1 |
| 列 | 列数を識別します。DotCode シンボルの行数と列数の合計は奇数でなければなりません。列数は少なくとも 5 である必要があります。<br/>            デフォルト値: -1 |
