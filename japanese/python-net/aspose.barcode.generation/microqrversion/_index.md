## MicroQRVersion enumeration

MicroQR Code のバージョン。<br/>            M1 から M4 まで。

## Members
| メンバー名 | 説明 |
| :- | :- |
| AUTO | MicroQRに最適なバージョンを自動的に選択することを指定します。<br/>            これがデフォルト値です。 |
| M1 | 11×11モジュールのMicro QR用バージョンM1を指定します。 |
| M2 | 13×13モジュールのMicro QR用バージョンM2を指定します。 |
| M3 | 15×15モジュールのMicro QR用バージョンM3を指定します。 |
| M4 | 17×17モジュールのMicro QR用バージョンM4を指定します。 |
