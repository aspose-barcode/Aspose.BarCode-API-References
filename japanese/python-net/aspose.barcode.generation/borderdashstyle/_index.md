## BorderDashStyle enumeration

破線の枠線スタイルを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| SOLID | 実線を指定します。 |
| DASH | 破線で構成された線を指定します。 |
| DOT | 点線で構成された線を指定します。 |
| DASH_DOT | 破線と点線が交互に繰り返されるパターンの線を指定します。 |
| DASH_DOT_DOT | 破線と点線が2つ続くパターンが繰り返される線を指定します。 |
