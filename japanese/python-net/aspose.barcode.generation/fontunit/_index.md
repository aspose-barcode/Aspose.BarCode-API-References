## FontUnit class

テキストの特定のフォーマットを定義します。フォントファミリー、サイズ、スタイル属性を含み、<br/>            サイズは Unit 値プロパティ内です。

FontUnit 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| family_name | このフォントのフェイス名を取得または設定します。 |
| style | この FontUnit のスタイル情報を取得または設定します。 |
| size | この FontUnit のサイズを単位値で取得または設定します。 |
