## HanXinParameters class

Han Xin パラメータ。

HanXinParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| version | HanXinコードのバージョン。<br/>            Han XinコードのVersion01からVersion84まで。<br/>            デフォルト値はVersion.Autoです。 |
| error_level | Han Xinバーコードのリード・ソロモン誤り訂正レベル。<br/>             低から高: L1、L2、L3、L4。ErrorLevelを参照してください。 |
| encode_mode | HanXinエンコーディングモード。<br/>            デフォルト値: EncodeMode.Mixed。 |
| eci_encoding | 拡張チャネル解釈識別子。<br/>            バーコードリーダーにシンボル内のデータをエンコードする際に使用される参照の詳細を伝えるために使用されます。<br/>            現在の実装は、すべてのよく知られた文字セットエンコーディングを含んでいます。 |
