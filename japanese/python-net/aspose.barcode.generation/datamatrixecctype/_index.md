## DataMatrixEccType enumeration

エンコードする ECC のタイプを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| ECC_AUTO | エンコードされた ECC タイプは、デフォルトの Reed-Solomon 誤り訂正または ECC 200 によって定義されることを指定します。 |
| ECC000 | エンコードされた ECC タイプは ECC 000 によって定義されることを指定します。 |
| ECC050 | エンコードされた ECC タイプは ECC 050 によって定義されることを指定します。 |
| ECC080 | エンコードされた ECC タイプは ECC 080 によって定義されることを指定します。 |
| ECC100 | エンコードされた ECC タイプは ECC 100 によって定義されることを指定します。 |
| ECC140 | エンコードされた ECC タイプは ECC 140 によって定義されることを指定します。 |
| ECC200 | エンコードされたEccタイプがECC 200として定義されていることを指定します。使用することを推奨します。 |
