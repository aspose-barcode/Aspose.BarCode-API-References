## EncodeTypes class

エンコードするバーコードのタイプを指定します。

EncodeTypes 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| all_encode_types | 利用可能なすべてのシンボロジーでデータがチェックされることを指定します。 |
| NONE | エンコードタイプが未指定です。 |
| CODABAR | データを CODABAR バーコード仕様でエンコードすることを指定します。 |
| CODE11 | データを CODE 11 バーコード仕様でエンコードすることを指定します。 |
| CODE39 | データを Code 39 基本文字セットバーコード仕様（ISO/IEC 16388）でエンコードすることを指定します。 |
| CODE_39_FULL_ASCII | データを Code 39 フル ASCII 文字セットバーコード仕様（ISO/IEC 16388）でエンコードすることを指定します。 |
| CODE93 | データを CODE 93 バーコード仕様でエンコードすることを指定します。 |
| CODE128 | データを CODE 128 バーコード仕様でエンコードすることを指定します。 |
| GS1_CODE_128 | データを GS1 Code 128 バーコード仕様でエンコードすることを指定します。コードテキストは AI 用に括弧を含む必要があります。 |
| EAN8 | データを EAN-8 バーコード仕様でエンコードすることを指定します。 |
| EAN13 | データを EAN-13 バーコード仕様でエンコードすることを指定します。 |
| EAN14 | データを EAN14 バーコード仕様でエンコードすることを指定します。 |
| SCC14 | データを SCC14 バーコード仕様でエンコードすることを指定します。 |
| SSCC18 | データを SSCC18 バーコード仕様でエンコードすることを指定します。 |
| UPCA | データを UPC-A バーコード仕様でエンコードすることを指定します。 |
| UPCE | データを UPC-E バーコード仕様でエンコードすることを指定します。 |
| ISBN | データを ISBN バーコード仕様でエンコードすることを指定します。 |
| ISSN | データを ISSN バーコード仕様でエンコードすることを指定します。 |
| ISMN | データを ISMN バーコード仕様でエンコードすることを指定します。 |
| STANDARD_2OF_5 | データを Standard 2 of 5 バーコード仕様でエンコードすることを指定します。 |
| INTERLEAVED_2OF_5 | データを INTERLEAVED 2 of 5 バーコード仕様でエンコードすることを指定します。 |
| MATRIX_2OF_5 | Matrix 2 of 5 バーコードを表します。 |
| ITALIAN_POST25 | Italian Post 25 バーコードを表します。 |
| IATA2OF_5 | IATA 2 of 5 バーコードを表します。IATA（International Air Transport Association）はこのバーコードを航空貨物の管理に使用します。 |
| ITF14 | データを ITF14 バーコード仕様でエンコードすることを指定します |
| ITF6 | ITF-6 バーコードを表します。 |
| MSI | データを MSI Plessey バーコード仕様でエンコードすることを指定します |
| VIN | VIN（Vehicle Identification Number）バーコードを表します。 |
| DEUTSCHE_POST_IDENTCODE | Deutsch Post バーコードを表します。このシンボルは Identcode、CodeIdentcode、German Postal 2 of 5 Identcode とも呼ばれます、<br/>            Deutsch Post AG Identcode、Deutsch Frachtpost Identcode、Deutsch Post AG（DHL） |
| DEUTSCHE_POST_LEITCODE | Deutsch Post Leitcode バーコードを表します。また、German Postal 2 of 5 Leitcode、CodeLeitcode、Leitcode、Deutsch Post AG（DHL）としても知られています。 |
| OPC | OPC（Optical Product Code）バーコードを表します。また、VCA Barcode VCA OPC、Vision Council of America OPC Barcode とも呼ばれます。 |
| PZN | PZN バーコードを表します。このシンボルは Pharmacy central number、Pharmazentralnummer とも呼ばれます。PZN7 と PZN8 がサポートされています。<br/>            PZN7 は 6 桁以下の数字から生成されます（例："123456"）。PZN8 は 7 桁以上の数字から生成されます（例："1234567"）。<br/>            指定された最後のチェックサム桁は無視され、バーコードエンジンによって生成されます。 |
| CODE_16K | Code 16K バーコードを表します。 |
| PHARMACODE | Pharmacode バーコードを表します。 |
| DATA_MATRIX | 2D バーコードシンボル DataMatrix |
| QR | データを QR Code バーコード仕様でエンコードすることを指定します |
| AZTEC | データを Aztec バーコード仕様でエンコードすることを指定します |
| GS1_AZTEC | データを GS1 Aztec バーコード仕様でエンコードすることを指定します。コードテキストは AI のために丸括弧を含む必要があります。 |
| PDF417 | データを Pdf417 バーコード仕様でエンコードすることを指定します |
| MACRO_PDF417 | データを MacroPdf417 バーコード仕様でエンコードすることを指定します |
| GS1_DATA_MATRIX | GS1 文字列形式の 2D バーコードシンボル DataMatrix |
| MICRO_PDF417 | データを MicroPdf417 バーコード仕様でエンコードすることを指定します |
| GS1_MICRO_PDF_417 | データを GS1MicroPdf417 バーコード仕様でエンコードすることを指定します |
| GS1QR | GS1 文字列形式の 2D バーコードシンボル QR |
| MAXI_CODE | データを MaxiCode バーコード仕様でエンコードすることを指定します |
| DOT_CODE | データを DotCode バーコード仕様でエンコードすることを指定します |
| HAN_XIN | データを Han Xin バーコード仕様でエンコードすることを指定します |
| GS1_HAN_XIN | GS1 文字列形式の 2D バーコードシンボル HanXin |
| MICRO_QR | データを MicroQR Code バーコード仕様でエンコードすることを指定します |
| RECT_MICRO_QR | データが RectMicroQR (rMQR) Code バーコード仕様でエンコードされることを指定します |
| AUSTRALIA_POST | オーストラリアポスト カスタマー BarCode を表します |
| JAPAN_POST | 日本郵便 BarCode を表します |
| POSTNET | データが Postnet バーコード仕様でエンコードされることを指定します |
| PLANET | データが Planet バーコード仕様でエンコードされることを指定します |
| ONE_CODE | データが USPS OneCode バーコード仕様でエンコードされることを指定します |
| RM4SCC | RM4SCC バーコードを表します。RM4SCC (Royal Mail 4-state Customer Code) は英国の自動メール仕分けプロセスで使用されます。 |
| MAILMARK | Royal Mail Mailmark バーコードを表します。 |
| DATABAR_OMNI_DIRECTIONAL | データが GS1 Databar omni-directional バーコード仕様でエンコードされることを指定します。 |
| DATABAR_TRUNCATED | データが GS1 Databar truncated バーコード仕様でエンコードされることを指定します。 |
| DATABAR_LIMITED | GS1 Databar limited バーコードを表します。 |
| DATABAR_EXPANDED | GS1 Databar expanded バーコードを表します。 |
| DATABAR_EXPANDED_STACKED | GS1 Databar expanded stacked バーコードを表します。 |
| DATABAR_STACKED | GS1 Databar stacked バーコードを表します。 |
| DATABAR_STACKED_OMNI_DIRECTIONAL | GS1 Databar stacked omni-directional バーコードを表します。 |
| SINGAPORE_POST | データが Singapore Post Barcode バーコード仕様でエンコードされることを指定します |
| AUSTRALIAN_POSTE_PARCEL | データが Australian Post Domestic eParcel Barcode バーコード仕様でエンコードされることを指定します |
| SWISS_POST_PARCEL | データが Swiss Post Parcel Barcode バーコード仕様でエンコードされることを指定します。サポートされるタイプ: Domestic Mail、International Mail、Additional Services (new) |
| PATCH_CODE | Patch code バーコードを表します |
| CODE32 | データが Code32 バーコード仕様でエンコードされることを指定します |
| DATA_LOGIC_2OF_5 | データが DataLogic 2 of 5 バーコード仕様でエンコードされることを指定します |
| DUTCH_KIX | データが Dutch KIX バーコード仕様でエンコードされることを指定します |
| UPCA_GS_1_CODE_128_COUPON | データが UPC クーポン（GS1-128 Extended Code）バーコード仕様でエンコードされることを指定します。<br/>            入力文字列の例:<br/>            BarcodeGenerator.Codetext = "514141100906(8102)03",<br/>            ここで UPCA 部分は "514141100906"、GS1Code128 部分は (8102)03 です。 |
| UPCA_GS_1_DATABAR_COUPON | データを UPC クーポン（GS1 DataBar 追加）バーコード仕様でエンコードすることを指定します。<br/>            入力文字列の例：<br/>            BarcodeGenerator.Codetext = "514141100906(8110)106141416543213500110000310123196000",<br/>            ここで UPCA 部分は "514141100906"、Databar 部分は "(8110)106141416543213500110000310123196000"です。<br/>            キャプションを変更するには、Parameters.CaptionAbove.Text = "company prefix + offer code"; を使用します。 |
| CODABLOCK_F | データを Codablock-F バーコード仕様でエンコードすることを指定します。 |
| GS1_CODABLOCK_F | データを GS1 Codablock-F バーコード仕様でエンコードすることを指定します。コードテキストは AI 用に括弧を含む必要があります。 |
| GS1_COMPOSITE_BAR | データを GS1 Composite Bar バーコード仕様でエンコードすることを指定します。コードテキストは AI 用に括弧を含む必要があります。1D コードテキストと 2D コードテキストは '/' 記号で区切る必要があります。 |
| HIBC_CODE_39LIC | データを HIBC LIC Code39 バーコード仕様でエンコードすることを指定します。 |
| HIBC_CODE_128LIC | データを HIBC LIC Code128 バーコード仕様でエンコードすることを指定します。 |
| HIBC_AZTEC_LIC | データを HIBC LIC Aztec バーコード仕様でエンコードすることを指定します。 |
| HIBC_DATA_MATRIX_LIC | データを HIBC LIC DataMatrix バーコード仕様でエンコードすることを指定します。 |
| HIBCQRLIC | データを HIBC LIC QR バーコード仕様でエンコードすることを指定します。 |
| HIBC_CODE_39PAS | データを HIBC PAS Code39 バーコード仕様でエンコードすることを指定します。 |
| HIBC_CODE_128PAS | データを HIBC PAS Code128 バーコード仕様でエンコードすることを指定します。 |
| HIBC_AZTEC_PAS | データを HIBC PAS Aztec バーコード仕様でエンコードすることを指定します。 |
| HIBC_DATA_MATRIX_PAS | データを HIBC PAS DataMatrix バーコード仕様でエンコードすることを指定します。 |
| HIBCQRPAS | データを HIBC PAS QR バーコード仕様でエンコードすることを指定します。 |
| GS1_DOT_CODE | データを GS1 DotCode バーコード仕様でエンコードすることを指定します。コードテキストは AI 用に括弧を含む必要があります。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_names() | エンコードタイプの名前の配列を取得します。 |
| parse(parsing_type, result) | BaseEncodeType の文字列表現をインスタンスに変換します。<br/>            戻り値は変換が成功したか失敗したかを示します。 |
| try_parse(parsing_type, result) | BaseEncodeType の文字列表現をインスタンスに変換します。<br/>            戻り値は変換が成功したか失敗したかを示します。 |
