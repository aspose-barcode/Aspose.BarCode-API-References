## SvgParameters class

SVG パラメータ。

SvgParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_explicit_size_in_pixels | SVG 画像にピクセル単位の明示的なサイズが含まれていますか（推奨）<br/>            デフォルト値: true. |
| is_text_drawn_in_text_element | SVG 画像にパスではなくテキスト要素としてテキストが含まれていますか（推奨）<br/>            デフォルト値: true. |
| svg_color_mode | svg ファイルの塗りつぶし色の可能なモードです。RGB がデフォルトで SVG 1.1 でサポートされています。<br/>            RGBA、HSL、HSLA は SVG 2.0 標準で許可されています。<br/>            RGB でも不透明度は "fill-opacity" パラメータで設定されます。 |
