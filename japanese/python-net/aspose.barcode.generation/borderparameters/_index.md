## BorderParameters class

バーコード画像の境界パラメータ

BorderParameters 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| visible | ボーダーの可視性。false の場合、パラメーター Width は常に無視されます (0)。<br/>            デフォルト値: false. |
| width | ボーダー幅。<br/>            デフォルト値: 0.<br/>            Visible が false に設定されている場合は無視されます。 |
| dash_style | ボーダーのダッシュスタイル。<br/>            デフォルト値: BorderDashStyle.Solid. |
| 色 | ボーダーの色。<br/>            デフォルト値: Color.Black. |
