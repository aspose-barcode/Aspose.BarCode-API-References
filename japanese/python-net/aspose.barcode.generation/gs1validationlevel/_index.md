## GS1ValidationLevel enumeration

GS1 データ検証のレベルを指定します。<br/>            より高い検証レベルは、下位レベルのすべてのチェックを含みます。

## Members
| メンバー名 | 説明 |
| :- | :- |
| SYNTAX | GS1 の構文を検証します。アプリケーション識別子、<br/>            フィールド長、必要な区切り文字を含みます。 |
| CONTENT | GS1 の構文とアプリケーション識別子値の内容を検証します。<br/>            文字セット、チェックサム、値固有のルールを含みます。 |
