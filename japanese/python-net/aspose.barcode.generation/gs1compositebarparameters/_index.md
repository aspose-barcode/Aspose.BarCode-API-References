## GS1CompositeBarParameters class

GS1 コンポジットバー パラメータ。

GS1CompositeBarParameters 型は、次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| linear_component_type | リニア コンポーネント タイプ: GS1Code128、UPCE、EAN8、UPCA、EAN13、DatabarStacked、DatabarStackedOmniDirectional、DatabarLimited、DatabarOmniDirectional、DatabarExpanded、DatabarExpandedStacked |
| two_d_component_type | 2D コンポーネント タイプ |
| allow_only_gs1_encoding | このフラグが設定されている場合、GS1CompositeBar 2D コンポーネントに対して GS1 エンコーディング標準のみが許可されます。 |
