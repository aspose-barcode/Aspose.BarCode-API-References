## Code16KParameters class

Code16K パラメータ。

Code16KParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| aspect_ratio | 2D バーコードモジュールの高さ/幅比率。 |
| quiet_zone_left_coef | xDimension における左側のクワイエットゾーンのサイズ。<br/>            デフォルト値: 10。つまり、xDimension = 2px の場合、左側のクワイエットゾーンは 20px になります。 |
| quiet_zone_right_coef | xDimension における右側のクワイエットゾーンのサイズ。<br/>            デフォルト値: 1。つまり、xDimension = 2px の場合、右側のクワイエットゾーンは 2px になります。 |
