## MacroCharacter enumeration

マクロ文字 05 と 06 の値は、特殊モードでよりコンパクトなエンコーディングを取得するために使用されます。<br/>            05 マクロ文字はデコードされたデータヘッダーとして "[)>\u001E05\u001D" に、デコードされたデータトレーラーとして "\u001E\u0004" に変換されます。<br/>            06 マクロ文字はデコードされたデータヘッダーとして "[)>\u001E06\u001D" に、デコードされたデータトレーラーとして "\u001E\u0004" に変換されます。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | マクロ文字はバーコードデータに追加されません |
| MACRO05 | 05 マクロ文字がバーコードデータの先頭位置に追加されます。<br/>            GS1 データ識別子 ISO 15434<br/>            文字はデコードされたデータヘッダーとして "[)>\u001E05\u001D" に、デコードされたデータトレーラーとして "\u001E\u0004" に変換されます。 |
| MACRO06 | 06 マクロ文字がバーコードデータの先頭位置に追加されます。<br/>            ASC MH10 データ識別子 ISO 15434<br/>            文字はデコードされたデータヘッダーとして "[)>\u001E06\u001D" に、デコードされたデータトレーラーとして "\u001E\u0004" に変換されます。 |
