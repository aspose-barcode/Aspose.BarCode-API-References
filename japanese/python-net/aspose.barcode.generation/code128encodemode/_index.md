## Code128EncodeMode enumeration

Code128 バーコードのエンコードモード。

## Members
| メンバー名 | 説明 |
| :- | :- |
| AUTO | コードテキストを従来の ISO 15417 モードでエンコードします。このモードはすべての通常の場合に使用すべきです。 |
| CODE_A | コードテキストを 128A コードセットのみでエンコードします。 |
| CODE_B | コードテキストを 128B コードセットのみでエンコードします。 |
| CODE_C | コードテキストを 128C コードセットのみでエンコードします。 |
| CODE_AB | コードテキストを 128A と 128B のコードセットのみでエンコードします。 |
| CODE_AC | コードテキストを 128A と 128C のコードセットのみでエンコードします。 |
| CODE_BC | コードテキストを 128B と 128C のコードセットのみでエンコードします。 |
