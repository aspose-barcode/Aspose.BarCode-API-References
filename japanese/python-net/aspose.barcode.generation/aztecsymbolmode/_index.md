## AztecSymbolMode enumeration

Aztec シンボルモードを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| AUTO | Aztec 用にベストなシンボル（Compact または Full-range）を自動的に選択することを指定します。<br/>            これはデフォルト値です。 |
| COMPACT | Aztec 用の Compact シンボルを指定します。<br/>            Aztec Compact シンボルは 1、2、3、または 4 層のみ許可します。 |
| FULL_RANGE | Aztec 用の Full-range シンボルを指定します。<br/>            Aztec Full-range シンボルは 1 から 32 層まで許可します。 |
| RUNE | Aztec 用の Rune シンボルを指定します。<br/>            Aztec Runes は小さくてもはっきりした機械可読マークの系列です。0 から 255 までの数値のみ許可します。 |
