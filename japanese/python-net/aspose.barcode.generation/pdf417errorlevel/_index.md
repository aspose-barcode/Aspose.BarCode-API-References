## Pdf417ErrorLevel enumeration

pdf417 バーコードの誤り訂正レベルです。レベル 0 からレベル 9 まであり、レベル 0 は誤り訂正なし、レベル 8 は最高の誤り訂正を意味します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| LEVEL0 | エラー訂正レベル - 0。エラー訂正コードワード - 2。 |
| LEVEL1 | エラー訂正レベル - 1。エラー訂正コードワード - 4。 |
| LEVEL2 | エラー訂正レベル - 2。エラー訂正コードワード - 8。 |
| LEVEL3 | エラー訂正レベル - 3。エラー訂正コードワード - 16。 |
| LEVEL4 | エラー訂正レベル - 4。エラー訂正コードワード - 32。 |
| LEVEL5 | エラー訂正レベル - 5。エラー訂正コードワード - 64。 |
| LEVEL6 | エラー訂正レベル - 6. エラー訂正コードワード - 128. |
| LEVEL7 | エラー訂正レベル - 7. エラー訂正コードワード - 256. |
| LEVEL8 | エラー訂正レベル - 8. エラー訂正コードワード - 512. |
