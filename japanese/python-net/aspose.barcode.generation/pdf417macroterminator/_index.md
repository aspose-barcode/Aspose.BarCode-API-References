## Pdf417MacroTerminator enumeration

エンコーダにセグメントへ Macro PDF417 ターミネータ（コードワード 922）を追加するかどうかを指示するために使用します。<br/>            Macro PDF417 にのみ適用されます。

## Members
| メンバー名 | 説明 |
| :- | :- |
| AUTO | セグメント数が指定され、かつ現在のセグメントが最後の場合、ターミネータは自動的に追加されます。<br/>            それ以外の場合、ターミネータは追加されません。 |
| NONE | ターミネータは追加されません。 |
| SET | ターミネータが追加されます。 |
