## CodabarParameters class

Codabar パラメータ。

CodabarParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| checksum_mode | Codabar バーコードのチェックサムアルゴリズムを取得または設定します。<br/>            デフォルト値: CodabarChecksumMode.Mod16。<br/>            チェックサム計算を有効にするには、プロパティ EnableChecksum に値 EnableChecksum.Yes を設定します。<br/>            詳細は [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/) を参照してください。 |
| start_symbol | Codabar シンボルの開始シンボル（文字）。<br/>            デフォルト値: CodabarSymbol.A |
| stop_symbol | Codabar シンボルの停止シンボル（文字）。<br/>            デフォルト値: CodabarSymbol.A |
