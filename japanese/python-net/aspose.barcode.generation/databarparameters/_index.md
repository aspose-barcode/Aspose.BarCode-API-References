## DataBarParameters class

Databar パラメータ。

DataBarParameters 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_2d_composite_component | DataBar バーコードを使用した 2D 複合コンポーネントのフラグを有効にします |
| allow_only_gs1_encoding | このフラグが設定されている場合、Databar バーコードタイプに対して GS1 エンコーディング標準のみを許可します |
| 列 | 列数。 |
| 行 | 行数。 |
| aspect_ratio | 2D バーコードモジュールの高さ/幅比率。<br/>            DataBar スタックに使用されます。 |
