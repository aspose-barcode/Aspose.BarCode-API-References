## HIBCPASCodetext class

| 名前 | 説明 |
| :- | :- |

| 名前 | 説明 |
| :- | :- |
| barcode_type | バーコードタイプを取得または設定します。HIBC PAS コードテキストは HIBCCode39PAS、HIBCCode128PAS、HIBCAztec:PAS、HIBCDataMatrixPAS、HIBCQRPAS のエンコードタイプを使用してエンコードできます。<br/>            デフォルト値: HIBCCode39PAS. |
