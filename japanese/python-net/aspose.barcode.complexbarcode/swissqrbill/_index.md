## SwissQRBill class

SwissQR 請求書データ

SwissQRBill 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| version | SwissQR 請求書標準のバージョンを取得または設定します。 |
| amount | 支払金額を取得または設定します。 |
| currency | 支払通貨を取得または設定します。 |
| account | 債権者の口座番号を取得または設定します。 |
| creditor | 債権者の住所を取得または設定します。 |
| reference | 債権者の支払参照を取得または設定します。 |
| 債務者 | 債務者の住所を取得または設定します。 |
| unstructured_message | 追加の非構造化メッセージを取得または設定します。 |
| bill_information | 追加の構造化請求情報を取得または設定します。 |
| alternative_schemes | 代替支払スキームを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| create_and_set_creditor_reference(raw_reference) | 生の文字列から、<br/>            "RF" とモジュロ97チェックサムを付加した文字列で ISO11649 債権者参照を作成し設定します。 |
| equals(other) | 指定されたオブジェクトが現在のオブジェクトと等しいかどうかを判断します。 |
