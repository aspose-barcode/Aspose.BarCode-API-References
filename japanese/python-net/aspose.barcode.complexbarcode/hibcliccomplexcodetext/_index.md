## HIBCLICComplexCodetext class

HIBC LIC コードに埋め込まれたテキストをエンコードおよびデコードするための基底クラス。

HIBCLICComplexCodetext 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| barcode_type | バーコードタイプを取得または設定します。HIBC LIC コードテキストは HIBCCode39LIC、HIBCCode128LIC、HIBCAztecLIC、HIBCDataMatrixLIC、HIBCQRLIC のエンコードタイプを使用してエンコードできます。<br/>            デフォルト値: HIBCCode39LIC。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_constructed_codetext() | コードテキストを構築します |
| init_from_string(constructed_codetext) | 構築されたコードテキストからインスタンスを初期化します。 |
| get_barcode_type() | バーコードのタイプを取得します。 |
