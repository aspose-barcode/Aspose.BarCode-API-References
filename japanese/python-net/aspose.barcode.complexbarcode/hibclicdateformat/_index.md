## HIBCLICDateFormat enumeration

HIBC LIC の日付形式のさまざまなタイプを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| YYYYMMDD | YYYYMMDD 形式です。追加の補足データにエンコードされます。 |
| MMYY | MMYY 形式です。 |
| MMDDYY | MMDDYY 形式です。 |
| YYMMDD | YYMMDD 形式です。 |
| YYMMDDHH | YYMMDDHH 形式です。 |
| YYJJJ | ユリウス日付形式です。 |
| YYJJJHH | 時間付きユリウス日形式。 |
| NONE | 有効期限の日付をエンコードしないでください。 |
