## Address class

債権者または債務者の住所。

Address型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Address() | Addressのインスタンスを作成します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| type | アドレスのタイプを取得します。 |
| name | 名前を取得または設定します。自然人の場合は名と姓、または<br/>            法人の場合は会社名です。 |
| address_line1 | 住所行1を取得または設定します。 |
| address_line2 | 住所行2を取得または設定します。 |
| street | 通りを取得または設定します。 |
| house_no | 住宅番号を取得または設定します。 |
| postal_code | 郵便番号を取得または設定します。 |
| town | 町または市を取得または設定します。 |
| country_code | 2文字のISO国コードを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| clear() | すべてのフィールドをクリアし、タイプを[UNDETERMINED](/barcode/python-net/aspose.barcode.complexbarcode/addresstype/)に設定します。 |
| equals(other) | 指定されたオブジェクトが現在のオブジェクトと等しいかどうかを判断します。 |
