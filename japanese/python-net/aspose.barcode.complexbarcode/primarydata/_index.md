## PrimaryData class

HIBC LIC の一次データを保存するクラス。

PrimaryData 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| PrimaryData() | PrimaryData クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| labeler_identification_code | ラベラー識別コードの日付を識別します。<br/>            ラベラー識別コードは4文字の英数字文字列で、最初の文字は必ずアルファベットである必要があります。 |
| product_or_catalog_number | 製品またはカタログ番号を識別します。製品またはカタログ番号は最大18文字の英数字文字列である必要があります。 |
| unit_of_measure_id | 測定単位 ID を識別します。測定単位 ID は0から9までの整数値である必要があります。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| parse_from_string(primary_data_codetext) | HIBC LIC 仕様に従い、文字列形式から一次データをインスタンス化します。 |
