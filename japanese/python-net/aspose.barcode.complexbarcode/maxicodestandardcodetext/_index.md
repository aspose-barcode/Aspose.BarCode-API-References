## MaxiCodeStandardCodetext class

モード 4、5、6 用の MaxiCode コードテキストをエンコードおよびデコードするクラス。

MaxiCodeStandardCodetext 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| MaxiCodeStandardCodetext() | MaxiCodeStandardCodetext クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| encode_mode | MaxiCode エンコードモードを取得または設定します。 <br/>            デフォルト値: Auto. |
| eci_encoding | ECI エンコーディングを取得または設定します。 MaxiCodeEncodeMode が Auto の場合に使用されます。<br/>            デフォルト値: ISO-8859-1 |
| モード | MaxiCode のモードを取得または設定します。標準コードテキストはモード 4、5、6 のみで使用できます。 |
| message | メッセージを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_mode() | MaxiCodeモードを取得します。 |
| get_constructed_codetext() | コードテキストを構築します |
| init_from_string(constructed_codetext) | 構築されたコードテキストからインスタンスを初期化します。 |
| get_barcode_type() | バーコードのタイプを取得します。 |
