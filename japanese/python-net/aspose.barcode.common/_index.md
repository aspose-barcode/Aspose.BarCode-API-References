主要な機能を維持するための共通機能とヘルパーツールを含みます。

## クラス
| クラス | 説明 |
| :- | :- |
| [GS1Element](/barcode/python-net/aspose.barcode.common/gs1element/) | 不変の GS1 アプリケーション識別子と値のペアを表します。 |
| [GS1ValidationIssue](/barcode/python-net/aspose.barcode.common/gs1validationissue/) | 1つの GS1 検証エラーを記述します。 |
| [GS1ValidationResult](/barcode/python-net/aspose.barcode.common/gs1validationresult/) | GS1 要素文字列、Digital Link URI、または AI 値のすべての独立検出可能なエラーを含みます。 |
| [ProcessorSettings](/barcode/python-net/aspose.barcode.common/processorsettings/) | ProcessorSettings は、マルチスレッドによるパフォーマンス向上でバーコードを認識できるようにします |
## 列挙型
| 列挙型 | 説明 |
| :- | :- |
| [GS1ValidationErrorCode](/barcode/python-net/aspose.barcode.common/gs1validationerrorcode/) | GS1 要素文字列、Digital Link URI、または値の検証エラーを識別します。 |
