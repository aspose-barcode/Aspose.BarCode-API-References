## GS1ValidationIssue class

1つの GS1 検証エラーを記述します。

GS1ValidationIssue 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| code | 安定した機械可読エラーコードを取得します。 |
| application_identifier | エラーに関連するアプリケーション識別子を取得します。入力からアプリケーション<br/>            識別子を特定できない場合は null が返されます。 |
| message | 人間が読めるエラーメッセージを取得します。 |
