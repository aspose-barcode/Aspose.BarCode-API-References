## GS1Element class

不変の GS1 アプリケーション識別子と値のペアを表します。

GS1Element 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| application_identifier | 正確な GS1 Application Identifier を取得します。 |
| value | Application Identifier に関連付けられた検証済みの値を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| validate(application_identifier, value) | 正確な GS1 Application Identifier の値を検証します。 |
