## ProcessorSettings class

ProcessorSettings は、マルチスレッドによるパフォーマンス向上でバーコードを認識できるようにします

ProcessorSettings 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| use_all_cores | すべてのコアを使用するために必要です。 |
| use_only_this_cores_count | 使用するコア数を指定します。 <br/>            プロパティ "UseAllCores" を "false" に変更する必要があります。 |
| max_additional_allowed_threads | コードを並列で実行するために許可される最大追加スレッド数を指定します |
