## Pdf417ExtendedParameters class

Tanınan barkodun MacroPdf417 meta veri bilgilerini depolar

Pdf417ExtendedParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_empty | Tüm parametrelerin yalnızca varsayılan değerlere sahip olup olmadığını test eder. |
| macro_pdf_417_file_id | Barkodun dosya kimliğini alır, yalnızca MacroPdf417 ile kullanılabilir. |
| macro_pdf_417_segment_id | Barkodun segment kimliğini alır, yalnızca MacroPdf417 ile kullanılabilir. |
| macro_pdf_417_segments_count | Macro pdf417 barkod segment sayısını alır. Varsayılan değer -1'dir. |
| macro_pdf_417_file_name | Macro PDF417 dosya adı (isteğe bağlı). |
| macro_pdf_417_file_size | Macro PDF417 dosya boyutu (isteğe bağlı). |
| macro_pdf_417_sender | Macro PDF417 gönderici adı (isteğe bağlı). |
| macro_pdf_417_addressee | Macro PDF417 alıcı adı (isteğe bağlı). |
| macro_pdf_417_time_stamp | Macro PDF417 zaman damgası (isteğe bağlı). |
| macro_pdf_417_checksum | Macro PDF417 sağlama toplamı (isteğe bağlı). |
| macro_pdf_417_terminator | Segmentin bir Macro PDF417 dosyasının son segmenti olup olmadığını gösterir. |
| is_reader_initialization | Okuyucuya, sembol içinde bulunan verileri okuyucu başlatması için programlama olarak yorumlaması talimatını vermek için kullanılır. |
| is_linked | Barkodun 1D barkoda bağlanması gerektiğini gösteren bayrak. |
| is_code_128_emulation | MicroPdf417 barkodunun 908, 909, 910 veya 911 Code 128 taklit kod sözcükleriyle kodlandığını gösteren bayrak. |
