## AztecExtendedParameters class

Aztec tanınan barkodun özel verilerini depolar

AztecExtendedParameters türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_empty | Tüm parametrelerin yalnızca varsayılan değerlere sahip olup olmadığını test eder. |
| structured_append_barcodes_count | Aztec yapılandırılmış ekleme modundaki barkod sayısını alır. Varsayılan değer 0'dır. Sayı 1 ile 26 arasında bir değer olmalıdır. |
| structured_append_barcode_id | Aztec yapılandırılmış ekleme modundaki barkodun kimliğini alır. Kimlik 1'den başlar ve barkod sayısına eşit veya daha düşük olmalıdır. Varsayılan değer 0'dır. |
| structured_append_file_id | Aztec yapılandırılmış ekleme modunun dosya kimliğini alır. Varsayılan değer boş dizedir. |
| is_reader_initialization | Kodun, barkod okuyucusunu başlatma veya yeniden programlama talimatları olarak aşağıdaki verileri yorumlaması için okuyucuya talimat vermek amacıyla kullanılıp kullanılmadığını gösterir.<br/>            Varsayılan değer false'tur. |
