## QRExtendedParameters class

Tanınan barkodun QR Structured Append bilgilerini depolar

QRExtendedParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_empty | Tüm parametrelerin yalnızca varsayılan değerlere sahip olup olmadığını test eder. |
| structured_append_mode_bar_codes_quantity | QR yapılandırılmış ekleme modu barkod miktarını alır. Varsayılan değer -1'dir. |
| structured_append_mode_bar_code_index | QR yapılandırılmış ekleme modu barkodunun indeksini alır. İndeks 0'dan başlar. Varsayılan değer -1'dir. |
| structured_append_mode_parity_data | QR yapılandırılmış ekleme modu parite verisini alır. Varsayılan değer -1'dir. |
| version | Tanımlanan QR Kod sürümü. Version1'den Version40'a kadar. |
| micro_qr_version | Tanımlanan MicroQR Kod sürümü. M1'den M4'e kadar. |
| rect_micro_qr_version | Tanımlanan RectMicroQR Kod sürümü. R7x43'ten R17x139'a kadar. |
| error_level | Tanımlanan barkodun Reed-Solomon hata düzeltme seviyesi. Düşükten yükseğe: LevelL, LevelM, LevelQ, LevelH. |
