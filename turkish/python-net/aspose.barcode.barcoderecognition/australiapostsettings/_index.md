## AustraliaPostSettings class

AustraliaPost kod çözme parametreleri. AustraliaPost sembolojisinin tanınan verileri üzerinde etkisi olan parametreleri içerir.

AustraliaPostSettings türü aşağıdaki üyeleri ortaya çıkarır:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| customer_information_interpreting_type | AvustralyaPost BarCode'un Müşteri Bilgileri için Yorumlama Türünü alır veya ayarlar. Varsayılan, CustomerInformationInterpretingType.Other'dur. |
| ignore_ending_filling_patterns_for_c_table | AustraliaPost çözücüsünün, CTable yöntemiyle kod çözerken Müşteri Bilgi Alanındaki son doldurma desenlerini yok saymasını zorlayan bayrak.<br/>            CTable kodlama yöntemi kodlama tablosunda boşluk içermez ve \"333\" doldurma deseni dizisi \"z\" harfi olarak çözülür. |
| customer_information_decoder | AustraliaPost sembolojisinde kullanılan Müşteri Bilgi Alanı kod çözme için genel arayüz. |
