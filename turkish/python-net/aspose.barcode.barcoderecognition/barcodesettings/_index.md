## BarcodeSettings class

Ana BarCode kod çözme parametreleri. Tanınan veriler üzerinde etkisi olan parametreleri içerir.

BarcodeSettings türü aşağıdaki üyeleri ortaya çıkarır:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Kod metninden FNC1, FNC2, FNC3 karakterlerini kaldır. Varsayılan değer false'tur. |
| only_requested_types | Yalnızca tanıma için açıkça belirtilen barkod tiplerini döndürür. <br/>            Etkinleştirildiğinde, diğer uyumlu veya eşdeğer tiplerdeki tanınan barkodlar filtrelenir. <br/>            Varsayılan değer false'tur. |
| detect_encoding | Unicode kod takımları için kod metni kodlamasını algılamasını zorlayan bayrak. Varsayılan değer true'dur. |
| australia_post | AustraliaPost kod çözme parametrelerini alır |
| calculate_symbol_quality | Tanıma sırasında barkod sembol kalitesinin hesaplanıp hesaplanmayacağını belirten bir değeri alır veya ayarlar. |
