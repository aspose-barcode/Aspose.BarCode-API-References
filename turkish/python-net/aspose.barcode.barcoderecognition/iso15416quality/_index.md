## Iso15416Quality class

1D barkodlar için ISO/IEC 15416 standardına göre hesaplanan barkod kalite derecelerini depolar.

Iso15416Quality türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| grade | ISO/IEC 15416'ya göre genel barkod kalite derecesini alır. |
| decode | Barkodun referans çözümleme algoritmasıyla çözülebilir olup olmadığını gösteren çözümleme derecesini alır. |
| symbol_contrast | Maksimum ve minimum yansıtma arasındaki farka dayalı sembol kontrast derecesini alır. |
| minimum_reflectance | En karanlık çubuk yansıtıcılığına dayanarak minimum yansıtıcılık derecesini alır. |
| minimum_edge_contrast | Komşu çubuklar ve boşluklar arasındaki en küçük yansıtıcılık farkına dayanarak minimum kenar kontrastı derecesini alır. |
| modulation | Barkod boyunca kenar kontrastının tekdüzeliğine dayanarak modülasyon derecesini alır. |
| defects | Çubuklar ve boşluklar içindeki yansıtıcılık düzensizliklerine dayanarak kusur derecesini alır. |
| decodability | Çubuk ve boşluk genişliklerinin doğruluğuna dayanarak kod çözülebilirlik derecesini alır. |
