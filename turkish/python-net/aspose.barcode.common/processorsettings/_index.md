## ProcessorSettings class

ProcessorSettings, çok iş parçacıklı performans artışıyla barkodları tanımayı sağlar.

ProcessorSettings türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| use_all_cores | Tüm çekirdekleri kullanmak için gereklidir. |
| use_only_this_cores_count | Kullanılacak çekirdek sayısını belirtin. <br/>            "UseAllCores" özelliğini "false" olarak değiştirmeniz gerekir. |
| max_additional_allowed_threads | Kodu paralel çalıştırmak için izin verilen ek iş parçacıklarının azami sayısını belirtin |
