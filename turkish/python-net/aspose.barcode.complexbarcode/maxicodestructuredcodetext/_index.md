## MaxiCodeStructuredCodetext class

Mod 2 ve 3 için MaxiCode koduna gömülü metni kodlamak ve çözmek için temel sınıf.

MaxiCodeStructuredCodetext tipi aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| encode_mode | Bir MaxiCode kodlama modunu alır veya ayarlar. <br/>            Varsayılan değer: Auto. |
| eci_encoding | ECI kodlamasını alır veya ayarlar. MaxiCodeEncodeMode Auto olduğunda kullanılır.<br/>            Varsayılan değer: ISO-8859-1 |
| postal_code | Posta kodunu tanımlar. Mod 2'de 9 rakam olmalı veya <br/>            Mod 3'te 6 alfanümerik sembol olmalıdır. |
| country_code | 3 haneli ülke kodunu tanımlar. |
| service_category | 3 basamaklı hizmet kategorisini tanımlar. |
| second_message | Barkodun ikinci mesajını tanımlar. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| get_mode() | MaxiCode modunu alır. |
| get_constructed_codetext() | Kod metnini oluşturur |
| init_from_string(constructed_codetext) | Oluşturulmuş kod metninden örneği başlatır. |
| get_barcode_type() | Barkod tipini alır. |
