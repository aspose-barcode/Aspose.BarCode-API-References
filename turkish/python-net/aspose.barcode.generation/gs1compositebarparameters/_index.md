## GS1CompositeBarParameters class

GS1 Bileşik çubuk parametreleri.

GS1CompositeBarParameters türü aşağıdaki üyeleri ortaya çıkarır:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| linear_component_type | Lineer bileşen türü: GS1Code128, UPCE, EAN8, UPCA, EAN13, DatabarStacked, DatabarStackedOmniDirectional, DatabarLimited, DatabarOmniDirectional, DatabarExpanded, DatabarExpandedStacked |
| two_d_component_type | 2D bileşen türü |
| allow_only_gs1_encoding | Bu bayrak ayarlanırsa, yalnızca GS1CompositeBar 2D Bileşeni için GS1 kodlama standardına izin verir |
