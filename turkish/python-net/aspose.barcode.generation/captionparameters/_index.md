## CaptionParameters class

Başlık parametreleri.

CaptionParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| text | Altyazı metni.<br/>            Varsayılan değer: boş dize. |
| font | Altyazı yazı tipi.<br/>            Varsayılan değer: Arial 8pt normal. |
| visible | Altyazı metni görünürlüğü.<br/>            Varsayılan değer: false. |
| text_color | Altyazı metni rengi.<br/>            Varsayılan değer: Color.Black. |
| padding | Altyazı dolguları.<br/>            CaptionAbove için varsayılan değer: 5pt 5pt 0 5pt.<br/>            CaptionBelow için varsayılan değer: 0 5pt 5pt 5pt. |
| hizalama | Altyazı testi yatay hizalama.<br/>            Varsayılan değer: StringAlignment.Center. |
| no_wrap | Metin içinde kelime kaydırmalarını (satır sonlarını) belirtin.<br/>            Varsayılan değer: false. |
