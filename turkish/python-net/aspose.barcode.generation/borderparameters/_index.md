## BorderParameters class

Barkod görüntüsü kenar parametreleri

BorderParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| visible | Kenarlık görünürlüğü. Yanlış ise Width parametresi her zaman göz ardı edilir (0).<br/>            Varsayılan değer: false. |
| width | Kenarlık genişliği.<br/>            Varsayılan değer: 0.<br/>            Visible false olarak ayarlanmışsa göz ardı edilir. |
| dash_style | Kenarlık kesikli stil.<br/>            Varsayılan değer: BorderDashStyle.Solid. |
| renk | Kenarlık rengi.<br/>            Varsayılan değer: Color.Black. |
