## AztecParameters class

Aztec parametreleri.

AztecParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| encode_mode | Aztec kodlama modunu alır veya ayarlar. <br/>            Varsayılan değer: Auto. |
| eci_encoding | ECI kodlamasını alır veya ayarlar. AztecEncodeMode Auto olduğunda kullanılır.<br/>            Varsayılan değer: ISO-8859-1 |
| structured_append_barcode_id | Aztec barkodunun Structured Append modu için Barkod Kimliği. Barkod Kimliği 1 ile barkod sayısı arasında olmalıdır.<br/>            Varsayılan değer: 0 |
| structured_append_barcodes_count | Aztec barkodunun Structured Append modunda barkod sayısı. Barkod sayısı 1 ile 26 arasında olmalıdır.<br/>            Varsayılan değer: 0 |
| structured_append_file_id | Aztec barkodunun Structured Append modu için Dosya Kimliği (isteğe bağlı alan). Dosya Kimliği boşluk içermemelidir.<br/>            Varsayılan değer: boş string |
| error_level | Aztec barkod türlerinin hata düzeltme seviyesi.<br/>            Değer 5 ile 95 arasında olmalıdır. |
| symbol_mode | Aztec Sembol modunu alır veya ayarlar.<br/>            Varsayılan değer: AztecSymbolMode.Auto. |
| layers_count | Aztec sembolünün katman sayısını alır veya ayarlar. Katman sayısı Compact mod için 1 ile 3 arasında, Full Range mod için 1 ile 32 arasında olmalıdır.<br/>            Varsayılan değer: 0 (otomatik). |
| is_reader_initialization | Okuyucuya sembol içinde bulunan verileri okuyucu başlatması için programlama olarak yorumlamasını söylemek için kullanılır.<br/>             |
| aspect_ratio | 2D Barkod modülünün Yükseklik/Genişlik oranı. |
