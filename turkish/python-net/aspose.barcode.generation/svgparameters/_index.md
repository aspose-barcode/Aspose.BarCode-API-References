## SvgParameters class

SVG parametreleri.

SvgParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_explicit_size_in_pixels | SVG görüntüsü piksel cinsinden açık bir boyuta sahip mi (önerilir)<br/>            Varsayılan değer: true. |
| is_text_drawn_in_text_element | SVG görüntüsü metni yollar yerine metin öğesi olarak içeriyor mu (önerilir)<br/>            Varsayılan değer: true. |
| svg_color_mode | svg dosyasında renk doldurma için olası modlar, RGB varsayılan ve SVG 1.1 tarafından desteklenir.<br/>            RGBA, HSL, HSLA SVG 2.0 standardında izinlidir.<br/>            RGB'de bile opaklık "fill-opacity" parametresi ile ayarlanır. |
