PDF parametreleri.

## Özellikler
| Ad | Açıklama |
| :- | :- |
| cmyk_bar_color | Nullable. Bar kodunun CMYK renk değeri. Null, CMYK renginin kullanılmadığı, bunun yerine normal RGB renginin kullanıldığı anlamına gelir. |
