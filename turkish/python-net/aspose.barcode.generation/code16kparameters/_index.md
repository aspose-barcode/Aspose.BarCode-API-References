## Code16KParameters class

Code16K parametreleri.

Code16KParameters türü aşağıdaki üyeleri ortaya çıkarır:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| aspect_ratio | 2D Barkod modülünün Yükseklik/Genişlik oranı. |
| quiet_zone_left_coef | Sol sessiz bölgenin xDimension cinsinden boyutu.<br/>            Varsayılan değer: 10, yani xDimension = 2px ise sol sessiz bölge 20px olur. |
| quiet_zone_right_coef | Sağ sessiz bölgenin xDimension cinsinden boyutu.<br/>            Varsayılan değer: 1, yani xDimension = 2px ise sağ sessiz bölge 2px olur. |
