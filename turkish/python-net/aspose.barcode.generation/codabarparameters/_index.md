## CodabarParameters class

Codabar parametreleri.

CodabarParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| checksum_mode | Codabar barkodları için sağlama algoritmasını alın veya ayarlayın.<br/>            Varsayılan değer: CodabarChecksumMode.Mod16.<br/>            Sağlama hesaplamasını etkinleştirmek için EnableChecksum.Yes değerini EnableChecksum özelliğine ayarlayın.<br/>            Bakın [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Codabar sembolojisinin başlangıç simgesi (karakter).<br/>            Varsayılan değer: CodabarSymbol.A |
| stop_symbol | Codabar sembolojisinin durma simgesi (karakter).<br/>            Varsayılan değer: CodabarSymbol.A |
