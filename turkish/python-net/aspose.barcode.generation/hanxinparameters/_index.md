## HanXinParameters class

Han Xin parametreleri.

HanXinParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| version | HanXin Kodunun Sürümü.<br/>            Version01'den Version84'e kadar Han Xin kodu için.<br/>            Varsayılan değer Version.Auto'dur. |
| error_level | Han Xin barkod için Reed-Solomon hata düzeltme seviyesi.<br/>             Düşükten yükseğe: L1, L2, L3, L4. ErrorLevel'e bakın. |
| encode_mode | HanXin kodlama modu.<br/>            Varsayılan değer: EncodeMode.Mixed. |
| eci_encoding | Genişletilmiş Kanal Yorumlama Tanımlayıcıları. Barkod okuyucuya detayları bildirmek için kullanılır<br/>            kullanılan referanslar hakkında semboldeki veriyi kodlamak için.<br/>            Mevcut uygulama tüm bilinen karakter seti kodlamalarını içerir. |
