## Code128EncodeMode enumeration

## Members

| :- | :- |

| CODE_A | Kod metnini yalnızca 128A kod kümesinde kodlayın. |
| CODE_B | Kod metnini yalnızca 128B kod kümesinde kodlayın. |
| CODE_C | Kod metnini yalnızca 128C kod kümesinde kodlayın. |
| CODE_AB | Kod metnini yalnızca 128A ve 128B kod kümelerinde kodlayın. |
| CODE_AC | Kod metnini yalnızca 128A ve 128C kod kümelerinde kodlayın. |
| CODE_BC | Kod metnini yalnızca 128B ve 128C kod kümelerinde kodlayın. |
