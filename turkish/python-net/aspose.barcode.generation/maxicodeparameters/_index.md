## MaxiCodeParameters class

MaxiCode parametreleri.

MaxiCodeParameters türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| mod | Bir MaxiCode kodlama modunu alır veya ayarlar. |
| encode_mode | Bir MaxiCode kodlama modunu alır veya ayarlar. <br/>            Varsayılan değer: Auto. |
| eci_encoding | ECI kodlamasını alır veya ayarlar. MaxiCodeEncodeMode Auto olduğunda kullanılır.<br/>            Varsayılan değer: ISO-8859-1 |
| structured_append_mode_barcode_id | Yapılandırılmış ekleme modunda bir MaxiCode barkod kimliğini alır veya ayarlar. <br/>            Kimlik 1 ile 8 arasında bir değer olmalıdır. <br/>            Varsayılan değer: 0 |
| structured_append_mode_barcodes_count | Yapılandırılmış ekleme modunda bir MaxiCode barkod sayısını alır veya ayarlar. <br/>            Sayım sayısı 2 ile 8 arasında bir değer olmalıdır (maksimum barkod sayısı).<br/>            Varsayılan değer: -1 |
| aspect_ratio | 2D Barkod modülünün Yükseklik/Genişlik oranı. |
