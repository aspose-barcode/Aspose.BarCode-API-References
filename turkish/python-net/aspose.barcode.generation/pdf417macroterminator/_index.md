## Pdf417MacroTerminator enumeration

Kodlayıcıya segment'e Makro PDF417 Terminatörü (kod sözcüğü 922) ekleyip eklemeyeceğini söylemek için kullanılır. <br/>            Yalnızca Makro PDF417 için uygulanır.

## Members
| Üye adı | Açıklama |
| :- | :- |
| AUTO | Terminasyon işareti, segment sayısı sağlanmışsa ve mevcut segment sonuncu ise otomatik olarak eklenecektir <br/>            diğer durumlarda terminasyon işareti eklenmeyecektir. |
| NONE | Terminasyon işareti eklenmeyecek. |
| SET | Terminasyon işareti eklenecek. |
