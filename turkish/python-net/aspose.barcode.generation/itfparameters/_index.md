## ITFParameters class

ITF parametreleri.

ITFParameters türü aşağıdaki üyeleri ortaya koyar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| border_thickness | ITF kenar (taşıyıcı çubuk) kalınlığını Birim değeri olarak alır veya ayarlar.<br/>            Varsayılan değer: 12pt. |
| border_type | ITF barkodunun kenar türü.<br/>            Varsayılan değer: ITF14BorderType.Bar. |
| quiet_zone_coef | Sessiz bölgelerin xDimension içindeki boyutu.<br/>            Varsayılan değer: 10, yani xDimension = 2px ise sessiz bölgeler 20px olur. |
