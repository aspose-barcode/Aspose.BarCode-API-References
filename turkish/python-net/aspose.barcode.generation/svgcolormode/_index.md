## SvgColorMode enumeration

svg dosyasında renk doldurma için olası modlar, RGB varsayılan ve SVG 1.1 tarafından desteklenir.<br/>            RGBA, HSL, HSLA SVG 2.0 standardında izinlidir.<br/>            RGB'de bile opaklık "fill-opacity" parametresi ile ayarlanır.

## Members
| Üye adı | Açıklama |
| :- | :- |
| RGB | RGB modu, örnek: fill="#ff5511" fill-opacity="0.73". Varsayılan mod. |
| RGBA | RGBA modu, örnek: fill="rgba(255, 85, 17, 0.73)" |
| HSL | HSL modu, örnek: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | HSLA modu, örnek: fill="hsla(30, 50%, 70%, 0.8)" |
