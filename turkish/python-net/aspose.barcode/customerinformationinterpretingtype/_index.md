## CustomerInformationInterpretingType enumeration

AustralianPost BarCode için müşteri bilgilerinin yorumlama türünü (CTable, NTable veya Other) tanımlar.

## Members
| Üye adı | Açıklama |
| :- | :- |
| C_TABLE | Müşteri bilgilerini yorumlamak için CTable kullanın. A..Z, a..z, 1..9, boşluk ve # işaretine izin verir. |
| N_TABLE | Müşteri bilgilerini yorumlamak için NTable kullanın. Rakamlarla sınırlıdır. |
| OTHER | Müşteri bilgilerini yorumlamayın. Yalnızca 0, 1, 2 veya 3 sembolüne izin verir. |
