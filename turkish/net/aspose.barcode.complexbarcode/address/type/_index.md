## Address.Type property

Adres türünü alır.

Adres türü, sokak / ev numarası ya da adres satırı 1 ve 2 ayarlanarak otomatik olarak belirlenir. Alanlar ayarlanmadan önce, adres türü Undetermined'dır. Her iki türden alanlar ayarlanırsa, adres türü Conflicting olur.

```csharp
public AddressType Type { get; }
```

### Property Value

Adres türü.
