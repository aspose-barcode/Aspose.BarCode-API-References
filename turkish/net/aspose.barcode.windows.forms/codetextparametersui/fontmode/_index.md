## CodetextParametersUI.FontMode property

FontMode'u belirtin. FontMode Auto olarak ayarlanırsa, yazı tipi boyutu xDimension değerine göre otomatik olarak hesaplanır. FontMode.Auto'yu özellikle AutoSizeMode.Nearest veya AutoSizeMode.Interpolation içinde kullanmanız önerilir. Varsayılan değer: FontMode.Auto.

```csharp
public FontMode FontMode { get; set; }
```
