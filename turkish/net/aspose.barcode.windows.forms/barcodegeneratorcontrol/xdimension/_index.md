## BarCodeGeneratorControl.XDimension property

X-dimension, Barkod çubukları veya boşlukları biriminin en küçük genişliğidir. Bunu artırmak, tüm barkod görüntüsü genişliğini artırır. [`AutoSizeMode`](../../../aspose.barcode.generation/autosizemode/) özelliği AutoSizeMode.Nearest veya AutoSizeMode.Interpolation olarak ayarlanmışsa yok sayılır.

public Unit XDimension { get; }
