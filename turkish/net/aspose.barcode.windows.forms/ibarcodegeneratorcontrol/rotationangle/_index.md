## IBarCodeGeneratorControl.RotationAngle property

BarCode görüntüsü döndürme açısı, derece cinsinden ölçülür, ör. RotationAngle = 0 veya RotationAngle = 360 dönüş olmadığını gösterir. RotationAngle 90, 180, 270 veya 0'a eşit değilse, tarayıcının görüntüyü okumasını zorlaştırabilir.

public float RotationAngle { get; set; }
