## CodabarParameters.ChecksumMode property

Checksum algoritmasını alır veya ayarlar Codabar barkodları için. Varsayılan değer: CodabarChecksumMode.Mod16. Checksum hesaplamasını etkinleştirmek için EnableChecksum.Yes değerini EnableChecksum özelliğine ayarlayın. Bkz `ChecksumMode`.

public CodabarChecksumMode ChecksumMode { get; set; }
