## PrimaryData class

Kelas untuk menyimpan data utama HIBC LIC.

Tipe PrimaryData menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PrimaryData() | Menginisialisasi instance baru dari kelas PrimaryData |
## Properti
| Nama | Deskripsi |
| :- | :- |
| labeler_identification_code | Mengidentifikasi tanggal kode identifikasi pelabel.<br/>            Kode identifikasi pelabel harus berupa string alfanumerik 4 simbol, dengan karakter pertama selalu alfabet. |
| product_or_catalog_number | Mengidentifikasi nomor produk atau katalog. Nomor produk atau katalog harus berupa string alfanumerik dengan panjang hingga 18 simbol. |
| unit_of_measure_id | Mengidentifikasi ID satuan ukuran. ID satuan ukuran harus berupa nilai integer dari 0 hingga 9. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| parse_from_string(primary_data_codetext) | Membuat instance data utama dari format string sesuai spesifikasi HIBC LIC. |
