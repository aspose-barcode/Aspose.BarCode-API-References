## SwissQRBill class

Data tagihan SwissQR

Tipe SwissQRBill menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| version | Mendapatkan atau mengatur versi standar tagihan SwissQR. |
| amount | Mendapatkan atau mengatur jumlah pembayaran. |
| currency | Mendapatkan atau mengatur mata uang pembayaran. |
| account | Mendapatkan atau mengatur nomor rekening kreditor. |
| creditor | Mendapatkan atau mengatur alamat kreditor. |
| reference | Mendapatkan atau mengatur referensi pembayaran kreditor. |
| debitor | Mendapatkan atau mengatur alamat debitor. |
| pesan_tidak_terstruktur | Mendapatkan atau mengatur pesan tidak terstruktur tambahan. |
| informasi_tagihan | Mendapatkan atau mengatur informasi tagihan terstruktur tambahan. |
| skema_alternatif | Mendapatkan atau mengatur skema pembayaran alternatif. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| create_and_set_creditor_reference(raw_reference) | Membuat dan mengatur referensi kreditur ISO11649 dari string mentah dengan menambahkan<br/>            String dengan "RF" dan checksum modulo 97. |
| equals(other) | Menentukan apakah objek yang ditentukan sama dengan objek saat ini. |
