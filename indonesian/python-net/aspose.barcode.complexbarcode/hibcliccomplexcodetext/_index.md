## HIBCLICComplexCodetext class

Kelas dasar untuk menyandikan dan menguraikan teks yang tertanam dalam kode HIBC LIC.

Tipe HIBCLICComplexCodetext menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| barcode_type | Mendapatkan atau mengatur tipe barcode. Codetext HIBC LIC dapat dienkode menggunakan HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC, dan HIBCQRLIC tipe enkode.<br/>            Nilai default: HIBCCode39LIC. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_constructed_codetext() | Membuat codetext |
| init_from_string(constructed_codetext) | Menginisialisasi instance dari codetext yang dibangun. |
| get_barcode_type() | Mendapatkan tipe barcode. |
