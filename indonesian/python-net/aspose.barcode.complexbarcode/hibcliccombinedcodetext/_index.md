## HIBCLICCombinedCodetext class

Kelas untuk menyandikan dan menguraikan teks yang tertanam dalam kode HIBC LIC yang menyimpan data utama dan sekunder.

Tipe HIBCLICCombinedCodetext menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| HIBCLICCombinedCodetext() | Menginisialisasi instance baru dari kelas HIBCLICCombinedCodetext |
## Properti
| Nama | Deskripsi |
| :- | :- |
| barcode_type | Mendapatkan atau mengatur tipe barcode. Codetext HIBC LIC dapat dienkode menggunakan HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC, dan HIBCQRLIC tipe enkode.<br/>            Nilai default: HIBCCode39LIC. |
| primary_data | Mengidentifikasi data utama. |
| secondary_and_additional_data | Mengidentifikasi data sekunder dan tambahan tambahan. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_constructed_codetext() | Membuat codetext |
| init_from_string(constructed_codetext) | Menginisialisasi instance dari codetext yang dibangun. |
| get_barcode_type() | Mendapatkan tipe barcode. |
