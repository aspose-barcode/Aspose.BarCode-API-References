## MaxiCodeStandardCodetext class

Kelas untuk menyandikan dan menguraikan teks kode MaxiCode untuk mode 4, 5, dan 6.

Tipe MaxiCodeStandardCodetext menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| MaxiCodeStandardCodetext() | Menginisialisasi instance baru dari kelas MaxiCodeStandardCodetext |
## Properti
| Nama | Deskripsi |
| :- | :- |
| encode_mode | Mendapatkan atau mengatur mode enkode MaxiCode. <br/>            Nilai default: Auto. |
| eci_encoding | Mendapatkan atau mengatur enkoding ECI. Digunakan ketika MaxiCodeEncodeMode adalah Auto.<br/>            Nilai default: ISO-8859-1 |
| mode | Mendapatkan atau mengatur mode MaxiCode. Codetext standar hanya dapat digunakan dengan mode 4, 5, dan 6. |
| message | Mendapatkan atau mengatur pesan. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_mode() | Mendapatkan mode MaxiCode. |
| get_constructed_codetext() | Membuat codetext |
| init_from_string(constructed_codetext) | Menginisialisasi instance dari codetext yang dibangun. |
| get_barcode_type() | Mendapatkan tipe barcode. |
