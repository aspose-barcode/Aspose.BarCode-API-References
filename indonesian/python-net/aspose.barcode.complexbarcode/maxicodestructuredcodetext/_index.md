## MaxiCodeStructuredCodetext class

Kelas dasar untuk menyandikan dan menguraikan teks yang tertanam dalam kode MaxiCode untuk mode 2 dan 3.

Tipe MaxiCodeStructuredCodetext menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| encode_mode | Mendapatkan atau mengatur mode enkode MaxiCode. <br/>            Nilai default: Auto. |
| eci_encoding | Mendapatkan atau mengatur enkoding ECI. Digunakan ketika MaxiCodeEncodeMode adalah Auto.<br/>            Nilai default: ISO-8859-1 |
| postal_code | Mengidentifikasi kode pos. Harus 9 digit dalam mode 2 atau <br/>            6 simbol alfanumerik dalam mode 3. |
| country_code | Mengidentifikasi kode negara 3 digit. |
| service_category | Mengidentifikasi kategori layanan 3 digit. |
| second_message | Mengidentifikasi pesan kedua dari kode batang. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_mode() | Mendapatkan mode MaxiCode. |
| get_constructed_codetext() | Membuat codetext |
| init_from_string(constructed_codetext) | Menginisialisasi instance dari codetext yang dibangun. |
| get_barcode_type() | Mendapatkan tipe barcode. |
