## HIBCPASCodetext class

Kelas untuk menyandikan dan menguraikan teks yang tertanam dalam kode HIBC PAS.

Tipe HIBCPASCodetext menyajikan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| HIBCPASCodetext() | Menginisialisasi sebuah instance baru dari kelas HIBCPASCodetext |
## Properti
| Nama | Deskripsi |
| :- | :- |
| barcode_type | Mendapatkan atau mengatur tipe barcode. Kode teks HIBC PAS dapat dienkode menggunakan HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS, dan HIBCQRPAS.<br/>            Nilai default: HIBCCode39PAS. |
| data_location | Mengidentifikasi lokasi data. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| add_record(data_type, data) | Menambahkan catatan baru |
| add_record(record) | Menambahkan catatan baru |
| get_records() | Mendapatkan daftar catatan |
| clear() | Menghapus daftar catatan |
| get_barcode_type() | Mendapatkan tipe barcode. |
| get_constructed_codetext() | Membuat codetext |
| init_from_string(constructed_codetext) | Menginisialisasi instance dari codetext yang dibangun. |
