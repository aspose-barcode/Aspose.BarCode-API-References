## Address class

Alamat kreditur atau debitur.

Tipe Address menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Address() | Membuat instance dari Address |
## Properti
| Nama | Deskripsi |
| :- | :- |
| type | Mendapatkan tipe alamat. |
| name | Mendapatkan atau mengatur nama, baik nama depan dan belakang dari orang alami atau <br/>            nama perusahaan dari orang hukum. |
| address_line1 | Mendapatkan atau mengatur baris alamat 1. |
| address_line2 | Mendapatkan atau mengatur baris alamat 2. |
| street | Mendapatkan atau mengatur jalan. |
| house_no | Mendapatkan atau mengatur nomor rumah. |
| postal_code | Mendapatkan atau mengatur kode pos. |
| town | Mendapatkan atau mengatur kota atau daerah. |
| country_code | Mendapatkan atau mengatur kode negara ISO dua huruf. |
