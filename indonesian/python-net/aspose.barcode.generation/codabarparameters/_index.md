## CodabarParameters class

Parameter Codabar.

Tipe CodabarParameters menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| checksum_mode | Dapatkan atau atur algoritma checksum untuk kode batang Codabar.<br/>            Nilai default: CodabarChecksumMode.Mod16.<br/>            Untuk mengaktifkan perhitungan checksum, setel nilai EnableChecksum.Yes ke properti EnableChecksum.<br/>            Lihat [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Simbol awal (karakter) dari simbolologi Codabar.<br/>            Nilai default: CodabarSymbol.A |
| stop_symbol | Simbol akhir (karakter) dari simbolologi Codabar.<br/>            Nilai default: CodabarSymbol.A |
