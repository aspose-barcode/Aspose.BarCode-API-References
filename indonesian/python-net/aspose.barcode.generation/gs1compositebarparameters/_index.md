## GS1CompositeBarParameters class

Parameter bar komposit GS1.

Tipe GS1CompositeBarParameters mengungkapkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| linear_component_type | Tipe komponen linear: GS1Code128, UPCE, EAN8, UPCA, EAN13, DatabarStacked, DatabarStackedOmniDirectional, DatabarLimited, DatabarOmniDirectional, DatabarExpanded, DatabarExpandedStacked |
| two_d_component_type | Tipe komponen 2D |
| allow_only_gs1_encoding | Jika flag ini diatur, hanya memperbolehkan standar enkoding GS1 untuk Komponen 2D GS1CompositeBar |
