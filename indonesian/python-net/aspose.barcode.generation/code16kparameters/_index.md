## Code16KParameters class

Parameter Code16K.

Tipe Code16KParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| aspect_ratio | Rasio Tinggi/ Lebar modul BarCode 2D. |
| quiet_zone_left_coef | Ukuran zona tenang kiri dalam xDimension.<br/>            Nilai default: 10, artinya jika xDimension = 2px maka zona tenang kiri akan menjadi 20px. |
| quiet_zone_right_coef | Ukuran zona tenang kanan dalam xDimension.<br/>            Nilai default: 1, artinya jika xDimension = 2px maka zona tenang kanan akan menjadi 2px. |
