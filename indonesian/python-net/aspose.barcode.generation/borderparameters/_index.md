## BorderParameters class

Parameter batas gambar barcode

Tipe BorderParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| visible | Visibilitas border. Jika false maka parameter Width selalu diabaikan (0).<br/>            Nilai default: false. |
| width | Border width.<br/>            Nilai default: 0.<br/>            Diabaikan jika Visible diatur ke false. |
| dash_style | Gaya dash border.<br/>            Nilai default: BorderDashStyle.Solid. |
| warna | Warna border.<br/>            Nilai default: Color.Black. |
