## HslaColor class

Kelas untuk merepresentasikan warna HSLA (Hue, Saturation, Lightness, Alpha)

Tipe HslaColor mengekspos anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| HslaColor(h, s, l, a) | Menginisialisasi instance baru dari kelas HslaColor |
## Properti
| Nama | Deskripsi |
| :- | :- |
| H | Hue [0, 360] |
| S | Saturasi [0, 100] |
| L | Kecerahan [0, 100] |
| a | Alpha (opasitas) [0.0f, 1.0f] |
## Metode
| Nama | Deskripsi |
| :- | :- |
| convert_hsla_to_rgba(hsla_color) | Menggunakan https://en.wikipedia.org/wiki/HSL_and_HSV#HSL_to_RGB |
