## DataBarParameters class

Parameter Databar.

Tipe DataBarParameters mengekspos anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_2d_composite_component | Mengaktifkan flag komponen komposit 2D dengan kode batang DataBar |
| allow_only_gs1_encoding | Jika flag ini diatur, hanya standar enkoding GS1 yang diizinkan untuk tipe kode batang Databar |
| kolom | Jumlah kolom. |
| baris | Jumlah baris. |
| aspect_ratio | Rasio Tinggi/ Lebar modul BarCode 2D.<br/>            Digunakan untuk DataBar bertumpuk. |
