## SvgColorMode enumeration

Mode yang mungkin untuk mengisi warna dalam file svg, RGB adalah default dan didukung oleh SVG 1.1.<br/>            RGBA, HSL, HSLA diizinkan dalam standar SVG 2.0.<br/>            Bahkan dalam RGB opasitas akan diatur melalui "fill-opacity" parameter

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| RGB | Mode RGB, contoh: fill="#ff5511" fill-opacity="0.73". Mode default. |
| RGBA | Mode RGBA, contoh: fill="rgba(255, 85, 17, 0.73)" |
| HSL | Mode HSL, contoh: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | Mode HSLA, contoh: fill="hsla(30, 50%, 70%, 0.8)" |
