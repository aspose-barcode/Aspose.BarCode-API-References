## MaxiCodeMode enumeration

Mode enkoding untuk barcode MaxiCode.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| MODE2 | Mode 2 mengkodekan informasi pos dalam pesan pertama dan data dalam pesan kedua. <br/>            Memiliki kode pos 9 digit (hanya digunakan di USA). |
| MODE3 | Mode 3 mengkodekan informasi pos dalam pesan pertama dan data dalam pesan kedua. <br/>            Memiliki kode pos alfanumerik 6 karakter, digunakan di seluruh dunia. |
| MODE4 | Mode 4 mengkodekan data dalam pesan pertama dan kedua, dengan koreksi ECC pendek. |
| MODE5 | Mode 5 mengkodekan data dalam pesan pertama dan kedua, dengan koreksi ECC panjang. |
| MODE6 | Mode 6 mengkodekan data dalam pesan pertama dan kedua, dengan koreksi ECC pendek.<br/>            Digunakan untuk mengkodekan perangkat. |
