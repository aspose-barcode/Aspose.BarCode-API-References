## SupplementParameters class

Parameter tambahan. Digunakan untuk Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

Tipe SupplementParameters menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| supplement_data | Data tambahan setelah BarCode. |
| supplement_space | Jarak antara BarCode utama dan BarCode tambahan dalam nilai [Unit](/barcode/python-net/aspose.barcode.generation/unit/). |
