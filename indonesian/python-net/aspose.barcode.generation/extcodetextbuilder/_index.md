## ExtCodetextBuilder class

Kelas pembantu untuk pembuatan codetext otomatis pada Mode Codetext Diperluas

Tipe ExtCodetextBuilder menampilkan anggota-anggota berikut:
## Metode
| Nama | Deskripsi |
| :- | :- |
| clear() | Menghapus item codetext yang diperluas |
| add_plain_codetext(codetext) | Menambahkan codetext biasa ke item codetext yang diperluas |
| add_eci_codetext(eci_encoding, codetext) | Menambahkan codetext dengan Extended Channel Identifier |
| get_extended_codetext() | Hasilkan codetext ekstensi dari daftar item generasi |
