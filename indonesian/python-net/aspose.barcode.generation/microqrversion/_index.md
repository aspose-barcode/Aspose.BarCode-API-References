## MicroQRVersion enumeration

Versi MicroQR Code.<br/>            Dari M1 hingga M4.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| AUTO | Menentukan untuk secara otomatis memilih versi terbaik untuk MicroQR.<br/>            Ini adalah nilai default. |
| M1 | Menentukan versi M1 untuk Micro QR dengan modul 11 x 11. |
| M2 | Menentukan versi M2 untuk Micro QR dengan modul 13 x 13. |
| M3 | Menentukan versi M3 untuk Micro QR dengan modul 15 x 15. |
| M4 | Menentukan versi M4 untuk Micro QR dengan modul 17 x 17. |
