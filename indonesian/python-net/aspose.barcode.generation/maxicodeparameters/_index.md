## MaxiCodeParameters class

Parameter MaxiCode.

Tipe MaxiCodeParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| mode | Mendapatkan atau mengatur mode enkode MaxiCode. |
| encode_mode | Mendapatkan atau mengatur mode enkode MaxiCode. <br/>            Nilai default: Auto. |
| eci_encoding | Mendapatkan atau mengatur enkoding ECI. Digunakan ketika MaxiCodeEncodeMode adalah Auto.<br/>            Nilai default: ISO-8859-1 |
| structured_append_mode_barcode_id | Mendapatkan atau mengatur ID kode batang MaxiCode dalam mode penambahan terstruktur. <br/>            ID harus berupa nilai antara 1 dan 8. <br/>            Nilai default: 0 |
| structured_append_mode_barcodes_count | Mendapatkan atau mengatur jumlah kode batang MaxiCode dalam mode penambahan terstruktur. <br/>            Jumlah harus berupa nilai antara 2 dan 8 (jumlah kode batang maksimum).<br/>            Nilai default: -1 |
| aspect_ratio | Rasio Tinggi/ Lebar modul BarCode 2D. |
