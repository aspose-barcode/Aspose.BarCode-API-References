## Pdf417MacroTerminator enumeration

Digunakan untuk memberi tahu enkoder apakah menambahkan Terminator Macro PDF417 (codeword 922) ke segmen. <br/>            Hanya diterapkan untuk Macro PDF417.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| AUTO | Terminator akan ditambahkan secara otomatis jika jumlah segmen disediakan <br/>            dan segmen saat ini adalah yang terakhir. Dalam kasus lain, terminator tidak akan ditambahkan. |
| NONE | Terminator tidak akan ditambahkan. |
| SET | Terminator akan ditambahkan. |
