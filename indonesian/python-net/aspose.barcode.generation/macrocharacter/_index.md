## MacroCharacter enumeration

Nilai Macro Karakter 05 dan 06 digunakan untuk memperoleh enkoding yang lebih kompak dalam mode khusus.<br/>            Karakter Macro 05 diterjemahkan menjadi "[)>\u001E05\u001D" sebagai header data terdekripsi dan "\u001E\u0004" sebagai trailer data terdekripsi.<br/>            Karakter Macro 06 diterjemahkan menjadi "[)>\u001E06\u001D" sebagai header data terdekripsi dan "\u001E\u0004" sebagai trailer data terdekripsi.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Tidak ada Macro Characters ditambahkan ke data kode batang. |
| MACRO05 | 05 Macro craracter ditambahkan ke data kode batang pada posisi pertama.<br/>            GS1 Data Identifier ISO 15434<br/>            Karakter diterjemahkan menjadi "[)>\u001E05\u001D" sebagai header data terdekripsi dan "\u001E\u0004" sebagai trailer data terdekripsi. |
| MACRO06 | 06 Macro craracter ditambahkan ke data kode batang pada posisi pertama.<br/>            ASC MH10 Data Identifier ISO 15434<br/>            Karakter diterjemahkan menjadi "[)>\u001E06\u001D" sebagai header data terdekripsi dan "\u001E\u0004" sebagai trailer data terdekripsi. |
