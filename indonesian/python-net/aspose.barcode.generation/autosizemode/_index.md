## AutoSizeMode enumeration

Menentukan berbagai jenis mode penyesuaian ukuran otomatis.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Pengubahan ukuran otomatis dinonaktifkan. |
| NEAREST | Mengubah ukuran barcode ke ukuran terdekat terendah yang mungkin ditentukan oleh properti ImageWidth dan ImageHeight.<br/>            Mempertahankan rasio aspek default. |
| INTERPOLATION | Mengubah ukuran barcode ke ukuran yang ditentukan.<br/>            Ukuran dapat ditentukan oleh properti ImageWidth dan ImageHeight.<br/>            Barcode yang dihasilkan mungkin tidak valid (tidak dapat dibaca) setelah skala. |
