## HanXinParameters class

Parameter Han Xin.

Tipe HanXinParameters mengungkapkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| version | Versi dari Kode HanXin.<br/>            Dari Version01 hingga Version84 untuk kode Han Xin.<br/>            Nilai default adalah Version.Auto. |
| error_level | Level koreksi kesalahan Reed-Solomon untuk kode batang Han Xin.<br/>             Dari rendah ke tinggi: L1, L2, L3, L4. lihat ErrorLevel. |
| encode_mode | Mode enkoding HanXin.<br/>            Nilai default: EncodeMode.Mixed. |
| eci_encoding | Identifier Interpretasi Saluran yang Diperluas. Ini digunakan untuk memberi tahu pembaca kode batang detail<br/>            tentang referensi yang digunakan untuk mengenkode data dalam simbol.<br/>            Implementasi saat ini berisi semua enkoding charset yang dikenal. |
