## DotCodeParameters class

Parameter DotCode.

Tipe DotCodeParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| aspect_ratio | Rasio Tinggi/ Lebar modul BarCode 2D. |
| encode_mode | Mengidentifikasi mode enkode DotCode. <br/>            Nilai default: Auto. |
| is_reader_initialization | Menunjukkan apakah kode digunakan untuk menginstruksikan pembaca agar menafsirkan data berikut sebagai instruksi untuk inisialisasi atau pemrograman ulang pembaca kode batang.<br/>            Nilai default adalah false. |
| structured_append_mode_barcode_id | Mengidentifikasi ID dari kode batang mode penambahan terstruktur DotCode. ID dimulai dari 1 dan harus kurang atau sama dengan jumlah kode batang. Nilai default adalah -1. |
| structured_append_mode_barcodes_count | Mengidentifikasi jumlah kode batang mode penambahan terstruktur DotCode. Nilai default adalah -1. Jumlah harus bernilai antara 1 hingga 35. |
| eci_encoding | Mengidentifikasi encoding ECI. Digunakan ketika DotCodeEncodeMode diatur ke Auto.<br/>            Nilai default: ISO-8859-1 |
| baris | Mengidentifikasi jumlah baris. Jumlah baris ditambah jumlah kolom dari simbol DotCode harus ganjil. Jumlah baris harus minimal 5.<br/>            Nilai default: -1 |
| kolom | Mengidentifikasi jumlah kolom. Jumlah baris ditambah jumlah kolom dari simbol DotCode harus ganjil. Jumlah kolom harus minimal 5.<br/>            Nilai default: -1 |
