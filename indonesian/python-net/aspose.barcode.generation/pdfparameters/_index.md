## PdfParameters class

Parameter PDF.

Tipe PdfParameters menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| cmyk_bar_color | Nullable. Nilai warna CMYK dari kode batang. Null berarti warna CMYK tidak digunakan, melainkan warna RGB normal yang digunakan. |
| cmyk_back_color | Nullable. Nilai warna latar belakang CMYK. Null berarti warna CMYK tidak digunakan, melainkan warna RGB normal yang digunakan. |
| cmyk_codetext_color | Nullable. Nilai warna CMYK dari Codetext. Null berarti warna CMYK tidak digunakan, melainkan warna RGB normal yang digunakan. |
| cmyk_caption_above_color | Nullable. Nilai warna CMYK dari caption di atas. Null berarti warna CMYK tidak digunakan, melainkan warna RGB normal yang digunakan. |
| cmyk_caption_below_color | Nullable. Nilai warna CMYK dari caption di bawah. Null berarti warna CMYK tidak digunakan, melainkan warna RGB normal yang digunakan. |
| is_text_as_path | Apakah jalur digunakan alih-alih teks (gunakan jika karakter Unicode tidak ditampilkan)<br/>            Nilai default: false. |
