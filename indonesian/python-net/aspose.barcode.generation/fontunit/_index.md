## FontUnit class

Mendefinisikan format khusus untuk teks, termasuk jenis font, ukuran, dan atribut gaya<br/>            dimana ukuran berada dalam properti nilai Unit.

Tipe FontUnit menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| family_name | Mendapatkan atau mengatur nama jenis Font ini. |
| style | Mendapatkan atau mengatur informasi gaya untuk FontUnit ini. |
| size | Mendapatkan atau mengatur ukuran FontUnit ini dalam nilai Unit. |
