## SvgParameters class

Parameter SVG.

Tipe SvgParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_explicit_size_in_pixels | Apakah gambar SVG memiliki ukuran eksplisit dalam piksel (direkomendasikan)<br/>            Nilai default: true. |
| is_text_drawn_in_text_element | Apakah gambar SVG berisi teks sebagai elemen teks bukan sebagai jalur (direkomendasikan)<br/>            Nilai default: true. |
| svg_color_mode | Mode yang mungkin untuk mengisi warna dalam file svg, RGB adalah default dan didukung oleh SVG 1.1.<br/>            RGBA, HSL, HSLA diizinkan dalam standar SVG 2.0.<br/>            Bahkan dalam RGB opasitas akan diatur melalui "fill-opacity" parameter |
