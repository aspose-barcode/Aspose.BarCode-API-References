## Code128EncodeMode enumeration

Mode enkode untuk kode batang Code128.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| AUTO | Enkode teks kode dalam mode ISO 15417 klasik. Mode ini harus digunakan dalam semua kasus biasa. |
| CODE_A | Enkode teks kode hanya dalam kumpulan kode 128A. |
| CODE_B | Enkode teks kode hanya dalam kumpulan kode 128B. |
| CODE_C | Enkode teks kode hanya dalam kumpulan kode 128C. |
| CODE_AB | Enkode teks kode hanya dalam kumpulan kode 128A dan 128B. |
| CODE_AC | Enkode teks kode hanya dalam kumpulan kode 128A dan 128C. |
| CODE_BC | Enkode teks kode hanya dalam kumpulan kode 128B dan 128C. |
