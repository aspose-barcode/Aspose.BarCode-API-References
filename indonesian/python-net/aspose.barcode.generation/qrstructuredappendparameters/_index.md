## QrStructuredAppendParameters class

Parameter penambahan terstruktur QR.

Tipe QrStructuredAppendParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| parity_byte | Mendapatkan atau mengatur data parity mode QR structured append. |
| sequence_indicator | Mendapatkan atau mengatur indeks barcode mode QR structured append. Indeks dimulai dari 0. |
| total_count | Mendapatkan atau mengatur jumlah barcode mode QR structured append. Nilai maksimum adalah 16. |
