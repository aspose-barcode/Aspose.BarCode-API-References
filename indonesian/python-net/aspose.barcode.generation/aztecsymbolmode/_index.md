## AztecSymbolMode enumeration

Menentukan mode simbol Aztec.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| AUTO | Menentukan untuk secara otomatis memilih simbol terbaik (Compact atau Full-range) untuk Aztec.<br/>            Ini adalah nilai default. |
| COMPACT | Menentukan simbol Compact untuk Aztec.<br/>            Simbol Compact Aztec hanya memperbolehkan 1, 2, 3, atau 4 lapisan. |
| FULL_RANGE | Menentukan simbol Full-range untuk Aztec.<br/>            Simbol Full-range Aztec memperbolehkan dari 1 hingga 32 lapisan. |
| RUNE | Menentukan simbol Rune untuk Aztec.<br/>            Rune Aztec adalah serangkaian tanda kecil namun berbeda yang dapat dibaca mesin. Hanya memperbolehkan nilai angka dari 0 hingga 255. |
