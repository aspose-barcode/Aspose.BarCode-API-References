## ITFParameters class

Parameter ITF.

Tipe ITFParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| border_thickness | Mendapatkan atau mengatur ketebalan batas ITF (bearer bar) dalam nilai Unit.<br/>            Nilai default: 12pt. |
| border_type | Jenis batas barcode ITF.<br/>            Nilai default: ITF14BorderType.Bar. |
| quiet_zone_coef | Ukuran zona tenang dalam xDimension.<br/>            Nilai default: 10, yang berarti jika xDimension = 2px maka zona tenang akan menjadi 20px. |
