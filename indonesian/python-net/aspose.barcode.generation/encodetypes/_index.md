## EncodeTypes class

Menentukan jenis barcode yang akan dienkode.

Tipe EncodeTypes menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| all_encode_types | Menentukan bahwa data akan diperiksa dengan semua simbol yang tersedia. |
| NONE | Tipe enkode tidak ditentukan. |
| CODABAR | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang CODABAR |
| CODE11 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang CODE 11 |
| CODE39 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang Code 39 set karakter dasar: ISO/IEC 16388 |
| CODE_39_FULL_ASCII | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang Code 39 set karakter ASCII penuh: ISO/IEC 16388 |
| CODE93 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang CODE 93 |
| CODE128 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang CODE 128 |
| GS1_CODE_128 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang GS1 Code 128. Teks kode harus berisi tanda kurung untuk AI. |
| EAN8 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang EAN-8 |
| EAN13 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang EAN-13 |
| EAN14 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang EAN14 |
| SCC14 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang SCC14 |
| SSCC18 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang SSCC18 |
| UPCA | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang UPC-A |
| UPCE | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang UPC-E |
| ISBN | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang ISBN |
| ISSN | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang ISSN |
| ISMN | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang ISMN |
| STANDARD_2OF_5 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang Standard 2 of 5 |
| INTERLEAVED_2OF_5 | Menentukan bahwa data harus dienkode dengan spesifikasi kode batang INTERLEAVED 2 of 5 |
| MATRIX_2OF_5 | Mewakili Kode Batang Matrix 2 of 5 |
| ITALIAN_POST25 | Mewakili kode batang Italian Post 25. |
| IATA2OF_5 | Mewakili kode batang IATA 2 of 5. IATA (International Air Transport Association) menggunakan kode batang ini untuk manajemen kargo udara. |
| ITF14 | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang ITF14 |
| ITF6 | Mewakili kode batang ITF-6. |
| MSI | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang MSI Plessey |
| VIN | Mewakili kode batang VIN (Vehicle Identification Number). |
| DEUTSCHE_POST_IDENTCODE | Mewakili kode batang Deutsch Post, Simbologi ini juga dikenal sebagai Identcode,CodeIdentcode,German Postal 2 of 5 Identcode, <br/>            Deutsch Post AG Identcode, Deutsch Frachtpost Identcode,  Deutsch Post AG (DHL) |
| DEUTSCHE_POST_LEITCODE | Mewakili kode batang Deutsch Post Leitcode, juga dikenal sebagai German Postal 2 of 5 Leitcode, CodeLeitcode, Leitcode, Deutsch Post AG (DHL). |
| OPC | Mewakili kode batang OPC (Optical Product Code), juga dikenal sebagai , VCA Barcode VCA OPC, Vision Council of America OPC Barcode. |
| PZN | Mewakili kode batang PZN. Simbologi ini juga dikenal sebagai Pharmacy central number, Pharmazentralnummer. PZN7 dan PZN8 didukung. <br/>            PZN7 dihasilkan dari 6 digit atau kurang, seperti "123456". PZN8 dihasilkan dari 7 digit atau lebih, seperti "1234567". <br/>            Digit checksum terakhir yang diberikan diabaikan dan dihasilkan oleh mesin kode batang. |
| CODE_16K | Mewakili kode batang Code 16K. |
| PHARMACODE | Mewakili kode batang Pharmacode. |
| DATA_MATRIX | Simbologi kode batang 2D DataMatrix |
| QR | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang QR Code |
| AZTEC | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang Aztec |
| GS1_AZTEC | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang GS1 Aztec. Teks kode harus mengandung tanda kurung untuk AI. |
| PDF417 | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang Pdf417 |
| MACRO_PDF417 | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang MacroPdf417 |
| GS1_DATA_MATRIX | Simbologi kode batang 2D DataMatrix dengan format string GS1 |
| MICRO_PDF417 | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang MicroPdf417 |
| GS1_MICRO_PDF_417 | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang GS1MicroPdf417 |
| GS1QR | Simbologi kode batang 2D QR dengan format string GS1 |
| MAXI_CODE | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang MaxiCode |
| DOT_CODE | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang DotCode |
| HAN_XIN | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang Han Xin |
| GS1_HAN_XIN | Simbologi kode batang 2D HanXin dengan format string GS1 |
| MICRO_QR | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang MicroQR Code |
| RECT_MICRO_QR | Menentukan bahwa data harus dienkode dengan spesifikasi barcode RectMicroQR (rMQR) Code |
| AUSTRALIA_POST | Mewakili BarCode Pelanggan Australia Post |
| JAPAN_POST | Mewakili BarCode Japan Post |
| POSTNET | Menentukan bahwa data harus dienkode dengan spesifikasi barcode Postnet |
| PLANET | Menentukan bahwa data harus dienkode dengan spesifikasi barcode Planet |
| ONE_CODE | Menentukan bahwa data harus dienkode dengan spesifikasi barcode USPS OneCode |
| RM4SCC | Mewakili barcode RM4SCC. RM4SCC (Royal Mail 4-state Customer Code) digunakan untuk proses penyortiran surat otomatis di Inggris. |
| MAILMARK | Mewakili barcode Royal Mail Mailmark. |
| DATABAR_OMNI_DIRECTIONAL | Menentukan bahwa data harus dienkode dengan spesifikasi barcode GS1 Databar omni-directional. |
| DATABAR_TRUNCATED | Menentukan bahwa data harus dienkode dengan spesifikasi barcode GS1 Databar truncated. |
| DATABAR_LIMITED | Mewakili barcode GS1 Databar limited. |
| DATABAR_EXPANDED | Mewakili barcode GS1 Databar expanded. |
| DATABAR_EXPANDED_STACKED | Mewakili barcode GS1 Databar expanded stacked. |
| DATABAR_STACKED | Mewakili barcode GS1 Databar stacked. |
| DATABAR_STACKED_OMNI_DIRECTIONAL | Mewakili barcode GS1 Databar stacked omni-directional. |
| SINGAPORE_POST | Menentukan bahwa data harus dienkode dengan spesifikasi barcode Singapore Post Barcode. |
| AUSTRALIAN_POSTE_PARCEL | Menentukan bahwa data harus dienkode dengan spesifikasi barcode Australian Post Domestic eParcel Barcode. |
| SWISS_POST_PARCEL | Menentukan bahwa data harus dienkode dengan spesifikasi barcode Swiss Post Parcel Barcode. Tipe yang didukung: Domestic Mail, International Mail, Additional Services (new). |
| PATCH_CODE | Mewakili barcode Patch code |
| CODE32 | Menentukan bahwa data harus dienkode dengan spesifikasi barcode Code32. |
| DATA_LOGIC_2OF_5 | Menentukan bahwa data harus dienkode dengan spesifikasi barcode DataLogic 2 of 5. |
| DUTCH_KIX | Menentukan bahwa data harus dienkode dengan spesifikasi barcode Dutch KIX. |
| UPCA_GS_1_CODE_128_COUPON | Menentukan bahwa data harus dienkode dengan kupon UPC dengan spesifikasi barcode GS1-128 Extended Code.<br/>            Contoh string input:<br/>            BarcodeGenerator.Codetext = "514141100906(8102)03",<br/>            dimana bagian UPCA adalah "514141100906", bagian GS1Code128 adalah (8102)03. |
| UPCA_GS_1_DATABAR_COUPON | Menentukan bahwa data harus dikodekan dengan kupon UPC dengan spesifikasi kode batang tambahan GS1 DataBar.<br/>            Contoh string input:<br/>            BarcodeGenerator.Codetext = "514141100906(8110)106141416543213500110000310123196000",<br/>            dimana bagian UPCA adalah "514141100906", bagian Databar adalah "(8110)106141416543213500110000310123196000".<br/>            Untuk mengubah caption, gunakan Parameters.CaptionAbove.Text = "company prefix + offer code"; |
| CODABLOCK_F | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang Codablock-F. |
| GS1_CODABLOCK_F | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang GS1 Codablock-F. Codetext harus berisi tanda kurung untuk AI. |
| GS1_COMPOSITE_BAR | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang GS1 Composite Bar. Codetext harus berisi tanda kurung untuk AI. Codetext 1D dan 2D harus dipisahkan dengan simbol '/' |
| HIBC_CODE_39LIC | Menentukan bahwa data harus dikodekan dengan spesifikasi kode batang HIBC LIC Code39. |

| :- | :- |
