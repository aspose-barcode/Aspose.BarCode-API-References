## CaptionParameters class

Parameter caption.

Tipe CaptionParameters menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| text | Teks caption.<br/>            Nilai default: string kosong. |
| font | Font caption.<br/>            Nilai default: Arial 8pt regular. |
| visible | Visibilitas teks caption.<br/>            Nilai default: false. |
| text_color | Warna teks caption.<br/>            Nilai default: Color.Black. |
| padding | Padding caption.<br/>            Nilai default untuk CaptionAbove: 5pt 5pt 0 5pt.<br/>            Nilai default untuk CaptionBelow: 0 5pt 5pt 5pt. |
| perataan | Perataan horizontal caption.<br/>            Nilai default: StringAlignment.Center. |
| tanpa_lipat | Tentukan pembungkusan kata (pemutusan baris) dalam teks.<br/>            Nilai default: false. |
