## AztecParameters class

Parameter Aztec.

Tipe AztecParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| encode_mode | Mendapatkan atau mengatur mode enkode Aztec. <br/>            Nilai default: Auto. |
| eci_encoding | Mendapatkan atau mengatur enkoding ECI. Digunakan ketika AztecEncodeMode adalah Auto.<br/>            Nilai default: ISO-8859-1 |
| structured_append_barcode_id | ID Barcode untuk mode Structured Append pada barcode Aztec. ID Barcode harus berada dalam rentang 1 hingga jumlah barcode.<br/>            Nilai default: 0 |
| structured_append_barcodes_count | Jumlah barcode untuk mode Structured Append pada barcode Aztec. Jumlah barcode harus berada dalam rentang 1 hingga 26.<br/>            Nilai default: 0 |
| structured_append_file_id | ID File untuk mode Structured Append pada barcode Aztec (field opsional). ID File tidak boleh mengandung spasi.<br/>            Nilai default: string kosong |
| error_level | Level koreksi kesalahan untuk tipe barcode Aztec.<br/>            Nilai harus antara 5 hingga 95. |
| symbol_mode | Mendapatkan atau mengatur mode Simbol Aztec.<br/>            Nilai default: AztecSymbolMode.Auto. |
| layers_count | Mendapatkan atau mengatur jumlah lapisan simbol Aztec. Jumlah lapisan harus berada dalam rentang 1 hingga 3 untuk mode Compact dan<br/>            dalam rentang 1 hingga 32 untuk mode Full Range.<br/>            Nilai default: 0 (otomatis). |
| is_reader_initialization | Digunakan untuk memberi instruksi kepada pembaca agar menafsirkan data yang terdapat dalam simbol<br/>            sebagai pemrograman untuk inisialisasi pembaca. |
| aspect_ratio | Rasio Tinggi/ Lebar modul BarCode 2D. |
