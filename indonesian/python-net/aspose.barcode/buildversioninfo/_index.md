## BuildVersionInfo class

Berisi informasi versi build saat ini.

Tipe BuildVersionInfo menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| ASSEMBLY_VERSION | Versi assembly. |
| FILE_VERSION | Versi file. |
| PRODUCT | Judul produk. |
| PRODUCT_MAJOR | Versi utama produk. |
| PRODUCT_MINOR | Versi minor produk. |
| RELEASE_DATE | Tanggal rilis produk. |
