## Metered class

Menyediakan metode untuk mengatur kunci bermeter.

Tipe Metered menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Metered() | Menginisialisasi instance baru dari kelas Metered |
## Metode
| Nama | Deskripsi |
| :- | :- |
| set_metered_key(public_key, private_key) | Mengatur kunci publik dan privat berbayar.<br/>            Jika Anda membeli lisensi berbayar, saat memulai aplikasi, API ini harus dipanggil, biasanya ini sudah cukup. <br/>            Namun, jika selalu gagal mengunggah data konsumsi dan melebihi 24 jam, lisensi akan diubah menjadi status evaluasi, <br/>            untuk menghindari hal tersebut, Anda harus secara rutin memeriksa status lisensi, jika berada dalam status evaluasi, panggil API ini lagi. |
