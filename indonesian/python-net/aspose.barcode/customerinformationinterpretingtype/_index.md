## CustomerInformationInterpretingType enumeration

Mendefinisikan tipe interpretasi (CTable, NTable, atau Lainnya) dari informasi pelanggan untuk AustralianPost BarCode.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| C_TABLE | Gunakan CTable untuk menginterpretasikan informasi pelanggan. Mengizinkan A..Z, a..z, 1..9, spasi, dan tanda #. |
| N_TABLE | Gunakan NTable untuk menginterpretasikan informasi pelanggan. Mengizinkan digit. |
| OTHER | Jangan menginterpretasikan informasi pelanggan. Mengizinkan hanya simbol 0, 1, 2, atau 3. |
