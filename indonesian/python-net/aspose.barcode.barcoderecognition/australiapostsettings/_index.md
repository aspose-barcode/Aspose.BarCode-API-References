## AustraliaPostSettings class

Parameter dekode AustraliaPost. Berisi parameter yang memengaruhi data yang dikenali dari simbol AustraliaPost.

Tipe AustraliaPostSettings menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| customer_information_interpreting_type | Mendapatkan atau mengatur Interpreting Type untuk Customer Information dari AustralianPost BarCode. Nilai default adalah CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | Bendera yang memaksa decoder AustraliaPost mengabaikan pola pengisian terakhir dalam Customer Information Field selama proses decoding sebagai metode CTable.<br/>            Metode enkoding CTable tidak memiliki celah dalam tabel enkoding dan urutan "333" dari pola pengisian didekode sebagai huruf "z". |
| customer_information_decoder | Antarmuka publik untuk decoding Customer Information Field yang digunakan dalam simbol AustraliaPost. |
