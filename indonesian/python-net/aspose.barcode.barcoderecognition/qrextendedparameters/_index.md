## QRExtendedParameters class

Menyimpan informasi QR Structured Append dari kode batang yang dikenali

Tipe QRExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| structured_append_mode_bar_codes_quantity | Mendapatkan jumlah barcode mode penambahan terstruktur QR. Nilai default adalah -1. |
| structured_append_mode_bar_code_index | Mendapatkan indeks barcode mode penambahan terstruktur QR. Indeks dimulai dari 0. Nilai default adalah -1. |
| structured_append_mode_parity_data | Mendapatkan data parity mode penambahan terstruktur QR. Nilai default adalah -1. |
| version | Versi QR Code yang dikenali. Dari Version1 hingga Version40. |
| micro_qr_version | Versi MicroQR Code yang dikenali. Dari M1 hingga M4. |
| rect_micro_qr_version | Versi RectMicroQR Code yang dikenali. Dari R7x43 hingga R17x139. |
| error_level | Level koreksi kesalahan Reed-Solomon dari barcode yang dikenali. Dari rendah ke tinggi: LevelL, LevelM, LevelQ, LevelH. |
