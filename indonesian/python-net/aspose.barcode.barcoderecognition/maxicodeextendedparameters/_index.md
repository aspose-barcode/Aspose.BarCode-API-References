## MaxiCodeExtendedParameters class

Menyimpan informasi tambahan MaxiCode dari kode batang yang dikenali

Tipe MaxiCodeExtendedParameters menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| mode | Mendapatkan atau mengatur mode enkoding MaxiCode.<br/>            Nilai default: Mode4 |
| structured_append_mode_barcode_id | Mendapatkan atau mengatur ID barcode MaxiCode dalam mode penambahan terstruktur.<br/>            Nilai default: 0 |
| structured_append_mode_barcodes_count | Mendapatkan atau mengatur jumlah barcode MaxiCode dalam mode penambahan terstruktur.<br/>            Nilai default: -1 |
