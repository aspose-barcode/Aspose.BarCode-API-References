## LuminanceFrame class

Mewakili bingkai gambar grayscale 8-bit. Setiap piksel diwakili oleh satu byte yang berisi nilai luminansinya.

Tipe LuminanceFrame menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Menginisialisasi instance baru dari kelas LuminanceFrame |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Menginisialisasi instance baru dari kelas LuminanceFrame |
## Properti
| Nama | Deskripsi |
| :- | :- |
| data | Mendapatkan data luminansi. |
| width | Mendapatkan lebar frame dalam piksel. |
| height | Mendapatkan tinggi frame dalam piksel. |
| row_stride | Mendapatkan jarak dalam byte antara awal<br/>            dua baris yang berdekatan. |
| rotation_degrees | Mendapatkan jumlah derajat yang harus diputar frame searah jarum jam untuk mendapatkan orientasi yang benar. |
