## GS1CompositeBarExtendedParameters class

Menyimpan data khusus dari kode batang GS1 Composite Bar yang dikenali

Tipe GS1CompositeBarExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| one_d_type | Mendapatkan tipe barcode 1D (linier) dari GS1 Composite |
| one_d_code_text | Mendapatkan nilai barcode 1D (linier) dari GS1 Composite |
| two_d_type | Mendapatkan tipe barcode 2D dari GS1 Composite |
| two_d_code_text | Mendapatkan nilai barcode 2D dari GS1 Composite |
