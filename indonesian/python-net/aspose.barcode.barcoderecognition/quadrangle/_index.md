## Quadrangle class

Menyimpan sekumpulan empat [Point](/barcode/python-net/aspose.drawing/point/) yang mewakili wilayah [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/).

Tipe Quadrangle menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Quadrangle() | Menginisialisasi instance baru yang kosong dari kelas [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Menginisialisasi instance baru dari kelas Quadrangle |
## Properti
| Nama | Deskripsi |
| :- | :- |
| left_top | Mendapatkan sudut kiri-atas [Point](/barcode/python-net/aspose.drawing/point/) dari wilayah [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| right_top | Mendapatkan sudut kanan-atas [Point](/barcode/python-net/aspose.drawing/point/) dari wilayah [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| right_bottom | Mendapatkan sudut kanan-bawah [Point](/barcode/python-net/aspose.drawing/point/) dari wilayah [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| left_bottom | Mendapatkan sudut kiri-bawah [Point](/barcode/python-net/aspose.drawing/point/) dari wilayah [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| is_empty | Menguji apakah semua [Point](/barcode/python-net/aspose.drawing/point/) dari [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) ini memiliki nilai nol. |
| bounding_rectangle | Mendapatkan [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) yang membatasi [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) ini |
| EMPTY | Mewakili kelas [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) dengan properti-propertinya belum diinisialisasi. |
