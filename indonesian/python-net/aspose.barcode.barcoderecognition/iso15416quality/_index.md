## Iso15416Quality class

Menyimpan nilai kualitas kode batang yang dihitung menurut standar ISO/IEC 15416 untuk kode batang 1D.

Tipe Iso15416Quality menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| grade | Mendapatkan grade kualitas barcode secara keseluruhan menurut ISO/IEC 15416. |
| decode | Mendapatkan grade decode yang menunjukkan apakah barcode dapat didekode menggunakan algoritma decode referensi. |
| symbol_contrast | Mendapatkan grade kontras simbol berdasarkan perbedaan antara reflektansi maksimum dan minimum. |
| minimum_reflectance | Mendapatkan nilai grade reflektansi minimum berdasarkan reflektansi bar paling gelap. |
| minimum_edge_contrast | Mendapatkan nilai grade kontras tepi minimum berdasarkan perbedaan reflektansi terkecil antara bar dan spasi yang berdekatan. |
| modulation | Mendapatkan nilai grade modulasi berdasarkan keseragaman kontras tepi di seluruh kode batang. |
| defects | Mendapatkan nilai grade cacat berdasarkan ketidakteraturan reflektansi di dalam bar dan spasi. |
| decodability | Mendapatkan nilai grade kemampuan dekode berdasarkan akurasi lebar bar dan spasi. |
