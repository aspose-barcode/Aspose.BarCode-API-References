## DataMatrixExtendedParameters class

Menyimpan data khusus dari kode batang DataMatrix yang dikenali

Tipe DataMatrixExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| structured_append_barcodes_count | Mendapatkan jumlah barcode mode structured append DataMatrix. Nilai default adalah -1. Jumlah harus berupa nilai antara 1 hingga 35. |
| structured_append_barcode_id | Mendapatkan ID barcode mode structured append DataMatrix. ID dimulai dari 1 dan harus kurang atau sama dengan jumlah barcode. Nilai default adalah -1. |
| structured_append_file_id | Mendapatkan ID barcode mode structured append DataMatrix. ID dimulai dari 1 dan harus kurang atau sama dengan jumlah barcode. Nilai default adalah -1. |
| is_reader_programming | Menunjukkan apakah kode digunakan untuk menginstruksikan pembaca agar menafsirkan data berikut sebagai instruksi untuk inisialisasi atau pemrograman ulang pembaca kode batang.<br/>            Nilai default adalah false. |
