## OneDExtendedParameters class

Menyimpan data khusus dari kode batang 1D yang dikenali seperti teks kode terpisah dan checksum

Tipe OneDExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| value | Mendapatkan teks kode barcode 1D tanpa checksum. |
| check_sum | Mendapatkan checksum untuk barcode 1D. |
