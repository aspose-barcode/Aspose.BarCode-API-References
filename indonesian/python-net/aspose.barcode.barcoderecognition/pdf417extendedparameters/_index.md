## Pdf417ExtendedParameters class

Menyimpan informasi metadata MacroPdf417 dari kode batang yang dikenali

Tipe Pdf417ExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| macro_pdf_417_file_id | Mendapatkan ID file barcode, hanya tersedia dengan MacroPdf417. |
| macro_pdf_417_segment_id | Mendapatkan ID segmen barcode, hanya tersedia dengan MacroPdf417. |
| macro_pdf_417_segments_count | Mendapatkan jumlah segmen barcode macro pdf417. Nilai default adalah -1. |
| macro_pdf_417_file_name | Nama file Macro PDF417 (opsional). |
| macro_pdf_417_file_size | Ukuran file Macro PDF417 (opsional). |
| macro_pdf_417_sender | Nama pengirim Macro PDF417 (opsional). |
| macro_pdf_417_addressee | Nama penerima Macro PDF417 (opsional). |
| macro_pdf_417_time_stamp | Stempel waktu Macro PDF417 (opsional). |
| macro_pdf_417_checksum | Checksum Macro PDF417 (opsional). |
| macro_pdf_417_terminator | Menunjukkan apakah segmen tersebut adalah segmen terakhir dari file Macro PDF417. |
| is_reader_initialization | Digunakan untuk memberi instruksi kepada pembaca agar menafsirkan data yang terdapat dalam simbol sebagai pemrograman untuk inisialisasi pembaca. |
| is_linked | Bendera yang menunjukkan bahwa barcode harus terhubung ke barcode 1D. |
| is_code_128_emulation | Bendera yang menunjukkan bahwa barcode MicroPdf417 dienkode dengan kode kata emulasi Code 128 908, 909, 910, atau 911. |
