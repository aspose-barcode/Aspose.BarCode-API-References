## CodabarExtendedParameters class

Menyimpan informasi tambahan Codabar dari kode batang yang dikenali

Tipe CodabarExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| start_symbol | Mendapatkan atau mengatur simbol awal Codabar.<br/>            Nilai default: CodabarSymbol.A |
| stop_symbol | Mendapatkan atau mengatur simbol akhir Codabar.<br/>            Nilai default: CodabarSymbol.A |
