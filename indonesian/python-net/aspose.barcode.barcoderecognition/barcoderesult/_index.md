## BarCodeResult class

Menyimpan data kode batang yang dikenali seperti tipe [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/), string codetext, <br/>            wilayah [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) dan parameter lainnya

Tipe BarCodeResult menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| BarCodeResult(result) | Menginisialisasi instance baru dari kelas BarCodeResult |
## Properti
| Nama | Deskripsi |
| :- | :- |
| reading_quality | Mendapatkan kualitas pembacaan. Berfungsi untuk barcode 1D dan pos. |
| confidence | Mendapatkan tingkat kepercayaan pengenalan barcode yang dikenali |
| code_text | Mendapatkan teks kode |
| code_bytes | Mendapatkan byte kode yang terenkode |
| code_type | Mendapatkan tipe barcode |
| code_type_name | Mendapatkan nama tipe barcode |
| region | Mendapatkan wilayah kode batang |
| extended | Mendapatkan parameter tambahan dari kode batang yang dikenali |
| iso_symbol_quality | Mendapatkan hasil evaluasi kualitas simbol ISO/IEC untuk kode batang yang dikenali. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_code_text(encoding) | Mendapatkan teks kode dengan enkoding. |
| equals(other) | Mengembalikan nilai yang menunjukkan apakah instance ini sama dengan nilai [BarCodeResult](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderesult/) yang ditentukan. |
| clone() | Membuat salinan kelas [BarCodeResult](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderesult/). |
