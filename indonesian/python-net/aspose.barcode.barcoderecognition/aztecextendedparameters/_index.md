## AztecExtendedParameters class

Menyimpan data khusus dari kode batang Aztec yang dikenali

Tipe AztecExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| structured_append_barcodes_count | Mendapatkan jumlah barcode mode penambahan terstruktur Aztec. Nilai default adalah 0. Jumlah harus bernilai antara 1 hingga 26. |
| structured_append_barcode_id | Mendapatkan ID barcode mode penambahan terstruktur Aztec. ID dimulai dari 1 dan harus kurang atau sama dengan jumlah barcode. Nilai default adalah 0. |
| structured_append_file_id | Mendapatkan ID File dari mode penambahan terstruktur Aztec. Nilai default adalah string kosong |
| is_reader_initialization | Menunjukkan apakah kode digunakan untuk menginstruksikan pembaca agar menafsirkan data berikut sebagai instruksi untuk inisialisasi atau pemrograman ulang pembaca kode batang.<br/>            Nilai default adalah false. |
