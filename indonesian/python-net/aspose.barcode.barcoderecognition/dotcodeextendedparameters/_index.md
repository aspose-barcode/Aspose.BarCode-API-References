## DotCodeExtendedParameters class

Menyimpan data khusus dari kode batang DotCode yang dikenali

Tipe DotCodeExtendedParameters menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_empty | Menguji apakah semua parameter hanya memiliki nilai default |
| structured_append_mode_barcodes_count | Mendapatkan jumlah kode batang mode penambahan terstruktur DotCode. Nilai default adalah -1. Jumlah harus berupa nilai antara 1 hingga 35. |
| structured_append_mode_barcode_id | Mendapatkan ID kode batang mode penambahan terstruktur DotCode. ID dimulai dari 1 dan harus kurang atau sama dengan jumlah kode batang. Nilai default adalah -1. |
| is_reader_initialization | Menunjukkan apakah kode digunakan untuk menginstruksikan pembaca agar menafsirkan data berikut sebagai instruksi untuk inisialisasi atau pemrograman ulang pembaca kode batang.<br/>            Nilai default adalah false. |
