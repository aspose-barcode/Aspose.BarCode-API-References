## BarcodeSettings class

Parameter utama dekode BarCode. Berisi parameter yang memengaruhi data yang dikenali.

Tipe BarcodeSettings menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Hapus karakter FNC1, FNC2, FNC3 dari teks kode. Nilai default adalah false. |
| only_requested_types | Mengembalikan hanya tipe barcode yang secara eksplisit ditentukan untuk pengenalan. <br/>            Ketika diaktifkan, barcode yang dikenali dengan tipe lain yang kompatibel atau setara akan disaring. <br/>            Nilai default adalah false. |
| detect_encoding | Bendera yang memaksa mesin mendeteksi pengkodean teks kode untuk set kode Unicode. Nilai default adalah true. |
| australia_post | Mendapatkan parameter decoding AustraliaPost |
| calculate_symbol_quality | Mendapatkan atau mengatur nilai yang menunjukkan apakah kualitas simbol barcode harus dihitung selama pengenalan. |
