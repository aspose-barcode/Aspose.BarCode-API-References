## GS1ValidationIssue class

Menjelaskan satu kesalahan validasi GS1.

Tipe GS1ValidationIssue menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| code | Mendapatkan kode kesalahan yang dapat dibaca mesin secara stabil. |
| application_identifier | Mendapatkan Identifier Aplikasi yang terkait dengan kesalahan, atau null ketika Identifier Aplikasi<br/>            tidak dapat ditentukan dari input. |
| message | Mendapatkan pesan kesalahan yang dapat dibaca manusia. |
