## GS1Element class

Mewakili satu pasangan Identifier Aplikasi GS1 yang tidak dapat diubah dan nilainya.

Tipe GS1Element menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| application_identifier | Mendapatkan Application Identifier GS1 yang tepat. |
| value | Mendapatkan nilai yang telah divalidasi yang terkait dengan Application Identifier. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| validate(application_identifier, value) | Memvalidasi nilai untuk Application Identifier GS1 yang tepat. |
