## ProcessorSettings class

ProcessorSettings memungkinkan pengenalan kode batang dengan peningkatan kinerja multi‑thread.

Tipe ProcessorSettings menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| use_all_cores | Diperlukan untuk menggunakan semua core. |
| use_only_this_cores_count | Tentukan jumlah core yang akan digunakan. <br/>            Anda perlu mengubah properti "UseAllCores" menjadi "false". |
| max_additional_allowed_threads | Tentukan jumlah maksimal thread tambahan untuk menjalankan kode secara paralel |
