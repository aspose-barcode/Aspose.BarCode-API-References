Menyediakan informasi tentang nama produk dan versi saat ini. Menunjukkan cara menggunakan BuildVersionInfo untuk memperoleh informasi tentang produk ini. System.out.prinln(MessageFormat.format("I am currently using %s, version number %s.", BuildVersionInfo.PRODUCT, BuildVersionInfo.ASSEMBLY\_VERSION));
