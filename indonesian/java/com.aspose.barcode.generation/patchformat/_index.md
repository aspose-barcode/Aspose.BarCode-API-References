Format PatchCode. Pilih PATCH\_ONLY untuk menghasilkan satu PatchCode. Gunakan format halaman untuk menghasilkan halaman Patch dengan PatchCodes sebagai batas.
## Bidang

| Bidang | Deskripsi |
| --- | --- |
| [A4](#A4) | Menghasilkan halaman format A4 dengan PatchCodes sebagai batas dan QR opsional di tengah. |
| [A4_LANDSCAPE](#A4-LANDSCAPE) | Menghasilkan halaman format A4 lanskap dengan PatchCodes sebagai batas dan QR opsional di tengah. |
| [PATCH_ONLY](#PATCH-ONLY) | Menghasilkan hanya PatchCode. |
| [US_LETTER](#US-LETTER) | Menghasilkan halaman format US letter dengan PatchCodes sebagai batas dan QR opsional di tengah. |
| [US_LETTER_LANDSCAPE](#US-LETTER-LANDSCAPE) | Menghasilkan halaman format US letter lanskap dengan PatchCodes sebagai batas dan QR opsional di tengah. |
