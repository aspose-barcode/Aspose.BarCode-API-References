## CodetextParameters::set_FontMode method


Tentukan FontMode. Jika FontMode diatur ke Auto, ukuran font akan dihitung secara otomatis berdasarkan nilai xDimension. Disarankan menggunakan [FontMode.Auto](../../aztecencodemode/) terutama dalam [AutoSizeMode.Nearest](../../autosizemode/) atau [AutoSizeMode.Interpolation](../../autosizemode/).
