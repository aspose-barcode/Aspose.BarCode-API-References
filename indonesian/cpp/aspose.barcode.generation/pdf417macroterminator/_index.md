## Pdf417MacroTerminator enum


Digunakan untuk memberi tahu encoder apakah harus menambahkan Terminator Macro PDF417 (codeword 922) ke segmen. Hanya diterapkan untuk Macro PDF417.

```cpp
enum class Pdf417MacroTerminator
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Otomatis | 0 | Terminator akan ditambahkan secara otomatis jika jumlah segmen diberikan dan segmen saat ini adalah yang terakhir. Dalam kasus lain, terminator tidak akan ditambahkan. |
| Tidak ada | 1 | Terminator tidak akan ditambahkan. |
| Set | 2 | Terminator akan ditambahkan. |
