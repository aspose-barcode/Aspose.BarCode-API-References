## BarcodeParameters::get_ThrowExceptionWhenCodeTextIncorrect method


Hanya untuk barcode 1D. Jika codetext tidak benar dan nilai diatur ke true - pengecualian akan dilempar. Jika tidak, codetext akan diperbaiki agar sesuai dengan spesifikasi barcode. Pengecualian selalu akan dilempar untuk: Databar symbology jika codetext tidak benar. Pengecualian tidak akan pernah dilempar untuk: AustraliaPost, SingapurePost, Code39FullASCII, Code93, Code16K, Code128 symbology jika codetext tidak benar.
