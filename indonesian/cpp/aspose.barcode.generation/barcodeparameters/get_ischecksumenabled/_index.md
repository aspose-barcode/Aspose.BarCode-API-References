## BarcodeParameters::get_IsChecksumEnabled method




```cpp
EnableChecksum Aspose::BarCode::Generation::BarcodeParameters::get_IsChecksumEnabled() const
```

## Catatan


Aktifkan checksum selama pembuatan barcode 1D.

Default diperlakukan sebagai Ya untuk simbol yang harus mengandung checksum, dan sebagai Tidak dimana checksum hanya mungkin.

Checksum memungkinkan: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN, Codabar

Checksum selalu digunakan: Simbol lainnya
