## MicroQRVersion enum


Versi MicroQR Code. Dari M1 hingga M4.

```cpp
enum class MicroQRVersion
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Otomatis | 0 | Menentukan untuk secara otomatis memilih versi terbaik untuk MicroQR. Ini adalah nilai default. |
| M1 | 1 | Menentukan versi M1 untuk Micro QR dengan modul 11 x 11. |
| M2 | 2 | Menentukan versi M2 untuk Micro QR dengan modul 13 x 13. |
| M3 | 3 | Menentukan versi M3 untuk Micro QR dengan modul 15 x 15. |
| M4 | 4 | Menentukan versi M4 untuk Micro QR dengan modul 17 x 17. |
