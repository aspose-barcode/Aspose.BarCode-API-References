## Catatan


Referensi wajib untuk IBAN SwissQR, yaitu IBAN dalam rentang CHxx30000xxxxxx hingga CHxx31999xxxxx.

Jika ditentukan, referensi harus berupa referensi SwissQR yang valid (sesuai formulir referensi ISR) atau referensi kreditur yang valid menurut ISO 11649 ("RFxxxx"). Kedua-duanya dapat berisi spasi untuk pemformatan.
