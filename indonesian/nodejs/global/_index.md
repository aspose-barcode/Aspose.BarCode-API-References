Namespace Global menyediakan kumpulan enumerasi dasar dan tipe pembantu yang mendefinisikan properti kode batang seperti mode enkoding, ukuran simbol, tingkat kepercayaan, dan format gambar. Definisi-definisi ini dirujuk di seluruh API Aspose.BarCode untuk mengkonfigurasi dan menafsirkan pembuatan serta pengenalan kode batang.
