## MacroCharacter

Nilai Macro Characters 05 dan 06 digunakan untuk memperoleh enkoding yang lebih kompak dalam mode khusus. Macro karakter 05 diterjemahkan menjadi "[)>\u001E05\u001D" sebagai header data terdekripsi dan "\u001E\u0004" sebagai trailer data terdekripsi. Macro karakter 06 diterjemahkan menjadi "[)>\u001E06\u001D" sebagai header data terdekripsi dan "\u001E\u0004" sebagai trailer data terdekripsi. contoh ini menunjukkan cara mengenkode Macro Characters dalam MicroPdf417 dan DataMatrix
