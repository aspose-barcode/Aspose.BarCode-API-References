## EnableChecksum

Aktifkan checksum selama pembuatan untuk kode batang 1D. Default diperlakukan sebagai Ya untuk simbol yang harus mengandung checksum, sebagai Tidak dimana checksum hanya mungkin. Checksum tidak pernah digunakan: Codabar. Checksum memungkinkan: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN. Checksum selalu digunakan: Simbol lainnya.

## Nilai

| Nama | Deskripsi |
| --- | --- |
| DEFAULT | Jika checksum diperlukan oleh spesifikasi - itu akan dilampirkan. |
| YA | Selalu gunakan checksum jika memungkinkan. |
| TIDAK | Jangan gunakan checksum. |
