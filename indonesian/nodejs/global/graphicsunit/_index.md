## GraphicsUnit

Menentukan satuan ukuran untuk data yang diberikan.

## Nilai

| Nama | Deskripsi |
| --- | --- |
| WORLD | Menentukan unit sistem koordinat dunia sebagai satuan ukuran. |
| DISPLAY | Menentukan satuan ukuran perangkat tampilan. Biasanya piksel untuk tampilan video, dan 1/100 inci untuk printer. |
| PIXEL | Menentukan piksel perangkat sebagai satuan ukuran. |
| POINT | Menentukan titik printer = 1/72 inci) sebagai satuan ukuran. |
| INCH | Menentukan inci sebagai satuan ukuran. |
| DOCUMENT | Menentukan satuan dokumen = 1/300 inci) sebagai satuan ukuran. |
| MILLIMETER | Menentukan milimeter sebagai satuan ukuran. |
