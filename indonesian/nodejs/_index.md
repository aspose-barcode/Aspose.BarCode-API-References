API menyediakan kelas untuk pembuatan, pengenalan, dan manipulasi barcode, memungkinkan integrasi mulus ke dalam aplikasi Node.js melalui interoperabilitas Java. Simbol yang didukung mencakup linear, 2‑D, dan kode pos seperti Code128, EAN‑13, QR, DataMatrix, Aztec, dan PDF417. Semua fungsi diatur di bawah namespace aspose.barcode, dengan utilitas tambahan berada di namespace Global.

## Namespace

| Namespace | Deskripsi |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | Namespace aspose.barcode menyediakan kelas dan enum untuk membuat, menyesuaikan, dan mendekode berbagai jenis barcode di Node.js via Java. |
| [Global](./global/) | Namespace Global mengelompokkan enumerasi inti dan kelas utilitas yang digunakan di seluruh Aspose.BarCode untuk Node.js via Java. |
