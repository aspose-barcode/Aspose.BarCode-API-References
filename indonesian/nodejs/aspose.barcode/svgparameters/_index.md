### getSvgColorMode() {#getsvgcolormode}

Mode yang mungkin untuk mengisi warna dalam file svg, RGB adalah default dan didukung oleh SVG 1.1. RGBA, HSL, HSLA diizinkan dalam standar SVG 2.0. Bahkan dalam RGB opasitas akan diatur melalui parameter "fill-opacity"

### isExplicitSizeInPixels() {#isexplicitsizeinpixels}

Apakah gambar SVG memiliki ukuran eksplisit dalam piksel (disarankan) Nilai default: true.

### isTextDrawnInTextElement() {#istextdrawnintextelement}

Apakah gambar SVG berisi teks sebagai elemen teks bukan jalur (disarankan) Nilai default: true.

### setExplicitSizeInPixels() {#setexplicitsizeinpixels}

Apakah gambar SVG memiliki ukuran eksplisit dalam piksel (disarankan) Nilai default: true.

### setSvgColorMode() {#setsvgcolormode}

Mode yang mungkin untuk mengisi warna dalam file svg, RGB adalah default dan didukung oleh SVG 1.1. RGBA, HSL, HSLA diizinkan dalam standar SVG 2.0. Bahkan dalam RGB opasitas akan diatur melalui parameter "fill-opacity"

### setTextDrawnInTextElement() {#settextdrawnintextelement}

Apakah gambar SVG berisi teks sebagai elemen teks bukan jalur (disarankan) Nilai default: true.
