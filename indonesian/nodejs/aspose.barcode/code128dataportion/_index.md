## Code128DataPortion class

Berisi data subtipe untuk barcode tipe Code128

```js
new Code128DataPortion()
```

Membuat instance baru dari kelas `Code128DataPortion` dengan simbol kode awal dan teks kode yang telah didekode.

## Metode

| Nama | Deskripsi |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Mendapatkan tipe subset Code128 |
| [getData()](#getdata) | Mendapatkan bagian teks kode yang terkait dengan subtipe. |
| [toString()](#tostring) | Mengembalikan representasi string yang dapat dibaca manusia dari `Code128DataPortion` ini. |

### getCode128SubType() {#getcode128subtype}

Mendapatkan tipe subset Code128

**Returns:** The type of Code128 subset

### getData() {#getdata}

Mendapatkan bagian teks kode yang terkait dengan subtipe.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Mengembalikan representasi string yang dapat dibaca manusia dari `Code128DataPortion` ini.

**Returns:** A string that represents this `Code128DataPortion`.
