## HslaColor class

Kelas untuk merepresentasikan warna HSLA (Hue, Saturation, Lightness, Alpha)

```js
new HslaColor(h, s, l, a)
```

Konstruktor untuk HslaColor

| Parameter | Deskripsi |
| --- | --- |
| h | Hue [0, 360] |
| s | Saturation [0, 100] |
| l | Lightness [0, 100] |
| a | Alpha (opasitas) [0.0f, 1.0f] |
