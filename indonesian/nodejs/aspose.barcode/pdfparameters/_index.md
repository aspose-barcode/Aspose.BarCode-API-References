## PdfParameters class

Pembungkus parameter PDF. Mengharapkan sebuah instance `mwObject` yang mendasari yang menyediakan metode getter/setter yang sesuai yang mengembalikan/menerima string CMYK seperti "30_100_0_30" atau `null`.

```js
new PdfParameters(mwObject)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| mwObject | objek | – instance dari kelas Java PdfParameters |
