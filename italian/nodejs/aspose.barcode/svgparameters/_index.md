### getSvgColorMode() {#getsvgcolormode}

Modalità possibili per il riempimento del colore nel file svg, RGB è il valore predefinito e supportato da SVG 1.1. RGBA, HSL, HSLA sono consentiti nello standard SVG 2.0. Anche in RGB l'opacità sarà impostata tramite il parametro "fill-opacity" parameter

### isExplicitSizeInPixels() {#isexplicitsizeinpixels}

L'immagine SVG contiene dimensioni esplicite in pixel (consigliato). Valore predefinito: true.

### isTextDrawnInTextElement() {#istextdrawnintextelement}

L'immagine SVG contiene testo come elemento di testo anziché percorsi (consigliato). Valore predefinito: true.

### setExplicitSizeInPixels() {#setexplicitsizeinpixels}

L'immagine SVG contiene dimensioni esplicite in pixel (consigliato). Valore predefinito: true.

### setSvgColorMode() {#setsvgcolormode}

Modalità possibili per il riempimento del colore nel file svg, RGB è il valore predefinito e supportato da SVG 1.1. RGBA, HSL, HSLA sono consentiti nello standard SVG 2.0. Anche in RGB l'opacità sarà impostata tramite il parametro "fill-opacity" parameter

### setTextDrawnInTextElement() {#settextdrawnintextelement}

L'immagine SVG contiene testo come elemento di testo anziché percorsi (consigliato). Valore predefinito: true.
