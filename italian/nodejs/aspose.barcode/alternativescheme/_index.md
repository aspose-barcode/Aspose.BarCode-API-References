
### equals(obj) {#equals}

Determina se l'oggetto specificato è uguale all'oggetto corrente.

| Parametro | Descrizione |
| --- | --- |
| obj | L'oggetto da confrontare con l'oggetto corrente. |

**Returns:** true if the specified object is equal to the current object; otherwise, false.

### getInstruction() {#getinstruction}

Ottiene l'istruzione di pagamento per una fattura data. L'istruzione consiste in un'abbreviazione di due lettere per lo schema, un carattere separatore e una sequenza di parametri (separati dal carattere all'indice 2).

### hashCode() {#hashcode}

Ottiene il codice hash per questa istanza.

**Returns:** hash code for the current object.

### setInstruction() {#setinstruction}

Ottiene l'istruzione di pagamento per una fattura data. L'istruzione consiste in un'abbreviazione di due lettere per lo schema, un carattere separatore e una sequenza di parametri (separati dal carattere all'indice 2).
