## DataElement class

Rappresenta un campo dati specifico per giurisdizione usato nei documenti, ad esempio ElementID = "ZVA" con Value = "01".

```js
new DataElement()
```

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getElementID()](#getelementid) | Un codice di 3 caratteri che identifica il campo specifico della giurisdizione, ad es., "ZVA". |
| [getValue()](#getvalue) | Il valore di testo associato al campo, tipicamente definito dalle regole della giurisdizione. |
| [setElementID()](#setelementid) | Un codice di 3 caratteri che identifica il campo specifico della giurisdizione, ad es., "ZVA". |
| [setValue()](#setvalue) | Il valore di testo associato al campo, tipicamente definito dalle regole della giurisdizione. |
