## HslaColor class

Classe per rappresentare il colore HSLA (Hue, Saturation, Lightness, Alpha)

```js
new HslaColor(h, s, l, a)
```

Costruttore per HslaColor

| Parametro | Descrizione |
| --- | --- |
| h | Tonalità [0, 360] |
| s | Saturazione [0, 100] |
| l | Luminosità [0, 100] |
| a | Alfa (opacità) [0.0f, 1.0f] |
