## Code128DataPortion class

Contiene i dati del sottotipo per il barcode di tipo Code128

```js
new Code128DataPortion()
```

Crea una nuova istanza della classe `Code128DataPortion` con il simbolo del codice di avvio e il testo codificato decodificato.

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Ottiene il tipo del sottoinsieme Code128 |
| [getData()](#getdata) | Ottiene la parte del testo del codice relativa al sottotipo. |
| [toString()](#tostring) | Restituisce una rappresentazione stringa leggibile dall'uomo di questo `Code128DataPortion`. |

### getCode128SubType() {#getcode128subtype}

Ottiene il tipo del sottoinsieme Code128

**Returns:** The type of Code128 subset

### getData() {#getdata}

Ottiene la parte del testo del codice relativa al sottotipo.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Restituisce una rappresentazione stringa leggibile dall'uomo di questo `Code128DataPortion`.

**Returns:** A string that represents this `Code128DataPortion`.
