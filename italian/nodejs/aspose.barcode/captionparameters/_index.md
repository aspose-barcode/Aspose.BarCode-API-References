## CaptionParameters class

Parametri della didascalia.

```js
new CaptionParameters()
```

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getAlignment()](#getalignment) | Allineamento orizzontale del testo della didascalia. Valore predefinito TextAlignment.CENTER. |
| [getFont()](#getfont) | Carattere della didascalia. Valore predefinito: Arial 8pt regular. |
| [getNoWrap()](#getnowrap) | Specifica l'andatura delle parole (interruzioni di riga) nel testo. Valore predefinito: false. |
| [getPadding()](#getpadding) | Spaziatura delle didascalie. Valore predefinito per CaptionAbove: 5pt 5pt 0 5pt. Valore predefinito per CaptionBelow: 0 5pt 5pt 5pt. |
| [getText()](#gettext) | Testo della didascalia. Valore predefinito: stringa vuota. |
| [getTextColor()](#gettextcolor) | Colore del testo della didascalia. Valore predefinito NERO. |
| [getVisible()](#getvisible) | Visibilità del testo della didascalia. Valore predefinito: false. |
| [setAlignment()](#setalignment) | Allineamento orizzontale del testo della didascalia. Valore predefinito TextAlignment.CENTER. |
| [setNoWrap()](#setnowrap) | Specifica l'andatura delle parole (interruzioni di riga) nel testo. Valore predefinito: false. |

| [setText()](#settext) | Testo della didascalia. Valore predefinito: stringa vuota. |
