## IComplexCodetext class

Interfaccia per codetext complesso usato con ComplexBarcodeGenerator.

```js
new IComplexCodetext()
```

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getBarcodeType()](#getbarcodetype) | Ottiene il tipo di codice a barre. |
| [getConstructedCodetext()](#getconstructedcodetext) | Costruisci il codetext per il codice a barre complesso |
| [initFromString(constructedCodetext)](#initfromstring) | Inizializza l'istanza con il codetext costruito. |

### getBarcodeType() {#getbarcodetype}

Ottiene il tipo di codice a barre.

**Returns:** Barcode type.

### getConstructedCodetext() {#getconstructedcodetext}

Costruisci il codetext per il codice a barre complesso

**Returns:** Constructed codetext

### initFromString(constructedCodetext) {#initfromstring}

Inizializza l'istanza con il codetext costruito.

| Parametro | Descrizione |
| --- | --- |
| constructedCodetext | Codetext costruito. |
