## SwissQRCodetext class

Classe per la codifica e la decodifica del testo incorporato nel codice SwissQR.

```js
new SwissQRCodetext(bill)
```

Crea un'istanza di SwissQRCodetext.

| Parametro | Descrizione |
| --- | --- |
| fattura | Dati della fattura SwissQR |

**Throws:** BarcodeException

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getBarcodeType()](#getbarcodetype) | Ottiene il tipo di codice a barre. |
| [getBill()](#getbill) | Dati della fattura SwissQR |
| [getConstructedCodetext()](#getconstructedcodetext) | Costruisce il codetext dai dati della fattura SwissQR. |
| [initFromString(constructedCodetext)](#initfromstring) | Inizializza Bill con il codetext costruito. |

### getBarcodeType() {#getbarcodetype}

### getBill() {#getbill}
