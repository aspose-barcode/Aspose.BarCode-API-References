## SupplementParameters class

Parametri supplementari. Utilizzati per Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

```js
new SupplementParameters()
```

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getSupplementData()](#getsupplementdata) | Dati supplementari dopo il codice a barre. |
| [getSupplementSpace()](#getsupplementspace) | Spazio tra il BarCode principale e il BarCode supplementare in valore Unit. |
| [setSupplementData()](#setsupplementdata) | Dati supplementari dopo il codice a barre. |
| [toString()](#tostring) | Restituisce una rappresentazione stringa leggibile dall'uomo di questi SupplementParameters. |

### getSupplementData() {#getsupplementdata}

Dati supplementari dopo il codice a barre.

### getSupplementSpace() {#getsupplementspace}

Spazio tra il BarCode principale e il BarCode supplementare in valore Unit.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

Dati supplementari dopo il codice a barre.

### toString() {#tostring}

Restituisce una rappresentazione stringa leggibile dall'uomo di questi SupplementParameters.

**Returns:** A string that represents this SupplementParameters.
