## BorderParameters class

Parametri del bordo dell'immagine Barcode

```js
new BorderParameters()
```

## Metodi

| Nome | Descrizione |
| --- | --- |
| [getColor()](#getcolor) | Colore del bordo. Valore predefinito: #000000 |
| [getDashStyle()](#getdashstyle) | Stile tratteggio del bordo. Valore predefinito: BorderDashStyle.SOLID. |
| [getVisible()](#getvisible) | Visibilità del bordo. Se false, il parametro Width è sempre ignorato (0). Valore predefinito: false. |
| [getWidth()](#getwidth) | Larghezza del bordo. Valore predefinito: 0. Ignorata se Visible è impostato a false. |
| [setColor()](#setcolor) | Colore del bordo. Valore predefinito: #000000 |
| [setDashStyle()](#setdashstyle) | Stile tratteggio del bordo. Valore predefinito: BorderDashStyle.SOLID. |
| [setVisible()](#setvisible) | Visibilità del bordo. Se false, il parametro Width è sempre ignorato (0). Valore predefinito: false. |
| [setWidth()](#setwidth) | Larghezza del bordo. Valore predefinito: 0. Ignorata se Visible è impostato a false. |
| [toString()](#tostring) | Restituisce una rappresentazione stringa leggibile dall'uomo di questo BorderParameters. |

### getColor() {#getcolor}

Colore del bordo. Valore predefinito: #000000

### getDashStyle() {#getdashstyle}

Stile tratteggio del bordo. Valore predefinito: BorderDashStyle.SOLID.

### getVisible() {#getvisible}

Visibilità del bordo. Se false, il parametro Width è sempre ignorato (0). Valore predefinito: false.

### getWidth() {#getwidth}

Larghezza del bordo. Valore predefinito: 0. Ignorata se Visible è impostato a false.

### setColor() {#setcolor}

Colore del bordo. Valore predefinito: #000000

### setDashStyle() {#setdashstyle}

Stile tratteggio del bordo. Valore predefinito: BorderDashStyle.SOLID.

### setVisible() {#setvisible}

Visibilità del bordo. Se false, il parametro Width è sempre ignorato (0). Valore predefinito: false.

### setWidth() {#setwidth}

Larghezza del bordo. Valore predefinito: 0. Ignorata se Visible è impostato a false.

### toString() {#tostring}

Restituisce una rappresentazione stringa leggibile dall'uomo di questo BorderParameters.

**Returns:** A string that represents this BorderParameters.
