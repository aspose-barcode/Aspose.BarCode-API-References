## Pdf417CompactionMode

Modalità di compattazione del codice a barre Pdf417.

## Valori

| Nome | Descrizione |
| --- | --- |
| AUTO | rileva automaticamente la modalità di compressione |
| TEXT | compressione del testo |
| NUMERIC | modalità di compressione numerica |
| BINARY | modalità di compressione binaria |
