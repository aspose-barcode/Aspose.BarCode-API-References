## GraphicsUnit

Specifica l'unità di misura per i dati forniti.

## Valori

| Nome | Descrizione |
| --- | --- |
| WORLD | Specifica l'unità del sistema di coordinate mondiali come unità di misura. |
| DISPLAY | Specifica l'unità di misura del dispositivo di visualizzazione. Tipicamente pixel per i display video e 1/100 di pollice per le stampanti. |
| PIXEL | Specifica un pixel del dispositivo come unità di misura. |
| POINT | Specifica il punto della stampante = 1/72 di pollice) come unità di misura. |
| INCH | Specifica il pollice come unità di misura. |
| DOCUMENT | Specifica l'unità del documento = 1/300 di pollice) come unità di misura. |
| MILLIMETER | Specifica il millimetro come unità di misura. |
