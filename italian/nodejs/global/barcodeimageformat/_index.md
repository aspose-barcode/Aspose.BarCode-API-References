## BarCodeImageFormat

Specifica il formato file dell'immagine.

## Valori

| Nome | Descrizione |
| --- | --- |
| BMP | Specifica il formato immagine bitmap (BMP). |
| GIF | Specifica il formato immagine Graphics Interchange Format (GIF). |
| JPEG | Specifica il formato immagine Joint Photographic Experts Group (JPEG). |
| PNG | Specifica il formato immagine W3C Portable Network Graphics (PNG). |
| TIFF | Specifica il formato immagine Tagged Image File Format (TIFF). |
| TIFF_IN_CMYK | Specifica il formato immagine Tagged Image File Format (TIFF) nel modello di colore CMYK. |
| EMF | Specifica il formato immagine Enhanced Metafile (EMF). |
| SVG | Specifica il formato immagine Scalable Vector Graphics (SVG). |
| PDF | Specifica il formato immagine Portable Document Format (PDF). |
