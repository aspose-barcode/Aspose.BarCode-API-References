### getChecksumMode() {#getChecksumMode--}
```
public final CodabarChecksumMode getChecksumMode()
```


Ottieni l'algoritmo di checksum per i codici a barre Codabar. Valore predefinito: CodabarChecksumMode.Mod16. Per abilitare il calcolo del checksum imposta il valore EnableChecksum.Yes sulla proprietà EnableChecksum. Vedi ChecksumMode (\#getChecksumMode.getChecksumMode/\#setChecksumMode.setChecksumMode).

**Returns:**
[CodabarChecksumMode](../../com.aspose.barcode.generation/codabarchecksummode) - the checksum algorithm for Codabar barcodes.
