## DataMatrixExtendedParameters.StructuredAppendBarcodeId property

Ottiene l'ID del codice a barre DataMatrix in modalità append strutturata. L'ID inizia da 1 e deve essere minore o uguale al numero di codici a barre. Il valore predefinito è -1.

```csharp
public int StructuredAppendBarcodeId { get; }
```

### Property Value

L'ID del codice a barre in modalità structured append di DataMatrix.
