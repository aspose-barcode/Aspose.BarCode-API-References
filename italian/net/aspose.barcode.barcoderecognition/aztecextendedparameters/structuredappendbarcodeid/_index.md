## AztecExtendedParameters.StructuredAppendBarcodeId property

Ottiene l'ID del codice a barre in modalità append strutturata Aztec. L'ID inizia da 1 e deve essere minore o uguale al conteggio dei codici a barre. Il valore predefinito è 0.

```csharp
public int StructuredAppendBarcodeId { get; }
```

### Property Value

L'ID del codice a barre della modalità append strutturata Aztec.
