## DotCodeExtendedParameters.StructuredAppendModeBarcodeId property

Ottiene l'ID del codice a barre in modalità di aggiunta strutturata DotCode. L'ID inizia da 1 e deve essere minore o uguale al conteggio dei codici a barre. Il valore predefinito è -1.

```csharp
public int StructuredAppendModeBarcodeId { get; }
```

### Property Value

L'ID del codice a barre in modalità di aggiunta strutturata DotCode.
