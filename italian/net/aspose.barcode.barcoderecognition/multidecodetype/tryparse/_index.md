## MultiDecodeType.TryParse method

Converte la rappresentazione stringa di un MultiDecodeType nella sua istanza. Un valore di ritorno indica se la conversione è riuscita o è fallita.

```csharp
public static bool TryParse(string parsingType, out MultiDecodeType result)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| parsingType | String | Una stringa nel formato, ad esempio "AllSupportedTypes" o "EAN8,EAN13,CodaBar", da convertire. |
| result | MultiDecodeType& | Viene restituito un vero MultiDecodeType, quando la conversione è completata con successo; |

### Valore restituito

**true** if s was converted successfully; otherwise, **false**.
