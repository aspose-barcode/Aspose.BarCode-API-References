## SvgColorMode enumeration

Modalità possibili per il riempimento del colore nel file svg, RGB è predefinito e supportato da SVG 1.1. RGBA, HSL, HSLA sono consentiti nello standard SVG 2.0. Anche in RGB l'opacità sarà impostata tramite il parametro \"fill-opacity\"

```csharp
public enum SvgColorMode
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| RGB | `0` | Modalità RGB, esempio: fill=\"#ff5511\" fill-opacity=\"0.73\". Modalità predefinita. |
| RGBA | `1` | Modalità RGBA, esempio: fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | `2` | Modalità HSL, esempio: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | `3` | Modalità HSLA, esempio: fill=\"hsla(30, 50%, 70%, 0.8)\" |
