## CodabarParameters.ChecksumMode property

Ottieni o imposta l'algoritmo di checksum per i codici a barre Codabar. Valore predefinito: CodabarChecksumMode.Mod16. Per abilitare il calcolo del checksum imposta il valore EnableChecksum.Yes sulla proprietà EnableChecksum. Vedi `ChecksumMode`.

public CodabarChecksumMode ChecksumMode { get; set; }
