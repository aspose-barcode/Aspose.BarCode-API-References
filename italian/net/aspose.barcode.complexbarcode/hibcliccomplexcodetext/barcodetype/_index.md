## HIBCLICComplexCodetext.BarcodeType property

Ottiene o imposta il tipo di codice a barre. Il testo del codice HIBC LIC può essere codificato usando i tipi di codifica HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC e HIBCQRLIC. Valore predefinito: HIBCCode39LIC.

```csharp
public BaseEncodeType BarcodeType { get; set; }
```

### Valore restituito

Tipo di codice a barre.
