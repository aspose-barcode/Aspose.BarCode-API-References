## GS1Codetext.Parse method

Analizza una stringa di elemento GS1 tra parentesi nella forma (AI)value(AI)value. Una parentesi '(' letterale all'interno di un valore deve essere scritta come \\(; nessun'altra sequenza di escape è supportata e ')' non richiede escape.

```csharp
public static GS1Codetext Parse(string value)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| valore | String | Stringa di elemento GS1 tra parentesi da analizzare. |

### Valore restituito

Un codetext GS1 analizzato.
