## AztecParametersUI.LayersCount property

Ottiene o imposta il numero di livelli del simbolo Aztec. Il numero di livelli deve essere compreso tra 1 e 3 per la modalità Compact e tra 1 e 32 per la modalità Full Range. Valore predefinito: 0 (auto).

public int LayersCount { get; set; }
