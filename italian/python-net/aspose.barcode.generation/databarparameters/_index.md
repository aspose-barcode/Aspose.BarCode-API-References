## DataBarParameters class

Parametri Databar.

Il tipo DataBarParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_2d_composite_component | Abilita il flag del componente composito 2D con il codice a barre DataBar |
| allow_only_gs1_encoding | Se questo flag è impostato, consente solo lo standard di codifica GS1 per i tipi di codice a barre Databar |
| colonne | Conteggio colonne. |
| righe | Conteggio righe. |
| aspect_ratio | Rapporto Altezza/Larghezza del modulo BarCode 2D.<br/>            Utilizzato per DataBar impilato. |
