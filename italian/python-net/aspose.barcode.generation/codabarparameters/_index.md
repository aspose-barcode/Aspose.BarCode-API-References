## CodabarParameters class

Parametri Codabar.

Il tipo CodabarParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| checksum_mode | Ottieni o imposta l'algoritmo di checksum per i codici a barre Codabar.<br/>            Valore predefinito: CodabarChecksumMode.Mod16.<br/>            Per abilitare il calcolo del checksum imposta il valore EnableChecksum.Yes sulla proprietà EnableChecksum.<br/>            Vedi [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Simbolo di inizio (carattere) della simbologia Codabar.<br/>            Valore predefinito: CodabarSymbol.A |
| stop_symbol | Simbolo di fine (carattere) della simbologia Codabar.<br/>            Valore predefinito: CodabarSymbol.A |
