## HslaColor class

Classe per rappresentare il colore HSLA (Tonalità, Saturazione, Luminosità, Alfa)

Il tipo HslaColor espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| HslaColor(h, s, l, a) | Inizializza una nuova istanza della classe HslaColor |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| H | Tonalità [0, 360] |
| S | Saturazione [0, 100] |
| L | Luminosità [0, 100] |
| a | Alfa (opacità) [0.0f, 1.0f] |
## Metodi
| Nome | Descrizione |
| :- | :- |
| convert_hsla_to_rgba(hsla_color) | Utilizza https://en.wikipedia.org/wiki/HSL_and_HSV#HSL_to_RGB |
