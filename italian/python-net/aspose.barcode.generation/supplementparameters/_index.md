## SupplementParameters class

Parametri supplementari. Utilizzati per Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

Il tipo SupplementParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| supplement_data | Dati supplementari dopo BarCode. |
| supplement_space | Spazio tra il BarCode principale e il BarCode supplementare in valore [Unit](/barcode/python-net/aspose.barcode.generation/unit/). |
