## CaptionParameters class

Parametri della didascalia.

Il tipo CaptionParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| text | Testo della didascalia.<br/>            Valore predefinito: stringa vuota. |
| font | Carattere della didascalia.<br/>            Valore predefinito: Arial 8pt regular. |
| visible | Visibilità del testo della didascalia.<br/>            Valore predefinito: false. |
| text_color | Colore del testo della didascalia.<br/>            Valore predefinito: Color.Black. |
| padding | Spaziatura delle didascalie.<br/>            Valore predefinito per CaptionAbove: 5pt 5pt 0 5pt.<br/>            Valore predefinito per CaptionBelow: 0 5pt 5pt 5pt. |
| allineamento | Allineamento orizzontale del test della didascalia.<br/>            Valore predefinito: StringAlignment.Center. |
| no_wrap | Specifica le interruzioni di riga (a capo) all'interno del testo.<br/>            Valore predefinito: false. |
