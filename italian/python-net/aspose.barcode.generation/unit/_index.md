## Unit class

Specifica il valore di dimensione in diverse unità (Pixel, Pollici, ecc.).

Il tipo Unit espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| pixel | Ottiene o imposta il valore della dimensione in pixel. |
| pollici | Ottiene o imposta il valore della dimensione in pollici. |
| millimetri | Ottiene o imposta il valore della dimensione in millimetri. |
| punto | Ottiene o imposta il valore della dimensione in punti. |
| documento | Ottiene o imposta il valore della dimensione in unità di documento. |
| risoluzione | Risoluzione |
