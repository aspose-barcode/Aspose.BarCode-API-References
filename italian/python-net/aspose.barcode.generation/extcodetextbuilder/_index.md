## ExtCodetextBuilder class

Classe di supporto per la generazione automatica di codetext nella Modalità Codetext Estesa

Il tipo ExtCodetextBuilder espone i seguenti membri:
## Metodi
| Nome | Descrizione |
| :- | :- |
| clear() | Cancella gli elementi di codetext esteso |
| add_plain_codetext(codetext) | Aggiunge codetext semplice agli elementi di codetext esteso |
| add_eci_codetext(eci_encoding, codetext) | Aggiunge codetext con Identificatore di Canale Esteso |
| get_extended_codetext() | Genera codetext esteso dall'elenco degli elementi di generazione |
