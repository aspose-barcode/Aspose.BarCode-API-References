## ITF14BorderType enumeration

Tipo di bordo ITF14 del codice a barre

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Nessun bordo che racchiude il codice a barre |
| FRAME | Cornice che racchiude il codice a barre |
| BAR | Due barre orizzontali che racchiudono il codice a barre |
| FRAME_OUT | Cornice che racchiude il codice a barre. Viene disegnata all'esterno del codice a barre e non influisce sull'altezza. |
| BAR_OUT | Due barre orizzontali che racchiudono il codice a barre. Vengono disegnate all'esterno del codice a barre e non influiscono sull'altezza. |
