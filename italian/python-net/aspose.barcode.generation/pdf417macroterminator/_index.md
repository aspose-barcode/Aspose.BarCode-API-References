## Pdf417MacroTerminator enumeration

Usato per indicare al codificatore se aggiungere il Terminatore Macro PDF417 (codeword 922) al segmento. <br/>            Applicato solo per Macro PDF417.

## Members
| Nome membro | Descrizione |
| :- | :- |
| AUTO | Il terminatore verrà aggiunto automaticamente se è fornito il numero di segmenti <br/>            e il segmento corrente è l'ultimo. In altri casi, il terminatore non verrà aggiunto. |
| NONE | Il terminatore non verrà aggiunto. |
| SET | Il terminatore verrà aggiunto. |
