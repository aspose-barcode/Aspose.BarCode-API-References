## Code16KParameters class

Parametri Code16K.

Il tipo Code16KParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| aspect_ratio | Rapporto altezza/larghezza del modulo 2D BarCode. |
| quiet_zone_left_coef | Dimensione della zona silenziosa sinistra in xDimension.<br/>            Valore predefinito: 10, il che significa che se xDimension = 2px la zona silenziosa sinistra sarà di 20px. |
| quiet_zone_right_coef | Dimensione della zona silenziosa destra in xDimension.<br/>            Valore predefinito: 1, il che significa che se xDimension = 2px la zona silenziosa destra sarà di 2px. |
