## PdfParameters class

Parametri PDF.

Il tipo PdfParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| cmyk_bar_color | Nullable. Valore colore CMYK del codice a barre. Null indica che il colore CMYK non è usato, invece viene utilizzato il colore RGB normale. |
| cmyk_back_color | Nullable. Valore colore CMYK di sfondo. Null indica che il colore CMYK non è usato, invece viene utilizzato il colore RGB normale. |
| cmyk_codetext_color | Nullable. Valore colore CMYK del Codetext. Null indica che il colore CMYK non è usato, invece viene utilizzato il colore RGB normale. |
| cmyk_caption_above_color | Nullable. Valore colore CMYK della didascalia superiore. Null indica che il colore CMYK non è usato, invece viene utilizzato il colore RGB normale. |
| cmyk_caption_below_color | Nullable. Valore colore CMYK della didascalia inferiore. Null indica che il colore CMYK non è usato, invece viene utilizzato il colore RGB normale. |
| is_text_as_path | I percorsi sono usati al posto del testo (usare se i caratteri Unicode non vengono visualizzati)<br/>            Valore predefinito: false. |
