## AutoSizeMode enumeration

Specifica i diversi tipi di modalità di dimensionamento automatico.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Il ridimensionamento automatico è disabilitato. |
| NEAREST | Ridimensiona il codice a barre alla dimensione più bassa possibile più vicina specificata dalle proprietà ImageWidth e ImageHeight.<br/>            Preserva il rapporto d'aspetto predefinito. |
| INTERPOLATION | Ridimensiona il codice a barre alla dimensione specificata.<br/>            La dimensione può essere specificata dalle proprietà ImageWidth e ImageHeight.<br/>            Il codice a barre generato potrebbe risultare non valido (illeggibile) dopo la scalatura. |
