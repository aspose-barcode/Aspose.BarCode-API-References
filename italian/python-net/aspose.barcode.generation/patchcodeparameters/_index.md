## PatchCodeParameters class

Parametri PatchCode.

Il tipo PatchCodeParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| extra_barcode_text | Specifica il codetext per un QR barcode aggiuntivo, quando PatchCode è generato in modalità pagina. |
| format | Formato PatchCode. Scegli PatchOnly per generare un singolo PatchCode. Usa il formato pagina per generare una pagina Patch con i PatchCode come bordi.<br/>            Valore predefinito: PatchFormat.PatchOnly |
| patch_format | Formato PatchCode. Scegli PatchOnly per generare un singolo PatchCode. Usa il formato pagina per generare una pagina Patch con i PatchCode come bordi.<br/>            Valore predefinito: PatchFormat.PatchOnly |
