## BorderParameters class

Parametri del bordo dell'immagine barcode

Il tipo BorderParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| visible | Visibilità del bordo. Se false, il parametro Width è sempre ignorato (0).<br/>            Valore predefinito: false. |
| larghezza | Larghezza del bordo.<br/>            Valore predefinito: 0.<br/>            Ignorata se Visible è impostato a false. |
| dash_style | Stile di tratteggio del bordo.<br/>            Valore predefinito: BorderDashStyle.Solid. |
| colore | Colore del bordo.<br/>            Valore predefinito: Color.Black. |
