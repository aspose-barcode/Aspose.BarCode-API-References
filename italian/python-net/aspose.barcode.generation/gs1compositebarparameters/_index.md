## GS1CompositeBarParameters class

Parametri della barra composita GS1.

Il tipo GS1CompositeBarParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| linear_component_type | Tipo di componente lineare: GS1Code128, UPCE, EAN8, UPCA, EAN13, DatabarStacked, DatabarStackedOmniDirectional, DatabarLimited, DatabarOmniDirectional, DatabarExpanded, DatabarExpandedStacked |
| two_d_component_type | Tipo di componente 2D |
| allow_only_gs1_encoding | Se questo flag è impostato, consente solo lo standard di codifica GS1 per il componente 2D GS1CompositeBar |
