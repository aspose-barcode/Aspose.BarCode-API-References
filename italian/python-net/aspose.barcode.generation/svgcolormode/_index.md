## SvgColorMode enumeration

Modalità possibili per il colore di riempimento in un file svg, RGB è predefinito e supportato da SVG 1.1.<br/>            RGBA, HSL, HSLA sono consentiti nello standard SVG 2.0.<br/>            Anche con RGB l'opacità sarà impostata tramite il parametro "fill-opacity".

## Members
| Nome membro | Descrizione |
| :- | :- |
| RGB | Modalità RGB, esempio: fill=\"#ff5511\" fill-opacity=\"0.73\". Modalità predefinita. |
| RGBA | Modalità RGBA, esempio: fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | Modalità HSL, esempio: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | Modalità HSLA, esempio: fill=\"hsla(30, 50%, 70%, 0.8)\" |
