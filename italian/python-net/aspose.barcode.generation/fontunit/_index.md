## FontUnit class

Definisce un formato particolare per il testo, includendo il tipo di carattere, la dimensione e gli attributi di stile<br/>            dove la dimensione è nella proprietà valore Unit.

Il tipo FontUnit espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| family_name | Ottiene o imposta il nome del tipo di carattere di questo Font. |
| style | Ottiene o imposta le informazioni di stile per questo FontUnit. |
| size | Ottiene o imposta la dimensione di questo FontUnit in valore Unit. |
