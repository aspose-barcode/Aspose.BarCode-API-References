## EncodeTypes class

Specifica il tipo di barcode da codificare.

Il tipo EncodeTypes espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| all_encode_types | Specifica che i dati verranno controllati con tutte le simbologie disponibili. |
| NONE | Tipo di codifica non specificato. |
| CODABAR | Specifica che i dati devono essere codificati secondo la specifica del codice a barre CODABAR |
| CODE11 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre CODE 11 |
| CODE39 | Specifica che i dati devono essere codificati secondo la specifica del set di caratteri base del codice a barre Code 39: ISO/IEC 16388 |
| CODE_39_FULL_ASCII | Specifica che i dati devono essere codificati secondo la specifica del set di caratteri ASCII completo del codice a barre Code 39: ISO/IEC 16388 |
| CODE93 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre CODE 93 |
| CODE128 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre CODE 128 |
| GS1_CODE_128 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre GS1 Code 128. Il testo del codice deve contenere parentesi per l'AI. |
| EAN8 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre EAN-8 |
| EAN13 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre EAN-13 |
| EAN14 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre EAN14 |
| SCC14 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre SCC14 |
| SSCC18 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre SSCC18 |
| UPCA | Specifica che i dati devono essere codificati secondo la specifica del codice a barre UPC-A |
| UPCE | Specifica che i dati devono essere codificati secondo la specifica del codice a barre UPC-E |
| ISBN | Specifica che i dati devono essere codificati secondo la specifica del codice a barre ISBN |
| ISSN | Specifica che i dati devono essere codificati secondo la specifica del codice a barre ISSN |
| ISMN | Specifica che i dati devono essere codificati secondo la specifica del codice a barre ISMN |
| STANDARD_2OF_5 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Standard 2 of 5 |
| INTERLEAVED_2OF_5 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre INTERLEAVED 2 of 5 |
| MATRIX_2OF_5 | Rappresenta il codice a barre Matrix 2 of 5 |
| ITALIAN_POST25 | Rappresenta il codice a barre Italian Post 25. |
| IATA2OF_5 | Rappresenta il codice a barre IATA 2 of 5. IATA (International Air Transport Association) utilizza questo codice a barre per la gestione del carico aereo. |
| ITF14 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre ITF14 |
| ITF6 | Rappresenta il codice a barre ITF-6. |
| MSI | Specifica che i dati devono essere codificati secondo la specifica del codice a barre MSI Plessey |
| VIN | Rappresenta il codice a barre VIN (Vehicle Identification Number). |
| DEUTSCHE_POST_IDENTCODE | Rappresenta il codice a barre Deutsch Post, questa simbologia è anche nota come Identcode,CodeIdentcode,German Postal 2 of 5 Identcode, <br/>            Deutsch Post AG Identcode, Deutsch Frachtpost Identcode, Deutsch Post AG (DHL) |
| DEUTSCHE_POST_LEITCODE | Rappresenta il codice a barre Deutsch Post Leitcode, anche noto come German Postal 2 of 5 Leitcode, CodeLeitcode, Leitcode, Deutsch Post AG (DHL). |
| OPC | Rappresenta il codice a barre OPC (Optical Product Code), anche noto come VCA Barcode VCA OPC, Vision Council of America OPC Barcode. |
| PZN | Rappresenta il codice a barre PZN. Questa simbologia è anche nota come Pharmacy central number, Pharmazentralnummer. Sono supportati PZN7 e PZN8. <br/>            PZN7 è generato da 6 o meno cifre, come "123456". PZN8 è generato da 7 o più cifre, come "1234567". <br/>            L'ultima cifra di controllo fornita viene ignorata e generata dal motore del codice a barre. |
| CODE_16K | Rappresenta il codice a barre Code 16K. |
| PHARMACODE | Rappresenta il codice a barre Pharmacode. |
| DATA_MATRIX | Simbologia di codice a barre 2D DataMatrix |
| QR | Specifica che i dati devono essere codificati secondo la specifica del codice a barre QR Code |
| AZTEC | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Aztec |
| GS1_AZTEC | Specifica che i dati devono essere codificati secondo la specifica del codice a barre GS1 Aztec. Il testo del codice deve contenere parentesi per l'AI. |
| PDF417 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Pdf417 |
| MACRO_PDF417 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre MacroPdf417 |
| GS1_DATA_MATRIX | Simbologia di codice a barre 2D DataMatrix con formato stringa GS1 |
| MICRO_PDF417 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre MicroPdf417 |
| GS1_MICRO_PDF_417 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre GS1MicroPdf417 |
| GS1QR | Simbologia di codice a barre 2D QR con formato stringa GS1 |
| MAXI_CODE | Specifica che i dati devono essere codificati secondo la specifica del codice a barre MaxiCode |
| DOT_CODE | Specifica che i dati devono essere codificati secondo la specifica del codice a barre DotCode |
| HAN_XIN | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Han Xin |
| GS1_HAN_XIN | Simbologia di codice a barre 2D HanXin con formato stringa GS1 |
| MICRO_QR | Specifica che i dati devono essere codificati secondo la specifica del codice a barre MicroQR Code |
| RECT_MICRO_QR | Specifica che i dati devono essere codificati secondo la specifica del codice a barre RectMicroQR (rMQR) Code |
| AUSTRALIA_POST | Rappresenta il codice a barre del cliente Australia Post |
| JAPAN_POST | Rappresenta il codice a barre Japan Post |
| POSTNET | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Postnet |
| PLANET | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Planet |
| ONE_CODE | Specifica che i dati devono essere codificati secondo la specifica del codice a barre USPS OneCode |
| RM4SCC | Rappresenta il codice a barre RM4SCC. RM4SCC (Royal Mail 4-state Customer Code) è utilizzato per il processo di smistamento automatico della posta nel Regno Unito. |
| MAILMARK | Rappresenta il codice a barre Royal Mail Mailmark. |
| DATABAR_OMNI_DIRECTIONAL | Specifica che i dati devono essere codificati secondo la specifica del codice a barre GS1 Databar omni-directional. |
| DATABAR_TRUNCATED | Specifica che i dati devono essere codificati secondo la specifica del codice a barre GS1 Databar truncated. |
| DATABAR_LIMITED | Rappresenta il codice a barre GS1 Databar limited. |
| DATABAR_EXPANDED | Rappresenta il codice a barre GS1 Databar expanded. |
| DATABAR_EXPANDED_STACKED | Rappresenta il codice a barre GS1 Databar expanded stacked. |
| DATABAR_STACKED | Rappresenta il codice a barre GS1 Databar stacked. |
| DATABAR_STACKED_OMNI_DIRECTIONAL | Rappresenta il codice a barre GS1 Databar stacked omni-directional. |
| SINGAPORE_POST | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Singapore Post Barcode. |
| AUSTRALIAN_POSTE_PARCEL | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Australian Post Domestic eParcel Barcode. |
| SWISS_POST_PARCEL | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Swiss Post Parcel Barcode. Tipi supportati: Domestic Mail, International Mail, Additional Services (new). |
| PATCH_CODE | Rappresenta il codice a barre Patch code. |
| CODE32 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Code32. |
| DATA_LOGIC_2OF_5 | Specifica che i dati devono essere codificati secondo la specifica del codice a barre DataLogic 2 of 5. |
| DUTCH_KIX | Specifica che i dati devono essere codificati secondo la specifica del codice a barre Dutch KIX. |
| UPCA_GS_1_CODE_128_COUPON | Specifica che i dati devono essere codificati secondo la specifica del codice a barre UPC coupon con GS1-128 Extended Code.<br/>            Un esempio della stringa di input:<br/>            BarcodeGenerator.Codetext = "514141100906(8102)03",<br/>            dove la parte UPCA è "514141100906", la parte GS1Code128 è (8102)03. |
| UPCA_GS_1_DATABAR_COUPON | Specifica che i dati devono essere codificati con il coupon UPC con specifica di codice a barre GS1 DataBar addition.<br/>            Un esempio della stringa di input:<br/>            BarcodeGenerator.Codetext = "514141100906(8110)106141416543213500110000310123196000",<br/>            dove la parte UPCA è "514141100906", la parte Databar è "(8110)106141416543213500110000310123196000".<br/>            Per modificare la didascalia, utilizzare Parameters.CaptionAbove.Text = "company prefix + offer code"; |
| CODABLOCK_F | Specifica che i dati devono essere codificati con la specifica del codice a barre Codablock-F. |
| GS1_CODABLOCK_F | Specifica che i dati devono essere codificati con la specifica del codice a barre GS1 Codablock-F. Il codetext deve contenere parentesi per gli AI. |
| GS1_COMPOSITE_BAR | Specifica che i dati devono essere codificati con la specifica del codice a barre GS1 Composite Bar. Il codetext deve contenere parentesi per gli AI. Il codetext 1D e il codetext 2D devono essere separati dal simbolo '/' |
| HIBC_CODE_39LIC | Specifica che i dati devono essere codificati con la specifica del codice a barre HIBC LIC Code39. |

| Nome | Descrizione |
