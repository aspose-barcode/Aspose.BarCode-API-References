## SvgParameters class

Parametri SVG.

Il tipo SvgParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_explicit_size_in_pixels | L'immagine SVG contiene una dimensione esplicita in pixel (consigliato)<br/>            Valore predefinito: true. |
| is_text_drawn_in_text_element | L'immagine SVG contiene testo come elemento di testo anziché percorsi (consigliato)<br/>            Valore predefinito: true. |
| svg_color_mode | Modalità possibili per il colore di riempimento in un file svg, RGB è predefinito e supportato da SVG 1.1.<br/>            RGBA, HSL, HSLA sono consentiti nello standard SVG 2.0.<br/>            Anche con RGB l'opacità sarà impostata tramite il parametro "fill-opacity". |
