## ITFParameters class

Parametri ITF.

Il tipo ITFParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| border_thickness | Ottiene o imposta lo spessore del bordo ITF (barra di supporto) in valore Unit.<br/>            Valore predefinito: 12pt. |
| border_type | Tipo di bordo del codice a barre ITF.<br/>            Valore predefinito: ITF14BorderType.Bar. |
| quiet_zone_coef | Dimensione delle zone silenziose in xDimension.<br/>            Valore predefinito: 10, il che significa che se xDimension = 2px le zone silenziose saranno 20px. |
