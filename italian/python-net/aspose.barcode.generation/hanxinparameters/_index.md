## HanXinParameters class

Parametri Han Xin.

Il tipo HanXinParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| version | Versione del codice HanXin.<br/>            Da Version01 a Version84 per il codice Han Xin.<br/>            Il valore predefinito è Version.Auto. |
| error_level | Livello di correzione errori Reed-Solomon per il codice a barre Han Xin.<br/>            Da basso a alto: L1, L2, L3, L4. vedi ErrorLevel. |
| encode_mode | Modalità di codifica HanXin.<br/>            Valore predefinito: EncodeMode.Mixed. |
| eci_encoding | Identificatori di Extended Channel Interpretation. Vengono usati per fornire al lettore di codici a barre dettagli<br/>            sui riferimenti utilizzati per codificare i dati nel simbolo.<br/>            L'implementazione corrente contiene tutte le codifiche di set di caratteri conosciute. |
