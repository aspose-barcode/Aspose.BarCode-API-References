## DataMatrixEccType enumeration

Specifica il tipo di ECC da codificare.

## Members
| Nome membro | Descrizione |
| :- | :- |
| ECC_AUTO | Specifica che il tipo Ecc codificato è definito per impostazione predefinita dalla correzione d'errore Reed-Solomon o ECC 200. |
| ECC000 | Specifica che il tipo Ecc codificato è definito ECC 000. |
| ECC050 | Specifica che il tipo Ecc codificato è definito ECC 050. |
| ECC080 | Specifica che il tipo Ecc codificato è definito ECC 080. |
| ECC100 | Specifica che il tipo Ecc codificato è definito ECC 100. |
| ECC140 | Specifica che il tipo Ecc codificato è definito ECC 140. |
| ECC200 | Specifica che il tipo Ecc codificato è definito ECC 200. Si consiglia di usarlo. |
