## Costruttori

## Metodi
| Nome | Descrizione |
| :- | :- |
| clear() | Cancella gli elementi di codetext esteso |
| add_plain_codetext(codetext) | Aggiunge codetext semplice agli elementi di codetext esteso |

| get_extended_codetext() | Genera il Codetext Esteso dall'elenco di codetext esteso. |
