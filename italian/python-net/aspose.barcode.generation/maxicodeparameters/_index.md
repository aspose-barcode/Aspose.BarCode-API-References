## MaxiCodeParameters class

Parametri MaxiCode.

Il tipo MaxiCodeParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| modalità | Ottiene o imposta una modalità di codifica MaxiCode. |
| encode_mode | Ottiene o imposta una modalità di codifica MaxiCode. <br/>            Valore predefinito: Auto. |
| eci_encoding | Ottiene o imposta la codifica ECI. Usato quando MaxiCodeEncodeMode è Auto.<br/>            Valore predefinito: ISO-8859-1 |
| structured_append_mode_barcode_id | Ottiene o imposta un ID di codice a barre MaxiCode in modalità di aggiunta strutturata. <br/>            L'ID deve essere un valore compreso tra 1 e 8. <br/>            Valore predefinito: 0 |
| structured_append_mode_barcodes_count | Ottiene o imposta il conteggio dei codici a barre MaxiCode in modalità di aggiunta strutturata. <br/>            Il numero di conteggio deve essere un valore compreso tra 2 e 8 (conteggio massimo di codici a barre).<br/>            Valore predefinito: -1 |
| aspect_ratio | Rapporto altezza/larghezza del modulo 2D BarCode. |
