## Code128EncodeMode enumeration

Modalità di codifica per i codici a barre Code128.

## Members
| Nome membro | Descrizione |
| :- | :- |
| AUTO | Codifica il testo del codice in modalità classica ISO 15417. La modalità dovrebbe essere utilizzata in tutti i casi ordinari. |
| CODE_A | Codifica il testo del codice solo nel set di codici 128A. |
| CODE_B | Codifica il testo del codice solo nel set di codici 128B. |
| CODE_C | Codifica il testo del codice solo nel set di codici 128C. |
| CODE_AB | Codifica il testo del codice solo nei set di codici 128A e 128B. |
| CODE_AC | Codifica il testo del codice solo nei set di codici 128A e 128C. |
| CODE_BC | Codifica il testo del codice solo nei set di codici 128B e 128C. |
