## DotCodeParameters class

Parametri DotCode.

Il tipo DotCodeParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| aspect_ratio | Rapporto altezza/larghezza del modulo 2D BarCode. |
| encode_mode | Identifica la modalità di codifica DotCode. <br/>            Valore predefinito: Auto. |
| is_reader_initialization | Indica se il codice è usato per istruire il lettore a interpretare i dati seguenti come istruzioni per l'inizializzazione o la riprogrammazione del lettore di codici a barre.<br/>            Il valore predefinito è false. |
| structured_append_mode_barcode_id | Identifica l'ID del codice a barre in modalità di aggiunta strutturata DotCode. L'ID inizia da 1 e deve essere minore o uguale al conteggio dei codici a barre. Il valore predefinito è -1. |
| structured_append_mode_barcodes_count | Identifica il conteggio dei codici a barre in modalità di aggiunta strutturata DotCode. Il valore predefinito è -1. Il conteggio deve essere un valore da 1 a 35. |
| eci_encoding | Identifica la codifica ECI. Utilizzata quando DotCodeEncodeMode è Auto.<br/>            Valore predefinito: ISO-8859-1 |
| righe | Identifica il conteggio delle righe. La somma del numero di righe più il numero di colonne di un simbolo DotCode deve essere dispari. Il numero di righe deve essere almeno 5.<br/>            Valore predefinito: -1 |
| colonne | Identifica il conteggio delle colonne. La somma del numero di righe più il numero di colonne di un simbolo DotCode deve essere dispari. Il numero di colonne deve essere almeno 5.<br/>            Valore predefinito: -1 |
