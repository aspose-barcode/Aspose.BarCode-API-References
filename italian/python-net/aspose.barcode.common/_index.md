## Classi
| Classe | Descrizione |
| :- | :- |
| [GS1Element](/barcode/python-net/aspose.barcode.common/gs1element/) | Rappresenta una coppia immutabile di Identificatore Applicazione GS1 e valore. |
| [GS1ValidationIssue](/barcode/python-net/aspose.barcode.common/gs1validationissue/) | Descrive un errore di convalida GS1. |
| [GS1ValidationResult](/barcode/python-net/aspose.barcode.common/gs1validationresult/) | Contiene tutti gli errori rilevabili in modo indipendente per una stringa di elemento GS1, URI Digital Link o un valore AI. |
| [ProcessorSettings](/barcode/python-net/aspose.barcode.common/processorsettings/) | ProcessorSettings consente di riconoscere i codici a barre con aumento delle prestazioni tramite multithreading. |
