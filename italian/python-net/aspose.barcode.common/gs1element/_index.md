## GS1Element class

Rappresenta una coppia immutabile di Identificatore Applicazione GS1 e valore.

Il tipo GS1Element espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| application_identifier | Ottiene l'Identificatore di Applicazione GS1 esatto. |
| value | Ottiene il valore convalidato associato all'Identificatore di Applicazione. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| validate(application_identifier, value) | Convalida un valore per un Identificatore di Applicazione GS1 esatto. |
