## ProcessorSettings class

ProcessorSettings consente di riconoscere i codici a barre con aumento delle prestazioni tramite multithreading.

Il tipo ProcessorSettings espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| use_all_cores | È necessario per utilizzare tutti i core. |
| use_only_this_cores_count | Specifica il numero di core da utilizzare. <br/>            È necessario modificare la proprietà "UseAllCores" su "false". |
| max_additional_allowed_threads | Specifica il numero massimo di thread aggiuntivi per eseguire il codice in parallelo |
