## GS1ValidationIssue class

Descrive un errore di convalida GS1.

Il tipo GS1ValidationIssue espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| code | Restituisce un codice di errore leggibile dalla macchina stabile. |
| application_identifier | Restituisce l'Identificatore dell'Applicazione relativo all'errore, o null quando l'Identificatore dell'Applicazione<br/>            non può essere determinato dall'input. |
| message | Restituisce il messaggio di errore leggibile dall'uomo. |
