## GS1ValidationResult class

Contiene tutti gli errori rilevabili in modo indipendente per una stringa di elemento GS1, URI Digital Link o un valore AI.

Il tipo GS1ValidationResult espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_valid | Restituisce un valore che indica se la convalida è terminata senza errori. |
| problemi | Restituisce gli errori di convalida in ordine deterministico. |
