## PrimaryData class

Classe per la memorizzazione dei dati primari HIBC LIC.

Il tipo PrimaryData espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PrimaryData() | Inizializza una nuova istanza della classe PrimaryData |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| labeler_identification_code | Identifica la data del codice di identificazione del produttore.<br/>            Il codice di identificazione del produttore deve essere una stringa alfanumerica di 4 simboli, con il primo carattere sempre alfabetico. |
| product_or_catalog_number | Identifica il numero di prodotto o di catalogo. Il numero di prodotto o di catalogo deve essere una stringa alfanumerica con una lunghezza massima di 18 simboli. |
| unit_of_measure_id | Identifica l'ID dell'unità di misura. L'ID dell'unità di misura deve essere un valore intero da 0 a 9. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| parse_from_string(primary_data_codetext) | Istanzia i dati primari dal formato stringa secondo la specifica HIBC LIC. |
