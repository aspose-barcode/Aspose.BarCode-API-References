## SwissQRBill class

Dati della fattura SwissQR

Il tipo SwissQRBill espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| version | Ottiene o imposta la versione dello standard SwissQR bill. |
| amount | Ottiene o imposta l'importo del pagamento. |
| currency | Ottiene o imposta la valuta del pagamento. |
| account | Ottiene o imposta il numero di conto del creditore. |
| creditor | Ottiene o imposta l'indirizzo del creditore. |
| reference | Ottiene o imposta il riferimento di pagamento del creditore. |
| debtor | Ottiene o imposta l'indirizzo del debitore. |
| unstructured_message | Ottiene o imposta il messaggio non strutturato aggiuntivo. |
| bill_information | Ottiene o imposta le informazioni di fattura strutturate aggiuntive. |
| alternative_schemes | Ottiene o imposta gli schemi di pagamento alternativi. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| create_and_set_creditor_reference(raw_reference) | Crea e imposta un riferimento creditore ISO11649 da una stringa grezza aggiungendo<br/>            la stringa con "RF" e il checksum modulo 97. |
| equals(other) | Determina se l'oggetto specificato è uguale all'oggetto corrente. |
