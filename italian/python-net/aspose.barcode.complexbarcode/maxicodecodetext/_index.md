## MaxiCodeCodetext class

Classe base per la codifica e la decodifica del testo incorporato nel codice MaxiCode.

Il tipo MaxiCodeCodetext espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| encode_mode | Ottiene o imposta una modalità di codifica MaxiCode. <br/>            Valore predefinito: Auto. |
| eci_encoding | Ottiene o imposta la codifica ECI. Usato quando MaxiCodeEncodeMode è Auto.<br/>            Valore predefinito: ISO-8859-1 |
## Metodi
| Nome | Descrizione |
| :- | :- |
| get_mode() | Ottiene la modalità MaxiCode. |
| get_constructed_codetext() | Costruisce codetext |
| init_from_string(constructed_codetext) | Inizializza l'istanza dal codetext costruito. |
| get_barcode_type() | Ottiene il tipo di codice a barre. |
