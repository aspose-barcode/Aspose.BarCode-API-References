## Address class

Indirizzo del creditore o del debitore.

Il tipo Address espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Address() | Crea un'istanza di Address |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| type | Ottiene il tipo di indirizzo. |
| name | Ottiene o imposta il nome, sia il nome e cognome di una persona fisica o il<br/>            nome dell'azienda di una persona giuridica. |
| address_line1 | Ottiene o imposta la riga di indirizzo 1. |
| address_line2 | Ottiene o imposta la riga di indirizzo 2. |
| street | Ottiene o imposta la via. |
| house_no | Ottiene o imposta il numero civico. |
| postal_code | Ottiene o imposta il codice postale. |
| town | Ottiene o imposta il paese o la città. |
| country_code | Ottiene o imposta il codice paese ISO a due lettere. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| clear() | Cancella tutti i campi e imposta il tipo su [UNDETERMINED](/barcode/python-net/aspose.barcode.complexbarcode/addresstype/). |
| equals(other) | Determina se l'oggetto specificato è uguale all'oggetto corrente. |
