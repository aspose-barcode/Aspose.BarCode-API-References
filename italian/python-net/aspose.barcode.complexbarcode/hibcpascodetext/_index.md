## HIBCPASCodetext class

Classe per la codifica e la decodifica del testo incorporato nel codice HIBC PAS.

Il tipo HIBCPASCodetext espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| HIBCPASCodetext() | Inizializza una nuova istanza della classe HIBCPASCodetext |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| barcode_type | Ottiene o imposta il tipo di codice a barre. Il codetext HIBC PAS può essere codificato usando i tipi di codifica HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS e HIBCQRPAS.<br/>            Valore predefinito: HIBCCode39PAS. |
| data_location | Identifica la posizione dei dati. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| add_record(data_type, data) | Aggiunge un nuovo record |
| add_record(record) | Aggiunge un nuovo record |
| get_records() | Ottiene l'elenco dei record |
| clear() | Cancella l'elenco dei record |
| get_barcode_type() | Ottiene il tipo di codice a barre. |
| get_constructed_codetext() | Costruisce codetext |
| init_from_string(constructed_codetext) | Inizializza l'istanza dal codetext costruito. |
