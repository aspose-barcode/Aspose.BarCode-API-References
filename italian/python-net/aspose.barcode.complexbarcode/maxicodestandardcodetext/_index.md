## MaxiCodeStandardCodetext class

Classe per la codifica e la decodifica del codetext MaxiCode per le modalità 4, 5 e 6.

Il tipo MaxiCodeStandardCodetext espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| MaxiCodeStandardCodetext() | Inizializza una nuova istanza della classe MaxiCodeStandardCodetext |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| encode_mode | Ottiene o imposta una modalità di codifica MaxiCode. <br/>            Valore predefinito: Auto. |
| eci_encoding | Ottiene o imposta la codifica ECI. Usato quando MaxiCodeEncodeMode è Auto.<br/>            Valore predefinito: ISO-8859-1 |
| modalità | Ottiene o imposta la modalità MaxiCode. Il codetext standard può essere usato solo con le modalità 4, 5 e 6. |
| message | Ottiene o imposta il messaggio. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| get_mode() | Ottiene la modalità MaxiCode. |
| get_constructed_codetext() | Costruisce codetext |
| init_from_string(constructed_codetext) | Inizializza l'istanza dal codetext costruito. |
| get_barcode_type() | Ottiene il tipo di codice a barre. |
