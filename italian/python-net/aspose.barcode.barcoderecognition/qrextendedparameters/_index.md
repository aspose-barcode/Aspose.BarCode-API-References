## QRExtendedParameters class

Memorizza informazioni Structured Append QR del codice a barre riconosciuto

Il tipo QRExtendedParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_empty | Verifica se tutti i parametri hanno solo valori predefiniti |
| structured_append_mode_bar_codes_quantity | Restituisce la quantità di codici a barre in modalità di aggiunta strutturata QR. Il valore predefinito è -1. |
| structured_append_mode_bar_code_index | Restituisce l'indice del codice a barre in modalità di aggiunta strutturata QR. L'indice parte da 0. Il valore predefinito è -1. |
| structured_append_mode_parity_data | Restituisce i dati di parità della modalità di aggiunta strutturata QR. Il valore predefinito è -1. |
| version | Versione del QR Code riconosciuto. Da Versione1 a Versione40. |
| micro_qr_version | Versione del MicroQR Code riconosciuto. Da M1 a M4. |
| rect_micro_qr_version | Versione del RectMicroQR Code riconosciuto. Da R7x43 a R17x139. |
| error_level | Livello di correzione errori Reed-Solomon del codice a barre riconosciuto. Da basso a alto: LevelL, LevelM, LevelQ, LevelH. |
