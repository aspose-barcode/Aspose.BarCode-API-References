## AztecExtendedParameters class

Memorizza dati speciali del codice a barre Aztec riconosciuto

Il tipo AztecExtendedParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_empty | Verifica se tutti i parametri hanno solo valori predefiniti |
| structured_append_barcodes_count | Restituisce il conteggio dei codici a barre in modalità structured append di Aztec. Il valore predefinito è 0. Il conteggio deve essere un valore da 1 a 26. |
| structured_append_barcode_id | Restituisce l'ID del codice a barre in modalità structured append di Aztec. L'ID inizia da 1 e deve essere minore o uguale al conteggio dei codici a barre. Il valore predefinito è 0. |
| structured_append_file_id | Restituisce l'ID file della modalità structured append di Aztec. Il valore predefinito è una stringa vuota. |
| is_reader_initialization | Indica se il codice è usato per istruire il lettore a interpretare i dati seguenti come istruzioni per l'inizializzazione o la riprogrammazione del lettore di codici a barre.<br/>            Il valore predefinito è false. |
