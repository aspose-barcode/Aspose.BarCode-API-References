## Pdf417ExtendedParameters class

Memorizza informazioni di metadati MacroPdf417 del codice a barre riconosciuto

Il tipo Pdf417ExtendedParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_empty | Verifica se tutti i parametri hanno solo valori predefiniti |
| macro_pdf_417_file_id | Ottiene l'ID file del codice a barre, disponibile solo con MacroPdf417. |
| macro_pdf_417_segment_id | Ottiene l'ID segmento del codice a barre, disponibile solo con MacroPdf417. |
| macro_pdf_417_segments_count | Ottiene il conteggio dei segmenti del codice a barre macro pdf417. Il valore predefinito è -1. |
| macro_pdf_417_file_name | Nome file Macro PDF417 (opzionale). |
| macro_pdf_417_file_size | Dimensione file Macro PDF417 (opzionale). |
| macro_pdf_417_sender | Nome del mittente Macro PDF417 (opzionale). |
| macro_pdf_417_addressee | Nome del destinatario Macro PDF417 (opzionale). |
| macro_pdf_417_time_stamp | Marca temporale Macro PDF417 (opzionale). |
| macro_pdf_417_checksum | Checksum Macro PDF417 (opzionale). |
| macro_pdf_417_terminator | Indica se il segmento è l'ultimo segmento di un file Macro PDF417. |
| is_reader_initialization | Utilizzato per istruire il lettore a interpretare i dati contenuti nel simbolo come programmazione per l'inizializzazione del lettore. |
| is_linked | Flag che indica che il codice a barre deve essere collegato a un codice a barre 1D. |
| is_code_128_emulation | Flag che indica che il codice a barre MicroPdf417 è codificato con i codici di emulazione Code 128 908, 909, 910 o 911. |
