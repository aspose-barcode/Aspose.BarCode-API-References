## AustraliaPostSettings class

Parametri di decodifica AustraliaPost. Contiene parametri che influenzano i dati riconosciuti della simbologia AustraliaPost.

Il tipo AustraliaPostSettings espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| customer_information_interpreting_type | Ottiene o imposta il Tipo di Interpretazione per le Informazioni Cliente del BarCode AustralianPost. Il valore predefinito è CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | Il flag che forza il decoder AustraliaPost a ignorare gli ultimi pattern di riempimento nel campo Informazioni Cliente durante la decodifica con il metodo CTable.<br/>            Il metodo di codifica CTable non presenta lacune nella tabella di codifica e la sequenza "333" dei pattern di riempimento viene decodificata come lettera "z". |
| customer_information_decoder | Interfaccia pubblica per la decodifica del campo Informazioni Cliente utilizzata nella simbologia AustraliaPost. |
