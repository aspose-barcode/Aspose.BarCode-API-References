## Iso15416Quality class

Memorizza i gradi di qualità del codice a barre calcolati secondo lo standard ISO/IEC 15416 per i codici a barre 1D.

Il tipo Iso15416Quality espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| grade | Ottiene il grado complessivo di qualità del codice a barre secondo ISO/IEC 15416. |
| decode | Ottiene il grado di decodifica che indica se il codice a barre può essere decodificato usando l'algoritmo di decodifica di riferimento. |
| symbol_contrast | Ottiene il grado di contrasto del simbolo basato sulla differenza tra la riflettanza massima e minima. |
| minimum_reflectance | Restituisce il grado di riflettanza minimo basato sulla riflettanza della barra più scura. |
| minimum_edge_contrast | Restituisce il grado di contrasto dei bordi minimo basato sulla più piccola differenza di riflettanza tra barre e spazi adiacenti. |
| modulation | Restituisce il grado di modulazione basato sull'uniformità del contrasto dei bordi lungo tutto il codice a barre. |
| defects | Restituisce il grado di difetti basato sulle irregolarità di riflettanza all'interno di barre e spazi. |
| decodability | Restituisce il grado di decodificabilità basato sulla precisione delle larghezze di barre e spazi. |
