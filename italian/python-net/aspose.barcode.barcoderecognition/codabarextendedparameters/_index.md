## CodabarExtendedParameters class

Memorizza informazioni aggiuntive Codabar del codice a barre riconosciuto

Il tipo CodabarExtendedParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_empty | Verifica se tutti i parametri hanno solo valori predefiniti |
| start_symbol | Ottiene o imposta un simbolo di avvio Codabar.<br/>            Valore predefinito: CodabarSymbol.A |
| stop_symbol | Ottiene o imposta un simbolo di arresto Codabar.<br/>            Valore predefinito: CodabarSymbol.A |
