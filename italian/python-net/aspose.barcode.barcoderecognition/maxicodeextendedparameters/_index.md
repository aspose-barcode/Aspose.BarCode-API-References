## MaxiCodeExtendedParameters class

Memorizza informazioni aggiuntive MaxiCode del codice a barre riconosciuto

Il tipo MaxiCodeExtendedParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_empty | Verifica se tutti i parametri hanno solo valori predefiniti |
| modalità | Ottiene o imposta una modalità di codifica MaxiCode.<br/>            Valore predefinito: Mode4 |
| structured_append_mode_barcode_id | Ottiene o imposta un ID del codice a barre MaxiCode in modalità di aggiunta strutturata.<br/>            Valore predefinito: 0 |
| structured_append_mode_barcodes_count | Ottiene o imposta il conteggio dei codici a barre MaxiCode in modalità di aggiunta strutturata.<br/>            Valore predefinito: -1 |
