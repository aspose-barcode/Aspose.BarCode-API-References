## BarCodeResult class

Memorizza i dati del codice a barre riconosciuto come tipo [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/), stringa codetext, <br/>            regione [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) e altri parametri

Il tipo BarCodeResult espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| BarCodeResult(result) | Inizializza una nuova istanza della classe BarCodeResult |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| reading_quality | Restituisce la qualità di lettura. Funziona per codici a barre 1D e postali. |
| confidence | Restituisce il livello di fiducia del riconoscimento del codice a barre riconosciuto |
| code_text | Restituisce il testo del codice |
| code_bytes | Restituisce i byte codificati del codice |
| code_type | Restituisce il tipo di codice a barre |
| code_type_name | Restituisce il nome del tipo di codice a barre |
| regione | Ottiene la regione del codice a barre |
| esteso | Ottiene i parametri estesi del codice a barre riconosciuto |
| iso_symbol_quality | Ottiene i risultati della valutazione della qualità del simbolo ISO/IEC per il codice a barre riconosciuto. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| get_code_text(encoding) | Ottiene il testo del codice con codifica. |
| equals(other) | Restituisce un valore che indica se questa istanza è uguale a un valore [BarCodeResult](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderesult/) specificato. |
| clone() | Crea una copia della classe [BarCodeResult](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderesult/). |
