## BarCodeRegionParameters class

Rappresenta la regione del codice a barre riconosciuto e l'angolo del codice a barre

Il tipo BarCodeRegionParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| quadrangle | Ottiene [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) regione delimitante del codice a barre |
| angolo | Ottiene l'angolo del codice a barre (0-360). |
| points | Ottiene l'array di [Point](/barcode/python-net/aspose.drawing/point/) che delimitano la regione del codice a barre |
| rettangolo | Ottiene la regione delimitante del codice a barre |
