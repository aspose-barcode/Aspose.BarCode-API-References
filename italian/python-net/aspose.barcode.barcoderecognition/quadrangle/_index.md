## Quadrangle class

Memorizza un insieme di quattro [Point](/barcode/python-net/aspose.drawing/point/) che rappresentano una regione [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/).

Il tipo Quadrangle espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Quadrangle() | Inizializza una nuova istanza vuota della classe [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Inizializza una nuova istanza della classe Quadrangle |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| left_top | Ottiene l'angolo superiore sinistro [Point](/barcode/python-net/aspose.drawing/point/) della regione [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| right_top | Ottiene l'angolo superiore destro [Point](/barcode/python-net/aspose.drawing/point/) della regione [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| right_bottom | Ottiene l'angolo inferiore destro [Point](/barcode/python-net/aspose.drawing/point/) della regione [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| left_bottom | Ottiene l'angolo inferiore sinistro [Point](/barcode/python-net/aspose.drawing/point/) della regione [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| is_empty | Verifica se tutti i [Point](/barcode/python-net/aspose.drawing/point/) di questo [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) hanno valori zero. |
| bounding_rectangle | Ottiene il [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) che delimita questo [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| EMPTY | Rappresenta una classe [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) con le sue proprietà non inizializzate. |
