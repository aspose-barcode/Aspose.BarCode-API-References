## AustraliaPostCustomerInformationDecoder class

Interfaccia pubblica per la decodifica del campo Informazioni Cliente utilizzata nella simbologia AustraliaPost. L'implementazione deve essere fornita dall'utente.

Il tipo AustraliaPostCustomerInformationDecoder espone i seguenti membri:
## Metodi
| Nome | Descrizione |
| :- | :- |
| decode(customer_information_field) | Decodifica il campo di informazioni del cliente dalla simbologia AustraliaPost. <br/>            Può essere utilizzato per diverse interpretazioni dei dati dalla codifica NTable e CTable.<br/>            I dati sono forniti come una riga di valori di barra: 0, 1, 2 o 3. |
