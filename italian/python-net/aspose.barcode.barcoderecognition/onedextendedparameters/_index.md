## OneDExtendedParameters class

Memorizza dati speciali del codice a barre 1D riconosciuto, come testo del codice separato e checksum

Il tipo OneDExtendedParameters espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_empty | Verifica se tutti i parametri hanno solo valori predefiniti |
| value | Ottiene il testo del codice dei codici a barre 1D senza checksum. |
| check_sum | Ottiene il checksum per i codici a barre 1D. |
