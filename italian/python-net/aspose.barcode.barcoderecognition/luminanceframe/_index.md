## LuminanceFrame class

Rappresenta un fotogramma immagine in scala di grigi a 8 bit. Ogni pixel è rappresentato da un byte che contiene il suo valore di luminanza.

Il tipo LuminanceFrame espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Inizializza una nuova istanza della classe LuminanceFrame |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Inizializza una nuova istanza della classe LuminanceFrame |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| dati | Restituisce i dati di luminanza. |
| larghezza | Restituisce la larghezza del fotogramma in pixel. |
| altezza | Restituisce l'altezza del fotogramma in pixel. |
| row_stride | Restituisce la distanza in byte tra gli inizi<br/>            di due righe adiacenti. |
| rotation_degrees | Restituisce il numero di gradi di rotazione in senso orario necessari al fotogramma per avere l'orientamento corretto. |
