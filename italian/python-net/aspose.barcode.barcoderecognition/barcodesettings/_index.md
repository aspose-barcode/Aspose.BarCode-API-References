## BarcodeSettings class

I principali parametri di decodifica BarCode. Contiene parametri che influenzano i dati riconosciuti.

Il tipo BarcodeSettings espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Rimuove i caratteri FNC1, FNC2, FNC3 dal testo del codice. Il valore predefinito è false. |
| only_requested_types | Restituisce solo i tipi di codice a barre specificati esplicitamente per il riconoscimento. <br/>            Quando abilitato, i codici a barre riconosciuti di altri tipi compatibili o equivalenti vengono filtrati. <br/>            Il valore predefinito è false. |
| detect_encoding | Flag che forza il motore a rilevare la codifica del testo del codice per i set di caratteri Unicode. Il valore predefinito è true. |
| australia_post | Ottiene i parametri di decodifica AustraliaPost |
| calculate_symbol_quality | Ottiene o imposta un valore che indica se calcolare la qualità del simbolo del codice a barre durante il riconoscimento. |
