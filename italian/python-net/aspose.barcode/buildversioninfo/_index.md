## BuildVersionInfo class

Contiene le informazioni sulla versione di build corrente.

Il tipo BuildVersionInfo espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| ASSEMBLY_VERSION | La versione dell'assembly. |
| FILE_VERSION | La versione del file. |
| PRODUCT | Il titolo del prodotto. |
| PRODUCT_MAJOR | La versione principale del prodotto. |
| PRODUCT_MINOR | La versione secondaria del prodotto. |
| RELEASE_DATE | La data di rilascio del prodotto. |
