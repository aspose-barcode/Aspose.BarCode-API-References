## BarCodeImageFormat enum


Specifica il formato file dell'immagine.

```cpp
enum class BarCodeImageFormat
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Bmp | 0 | Specifica il formato immagine bitmap (BMP). |
| Gif | 1 | Specifica il formato immagine Graphics Interchange Format (GIF). |
| Jpeg | 2 | Specifica il formato immagine Joint Photographic Experts Group (JPEG). |
| Png | 3 | Specifica il formato immagine W3C Portable Network Graphics (PNG). |
| Tiff | 4 | Specifica il formato immagine Tagged Image File Format (TIFF). |
| TiffInCmyk | 5 | Specifica il formato immagine Tagged Image File Format (TIFF) nel modello colore CMYK. (Supportato solo sulla piattaforma [Windows](../../aspose.barcode.windows/), su piattaforme *nix viene salvato come Tiff) |
| Emf | 6 | Specifica il formato immagine Enhanced Metafile (EMF). (Supportato solo sulla piattaforma [Windows](../../aspose.barcode.windows/), su piattaforme *nix viene salvato come PNG) |
| Svg | 7 | Specifica il formato immagine Scalable Vector Graphics (SVG). |
| Pdf | 8 | Specifica il formato immagine Portable Document Format (PDF). |
