## AustraliaPostCustomerInformationDecoder class


Interfaccia pubblica per la decodifica del campo Customer Information, utilizzata nella simbologia AustraliaPost. L'implementazione deve essere fornita dall'utente.

```cpp
class AustraliaPostCustomerInformationDecoder : public virtual System::Object
```

## Metodi

| Metodo | Descrizione |
| --- | --- |
| virtual [Decode](./decode/)(System::String) | Decodifica il campo Customer Information dalla simbologia AustraliaPost. Può essere utilizzato per diverse interpretazioni dei dati dalla codifica NTable e CTable. I dati sono forniti come una riga di valori di barra: 0, 1, 2 o 3. |
