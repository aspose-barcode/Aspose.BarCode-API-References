## Address class

债权人或债务人的地址。

该 Address 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Address() | 创建 Address 实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| type | 获取地址类型。 |
| name | 获取或设置名称，可以是自然人的名和姓，或<br/>            法人的公司名称。 |
| address_line1 | 获取或设置地址行 1。 |
| address_line2 | 获取或设置地址行 2。 |
| street | 获取或设置街道。 |
| house_no | 获取或设置房屋号码。 |
| postal_code | 获取或设置邮政编码。 |
| town | 获取或设置城镇或城市。 |
| country_code | 获取或设置两个字母的 ISO 国家代码。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| clear() | 清除所有字段并将类型设置为 [UNDETERMINED](/barcode/python-net/aspose.barcode.complexbarcode/addresstype/)。 |
| equals(other) | 确定指定的对象是否等于当前对象。 |
