## HIBCLICComplexCodetext class

用于编码和解码嵌入在 HIBC LIC 代码中的文本的基类。

HIBCLICComplexCodetext 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| barcode_type | 获取或设置条码类型。HIBC LIC 代码文本可以使用 HIBCCode39LIC、HIBCCode128LIC、HIBCAztecLIC、HIBCDataMatrixLIC 和 HIBCQRLIC 编码类型进行编码。<br/>            默认值：HIBCCode39LIC。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| get_constructed_codetext() | 构建代码文本 |
| init_from_string(constructed_codetext) | 从构建的代码文本初始化实例。 |
| get_barcode_type() | 获取条形码类型。 |
