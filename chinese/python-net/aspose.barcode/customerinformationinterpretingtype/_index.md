## CustomerInformationInterpretingType enumeration

定义 AustralianPost 条码的客户信息的解释类型（CTable、NTable 或 Other）。

## Members
| 成员名称 | 描述 |
| :- | :- |
| C_TABLE | 使用 CTable 解释客户信息。允许 A..Z、a..z、1..9、空格和 # 符号。 |
| N_TABLE | 使用 NTable 解释客户信息。允许数字。 |
| OTHER | 不解释客户信息。仅允许 0、1、2 或 3 符号。 |
