## HanXinParameters class

Han Xin 参数。

HanXinParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| version | HanXin 码的版本。<br/>            从 Version01 到 Version84（适用于汉信码）。<br/>            默认值为 Version.Auto。 |
| error_level | Han Xin 条形码的 Reed-Solomon 错误更正级别。<br/>            从低到高：L1、L2、L3、L4。参见 ErrorLevel。 |
| encode_mode | HanXin 编码模式。<br/>            默认值：EncodeMode.Mixed。 |
| eci_encoding | 扩展通道解释标识符。<br/>            它用于向条码阅读器提供有关在符号中编码数据所使用的参考的详细信息。<br/>            当前实现包含所有已知的字符集编码。 |
