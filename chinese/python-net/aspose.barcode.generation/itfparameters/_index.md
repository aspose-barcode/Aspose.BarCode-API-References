## ITFParameters class

ITF 参数。

ITFParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| border_thickness | 获取或设置 ITF 边框（承载条）的厚度，单位为 Unit 值。<br/>            默认值：12pt。 |
| border_type | ITF 条码的边框类型。<br/>            默认值：ITF14BorderType.Bar。 |
| quiet_zone_coef | 在 xDimension 中安静区的大小。<br/>            默认值：10，表示如果 xDimension = 2px，则安静区将为 20px。 |
