## DataMatrixEccType enumeration

指定要编码的 ECC 类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| ECC_AUTO | 指定编码的 Ecc 类型由默认的 Reed-Solomon 错误校正或 ECC 200 定义。 |
| ECC000 | 指定编码的 Ecc 类型为 ECC 000。 |
| ECC050 | 指定编码的 Ecc 类型为 ECC 050。 |
| ECC080 | 指定编码的 Ecc 类型为 ECC 080。 |
| ECC100 | 指定编码的 Ecc 类型为 ECC 100。 |
| ECC140 | 指定编码的 Ecc 类型为 ECC 140。 |
| ECC200 | 指定编码的 Ecc 类型为 ECC 200。建议使用。 |
