## FontUnit class

定义文本的特定格式，包括字体、大小和样式属性<br/>            其中大小在 Unit 值属性中。

FontUnit 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| family_name | 获取或设置此字体的字体名称。 |
| style | 获取或设置此 FontUnit 的样式信息。 |
| size | 获取或设置此 FontUnit 的大小（以 Unit 为单位）。 |
