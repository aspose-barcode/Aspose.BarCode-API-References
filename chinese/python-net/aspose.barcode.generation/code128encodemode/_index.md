## Code128EncodeMode enumeration

Code128 条码的编码模式。

## Members
| 成员名称 | 描述 |
| :- | :- |
| AUTO | 在经典 ISO 15417 模式下编码代码文本。该模式应在所有常规情况下使用。 |
| CODE_A | 仅在 128A 代码集编码代码文本。 |
| CODE_B | 仅在 128B 代码集编码代码文本。 |
| CODE_C | 仅在 128C 代码集编码代码文本。 |
| CODE_AB | 仅在 128A 和 128B 代码集编码代码文本。 |
| CODE_AC | 仅在 128A 和 128C 代码集编码代码文本。 |
| CODE_BC | 仅在 128B 和 128C 代码集编码代码文本。 |
