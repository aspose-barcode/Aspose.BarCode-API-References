## SupplementParameters class

SupplementParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| supplement_data | 在条形码后面的补充数据。 |
| supplement_space | 主 BarCode 与补充 BarCode 之间的间距，以 [Unit](/barcode/python-net/aspose.barcode.generation/unit/) 为单位。 |
