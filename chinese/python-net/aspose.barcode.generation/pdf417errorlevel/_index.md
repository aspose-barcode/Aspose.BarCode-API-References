## Pdf417ErrorLevel enumeration

pdf417 条形码的错误更正级别，范围从 0 级到 9 级，0 级表示无错误更正，8 级表示最佳错误更正

## Members
| 成员名称 | 描述 |
| :- | :- |
| LEVEL0 | 错误更正级别 - 0。错误更正码字 - 2。 |
| LEVEL1 | 错误更正级别 - 1。错误更正码字 - 4。 |
| LEVEL2 | 错误更正级别 - 2。错误更正码字 - 8。 |
| LEVEL3 | 错误更正级别 - 3。错误更正码字 - 16。 |
| LEVEL4 | 错误更正级别 - 4。错误更正码字 - 32。 |
| LEVEL5 | 错误更正级别 - 5。错误更正码字 - 64。 |
| LEVEL6 | 错误更正级别 - 6. 错误更正码字 - 128. |
| LEVEL7 | 错误更正级别 - 7. 错误更正码字 - 256. |
| LEVEL8 | 错误更正级别 - 8. 错误更正码字 - 512. |
