## DotCodeParameters class

DotCode 参数。

DotCodeParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| aspect_ratio | 2D 条码模块的高/宽比例。 |
| encode_mode | 标识 DotCode 编码模式。<br/>默认值：Auto。 |
| is_reader_initialization | 指示代码是否用于指示读取器将以下数据解释为条码读取器的初始化或重新编程指令。<br/>            默认值为 false。 |
| structured_append_mode_barcode_id | 标识 DotCode 结构化追加模式条码的 ID。ID 从 1 开始，且必须小于或等于条码数量。默认值为 -1。 |
| structured_append_mode_barcodes_count | 标识 DotCode 结构化追加模式条码的数量。默认值为 -1。计数必须在 1 到 35 之间。 |
| eci_encoding | 标识 ECI 编码。当 DotCodeEncodeMode 为 Auto 时使用。<br/>默认值：ISO-8859-1 |
| 行 | 标识行数。DotCode 符号的行数与列数之和必须为奇数。行数必须至少为 5。<br/>默认值：-1 |
| 列 | 标识列数。DotCode 符号的行数与列数之和必须为奇数。列数必须至少为 5。<br/>默认值：-1 |
