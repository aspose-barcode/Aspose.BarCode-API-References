## MaxiCodeParameters class

MaxiCode 参数。

MaxiCodeParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| 模式 | 获取或设置 MaxiCode 编码模式。 |
| encode_mode | 获取或设置 MaxiCode 编码模式。<br/>            默认值：Auto。 |
| eci_encoding | 获取或设置 ECI 编码。当 MaxiCodeEncodeMode 为 Auto 时使用。<br/>            默认值：ISO-8859-1 |
| structured_append_mode_barcode_id | 获取或设置结构化追加模式下的 MaxiCode 条形码 ID。 <br/>            ID 必须是 1 到 8 之间的值。 <br/>            默认值：0 |
| structured_append_mode_barcodes_count | 获取或设置结构化追加模式下的 MaxiCode 条形码数量。 <br/>            数量必须是 2 到 8 之间的值（最大条形码数量）。<br/>            默认值：-1 |
| aspect_ratio | 2D 条码模块的高/宽比例。 |
