## 属性
| 名称 | 描述 |
| :- | :- |
| cmyk_bar_color | 可空。条形码的 CMYK 颜色值。Null 表示不使用 CMYK 颜色，而使用普通的 RGB 颜色。 |
| cmyk_back_color | 可空。背景的 CMYK 颜色值。Null 表示不使用 CMYK 颜色，而使用普通的 RGB 颜色。 |
| cmyk_codetext_color | 可空。代码文本的 CMYK 颜色值。Null 表示不使用 CMYK 颜色，而使用普通的 RGB 颜色。 |
| cmyk_caption_above_color | 可空。上方标题的 CMYK 颜色值。Null 表示不使用 CMYK 颜色，而使用普通的 RGB 颜色。 |
