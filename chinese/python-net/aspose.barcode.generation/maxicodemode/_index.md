## MaxiCodeMode enumeration

MaxiCode 条形码的编码模式。

## Members
| 成员名称 | 描述 |
| :- | :- |
| MODE2 | Mode 2 在第一条消息中编码邮政信息，在第二条消息中编码数据。 <br/>            仅在美国使用的 9 位邮政编码。 |
| MODE3 | 模式3在第一条信息中编码邮政信息，在第二条信息中编码数据。 <br/>            具有6位字母数字邮政编码，全球使用。 |
| MODE4 | 模式4在第一条和第二条信息中编码数据，使用短ECC纠错。 |
| MODE5 | 模式5在第一条和第二条信息中编码数据，使用长ECC纠错。 |
| MODE6 | 模式6在第一条和第二条信息中编码数据，使用短ECC纠错。<br/>            用于编码设备。 |
