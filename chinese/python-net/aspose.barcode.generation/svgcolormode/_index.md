## SvgColorMode enumeration

svg 文件中填充颜色的可能模式，RGB 为默认且受 SVG 1.1 支持。<br/>            SVG 2.0 标准允许使用 RGBA、HSL、HSLA。<br/>            即使是 RGB，透明度也将通过 "fill-opacity" 参数设置。

## Members
| 成员名称 | 描述 |
| :- | :- |
| RGB | RGB 模式，示例：fill=\"#ff5511\" fill-opacity=\"0.73\"。默认模式。 |
| RGBA | RGBA 模式，示例：fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | HSL 模式，示例：fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | HSLA 模式，示例：fill=\"hsla(30, 50%, 70%, 0.8)\" |
