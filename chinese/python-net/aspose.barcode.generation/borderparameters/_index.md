## BorderParameters class

条码图像边框参数

BorderParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| visible | 边框可见性。如果为 false，则参数 Width 始终被忽略 (0)。<br/>            默认值：false。 |
| width | 边框宽度。<br/>            默认值：0。<br/>            如果 Visible 设置为 false，则被忽略。 |
| dash_style | 边框虚线样式。<br/>            默认值：BorderDashStyle.Solid。 |
| 颜色 | 边框颜色。<br/>            默认值：Color.Black。 |
