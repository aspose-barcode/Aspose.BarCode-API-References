## Pdf417MacroTerminator enumeration

用于告知编码器是否向段中添加宏 PDF417 终止符（代码字 922）。<br/>            仅适用于宏 PDF417。

## Members
| 成员名称 | 描述 |
| :- | :- |
| AUTO | 如果提供了段数，终止符将自动添加 <br/>            并且当前段是最后一段。否则，终止符将不会被添加。 |
| NONE | 终止符将不会被添加。 |
| SET | 终止符将被添加。 |
