## AztecSymbolMode enumeration

指定 Aztec 符号模式。

## Members
| 成员名称 | 描述 |
| :- | :- |
| AUTO | 指定自动选择最适合的 Aztec 符号（Compact 或 Full-range）。<br/>            这是默认值。 |
| COMPACT | 指定 Aztec 的 Compact 符号。<br/>            Aztec Compact 符号仅允许 1、2、3 或 4 层。 |
| FULL_RANGE | 指定 Aztec 的 Full-range 符号。<br/>            Aztec Full-range 符号允许 1 到 32 层。 |
| RUNE | 指定 Aztec 的 Rune 符号。<br/>            Aztec Rune 是一系列小但独特的机器可读标记。它仅允许 0 到 255 的数值。 |
