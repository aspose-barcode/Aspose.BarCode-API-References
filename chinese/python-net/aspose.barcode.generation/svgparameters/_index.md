## SvgParameters class

SVG 参数。

SvgParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_explicit_size_in_pixels | SVG 图像是否包含像素单位的显式大小（推荐）<br/>            默认值：true。 |
| is_text_drawn_in_text_element | SVG 图像是否将文本作为文本元素而不是路径（推荐）<br/>            默认值：true。 |
| svg_color_mode | svg 文件中填充颜色的可能模式，RGB 为默认且受 SVG 1.1 支持。<br/>            SVG 2.0 标准允许使用 RGBA、HSL、HSLA。<br/>            即使是 RGB，透明度也将通过 "fill-opacity" 参数设置。 |
