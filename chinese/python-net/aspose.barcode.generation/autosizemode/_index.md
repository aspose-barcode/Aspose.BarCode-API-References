## AutoSizeMode enumeration

指定自动尺寸模式的不同类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 已禁用自动调整大小。 |
| NEAREST | 将条码调整为由 ImageWidth 和 ImageHeight 属性指定的最近的最小可能尺寸。<br/>            保持默认宽高比。 |
| INTERPOLATION | 将条码调整为指定尺寸。<br/>            尺寸可通过 ImageWidth 和 ImageHeight 属性指定。<br/>            缩放后生成的条码可能无效（不可读取）。 |
