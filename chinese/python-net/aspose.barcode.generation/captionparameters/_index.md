## CaptionParameters class

标题参数。

CaptionParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| text | 标题文本。<br/>            默认值：空字符串。 |
| font | 标题字体。<br/>            默认值：Arial 8pt regular。 |
| visible | 标题文本可见性。<br/>            默认值：false。 |
| text_color | 标题文本颜色。<br/>            默认值：Color.Black。 |
| padding | 标题填充。<br/>            CaptionAbove 的默认值：5pt 5pt 0 5pt。<br/>            CaptionBelow 的默认值：0 5pt 5pt 5pt。 |
| 对齐 | 标题文本水平对齐。<br/>            默认值：StringAlignment.Center。 |
| 不换行 | 指定文本中的自动换行（换行符）。<br/>            默认值: false. |
