## GS1ValidationLevel enumeration

指定 GS1 数据验证的级别。<br/>            更高的验证级别包括所有低级别的检查。

## Members
| 成员名称 | 描述 |
| :- | :- |
| SYNTAX | 验证 GS1 语法，包括应用标识符，<br/>            字段长度和必需的分隔符。 |
| CONTENT | 验证 GS1 语法以及应用标识符值的内容，<br/>            包括字符集、校验和和特定值规则。 |
