## ProcessorSettings class

ProcessorSettings 允许通过多线程提升性能来识别条形码

ProcessorSettings 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| use_all_cores | 需要使用所有核心。 |
| use_only_this_cores_count | 指定要使用的核心数量。 <br/>            您需要将属性 "UseAllCores" 更改为 "false"。 |
| max_additional_allowed_threads | 指定并行运行代码的最大额外线程数 |
