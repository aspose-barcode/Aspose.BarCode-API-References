## AztecExtendedParameters class

存储已识别的 Aztec 条码的特殊数据

AztecExtendedParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_empty | 测试所有参数是否仅具有默认值 |
| structured_append_barcodes_count | 获取 Aztec 结构化追加模式条形码的计数。默认值为 0。计数必须在 1 到 26 之间。 |
| structured_append_barcode_id | 获取 Aztec 结构化追加模式条形码的 ID。ID 从 1 开始，且必须小于或等于条形码计数。默认值为 0。 |
| structured_append_file_id | 获取 Aztec 结构化追加模式的文件 ID。默认值为空字符串。 |
| is_reader_initialization | 指示代码是否用于指示读取器将以下数据解释为条码读取器的初始化或重新编程指令。<br/>            默认值为 false。 |
