## QRExtendedParameters class

存储已识别条形码的 QR 结构化追加信息

QRExtendedParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_empty | 测试所有参数是否仅具有默认值 |
| structured_append_mode_bar_codes_quantity | 获取 QR 结构化追加模式条码的数量。默认值为 -1。 |
| structured_append_mode_bar_code_index | 获取 QR 结构化追加模式条码的索引。索引从 0 开始。默认值为 -1。 |
| structured_append_mode_parity_data | 获取 QR 结构化追加模式的奇偶校验数据。默认值为 -1。 |
| version | 识别的 QR 码版本。范围从 Version1 到 Version40。 |
| micro_qr_version | 识别的 MicroQR 码版本。范围从 M1 到 M4。 |
| rect_micro_qr_version | 识别的 RectMicroQR 码版本。范围从 R7x43 到 R17x139。 |
| error_level | 识别的条码的 Reed-Solomon 错误纠正级别。从低到高：LevelL、LevelM、LevelQ、LevelH。 |
