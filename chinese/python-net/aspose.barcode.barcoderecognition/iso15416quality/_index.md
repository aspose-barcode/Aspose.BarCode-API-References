## Iso15416Quality class

存储根据 ISO/IEC 15416 标准为 1D 条形码计算的条形码质量等级。

Iso15416Quality 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| grade | 根据 ISO/IEC 15416 获取条形码整体质量等级。 |
| decode | 获取解码等级，指示条形码是否可以使用参考解码算法进行解码。 |
| symbol_contrast | 根据最大和最小反射率的差异获取符号对比度等级。 |
| minimum_reflectance | 获取基于最暗条纹反射率的最低反射率等级。 |
| minimum_edge_contrast | 获取基于相邻条纹和空白之间最小反射率差异的最低边缘对比度等级。 |
| modulation | 获取基于条码整体边缘对比度均匀性的调制等级。 |
| defects | 获取基于条纹和空白内部反射率不规则性的缺陷等级。 |
| decodability | 获取基于条纹和空白宽度精确度的可解码性等级。 |
