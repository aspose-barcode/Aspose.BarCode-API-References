## Pdf417ExtendedParameters class

存储已识别条形码的 MacroPdf417 元数据

Pdf417ExtendedParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_empty | 测试所有参数是否仅具有默认值 |
| macro_pdf_417_file_id | 获取条形码的文件 ID，仅在 MacroPdf417 中可用。 |
| macro_pdf_417_segment_id | 获取条形码的段 ID，仅在 MacroPdf417 中可用。 |
| macro_pdf_417_segments_count | 获取宏 PDF417 条形码段计数。默认值为 -1。 |
| macro_pdf_417_file_name | 宏 PDF417 文件名（可选）。 |
| macro_pdf_417_file_size | 宏 PDF417 文件大小（可选）。 |
| macro_pdf_417_sender | 宏 PDF417 发送者名称（可选）。 |
| macro_pdf_417_addressee | 宏 PDF417 收件人名称（可选）。 |
| macro_pdf_417_time_stamp | Macro PDF417 时间戳（可选）。 |
| macro_pdf_417_checksum | Macro PDF417 校验和（可选）。 |
| macro_pdf_417_terminator | 指示该段是否为 Macro PDF417 文件的最后一段。 |
| is_reader_initialization | 用于指示阅读器将符号中包含的数据解释为阅读器初始化的编程。 |
| is_linked | 标志，指示条码必须链接到 1D 条码。 |
| is_code_128_emulation | 标志，指示 MicroPdf417 条码使用 908、909、910 或 911 Code 128 仿真代码字进行编码。 |
