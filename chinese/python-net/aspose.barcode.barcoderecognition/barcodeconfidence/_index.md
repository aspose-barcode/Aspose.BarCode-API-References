## BarCodeConfidence enumeration

包含识别置信度水平

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 条形码的识别置信度，当代码文本未被正确识别或条形码被检测为可能的伪造时。 |
| MODERATE | 条形码的识别置信度（主要是 1D 条形码），校验和弱或甚至没有校验和。可能会出现代码文本的一些误识别<br/>            或甚至伪识别。 |
| STRONG | 通过 BCH 码（如 Reed–Solomon）确认的识别置信度。读取的代码文本中必须没有错误或伪识别。 |
