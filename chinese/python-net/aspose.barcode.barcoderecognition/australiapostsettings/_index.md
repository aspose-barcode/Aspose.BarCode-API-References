## AustraliaPostSettings class

AustraliaPost 解码参数。包含对 AustraliaPost 符号的已识别数据产生影响的参数。

AustraliaPostSettings 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| customer_information_interpreting_type | 获取或设置 AustralianPost 条形码的客户信息的解释类型。默认是 CustomerInformationInterpretingType.Other。 |
| ignore_ending_filling_patterns_for_c_table | 此标志强制 AustraliaPost 解码器在使用 CTable 方法解码时忽略客户信息字段中的最后填充模式。<br/>            CTable 编码方法在编码表中没有任何间隙，填充模式序列 \"333\" 被解码为字母 \"z\"。 |
| customer_information_decoder | 用于 AustraliaPost 符号系统的客户信息字段解码的公共接口。 |
