## LuminanceFrame class

表示一个 8 位灰度图像帧。每个像素由一个包含其亮度值的字节表示。

LuminanceFrame 类型公开以下成员：
## 构造函数
| 名称 | 描述 |

## 属性
| 名称 | 描述 |
| :- | :- |
| 数据 | 获取亮度数据。 |
| width | 获取帧的宽度（像素）。 |
| height | 获取帧的高度（像素）。 |
| row_stride | 获取相邻两行起始位置之间的字节距离<br/>            。 |
| rotation_degrees | 获取帧必须顺时针旋转的角度数，以获得正确的方向。 |
