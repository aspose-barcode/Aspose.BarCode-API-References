## DotCodeExtendedParameters class

存储 DotCode 识别的条形码的特殊数据

DotCodeExtendedParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_empty | 测试所有参数是否仅具有默认值 |
| structured_append_mode_barcodes_count | 获取 DotCode 结构化追加模式条码的数量。默认值为 -1。计数必须在 1 到 35 之间。 |
| structured_append_mode_barcode_id | 获取 DotCode 结构化追加模式条码的 ID。ID 从 1 开始，且必须小于或等于条码数量。默认值为 -1。 |
| is_reader_initialization | 指示代码是否用于指示读取器将以下数据解释为条码读取器的初始化或重新编程指令。<br/>            默认值为 false。 |
