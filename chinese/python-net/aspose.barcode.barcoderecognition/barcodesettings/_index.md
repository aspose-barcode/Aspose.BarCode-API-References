## BarcodeSettings class

主要的 BarCode 解码参数。包含对已识别数据产生影响的参数。

BarcodeSettings 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| checksum_validation |  |
| strip_fnc | 从代码文本中剥离 FNC1、FNC2、FNC3 字符。默认值为 false。 |
| only_requested_types | 仅返回明确指定用于识别的条码类型。<br/>            启用后，其他兼容或等效类型的已识别条码将被过滤掉。<br/>            默认值为 false。 |
