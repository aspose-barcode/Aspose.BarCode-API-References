## XDimensionMode enumeration



## Members
| 成员名称 | 描述 |
| :- | :- |
| AUTO | XDimension 的值由 AI（SVM）检测。目前与 Normal 相同。 |
| SMALL | 检测 XDimension 为 1 像素或更大的小尺寸条码，质量来自 BarcodeQuality。 |
| NORMAL | 检测 XDimension 为 2 像素或更大的经典尺寸条码，质量来自 BarcodeQuality 或高质量条码。 |
| LARGE | 检测 XDimension 为大尺寸的条码，质量来自使用高分辨率相机捕获的 BarcodeQuality。 |
| USE_MINIMAL_X_DIMENSION | 检测尺寸设定为 MinimalXDimension 的条码，质量来自 BarcodeQuality。 |
