## DataMatrixExtendedParameters class

存储已识别的 DataMatrix 条码的特殊数据

DataMatrixExtendedParameters 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_empty | 测试所有参数是否仅具有默认值 |
| structured_append_barcodes_count | 获取 DataMatrix 结构化追加模式条码的计数。默认值为 -1。计数必须在 1 到 35 之间。 |
| structured_append_barcode_id | 获取 DataMatrix 结构化追加模式条码的 ID。ID 从 1 开始，且必须小于或等于条码计数。默认值为 -1。 |
| structured_append_file_id | 获取 DataMatrix 结构化追加模式条码的 ID。ID 从 1 开始，且必须小于或等于条码计数。默认值为 -1。 |
| is_reader_programming | 指示代码是否用于指示读取器将以下数据解释为条码读取器的初始化或重新编程指令。<br/>            默认值为 false。 |
