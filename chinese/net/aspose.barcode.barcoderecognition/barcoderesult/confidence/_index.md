## BarCodeResult.Confidence property

获取已识别条形码的识别置信度水平

```csharp
public BarCodeConfidence Confidence { get; }
```

### Property Value

Strong 不会出现伪造或误识别，Moderate 有时可能出现伪造或不正确的 codetext，因为此置信度级别适用于校验和弱或甚至没有校验和的 barcodews，None 始终具有不正确的 codetext，可能是伪造的识别。
