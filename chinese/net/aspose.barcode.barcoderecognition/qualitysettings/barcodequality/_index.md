## QualitySettings.BarcodeQuality property

模式，使能够使用所选质量识别条形码元素。质量较低的条形码元素需要更复杂的方法，从而减慢识别速度。

```csharp
public BarcodeQualityMode BarcodeQuality { get; set; }
```

### Property Value

模式用于启用使用所选质量识别条形码元素的方法。
