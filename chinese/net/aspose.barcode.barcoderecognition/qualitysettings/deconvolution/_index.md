## QualitySettings.Deconvolution property

去卷积（图像恢复）模式，用于定义图像退化的程度。去卷积最初是一种能够恢复因自然函数（如模糊）在相机拍摄时导致的退化（卷积）图像的功能。由于我们无法检测导致图像损坏的函数，只能检查最常见的函数，如锐化或数学形态学。

```csharp
public DeconvolutionMode Deconvolution { get; set; }
```

### Property Value

去卷积模式，用于定义图像退化程度。
