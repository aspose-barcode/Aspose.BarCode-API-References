## Address.HouseNo property

获取或设置门牌号。

设置此字段会将地址类型设为 Structured，除非它已经是 CombinedElements，此时会变为 Conflicting。

此字段仅用于结构化地址，可选。

```csharp
public string HouseNo { get; set; }
```

### Property Value

门牌号。
