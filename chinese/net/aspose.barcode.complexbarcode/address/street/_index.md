## Address.Street property

获取或设置街道。

必须在不包含门牌号的情况下指定街道。

设置此字段会将地址类型设为 Structured，除非它已经是 CombinedElements，此时会变为 Conflicting。

此字段仅用于结构化地址，可选。

```csharp
public string Street { get; set; }
```

### Property Value

街道。
