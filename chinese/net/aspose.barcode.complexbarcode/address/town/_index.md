## Address.Town property

获取或设置城镇或城市。

设置此字段会将地址类型设为 Structured，除非它已经是 CombinedElements，此时会变为 Conflicting。

此字段仅用于结构化地址。对于此类型，它是必需的。

```csharp
public string Town { get; set; }
```

### Property Value

城镇或城市。
