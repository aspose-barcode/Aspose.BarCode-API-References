## Address.Type property

获取地址类型。

地址类型会在设置街道/门牌号或地址行 1 和 2 时自动设置。在设置字段之前，地址类型为 Undetermined。如果同时设置了两种类型的字段，地址类型将变为 Conflicting。

```csharp
public AddressType Type { get; }
```

### Property Value

地址类型。
