## Address.PostalCode property

获取或设置邮政编码。

设置此字段会将地址类型设为 Structured，除非它已经是 CombinedElements，此时会变为 Conflicting。

此字段仅用于结构化地址。对于此类型，它是必需的。

```csharp
public string PostalCode { get; set; }
```

### Property Value

邮政编码。
