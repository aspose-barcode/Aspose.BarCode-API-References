## Address.AddressLine2 property

获取或设置地址行 2。

地址行 2 包含邮政编码和城镇。

设置此字段会将地址类型设为 CombinedElements，除非它已经是 Structured，此时会变为 Conflicting。

此字段仅用于组合元素地址。对于此类型，它是必需的。

```csharp
public string AddressLine2 { get; set; }
```

### Property Value

地址行 2。
