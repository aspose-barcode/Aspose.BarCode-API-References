## Address.AddressLine1 property

获取或设置地址行 1。

地址行 1 包含街道名称、门牌号或邮政信箱。

设置此字段会将地址类型设为 CombinedElements，除非它已经是 Structured，此时会变为 Conflicting。

此字段仅用于组合元素地址，可选。

```csharp
public string AddressLine1 { get; set; }
```

### Property Value

地址行 1。
