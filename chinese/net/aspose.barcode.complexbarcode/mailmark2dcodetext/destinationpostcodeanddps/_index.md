## Mailmark2DCodetext.DestinationPostCodeAndDPS property

包含带有 DPS 的收货地址邮编。如果在内陆，邮编/DP 包含以下字符数：地区（1 或 2 个字符） 区（1 或 2 个字符） 扇区（1 个字符） 单元（2 个字符） DPS（2 个字符）。邮编和 DPS 必须符合有效的 PAF® 格式。

public string DestinationPostCodeAndDPS { get; set; }
