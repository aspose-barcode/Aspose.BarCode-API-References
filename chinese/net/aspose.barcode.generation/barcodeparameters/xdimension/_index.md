## BarcodeParameters.XDimension property

x-dimension 是条码条或空格单元的最小宽度。增大此值会增加整个条码图像的宽度。如果 [`AutoSizeMode`](../../basegenerationparameters/autosizemode/) 属性设置为 AutoSizeMode.Nearest 或 AutoSizeMode.Interpolation，则会被忽略。

public Unit XDimension { get; set; }
