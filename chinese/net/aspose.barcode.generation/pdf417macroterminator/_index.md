## Pdf417MacroTerminator enumeration

用于告知编码器是否在段中添加 Macro PDF417 终止符（代码字 922）。仅适用于 Macro PDF417。

```csharp
public enum Pdf417MacroTerminator
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Auto | `0` | 如果提供了段数且当前段是最后一个，则会自动添加终止符。否则，不会添加终止符。 |
| None | `1` | 终止符将不会被添加。 |
| Set | `2` | 终止符将被添加。 |
