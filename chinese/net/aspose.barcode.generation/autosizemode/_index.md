## AutoSizeMode enumeration

指定自动尺寸模式的不同类型。

```csharp
public enum AutoSizeMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 已禁用自动调整大小。 |
| Nearest | `1` | 将条形码调整为由 ImageWidth 和 ImageHeight 属性指定的最近的最小可能尺寸。保持默认宽高比。 |
| Interpolation | `2` | 将条形码调整为指定尺寸。尺寸可通过 ImageWidth 和 ImageHeight 属性指定。缩放后生成的条形码可能无效（不可读取）。 |
