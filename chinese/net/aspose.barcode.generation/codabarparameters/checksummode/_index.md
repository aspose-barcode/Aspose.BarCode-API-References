## CodabarParameters.ChecksumMode property

获取或设置 Codabar 条形码的校验和算法。默认值：CodabarChecksumMode.Mod16。要启用校验和计算，请将属性 EnableChecksum 的值设为 EnableChecksum.Yes。参见 `ChecksumMode`。

```csharp
public CodabarChecksumMode ChecksumMode { get; set; }
```
