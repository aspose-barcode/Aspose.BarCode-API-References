## EncodeTypes.TryParse method

将 BaseEncodeType 的字符串表示转换为其实例。返回值指示转换是成功还是失败。

```csharp
public static bool TryParse(string parsingType, out BaseEncodeType result)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| parsingType | 字符串 | 要转换的字符串，格式为 "Index:-1; Name:None" |
| 结果 | BaseEncodeType& | 当转换成功完成时返回实际的 SingleEncodeType； |

### 返回值

**true** if s was converted successfully; otherwise, **false**.
