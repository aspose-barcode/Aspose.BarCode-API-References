## CodetextParameters.Location property

指定 CodeText 的显示位置，设置为 CodeLocation.None 可隐藏 CodeText。默认值：1D 条码使用 CodeLocation.Below，2D 条码使用 CodeLocation.None。

public CodeLocation Location { get; set; }
