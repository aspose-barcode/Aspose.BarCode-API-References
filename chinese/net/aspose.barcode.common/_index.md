该 **BarCode.Common** 包含通用功能和辅助工具，以维护主要功能。

## 类

| 类 | 描述 |
| --- | --- |
| [GS1Element](./gs1element/) | 表示一个不可变的 GS1 应用标识符及其值对。 |
| [GS1ValidationException](./gs1validationexception/) | 当验证失败时，由严格的 GS1 操作抛出的异常。 |
| [GS1ValidationIssue](./gs1validationissue/) | 描述一个 GS1 验证错误。 |
| [GS1ValidationResult](./gs1validationresult/) | 包含针对 GS1 元素字符串、Digital Link URI 或单个 AI 值的所有可独立检测的错误。 |
| [ProcessorSettings](./processorsettings/) | ProcessorSettings 允许通过多线程提升性能来识别条码。 |
## 枚举

| --- | --- |
