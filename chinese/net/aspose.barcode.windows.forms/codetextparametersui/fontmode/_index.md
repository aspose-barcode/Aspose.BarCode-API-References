## CodetextParametersUI.FontMode property

指定 FontMode。若 FontMode 设置为 Auto，则字体大小将根据 xDimension 值自动计算。建议在 AutoSizeMode.Nearest 或 AutoSizeMode.Interpolation 中使用 FontMode.Auto。默认值：FontMode.Auto。

```csharp
public FontMode FontMode { get; set; }
```
