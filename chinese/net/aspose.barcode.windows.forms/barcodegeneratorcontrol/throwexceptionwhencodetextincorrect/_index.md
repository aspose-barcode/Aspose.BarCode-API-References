## BarCodeGeneratorControl.ThrowExceptionWhenCodeTextIncorrect property

仅适用于 1D 条码。如果 codetext 不正确且值设为 true——将抛出异常。否则 codetext 将被纠正以符合条码规范。以下情况始终会抛出异常：Databar 符号如果 codetext 不正确。以下情况始终不会抛出异常：AustraliaPost、SingapurePost、Code39Extended、Code93Extended、Code16K、Code128 符号如果 codetext 不正确。

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
