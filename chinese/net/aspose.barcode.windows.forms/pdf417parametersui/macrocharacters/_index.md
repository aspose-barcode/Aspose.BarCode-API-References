## Pdf417ParametersUI.MacroCharacters property

宏字符 05 和 06 的值用于在特殊模式下获得更紧凑的编码。只能与 MicroPdf417 一起使用，并对 916 和 917 MicroPdf417 模式进行编码。默认值：MacroCharacters.None。

public MacroCharacter MacroCharacters { get; set; }
