### AUTO {#AUTO}
```
public static final DotCodeEncodeMode AUTO
```


在 Auto 模式下，CodeText 以最高的数据紧凑度进行编码。Unicode 字符会使用 ECIEncoding 指定的编码重新编码，并插入 ECI 标识符。如果发现字符不受所选 ECI 编码支持，则会抛出异常。

### BINARY {#BINARY}
```
public static final DotCodeEncodeMode BINARY
```


在 Binary 模式下，CodeText 以最高的数据紧凑度进行编码。如果出现 Unicode 字符，则会抛出异常。

### ECI {#ECI}
```
public static final DotCodeEncodeMode ECI
```


在 ECI 模式下，整个消息会使用 ECIEncoding 指定的编码重新编码，并插入 ECI 标识符。如果发现字符不受所选 ECI 编码支持，则会抛出异常。请注意，某些旧（2006 年之前）的扫描仪可能不支持此模式。

### EXTENDED {#EXTENDED}
```
public static final DotCodeEncodeMode EXTENDED
```


支持多 ECI 模式的扩展模式。

最好使用 DotCodeExtCodetextBuilder 来生成扩展的代码文本。

使用 Display2DText 属性设置可见文本，以去除管理字符。

ECI 标识符设置为单斜杠加六位数字标识符 "\\000026" - UTF8 ECI 标识符

ECI 标识符之后的所有 Unicode 字符会自动编码为正确的字符集。
