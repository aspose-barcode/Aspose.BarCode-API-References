## ITF14BorderType enum


ITF14 条形码的边框类型

```cpp
enum class ITF14BorderType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| 无 | 0 | 无边框包围条码 |
| 框架 | 1 | 框架包围条码 |
| 条形 | 2 | 两个水平条形包围条码 |
| FrameOut | 3 | 框架包围条码。它绘制在条码外部，并且不影响高度 |
| BarOut | 4 | 两个水平条形包围条码。它绘制在条码外部，并且不影响高度 |
