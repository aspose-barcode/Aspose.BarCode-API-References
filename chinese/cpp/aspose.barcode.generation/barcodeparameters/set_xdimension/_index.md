## BarcodeParameters::set_XDimension method


x-dimension 是 [BarCode](../../../aspose.barcode/) 条或空格单元的最小宽度。增大此值会增加整个条码图像的宽度。如果 [BaseGenerationParameters::AutoSizeMode](../) 属性设置为 [AutoSizeMode.Nearest](../../autosizemode/) 或 [AutoSizeMode.Interpolation](../../autosizemode/)，则会被忽略。
