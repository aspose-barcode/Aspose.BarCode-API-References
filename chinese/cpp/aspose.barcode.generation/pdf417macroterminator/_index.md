## Pdf417MacroTerminator enum


用于告知编码器是否向段中添加 Macro PDF417 Terminator（代码字 922）。仅在 Macro PDF417 中适用。

```cpp
enum class Pdf417MacroTerminator
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| 自动 | 0 | 如果提供了段数且当前段是最后一个，则会自动添加终止符。在其他情况下，不会添加终止符。 |
| 无 | 1 | 不会添加终止符。 |
| 设置 | 2 | 将添加终止符。 |
