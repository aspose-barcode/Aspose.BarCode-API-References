## GS1ValidationLevel enum


指定 GS1 数据验证的级别。更高的验证级别包括所有低级别的检查。

```cpp
enum class GS1ValidationLevel
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| 语法 | 0 | 验证 GS1 语法，包括应用标识符、字段长度和必需的分隔符。 |
| 内容 | 1 | 验证 GS1 语法以及应用标识符值的内容，包括字符集、校验和和特定值规则。 |
