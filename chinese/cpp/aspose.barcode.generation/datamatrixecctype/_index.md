## DataMatrixEccType enum


指定要编码的 ECC 类型。

```cpp
enum class DataMatrixEccType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| EccAuto | 0 | 指定编码的 Ecc 类型默认由 Reed-Solomon 错误校正或 ECC 200 定义。 |
| Ecc000 | 1 | 指定编码的 Ecc 类型为 ECC 000。 |
| Ecc050 | 2 | 指定编码的 Ecc 类型为 ECC 050。 |
| Ecc080 | 3 | 指定编码的 Ecc 类型为 ECC 080。 |
| Ecc100 | 4 | 指定编码的 Ecc 类型为 ECC 100。 |
| Ecc140 | 5 | 指定编码的 Ecc 类型为 ECC 140。 |
| Ecc200 | 6 | 指定编码的 Ecc 类型为 ECC 200。推荐使用。 |
