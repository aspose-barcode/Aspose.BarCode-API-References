## 备注


对于 SwissQR IBAN（即范围在 CHxx30000xxxxxx 到 CHxx31999xxxxx 之间的 IBAN），参考号是必需的。

如果指定，参考号必须是有效的 SwissQR 参考（对应 ISR 参考格式）或符合 ISO 11649（\"RFxxxx\"）的有效债权人参考。两者都可以包含空格用于格式化。
