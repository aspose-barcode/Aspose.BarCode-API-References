## HIBCLICDateFormat enum


指定 HIBC LIC 的不同日期格式类型。

```cpp
enum class HIBCLICDateFormat
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| YYYYMMDD | 0 | YYYYMMDD 格式。将在附加补充数据中编码。 |
| MMYY | 1 | MMYY 格式。 |
| MMDDYY | 2 | MMDDYY 格式。 |
| YYMMDD | 3 | YYMMDD 格式。 |
| YYMMDDHH | 4 | YYMMDDHH 格式。 |
| YYJJJ | 5 | 儒略日期格式。 |
| YYJJJHH | 6 | 带小时的儒略日期格式。 |
| 无 | 7 | 不要编码到期日期。 |
