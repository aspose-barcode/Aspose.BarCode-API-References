API 提供用于条码创建、识别和操作的类，允许通过 Java 互操作将其无缝集成到 Node.js 应用程序中。支持的符号覆盖线性、2‑D 和邮政码，例如 Code128、EAN‑13、QR、DataMatrix、Aztec 和 PDF417。所有功能均组织在 aspose.barcode 命名空间下，辅助实用程序位于 Global 命名空间中。

## 命名空间

| 命名空间 | 描述 |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | aspose.barcode 命名空间提供用于在 Node.js via Java 中创建、定制和解码各种条码类型的类和枚举。 |
| [Global](./global/) | Global 命名空间将跨 Aspose.BarCode for Node.js via Java 使用的核心枚举和实用类进行分组。 |
