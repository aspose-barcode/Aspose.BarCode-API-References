## BarCodeImageFormat

指定图像的文件格式。

## 值

| 名称 | 描述 |
| --- | --- |
| BMP | 指定位图 (BMP) 图像格式。 |
| GIF | 指定图形交换格式 (GIF) 图像格式。 |
| JPEG | 指定联合图像专家组 (JPEG) 图像格式。 |
| PNG | 指定 W3C 可移植网络图形 (PNG) 图像格式。 |
| TIFF | 指定标记图像文件格式 (TIFF) 图像格式。 |
| TIFF_IN_CMYK | 指定在 CMYK 颜色模型下的标记图像文件格式 (TIFF) 图像格式。 |
| EMF | 指定增强型图元文件 (EMF) 图像格式。 |
| SVG | 指定可缩放矢量图形 (SVG) 图像格式。 |
| PDF | 指定可移植文档格式 (PDF) 图像格式。 |
