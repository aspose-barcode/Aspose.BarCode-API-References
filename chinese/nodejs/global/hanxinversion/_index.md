## HanXinVersion

汉信码的版本。从 Version01 - 23×23 模块到 Version84 - 189×189 模块，每边以 2 模块递增。

## 值

| 名称 | 描述 |
| --- | --- |
| 无 | 无包围条形码的边框 |
| FRAME | 框架包围条形码 |
| BAR | 两个水平条围绕条形码 |
| FRAME_OUT | 框架包围条形码 |
| BAR_OUT | 两个水平条围绕条形码 |
