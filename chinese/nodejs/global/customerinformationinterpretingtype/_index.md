## CustomerInformationInterpretingType

定义 AustralianPost 条码的客户信息解释类型（C_TABLE 或 N_TABLE）。

## 值

| 名称 | 描述 |
| --- | --- |
| C_TABLE | 使用 C_TABLE 解释客户信息。允许 A..Z、a..z、1..9、空格和 # 符号。 |
| N_TABLE | 使用 N_TABLE 解释客户信息。允许数字。 |
| OTHER | 不要解释客户信息。仅允许 0、1、2 或 3 符号。 |
