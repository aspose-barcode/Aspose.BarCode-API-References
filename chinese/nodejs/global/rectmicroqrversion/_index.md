## RectMicroQRVersion

RectMicroQR 码的版本。从 R7x43 版本到 R17x139 版本。

## 值

| 名称 | 描述 |
| --- | --- |
| AUTO | 指定自动选择 RectMicroQR 的最佳版本。这是默认值。 |
| R7x43 | 指定版本为 7 x 43 模块。 |
| R7x59 | 指定版本为 7 x 59 模块。 |
| R7x77 | 指定版本为 7 x 77 模块。 |
| R7x99 | 指定版本为 7 x 99 模块。 |
