## BarCodeConfidence

包含识别置信水平

## 值

| 名称 | 描述 |
| --- | --- |
| 无 | 条形码的识别置信度，当条码文本未被正确识别或条码被检测为可能的伪造时 |
| MODERATE | 条形码的识别置信度（主要是 1D 条码），校验和弱或甚至没有校验和。若置信度低，可能会出现条码文本的误识别或伪识别 |
| STRONG | 通过 BCH 码（如 Reed–Solomon）确认的识别置信度。读取的条码文本不得出现错误或伪识别 |
