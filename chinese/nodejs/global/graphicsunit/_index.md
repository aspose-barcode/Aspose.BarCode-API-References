## GraphicsUnit

指定给定数据的计量单位。

## 值

| 名称 | 描述 |
| --- | --- |
| WORLD | 指定世界坐标系单位为计量单位。 |
| DISPLAY | 指定显示设备的计量单位。通常视频显示为像素，打印机为 1/100 英寸。 |
| PIXEL | 指定设备像素为计量单位。 |
| POINT | 指定打印机的点（= 1/72 英寸）为计量单位。 |
| INCH | 指定英寸为计量单位。 |
| DOCUMENT | 指定文档单位（= 1/300 英寸）为计量单位。 |
| MILLIMETER | 指定毫米为计量单位。 |
