## Pdf417CompactionMode

Pdf417 条码的压缩模式

## 值

| 名称 | 描述 |
| --- | --- |
| AUTO | 自动检测压缩模式 |
| TEXT | 文本压缩 |
| NUMERIC | 数值压缩模式 |
| BINARY | 二进制压缩模式 |
