## HIBCPASDataLocation

HIBC PAS 数据位置类型。

## 值

| 名称 | 描述 |
| --- | --- |
| 无 | 无包围条形码的边框 |
| FRAME | 框架包围条形码 |
| BAR | 两个水平条围绕条形码 |
| FRAME_OUT | 框架包围条形码 |
| BAR_OUT | 两个水平条围绕条形码 |
