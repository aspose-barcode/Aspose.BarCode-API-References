## HanXinErrorLevel

Reed-Solomon 错误更正级别。从低到高：L1、L2、L3、L4。

## 值

| 名称 | 描述 |
| --- | --- |
| 无 | 无包围条形码的边框 |
| FRAME | 框架包围条形码 |
| BAR | 两个水平条围绕条形码 |
| FRAME_OUT | 框架包围条形码 |
| BAR_OUT | 两个水平条围绕条形码 |
