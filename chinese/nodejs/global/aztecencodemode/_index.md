## AztecEncodeMode

Aztec 条码的编码模式。

## 值

| 名称 | 描述 |
| --- | --- |
| AUTO | 指定自动为 Aztec 选择最佳符号（COMPACT 或 FULL-range）。这是默认值。 |
| COMPACT | 指定 Aztec 的 COMPACT 符号。Aztec COMPACT 符号仅允许 1、2、3 或 4 层。 |
| FULL_RANGE | 指定 Aztec 的 FULL-range 符号。Aztec FULL-range 符号允许 1 到 32 层。 |
| RUNE | 指定 Aztec 的 RUNE 符号。Aztec Runes 是一系列小而独特的机器可读标记。它仅允许 0 到 255 的数值。 |
