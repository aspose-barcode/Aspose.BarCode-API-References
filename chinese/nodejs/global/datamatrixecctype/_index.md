## DataMatrixEccType

指定要编码的 ECC 类型。

## 值

| 名称 | 描述 |
| --- | --- |
| ECC_AUTO | 指定编码的 ECC 类型默认由 Reed-Solomon 错误校正或 ECC 200 定义。 |
| ECC_000 | 指定编码的 ECC 类型为 ECC 000。 |
| ECC_050 | 指定编码的 ECC 类型为 ECC 050。 |
| ECC_080 | 指定编码的 ECC 类型为 ECC 080。 |
| ECC_100 | 指定编码的 ECC 类型为 ECC 100。 |
| ECC_140 | 指定编码的 ECC 类型为 ECC 140。 |
| ECC_200 | 指定编码的 ECC 类型为 ECC 200。推荐使用。 |
