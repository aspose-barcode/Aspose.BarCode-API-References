## BorderDashStyle

指定虚线边框的样式。

## 值

| 名称 | 描述 |
| --- | --- |
| SOLID | 指定实线。 |
| DASH | 指定由短划线组成的线。 |
| DOT | 指定由点组成的线。 |
| DASH_DOT | 指定由短划线-点的重复模式组成的线。 |
| DASH_DOT_DOT | 指定由短划线-点-点的重复模式组成的线。 |
