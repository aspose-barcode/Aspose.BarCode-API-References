## Code128SubType

包含 Code128 子集的类型

## 值

| 名称 | 描述 |
| --- | --- |
| CODE_SET_A | ASCII 字符 00 到 95（0–9，A–Z 和控制码），特殊字符，以及 FNC 1–4 /// |
| CODE_SET_B | ASCII 字符 32 到 127（0–9，A–Z，a–z），特殊字符，以及 FNC 1–4 /// |
| CODE_SET_C | 00–99（使用单个代码点编码两个数字）和 FNC1 /// |
