## IComplexCodetext class

用于与 ComplexBarcodeGenerator 一起使用的复杂码文本接口。

```js
new IComplexCodetext()
```

## 方法

| 名称 | 描述 |
| --- | --- |
| [getBarcodeType()](#getbarcodetype) | 获取条形码类型。 |
| [getConstructedCodetext()](#getconstructedcodetext) | 构造复杂条形码的编码文本 |
| [initFromString(constructedCodetext)](#initfromstring) | 使用构造的编码文本初始化实例。 |

### getBarcodeType() {#getbarcodetype}

获取条形码类型。

**Returns:** Barcode type.

### getConstructedCodetext() {#getconstructedcodetext}

构造复杂条形码的编码文本

**Returns:** Constructed codetext

### initFromString(constructedCodetext) {#initfromstring}

使用构造的编码文本初始化实例。

| 参数 | 描述 |
| --- | --- |
| constructedCodetext | 已构造的 codetext。 |
