## SupplementParameters class

补充参数。用于 Interleaved2of5、Standard2of5、EAN13、EAN8、UPCA、UPCE、ISBN、ISSN、ISMN。

```js
new SupplementParameters()
```

## 方法

| 名称 | 描述 |
| --- | --- |
| [getSupplementData()](#getsupplementdata) | 在 BarCode 之后补充数据。 |
| [getSupplementSpace()](#getsupplementspace) | 主条形码和补充条形码之间的间距（单位值）。 |
| [setSupplementData()](#setsupplementdata) | 在 BarCode 之后补充数据。 |
| [toString()](#tostring) | 返回此 SupplementParameters 的人类可读字符串表示。 |

### getSupplementData() {#getsupplementdata}

在 BarCode 之后补充数据。

### getSupplementSpace() {#getsupplementspace}

主条形码和补充条形码之间的间距（单位值）。

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementData() {#setsupplementdata}

在 BarCode 之后补充数据。

### toString() {#tostring}

返回此 SupplementParameters 的人类可读字符串表示。

**Returns:** A string that represents this SupplementParameters.
