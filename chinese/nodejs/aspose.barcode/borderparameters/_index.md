## BorderParameters class

条形码图像边框参数

```js
new BorderParameters()
```

## 方法

| 名称 | 描述 |
| --- | --- |
| [getColor()](#getcolor) | 边框颜色。默认值：#000000 |
| [getDashStyle()](#getdashstyle) | 边框虚线样式。默认值：BorderDashStyle.SOLID. |
| [getVisible()](#getvisible) | 边框可见性。如果为 false，则参数 Width 始终被忽略（0）。默认值：false. |
| [getWidth()](#getwidth) | 边框宽度。默认值：0。如果 Visible 设置为 false，则被忽略。 |
| [setColor()](#setcolor) | 边框颜色。默认值：#000000 |
| [setDashStyle()](#setdashstyle) | 边框虚线样式。默认值：BorderDashStyle.SOLID. |
| [setVisible()](#setvisible) | 边框可见性。如果为 false，则参数 Width 始终被忽略（0）。默认值：false. |
| [setWidth()](#setwidth) | 边框宽度。默认值：0。如果 Visible 设置为 false，则被忽略。 |
| [toString()](#tostring) | 返回此 BorderParameters 的人类可读字符串表示。 |

### getColor() {#getcolor}

### getVisible() {#getvisible}

### getWidth() {#getwidth}

### setColor() {#setcolor}

边框颜色。默认值：#000000

### setDashStyle() {#setdashstyle}

边框虚线样式。默认值：BorderDashStyle.SOLID.

### setVisible() {#setvisible}

边框可见性。如果为 false，则参数 Width 始终被忽略（0）。默认值：false.

### setWidth() {#setwidth}

边框宽度。默认值：0。如果 Visible 设置为 false，则被忽略。

### toString() {#tostring}
