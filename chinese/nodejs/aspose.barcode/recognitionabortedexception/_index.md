## RecognitionAbortedException class

表示在使用 BarCodeReader 进行识别时超时导致抛出的识别中止异常。

```js
new RecognitionAbortedException(message, executionTime)
```

使用指定的识别中止消息初始化该类的新实例。

| 参数 | 描述 |
| --- | --- |
| 消息 | 异常的错误消息。 |
| executionTime | 当前识别会话的执行时间。 |
