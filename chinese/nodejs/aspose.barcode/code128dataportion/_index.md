## Code128DataPortion class

包含 Code128 类型条形码的子类型数据

```js
new Code128DataPortion()
```

创建一个 `Code128DataPortion` 类的新实例，包含起始代码符号和已解码的代码文本。

## 方法

| 名称 | 描述 |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | 获取 Code128 子集的类型 |
| [getData()](#getdata) | 获取与子类型相关的代码文本部分。 |
| [toString()](#tostring) | 返回此 `Code128DataPortion` 的可读字符串表示。 |

### getCode128SubType() {#getcode128subtype}

获取 Code128 子集的类型

**Returns:** The type of Code128 subset

### getData() {#getdata}

获取与子类型相关的代码文本部分。

**Returns:** The part of code text related to subtype

### toString() {#tostring}

返回此 `Code128DataPortion` 的可读字符串表示。

**Returns:** A string that represents this `Code128DataPortion`.
