## CouponParameters class

优惠券参数。用于 UpcaGs1DatabarCoupon、UpcaGs1Code128Coupon。

```js
new CouponParameters()
```

## 方法

| 名称 | 描述 |
| --- | --- |

| [setSupplementSpace()](#setsupplementspace) | 主条形码和补充条形码之间的间距（单位值）。 |
| [toString()](#tostring) | 返回此 CouponParameters 的可读字符串表示。 |

### getSupplementSpace() {#getsupplementspace}

主条形码和补充条形码之间的间距（单位值）。

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementSpace() {#setsupplementspace}

主条形码和补充条形码之间的间距（单位值）。

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### toString() {#tostring}

返回此 CouponParameters 的可读字符串表示。

**Returns:** A string that represents this CouponParameters.
