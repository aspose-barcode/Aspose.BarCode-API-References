## QrExtCompactionMode

Spécifie le mode de compaction QR pour le texte de code ajouté par QrExtCodetextBuilder.

## Valeurs

| Nom | Description |
| --- | --- |
| AUTO | L'encodeur sélectionne automatiquement le mode de compression QR le plus efficace. |
| NUMERIC | Encode le texte du code en mode numérique QR. Seuls les chiffres 0-9 sont autorisés. |
| ALPHA_NUMERIC | Encode le texte du code en mode alphanumérique QR. |
| BYTES | Encode le texte du code en mode octet QR. |
| KANJI | Encode le texte du code en mode Kanji QR. |
