## BarCodeImageFormat

Spécifie le format de fichier de l'image.

## Valeurs

| Nom | Description |
| --- | --- |
| BMP | Spécifie le format d'image bitmap (BMP). |
| GIF | Spécifie le format d'image Graphics Interchange Format (GIF). |
| JPEG | Spécifie le format d'image Joint Photographic Experts Group (JPEG). |
| PNG | Spécifie le format d'image W3C Portable Network Graphics (PNG). |
| TIFF | Spécifie le format d'image Tagged Image File Format (TIFF). |
| TIFF_IN_CMYK | Spécifie le format d'image Tagged Image File Format (TIFF) en modèle de couleur CMYK. |
| EMF | Spécifie le format d'image Enhanced Metafile (EMF). |
| SVG | Spécifie le format d'image Scalable Vector Graphics (SVG). |
| PDF | Spécifie le format d'image Portable Document Format (PDF). |
