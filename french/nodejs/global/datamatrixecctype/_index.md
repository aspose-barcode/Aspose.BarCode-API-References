## DataMatrixEccType

Spécifiez le type de ECC à encoder.

## Valeurs

| Nom | Description |
| --- | --- |
| ECC_AUTO | Spécifie que le type Ecc encodé est défini par défaut par la correction d'erreurs Reed-Solomon ou ECC 200. |
| ECC_000 | Spécifie que le type Ecc encodé est défini ECC 000. |
| ECC_050 | Spécifie que le type Ecc encodé est défini ECC 050. |
| ECC_080 | Spécifie que le type Ecc encodé est défini ECC 080. |
| ECC_100 | Spécifie que le type Ecc encodé est défini ECC 100. |
| ECC_140 | Spécifie que le type Ecc encodé est défini ECC 140. |
| ECC_200 | Spécifie que le type Ecc encodé est défini ECC 200. Recommandé de l'utiliser. |
