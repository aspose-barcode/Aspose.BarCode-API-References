## BarCodeConfidence

Contient le niveau de confiance de reconnaissance

## Valeurs

| Nom | Description |
| --- | --- |
| NONE | Confiance de reconnaissance du code-barres lorsque le texte du code n'a pas été reconnu correctement ou que le code-barres a été détecté comme une possible contrefaçon |
| MODERATE | Confiance de reconnaissance du code-barres (principalement les codes-barres 1D) avec une somme de contrôle faible ou même sans. Peut contenir quelques erreurs de reconnaissance dans le texte du code ou même des reconnaissances factices si elle est basse |
| STRONG | Confiance de reconnaissance confirmée par des codes BCH comme Reed–Solomon. Il ne doit y avoir aucune erreur dans le texte du code lu ou de fausses reconnaissances |
