## QRErrorLevel

Niveau de correction d'erreurs Reed-Solomon. Du plus bas au plus haut : LEVEL_L, LEVEL_M, LEVEL_Q, LEVEL_H.

## Valeurs

| Nom | Description |
| --- | --- |
| LEVEL_L | Permet la récupération de 7% du texte du code |
| LEVEL_M | Permet la récupération de 15% du texte du code |
| LEVEL_Q | Permet la récupération de 25% du texte du code |
| LEVEL_H | Permet la récupération de 30% du texte du code |
