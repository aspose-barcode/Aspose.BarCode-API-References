## AutoSizeMode

Spécifie les différents types de modes de dimensionnement automatique. La valeur par défaut est AutoSizeMode.NONE.

## Valeurs

| Nom | Description |
| --- | --- |
| NONE | Le redimensionnement automatique est désactivé. Valeur par défaut. |
| NEAREST | Le code-barres est redimensionné à la taille la plus proche la plus basse possible, telle que spécifiée par les propriétés BarCodeWidth et BarCodeHeight. |
| INTERPOLATION | Redimensionne le code-barres à la taille spécifiée avec un léger agrandissement mais il peut être légèrement endommagé dans certains cas à cause de l'interpolation utilisée pour le redimensionnement. La taille peut être spécifiée par les propriétés BarcodeGenerator.BarCodeWidth et BarcodeGenerator.BarCodeHeight. |
