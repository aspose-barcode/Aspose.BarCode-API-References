## SvgColorMode

Modes possibles pour le remplissage de couleur dans le fichier svg, RGB est la valeur par défaut et pris en charge par SVG 1.1. RGBA, HSL, HSLA sont autorisés dans la norme SVG 2.0. Même en RGB, l'opacité sera définie via le paramètre "fill-opacity".

## Valeurs

| Nom | Description |
| --- | --- |
| LEFT | Position gauche. |
| CENTER | Position centrale. |
| RIGHT | Position droite. |
