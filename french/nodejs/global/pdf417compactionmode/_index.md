## Pdf417CompactionMode

Mode de compression du code-barres Pdf417

## Valeurs

| Nom | Description |
| --- | --- |
| AUTO | détection automatique du mode de compaction |
| TEXT | compaction du texte |
| NUMERIC | mode de compaction numérique |
| BINARY | mode de compaction binaire |
