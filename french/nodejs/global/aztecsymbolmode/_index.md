## AztecSymbolMode

Spécifie le mode du symbole Aztec.

## Valeurs

| Nom | Description |
| --- | --- |
| AUTO | Spécifie de sélectionner automatiquement le meilleur symbole (COMPACT ou FULL-range) pour Aztec. C'est la valeur par défaut. |
| COMPACT | Spécifie le symbole COMPACT pour Aztec. Le symbole COMPACT d'Aztec ne permet que 1, 2, 3 ou 4 couches. |
| FULL_RANGE | Spécifie le symbole FULL-range pour Aztec. Le symbole FULL-range d'Aztec permet de 1 à 32 couches. |
| RUNE | Spécifie le symbole RUNE pour Aztec. Les runes Aztec sont une série de petites marques lisibles par machine mais distinctes. Elles ne permettent que des valeurs numériques de 0 à 255. |
