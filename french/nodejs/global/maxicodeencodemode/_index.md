## MaxiCodeEncodeMode

Mode d'encodage pour les codes-barres MaxiCode.

## Valeurs

| Nom | Description |
| --- | --- |
| AUTO | Spécifie de sélectionner automatiquement la meilleure version pour MicroQR. C’est la valeur par défaut. |
| M1 | Spécifie la version M1 pour Micro QR avec des modules de 11 x 11. |
| M2 | Spécifie la version M2 pour Micro QR avec des modules de 13 x 13. |
| M3 | Spécifie la version M3 pour Micro QR avec des modules de 15 x 15. |
| M4 | Spécifie la version M4 pour Micro QR avec des modules de 17 x 17. |
