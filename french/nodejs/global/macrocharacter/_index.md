## MacroCharacter

Les valeurs des caractères macro 05 et 06 sont utilisées pour obtenir un codage plus compact en modes spéciaux. Le caractère macro 05 est traduit en "[)>\u001E05\u001D" comme en-tête de données décodées et "\u001E\u0004" comme pied de données décodées. Le caractère macro 06 est traduit en "[)>\u001E06\u001D" comme en-tête de données décodées et "\u001E\u0004" comme pied de données décodées. Ces exemples montrent comment encoder les caractères macro dans MicroPdf417 et DataMatrix

## Valeurs

| Nom | Description |
| --- | --- |
| AUTO | Détermination automatique |
| TYPE_7 | 24 x 24 modules |
| TYPE_9 | 32 x 32 modules |
| TYPE_29 | 16 x 48 modules |
