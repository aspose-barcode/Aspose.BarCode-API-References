### getAspectRatio() {#getaspectratio}

### getMaxiCodeStructuredAppendModeBarcodesCount() {#getmaxicodestructuredappendmodebarcodescount}

> **Deprecated.** See method description for replacement.

Obtient le nombre de codes-barres MaxiCode en mode d'ajout structuré. Le nombre doit être une valeur comprise entre 2 et 8 (maximum du nombre de codes-barres). Valeur par défaut : -1

### getMode() {#getmode}

Obtient un mode d'encodage MaxiCode.

**Returns:** a MaxiCode encode mode.

### getStructuredAppendModeBarcodeId() {#getstructuredappendmodebarcodeid}

Obtient l'ID du code-barres MaxiCode en mode d'ajout structuré. L'ID doit être une valeur comprise entre 1 et 8. Valeur par défaut : 0

**Returns:** a MaxiCode barcode id in structured append mode.

### getStructuredAppendModeBarcodesCount() {#getstructuredappendmodebarcodescount}

Obtient le nombre de codes-barres MaxiCode en mode d'ajout structuré. Le nombre doit être une valeur comprise entre 2 et 8 (maximum du nombre de codes-barres). Valeur par défaut : -1

**Returns:** a MaxiCode barcodes count in structured append mode.
