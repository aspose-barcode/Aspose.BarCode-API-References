## DataElement class

Représente un champ de données spécifique à une juridiction utilisé dans les documents, par exemple ElementID = "ZVA" avec Value = "01".

```js
new DataElement()
```

## Méthodes

| Nom | Description |
| --- | --- |
| [getElementID()](#getelementid) | Un code de 3 caractères qui identifie le champ spécifique à la juridiction, par ex., "ZVA". |
| [getValue()](#getvalue) | La valeur texte associée au champ, généralement définie par les règles de la juridiction. |
| [setElementID()](#setelementid) | Un code de 3 caractères qui identifie le champ spécifique à la juridiction, par ex., "ZVA". |
