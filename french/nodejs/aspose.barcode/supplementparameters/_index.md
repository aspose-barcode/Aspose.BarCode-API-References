## SupplementParameters class

Paramètres de supplément. Utilisé pour Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

```js
new SupplementParameters()
```

## Méthodes

| Nom | Description |
| --- | --- |
| [getSupplementData()](#getsupplementdata) | Données de supplément suivant BarCode. |
| [getSupplementSpace()](#getsupplementspace) | Espace entre le BarCode principal et le BarCode supplémentaire en valeur d'unité. |
| [setSupplementData()](#setsupplementdata) | Données de supplément suivant BarCode. |
| [toString()](#tostring) | Renvoie une représentation sous forme de chaîne lisible par l'homme de ce SupplementParameters. |

### getSupplementData() {#getsupplementdata}

Données de supplément suivant BarCode.

### getSupplementSpace() {#getsupplementspace}

Espace entre le BarCode principal et le BarCode supplémentaire en valeur d'unité.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementData() {#setsupplementdata}

Données de supplément suivant BarCode.

### toString() {#tostring}

Renvoie une représentation sous forme de chaîne lisible par l'homme de ce SupplementParameters.

**Returns:** A string that represents this SupplementParameters.
