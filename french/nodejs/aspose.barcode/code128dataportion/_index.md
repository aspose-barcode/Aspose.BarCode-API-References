## Code128DataPortion class

Contient les données du sous-type pour le code-barres de type Code128

```js
new Code128DataPortion()
```

Crée une nouvelle instance de la classe `Code128DataPortion` avec le symbole de code de départ et le texte décodé.

## Méthodes

| Nom | Description |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Obtient le type du sous-ensemble Code128 |
| [getData()](#getdata) | Obtient la partie du texte de code liée au sous-type. |
| [toString()](#tostring) | Renvoie une représentation sous forme de chaîne lisible par l'homme de ce `Code128DataPortion`. |

### getCode128SubType() {#getcode128subtype}

Obtient le type du sous-ensemble Code128

**Returns:** The type of Code128 subset

### getData() {#getdata}

Obtient la partie du texte de code liée au sous-type.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Renvoie une représentation sous forme de chaîne lisible par l'homme de ce `Code128DataPortion`.

**Returns:** A string that represents this `Code128DataPortion`.
