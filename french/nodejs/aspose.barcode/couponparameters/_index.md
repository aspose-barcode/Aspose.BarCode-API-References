## CouponParameters class

Paramètres du coupon. Utilisé pour UpcaGs1DatabarCoupon, UpcaGs1Code128Coupon.

```js
new CouponParameters()
```

## Méthodes

| Nom | Description |
| --- | --- |
| [getSupplementSpace()](#getsupplementspace) | Espace entre le BarCode principal et le BarCode supplémentaire en valeur d'unité. |
| [setSupplementSpace()](#setsupplementspace) | Espace entre le BarCode principal et le BarCode supplémentaire en valeur d'unité. |
| [toString()](#tostring) | Renvoie une représentation sous forme de chaîne lisible par l'homme de ces CouponParameters. |

### getSupplementSpace() {#getsupplementspace}

Espace entre le BarCode principal et le BarCode supplémentaire en valeur d'unité.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementSpace() {#setsupplementspace}

Espace entre le BarCode principal et le BarCode supplémentaire en valeur d'unité.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### toString() {#tostring}

Renvoie une représentation sous forme de chaîne lisible par l'homme de ces CouponParameters.

**Returns:** A string that represents this CouponParameters.
