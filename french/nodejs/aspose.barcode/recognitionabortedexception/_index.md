## RecognitionAbortedException class

Représente l'exception d'annulation de reconnaissance qui est levée lorsqu'un délai d'attente est dépassé pendant la reconnaissance avec BarCodeReader.

```js
new RecognitionAbortedException(message, executionTime)
```

Initialise une nouvelle instance de la classe avec le message d'arrêt de reconnaissance spécifié.

| Paramètre | Description |
| --- | --- |
| message | Le message d'erreur de l'exception. |
| executionTime | Le temps d'exécution de la session de reconnaissance actuelle. |
