### getExtraBarcodeText() {#getextrabarcodetext}

Spécifie le texte du code pour un QR supplémentaire, lorsque PatchCode est généré en mode page.

### getFormat() {#getformat}

Format PatchCode. Choisissez PatchOnly pour générer un seul PatchCode. Utilisez le format page pour générer une page Patch avec les PatchCodes comme bordures. Valeur par défaut : PatchFormat.PatchOnly

### getPatchFormat() {#getpatchformat}

> **Deprecated.** See method description for replacement.

Format PatchCode. Choisissez PatchOnly pour générer un seul PatchCode. Utilisez le format page pour générer une page Patch avec les PatchCodes comme bordures. Valeur par défaut : PatchFormat.PATCH_ONLY

**Returns:** PatchFormat
