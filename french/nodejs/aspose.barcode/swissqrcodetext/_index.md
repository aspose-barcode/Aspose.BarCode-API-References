## SwissQRCodetext class

Classe pour l'encodage et le décodage du texte intégré dans le code SwissQR.

```js
new SwissQRCodetext(bill)
```

| Paramètre | Description |
| --- | --- |
| facture | Données de facture SwissQR |

**Throws:** BarcodeException
