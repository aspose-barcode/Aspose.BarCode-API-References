L'API fournit des classes pour la création, la reconnaissance et la manipulation de codes-barres, permettant une intégration transparente dans les applications Node.js via l'interopérabilité Java. Les symbologies prises en charge couvrent les codes linéaires, 2‑D et postaux tels que Code128, EAN‑13, QR, DataMatrix, Aztec et PDF417. Toutes les fonctionnalités sont organisées sous l'espace de noms aspose.barcode, les utilitaires auxiliaires étant situés dans l'espace de noms Global.

| --- | --- |
| [aspose.barcode](./aspose.barcode/) | L'espace de noms aspose.barcode propose des classes et des énumérations pour créer, personnaliser et décoder une grande variété de types de codes-barres dans Node.js via Java. |
| [Global](./global/) | L'espace de noms Global regroupe les énumérations de base et les classes utilitaires utilisées dans Aspose.BarCode pour Node.js via Java. |
