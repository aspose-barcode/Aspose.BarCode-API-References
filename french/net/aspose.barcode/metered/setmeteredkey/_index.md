## Metered.SetMeteredKey method

Définit la clé publique et privée métérée. Si vous achetez une licence métérée, au démarrage de l'application, cette API doit être appelée ; normalement, cela suffit. Cependant, si le téléchargement des données de consommation échoue constamment et dépasse 24 heures, la licence sera mise en statut d'évaluation. Pour éviter ce cas, vous devez vérifier régulièrement le statut de la licence ; si elle est en statut d'évaluation, appelez à nouveau cette API.

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| publicKey | String | clé publique |
| privateKey | String | clé privée |
