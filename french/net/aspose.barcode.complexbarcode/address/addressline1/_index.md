## Address.AddressLine1 property

Obtient ou définit la ligne d'adresse 1.

La ligne d'adresse 1 contient le nom de rue, le numéro de maison ou la boîte postale.

Définir ce champ définit le type d'adresse sur CombinedElements sauf s'il est déjà Structured, auquel cas il devient Conflicting.

Ce champ n'est utilisé que pour les adresses à éléments combinés et est facultatif.

```csharp
public string AddressLine1 { get; set; }
```

### Property Value

La ligne d'adresse 1.
