## Address.AddressLine2 property

Obtient ou définit la ligne d'adresse 2.

La ligne d'adresse 2 contient le code postal et la ville.

Définir ce champ définit le type d'adresse sur CombinedElements sauf s'il est déjà Structured, auquel cas il devient Conflicting.

Ce champ n'est utilisé que pour les adresses à éléments combinés. Pour ce type, il est obligatoire.

```csharp
public string AddressLine2 { get; set; }
```

### Property Value

La ligne d'adresse 2.
