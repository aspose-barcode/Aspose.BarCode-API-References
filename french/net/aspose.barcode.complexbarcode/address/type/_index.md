## Address.Type property

Obtient le type d'adresse.

Le type d'adresse est automatiquement défini en réglant soit la rue / le numéro de maison, soit la ligne d'adresse 1 et 2. Avant de régler les champs, le type d'adresse est Undetermined. Si les champs des deux types sont définis, le type d'adresse devient Conflicting.

```csharp
public AddressType Type { get; }
```

### Property Value

Le type d'adresse.
