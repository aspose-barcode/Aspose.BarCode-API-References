## Address.PostalCode property

Obtient ou définit le code postal.

Définir ce champ définit le type d'adresse sur Structured sauf s'il est déjà CombinedElements, auquel cas il devient Conflicting.

Ce champ n'est utilisé que pour les adresses structurées. Pour ce type, il est obligatoire.

```csharp
public string PostalCode { get; set; }
```

### Property Value

Le code postal.
