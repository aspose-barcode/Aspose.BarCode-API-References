## Address.Street property

Obtient ou définit la rue.

La rue doit être spécifiée sans numéro de maison.

Définir ce champ définit le type d'adresse sur Structured sauf s'il est déjà CombinedElements, auquel cas il devient Conflicting.

Ce champ n'est utilisé que pour les adresses structurées et est facultatif.

```csharp
public string Street { get; set; }
```

### Property Value

La rue.
