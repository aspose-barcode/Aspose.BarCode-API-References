## MailmarkCodetext.DestinationPostCodePlusDPS property

Le PC et le DP doivent être conformes à un format PAF. Chaîne de neuf caractères désignant l'international "XY11 " (notez les 5 espaces de fin) ou un motif de caractères désignant un code de tri domestique. Un code de tri domestique se compose d'un code postal sortant, d'un code postal entrant et d'un suffixe de point de livraison.
