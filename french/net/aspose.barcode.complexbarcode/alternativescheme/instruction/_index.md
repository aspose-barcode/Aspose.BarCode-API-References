## AlternativeScheme.Instruction property

Obtient l'instruction de paiement pour une facture donnée.

L'instruction se compose d'une abréviation de deux lettres pour le schéma, d'un caractère séparateur et d'une séquence de paramètres (séparés par le caractère à l'index 2).

```csharp
public string Instruction { get; set; }
```

### Property Value

L'instruction de paiement.
