## Mailmark2DCodetext.DestinationPostCodeAndDPS property

Contient le code postal de l'adresse de livraison avec le DPS. Si le lieu est intérieur, le code postal/DP comporte le nombre de caractères suivant : zone (1 ou 2 caractères), district (1 ou 2 caractères), secteur (1 caractère), unité (2 caractères), DPS (2 caractères). Le code postal et le DPS doivent être conformes à un format PAF® valide.

public string DestinationPostCodeAndDPS { get; set; }
