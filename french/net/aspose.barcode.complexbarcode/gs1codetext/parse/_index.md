## GS1Codetext.Parse method

Analyse une chaîne d'élément GS1 entre crochets sous la forme (AI)value(AI)value. Un '(' littéral à l'intérieur d'une valeur doit être écrit comme \(; aucune autre séquence d'échappement n'est prise en charge, et ')' ne nécessite pas d'échappement.

```csharp
public static GS1Codetext Parse(string value)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| valeur | String | Chaîne d'élément GS1 entre crochets à analyser. |

### Valeur de retour

Un texte codé GS1 analysé.
