## HIBCPASCodetext.BarcodeType property

Obtient ou définit le type de code-barres. Le texte du code HIBC PAS peut être encodé en utilisant les types d'encodage HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS et HIBCQRPAS. Valeur par défaut : HIBCCode39PAS.

```csharp
public BaseEncodeType BarcodeType { get; set; }
```

### Valeur de retour

Type de code-barres.
