## HIBCLICComplexCodetext.BarcodeType property

Obtient ou définit le type de code-barres. Le texte du code HIBC LIC peut être encodé en utilisant les types d'encodage HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC et HIBCQRLIC. Valeur par défaut : HIBCCode39LIC.

```csharp
public BaseEncodeType BarcodeType { get; set; }
```

### Valeur de retour

Type de code-barres.
