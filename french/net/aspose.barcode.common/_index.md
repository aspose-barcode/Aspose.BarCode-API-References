Le **BarCode.Common** contient des fonctionnalités communes et des outils d'aide pour maintenir la fonctionnalité principale.

## Classes

| Classe | Description |
| --- | --- |
| [GS1Element](./gs1element/) | Représente une paire d'identifiant d'application GS1 immuable et de valeur. |
| [GS1ValidationException](./gs1validationexception/) | L'exception qui est levée par les opérations strictes GS1 lorsque la validation échoue. |
| [GS1ValidationIssue](./gs1validationissue/) | Décrit une erreur de validation GS1. |
| [GS1ValidationResult](./gs1validationresult/) | Contient toutes les erreurs détectables de manière indépendante pour une chaîne d'élément GS1, une URI Digital Link ou une valeur AI. |
| [ProcessorSettings](./processorsettings/) | ProcessorSettings permet de reconnaître les codes-barres avec une amélioration des performances multithreadée |
## Énumération

| Énumération | Description |
| --- | --- |
| [GS1ValidationErrorCode](./gs1validationerrorcode/) | Identifie une chaîne d'élément GS1, une URI Digital Link ou une erreur de validation de valeur. |
