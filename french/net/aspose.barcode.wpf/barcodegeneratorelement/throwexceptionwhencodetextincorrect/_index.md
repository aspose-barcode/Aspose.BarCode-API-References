## BarcodeGeneratorElement.ThrowExceptionWhenCodeTextIncorrect property

Uniquement pour les codes-barres 1D. Si le texte du code est incorrect et que la valeur est définie sur true, une exception sera levée. Sinon le texte du code sera corrigé pour correspondre à la spécification du code-barres.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
