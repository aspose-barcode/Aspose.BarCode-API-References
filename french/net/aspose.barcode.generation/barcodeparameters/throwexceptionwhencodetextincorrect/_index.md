## BarcodeParameters.ThrowExceptionWhenCodeTextIncorrect property

Uniquement pour les codes-barres 1D. Si le texte du code est incorrect et que la valeur est définie sur true, une exception sera levée. Sinon, le texte du code sera corrigé pour correspondre à la spécification du code-barres. Une exception sera toujours levée pour : la symbologie Databar si le texte du code est incorrect. Une exception ne sera jamais levée pour : AustraliaPost, SingapurePost, Code39FullASCII, Code93, Code16K, la symbologie Code128 si le texte du code est incorrect.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
