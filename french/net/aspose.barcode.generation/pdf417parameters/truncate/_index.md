## Pdf417Parameters.Truncate property

Indique si le type de symbologie Pdf417 du BarCode est tronqué (pour réduire l'espace). Aussi connu sous le nom de CompactPDF417. L'indicateur de ligne droite et le motif d'arrêt droit sont supprimés dans ce mode.
