## AutoSizeMode enumeration

Spécifie les différents types de modes de dimensionnement automatique.

```csharp
public enum AutoSizeMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Le redimensionnement automatique est désactivé. |
| Nearest | `1` | Redimensionne le code-barres à la taille la plus basse possible la plus proche spécifiée par les propriétés ImageWidth et ImageHeight. Conserve le rapport d'aspect par défaut. |
| Interpolation | `2` | Redimensionne le code-barres à la taille spécifiée. La taille peut être définie par les propriétés ImageWidth et ImageHeight. Le code-barres généré peut devenir invalide (illisible) après le redimensionnement. |
