## DataMatrixParameters.MacroCharacters property

Les valeurs des caractères macro 05 et 06 sont utilisées pour obtenir un encodage plus compact dans des modes spéciaux. Ne peut être utilisé qu'avec DataMatrixEccType.Ecc200 ou DataMatrixEccType.EccAuto. Ne peut pas être utilisé avec EncodeTypes.GS1DataMatrix Valeur par défaut : MacroCharacters.None.

public MacroCharacter MacroCharacters { get; set; }
