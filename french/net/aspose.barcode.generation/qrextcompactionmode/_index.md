## QrExtCompactionMode enumeration

Spécifie le mode de compaction QR pour le texte de code ajouté par QrExtCodetextBuilder.

```csharp
public enum QrExtCompactionMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | L'encodeur sélectionne automatiquement le mode de compaction QR le plus efficace. |
| Numeric | `1` | Encode le texte de code en mode QR numérique. Seuls les chiffres 0-9 sont autorisés. |
| AlphaNumeric | `2` | Encode le texte de code en mode QR alphanumérique. |
| Bytes | `3` | Encode le texte de code en mode QR octet. |
| Kanji | `4` | Encode le texte de code en mode QR Kanji. |
