## GS1ValidationLevel enumeration

Spécifie le niveau de validation des données GS1. Les niveaux de validation supérieurs incluent tous les contrôles des niveaux inférieurs.

```csharp
public enum GS1ValidationLevel
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Syntax | `0` | Valide la syntaxe GS1, y compris les identifiants d'application, les longueurs de champs et les séparateurs requis. |
| Content | `1` | Valide la syntaxe GS1 et le contenu des valeurs d'identifiant d'application, y compris les jeux de caractères, les sommes de contrôle et les règles spécifiques aux valeurs. |
