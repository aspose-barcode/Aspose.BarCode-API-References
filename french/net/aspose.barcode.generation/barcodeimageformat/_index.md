## BarCodeImageFormat enumeration

Spécifie le format de fichier de l'image.

```csharp
public enum BarCodeImageFormat
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Bmp | `0` | Spécifie le format d'image bitmap (BMP). |
| Gif | `1` | Spécifie le format d'image Graphics Interchange Format (GIF). |
| Jpeg | `2` | Spécifie le format d'image Joint Photographic Experts Group (JPEG). |
| Png | `3` | Spécifie le format d'image W3C Portable Network Graphics (PNG). |
| Tiff | `4` | Spécifie le format d'image Tagged Image File Format (TIFF). |
| TiffInCmyk | `5` | Spécifie le format d'image Tagged Image File Format (TIFF) en modèle de couleur CMYK. (Pris en charge uniquement sur la plateforme Windows, sur les plateformes *nix il est enregistré en tant que Tiff) |
| Emf | `6` | Spécifie le format d'image Enhanced Metafile (EMF). (Pris en charge uniquement sur la plateforme Windows, sur les plateformes *nix il est enregistré en tant que PNG) |
| Svg | `7` | Spécifie le format d'image Scalable Vector Graphics (SVG). |
| Pdf | `8` | Spécifie le format d'image Portable Document Format (PDF). |
