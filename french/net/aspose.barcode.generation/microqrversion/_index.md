## MicroQRVersion enumeration

Version du MicroQR Code. De M1 à M4.

```csharp
public enum MicroQRVersion
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Spécifie de sélectionner automatiquement la meilleure version pour MicroQR. C’est la valeur par défaut. |
| M1 | `1` | Spécifie la version M1 pour Micro QR avec 11 × 11 modules. |
| M2 | `2` | Spécifie la version M2 pour Micro QR avec 13 × 13 modules. |
| M3 | `3` | Spécifie la version M3 pour Micro QR avec 15 × 15 modules. |
| M4 | `4` | Spécifie la version M4 pour Micro QR avec 17 × 17 modules. |
