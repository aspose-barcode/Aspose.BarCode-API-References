## Pdf417MacroTerminator enumeration

Utilisé pour indiquer à l'encodeur s'il faut ajouter le Terminator Macro PDF417 (code mot 922) au segment. Appliqué uniquement pour Macro PDF417.

```csharp
public enum Pdf417MacroTerminator
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Le terminator sera ajouté automatiquement si le nombre de segments est fourni et que le segment actuel est le dernier. Dans les autres cas, le terminator ne sera pas ajouté. |
| None | `1` | Le terminateur ne sera pas ajouté. |
| Set | `2` | Le terminateur sera ajouté. |
