## DataMatrixEccType enumeration

Spécifiez le type de ECC à encoder.

```csharp

```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| EccAuto | `0` | Spécifie que le type ECC encodé est défini par défaut par la correction d'erreurs Reed-Solomon ou ECC 200. |
| Ecc000 | `1` | Spécifie que le type ECC encodé est défini ECC 000. |
| Ecc050 | `2` | Spécifie que le type ECC encodé est défini ECC 050. |
| Ecc080 | `3` | Spécifie que le type ECC encodé est défini ECC 080. |
| Ecc100 | `4` | Spécifie que le type ECC encodé est défini ECC 100. |
| Ecc140 | `5` | Spécifie que le type ECC encodé est défini ECC 140. |
| Ecc200 | `6` | Spécifie que le type ECC encodé est défini ECC 200. Recommandé de l'utiliser. |
