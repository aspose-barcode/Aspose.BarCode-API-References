## QrExtCodetextBuilder.AddFNC1SecondPosition method

Définit FNC1 à la deuxième position. Si un autre mode FNC1 avait été défini auparavant, il est remplacé.

```csharp
public void AddFNC1SecondPosition(string codetext)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| codetext | String | Valeur du FNC1 en deuxième position. La valeur doit être une seule lettre de a‑z ou A‑Z, ou un nombre à deux chiffres de 00 à 99. |
