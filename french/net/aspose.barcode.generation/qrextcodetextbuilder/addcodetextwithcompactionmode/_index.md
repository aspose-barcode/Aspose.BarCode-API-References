## QrExtCodetextBuilder.AddCodetextWithCompactionMode method

Ajoute du texte de code avec le mode de compaction QR spécifié aux éléments de texte de code étendu.

```csharp
public void AddCodetextWithCompactionMode(QrExtCompactionMode mode, string codetext)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| mode | QrExtCompactionMode | Mode de compaction QR pour le codetext. |
| codetext | String | Codetext en Unicode à ajouter comme élément de codetext étendu. |
