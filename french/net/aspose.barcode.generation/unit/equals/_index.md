## Unit.Equals method

Détermine si cette instance et un objet spécifié, qui doit également être un objet [`Unit`](../), ont la même valeur.

```csharp
public override bool Equals(object obj)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| obj | Object | Le [`Unit`](../) à comparer à cette instance. |

### Valeur de retour

true si obj est un [`Unit`](../) et que sa valeur est identique à celle de cette instance ; sinon, false. Si obj est null, la méthode renvoie false.
