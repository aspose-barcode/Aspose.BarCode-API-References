## EncodeTypes.UpcaGs1DatabarCoupon field

Spécifie que les données doivent être encodées avec la spécification de code-barres **UPC coupon with GS1 DataBar addition**. Un exemple de chaîne d'entrée : BarcodeGenerator.Codetext = "514141100906(8110)106141416543213500110000310123196000", où la partie UPCA est "514141100906", la partie Databar est "(8110)106141416543213500110000310123196000". Pour modifier la légende, utilisez Parameters.CaptionAbove.Text = "company prefix + offer code";

```csharp
public static readonly SymbologyEncodeType UpcaGs1DatabarCoupon;
```
