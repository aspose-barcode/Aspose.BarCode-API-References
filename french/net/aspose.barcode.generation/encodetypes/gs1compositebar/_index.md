## EncodeTypes.GS1CompositeBar field

Spécifie que les données doivent être encodées avec la spécification de code-barres **GS1 Composite Bar**. Le texte du code doit contenir des parenthèses pour l'AI. Le texte du code 1D et le texte du code 2D doivent être séparés par le symbole '/'

```csharp
public static readonly SymbologyEncodeType GS1CompositeBar;
```
