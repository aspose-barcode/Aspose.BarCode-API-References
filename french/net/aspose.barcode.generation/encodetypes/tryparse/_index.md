## EncodeTypes.TryParse method

Convertit la représentation sous forme de chaîne d'un BaseEncodeType en son instance. Une valeur de retour indique si la conversion a réussi ou échoué.

```csharp
public static bool TryParse(string parsingType, out BaseEncodeType result)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| parsingType | String | Une chaîne au format "Index:-1; Name:None" à convertir. |
| résultat | BaseEncodeType& | Un SingleEncodeType réel est renvoyé lorsque la conversion s'est terminée avec succès ; |

### Valeur de retour

**true** if s was converted successfully; otherwise, **false**.
