## DotCodeExtendedParameters.StructuredAppendModeBarcodeId property

Obtient l’ID du code‑barres DotCode en mode d’ajout structuré. L’ID commence à 1 et doit être inférieur ou égal au nombre de codes‑barres. La valeur par défaut est -1.

```csharp
public int StructuredAppendModeBarcodeId { get; }
```

### Property Value

L'ID du code-barres en mode d'ajout structuré DotCode.
