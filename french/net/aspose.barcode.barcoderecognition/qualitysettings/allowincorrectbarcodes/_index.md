## QualitySettings.AllowIncorrectBarcodes property

Permet au moteur de reconnaître les codes‑barres qui ont un checksum incorrect ou des valeurs incorrectes. Le mode peut être utilisé pour reconnaître les codes‑barres endommagés avec un texte incorrect.

```csharp
public bool AllowIncorrectBarcodes { get; set; }
```

### Property Value

Permet au moteur de reconnaître les codes-barres incorrects.
