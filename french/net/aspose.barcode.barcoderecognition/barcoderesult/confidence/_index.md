## BarCodeResult.Confidence property

Obtient le niveau de confiance de la reconnaissance du code-barres reconnu

```csharp
public BarCodeConfidence Confidence { get; }
```

### Property Value

Strong ne contient pas de faux ou de mauvaises reconnaissances, Moderate peut parfois contenir des faux ou un texte de code incorrect parce que ce niveau de confiance s'applique aux barcodes avec un checksum faible ou même sans, None a toujours un texte de code incorrect et peut entraîner des reconnaissances factices
