## BarCodeGeneratorControl.ThrowExceptionWhenCodeTextIncorrect property

Uniquement pour les codes-barres 1D. Si le codetext est incorrect et que la valeur est définie sur true, une exception sera levée. Sinon le codetext sera corrigé pour correspondre à la spécification du code-barres. Une exception sera toujours levée pour : la symbologie Databar si le codetext est incorrect. Une exception ne sera jamais levée pour : AustraliaPost, SingapurePost, Code39Extended, Code93Extended, Code16K, la symbologie Code128 si le codetext est incorrect.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
