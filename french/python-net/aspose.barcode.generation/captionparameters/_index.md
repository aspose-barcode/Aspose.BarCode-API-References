## CaptionParameters class

Paramètres de légende.

Le type CaptionParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| text | Texte de la légende.<br/>            Valeur par défaut : chaîne vide. |
| font | Police de la légende.<br/>            Valeur par défaut : Arial 8 pt régulier. |
| visible | Visibilité du texte de la légende.<br/>            Valeur par défaut : false. |
| text_color | Couleur du texte de la légende.<br/>            Valeur par défaut : Color.Black. |
| padding | Marges des légendes.<br/>            Valeur par défaut pour CaptionAbove : 5pt 5pt 0 5pt.<br/>            Valeur par défaut pour CaptionBelow : 0 5pt 5pt 5pt. |
| alignement | Alignement horizontal du texte de la légende.<br/>            Valeur par défaut : StringAlignment.Center. |
| no_wrap | Spécifie les retours à la ligne (sauts de ligne) dans le texte.<br/>            Valeur par défaut : false. |
