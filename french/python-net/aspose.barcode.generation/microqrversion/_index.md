## MicroQRVersion enumeration

Version du MicroQR Code.<br/>            De M1 à M4.

## Members
| Nom du membre | Description |
| :- | :- |
| AUTO | Spécifie de sélectionner automatiquement la meilleure version pour MicroQR.<br/>            C'est la valeur par défaut. |
| M1 | Spécifie la version M1 pour Micro QR avec des modules de 11 × 11. |
| M2 | Spécifie la version M2 pour Micro QR avec des modules de 13 × 13. |
| M3 | Spécifie la version M3 pour Micro QR avec des modules de 15 × 15. |
| M4 | Spécifie la version M4 pour Micro QR avec des modules de 17 × 17. |
