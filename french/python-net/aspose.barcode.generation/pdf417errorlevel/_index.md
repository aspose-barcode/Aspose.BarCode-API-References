## Pdf417ErrorLevel enumeration

Niveau de correction d'erreurs du code-barres pdf417, du niveau 0 au niveau 9, le niveau 0 signifie aucune correction d'erreurs, le niveau 8 signifie la meilleure correction d'erreurs
