## MaxiCodeMode enumeration

Mode d'encodage pour les codes-barres MaxiCode.

## Members
| Nom du membre | Description |
| :- | :- |
| MODE2 | Le mode 2 encode les informations postales dans le premier message et les données dans le deuxième message.<br/>            Il possède un code postal à 9 chiffres (utilisé uniquement aux États‑Unis). |
| MODE3 | Le Mode 3 encode les informations postales dans le premier message et les données dans le deuxième message. <br/>            Dispose d'un code postal alphanumérique de 6 caractères, utilisé dans le monde. |
| MODE4 | Le Mode 4 encode les données dans le premier et le deuxième message, avec une correction ECC courte. |
| MODE5 | Le Mode 5 encode les données dans le premier et le deuxième message, avec une correction ECC longue. |
| MODE6 | Le Mode 6 encode les données dans le premier et le deuxième message, avec une correction ECC courte.<br/>            Utilisé pour encoder l'appareil. |
