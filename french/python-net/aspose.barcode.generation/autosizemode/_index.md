## AutoSizeMode enumeration

Spécifie les différents types de modes de dimensionnement automatique.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Le redimensionnement automatique est désactivé. |
| NEAREST | Redimensionne le code-barres à la taille la plus proche et la plus petite possible spécifiée par les propriétés ImageWidth et ImageHeight.<br/>            Conserve le rapport d'aspect par défaut. |
| INTERPOLATION | Redimensionne le code-barres à la taille spécifiée.<br/>            La taille peut être spécifiée par les propriétés ImageWidth et ImageHeight.<br/>            Le code-barres généré peut être invalide (non lisible) après le redimensionnement. |
