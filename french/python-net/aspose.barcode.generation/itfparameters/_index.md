## ITFParameters class

Paramètres ITF.

Le type ITFParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| border_thickness | Obtient ou définit l'épaisseur d'une bordure ITF (barre porteuse) en valeur d'unité.<br/>            Valeur par défaut : 12pt. |
| border_type | Type de bordure du code-barres ITF.<br/>            Valeur par défaut : ITF14BorderType.Bar. |
| quiet_zone_coef | Taille des zones calmes dans xDimension.<br/>            Valeur par défaut : 10, ce qui signifie que si xDimension = 2 px alors les zones calmes seront de 20 px. |
