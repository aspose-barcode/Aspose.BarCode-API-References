## Pdf417MacroTerminator enumeration

Utilisé pour indiquer à l'encodeur s'il faut ajouter le Terminator Macro PDF417 (code mot 922) au segment. <br/>            Appliqué uniquement pour Macro PDF417.

## Members
| Nom du membre | Description |
| :- | :- |
| AUTO | Le terminateur sera ajouté automatiquement si le nombre de segments est fourni <br/>            et que le segment actuel est le dernier. Dans les autres cas, le terminateur ne sera pas ajouté. |
| NONE | Le terminateur ne sera pas ajouté. |
| SET | Le terminateur sera ajouté. |
