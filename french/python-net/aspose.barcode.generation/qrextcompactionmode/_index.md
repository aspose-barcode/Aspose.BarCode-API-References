## QrExtCompactionMode enumeration

Spécifie le mode de compaction QR pour le texte de code ajouté par QrExtCodetextBuilder.

## Members
| Nom du membre | Description |
| :- | :- |
| AUTO | L'encodeur sélectionne automatiquement le mode de compaction QR le plus efficace. |
| NUMERIC | Encode le texte du code en mode QR Numérique. Seuls les chiffres 0-9 sont autorisés. |
| ALPHA_NUMERIC | Encode le texte du code en mode QR Alphanumérique. |
| BYTES | Encode le texte du code en mode QR Octet. |
| KANJI | Encode le texte du code en mode QR Kanji. |
