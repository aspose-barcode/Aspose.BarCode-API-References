## BorderParameters class

Paramètres de bordure d'image de code-barres

Le type BorderParameters expose les membres suivants:
## Properties
| Name | Description |
| :- | :- |
| visible | Visibilité de la bordure. Si false alors le paramètre Width est toujours ignoré (0).<br/>            Valeur par défaut: false. |
| width | Largeur de la bordure.<br/>            Valeur par défaut: 0.<br/>            Ignorée si Visible est défini sur false. |
| dash_style | Style de tirets de la bordure.<br/>            Valeur par défaut: BorderDashStyle.Solid. |
| couleur | Couleur de la bordure.<br/>            Valeur par défaut: Color.Black. |
