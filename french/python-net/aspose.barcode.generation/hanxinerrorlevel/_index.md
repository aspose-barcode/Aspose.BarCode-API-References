## HanXinErrorLevel enumeration

Niveau de correction d'erreurs Reed-Solomon. Du bas vers le haut : L1, L2, L3, L4.

## Members
| Nom du membre | Description |
| :- | :- |
| L1 | Permet la récupération de 8 % du texte du code |
| L2 | Permet la récupération de 15 % du texte du code |
| L3 | Permet la récupération de 23 % du texte du code |
| L4 | Permet la récupération de 30 % du texte du code |
