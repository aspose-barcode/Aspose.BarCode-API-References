## QRErrorLevel enumeration

Niveau de correction d'erreurs Reed-Solomon. Du bas vers le haut : LevelL, LevelM, LevelQ, LevelH.

## Members
| Nom du membre | Description |
| :- | :- |
| LEVEL_L | Le niveau de correction d'erreur L peut être appliqué aux codes-barres QR et MicroQR.<br/>            Permet de récupérer 7 % du texte du code. |
| LEVEL_M | Le niveau de correction d'erreur M peut être appliqué aux codes-barres QR, aux codes-barres RectMicroQR et aux codes-barres MicroQR avec des versions de M2 à M4.<br/>            Permet de récupérer 15 % du texte du code. |
| LEVEL_Q | Le niveau de correction d'erreur Q peut être appliqué aux codes-barres QR et aux codes-barres MicroQR avec la version M4.<br/>            Permet de récupérer 25 % du texte du code. |
| LEVEL_H | Le niveau de correction d'erreur H peut être appliqué aux codes-barres QR et aux codes-barres RectMicroQR.<br/>            Permet de récupérer 30 % du texte du code. |
