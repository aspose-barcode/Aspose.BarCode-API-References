## MacroCharacter enumeration

Les valeurs des caractères macro 05 et 06 sont utilisées pour obtenir un encodage plus compact dans les modes spéciaux.<br/>            Le caractère macro 05 est traduit en "[)>\u001E05\u001D" comme en-tête de données décodées et "\u001E\u0004" comme pied de données décodées.<br/>            Le caractère macro 06 est traduit en "[)>\u001E06\u001D" comme en-tête de données décodées et "\u001E\u0004" comme pied de données décodées.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Aucun des caractères macro n'est ajouté aux données du code-barres |
| MACRO05 | Le caractère macro 05 est ajouté aux données du code-barres en première position.<br/>            Identifiant de données GS1 ISO 15434<br/>            Le caractère est traduit en "[)>\u001E05\u001D" comme en-tête de données décodées et "\u001E\u0004" comme bande-annonce de données décodées. |
| MACRO06 | Le caractère macro 06 est ajouté aux données du code-barres en première position.<br/>            Identifiant de données ASC MH10 ISO 15434<br/>            Le caractère est traduit en "[)>\u001E06\u001D" comme en-tête de données décodées et "\u001E\u0004" comme bande-annonce de données décodées. |
