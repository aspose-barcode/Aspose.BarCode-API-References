## AztecSymbolMode enumeration

Spécifie le mode du symbole Aztec.

## Members
| Nom du membre | Description |
| :- | :- |
| AUTO | Spécifie de sélectionner automatiquement le meilleur symbole (Compact ou Full-range) pour Aztec.<br/>            C’est la valeur par défaut. |
| COMPACT | Spécifie le symbole Compact pour Aztec.<br/>            Le symbole Compact d’Aztec ne permet que 1, 2, 3 ou 4 couches. |
| FULL_RANGE | Spécifie le symbole Full-range pour Aztec.<br/>            Le symbole Full-range d’Aztec permet de 1 à 32 couches. |
| RUNE | Spécifie le symbole Rune pour Aztec.<br/>            Les runes d’Aztec sont une série de petites marques lisibles par machine mais distinctes. Elles ne permettent que des valeurs numériques de 0 à 255. |
