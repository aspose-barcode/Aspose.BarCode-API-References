## Code128EncodeMode enumeration

Mode d'encodage pour les codes-barres Code128.

## Members
| Nom du membre | Description |
| :- | :- |
| AUTO | Encode le texte du code en mode ISO 15417 classique. Le mode doit être utilisé dans tous les cas ordinaires. |
| CODE_A | Encode le texte du code uniquement dans le jeu de codes 128A. |
| CODE_B | Encode le texte du code uniquement dans le jeu de codes 128B. |
| CODE_C | Encode le texte du code uniquement dans le jeu de codes 128C. |
| CODE_AB | Encode le texte du code uniquement dans les jeux de codes 128A et 128B. |
| CODE_AC | Encode le texte du code uniquement dans les jeux de codes 128A et 128C. |
| CODE_BC | Encode le texte du code uniquement dans les jeux de codes 128B et 128C. |
