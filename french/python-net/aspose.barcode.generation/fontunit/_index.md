## FontUnit class

Définit un format particulier pour le texte, incluant la police, la taille et les attributs de style<br/>            où la taille est dans la propriété Unit value.

Le type FontUnit expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| family_name | Obtient ou définit le nom de la police de ce Font. |
| style | Obtient ou définit les informations de style pour ce FontUnit. |
| size | Obtient ou définit la taille de ce FontUnit en valeur Unit. |
