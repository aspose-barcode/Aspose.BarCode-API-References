## SvgColorMode enumeration

Modes possibles pour la couleur de remplissage dans un fichier svg, RGB est la valeur par défaut et prise en charge par SVG 1.1.<br/>            RGBA, HSL, HSLA sont autorisés dans la norme SVG 2.0.<br/>            Même en RGB, l'opacité sera définie via le paramètre "fill-opacity".

## Members
| Nom du membre | Description |
| :- | :- |
| RGB | Mode RGB, exemple : fill=\"#ff5511\" fill-opacity=\"0.73\". Mode par défaut. |
| RGBA | Mode RGBA, exemple : fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | Mode HSL, exemple : fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | Mode HSLA, exemple : fill=\"hsla(30, 50%, 70%, 0.8)\" |
