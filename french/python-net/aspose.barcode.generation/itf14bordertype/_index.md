## ITF14BorderType enumeration

Type de bordure ITF14 du code-barres

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Aucune bordure entourant le code-barres |
| FRAME | Cadre entourant le code-barres |
| BAR | Deux barres horizontales entourant le code-barres |
| FRAME_OUT | Cadre entourant le code-barres. Il est dessiné à l'extérieur du code-barres et n'affecte pas la hauteur. |
| BAR_OUT | Deux barres horizontales entourant le code-barres. Elles sont dessinées à l'extérieur du code-barres et n'affectent pas la hauteur. |
