## BorderDashStyle enumeration

Spécifie le style des lignes de bordure en pointillés.

## Members
| Nom du membre | Description |
| :- | :- |
| SOLID | Spécifie une ligne pleine. |
| DASH | Spécifie une ligne composée de tirets. |
| DOT | Spécifie une ligne composée de points. |
| DASH_DOT | Spécifie une ligne composée d'un motif répété tiret-point. |
| DASH_DOT_DOT | Spécifie une ligne composée d'un motif répété tiret-point-point. |
