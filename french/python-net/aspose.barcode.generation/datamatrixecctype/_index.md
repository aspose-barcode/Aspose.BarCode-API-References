## DataMatrixEccType enumeration

Spécifiez le type du ECC à encoder.

## Members
| Nom du membre | Description |
| :- | :- |
| ECC_AUTO | Spécifie que le type Ecc encodé est défini par défaut par la correction d'erreurs Reed-Solomon ou ECC 200. |
| ECC000 | Spécifie que le type Ecc encodé est défini ECC 000. |
| ECC050 | Spécifie que le type Ecc encodé est défini ECC 050. |
| ECC080 | Spécifie que le type Ecc encodé est défini ECC 080. |
| ECC100 | Spécifie que le type Ecc encodé est défini ECC 100. |
| ECC140 | Spécifie que le type Ecc encodé est défini ECC 140. |
| ECC200 | Spécifie que le type Ecc encodé est défini ECC 200. Recommandé de l'utiliser. |
