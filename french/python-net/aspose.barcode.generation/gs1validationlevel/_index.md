## GS1ValidationLevel enumeration

Spécifie le niveau de validation des données GS1.<br/>            Les niveaux de validation supérieurs incluent tous les contrôles des niveaux inférieurs.

## Members
| Nom du membre | Description |
| :- | :- |
| SYNTAX | Valide la syntaxe GS1, y compris les identifiants d'application,<br/>            les longueurs de champ et les séparateurs requis. |
| CONTENT | Valide la syntaxe GS1 et le contenu des valeurs des identifiants d'application,<br/>            y compris les jeux de caractères, les sommes de contrôle et les règles spécifiques aux valeurs. |
