## MaxiCodeParameters class

Paramètres MaxiCode.

Le type MaxiCodeParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| mode | Obtient ou définit un mode d'encodage MaxiCode. |
| encode_mode | Obtient ou définit un mode d'encodage MaxiCode. <br/>            Valeur par défaut : Auto. |
| eci_encoding | Obtient ou définit l'encodage ECI. Utilisé lorsque MaxiCodeEncodeMode est Auto.<br/>            Valeur par défaut : ISO-8859-1 |
| structured_append_mode_barcode_id | Obtient ou définit un identifiant de code-barres MaxiCode en mode d'ajout structuré. <br/>            L'ID doit être une valeur comprise entre 1 et 8. <br/>            Valeur par défaut : 0 |
| structured_append_mode_barcodes_count | Obtient ou définit le nombre de codes-barres MaxiCode en mode d'ajout structuré. <br/>            Le nombre doit être une valeur comprise entre 2 et 8 (nombre maximal de codes-barres).<br/>            Valeur par défaut : -1 |
| aspect_ratio | Ratio hauteur/largeur du module de code-barres 2D. |
