## MaxiCodeCodetext class

Classe de base pour l'encodage et le décodage du texte intégré dans le code MaxiCode.

Le type MaxiCodeCodetext expose les membres suivants:
## Properties
| Name | Description |
| :- | :- |
| encode_mode | Obtient ou définit un mode d'encodage MaxiCode. <br/>            Valeur par défaut : Auto. |
| eci_encoding | Obtient ou définit l'encodage ECI. Utilisé lorsque MaxiCodeEncodeMode est Auto.<br/>            Valeur par défaut : ISO-8859-1 |
## Methods
| Name | Description |
| :- | :- |
| get_mode() | Obtient le mode MaxiCode. |
| get_constructed_codetext() | Construit le codetext |
| init_from_string(constructed_codetext) | Initialise l'instance à partir du codetext construit. |
| get_barcode_type() | Obtient le type de code-barres. |
