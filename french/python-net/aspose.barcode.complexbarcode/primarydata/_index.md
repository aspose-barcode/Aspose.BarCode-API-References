## PrimaryData class

Le type PrimaryData expose les membres suivants :
## Constructeurs
| Name | Description |
| :- | :- |
| PrimaryData() | Initialise une nouvelle instance de la classe PrimaryData |
## Properties
| Name | Description |
| :- | :- |
| labeler_identification_code | Identifie la date du code d'identification du labelisateur.<br/>            Le code d'identification du labelisateur doit être une chaîne alphanumérique de 4 symboles, le premier caractère étant toujours alphabétique. |
| product_or_catalog_number | Identifie le numéro de produit ou de catalogue. Le numéro de produit ou de catalogue doit être une chaîne alphanumérique d'une longueur maximale de 18 symboles. |
| unit_of_measure_id | Identifie l'ID de l'unité de mesure. L'ID de l'unité de mesure doit être une valeur entière de 0 à 9. |
