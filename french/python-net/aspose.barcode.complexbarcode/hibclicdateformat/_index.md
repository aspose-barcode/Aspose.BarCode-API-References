## HIBCLICDateFormat enumeration

Spécifie les différents types de formats de date pour HIBC LIC.

## Members
| Nom du membre | Description |
| :- | :- |
| YYYYMMDD | Format YYYYMMDD. Sera encodé dans les données supplémentaires complémentaires. |
| MMYY | Format MMYY. |
| MMDDYY | Format MMDDYY. |
| YYMMDD | Format YYMMDD. |
| YYMMDDHH | Format YYMMDDHH. |
| YYJJJ | Format de date julienne. |
| YYJJJHH | Format de date julien avec heures. |
| NONE | Ne pas encoder la date d'expiration. |
