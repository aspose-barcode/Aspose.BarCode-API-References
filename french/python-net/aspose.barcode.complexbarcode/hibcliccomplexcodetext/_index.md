## HIBCLICComplexCodetext class

Classe de base pour l'encodage et le décodage du texte intégré dans le code HIBC LIC.

Le type HIBCLICComplexCodetext expose les membres suivants:
## Properties
| Name | Description |
| :- | :- |
| barcode_type | Obtient ou définit le type de code-barres. Le texte de code HIBC LIC peut être encodé en utilisant les types d'encodage HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC et HIBCQRLIC.<br/>            Valeur par défaut: HIBCCode39LIC. |
## Methods
| Name | Description |
| :- | :- |
| get_constructed_codetext() | Construit le codetext |
| init_from_string(constructed_codetext) | Initialise l'instance à partir du codetext construit. |
| get_barcode_type() | Obtient le type de code-barres. |
