## Iso15416Quality class

Stocke les niveaux de qualité du code-barres calculés selon la norme ISO/IEC 15416 pour les codes-barres 1D.

Le type Iso15416Quality expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| grade | Obtient la note globale de qualité du code-barres selon ISO/IEC 15416. |
| decode | Obtient la note de décodage indiquant si le code-barres peut être décodé à l'aide de l'algorithme de décodage de référence. |
| symbol_contrast | Obtient la note de contraste du symbole basée sur la différence entre la réflectance maximale et minimale. |
| minimum_reflectance | Obtient le grade de réflectance minimum basé sur la réflectance de la barre la plus sombre. |
| minimum_edge_contrast | Obtient le grade de contraste de bord minimum basé sur la plus petite différence de réflectance entre les barres et espaces adjacents. |
| modulation | Obtient le grade de modulation basé sur l'uniformité du contraste de bord sur l'ensemble du code-barres. |
| defects | Obtient le grade de défauts basé sur les irrégularités de réflectance au sein des barres et espaces. |
| decodability | Obtient le grade de décodabilité basé sur la précision des largeurs des barres et espaces. |
