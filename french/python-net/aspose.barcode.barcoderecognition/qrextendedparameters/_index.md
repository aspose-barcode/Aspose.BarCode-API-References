## QRExtendedParameters class

Stocke les informations d'ajout structuré QR du code-barres reconnu

Le type QRExtendedParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| is_empty | Teste si tous les paramètres n'ont que des valeurs par défaut |
| structured_append_mode_bar_codes_quantity | Obtient la quantité de codes-barres en mode d'ajout structuré QR. La valeur par défaut est -1. |
| structured_append_mode_bar_code_index | Obtient l'index du code-barres en mode d'ajout structuré QR. L'index commence à 0. La valeur par défaut est -1. |
| structured_append_mode_parity_data | Obtient les données de parité du mode d'ajout structuré QR. La valeur par défaut est -1. |
| version | Version du code QR reconnu. De Version1 à Version40. |
| micro_qr_version | Version du code MicroQR reconnu. De M1 à M4. |
| rect_micro_qr_version | Version du code RectMicroQR reconnu. De R7x43 à R17x139. |
| error_level | Niveau de correction d'erreurs Reed-Solomon du code-barres reconnu. Du plus bas au plus haut : LevelL, LevelM, LevelQ, LevelH. |
