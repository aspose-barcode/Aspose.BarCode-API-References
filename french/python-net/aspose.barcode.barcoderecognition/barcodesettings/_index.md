## BarcodeSettings class

Les principaux paramètres de décodage BarCode. Contient des paramètres qui influencent les données reconnues.

Le type BarcodeSettings expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Supprime les caractères FNC1, FNC2, FNC3 du codetext. La valeur par défaut est false. |
| only_requested_types | Renvoie uniquement les types de code-barres explicitement spécifiés pour la reconnaissance. <br/>            Lorsqu'il est activé, les code-barres reconnus d'autres types compatibles ou équivalents sont filtrés. <br/>            La valeur par défaut est false. |
| detect_encoding | L'indicateur qui force le moteur à détecter l'encodage du codetext pour les jeux de caractères Unicode. La valeur par défaut est true. |
| australia_post | Obtient les paramètres de décodage AustraliaPost |
| calculate_symbol_quality | Obtient ou définit une valeur indiquant s'il faut calculer la qualité du symbole du code-barres lors de la reconnaissance. |
