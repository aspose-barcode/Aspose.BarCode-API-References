## Pdf417ExtendedParameters class

Stocke les informations de métadonnées MacroPdf417 du code-barres reconnu

Le type Pdf417ExtendedParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| is_empty | Teste si tous les paramètres n'ont que des valeurs par défaut |
| macro_pdf_417_file_id | Obtient l'ID du fichier du code-barres, disponible uniquement avec MacroPdf417. |
| macro_pdf_417_segment_id | Obtient l'ID du segment du code-barres, disponible uniquement avec MacroPdf417. |
| macro_pdf_417_segments_count | Obtient le nombre de segments du code-barres macro pdf417. La valeur par défaut est -1. |
| macro_pdf_417_file_name | Nom du fichier Macro PDF417 (optionnel). |
| macro_pdf_417_file_size | Taille du fichier Macro PDF417 (optionnel). |
| macro_pdf_417_sender | Nom de l'expéditeur Macro PDF417 (optionnel). |
| macro_pdf_417_addressee | Nom du destinataire Macro PDF417 (optionnel). |
| macro_pdf_417_time_stamp | Horodatage Macro PDF417 (facultatif). |
| macro_pdf_417_checksum | Somme de contrôle Macro PDF417 (facultatif). |
| macro_pdf_417_terminator | Indique si le segment est le dernier segment d'un fichier Macro PDF417. |
| is_reader_initialization | Utilisé pour indiquer au lecteur d'interpréter les données contenues dans le symbole comme une programmation pour l'initialisation du lecteur. |
| is_linked | Indicateur qui indique que le code-barres doit être lié à un code-barres 1D. |
| is_code_128_emulation | Indicateur qui indique que le code-barres MicroPdf417 est encodé avec les mots de code d'émulation Code 128 908, 909, 910 ou 911. |
