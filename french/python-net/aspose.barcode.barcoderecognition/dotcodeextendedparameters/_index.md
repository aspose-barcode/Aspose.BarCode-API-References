## DotCodeExtendedParameters class

Stocke les données spéciales du code-barres DotCode reconnu

Le type DotCodeExtendedParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| is_empty | Teste si tous les paramètres n'ont que des valeurs par défaut |
| structured_append_mode_barcodes_count | Obtient le nombre de codes-barres du mode d'ajout structuré DotCode. La valeur par défaut est -1. Le nombre doit être compris entre 1 et 35. |
| structured_append_mode_barcode_id | Obtient l'ID du code-barres du mode d'ajout structuré DotCode. L'ID commence à 1 et doit être inférieur ou égal au nombre de codes-barres. La valeur par défaut est -1. |
| is_reader_initialization | Indique si le code est utilisé pour instruire le lecteur à interpréter les données suivantes comme des instructions d'initialisation ou de reprogrammation du lecteur de code-barres.<br/>            Valeur par défaut : false. |
