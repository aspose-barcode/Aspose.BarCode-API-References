## AztecExtendedParameters class

Stocke les données spéciales du code-barres Aztec reconnu.

Le type AztecExtendedParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| is_empty | Teste si tous les paramètres n'ont que des valeurs par défaut |
| structured_append_barcodes_count | Obtient le nombre de codes-barres du mode d'ajout structuré Aztec. La valeur par défaut est 0. Le nombre doit être compris entre 1 et 26. |
| structured_append_barcode_id | Obtient l'ID du code-barres du mode d'ajout structuré Aztec. L'ID commence à 1 et doit être inférieur ou égal au nombre de codes-barres. La valeur par défaut est 0. |
| structured_append_file_id | Obtient l'ID du fichier du mode d'ajout structuré Aztec. La valeur par défaut est une chaîne vide |
| is_reader_initialization | Indique si le code est utilisé pour instruire le lecteur à interpréter les données suivantes comme des instructions d'initialisation ou de reprogrammation du lecteur de code-barres.<br/>            Valeur par défaut : false. |
