## BarCodeConfidence enumeration

Contient le niveau de confiance de la reconnaissance

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Confiance de reconnaissance du code-barres lorsque le texte du code n'a pas été reconnu correctement ou que le code-barres a été détecté comme éventuellement faux. |
| MODERATE | Confiance de reconnaissance du code-barres (principalement les codes-barres 1D) avec une somme de contrôle faible ou même sans. Peut contenir quelques erreurs de reconnaissance dans le texte du code<br/>            ou même des reconnaissances fausses si |
| STRONG | Confiance de reconnaissance confirmée par des codes BCH tels que Reed–Solomon. Il ne doit pas y avoir d'erreurs dans le texte du code lu ou de reconnaissances fausses. |
