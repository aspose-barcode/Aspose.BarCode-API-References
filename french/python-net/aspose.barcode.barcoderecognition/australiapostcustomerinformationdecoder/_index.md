## AustraliaPostCustomerInformationDecoder class

Interface publique pour le décodage du champ d'information client utilisé dans la symbologie AustraliaPost. L'implémentation doit être fournie par l'utilisateur.

Le type AustraliaPostCustomerInformationDecoder expose les membres suivants :
## Methods
| Name | Description |
| :- | :- |
| decode(customer_information_field) | Décode le champ d'information client à partir de la symbologie AustraliaPost. <br/>            Peut être utilisé pour différentes interprétations de données provenant du codage NTable et CTable.<br/>            Les données sont fournies sous forme d'une ligne de valeurs de barres : 0, 1, 2 ou 3. |
