## LuminanceFrame class

Représente une trame d'image en niveaux de gris 8 bits. Chaque pixel est représenté par un octet contenant sa valeur de luminance.

Le type LuminanceFrame expose les membres suivants :
## Constructeurs
| Name | Description |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Initialise une nouvelle instance de la classe LuminanceFrame |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Initialise une nouvelle instance de la classe LuminanceFrame |
## Properties
| Name | Description |
| :- | :- |
| data | Obtient les données de luminance. |
| width | Obtient la largeur du cadre en pixels. |
| height | Obtient la hauteur du cadre en pixels. |
| row_stride | Obtient la distance en octets entre les débuts<br/>            de deux lignes adjacentes. |
| rotation_degrees | Obtient le nombre de degrés de rotation horaire du cadre nécessaire pour obtenir l'orientation correcte. |
