## BarCodeRegionParameters class

Représente la région du code-barres reconnu et l'angle du code-barres.

Le type BarCodeRegionParameters expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| quadrangle | Obtient la région de code-barres délimitée par [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| angle | Obtient l'angle du code-barres (0‑360). |
| points | Obtient le tableau de [Point](/barcode/python-net/aspose.drawing/point/) délimitant la région du code-barres |
| rectangle | Obtient la région du code-barres délimitée |
