## ProcessorSettings class

ProcessorSettings permet de reconnaître les codes-barres avec une augmentation des performances grâce au multithreading

Le type ProcessorSettings expose les membres suivants:
## Properties
| Name | Description |
| :- | :- |
| use_all_cores | Est nécessaire pour utiliser tous les cœurs. |
| use_only_this_cores_count | Spécifiez le nombre de cœurs à utiliser. <br/>            Vous devez changer la propriété "UseAllCores" en "false". |
| max_additional_allowed_threads | Spécifiez le nombre maximal de threads supplémentaires pour exécuter le code en parallèle |
