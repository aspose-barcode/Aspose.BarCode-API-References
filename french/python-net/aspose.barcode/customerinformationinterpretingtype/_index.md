## CustomerInformationInterpretingType enumeration

Définit le type d'interprétation (CTable, NTable ou Other) des informations client pour le code-barres AustralianPost.

## Members
| Nom du membre | Description |
| :- | :- |
| C_TABLE | Utilisez CTable pour interpréter les informations client. Autorise A..Z, a..z, 1..9, l'espace et le caractère #. |
| N_TABLE | Utilisez NTable pour interpréter les informations client. Autorise les chiffres. |
| OTHER | N'interprétez pas les informations client. Autorise uniquement le symbole 0, 1, 2 ou 3. |
