Spécifie le mode de compaction QR pour le codetext ajouté par QrExtCodetextBuilder.
## Champs

| Champ | Description |
| --- | --- |
| [ALPHA_NUMERIC](#ALPHA-NUMERIC) | Encode le codetext en mode alphanumérique QR. |
| [AUTO](#AUTO) | L’encodeur sélectionne automatiquement le mode de compaction QR le plus efficace. |
| [BYTES](#BYTES) | Encode le codetext en mode octet QR. |
| [KANJI](#KANJI) | Encode le codetext en mode Kanji QR. |
| [NUMERIC](#NUMERIC) | Encode le codetext en mode numérique QR. |
