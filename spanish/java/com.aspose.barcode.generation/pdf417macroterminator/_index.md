Se usa para indicar al codificador si debe agregar el Terminador Macro PDF417 (código de palabra 922) al segmento. Aplicado solo para Macro PDF417.
## Campos

| Campo | Descripción |
| --- | --- |
| [AUTO](#AUTO) | El terminador se agregará automáticamente si se proporciona el número de segmentos y el segmento actual es el último. |
| [NONE](#NONE) | El terminador no se agregará. |
| [SET](#SET) | El terminador se agregará. |
