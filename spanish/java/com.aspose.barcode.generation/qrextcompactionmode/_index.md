Especifica el modo de compactación QR para el texto de código añadido por QrExtCodetextBuilder.
## Campos

| Campo | Descripción |
| --- | --- |
| [ALPHA_NUMERIC](#ALPHA-NUMERIC) | Codifica codetext en modo alfanumérico QR. |
| [AUTO](#AUTO) | El codificador selecciona automáticamente el modo de compactación QR más eficiente. |
| [BYTES](#BYTES) | Codifica codetext en modo byte QR. |
| [KANJI](#KANJI) | Codifica codetext en modo Kanji QR. |
| [NUMERIC](#NUMERIC) | Codifica codetext en modo numérico QR. |
