## DataBarParameters class

Parámetros de Databar.

El tipo DataBarParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_2d_composite_component | Habilita la bandera del componente compuesto 2D con el código de barras DataBar |
| allow_only_gs1_encoding | Si esta bandera está activada, permite solo el estándar de codificación GS1 para los tipos de código de barras Databar |
| columnas | Recuento de columnas. |
| filas | Recuento de filas. |
| aspect_ratio | Relación altura/ancho del módulo de código de barras 2D.<br/>            Usado para DataBar apilado. |
