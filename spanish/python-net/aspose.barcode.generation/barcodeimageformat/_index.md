## BarCodeImageFormat enumeration

Especifica el formato de archivo de la imagen.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| BMP | Especifica el formato de imagen bitmap (BMP). |
| GIF | Especifica el formato de imagen Graphics Interchange Format (GIF). |
| JPEG | Especifica el formato de imagen Joint Photographic Experts Group (JPEG). |
| PNG | Especifica el formato de imagen W3C Portable Network Graphics (PNG). |
| TIFF | Especifica el formato de imagen Tagged Image File Format (TIFF). |
| TIFF_IN_CMYK | Especifica el formato de imagen Tagged Image File Format (TIFF) en modelo de color CMYK. <br/>            (Solo compatible en la plataforma Windows, en plataformas *nix se guarda como Tiff) |
| EMF | Especifica el formato de imagen Enhanced Metafile (EMF).<br/>            (Solo compatible en la plataforma Windows, en plataformas *nix se guarda como PNG) |
| SVG | Especifica el formato de imagen Scalable Vector Graphics (SVG). |
| PDF | Especifica el formato de imagen Portable Document Format (PDF). |
