## Pdf417MacroTerminator enumeration

Se usa para indicar al codificador si debe agregar el Terminador Macro PDF417 (código de palabra 922) al segmento. <br/>            Aplicado solo para Macro PDF417.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| AUTO | El terminador se añadirá automáticamente si se proporciona el número de segmentos <br/>            y el segmento actual es el último. En otros casos, el terminador no se añadirá. |
| NONE | El terminador no se añadirá. |
| SET | El terminador se añadirá. |
