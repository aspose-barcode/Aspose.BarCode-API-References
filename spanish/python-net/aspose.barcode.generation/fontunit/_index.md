## FontUnit class

Define un formato particular para el texto, incluyendo la fuente, el tamaño y los atributos de estilo<br/>            donde el tamaño está en la propiedad Unit value.

El tipo FontUnit expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| family_name | Obtiene o establece el nombre de la fuente de este Font. |
| style | Obtiene o establece la información de estilo para este FontUnit. |
| size | Obtiene o establece el tamaño de este FontUnit en unidades. |
