## QrExtCompactionMode enumeration

Especifica el modo de compactación QR para el texto de código añadido por QrExtCodetextBuilder.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| AUTO | El codificador selecciona automáticamente el modo de compactación QR más eficiente. |
| NUMERIC | Codifica el texto del código en modo QR Numérico. Solo se permiten dígitos 0-9. |
| ALPHA_NUMERIC | Codifica el texto del código en modo QR Alfanumérico. |
| BYTES | Codifica el texto del código en modo QR de bytes. |
| KANJI | Codifica el texto del código en modo QR Kanji. |
