## Code16KParameters class

Parámetros de Code16K.

El tipo Code16KParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| aspect_ratio | Relación altura/ancho del módulo de código de barras 2D. |
| quiet_zone_left_coef | Tamaño de la zona silenciosa izquierda en xDimension.<br/>            Valor predeterminado: 10, lo que significa que si xDimension = 2px, la zona silenciosa izquierda será de 20px. |
| quiet_zone_right_coef | Tamaño de la zona silenciosa derecha en xDimension.<br/>            Valor predeterminado: 1, lo que significa que si xDimension = 2px, la zona silenciosa derecha será de 2px. |
