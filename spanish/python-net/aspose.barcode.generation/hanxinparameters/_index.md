## HanXinParameters class

Parámetros de Han Xin.

El tipo HanXinParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| version | Versión del código HanXin.<br/>            De Version01 a Version84 para el código Han Xin.<br/>            El valor predeterminado es Version.Auto. |
| error_level | Nivel de corrección de errores Reed-Solomon para el código de barras Han Xin.<br/>             De bajo a alto: L1, L2, L3, L4. ver ErrorLevel. |
| encode_mode | Modo de codificación HanXin.<br/>            Valor predeterminado: EncodeMode.Mixed. |
| eci_encoding | Identificadores de Interpretación de Canal Extendido. Se utiliza para indicar al lector de códigos de barras detalles<br/>            sobre las referencias usadas para codificar los datos en el símbolo.<br/>            La implementación actual contiene todas las codificaciones de conjuntos de caracteres conocidas. |
