## Code128EncodeMode enumeration

Modo de codificación para códigos de barras Code128.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| AUTO | Codifique el texto del código en modo clásico ISO 15417. El modo debe usarse en todos los casos ordinarios. |
| CODE_A | Codifique el texto del código solo en el conjunto de códigos 128A. |
| CODE_B | Codifique el texto del código solo en el conjunto de códigos 128B. |
| CODE_C | Codifique el texto del código solo en el conjunto de códigos 128C. |
| CODE_AB | Codifique el texto del código solo en los conjuntos de códigos 128A y 128B. |
| CODE_AC | Codifique el texto del código solo en los conjuntos de códigos 128A y 128C. |
| CODE_BC | Codifique el texto del código solo en los conjuntos de códigos 128B y 128C. |
