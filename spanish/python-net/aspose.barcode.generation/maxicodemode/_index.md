## MaxiCodeMode enumeration

Modo de codificación para códigos de barras MaxiCode.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| MODE2 | Mode 2 codifica información postal en el primer mensaje y datos en el segundo mensaje. <br/>            Tiene un código postal de 9 dígitos (utilizado solo en EE. UU.). |
| MODE3 | El modo 3 codifica información postal en el primer mensaje y datos en el segundo mensaje. <br/>            Tiene un código postal alfanumérico de 6 caracteres, usado en el mundo. |
| MODE4 | El modo 4 codifica datos en el primer y segundo mensaje, con corrección ECC corta. |
| MODE5 | El modo 5 codifica datos en el primer y segundo mensaje, con corrección ECC larga. |
| MODE6 | El modo 6 codifica datos en el primer y segundo mensaje, con corrección ECC corta.<br/>            Usado para codificar dispositivos. |
