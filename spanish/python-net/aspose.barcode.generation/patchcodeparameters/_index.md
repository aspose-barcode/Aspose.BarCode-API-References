## PatchCodeParameters class

Parámetros de PatchCode.

El tipo PatchCodeParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| extra_barcode_text | Especifica el texto de código para un código QR adicional, cuando se genera PatchCode en modo página. |
| format | Formato PatchCode. Elija PatchOnly para generar un solo PatchCode. Use el formato de página para generar una página Patch con PatchCodes como bordes.<br/>            Valor predeterminado: PatchFormat.PatchOnly |
| patch_format | Formato PatchCode. Elija PatchOnly para generar un solo PatchCode. Use el formato de página para generar una página Patch con PatchCodes como bordes.<br/>            Valor predeterminado: PatchFormat.PatchOnly |
