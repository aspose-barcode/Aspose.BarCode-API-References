## AztecSymbolMode enumeration

Especifica el modo de símbolo Aztec.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| AUTO | Especifica que se seleccione automáticamente el mejor símbolo (Compact o Full-range) para Aztec.<br/>            Este es el valor predeterminado. |
| COMPACT | Especifica el símbolo Compact para Aztec.<br/>            El símbolo Compact de Aztec permite solo 1, 2, 3 o 4 capas. |
| FULL_RANGE | Especifica el símbolo Full-range para Aztec.<br/>            El símbolo Full-range de Aztec permite de 1 a 32 capas. |
| RUNE | Especifica el símbolo Rune para Aztec.<br/>            Los Runes de Aztec son una serie de marcas pequeñas pero distintas legibles por máquina. Permite solo valores numéricos de 0 a 255. |
