## SupplementParameters class

Parámetros suplementarios. Usado para Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

El tipo SupplementParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| supplement_data | Datos suplementarios después del BarCode. |
| supplement_space | Espacio entre el BarCode principal y el BarCode suplementario en valor [Unit](/barcode/python-net/aspose.barcode.generation/unit/). |
