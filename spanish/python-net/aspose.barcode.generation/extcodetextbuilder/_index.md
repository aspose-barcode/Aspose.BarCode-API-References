## ExtCodetextBuilder class

Clase auxiliar para la generación automática de codetext del Extended Codetext Mode

El tipo ExtCodetextBuilder expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| clear() | Borra los elementos de codetext extendido |
| add_plain_codetext(codetext) | Agrega codetext plano a los elementos de codetext extendido |
| add_eci_codetext(eci_encoding, codetext) | Agrega codetext con Identificador de Canal Extendido |
| get_extended_codetext() | Generar texto de código extendido a partir de la lista de elementos de generación |
