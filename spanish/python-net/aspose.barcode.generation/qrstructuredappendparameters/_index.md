## QrStructuredAppendParameters class

Parámetros de anexado estructurado QR.

El tipo QrStructuredAppendParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| parity_byte | Obtiene o establece los datos de paridad del modo de anexado estructurado QR. |
| sequence_indicator | Obtiene o establece el índice del código de barras del modo de anexado estructurado QR. El índice comienza en 0. |
| total_count | Obtiene o establece la cantidad de códigos de barras del modo de anexado estructurado QR. El valor máximo es 16. |
