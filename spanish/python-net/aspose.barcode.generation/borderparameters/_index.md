## BorderParameters class

Parámetros del borde de la imagen del código de barras

El tipo BorderParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| visible | Visibilidad del borde. Si es false, el parámetro Width siempre se ignora (0).<br/>            Valor predeterminado: false. |
| width | Ancho del borde.<br/>            Valor predeterminado: 0.<br/>            Ignorado si Visible está configurado a false. |
| dash_style | Estilo de guión del borde.<br/>            Valor predeterminado: BorderDashStyle.Solid. |
| color | Color del borde.<br/>            Valor predeterminado: Color.Black. |
