## EncodeTypes class

Especifica el tipo de código de barras a codificar.

El tipo EncodeTypes expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| all_encode_types | Especifica que los datos se verificarán con todas las simbologías disponibles. |
| NONE | Tipo de codificación no especificado. |
| CODABAR | Especifica que los datos deben codificarse con la especificación de código de barras CODABAR |
| CODE11 | Especifica que los datos deben codificarse con la especificación de código de barras CODE 11 |
| CODE39 | Especifica que los datos deben codificarse con la especificación de código de barras Code 39 conjunto básico de caracteres: ISO/IEC 16388 |
| CODE_39_FULL_ASCII | Especifica que los datos deben codificarse con la especificación de código de barras Code 39 conjunto completo de caracteres ASCII: ISO/IEC 16388 |
| CODE93 | Especifica que los datos deben codificarse con la especificación de código de barras CODE 93 |
| CODE128 | Especifica que los datos deben codificarse con la especificación de código de barras CODE 128 |
| GS1_CODE_128 | Especifica que los datos deben codificarse con la especificación de código de barras GS1 Code 128. El texto del código debe contener paréntesis para el AI. |
| EAN8 | Especifica que los datos deben codificarse con la especificación de código de barras EAN-8 |
| EAN13 | Especifica que los datos deben codificarse con la especificación de código de barras EAN-13 |
| EAN14 | Especifica que los datos deben codificarse con la especificación de código de barras EAN14 |
| SCC14 | Especifica que los datos deben codificarse con la especificación de código de barras SCC14 |
| SSCC18 | Especifica que los datos deben codificarse con la especificación de código de barras SSCC18 |
| UPCA | Especifica que los datos deben codificarse con la especificación de código de barras UPC-A |
| UPCE | Especifica que los datos deben codificarse con la especificación de código de barras UPC-E |
| ISBN | Especifica que los datos deben codificarse con la especificación de código de barras ISBN |
| ISSN | Especifica que los datos deben codificarse con la especificación de código de barras ISSN |
| ISMN | Especifica que los datos deben codificarse con la especificación de código de barras ISMN |
| STANDARD_2OF_5 | Especifica que los datos deben codificarse con la especificación de código de barras Standard 2 of 5 |
| INTERLEAVED_2OF_5 | Especifica que los datos deben codificarse con la especificación de código de barras INTERLEAVED 2 of 5 |
| MATRIX_2OF_5 | Representa el código de barras Matrix 2 of 5 |
| ITALIAN_POST25 | Representa el código de barras Italian Post 25. |
| IATA2OF_5 | Representa el código de barras IATA 2 of 5. IATA (International Air Transport Association) utiliza este código de barras para la gestión de carga aérea. |
| ITF14 | Especifica que los datos deben codificarse con la especificación de código de barras ITF14 |
| ITF6 | Representa el código de barras ITF-6. |
| MSI | Especifica que los datos deben codificarse con la especificación de código de barras MSI Plessey |
| VIN | Representa el código de barras VIN (Número de Identificación del Vehículo). |
| DEUTSCHE_POST_IDENTCODE | Representa el código de barras Deutsch Post, esta simbología también se conoce como Identcode,CodeIdentcode,German Postal 2 of 5 Identcode, <br/>            Deutsch Post AG Identcode, Deutsch Frachtpost Identcode, Deutsch Post AG (DHL) |
| DEUTSCHE_POST_LEITCODE | Representa el código de barras Deutsch Post Leitcode, también conocido como German Postal 2 of 5 Leitcode, CodeLeitcode, Leitcode, Deutsch Post AG (DHL). |
| OPC | Representa el código de barras OPC (Código de Producto Óptico), también conocido como , VCA Barcode VCA OPC, Vision Council of America OPC Barcode. |
| PZN | Representa el código de barras PZN. Esta simbología también se conoce como Pharmacy central number, Pharmazentralnummer. Se admiten PZN7 y PZN8. <br/>            PZN7 se genera a partir de 6 o menos dígitos, como "123456". PZN8 se genera a partir de 7 o más dígitos, como "1234567". <br/>            El último dígito de verificación proporcionado se ignora y es generado por el motor de códigos de barras. |
| CODE_16K | Representa el código de barras Code 16K. |
| PHARMACODE | Representa el código de barras Pharmacode. |
| DATA_MATRIX | Simbología de código de barras 2D DataMatrix |
| QR | Especifica que los datos deben codificarse con la especificación de código de barras QR Code |
| AZTEC | Especifica que los datos deben codificarse con la especificación de código de barras Aztec |
| GS1_AZTEC | Especifica que los datos deben codificarse con la especificación de código de barras GS1 Aztec. El texto del código debe contener paréntesis para AI. |
| PDF417 | Especifica que los datos deben codificarse con la especificación de código de barras Pdf417 |
| MACRO_PDF417 | Especifica que los datos deben codificarse con la especificación de código de barras MacroPdf417 |
| GS1_DATA_MATRIX | Simbología de código de barras 2D DataMatrix con formato de cadena GS1 |
| MICRO_PDF417 | Especifica que los datos deben codificarse con la especificación de código de barras MicroPdf417 |
| GS1_MICRO_PDF_417 | Especifica que los datos deben codificarse con la especificación de código de barras GS1MicroPdf417 |
| GS1QR | Simbología de código de barras 2D QR con formato de cadena GS1 |
| MAXI_CODE | Especifica que los datos deben codificarse con la especificación de código de barras MaxiCode |
| DOT_CODE | Especifica que los datos deben codificarse con la especificación de código de barras DotCode |
| HAN_XIN | Especifica que los datos deben codificarse con la especificación de código de barras Han Xin |
| GS1_HAN_XIN | Simbología de código de barras 2D HanXin con formato de cadena GS1 |
| MICRO_QR | Especifica que los datos deben codificarse con la especificación de código de barras MicroQR Code |
| RECT_MICRO_QR | Especifica que los datos deben codificarse con la especificación de código de barras RectMicroQR (rMQR). |
| AUSTRALIA_POST | Representa el código de barras de cliente de Australia Post. |
| JAPAN_POST | Representa el código de barras de Japan Post. |
| POSTNET | Especifica que los datos deben codificarse con la especificación de código de barras Postnet. |
| PLANET | Especifica que los datos deben codificarse con la especificación de código de barras Planet. |
| ONE_CODE | Especifica que los datos deben codificarse con la especificación de código de barras USPS OneCode. |
| RM4SCC | Representa el código de barras RM4SCC. RM4SCC (Royal Mail 4-state Customer Code) se utiliza para el proceso automatizado de clasificación de correo en el Reino Unido. |
| MAILMARK | Representa el código de barras Royal Mail Mailmark. |
| DATABAR_OMNI_DIRECTIONAL | Especifica que los datos deben codificarse con la especificación de código de barras GS1 Databar omnidireccional. |
| DATABAR_TRUNCATED | Especifica que los datos deben codificarse con la especificación de código de barras GS1 Databar truncado. |
| DATABAR_LIMITED | Representa el código de barras GS1 Databar limitado. |
| DATABAR_EXPANDED | Representa el código de barras GS1 Databar expandido. |
| DATABAR_EXPANDED_STACKED | Representa el código de barras GS1 Databar expandido apilado. |
| DATABAR_STACKED | Representa el código de barras GS1 Databar apilado. |
| DATABAR_STACKED_OMNI_DIRECTIONAL | Representa el código de barras GS1 Databar apilado omnidireccional. |
| SINGAPORE_POST | Especifica que los datos deben codificarse con la especificación de código de barras Singapore Post Barcode. |
| AUSTRALIAN_POSTE_PARCEL | Especifica que los datos deben codificarse con la especificación de código de barras Australian Post Domestic eParcel Barcode. |
| SWISS_POST_PARCEL | Especifica que los datos deben codificarse con la especificación de código de barras Swiss Post Parcel Barcode. Tipos compatibles: Domestic Mail, International Mail, Additional Services (new) |
| PATCH_CODE | Representa el código de barras Patch code. |
| CODE32 | Especifica que los datos deben codificarse con la especificación de código de barras Code32. |
| DATA_LOGIC_2OF_5 | Especifica que los datos deben codificarse con la especificación de código de barras DataLogic 2 of 5. |
| DUTCH_KIX | Especifica que los datos deben codificarse con la especificación de código de barras Dutch KIX. |
| UPCA_GS_1_CODE_128_COUPON | Especifica que los datos deben codificarse con un cupón UPC con la especificación de código de barras GS1-128 Extended Code.<br/>            Un ejemplo de la cadena de entrada:<br/>            BarcodeGenerator.Codetext = "514141100906(8102)03",<br/>            donde la parte UPCA es "514141100906", la parte GS1Code128 es (8102)03. |
| UPCA_GS_1_DATABAR_COUPON | Especifica que los datos deben codificarse con un cupón UPC con la especificación de código de barras GS1 DataBar addition.<br/>            Un ejemplo de la cadena de entrada:<br/>            BarcodeGenerator.Codetext = "514141100906(8110)106141416543213500110000310123196000",<br/>            donde la parte UPCA es "514141100906", la parte Databar es "(8110)106141416543213500110000310123196000".<br/>            Para cambiar el título, use Parameters.CaptionAbove.Text = "company prefix + offer code"; |
| CODABLOCK_F | Especifica que los datos deben codificarse con la especificación de código de barras Codablock-F. |
| GS1_CODABLOCK_F | Especifica que los datos deben codificarse con la especificación de código de barras GS1 Codablock-F. El texto del código debe contener paréntesis para AI. |
| GS1_COMPOSITE_BAR | Especifica que los datos deben codificarse con la especificación de código de barras GS1 Composite Bar. El texto del código debe contener paréntesis para AI. El texto de código 1D y el texto de código 2D deben separarse con el símbolo '/' |
| HIBC_CODE_39LIC | Especifica que los datos deben codificarse con la especificación de código de barras HIBC LIC Code39. |
| HIBC_CODE_128LIC | Especifica que los datos deben codificarse con la especificación de código de barras HIBC LIC Code128. |
| HIBC_AZTEC_LIC | Especifica que los datos deben codificarse con la especificación de código de barras HIBC LIC Aztec. |
| HIBC_DATA_MATRIX_LIC | Especifica que los datos deben codificarse con la especificación de código de barras HIBC LIC DataMatrix. |
| HIBCQRLIC | Especifica que los datos deben codificarse con la especificación de código de barras HIBC LIC QR. |
| HIBC_CODE_39PAS | Especifica que los datos deben codificarse con la especificación de código de barras HIBC PAS Code39. |
| HIBC_CODE_128PAS | Especifica que los datos deben codificarse con la especificación de código de barras HIBC PAS Code128. |
| HIBC_AZTEC_PAS | Especifica que los datos deben codificarse con la especificación de código de barras HIBC PAS Aztec. |
| HIBC_DATA_MATRIX_PAS | Especifica que los datos deben codificarse con la especificación de código de barras HIBC PAS DataMatrix. |

## Métodos
| Nombre | Descripción |
| :- | :- |
| get_names() | Recupera una matriz con los nombres de los tipos de codificación. |
| parse(parsing_type, result) | Convierte la representación en cadena de un BaseEncodeType a su instancia.<br/>            Un valor de retorno indica si la conversión tuvo éxito o falló. |
| try_parse(parsing_type, result) | Convierte la representación en cadena de un BaseEncodeType a su instancia.<br/>            Un valor de retorno indica si la conversión tuvo éxito o falló. |
