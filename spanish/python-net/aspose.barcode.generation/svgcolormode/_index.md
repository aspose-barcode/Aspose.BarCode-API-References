## SvgColorMode enumeration

Modos posibles para el color de relleno en un archivo svg, RGB es el predeterminado y es compatible con SVG 1.1.<br/>            RGBA, HSL, HSLA están permitidos en el estándar SVG 2.0.<br/>            Incluso en RGB la opacidad se establecerá mediante el parámetro "fill-opacity".

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| RGB | Modo RGB, ejemplo: fill=\"#ff5511\" fill-opacity=\"0.73\". Modo predeterminado. |
| RGBA | Modo RGBA, ejemplo: fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | Modo HSL, ejemplo: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | Modo HSLA, ejemplo: fill=\"hsla(30, 50%, 70%, 0.8)\" |
