## AutoSizeMode enumeration

Especifica los diferentes tipos de modos de dimensionado automático.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | El redimensionamiento automático está deshabilitado. |
| NEAREST | Redimensiona el código de barras al tamaño más bajo posible más cercano especificado por las propiedades ImageWidth e ImageHeight.<br/>            Conserva la relación de aspecto predeterminada. |
| INTERPOLATION | Redimensiona el código de barras al tamaño especificado.<br/>            El tamaño puede especificarse mediante las propiedades ImageWidth e ImageHeight.<br/>            El código de barras generado puede ser inválido (ilegible) después del escalado). |
