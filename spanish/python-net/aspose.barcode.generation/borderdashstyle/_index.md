## BorderDashStyle enumeration

Especifica el estilo de líneas de borde punteadas.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| SOLID | Especifica una línea sólida. |
| DASH | Especifica una línea compuesta de guiones. |
| DOT | Especifica una línea compuesta de puntos. |
| DASH_DOT | Especifica una línea con un patrón repetido de guión-punto. |
| DASH_DOT_DOT | Especifica una línea con un patrón repetido de guión-punto-punto. |
