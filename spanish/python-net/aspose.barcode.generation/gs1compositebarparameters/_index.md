## GS1CompositeBarParameters class

Parámetros de barra compuesta GS1.

El tipo GS1CompositeBarParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| linear_component_type | Tipo de componente lineal: GS1Code128, UPCE, EAN8, UPCA, EAN13, DatabarStacked, DatabarStackedOmniDirectional, DatabarLimited, DatabarOmniDirectional, DatabarExpanded, DatabarExpandedStacked |
| two_d_component_type | Tipo de componente 2D |
| allow_only_gs1_encoding | Si este indicador está activado, permite solo el estándar de codificación GS1 para el componente 2D GS1CompositeBar |
