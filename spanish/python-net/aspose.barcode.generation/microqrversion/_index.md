## MicroQRVersion enumeration

Versión de MicroQR Code.<br/>            De M1 a M4.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| AUTO | Especifica seleccionar automáticamente la mejor versión para MicroQR.<br/>            Este es el valor predeterminado. |
| M1 | Especifica la versión M1 para Micro QR con módulos de 11 x 11. |
| M2 | Especifica la versión M2 para Micro QR con módulos de 13 x 13. |
| M3 | Especifica la versión M3 para Micro QR con módulos de 15 x 15. |
| M4 | Especifica la versión M4 para Micro QR con módulos de 17 x 17. |
