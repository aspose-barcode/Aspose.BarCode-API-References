## SvgParameters class

Parámetros de SVG.

El tipo SvgParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_explicit_size_in_pixels | ¿La imagen SVG contiene un tamaño explícito en píxeles (recomendado)<br/>            Valor predeterminado: true. |
| is_text_drawn_in_text_element | ¿La imagen SVG contiene texto como elemento de texto en lugar de rutas (recomendado)<br/>            Valor predeterminado: true. |
| svg_color_mode | Modos posibles para el color de relleno en un archivo svg, RGB es el predeterminado y es compatible con SVG 1.1.<br/>            RGBA, HSL, HSLA están permitidos en el estándar SVG 2.0.<br/>            Incluso en RGB la opacidad se establecerá mediante el parámetro "fill-opacity". |
