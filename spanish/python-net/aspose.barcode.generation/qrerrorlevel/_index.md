## QRErrorLevel enumeration

Nivel de corrección de errores Reed-Solomon. De bajo a alto: LevelL, LevelM, LevelQ, LevelH.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| LEVEL_L | La corrección de errores Nivel L puede aplicarse a códigos de barras QR y MicroQR.<br/>            Permite recuperar el 7% del texto del código. |
| LEVEL_M | La corrección de errores Nivel M puede aplicarse a códigos de barras QR, códigos RectMicroQR y códigos MicroQR con versiones de M2 a M4.<br/>            Permite recuperar el 15% del texto del código. |
| LEVEL_Q | La corrección de errores Nivel Q puede aplicarse a códigos de barras QR y MicroQR con la versión M4.<br/>            Permite recuperar el 25% del texto del código. |
| LEVEL_H | La corrección de errores Nivel H puede aplicarse a códigos de barras QR y RectMicroQR.<br/>            Permite recuperar el 30% del texto del código. |
