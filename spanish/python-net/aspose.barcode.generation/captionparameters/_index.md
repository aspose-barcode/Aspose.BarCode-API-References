## CaptionParameters class

Parámetros de leyenda.

El tipo CaptionParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| text | Texto del subtítulo.<br/>            Valor predeterminado: cadena vacía. |
| font | Fuente del subtítulo.<br/>            Valor predeterminado: Arial 8pt regular. |
| visible | Visibilidad del texto del subtítulo.<br/>            Valor predeterminado: false. |
| text_color | Color del texto del subtítulo.<br/>            Valor predeterminado: Color.Black. |
| padding | Rellenos de subtítulos.<br/>            Valor predeterminado para CaptionAbove: 5pt 5pt 0 5pt.<br/>            Valor predeterminado para CaptionBelow: 0 5pt 5pt 5pt. |
| alineación | Alineación horizontal de la prueba de subtítulo.<br/>            Valor predeterminado: StringAlignment.Center. |
| no_wrap | Especifique los ajustes de línea (saltos de línea) dentro del texto.<br/>            Valor predeterminado: false. |
