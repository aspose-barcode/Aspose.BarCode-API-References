## ITFParameters class

Parámetros de ITF.

El tipo ITFParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| border_thickness | Obtiene o establece el grosor de un borde ITF (barra portadora) en unidades.<br/>            Valor predeterminado: 12pt. |
| border_type | Tipo de borde del código de barras ITF.<br/>            Valor predeterminado: ITF14BorderType.Bar. |
| quiet_zone_coef | Tamaño de las zonas silenciosas en xDimension.<br/>            Valor predeterminado: 10, lo que significa que si xDimension = 2px, las zonas silenciosas serán de 20px. |
