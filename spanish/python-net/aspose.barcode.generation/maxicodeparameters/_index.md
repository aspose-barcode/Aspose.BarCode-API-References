## MaxiCodeParameters class

Parámetros de MaxiCode.

El tipo MaxiCodeParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| modo | Obtiene o establece un modo de codificación MaxiCode. |
| encode_mode | Obtiene o establece un modo de codificación MaxiCode. <br/>            Valor predeterminado: Auto. |
| eci_encoding | Obtiene o establece la codificación ECI. Se usa cuando MaxiCodeEncodeMode es Auto.<br/>            Valor predeterminado: ISO-8859-1 |
| structured_append_mode_barcode_id | Obtiene o establece un id de código de barras MaxiCode en modo de adición estructurada. <br/>            ID debe ser un valor entre 1 y 8. <br/>            Valor predeterminado: 0 |
| structured_append_mode_barcodes_count | Obtiene o establece el recuento de códigos de barras MaxiCode en modo de adición estructurada. <br/>            El número de recuento debe ser un valor entre 2 y 8 (recuento máximo de códigos de barras).<br/>            Valor predeterminado: -1 |
| aspect_ratio | Relación altura/ancho del módulo de código de barras 2D. |
