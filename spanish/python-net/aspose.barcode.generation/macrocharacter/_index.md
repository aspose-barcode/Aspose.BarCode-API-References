## MacroCharacter enumeration

Los valores de los caracteres macro 05 y 06 se utilizan para obtener una codificación más compacta en modos especiales.<br/>            El carácter macro 05 se traduce a "[)>\u001E05\u001D" como encabezado de datos decodificados y "\u001E\u0004" como pie de datos decodificados.<br/>            El carácter macro 06 se traduce a "[)>\u001E06\u001D" como encabezado de datos decodificados y "\u001E\u0004" como pie de datos decodificados.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | No se añaden caracteres macro a los datos del código de barras |
| MACRO05 | Se añade el carácter macro 05 a los datos del código de barras en la primera posición.<br/>            Identificador de datos GS1 ISO 15434<br/>            El carácter se traduce a "[)>\u001E05\u001D" como encabezado de datos decodificado y "\u001E\u0004" como tráiler de datos decodificado. |
| MACRO06 | Se añade el carácter macro 06 a los datos del código de barras en la primera posición.<br/>            Identificador de datos ASC MH10 ISO 15434<br/>            El carácter se traduce a "[)>\u001E06\u001D" como encabezado de datos decodificado y "\u001E\u0004" como tráiler de datos decodificado. |
