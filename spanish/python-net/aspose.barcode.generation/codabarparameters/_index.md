## CodabarParameters class

Parámetros de Codabar.

El tipo CodabarParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| checksum_mode | Obtener o establecer el algoritmo de suma de verificación para códigos de barras Codabar.<br/>            Valor predeterminado: CodabarChecksumMode.Mod16.<br/>            Para habilitar el cálculo de la suma de verificación, establezca el valor EnableChecksum.Yes en la propiedad EnableChecksum.<br/>            Ver [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Símbolo de inicio (carácter) de la simbología Codabar.<br/>            Valor predeterminado: CodabarSymbol.A |
| stop_symbol | Símbolo de parada (carácter) de la simbología Codabar.<br/>            Valor predeterminado: CodabarSymbol.A |
