## PdfParameters class

Parámetros de PDF.

El tipo PdfParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| cmyk_bar_color | Nullable. Valor de color CMYK del código de barras. Null significa que no se usa color CMYK, en su lugar se usa el color RGB normal. |
| cmyk_back_color | Nullable. Valor de color de fondo CMYK. Null significa que no se usa color CMYK, en su lugar se usa el color RGB normal. |
| cmyk_codetext_color | Nullable. Valor de color CMYK del Codetexto. Null significa que no se usa color CMYK, en su lugar se usa el color RGB normal. |
| cmyk_caption_above_color | Nullable. Valor de color CMYK del título superior. Null significa que no se usa color CMYK, en su lugar se usa el color RGB normal. |
| cmyk_caption_below_color | Nullable. Valor de color CMYK del título inferior. Null significa que no se usa color CMYK, en su lugar se usa el color RGB normal. |
| is_text_as_path | ¿Se utilizan rutas en lugar de texto (use si los caracteres Unicode no se muestran)<br/>            Valor predeterminado: false. |
