## DataMatrixEccType enumeration

Especifique el tipo de ECC a codificar.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| ECC_AUTO | Especifica que el tipo de ECC codificado se define por la corrección de errores Reed-Solomon predeterminada o ECC 200. |
| ECC000 | Especifica que el tipo de ECC codificado se define como ECC 000. |
| ECC050 | Especifica que el tipo de ECC codificado se define como ECC 050. |
| ECC080 | Especifica que el tipo de ECC codificado se define como ECC 080. |
| ECC100 | Especifica que el tipo de ECC codificado se define como ECC 100. |
| ECC140 | Especifica que el tipo de ECC codificado se define como ECC 140. |
| ECC200 | Especifica que el tipo Ecc codificado está definido como ECC 200. Se recomienda usarlo. |
