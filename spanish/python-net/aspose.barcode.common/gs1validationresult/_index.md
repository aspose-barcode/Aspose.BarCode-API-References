## GS1ValidationResult class

Contiene todos los errores detectables de forma independiente para una cadena de elemento GS1, URI Digital Link o un valor AI.

El tipo GS1ValidationResult expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_valid | Obtiene un valor que indica si la validación se completó sin errores. |
| incidencias | Obtiene los errores de validación en orden determinista. |
