## ProcessorSettings class

ProcessorSettings permite reconocer códigos de barras con aumento de rendimiento mediante multihilos.

El tipo ProcessorSettings expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| use_all_cores | Es necesario para usar todos los núcleos. |
| use_only_this_cores_count | Especifique el número de núcleos a usar. <br/>            Necesita cambiar la propiedad "UseAllCores" a "false". |
| max_additional_allowed_threads | Especifique el número máximo de hilos adicionales para ejecutar el código en paralelo |
