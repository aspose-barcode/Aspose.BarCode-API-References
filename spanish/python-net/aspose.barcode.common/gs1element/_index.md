## GS1Element class

Representa un par inmutable de Identificador de Aplicación GS1 y valor.

El tipo GS1Element expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| application_identifier | Obtiene el Identificador de Aplicación GS1 exacto. |
| value | Obtiene el valor validado asociado al Identificador de Aplicación. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| validate(application_identifier, value) | Valida un valor para un Identificador de Aplicación GS1 exacto. |
