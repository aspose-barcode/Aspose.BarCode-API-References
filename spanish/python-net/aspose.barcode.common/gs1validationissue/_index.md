## GS1ValidationIssue class

Describe un error de validación GS1.

El tipo GS1ValidationIssue expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| code | Obtiene un código de error legible por máquina y estable. |
| application_identifier | Obtiene el Identificador de Aplicación relacionado con el error, o null cuando el Identificador de Aplicación<br/>            no pudo determinarse a partir de la entrada. |
| message | Obtiene el mensaje de error legible por humanos. |
