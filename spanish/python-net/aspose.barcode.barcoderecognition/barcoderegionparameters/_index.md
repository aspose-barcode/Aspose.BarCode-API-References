## BarCodeRegionParameters class

Representa la región del código de barras reconocido y el ángulo del código de barras

El tipo BarCodeRegionParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| quadrangle | Obtiene [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) que delimita la región del código de barras |
| angle | Obtiene el ángulo del código de barras (0-360). |
| points | Obtiene la matriz de [Point](/barcode/python-net/aspose.drawing/point/) que delimita la región del código de barras |
| rectangle | Obtiene la región delimitadora del código de barras |
