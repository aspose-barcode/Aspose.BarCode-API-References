## AustraliaPostCustomerInformationDecoder class

Interfaz pública para la decodificación del Campo de Información del Cliente que se utiliza en la simbología AustraliaPost. La implementación debe ser proporcionada por el usuario.

El tipo AustraliaPostCustomerInformationDecoder expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| decode(customer_information_field) | Decodifica el campo de información del cliente de la simbología AustraliaPost. <br/>            Puede usarse para diferentes interpretaciones de datos de la codificación NTable y CTable.<br/>            Los datos se proporcionan como una fila de valores de barra: 0, 1, 2 o 3. |
