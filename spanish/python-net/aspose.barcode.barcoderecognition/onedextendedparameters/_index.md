## OneDExtendedParameters class

Almacena datos especiales del código de barras 1D reconocido, como texto de código separado y suma de verificación

El tipo OneDExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| value | Obtiene el texto del código de los códigos de barras 1D sin suma de verificación. |
| check_sum | Obtiene la suma de verificación de los códigos de barras 1D. |
