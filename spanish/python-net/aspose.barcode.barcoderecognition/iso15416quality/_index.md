## Iso15416Quality class

Almacena las calificaciones de calidad del código de barras calculadas según la norma ISO/IEC 15416 para códigos de barras 1D.

El tipo Iso15416Quality expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| grade | Obtiene la calificación general de calidad del código de barras según ISO/IEC 15416. |
| decode | Obtiene la calificación de decodificación que indica si el código de barras puede ser decodificado usando el algoritmo de decodificación de referencia. |
| symbol_contrast | Obtiene la calificación de contraste del símbolo basada en la diferencia entre la reflectancia máxima y mínima. |
| minimum_reflectance | Obtiene la calificación de reflectancia mínima basada en la reflectancia de la barra más oscura. |
| minimum_edge_contrast | Obtiene la calificación de contraste de borde mínima basada en la menor diferencia de reflectancia entre barras y espacios adyacentes. |
| modulation | Obtiene la calificación de modulación basada en la uniformidad del contraste de borde a lo largo del código de barras. |
| defects | Obtiene la calificación de defectos basada en irregularidades de reflectancia dentro de las barras y los espacios. |
| decodability | Obtiene la calificación de decodificabilidad basada en la precisión del ancho de barras y espacios. |
