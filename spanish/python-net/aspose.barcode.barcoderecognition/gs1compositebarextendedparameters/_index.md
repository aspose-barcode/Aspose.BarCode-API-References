## GS1CompositeBarExtendedParameters class

Almacena datos especiales del código de barras GS1 Composite Bar reconocido

El tipo GS1CompositeBarExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| one_d_type | Obtiene el tipo de código de barras 1D (lineal) de GS1 Composite |
| one_d_code_text | Obtiene el valor del código de barras 1D (lineal) de GS1 Composite |
| two_d_type | Obtiene el tipo de código de barras 2D de GS1 Composite |
| two_d_code_text | Obtiene el valor del código de barras 2D de GS1 Composite |
