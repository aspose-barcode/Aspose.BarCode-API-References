## BarcodeSettings class

Los principales parámetros de decodificación de BarCode. Contiene parámetros que influyen en los datos reconocidos.

El tipo BarcodeSettings expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Eliminar los caracteres FNC1, FNC2, FNC3 del texto del código. El valor predeterminado es false. |
| only_requested_types | Devuelve solo los tipos de códigos de barras especificados explícitamente para el reconocimiento. <br/>            Cuando está habilitado, los códigos de barras reconocidos de otros tipos compatibles o equivalentes se filtran. <br/>            El valor predeterminado es false. |
| detect_encoding | El indicador que obliga al motor a detectar la codificación del texto del código para juegos de caracteres Unicode. El valor predeterminado es true. |
| australia_post | Obtiene los parámetros de decodificación de AustraliaPost |
| calculate_symbol_quality | Obtiene o establece un valor que indica si se debe calcular la calidad del símbolo del código de barras durante el reconocimiento. |
