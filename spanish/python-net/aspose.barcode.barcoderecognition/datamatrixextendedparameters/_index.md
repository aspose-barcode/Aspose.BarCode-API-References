## DataMatrixExtendedParameters class

Almacena datos especiales del código de barras DataMatrix reconocido

El tipo DataMatrixExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| structured_append_barcodes_count | Obtiene el recuento de códigos de barras en modo Structured Append de DataMatrix. El valor predeterminado es -1. El recuento debe ser un valor de 1 a 35. |
| structured_append_barcode_id | Obtiene el ID del código de barras en modo Structured Append de DataMatrix. El ID comienza en 1 y debe ser menor o igual al recuento de códigos de barras. El valor predeterminado es -1. |
| structured_append_file_id | Obtiene el ID del código de barras en modo Structured Append de DataMatrix. El ID comienza en 1 y debe ser menor o igual al recuento de códigos de barras. El valor predeterminado es -1. |
| is_reader_programming | Indica si el código se usa para instruir al lector a interpretar los datos siguientes como instrucciones para la inicialización o reprogramación del lector de códigos de barras.<br/>            El valor predeterminado es false. |
