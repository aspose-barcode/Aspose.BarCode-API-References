## AztecExtendedParameters class

Almacena datos especiales del código de barras Aztec reconocido

El tipo AztecExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| structured_append_barcodes_count | Obtiene el recuento de códigos de barras del modo de anexado estructurado Aztec. El valor predeterminado es 0. El recuento debe ser un valor entre 1 y 26. |
| structured_append_barcode_id | Obtiene el ID del código de barras del modo de anexado estructurado Aztec. El ID comienza en 1 y debe ser menor o igual al recuento de códigos de barras. El valor predeterminado es 0. |
| structured_append_file_id | Obtiene el ID de archivo del modo de anexado estructurado Aztec. El valor predeterminado es una cadena vacía. |
| is_reader_initialization | Indica si el código se usa para instruir al lector a interpretar los datos siguientes como instrucciones para la inicialización o reprogramación del lector de códigos de barras.<br/>            El valor predeterminado es false. |
