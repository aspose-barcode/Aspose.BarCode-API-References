## Pdf417ExtendedParameters class

Almacena información de metadatos MacroPdf417 del código de barras reconocido

El tipo Pdf417ExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| macro_pdf_417_file_id | Obtiene el ID del archivo del código de barras, solo disponible con MacroPdf417. |
| macro_pdf_417_segment_id | Obtiene el ID del segmento del código de barras, solo disponible con MacroPdf417. |
| macro_pdf_417_segments_count | Obtiene el recuento de segmentos del código de barras macro pdf417. El valor predeterminado es -1. |
| macro_pdf_417_file_name | Nombre de archivo Macro PDF417 (opcional). |
| macro_pdf_417_file_size | Tamaño de archivo Macro PDF417 (opcional). |
| macro_pdf_417_sender | Nombre del remitente Macro PDF417 (opcional). |
| macro_pdf_417_addressee | Nombre del destinatario Macro PDF417 (opcional). |
| macro_pdf_417_time_stamp | Marca de tiempo Macro PDF417 (opcional). |
| macro_pdf_417_checksum | Checksum Macro PDF417 (opcional). |
| macro_pdf_417_terminator | Indica si el segmento es el último segmento de un archivo Macro PDF417. |
| is_reader_initialization | Se utiliza para instruir al lector a interpretar los datos contenidos en el símbolo como programación para la inicialización del lector. |
| is_linked | Indicador que indica que el código de barras debe estar vinculado a un código de barras 1D. |
| is_code_128_emulation | Indicador que indica que el código de barras MicroPdf417 está codificado con los códigos de emulación Code 128 908, 909, 910 o 911. |
