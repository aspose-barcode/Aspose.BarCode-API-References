## CodabarExtendedParameters class

Almacena información adicional de Codabar del código de barras reconocido

El tipo CodabarExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| start_symbol | Obtiene o establece un símbolo de inicio Codabar.<br/>            Valor predeterminado: CodabarSymbol.A |
| stop_symbol | Obtiene o establece un símbolo de parada Codabar.<br/>            Valor predeterminado: CodabarSymbol.A |
