## AustraliaPostSettings class

Parámetros de decodificación de AustraliaPost. Contiene parámetros que influyen en los datos reconocidos de la simbología AustraliaPost.

El tipo AustraliaPostSettings expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| customer_information_interpreting_type | Obtiene o establece el Tipo de Interpretación para la Información del Cliente del código de barras AustralianPost. El valor predeterminado es CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | La bandera que obliga al decodificador AustraliaPost a ignorar los últimos patrones de relleno en el Campo de Información del Cliente durante la decodificación como método CTable.<br/>            El método de codificación CTable no tiene huecos en la tabla de codificación y la secuencia "333" de patrones de relleno se decodifica como la letra "z". |
| customer_information_decoder | Interfaz pública para la decodificación del Campo de Información del Cliente que se utiliza en la simbología AustraliaPost. |
