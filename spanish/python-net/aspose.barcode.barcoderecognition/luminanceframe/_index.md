## LuminanceFrame class

Representa un cuadro de imagen en escala de grises de 8 bits. Cada píxel se representa con un byte que contiene su valor de luminancia.

El tipo LuminanceFrame expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Inicializa una nueva instancia de la clase LuminanceFrame |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Inicializa una nueva instancia de la clase LuminanceFrame |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| datos | Obtiene los datos de luminancia. |
| width | Obtiene el ancho del fotograma en píxeles. |
| height | Obtiene la altura del fotograma en píxeles. |
| row_stride | Obtiene la distancia en bytes entre los comienzos<br/>            de dos filas adyacentes. |
| rotation_degrees | Obtiene el número de grados que el fotograma debe rotarse en sentido horario para tener la orientación correcta. |
