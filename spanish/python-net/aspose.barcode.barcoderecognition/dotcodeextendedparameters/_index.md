## DotCodeExtendedParameters class

Almacena datos especiales del código de barras DotCode reconocido

El tipo DotCodeExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| structured_append_mode_barcodes_count | Obtiene el recuento de códigos de barras del modo de anexado estructurado DotCode. El valor predeterminado es -1. El recuento debe ser un valor de 1 a 35. |
| structured_append_mode_barcode_id | Obtiene el ID del código de barras del modo de anexado estructurado DotCode. El ID comienza en 1 y debe ser menor o igual al recuento de códigos de barras. El valor predeterminado es -1. |
| is_reader_initialization | Indica si el código se usa para instruir al lector a interpretar los datos siguientes como instrucciones para la inicialización o reprogramación del lector de códigos de barras.<br/>            El valor predeterminado es false. |
