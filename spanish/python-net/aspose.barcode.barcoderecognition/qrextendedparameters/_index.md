## QRExtendedParameters class

Almacena información de QR Structured Append del código de barras reconocido

El tipo QRExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| structured_append_mode_bar_codes_quantity | Obtiene la cantidad de códigos de barras del modo de anexado estructurado QR. El valor predeterminado es -1. |
| structured_append_mode_bar_code_index | Obtiene el índice del código de barras del modo de anexado estructurado QR. El índice comienza en 0. El valor predeterminado es -1. |
| structured_append_mode_parity_data | Obtiene los datos de paridad del modo de anexado estructurado QR. El valor predeterminado es -1. |
| version | Versión del código QR reconocido. Desde Version1 hasta Version40. |
| micro_qr_version | Versión del código MicroQR reconocido. Desde M1 hasta M4. |
| rect_micro_qr_version | Versión del código RectMicroQR reconocido. Desde R7x43 hasta R17x139. |
| error_level | Nivel de corrección de errores Reed-Solomon del código de barras reconocido. De bajo a alto: LevelL, LevelM, LevelQ, LevelH. |
