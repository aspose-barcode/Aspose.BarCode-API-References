## BarCodeConfidence enumeration

Contiene el nivel de confianza del reconocimiento

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | Confianza de reconocimiento del código de barras donde el texto del código no se reconoció correctamente o el código de barras se detectó como posible falso |
| MODERATE | Confianza de reconocimiento del código de barras (principalmente códigos de barras 1D) con suma de verificación débil o incluso sin ella. Podría contener algunas misreconocimientos en el texto del código<br/>            o incluso reconocimientos falsos si |
| STRONG | Confianza de reconocimiento que fue confirmada con códigos BCH como Reed–Solomon. No debe haber errores en el texto del código leído o reconocimientos falsos. |
