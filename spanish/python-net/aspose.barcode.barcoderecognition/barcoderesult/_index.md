## BarCodeResult class

Almacena datos del código de barras reconocido como tipo [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/), cadena codetext, <br/>            región [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) y otros parámetros

El tipo BarCodeResult expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| BarCodeResult(result) | Inicializa una nueva instancia de la clase BarCodeResult |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| reading_quality | Obtiene la calidad de lectura. Funciona para códigos de barras 1D y postales. |
| confidence | Obtiene el nivel de confianza del reconocimiento del código de barras reconocido |
| code_text | Obtiene el texto del código |
| code_bytes | Obtiene los bytes codificados del código |
| code_type | Obtiene el tipo de código de barras |
| code_type_name | Obtiene el nombre del tipo de código de barras |
| región | Obtiene la región del código de barras |
| extendido | Obtiene los parámetros extendidos del código de barras reconocido |
| iso_symbol_quality | Obtiene los resultados de la evaluación de la calidad del símbolo ISO/IEC para el código de barras reconocido. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_code_text(encoding) | Obtiene el texto del código con codificación. |
