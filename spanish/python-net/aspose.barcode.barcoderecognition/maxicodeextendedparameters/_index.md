## MaxiCodeExtendedParameters class

Almacena información adicional de MaxiCode del código de barras reconocido

El tipo MaxiCodeExtendedParameters expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_empty | Comprueba si todos los parámetros tienen solo valores predeterminados |
| modo | Obtiene o establece un modo de codificación MaxiCode.<br/>            Valor predeterminado: Mode4 |
| structured_append_mode_barcode_id | Obtiene o establece un id de código de barras MaxiCode en modo de anexado estructurado.<br/>            Valor predeterminado: 0 |
| structured_append_mode_barcodes_count | Obtiene o establece la cantidad de códigos de barras MaxiCode en modo de anexado estructurado.<br/>            Valor predeterminado: -1 |
