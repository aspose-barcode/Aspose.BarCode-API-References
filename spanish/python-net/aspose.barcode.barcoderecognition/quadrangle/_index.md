## Quadrangle class

Almacena un conjunto de cuatro [Point](/barcode/python-net/aspose.drawing/point/) que representan una región de [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/).

El tipo Quadrangle expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Quadrangle() | Inicializa una nueva instancia vacía de la clase [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Inicializa una nueva instancia de la clase Quadrangle |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| left_top | Obtiene la esquina superior izquierda [Point](/barcode/python-net/aspose.drawing/point/) de la región [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| right_top | Obtiene la esquina superior derecha [Point](/barcode/python-net/aspose.drawing/point/) de la región [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| right_bottom | Obtiene la esquina inferior derecha [Point](/barcode/python-net/aspose.drawing/point/) de la región [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| left_bottom | Obtiene la esquina inferior izquierda [Point](/barcode/python-net/aspose.drawing/point/) de la región [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| is_empty | Comprueba si todos los [Point](/barcode/python-net/aspose.drawing/point/) de este [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) tienen valores cero. |
| bounding_rectangle | Obtiene el [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) que delimita este [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| EMPTY | Representa una clase [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) con sus propiedades sin inicializar. |
