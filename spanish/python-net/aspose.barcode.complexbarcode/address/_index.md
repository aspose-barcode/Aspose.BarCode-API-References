## Address class

Dirección del acreedor o deudor.

El tipo Address expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Address() | Crea una instancia de Address |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| type | Obtiene el tipo de dirección. |
| name | Obtiene o establece el nombre, ya sea el nombre y apellido de una persona física o el<br/>            nombre de la empresa de una persona jurídica. |
| address_line1 | Obtiene o establece la línea de dirección 1. |
| address_line2 | Obtiene o establece la línea de dirección 2. |
| street | Obtiene o establece la calle. |
| house_no | Obtiene o establece el número de casa. |
| postal_code | Obtiene o establece el código postal. |
| town | Obtiene o establece la localidad o ciudad. |
| country_code | Obtiene o establece el código de país ISO de dos letras. |
