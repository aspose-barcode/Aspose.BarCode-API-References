## SwissQRBill class

Datos de factura SwissQR

El tipo SwissQRBill expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| version | Obtiene o establece la versión del estándar SwissQR bill. |
| amount | Obtiene o establece el importe del pago. |
| currency | Obtiene o establece la moneda del pago. |
| account | Obtiene o establece el número de cuenta del acreedor. |
| creditor | Obtiene o establece la dirección del acreedor. |
| reference | Obtiene o establece la referencia de pago del acreedor. |
| deudor | Obtiene o establece la dirección del deudor. |
| unstructured_message | Obtiene o establece el mensaje no estructurado adicional. |
| bill_information | Obtiene o establece la información de factura estructurada adicional. |
| alternative_schemes | Obtiene o establece los esquemas de pago alternativos. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| create_and_set_creditor_reference(raw_reference) | Crea y establece una referencia de acreedor ISO11649 a partir de una cadena sin formato añadiendo<br/>            la cadena con "RF" y el checksum módulo 97. |
| equals(other) | Determina si el objeto especificado es igual al objeto actual. |
