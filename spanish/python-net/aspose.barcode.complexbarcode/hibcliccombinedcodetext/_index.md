## HIBCLICCombinedCodetext class

Clase para codificar y decodificar el texto incrustado en el código HIBC LIC que almacena datos primarios y secundarios.

El tipo HIBCLICCombinedCodetext expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| HIBCLICCombinedCodetext() | Inicializa una nueva instancia de la clase HIBCLICCombinedCodetext |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| barcode_type | Obtiene o establece el tipo de código de barras. El texto de código HIBC LIC puede codificarse usando HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC y HIBCQRLIC tipos de codificación.<br/>            Valor predeterminado: HIBCCode39LIC. |
| primary_data | Identifica los datos primarios. |
| secondary_and_additional_data | Identifica datos secundarios y suplementarios adicionales. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_constructed_codetext() | Construye codetext |
| init_from_string(constructed_codetext) | Inicializa la instancia a partir del codetext construido. |
| get_barcode_type() | Obtiene el tipo de código de barras. |
