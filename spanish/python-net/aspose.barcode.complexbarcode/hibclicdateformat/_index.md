## HIBCLICDateFormat enumeration

Especifica los diferentes tipos de formatos de fecha para HIBC LIC.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| YYYYMMDD | Formato YYYYMMDD. Se codificará en datos suplementarios adicionales. |
| MMYY | Formato MMYY. |
| MMDDYY | Formato MMDDYY. |
| YYMMDD | Formato YYMMDD. |
| YYMMDDHH | Formato YYMMDDHH. |
| YYJJJ | Formato de fecha juliana. |
| YYJJJHH | Formato de fecha juliana con horas. |
| NONE | No codifique la fecha de vencimiento. |
