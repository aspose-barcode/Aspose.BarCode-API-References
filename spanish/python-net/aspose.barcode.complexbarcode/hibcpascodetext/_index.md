## HIBCPASCodetext class

Clase para codificar y decodificar el texto incrustado en el código HIBC PAS.

El tipo HIBCPASCodetext expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| HIBCPASCodetext() | Inicializa una nueva instancia de la clase HIBCPASCodetext |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| barcode_type | Obtiene o establece el tipo de código de barras. El codetext HIBC PAS puede codificarse usando HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS y HIBCQRPAS tipos de codificación.<br/>            Valor predeterminado: HIBCCode39PAS. |
| data_location | Identifica la ubicación de los datos. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add_record(data_type, data) | Agrega un nuevo registro |
| add_record(record) | Agrega un nuevo registro |
| get_records() | Obtiene la lista de registros |
| clear() | Borra la lista de registros |
| get_barcode_type() | Obtiene el tipo de código de barras. |
| get_constructed_codetext() | Construye codetext |
| init_from_string(constructed_codetext) | Inicializa la instancia a partir del codetext construido. |
