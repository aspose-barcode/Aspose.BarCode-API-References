## MaxiCodeStandardCodetext class

Clase para codificar y decodificar el texto de código MaxiCode para los modos 4, 5 y 6.

El tipo MaxiCodeStandardCodetext expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| MaxiCodeStandardCodetext() | Inicializa una nueva instancia de la clase MaxiCodeStandardCodetext |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| encode_mode | Obtiene o establece un modo de codificación MaxiCode. <br/>            Valor predeterminado: Auto. |
| eci_encoding | Obtiene o establece la codificación ECI. Se usa cuando MaxiCodeEncodeMode es Auto.<br/>            Valor predeterminado: ISO-8859-1 |
| modo | Obtiene o establece el modo MaxiCode. El codetext estándar solo puede usarse con los modos 4, 5 y 6. |
| message | Obtiene o establece el mensaje. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_mode() | Obtiene el modo MaxiCode. |
| get_constructed_codetext() | Construye codetext |
| init_from_string(constructed_codetext) | Inicializa la instancia a partir del codetext construido. |
| get_barcode_type() | Obtiene el tipo de código de barras. |
