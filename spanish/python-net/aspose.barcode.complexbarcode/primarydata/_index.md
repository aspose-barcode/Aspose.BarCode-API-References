## PrimaryData class

Clase para almacenar los datos primarios HIBC LIC.

El tipo PrimaryData expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PrimaryData() | Inicializa una nueva instancia de la clase PrimaryData |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| labeler_identification_code | Identifica la fecha del código de identificación del etiquetador.<br/>            El código de identificación del etiquetador debe ser una cadena alfanumérica de 4 símbolos, con el primer carácter siempre alfabético. |
| product_or_catalog_number | Identifica el número de producto o catálogo. El número de producto o catálogo debe ser una cadena alfanumérica de hasta 18 símbolos. |
| unit_of_measure_id | Identifica el ID de unidad de medida. El ID de unidad de medida debe ser un valor entero de 0 a 9. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| parse_from_string(primary_data_codetext) | Instancia datos primarios a partir de una cadena según la especificación HIBC LIC. |
