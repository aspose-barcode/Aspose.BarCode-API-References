## IComplexCodetext class

Interfaz para texto de código complejo utilizado con ComplexBarcodeGenerator.

El tipo IComplexCodetext expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_constructed_codetext() | Construye el codetexto para un código de barras complejo |
| init_from_string(constructed_codetext) | Inicializa la instancia con el codetexto construido. |
| get_barcode_type() | Obtiene el tipo de código de barras. |
