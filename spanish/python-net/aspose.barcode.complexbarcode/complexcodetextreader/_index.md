## ComplexCodetextReader class

ComplexCodetextReader decodifica el texto de código al tipo de código de barras complejo especificado.

El tipo ComplexCodetextReader expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| try_decode_swiss_qr(encoded_codetext) | Decodifica el texto codificado SwissQR. |
| try_decode_mailmark_2d(encoded_codetext) | Decodifica el texto codificado Royal Mail Mailmark 2D. |
| try_decode_mailmark(encoded_codetext) | Decodifica el texto codificado Royal Mail Mailmark 2D. |
| try_decode_maxi_code(maxi_code_mode, encoded_codetext) | Decodifica el texto codificado MaxiCode. |
| try_decode_hibclic(encoded_codetext) | Decodifica el texto codificado HIBC LIC. |
| try_decode_hibcpas(encoded_codetext) | Decodifica el texto de código HIBC PAS. |
| try_decode_usa_drive_id(encoded_codetext) | Decodifica el texto de código USADriveId. |
| try_decode_gs1_codetext(encoded_codetext) | Decodifica el texto de código GS1. |
| try_decode_gs1_digital_link(encoded_codetext) | Decodifica GS1 Digital Link. |
