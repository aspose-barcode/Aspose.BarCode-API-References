## CustomerInformationInterpretingType enumeration

Define el tipo de interpretación (CTable, NTable u Otro) de la información del cliente para AustralianPost BarCode.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| C_TABLE | Utilice CTable para interpretar la información del cliente. Permite A..Z, a..z, 1..9, espacio y el signo #. |
| N_TABLE | Utilice NTable para interpretar la información del cliente. Permite dígitos. |
| OTHER | No interprete la información del cliente. Permite solo los símbolos 0, 1, 2 o 3. |
