## BuildVersionInfo class

Contiene la información de la versión de compilación actual.

El tipo BuildVersionInfo expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| ASSEMBLY_VERSION | La versión del ensamblado. |
| FILE_VERSION | La versión del archivo. |
| PRODUCT | El título del producto. |
| PRODUCT_MAJOR | La versión principal del producto. |
| PRODUCT_MINOR | La versión menor del producto. |
| RELEASE_DATE | La fecha de lanzamiento del producto. |
