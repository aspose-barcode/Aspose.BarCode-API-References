## GraphicsUnit

Especifica la unidad de medida para los datos proporcionados.

## Valores

| Nombre | Descripción |
| --- | --- |
| WORLD | Especifica la unidad del sistema de coordenadas mundial como la unidad de medida. |
| DISPLAY | Especifica la unidad de medida del dispositivo de pantalla. Normalmente píxeles para pantallas de video y 1/100 de pulgada para impresoras. |
| PIXEL | Especifica un píxel del dispositivo como la unidad de medida. |
| POINT | Especifica el punto de la impresora = 1/72 de pulgada) como la unidad de medida. |
| INCH | Especifica la pulgada como la unidad de medida. |
| DOCUMENT | Especifica la unidad de documento = 1/300 de pulgada) como la unidad de medida. |
| MILLIMETER | Especifica el milímetro como la unidad de medida. |
