## Pdf417ErrorLevel

Nivel de corrección de errores del código de barras pdf417, desde el nivel 0 hasta el nivel 9; el nivel 0 significa sin corrección de errores, el nivel 9 significa la mejor corrección de errores.

## Valores

| Nombre | Descripción |
| --- | --- |
| LEVEL_0 | nivel = 0. |
| LEVEL_1 | nivel = 1. |

| LEVEL_4 | nivel = 4. |
