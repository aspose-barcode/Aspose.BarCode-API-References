## EnableChecksum

Habilitar suma de verificación durante la generación de códigos de barras 1D. Por defecto se trata como Sí para las simbologías que deben contener suma de verificación, y como No donde la suma de verificación solo es posible. Suma de verificación nunca usada: Codabar. Suma de verificación posible: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN. Suma de verificación siempre usada: el resto de simbologías.

## Valores

| Nombre | Descripción |
| --- | --- |
| DEFAULT | Si se requiere el checksum según la especificación, se adjuntará. |
| SÍ | Utilice siempre el checksum si es posible. |
| NO | No utilice el checksum. |
