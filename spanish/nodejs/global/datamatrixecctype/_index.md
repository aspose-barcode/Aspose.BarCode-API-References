## DataMatrixEccType

Especifique el tipo de ECC a codificar.

## Valores

| Nombre | Descripción |
| --- | --- |
| ECC_AUTO | Especifica que el tipo de ECC codificado se define por la corrección de errores Reed-Solomon predeterminada o ECC 200. |
| ECC_000 | Especifica que el tipo de ECC codificado se define ECC 000. |
| ECC_050 | Especifica que el tipo de ECC codificado se define ECC 050. |
| ECC_080 | Especifica que el tipo de ECC codificado se define ECC 080. |
| ECC_100 | Especifica que el tipo de ECC codificado se define ECC 100. |
| ECC_140 | Especifica que el tipo Ecc codificado está definido ECC 140. |
| ECC_200 | Especifica que el tipo Ecc codificado está definido ECC 200. Se recomienda usar. |
