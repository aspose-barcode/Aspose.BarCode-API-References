## AztecSymbolMode

Especifica el modo de símbolo Aztec.

## Valores

| Nombre | Descripción |
| --- | --- |
| AUTO | Especifica que se seleccione automáticamente el mejor símbolo (COMPACT o FULL-range) para Aztec. Este es el valor predeterminado. |
| COMPACT | Especifica el símbolo COMPACT para Aztec. El símbolo COMPACT de Aztec permite solo 1, 2, 3 o 4 capas. |
| FULL_RANGE | Especifica el símbolo FULL-range para Aztec. El símbolo FULL-range de Aztec permite de 1 a 32 capas. |
| RUNE | Especifica el símbolo RUNE para Aztec. Los Runes de Aztec son una serie de marcas pequeñas pero distintas legibles por máquina. Permite solo valores numéricos de 0 a 255. |
