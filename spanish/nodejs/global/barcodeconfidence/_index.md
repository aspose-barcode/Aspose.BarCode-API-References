## BarCodeConfidence

Contiene el nivel de confianza del reconocimiento

## Valores

| Nombre | Descripción |
| --- | --- |
| NONE | Confianza de reconocimiento del código de barras donde el texto del código no fue reconocido correctamente o el código de barras fue detectado como posible falso |
| MODERATE | Confianza de reconocimiento del código de barras (principalmente códigos de barras 1D) con suma de verificación débil o incluso sin ella. Puede contener algunas erratas en el texto del código o incluso reconocimientos falsos si es baja |
| STRONG | Confianza de reconocimiento que fue confirmada con códigos BCH como Reed–Solomon. No debe haber errores en el texto del código leído o reconocimientos falsos |
