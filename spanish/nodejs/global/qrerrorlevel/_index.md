## QRErrorLevel

Nivel de corrección de errores Reed-Solomon. De bajo a alto: LEVEL_L, LEVEL_M, LEVEL_Q, LEVEL_H.

## Valores

| Nombre | Descripción |
| --- | --- |
| LEVEL_L | Permite la recuperación del 7% del texto del código |
| LEVEL_M | Permite la recuperación del 15% del texto del código |
| LEVEL_Q | Permite la recuperación del 25% del texto del código |
| LEVEL_H | Permite la recuperación del 30% del texto del código |
