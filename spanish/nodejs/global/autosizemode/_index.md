## AutoSizeMode

Especifica los diferentes tipos de modos de dimensionado automático. El valor predeterminado es AutoSizeMode.NONE.

## Valores

| Nombre | Descripción |
| --- | --- |
| NONE | El dimensionado automático está desactivado. Valor predeterminado. |
| NEAREST | El código de barras se redimensiona al tamaño más bajo posible más cercano que está especificado por las propiedades BarCodeWidth y BarCodeHeight. |
| INTERPOLATION | Redimensiona el código de barras al tamaño especificado con un escalado leve, pero puede dañarse ligeramente en algunos casos debido al uso de interpolación para el escalado. El tamaño puede especificarse mediante las propiedades BarcodeGenerator.BarCodeWidth y BarcodeGenerator.BarCodeHeight. |
