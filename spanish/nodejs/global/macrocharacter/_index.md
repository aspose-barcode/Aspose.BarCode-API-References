## MacroCharacter

Los valores de los caracteres macro 05 y 06 se utilizan para obtener una codificación más compacta en modos especiales. El carácter macro 05 se traduce a "[)>\u001E05\u001D" como encabezado de datos decodificados y "\u001E\u0004" como tráiler de datos decodificados. El carácter macro 06 se traduce a "[)>\u001E06\u001D" como encabezado de datos decodificados y "\u001E\u0004" como tráiler de datos decodificados. Estas muestras muestran cómo codificar caracteres macro en MicroPdf417 y DataMatrix

## Valores

| Nombre | Descripción |
| --- | --- |
| AUTO | Determinación automática |
| TYPE_7 | 24 x 24 módulos |
| TYPE_9 | 32 x 32 módulos |
| TYPE_29 | 16 x 48 módulos |
