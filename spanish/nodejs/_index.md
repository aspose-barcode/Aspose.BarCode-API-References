La API proporciona clases para la creación, reconocimiento y manipulación de códigos de barras, permitiendo una integración fluida en aplicaciones Node.js mediante interoperabilidad Java. Las simbologías compatibles abarcan códigos lineales, 2‑D y códigos postales como Code128, EAN‑13, QR, DataMatrix, Aztec y PDF417. Toda la funcionalidad está organizada bajo el espacio de nombres aspose.barcode, con utilidades auxiliares ubicadas en el espacio de nombres Global.

## Espacios de nombres

| Espacio de nombres | Descripción |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | El espacio de nombres aspose.barcode ofrece clases y enumeraciones para crear, personalizar y decodificar una amplia variedad de tipos de códigos de barras en Node.js vía Java. |
| [Global](./global/) | El espacio de nombres Global agrupa enumeraciones centrales y clases de utilidad utilizadas en Aspose.BarCode para Node.js vía Java. |
