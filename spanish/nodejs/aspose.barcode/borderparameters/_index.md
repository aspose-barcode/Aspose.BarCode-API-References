## BorderParameters class

Parámetros del borde de la imagen del código de barras

```js
new BorderParameters()
```

## Métodos

| Nombre | Descripción |
| --- | --- |
| [getColor()](#getcolor) | Color del borde. Valor predeterminado: #000000 |
| [getDashStyle()](#getdashstyle) | Estilo de guión del borde. Valor predeterminado: BorderDashStyle.SOLID. |
| [getVisible()](#getvisible) | Visibilidad del borde. Si es false, entonces el parámetro Width siempre se ignora (0). Valor predeterminado: false. |
| [getWidth()](#getwidth) | Ancho del borde. Valor predeterminado: 0. Ignorado si Visible está establecido en false. |
| [setColor()](#setcolor) | Color del borde. Valor predeterminado: #000000 |
| [setDashStyle()](#setdashstyle) | Estilo de guión del borde. Valor predeterminado: BorderDashStyle.SOLID. |
| [setVisible()](#setvisible) | Visibilidad del borde. Si es false, entonces el parámetro Width siempre se ignora (0). Valor predeterminado: false. |
| [setWidth()](#setwidth) | Ancho del borde. Valor predeterminado: 0. Ignorado si Visible está establecido en false. |
| [toString()](#tostring) | Devuelve una representación de cadena legible por humanos de este BorderParameters. |
