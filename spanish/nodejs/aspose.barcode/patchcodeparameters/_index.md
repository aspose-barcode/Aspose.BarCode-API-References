### getExtraBarcodeText() {#getextrabarcodetext}

Especifica el texto del código para un QR adicional, cuando PatchCode se genera en modo página.

### getFormat() {#getformat}

Formato PatchCode. Elija PatchOnly para generar un solo PatchCode. Use el formato de página para generar una página Patch con PatchCodes como bordes. Valor predeterminado: PatchFormat.PatchOnly
