## PdfParameters class

Envoltorio de parámetros PDF. Espera una instancia subyacente `mwObject` que proporcione los métodos getter/setter correspondientes que devuelvan/acepten cadenas CMYK como "30_100_0_30" o `null`.

```js
new PdfParameters(mwObject)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| mwObject | objeto | – instancia de la clase Java PdfParameters |
