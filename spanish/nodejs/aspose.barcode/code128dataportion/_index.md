## Code128DataPortion class

Contiene los datos del subtipo para el código de barras tipo Code128

```js
new Code128DataPortion()
```

Crea una nueva instancia de la clase `Code128DataPortion` con el símbolo de código de inicio y el texto codificado decodificado.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Obtiene el tipo del subconjunto Code128 |
| [getData()](#getdata) | Obtiene la parte del texto de código relacionada con el subtipo. |
| [toString()](#tostring) | Devuelve una representación de cadena legible por humanos de este `Code128DataPortion`. |

### getCode128SubType() {#getcode128subtype}

Obtiene el tipo del subconjunto Code128

**Returns:** The type of Code128 subset

### getData() {#getdata}

Obtiene la parte del texto de código relacionada con el subtipo.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Devuelve una representación de cadena legible por humanos de este `Code128DataPortion`.

**Returns:** A string that represents this `Code128DataPortion`.
