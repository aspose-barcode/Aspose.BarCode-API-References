### getMacroCharacters() {#getmacrocharacters}

ISO/IEC 16022 5.2.4.7 Caracteres macro 11.3 Protocolo para caracteres macro en la primera posición (solo ECC 200) Los valores de los Caracteres Macro 05 y 06 se utilizan para obtener una codificación más compacta en modos especiales. Solo se puede usar con DataMatrixEccType.ECC_200 o DataMatrixEccType.ECC_AUTO. No se puede usar con EncodeTypes.GS_1_DATA_MATRIX Valor predeterminado: MacroCharacter.NONE.
