## RecognitionAbortedException class

Representa la excepción de aborto de reconocimiento que se lanza al exceder el tiempo de espera durante el reconocimiento con BarCodeReader.

```js
new RecognitionAbortedException(message, executionTime)
```

Inicializa una nueva instancia de la clase con el mensaje de aborto de reconocimiento especificado.

| Parámetro | Descripción |
| --- | --- |
| mensaje | El mensaje de error de la excepción. |
| executionTime | El tiempo de ejecución de la sesión de reconocimiento actual. |
