## License class

Proporciona métodos para licenciar el componente.

```js
new License()
```

Inicializa una nueva instancia de esta clase.

## Métodos

| Nombre | Descripción |
| --- | --- |
| [setLicense(licensePath)](#setlicense) | Licencia el componente. |

### setLicense(licensePath) {#setlicense}

Licencia el componente.

| Parámetro | Descripción |
| --- | --- |
| licensePath | ruta al archivo de licencia |
