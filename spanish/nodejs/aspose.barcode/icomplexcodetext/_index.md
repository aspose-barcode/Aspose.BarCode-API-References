## IComplexCodetext class

Interfaz para codetexto complejo usado con ComplexBarcodeGenerator.

```js
new IComplexCodetext()
```

## Métodos

| Nombre | Descripción |
| --- | --- |
| [getBarcodeType()](#getbarcodetype) | Obtiene el tipo de código de barras. |
| [getConstructedCodetext()](#getconstructedcodetext) | Construye el texto de código para un código de barras complejo |
| [initFromString(constructedCodetext)](#initfromstring) | Inicializa la instancia con el texto de código construido. |

### getBarcodeType() {#getbarcodetype}

Obtiene el tipo de código de barras.

**Returns:** Barcode type.

### getConstructedCodetext() {#getconstructedcodetext}

Construye el texto de código para un código de barras complejo

**Returns:** Constructed codetext

### initFromString(constructedCodetext) {#initfromstring}

Inicializa la instancia con el texto de código construido.

| Parámetro | Descripción |
| --- | --- |
| constructedCodetext | Codetext construido. |
