## SwissQRCodetext class

Clase para codificar y decodificar el texto incrustado en el código SwissQR.

```js
new SwissQRCodetext(bill)
```

Crea una instancia de SwissQRCodetext.

| Parámetro | Descripción |
| --- | --- |
| bill | Datos de factura SwissQR |

**Throws:** BarcodeException

## Métodos

| Nombre | Descripción |
| --- | --- |
| [getBarcodeType()](#getbarcodetype) | Obtiene el tipo de código de barras. |
| [getBill()](#getbill) | Datos de factura SwissQR |
| [getConstructedCodetext()](#getconstructedcodetext) | Construye codetext a partir de los datos de la factura SwissQR. |
| [initFromString(constructedCodetext)](#initfromstring) | Inicializa Bill con el codetext construido. |

### getBarcodeType() {#getbarcodetype}

Obtiene el tipo de código de barras.

**Returns:** Barcode type.

### getBill() {#getbill}

Datos de factura SwissQR

### getConstructedCodetext() {#getconstructedcodetext}

Construye codetext a partir de los datos de la factura SwissQR.

**Returns:** Constructed codetext

### initFromString(constructedCodetext) {#initfromstring}

Inicializa Bill con el codetext construido.

| Parámetro | Descripción |
| --- | --- |
| constructedCodetext | Codetext construido. |
