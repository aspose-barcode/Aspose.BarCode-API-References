## SvgColorMode enumeration

Modos posibles para el color de relleno en un archivo svg, RGB es el predeterminado y es compatible con SVG 1.1. RGBA, HSL, HSLA están permitidos en la norma SVG 2.0. Incluso en RGB la opacidad se establecerá mediante el parámetro "fill-opacity"

```csharp
public enum SvgColorMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| RGB | `0` | Modo RGB, ejemplo: fill="#ff5511" fill-opacity="0.73". Modo predeterminado. |
| RGBA | `1` | Modo RGBA, ejemplo: fill="rgba(255, 85, 17, 0.73)" |
| HSL | `2` | Modo HSL, ejemplo: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | `3` | Modo HSLA, ejemplo: fill="hsla(30, 50%, 70%, 0.8)" |
