## Pdf417Parameters.ErrorLevel property

Obtiene o establece el tipo de simbología Pdf417 del nivel de corrección de errores de BarCode, que varía de level0 a level8; level0 significa sin información de corrección de errores, level8 significa la mejor corrección, lo que implica una imagen más grande.

```csharp
public Pdf417ErrorLevel ErrorLevel { get; set; }
```
