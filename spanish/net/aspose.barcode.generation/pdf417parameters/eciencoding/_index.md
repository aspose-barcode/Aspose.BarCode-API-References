## Pdf417Parameters.ECIEncoding property

Identificadores de Interpretación de Canal Extendida. Se utilizan para indicar al lector de códigos de barras detalles sobre las referencias usadas para codificar los datos en el símbolo. No se aplican a los campos de texto Macro PDF417. La implementación actual incluye todas las codificaciones de conjunto de caracteres conocidas.

public ECIEncodings ECIEncoding { get; set; }
