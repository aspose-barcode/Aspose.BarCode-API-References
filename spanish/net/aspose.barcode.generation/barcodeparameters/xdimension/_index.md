## BarcodeParameters.XDimension property

x-dimension es el ancho más pequeño de la unidad de barras o espacios del código de barras. Incrementar esto aumentará el ancho total de la imagen del código de barras. Se ignora si la propiedad [`AutoSizeMode`](../../basegenerationparameters/autosizemode/) está configurada a AutoSizeMode.Nearest o AutoSizeMode.Interpolation.

public Unit XDimension { get; set; }
