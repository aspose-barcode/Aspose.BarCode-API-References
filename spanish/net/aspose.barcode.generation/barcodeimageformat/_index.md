| Nombre | Valor | Descripción |
| --- | --- | --- |
| Bmp | `0` | Especifica el formato de imagen bitmap (BMP). |
| Gif | `1` | Especifica el formato de imagen Graphics Interchange Format (GIF). |
| Jpeg | `2` | Especifica el formato de imagen Joint Photographic Experts Group (JPEG). |
| Png | `3` | Especifica el formato de imagen W3C Portable Network Graphics (PNG). |
| Tiff | `4` | Especifica el formato de imagen Tagged Image File Format (TIFF). |
| TiffInCmyk | `5` | Especifica el formato de imagen Tagged Image File Format (TIFF) en modelo de color CMYK. (Solo compatible en la plataforma Windows, en plataformas *nix se guarda como Tiff) |

| Svg | `7` | Especifica el formato de imagen Scalable Vector Graphics (SVG). |
| Pdf | `8` | Especifica el formato de imagen Portable Document Format (PDF). |
