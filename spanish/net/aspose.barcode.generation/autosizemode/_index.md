## AutoSizeMode enumeration

Especifica los diferentes tipos de modos de dimensionado automático.

```csharp
public enum AutoSizeMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | El redimensionado automático está deshabilitado. |
| Nearest | `1` | Redimensiona el código de barras al tamaño más bajo posible más cercano especificado por las propiedades ImageWidth e ImageHeight. Preserva la relación de aspecto predeterminada. |
| Interpolation | `2` | Redimensiona el código de barras al tamaño especificado. El tamaño puede especificarse mediante las propiedades ImageWidth e ImageHeight. El código de barras generado puede ser inválido (no legible) después del escalado. |
