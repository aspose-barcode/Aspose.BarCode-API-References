## DotCodeParameters.StructuredAppendModeBarcodeId property

Identifica el ID del código de barras en modo de anexado estructurado DotCode. El ID comienza en 1 y debe ser menor o igual al recuento de códigos de barras. El valor predeterminado es -1.

public int StructuredAppendModeBarcodeId { get; set; }
