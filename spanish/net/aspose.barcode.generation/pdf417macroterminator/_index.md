## Pdf417MacroTerminator enumeration

Se utiliza para indicar al codificador si debe agregar el Terminador Macro PDF417 (código de palabra 922) al segmento. Aplicado solo para Macro PDF417.

```csharp
public enum Pdf417MacroTerminator
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Auto | `0` | El terminador se agregará automáticamente si se proporciona el número de segmentos y el segmento actual es el último. En otros casos, el terminador no se agregará. |
| None | `1` | El terminador no será añadido. |
| Set | `2` | El terminador será añadido. |
