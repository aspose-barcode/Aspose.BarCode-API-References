## QrExtCodetextBuilder.AddCodetextWithCompactionMode method

Agrega codetext con el modo de compactación QR especificado a los elementos de codetext extendido.

```csharp
public void AddCodetextWithCompactionMode(QrExtCompactionMode mode, string codetext)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| modo | QrExtCompactionMode | Modo de compresión QR para el texto de código. |
| codetext | Cadena | Texto de código en Unicode para añadir como un elemento de texto de código extendido. |

### Excepciones

| excepción | condición |
| --- | --- |
| ArgumentException | El texto de código especificado no puede codificarse en el modo de compresión QR seleccionado. |
