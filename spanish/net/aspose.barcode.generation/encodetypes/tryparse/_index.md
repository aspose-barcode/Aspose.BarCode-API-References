## EncodeTypes.TryParse method

Convierte la representación en cadena de un BaseEncodeType a su instancia. Un valor de retorno indica si la conversión tuvo éxito o falló.

```csharp
public static bool TryParse(string parsingType, out BaseEncodeType result)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| parsingType | Cadena | Una cadena con el formato "Index:-1; Name:None" para convertir. |
| resultado | BaseEncodeType& | Un SingleEncodeType real se devuelve cuando la conversión se ha completado con éxito; |

### Valor de retorno

**true** if s was converted successfully; otherwise, **false**.
