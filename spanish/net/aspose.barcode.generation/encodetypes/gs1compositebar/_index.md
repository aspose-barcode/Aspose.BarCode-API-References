## EncodeTypes.GS1CompositeBar field

Especifica que los datos deben codificarse con la especificación de código de barras **GS1 Composite Bar**. El texto del código debe contener paréntesis para AI. El texto del código 1D y el texto del código 2D deben separarse con el símbolo '/'

public static readonly SymbologyEncodeType GS1CompositeBar;
