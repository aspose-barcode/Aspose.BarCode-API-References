## EncodeTypes.UpcaGs1DatabarCoupon field

Especifica que los datos deben codificarse con la especificación de código de barras **UPC coupon with GS1 DataBar addition**. Un ejemplo de la cadena de entrada: BarcodeGenerator.Codetext = "514141100906(8110)106141416543213500110000310123196000", donde la parte UPCA es "514141100906", la parte Databar es "(8110)106141416543213500110000310123196000". Para cambiar la leyenda, use Parameters.CaptionAbove.Text = "company prefix + offer code";

```csharp
public static readonly SymbologyEncodeType UpcaGs1DatabarCoupon;
```
