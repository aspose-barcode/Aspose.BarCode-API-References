## QRErrorLevel enumeration

Nivel de corrección de errores Reed-Solomon. De bajo a alto: LevelL, LevelM, LevelQ, LevelH.

```csharp
public enum QRErrorLevel
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| LevelL | `0` | La corrección de errores Nivel L se puede aplicar a códigos QR y MicroQR. Permite recuperar el 7 % del texto del código. |
| LevelM | `1` | La corrección de errores Nivel M se puede aplicar a códigos QR, códigos RectMicroQR y códigos MicroQR con versiones de M2 a M4. Permite recuperar el 15 % del texto del código. |
| LevelQ | `2` | La corrección de errores Nivel Q se puede aplicar a códigos QR y códigos MicroQR con versión M4. Permite recuperar el 25 % del texto del código. |
| LevelH | `3` | La corrección de errores Nivel H se puede aplicar a códigos QR y RectMicroQR. Permite recuperar el 30 % del texto del código. |
