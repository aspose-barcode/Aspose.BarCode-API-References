## CodabarParameters.ChecksumMode property

Obtenga o establezca el algoritmo de suma de verificación para códigos de barras Codabar. Valor predeterminado: CodabarChecksumMode.Mod16. Para habilitar el cálculo de la suma de verificación, establezca el valor EnableChecksum.Yes en la propiedad EnableChecksum. Ver `ChecksumMode`.

```csharp
public CodabarChecksumMode ChecksumMode { get; set; }
```
