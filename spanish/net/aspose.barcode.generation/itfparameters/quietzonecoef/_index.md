## ITFParameters.QuietZoneCoef property

Tamaño de las zonas silenciosas en xDimension. Valor predeterminado: 10, lo que significa que si xDimension = 2px, entonces las zonas silenciosas serán 20px.

```csharp
public int QuietZoneCoef { get; set; }
```

### Excepciones

| excepción | condición |
| --- | --- |
| ArgumentException | El valor del parámetro **QuietZoneCoef** es menor que 10. |
