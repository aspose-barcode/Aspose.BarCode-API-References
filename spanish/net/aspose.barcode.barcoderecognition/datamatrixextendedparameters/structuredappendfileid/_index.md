## DataMatrixExtendedParameters.StructuredAppendFileId property

Obtiene el ID del código de barras en modo structured append de DataMatrix. El ID comienza en 1 y debe ser menor o igual al número de códigos de barras. El valor predeterminado es -1.

```csharp
public int StructuredAppendFileId { get; }
```

### Property Value

El ID del código de barras DataMatrix en modo de adición estructurada.
