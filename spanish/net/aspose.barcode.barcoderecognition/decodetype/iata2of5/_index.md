## DecodeType.IATA2of5 field

Especifica que los datos deben decodificarse con la especificación de código de barras **IATA 2 of 5**. IATA (Asociación Internacional de Transporte Aéreo) utiliza este código de barras para la gestión de carga aérea.

public static readonly SingleDecodeType IATA2of5;
