## AustraliaPostCustomerInformationDecoder interface

Interfaz pública para la decodificación del Campo de Información del Cliente que se utiliza en la simbología AustraliaPost. La implementación debe ser proporcionada por el usuario.

```csharp
public interface AustraliaPostCustomerInformationDecoder
```

## Métodos

| Nombre | Descripción |
| --- | --- |
| [Decode](../../aspose.barcode.barcoderecognition/australiapostcustomerinformationdecoder/decode/)(string) | Decodifica el Campo de Información del Cliente de la simbología AustraliaPost. Puede usarse para diferentes interpretaciones de datos a partir de la codificación NTable y CTable. Los datos se proporcionan como una fila de valores de barra: 0, 1, 2 o 3. |
