## BarCodeResult.Confidence property

Obtiene el nivel de confianza del reconocimiento del código de barras reconocido.

```csharp
public BarCodeConfidence Confidence { get; }
```

### Property Value

Strong no tiene falsificaciones ni errores de reconocimiento, Moderate a veces puede tener falsificaciones o codetext incorrecto porque este nivel de confianza para barcodews con checksum débil o incluso sin él, None siempre tiene codetext incorrecto y podría generar reconocimientos falsos.
