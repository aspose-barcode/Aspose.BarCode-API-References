## BarCodeGeneratorControl.ThrowExceptionWhenCodeTextIncorrect property

Solo para códigos de barras 1D. Si el texto del código es incorrecto y el valor se establece en true, se lanzará una excepción. De lo contrario, el texto del código se corregirá para que coincida con la especificación del código de barras. La excepción siempre se lanzará para: simbología Databar si el texto del código es incorrecto. La excepción nunca se lanzará para: AustraliaPost, SingapurePost, Code39Extended, Code93Extended, Code16K, simbología Code128 si el texto del código es incorrecto.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
