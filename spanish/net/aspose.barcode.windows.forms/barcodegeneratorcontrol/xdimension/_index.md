## BarCodeGeneratorControl.XDimension property

X-dimension es el ancho más pequeño de la unidad de barras o espacios del código de barras. Incrementar esto aumentará el ancho total de la imagen del código de barras. Ignorado si la propiedad [`AutoSizeMode`](../../../aspose.barcode.generation/autosizemode/) está configurada a AutoSizeMode.Nearest o AutoSizeMode.Interpolation.

public Unit XDimension { get; }
