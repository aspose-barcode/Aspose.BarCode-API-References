## AztecParametersUI.LayersCount property

Obtiene o establece la cantidad de capas del símbolo Aztec. La cantidad de capas debe estar en el rango de 1 a 3 para el modo Compact y en el rango de 1 a 32 para el modo Full Range. Valor predeterminado: 0 (auto).

public int LayersCount { get; set; }
