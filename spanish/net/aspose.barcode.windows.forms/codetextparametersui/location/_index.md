## CodetextParametersUI.Location property

Especifique la ubicación de visualización de CodeText, establezca CodeLocation.None para ocultar CodeText. Valor predeterminado: CodeLocation.Below para códigos de barras 1D y CodeLocation.None para códigos de barras 2D.

public CodeLocation Location { get; set; }
