## GS1Codetext.Parse method

Analiza una cadena de elemento GS1 entre corchetes en la forma (AI)value(AI)value. Un '(' literal dentro de un valor debe escribirse como \(; no se admite ninguna otra secuencia de escape, y ')' no requiere escape.

```csharp
public static GS1Codetext Parse(string value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| valor | Cadena | Cadena de elemento GS1 entre corchetes para analizar. |

### Valor de retorno

Un codetexto GS1 analizado.
