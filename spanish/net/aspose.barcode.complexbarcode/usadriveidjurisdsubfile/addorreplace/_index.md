## AddOrReplace(string, string) {#addorreplace_1}

Agrega un nuevo DataElement con el identificador y valor especificados, o reemplaza el elemento existente si ya hay una entrada con el mismo ElementID.

```csharp
public DataElement AddOrReplace(string id, string value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| id | Cadena | Un identificador de 3 letras que especifica de forma única el elemento de datos relacionado con la jurisdicción. |
| valor | Cadena | El valor de texto asignado al elemento de datos; este valor sobrescribirá el existente si el elemento ya existe. |

### Valor de retorno

La instancia DataElement que se agregó a la colección o se actualizó en su lugar.
