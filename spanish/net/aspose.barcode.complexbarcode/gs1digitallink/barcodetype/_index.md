## GS1DigitalLink.BarcodeType property

Obtiene o establece el tipo de código de barras utilizado para codificar este GS1 Digital Link. Los tipos compatibles son QR, DataMatrix, Aztec, Pdf417, MicroPdf417, DotCode, HanXin, CodablockF y Code128. El valor predeterminado es QR.

public BaseEncodeType BarcodeType { get; set; }
