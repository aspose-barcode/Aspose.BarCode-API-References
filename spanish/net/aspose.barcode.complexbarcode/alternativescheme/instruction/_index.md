## AlternativeScheme.Instruction property

Obtiene la instrucción de pago para una factura dada.

La instrucción consiste en una abreviatura de dos letras para el esquema, un carácter separador y una secuencia de parámetros (separados por el carácter en el índice 2).

```csharp
public string Instruction { get; set; }
```

### Property Value

La instrucción de pago.
