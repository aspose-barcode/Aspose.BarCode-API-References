## HIBCLICComplexCodetext.BarcodeType property

Obtiene o establece el tipo de código de barras. El codetext HIBC LIC puede codificarse usando los tipos de codificación HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC y HIBCQRLIC. Valor predeterminado: HIBCCode39LIC.

```csharp
public BaseEncodeType BarcodeType { get; set; }
```

### Valor de retorno

Tipo de código de barras.
