## Address.Town property

Obtiene o establece la ciudad o pueblo.

Al establecer este campo, el tipo de dirección se establece en Structured a menos que ya sea CombinedElements, en cuyo caso se vuelve Conflicting.

Este campo solo se usa para direcciones estructuradas. Para este tipo, es obligatorio.

```csharp
public string Town { get; set; }
```

### Property Value

El pueblo o la ciudad.
