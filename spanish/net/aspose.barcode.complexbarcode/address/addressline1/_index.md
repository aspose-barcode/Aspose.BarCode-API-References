## Address.AddressLine1 property

Obtiene o establece la línea de dirección 1.

La línea de dirección 1 contiene el nombre de la calle, número de casa o apartado de correos.

Al establecer este campo, el tipo de dirección se establece en CombinedElements a menos que ya sea Structured, en cuyo caso se vuelve Conflicting.

Este campo solo se usa para direcciones de elementos combinados y es opcional.

```csharp
public string AddressLine1 { get; set; }
```

### Property Value

La línea de dirección 1.
