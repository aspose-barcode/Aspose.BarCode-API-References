## Address.AddressLine2 property

Obtiene o establece la línea de dirección 2.

Address line 2 contiene el código postal y la ciudad.

Al establecer este campo, el tipo de dirección se establece en CombinedElements a menos que ya sea Structured, en cuyo caso se vuelve Conflicting.

Este campo solo se usa para direcciones de elementos combinados. Para este tipo, es obligatorio.

```csharp
public string AddressLine2 { get; set; }
```

### Property Value

La línea de dirección 2.
