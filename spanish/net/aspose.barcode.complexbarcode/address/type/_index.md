## Address.Type property

Obtiene el tipo de dirección.

El tipo de dirección se establece automáticamente al configurar la calle / número de casa o address line 1 and 2. Antes de establecer los campos, el tipo de dirección es Undetermined. Si se establecen campos de ambos tipos, el tipo de dirección se vuelve Conflicting.

```csharp
public AddressType Type { get; }
```

### Property Value

El tipo de dirección.
