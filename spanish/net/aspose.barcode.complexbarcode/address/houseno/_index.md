## Address.HouseNo property

Obtiene o establece el número de casa.

Al establecer este campo, el tipo de dirección se establece en Structured a menos que ya sea CombinedElements, en cuyo caso se vuelve Conflicting.

Este campo solo se usa para direcciones estructuradas y es opcional.

```csharp
public string HouseNo { get; set; }
```

### Property Value

El número de casa.
