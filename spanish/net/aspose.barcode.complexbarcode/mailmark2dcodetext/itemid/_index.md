## Mailmark2DCodetext.ItemID property

Identifica el elemento único dentro del ID de la cadena de suministro. Cada código de barras Mailmark debe llevar un ID para que pueda ser identificado de forma única durante al menos 90 días. Valor máximo: 99999999.

public int ItemID { get; set; }
