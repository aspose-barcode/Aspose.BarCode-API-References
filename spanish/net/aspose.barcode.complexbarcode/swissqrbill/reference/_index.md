## SwissQRBill.Reference property

Obtiene o establece la referencia de pago del acreedor.

La referencia es obligatoria para los IBAN SwissQR, p.ej. los IBAN en el rango CHxx30000xxxxxx hasta CHxx31999xxxxx.

Si se especifica, la referencia debe ser una referencia SwissQR válida (correspondiente al formulario de referencia ISR) o una referencia de acreedor válida según ISO 11649 (\"RFxxxx\"). Ambas pueden contener espacios para el formato.

```csharp
public string Reference { get; set; }
```

### Property Value

La referencia de pago del acreedor.
