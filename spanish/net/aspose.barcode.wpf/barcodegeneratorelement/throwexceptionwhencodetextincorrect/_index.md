## BarcodeGeneratorElement.ThrowExceptionWhenCodeTextIncorrect property

Solo para códigos de barras 1D. Si el texto del código es incorrecto y el valor se establece en true, se lanzará una excepción. De lo contrario, el texto del código se corregirá para cumplir con la especificación del código de barras.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
