El **BarCode.Common** contiene características comunes y herramientas auxiliares para mantener la funcionalidad principal.

## Clases

| Clase | Descripción |
| --- | --- |
| [GS1Element](./gs1element/) | Representa un par inmutable de identificador de aplicación GS1 y valor. |
| [GS1ValidationException](./gs1validationexception/) | La excepción que se lanza por operaciones estrictas de GS1 cuando la validación falla. |
| [GS1ValidationIssue](./gs1validationissue/) | Describe un error de validación GS1. |
| [GS1ValidationResult](./gs1validationresult/) | Contiene todos los errores detectables de forma independiente para una cadena de elemento GS1, URI Digital Link o un valor AI. |
| [ProcessorSettings](./processorsettings/) | ProcessorSettings permite reconocer códigos de barras con un aumento de rendimiento mediante multihilos. |
## Enumeración

| Enumeración | Descripción |
| --- | --- |
