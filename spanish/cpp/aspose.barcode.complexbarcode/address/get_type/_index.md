## Observaciones


El tipo de dirección se establece automáticamente al configurar la calle / número de casa o la línea de dirección 1 y 2. Antes de establecer los campos, el tipo de dirección es *Undetermined*. Si se establecen campos de ambos tipos, el tipo de dirección se vuelve *Conflicting*.
