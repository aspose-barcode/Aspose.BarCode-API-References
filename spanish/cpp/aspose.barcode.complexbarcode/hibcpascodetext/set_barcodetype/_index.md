## HIBCPASCodetext::set_BarcodeType method


Establece el tipo de código de barras. El codetext HIBC PAS puede codificarse usando los tipos de codificación HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS y HIBCQRPAS. Valor predeterminado: HIBCCode39PAS.
