## Mailmark2DCodetext::get_DestinationPostCodeAndDPS method


Contiene el código postal de la [Address](../../address/) de entrega con DPS. Si es interior, el código postal/DP contiene el siguiente número de caracteres. Área (1 o 2 caracteres) Distrito (1 o 2 caracteres) Sector (1 carácter) Unidad (2 caracteres) DPS (2 caracteres). El código postal y el DPS deben cumplir con un formato PAF® válido.
