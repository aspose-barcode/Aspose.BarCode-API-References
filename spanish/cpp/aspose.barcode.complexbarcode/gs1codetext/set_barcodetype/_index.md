## GS1Codetext::set_BarcodeType method


Establece el tipo de código de barras utilizado para codificar este codetexto GS1. Los tipos compatibles son GS1Aztec, GS1CodablockF, GS1Code128, GS1DataMatrix, GS1DotCode, GS1HanXin, GS1MicroPdf417, GS1QR y tipos GS1 DataBar. El valor predeterminado es GS1Code128.
