## Payments::IsValidIso11649Reference method


Valida si la cadena es un número de referencia ISO 11649 válido

```cpp
static bool Aspose::BarCode::ComplexBarcode::Payments::IsValidIso11649Reference(System::String reference)
```


| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| reference | System::String | La referencia del acreedor ISO 11649 a validar. |

### ReturnValue

**true** if the creditor reference is valid, **false** otherwise.
## Observaciones


La cadena se verifica para caracteres válidos, longitud válida y un dígito de control válido. Los espacios en blanco se ignoran.
