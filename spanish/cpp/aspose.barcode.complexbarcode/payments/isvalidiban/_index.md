## Payments::IsValidIban method


Valida si la cadena es un número IBAN válido

```cpp
static bool Aspose::BarCode::ComplexBarcode::Payments::IsValidIban(System::String iban)
```


| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| iban | System::String | El IBAN a validar. |

### ReturnValue

**true** if the IBAN is valid, **false** otherwise.
## Observaciones


La cadena se verifica para caracteres válidos, longitud válida y un dígito de control válido. Los espacios en blanco se ignoran.
