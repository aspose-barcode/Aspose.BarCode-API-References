## BorderDashStyle enum


Especifica el estilo de las líneas de borde discontinuas.

```cpp
enum class BorderDashStyle
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Sólido | 0 | Especifica una línea sólida. |
| Guión | 1 | Especifica una línea compuesta de guiones. |
| Punto | 2 | Especifica una línea compuesta de puntos. |
| DashDot | 3 | Especifica una línea compuesta de un patrón repetido de guión-punto. |
| DashDotDot | 4 | Especifica una línea que consiste en un patrón repetido de guión-punto-punto. |
