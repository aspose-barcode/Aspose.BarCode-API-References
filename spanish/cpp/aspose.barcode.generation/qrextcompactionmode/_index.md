## QrExtCompactionMode enum


Especifica el modo de compactación QR para el texto de código añadido por [QrExtCodetextBuilder](../qrextcodetextbuilder/).

```cpp
enum class QrExtCompactionMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Automático | 0 | El codificador selecciona automáticamente el modo de compactación QR más eficiente. |
| Numérico | 1 | Codifica el texto de código en modo QR Numérico. Solo se permiten dígitos del 0 al 9. |
| Alfanumérico | 2 | Codifica el texto de código en modo QR Alfanumérico. |
| Bytes | 3 | Codifica el texto de código en modo QR Byte. |
| Kanji | 4 | Codifica el texto de código en modo QR Kanji. |
