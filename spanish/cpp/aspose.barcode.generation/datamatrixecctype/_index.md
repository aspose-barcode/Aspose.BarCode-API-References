## DataMatrixEccType enum


Especifique el tipo de ECC a codificar.

```cpp
enum class DataMatrixEccType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| EccAuto | 0 | Especifica que el tipo de ECC codificado se define por la corrección de errores Reed‑Solomon por defecto o ECC 200. |
| Ecc000 | 1 | Especifica que el tipo de ECC codificado se define como ECC 000. |
| Ecc050 | 2 | Especifica que el tipo de ECC codificado se define como ECC 050. |
| Ecc080 | 3 | Especifica que el tipo de ECC codificado se define como ECC 080. |
| Ecc100 | 4 | Especifica que el tipo de ECC codificado se define como ECC 100. |
| Ecc140 | 5 | Especifica que el tipo de ECC codificado se define como ECC 140. |
| Ecc200 | 6 | Especifica que el tipo de ECC codificado se define como ECC 200. Se recomienda usarlo. |
