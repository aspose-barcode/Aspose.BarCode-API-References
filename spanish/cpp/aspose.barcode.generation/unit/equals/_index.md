## Unit::Equals method


Determina si esta instancia y un objeto especificado, que también debe ser un objeto [Unit](../), tienen el mismo valor.

```cpp
bool Aspose::BarCode::Generation::Unit::Equals(System::SharedPtr<System::Object> obj) override
```


| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| obj | System::SharedPtr\<System::Object\> | El [Unit](../) para comparar con esta instancia. |

### ReturnValue

true si obj es un [Unit](../) y su valor es el mismo que esta instancia; de lo contrario, false. Si obj es null, el método devuelve false.
