## Pdf417MacroTerminator enum


Se utiliza para indicar al codificador si debe agregar el terminador Macro PDF417 (código de palabra 922) al segmento. Aplicado solo para Macro PDF417.

```cpp
enum class Pdf417MacroTerminator
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Automático | 0 | El terminador se agregará automáticamente si se proporciona el número de segmentos y el segmento actual es el último. En otros casos, el terminador no se agregará. |
| Ninguno | 1 | El terminador no se agregará. |
| Set | 2 | El terminador se agregará. |
