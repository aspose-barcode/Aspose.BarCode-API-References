## PZN field


Representa el código de barras PZN. Esta simbología también se conoce como Pharmacy central number, Pharmazentralnummer. Se admiten PZN7 y PZN8. PZN7 se genera a partir de 6 o menos dígitos, como "123456". PZN8 se genera a partir de 7 o más dígitos, como "1234567". El último dígito de checksum proporcionado se ignora y es generado por el motor del código de barras.
