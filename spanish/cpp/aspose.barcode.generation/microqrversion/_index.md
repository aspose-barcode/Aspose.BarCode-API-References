## MicroQRVersion enum


Versión del MicroQR Code. Desde M1 hasta M4.

```cpp
enum class MicroQRVersion
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Automático | 0 | Especifica que se seleccione automáticamente la mejor versión para MicroQR. Este es el valor predeterminado. |
| M1 | 1 | Especifica la versión M1 para Micro QR con módulos de 11 x 11. |
| M2 | 2 | Especifica la versión M2 para Micro QR con módulos de 13 x 13. |
| M3 | 3 | Especifica la versión M3 para Micro QR con módulos de 15 x 15. |
| M4 | 4 | Especifica la versión M4 para Micro QR con módulos de 17 x 17. |
