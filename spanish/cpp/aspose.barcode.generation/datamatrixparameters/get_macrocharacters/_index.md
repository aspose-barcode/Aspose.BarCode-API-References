## DataMatrixParameters::get_MacroCharacters method


Los valores Macro Characters 05 y 06 se utilizan para obtener una codificación más compacta en modos especiales. Solo se pueden usar con [DataMatrixEccType.Ecc200](../../datamatrixecctype/) o [DataMatrixEccType.EccAuto](../../datamatrixecctype/). No se pueden usar con [EncodeTypes.GS1DataMatrix](../../encodetypes/gs1datamatrix/). Valor predeterminado: [MacroCharacters.None](../../barcodeclassifications/).
