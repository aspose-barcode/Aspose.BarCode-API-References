Obtener o establecer el algoritmo de suma de verificación para códigos de barras Codabar. Valor predeterminado: [CodabarChecksumMode.Mod16](../../codabarchecksummode/). Para habilitar el cálculo de la suma de verificación, establezca el valor [EnableChecksum.Yes](../../enablechecksum/) en la propiedad EnableChecksum. Ver [ChecksumMode](../).
