## BarcodeParameters::get_WideNarrowRatio method


Relación de barras anchas a barras estrechas. Valor predeterminado: 3, es decir, las barras anchas son 3 veces más anchas que las barras estrechas. Utilizado para ITF, PZN, PharmaCode, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, IATA2of5, VIN, DeutschePost, OPC, Code32, DataLogic2of5, PatchCode, Code39, Code39FullASCII.

```cpp
float Aspose::BarCode::Generation::BarcodeParameters::get_WideNarrowRatio() const
```

## Observaciones



El valor del parámetro **WideNarrowRatio** es menor o igual a 0.
