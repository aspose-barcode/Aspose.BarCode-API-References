## Pdf417MacroTerminator enumeration

Används för att tala om för kodaren om Macro PDF417 Terminator (kodord 922) ska läggas till i segmentet. Tillämpas endast för Macro PDF417.

```csharp
public enum Pdf417MacroTerminator
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Auto | `0` | Terminatorn kommer att läggas till automatiskt om antalet segment anges och det aktuella segmentet är det sista. I andra fall kommer terminatoren inte att läggas till. |
| None | `1` | Terminatorn kommer inte att läggas till. |
| Set | `2` | Terminatorn kommer att läggas till. |
