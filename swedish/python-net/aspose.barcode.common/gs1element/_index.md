## GS1Element class

Representerar ett oföränderligt GS1-applikationsidentifierare och värdepar.

Typen GS1Element exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| application_identifier | Hämtar den exakta GS1 Application Identifier. |
| value | Hämtar det validerade värdet som är associerat med Application Identifier. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| validate(application_identifier, value) | Validerar ett värde för en exakt GS1 Application Identifier. |
