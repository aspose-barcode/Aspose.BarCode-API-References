## GS1ValidationIssue class

Beskriver ett GS1-valideringsfel.

Typen GS1ValidationIssue exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| code | Hämtar en stabil maskinläsbar felkod. |
| application_identifier | Hämtar applikationsidentifieraren som är relaterad till felet, eller null när applikationsidentifieraren<br/>            inte kunde bestämmas från indata. |
| message | Hämtar det människoläsbara felmeddelandet. |
