## ProcessorSettings class

ProcessorSettings möjliggör att känna igen streckkoder med flerkärnig prestandaökning

Typen ProcessorSettings exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| use_all_cores | Behövs för att använda alla kärnor. |
| use_only_this_cores_count | Ange antalet kärnor som ska användas. <br/>            Du måste ändra egenskapen "UseAllCores" till "false". |
| max_additional_allowed_threads | Ange det maximala antalet ytterligare trådar för att köra kod parallellt |
