## SvgColorMode enumeration

Möjliga lägen för fyllningsfärg i svg-fil, RGB är standard och stöds av SVG 1.1.<br/>            RGBA, HSL, HSLA är tillåtna i SVG 2.0-standarden.<br/>            Även i RGB kommer opacitet att sättas via parametern \"fill-opacity\".

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| RGB | RGB-läge, exempel: fill="#ff5511" fill-opacity="0.73". Standardläge. |
| RGBA | RGBA-läge, exempel: fill="rgba(255, 85, 17, 0.73)" |
| HSL | HSL-läge, exempel: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | HSLA-läge, exempel: fill="hsla(30, 50%, 70%, 0.8)" |
