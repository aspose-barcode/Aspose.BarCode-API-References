## FontUnit class

Definierar ett specifikt format för text, inklusive teckensnitt, storlek och stilattribut<br/>            där storlek i enhetsvärdeegenskapen.

FontUnit-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| family_name | Hämtar eller anger teckensnittets namn för detta Font. |
| style | Hämtar eller anger stilinformation för detta FontUnit. |
| size | Hämtar eller anger storleken på detta FontUnit i enhetsvärde. |
