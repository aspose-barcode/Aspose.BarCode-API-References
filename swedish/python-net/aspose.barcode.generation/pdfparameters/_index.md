## PdfParameters class

PDF-parametrar.

PdfParameters-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| cmyk_bar_color | Nullable. CMYK-färgvärde för streckkod. Null betyder att CMYK-färg inte används, utan normal RGB-färg används. |
| cmyk_back_color | Nullable. CMYK-bakgrundsfärgvärde. Null betyder att CMYK-färg inte används, utan normal RGB-färg används. |
| cmyk_codetext_color | Nullable. CMYK-färgvärde för kodtext. Null betyder att CMYK-färg inte används, utan normal RGB-färg används. |
| cmyk_caption_above_color | Nullable. CMYK-färgvärde för rubrik ovanför. Null betyder att CMYK-färg inte används, utan normal RGB-färg används. |
| cmyk_caption_below_color | Nullable. CMYK-färgvärde för rubrik nedanför. Null betyder att CMYK-färg inte används, utan normal RGB-färg används. |
| is_text_as_path | Används sökvägar istället för text (använd om Unicode-tecken inte visas)<br/>            Standardvärde: false. |
