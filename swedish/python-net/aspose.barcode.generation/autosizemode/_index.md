## AutoSizeMode enumeration

Anger de olika typerna av automatiska storlekslägen.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Automatisk storleksändring är inaktiverad. |
| NEAREST | Ändrar streckkodens storlek till närmaste lägsta möjliga storlek som anges av egenskaperna ImageWidth och ImageHeight.<br/>            Bevarar standardförhållandet. |
| INTERPOLATION | Ändrar streckkodens storlek till angiven storlek.<br/>            Storleken kan anges med egenskaperna ImageWidth och ImageHeight.<br/>            Genererad streckkod kan bli ogiltig (ej läsbar) efter skalning. |
