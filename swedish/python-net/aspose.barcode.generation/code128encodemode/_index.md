## Code128EncodeMode enumeration

Kodningsläge för Code128-streckkoder.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| AUTO | Koda kodtext i klassiskt ISO 15417-läge. Läget bör användas i alla vanliga fall. |
| CODE_A | Koda kodtext endast i 128A-koduppsättning. |
| CODE_B | Koda kodtext endast i 128B-koduppsättning. |
| CODE_C | Koda kodtext endast i 128C-koduppsättning. |
| CODE_AB | Koda kodtext endast i 128A- och 128B-koduppsättningar. |
| CODE_AC | Koda kodtext endast i 128A- och 128C-koduppsättningar. |
| CODE_BC | Koda kodtext endast i 128B- och 128C-koduppsättningar. |
