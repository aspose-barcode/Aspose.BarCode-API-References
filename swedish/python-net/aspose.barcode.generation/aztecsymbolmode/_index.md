## AztecSymbolMode enumeration

Anger Aztec-symbolläget.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| AUTO | Anger att automatiskt välja den bästa symbolen (Compact eller Full-range) för Aztec.<br/>            Detta är standardvärdet. |
| COMPACT | Anger den Compact-symbolen för Aztec.<br/>            Aztec Compact-symbolen tillåter endast 1, 2, 3 eller 4 lager. |
| FULL_RANGE | Anger den Full-range-symbolen för Aztec.<br/>            Aztec Full-range-symbolen tillåter från 1 till 32 lager. |
| RUNE | Anger Rune-symbolen för Aztec.<br/>            Aztec Runes är en serie av små men distinkta maskinläsbara märken. Den tillåter endast talvärden från 0 till 255. |
