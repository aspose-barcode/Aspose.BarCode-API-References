## ExtCodetextBuilder class

Hjälparklass för automatisk generering av codetext i Extended Codetext Mode.

Typen ExtCodetextBuilder exponerar följande medlemmar:
## Metoder
| Namn | Beskrivning |
| :- | :- |
| clear() | Rensar utökade kodtextobjekt |
| add_plain_codetext(codetext) | Lägger till vanlig kodtext till de utökade kodtextobjekten |
| add_eci_codetext(eci_encoding, codetext) | Lägger till kodtext med Extended Channel Identifier |
| get_extended_codetext() | Generera utökad kodtext från lista med genereringsobjekt |
