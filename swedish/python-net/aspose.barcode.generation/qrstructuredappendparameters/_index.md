## QrStructuredAppendParameters class

QR structured append-parametrar.

Typen QrStructuredAppendParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| parity_byte | Hämtar eller anger paritetsdata för QR structured append-läge. |
| sequence_indicator | Hämtar eller anger index för QR structured append-lägesstreckkoden. Index startar från 0. |
| total_count | Hämtar eller anger antalet streckkoder för QR structured append-läget. Maxvärdet är 16. |
