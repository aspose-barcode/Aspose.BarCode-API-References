## ITFParameters class

ITF-parametrar.

Typen ITFParameters exponeras med följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| border_thickness | Hämtar eller anger tjockleken på en ITF‑kant (bärare‑stapel) i enhetsvärde.<br/>            Standardvärde: 12pt. |
| border_type | Kanttyp för ITF‑streckkod.<br/>            Standardvärde: ITF14BorderType.Bar. |
| quiet_zone_coef | Storlek på de tysta zonerna i xDimension.<br/>            Standardvärde: 10, vilket betyder att om xDimension = 2px så blir de tysta zonerna 20px. |
