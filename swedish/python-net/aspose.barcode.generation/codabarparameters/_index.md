## CodabarParameters class

Codabar-parametrar.

Typen CodabarParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| checksum_mode | Hämta eller ange kontrollsummealgoritmen för Codabar-streckkoder.<br/>            Standardvärde: CodabarChecksumMode.Mod16.<br/>            För att aktivera kontrollsummeberäkning, sätt värdet EnableChecksum.Yes till egenskapen EnableChecksum.<br/>            Se [checksum_mode](/barcode/python-net/aspose.barcode.generation/codabarparameters/). |
| start_symbol | Startsymbol (tecken) för Codabar-symbologi.<br/>            Standardvärde: CodabarSymbol.A |
| stop_symbol | Stopsymbol (tecken) för Codabar-symbologi.<br/>            Standardvärde: CodabarSymbol.A |
