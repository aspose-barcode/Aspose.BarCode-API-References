## HanXinParameters class

Han Xin-parametrar.

HanXinParameters-typen visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| version | Version av HanXin Code.<br/>            Från Version01 till Version84 för Han Xin-kod.<br/>            Standardvärde är Version.Auto. |
| error_level | Nivå för Reed-Solomon felkorrigering för Han Xin-streckkod.<br/>             Från låg till hög: L1, L2, L3, L4. se ErrorLevel. |
| encode_mode | HanXin kodningsläge.<br/>            Standardvärde: EncodeMode.Mixed. |
| eci_encoding | Extended Channel Interpretation Identifierare. Det används för att informera streckkodsläsaren om detaljer<br/>            om de använda referenserna för kodning av data i symbolen.<br/>            Nuvarande implementation innehåller alla välkända teckenuppsättningskodningar. |
