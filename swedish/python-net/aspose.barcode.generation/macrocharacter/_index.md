## MacroCharacter enumeration

Macrotecken 05 och 06 används för att erhålla en mer kompakt kodning i speciallägen.<br/>            05 Macro-tecken översätts till "[)>\\u001E05\\u001D" som avkodad datatopp och "\\u001E\\u0004" som avkodad databotten.<br/>            06 Macro-tecken översätts till "[)>\\u001E06\\u001D" som avkodad datatopp och "\\u001E\\u0004" som avkodad databotten.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Inga makrotecken läggs till streckkodsdatan |
| MACRO05 | 05 makrotecken läggs till streckkodsdatan i första positionen.<br/>            GS1 Data Identifier ISO 15434<br/>            Tecknet översätts till "[)>\u001E05\u001D" som avkodad datahuvud och "\u001E\u0004" som avkodad databotten. |
| MACRO06 | 06 makrotecken läggs till streckkodsdatan i första positionen.<br/>            ASC MH10 Data Identifier ISO 15434<br/>            Tecknet översätts till "[)>\u001E06\u001D" som avkodad datahuvud och "\u001E\u0004" som avkodad databotten. |
