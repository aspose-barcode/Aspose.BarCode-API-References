## Pdf417MacroTerminator enumeration

Används för att tala om för kodaren om Macro PDF417 Terminator (kodord 922) ska läggas till segmentet. <br/>            Tillämpas endast för Macro PDF417.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| AUTO | Termineringen kommer att läggas till automatiskt om antalet segment anges <br/>            och det aktuella segmentet är det sista. I andra fall kommer termineringen inte att läggas till. |
| NONE | Termineringen kommer inte att läggas till. |
| SET | Termineringen kommer att läggas till. |
