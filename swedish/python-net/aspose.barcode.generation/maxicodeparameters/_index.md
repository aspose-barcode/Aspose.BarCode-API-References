## MaxiCodeParameters class

MaxiCode-parametrar.

Typen MaxiCodeParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| mode | Hämtar eller anger ett MaxiCode kodningsläge. |
| encode_mode | Hämtar eller anger ett MaxiCode-kodningsläge. <br/>            Standardvärde: Auto. |
| eci_encoding | Hämtar eller anger ECI-kodning. Används när MaxiCodeEncodeMode är Auto.<br/>            Standardvärde: ISO-8859-1 |
| structured_append_mode_barcode_id | Hämtar eller anger ett MaxiCode streckkod-id i strukturerat tilläggsläge. <br/>            ID måste vara ett värde mellan 1 och 8. <br/>            Standardvärde: 0 |
| structured_append_mode_barcodes_count | Hämtar eller anger antalet MaxiCode-streckkoder i strukturerat tilläggsläge. <br/>            Antalet måste vara ett värde mellan 2 och 8 (maximalt antal streckkoder).<br/>            Standardvärde: -1 |
| aspect_ratio | Höjd/Bredd-förhållande för 2D BarCode-modulen. |
