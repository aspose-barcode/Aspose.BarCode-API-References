## QRErrorLevel enumeration

Nivå för Reed-Solomon-felkorrigering. Från låg till hög: LevelL, LevelM, LevelQ, LevelH.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| LEVEL_L | Felkorrigering nivå L kan tillämpas på QR- och MicroQR-streckkoder.<br/>            Tillåter återställning av 7 % av kodtexten. |
| LEVEL_M | Felkorrigering nivå M kan tillämpas på QR-streckkoder, RectMicroQR-streckkoder och MicroQR-streckkoder med versioner från M2 till M4.<br/>            Tillåter återställning av 15 % av kodtexten. |
| LEVEL_Q | Felkorrigering nivå Q kan tillämpas på QR-streckkoder och MicroQR-streckkoder med version M4.<br/>            Tillåter återställning av 25 % av kodtexten. |
| LEVEL_H | Felkorrigering nivå H kan tillämpas på QR- och RectMicroQR-streckkoder.<br/>            Tillåter återställning av 30 % av kodtexten. |
