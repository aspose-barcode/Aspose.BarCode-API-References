## PatchCodeParameters class

PatchCode-parametrar.

Typen PatchCodeParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| extra_barcode_text | Anger kodtext för en extra QR-streckkod när PatchCode genereras i sidläge. |
| format | PatchCode-format. Välj PatchOnly för att generera en enskild PatchCode. Använd sidformat för att generera en Patch-sida med PatchCodes som kanter.<br/>            Standardvärde: PatchFormat.PatchOnly |
| patch_format | PatchCode-format. Välj PatchOnly för att generera en enskild PatchCode. Använd sidformat för att generera en Patch-sida med PatchCodes som kanter.<br/>            Standardvärde: PatchFormat.PatchOnly |
