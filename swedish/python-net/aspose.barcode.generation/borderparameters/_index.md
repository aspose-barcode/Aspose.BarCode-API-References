## BorderParameters class

Parametrar för streckkodsbildens kant

Typen BorderParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| visible | Kantens synlighet. Om falskt ignoreras parametern Width alltid (0).<br/>            Standardvärde: false. |
| width | Kantbredd.<br/>            Standardvärde: 0.<br/>            Ignoreras om Visible är satt till falskt. |
| dash_style | Kantens streckstil.<br/>            Standardvärde: BorderDashStyle.Solid. |
| färg | Kantfärg.<br/>            Standardvärde: Color.Black. |
