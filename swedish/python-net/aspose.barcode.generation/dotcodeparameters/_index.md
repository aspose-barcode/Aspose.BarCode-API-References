## DotCodeParameters class

DotCode-parametrar.

Typen DotCodeParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| aspect_ratio | Höjd/Bredd-förhållande för 2D BarCode-modulen. |
| encode_mode | Identifierar DotCode‑kodningsläge. <br/>            Standardvärde: Auto. |
| is_reader_initialization | Indikerar om koden används för att instruera läsaren att tolka följande data som instruktioner för initiering eller omprogrammering av streckkodsläsaren.<br/>            Standardvärdet är falskt. |
| structured_append_mode_barcode_id | Identifierar ID för DotCode strukturerade tilläggsläges‑streckkod. ID börjar på 1 och måste vara mindre än eller lika med antalet streckkoder. Standardvärde är -1. |
| structured_append_mode_barcodes_count | Identifierar antalet streckkoder för DotCode strukturerade tilläggsläge. Standardvärde är -1. Antalet måste vara ett värde mellan 1 och 35. |
| eci_encoding | Identifierar ECI‑kodning. Används när DotCodeEncodeMode är Auto.<br/>            Standardvärde: ISO-8859-1 |
| rader | Identifierar antalet rader. Summan av antalet rader och kolumner i en DotCode‑symbol måste vara udda. Antalet rader måste vara minst 5.<br/>            Standardvärde: -1 |
| kolumner | Identifierar antalet kolumner. Summan av antalet rader och kolumner i en DotCode‑symbol måste vara udda. Antalet kolumner måste vara minst 5.<br/>            Standardvärde: -1 |
