## Code16KParameters class

Code16K-parametrar.

Typen Code16KParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| aspect_ratio | Höjd/Bredd-förhållande för 2D BarCode-modulen. |
| quiet_zone_left_coef | Storleken på den vänstra tysta zonen i xDimension.<br/>            Standardvärde: 10, vilket betyder att om xDimension = 2px blir den vänstra tysta zonen 20px. |
| quiet_zone_right_coef | Storleken på den högra tysta zonen i xDimension.<br/>            Standardvärde: 1, vilket betyder att om xDimension = 2px blir den högra tysta zonen 2px. |
