## SvgParameters class

SVG-parametrar.

Typen SvgParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_explicit_size_in_pixels | Innehåller SVG-bilden explicit storlek i pixlar (rekommenderas)<br/>            Standardvärde: true. |
| is_text_drawn_in_text_element | Innehåller SVG-bilden text som textelement snarare än banor (rekommenderas)<br/>            Standardvärde: true. |
| svg_color_mode | Möjliga lägen för fyllningsfärg i svg-fil, RGB är standard och stöds av SVG 1.1.<br/>            RGBA, HSL, HSLA är tillåtna i SVG 2.0-standarden.<br/>            Även i RGB kommer opacitet att sättas via parametern \"fill-opacity\". |
