## CaptionParameters class

Bildtextparametrar.

Typen CaptionParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| text | Bildtext.<br/>            Standardvärde: tom sträng. |
| font | Bildtextens teckensnitt.<br/>            Standardvärde: Arial 8pt regular. |
| visible | Bildtextens synlighet.<br/>            Standardvärde: false. |
| text_color | Bildtextens färg.<br/>            Standardvärde: Color.Black. |
| padding | Bildtextens marginaler.<br/>            Standardvärde för CaptionAbove: 5pt 5pt 0 5pt.<br/>            Standardvärde för CaptionBelow: 0 5pt 5pt 5pt. |
| justering | Bildtextens horisontella justering.<br/>            Standardvärde: StringAlignment.Center. |
| no_wrap | Ange radbrytningar (linjebrott) i texten.<br/>            Standardvärde: false. |
