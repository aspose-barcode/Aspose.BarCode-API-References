## HIBCLICComplexCodetext class

Bas‑klass för kodning och avkodning av texten som är inbäddad i HIBC LIC-koden.

Typen HIBCLICComplexCodetext exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| barcode_type | Hämtar eller anger streckkodstyp. HIBC LIC-kodtext kan kodas med HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC och HIBCQRLIC kodningstyper.<br/>            Standardvärde: HIBCCode39LIC. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| get_constructed_codetext() | Skapar kodtext |
| init_from_string(constructed_codetext) | Initierar instans från konstruerad kodtext. |
| get_barcode_type() | Hämtar streckkodstyp. |
