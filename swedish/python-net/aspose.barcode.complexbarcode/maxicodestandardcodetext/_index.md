## MaxiCodeStandardCodetext class

Klass för kodning och avkodning av MaxiCode‑kodtext för lägena 4, 5 och 6.

Typen MaxiCodeStandardCodetext exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| MaxiCodeStandardCodetext() | Initierar en ny instans av klassen MaxiCodeStandardCodetext |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| encode_mode | Hämtar eller anger ett MaxiCode-kodningsläge. <br/>            Standardvärde: Auto. |
| eci_encoding | Hämtar eller anger ECI-kodning. Används när MaxiCodeEncodeMode är Auto.<br/>            Standardvärde: ISO-8859-1 |
| mode | Hämtar eller anger MaxiCode-läge. Standardkodtext kan endast användas med lägena 4, 5 och 6. |
| message | Hämtar eller anger meddelande. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| get_mode() | Hämtar MaxiCode-läge. |
| get_constructed_codetext() | Skapar kodtext |
| init_from_string(constructed_codetext) | Initierar instans från konstruerad kodtext. |
| get_barcode_type() | Hämtar streckkodstyp. |
