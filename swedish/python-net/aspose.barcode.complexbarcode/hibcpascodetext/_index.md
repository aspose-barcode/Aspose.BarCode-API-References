## HIBCPASCodetext class

Klass för kodning och avkodning av texten som är inbäddad i HIBC PAS-koden.

Typen HIBCPASCodetext exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| HIBCPASCodetext() | Initierar en ny instans av klassen HIBCPASCodetext |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| barcode_type | Hämtar eller anger streckkodstyp. HIBC PAS-kodtext kan kodas med HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS och HIBCQRPAS kodningstyper.<br/>            Standardvärde: HIBCCode39PAS. |
| data_location | Identifierar dataplats. |

| init_from_string(constructed_codetext) | Initierar instans från konstruerad kodtext. |
