## CustomerInformationInterpretingType enumeration

Definierar tolknings‑typen (CTable, NTable eller Other) för kundinformation för AustralianPost BarCode.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| C_TABLE | Använd CTable för att tolka kundinformationen. Tillåter A..Z, a..z, 1..9, mellanslag och #-tecken. |
| N_TABLE | Använd NTable för att tolka kundinformationen. Tillåter siffror. |
| OTHER | Tolkar inte kundinformationen. Tillåter endast 0, 1, 2 eller 3 symboler. |
