## BuildVersionInfo class

Innehåller information om den aktuella byggversionen.

Typen BuildVersionInfo exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| ASSEMBLY_VERSION | Assemblies versionen. |
| FILE_VERSION | Filens version. |
| PRODUCT | Produktens titel. |
| PRODUCT_MAJOR | Den huvudsakliga produktversionen. |
| PRODUCT_MINOR | Den mindre produktversionen. |
| RELEASE_DATE | Produktens releasedatum. |
