## CodabarExtendedParameters class

Lagrar ytterligare information för Codabar för igenkänd streckkod

Typen CodabarExtendedParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| start_symbol | Hämtar eller anger en Codabar startsymbol.<br/>            Standardvärde: CodabarSymbol.A |
| stop_symbol | Hämtar eller anger en Codabar stopsymbol.<br/>            Standardvärde: CodabarSymbol.A |
