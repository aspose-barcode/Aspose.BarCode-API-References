## BarCodeRegionParameters class

Representerar den igenkända streckkodens region och streckkodsvinkel

Typen BarCodeRegionParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| quadrangle | Hämtar [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) som avgränsar streckkodsområdet |
| vinkel | Hämtar vinkeln på streckkoden (0-360). |
| points | Hämtar en array av [Point](/barcode/python-net/aspose.drawing/point/) som avgränsar streckkodsområdet |
| rektangel | Hämtar avgränsande streckkodsområde |
