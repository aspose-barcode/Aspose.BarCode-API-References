## DataMatrixExtendedParameters class

Lagrar specialdata för DataMatrix-igenkänd streckkod

Typen DataMatrixExtendedParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| structured_append_barcodes_count | Hämtar antalet streckkoder i DataMatrix structured append‑läge. Standardvärdet är -1. Antalet måste vara ett värde mellan 1 och 35. |
| structured_append_barcode_id | Hämtar ID‑t för DataMatrix structured append‑streckkoden. ID börjar på 1 och måste vara mindre än eller lika med antalet streckkoder. Standardvärdet är -1. |
| structured_append_file_id | Hämtar ID‑t för DataMatrix structured append‑streckkoden. ID börjar på 1 och måste vara mindre än eller lika med antalet streckkoder. Standardvärdet är -1. |
| is_reader_programming | Indikerar om koden används för att instruera läsaren att tolka följande data som instruktioner för initiering eller omprogrammering av streckkodsläsaren.<br/>            Standardvärdet är falskt. |
