## AztecExtendedParameters class

Lagrar specialdata för Aztec igenkänd streckkod

Typen AztecExtendedParameters visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| structured_append_barcodes_count | Hämtar antalet streckkoder i Aztec strukturerade tilläggsläge. Standardvärdet är 0. Antalet måste vara ett värde mellan 1 och 26. |
| structured_append_barcode_id | Hämtar ID för Aztec strukturerade tilläggslägesstreckkod. ID börjar från 1 och måste vara mindre än eller lika med antalet streckkoder. Standardvärdet är 0. |
| structured_append_file_id | Hämtar fil-ID för Aztec strukturerade tilläggsläge. Standardvärdet är en tom sträng |
| is_reader_initialization | Indikerar om koden används för att instruera läsaren att tolka följande data som instruktioner för initiering eller omprogrammering av streckkodsläsaren.<br/>            Standardvärdet är falskt. |
