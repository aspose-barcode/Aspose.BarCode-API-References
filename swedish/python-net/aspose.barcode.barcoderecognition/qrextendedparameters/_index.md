## QRExtendedParameters class

Lagrar QR Structured Append‑information för en igenkänd streckkod.

Typen QRExtendedParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| structured_append_mode_bar_codes_quantity | Hämtar antalet streckkoder i QR:s strukturerade tilläggsläge. Standardvärdet är -1. |
| structured_append_mode_bar_code_index | Hämtar indexet för QR:s strukturerade tilläggsläges streckkod. Indexet börjar på 0. Standardvärdet är -1. |
| structured_append_mode_parity_data | Hämtar paritetsdata för QR:s strukturerade tilläggsläge. Standardvärdet är -1. |
| version | Version av identifierad QR-kod. Från Version1 till Version40. |
| micro_qr_version | Version av identifierad MicroQR-kod. Från M1 till M4. |
| rect_micro_qr_version | Version av identifierad RectMicroQR-kod. Från R7x43 till R17x139. |
| error_level | Reed-Solomon felkorrigeringsnivå för identifierad streckkod. Från låg till hög: LevelL, LevelM, LevelQ, LevelH. |
