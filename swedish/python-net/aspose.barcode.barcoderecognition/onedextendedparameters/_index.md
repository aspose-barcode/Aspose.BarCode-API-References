## OneDExtendedParameters class

Lagrar speciella data för 1D‑igenkänd streckkod, såsom separat kodtext och kontrollsumma.

Typen OneDExtendedParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| value | Hämtar kodtexten för 1D-streckkoder utan kontrollsumma. |
| check_sum | Hämtar kontrollsumman för 1D-streckkoder. |
