## MaxiCodeExtendedParameters class

Lagrar extra information för MaxiCode‑igenkänd streckkod.

Typen MaxiCodeExtendedParameters visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| mode | Hämtar eller anger ett MaxiCode-kodningsläge.<br/>            Standardvärde: Mode4 |
| structured_append_mode_barcode_id | Hämtar eller anger ett MaxiCode-streckkodsid i strukturerat tilläggsläge.<br/>            Standardvärde: 0 |
| structured_append_mode_barcodes_count | Hämtar eller anger antalet MaxiCode-streckkoder i strukturerat tilläggsläge.<br/>            Standardvärde: -1 |
