## Pdf417ExtendedParameters class

Lagrar metadata för MacroPdf417 för en igenkänd streckkod.

Typen Pdf417ExtendedParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| macro_pdf_417_file_id | Hämtar fil-ID för streckkoden, endast tillgängligt med MacroPdf417. |
| macro_pdf_417_segment_id | Hämtar segment-ID för streckkoden, endast tillgängligt med MacroPdf417. |
| macro_pdf_417_segments_count | Hämtar antalet segment för macro pdf417-streckkod. Standardvärdet är -1. |
| macro_pdf_417_file_name | Macro PDF417 filnamn (valfritt). |
| macro_pdf_417_file_size | Macro PDF417 filstorlek (valfritt). |
| macro_pdf_417_sender | Macro PDF417 avsändarnamn (valfritt). |
| macro_pdf_417_addressee | Macro PDF417 mottagarnamn (valfritt). |
| macro_pdf_417_time_stamp | Macro PDF417 tidsstämpel (valfritt). |
| macro_pdf_417_checksum | Macro PDF417 kontrollsumma (valfritt). |
| macro_pdf_417_terminator | Indikerar om segmentet är det sista segmentet i en Macro PDF417-fil. |
| is_reader_initialization | Används för att instruera läsaren att tolka data som finns i symbolen som programmering för läsarinitialisering. |
| is_linked | Flagga som indikerar att streckkoden måste länkas till en 1D-streckkod. |
| is_code_128_emulation | Flagga som indikerar att MicroPdf417-streckkoden är kodad med 908, 909, 910 eller 911 Code 128-emuleringskodord. |
