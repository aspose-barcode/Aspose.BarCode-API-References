## BarcodeSettings class

De huvudsakliga BarCode-avkodningsparametrarna. Innehåller parametrar som påverkar den igenkända datan.

Typen BarcodeSettings exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Ta bort FNC1-, FNC2- och FNC3-tecken från kodtexten. Standardvärdet är falskt. |
| only_requested_types | Returnerar endast streckkodstyper som uttryckligen specificerats för igenkänning. <br/>            När aktiverad filtreras igenkända streckkoder av andra kompatibla eller motsvarande typer bort. <br/>            Standardvärdet är falskt. |
| detect_encoding | Flaggan som tvingar motorn att upptäcka kodtextens kodning för Unicode-teckenuppsättningar. Standardvärdet är sant. |
| australia_post | Hämtar avkodningsparametrar för AustraliaPost |
| calculate_symbol_quality | Hämtar eller anger ett värde som indikerar om streckkodssymbolens kvalitet ska beräknas under igenkänning. |
