## AustraliaPostSettings class

Avkodningsparametrar för AustraliaPost. Innehåller parametrar som påverkar den igenkända datan för AustraliaPost-symbologi.

Typen AustraliaPostSettings visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| customer_information_interpreting_type | Hämtar eller anger tolkningstypen för kundinformation i AustralianPost BarCode. Standard är CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | Flaggan som tvingar AustraliaPost-dekodern att ignorera sista fyllningsmönstren i kundinformationsfältet under avkodning som CTable-metod.<br/>            CTable-kodningsmetoden har inga luckor i kodningstabellen och sekvensen "333" av fyllningsmönster avkodas som bokstaven "z". |
| customer_information_decoder | Offentlig gränssnitt för avkodning av kundinformationsfält som används i AustraliaPost-symbologi. |
