## Quadrangle class

Lagrar en uppsättning av fyra [Point](/barcode/python-net/aspose.drawing/point/) som representerar ett [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/)‑område.

Typen Quadrangle exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Quadrangle() | Initierar en ny tom instans av klassen [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Initierar en ny instans av Quadrangle-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| left_top | Hämtar vänster-övre hörn [Point](/barcode/python-net/aspose.drawing/point/) av [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) regionen |
| right_top | Hämtar höger-övre hörn [Point](/barcode/python-net/aspose.drawing/point/) av [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) regionen |
| right_bottom | Hämtar höger-nedre hörn [Point](/barcode/python-net/aspose.drawing/point/) av [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) regionen |
| left_bottom | Hämtar vänster-nedre hörn [Point](/barcode/python-net/aspose.drawing/point/) av [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) regionen |
| is_empty | Testar om alla [Point](/barcode/python-net/aspose.drawing/point/) i detta [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) har värdena noll. |
| bounding_rectangle | Hämtar [Rectangle](/barcode/python-net/aspose.drawing/rectangle/) som omger detta [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| EMPTY | Representerar en [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) klass med dess egenskaper oinitierade. |
