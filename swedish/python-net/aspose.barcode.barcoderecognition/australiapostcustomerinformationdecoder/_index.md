## AustraliaPostCustomerInformationDecoder class

Publikt gränssnitt för avkodning av Customer Information Field som används i AustraliaPost-symbologi. Implementering bör tillhandahållas av användaren.

Typen AustraliaPostCustomerInformationDecoder exponerar följande medlemmar:
## Metoder
| Namn | Beskrivning |
| :- | :- |
| decode(customer_information_field) | Avkoda Customer Information Field från AustraliaPost-symbologi. <br/>            Kan användas för olika datainterpretationer från NTable- och CTable-kodning.<br/>            Data tillhandahålls som en rad av stapelvärden: 0, 1, 2 eller 3. |
