## XDimensionMode enumeration



## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| AUTO | Värdet för XDimension upptäcks av AI (SVM). För närvarande samma som Normal |
| SMALL | Detekterar streckkoder med liten XDimension på 1 pixel eller mer med kvalitet från BarcodeQuality |
| NORMAL | Detekterar streckkoder med klassisk XDimension på 2 pixlar eller mer med kvalitet från BarcodeQuality eller högkvalitativa streckkoder. |
| LARGE | Detekterar streckkoder med stor XDimension med kvalitet från BarcodeQuality inspelade med högupplösta kameror. |
| USE_MINIMAL_X_DIMENSION | Detekterar streckkoder med storlek satt i MinimalXDimension med kvalitet från BarcodeQuality |
