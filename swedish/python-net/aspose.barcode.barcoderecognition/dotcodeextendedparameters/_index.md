## DotCodeExtendedParameters class

Lagrar speciella data för DotCode‑igenkänd streckkod.

Typen DotCodeExtendedParameters exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_empty | Testar om alla parametrar endast har standardvärden |
| structured_append_mode_barcodes_count | Hämtar antalet staplar i DotCode strukturerat tilläggsläge. Standardvärdet är -1. Antalet måste vara ett värde mellan 1 och 35. |
| structured_append_mode_barcode_id | Hämtar ID för DotCode stapel i strukturerat tilläggsläge. ID börjar på 1 och måste vara mindre än eller lika med antalet staplar. Standardvärdet är -1. |
| is_reader_initialization | Indikerar om koden används för att instruera läsaren att tolka följande data som instruktioner för initiering eller omprogrammering av streckkodsläsaren.<br/>            Standardvärdet är falskt. |
