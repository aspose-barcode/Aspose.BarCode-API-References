## LuminanceFrame class

Representerar en 8‑bits gråskale‑bildram. Varje pixel representeras av en byte som innehåller dess luminansvärde.

Typen LuminanceFrame exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Initierar en ny instans av klassen LuminanceFrame |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Initierar en ny instans av klassen LuminanceFrame |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| data | Hämtar luminansdata. |
| width | Hämtar bildramens bredd i pixlar. |
| height | Hämtar bildramens höjd i pixlar. |
| row_stride | Hämtar avståndet i byte mellan början<br/>            av två intilliggande rader. |
| rotation_degrees | Hämtar antalet grader som bildramen måste roteras medurs för att ha korrekt orientering. |
