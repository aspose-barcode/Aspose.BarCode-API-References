## Iso15416Quality class

Lagrar streckkodskvalitetsgrader beräknade enligt ISO/IEC 15416‑standarden för 1D‑streckkoder.

Typen Iso15416Quality exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| grad | Hämtar den övergripande streckkodskvalitetsgraden enligt ISO/IEC 15416. |
| avkoda | Hämtar avkodningsgraden som indikerar om streckkoden kan avkodas med hjälp av referensavkodningsalgoritmen. |
| symbol_contrast | Hämtar symbolkontrastgraden baserat på skillnaden mellan maximal och minimal reflektion. |
| minimum_reflectance | Hämtar den minsta reflektansgraden baserat på den mörkaste stapelns reflektans. |
| minimum_edge_contrast | Hämtar den minsta kantkontrastgraden baserat på den minsta reflektansskillnaden mellan intilliggande staplar och mellanrum. |
| modulation | Hämtar modulationsgraden baserat på enhetligheten i kantkontrast över hela streckkoden. |
| defects | Hämtar defektnivån baserat på reflektansirregulariteter inom staplar och mellanrum. |
| decodability | Hämtar avkodningsgraden baserat på noggrannheten i stapel- och mellanrumsmått. |
