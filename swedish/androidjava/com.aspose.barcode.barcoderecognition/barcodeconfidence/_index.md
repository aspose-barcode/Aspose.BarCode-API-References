### MODERATE {#MODERATE}
```
public static final BarCodeConfidence MODERATE
```


Identifieringskonfidens för streckkod (mest 1D-streckkoder) med svag kontrollsumma eller utan den. Kan innehålla vissa felidentifieringar i kodtexten eller till och med falska identifieringar om den är låg.

### NONE {#NONE}
```
public static final BarCodeConfidence NONE
```


Identifieringskonfidens för streckkod där kodtexten inte identifierades korrekt eller streckkoden upptäcktes som möjlig fakeBarCodeExtendedParameters.

### STRONG {#STRONG}
```
public static final BarCodeConfidence STRONG
```


Identifieringskonfidens som bekräftades med BCH-koder som Reed\\u2013Solomon. Det får inte finnas fel i läst kodtext eller falska identifieringar.
