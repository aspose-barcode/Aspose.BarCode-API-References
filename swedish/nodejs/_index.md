API:et tillhandahåller klasser för skapande, igenkänning och manipulation av streckkoder, vilket möjliggör sömlös integration i Node.js‑applikationer via Java‑interop. Stödda symboler omfattar linjära, 2‑D‑ och postkoder såsom Code128, EAN‑13, QR, DataMatrix, Aztec och PDF417. All funktionalitet är organiserad under namnutrymmet aspose.barcode, med hjälputrymmen placerade i Global‑namnutrymmet.

## Namnutrymmen

| Namnutrymme | Beskrivning |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | Namnutrymmet aspose.barcode erbjuder klasser och uppräkningar för att skapa, anpassa och avkoda ett brett utbud av streckkodstyper i Node.js via Java. |
| [Global](./global/) | Namnutrymmet Global grupperar grundläggande uppräkningar och verktygsklasser som används i hela Aspose.BarCode för Node.js via Java. |
