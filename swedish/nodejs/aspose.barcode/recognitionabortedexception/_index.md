## RecognitionAbortedException class

Representerar ett avbrottsundantag för igenkänning som kastas när tidsgränsen överskrids under igenkänning med BarCodeReader.

```js
new RecognitionAbortedException(message, executionTime)
```

Initierar en ny instans av klassen med angivet avbrytningsmeddelande för igenkänning.

| Parameter | Beskrivning |
| --- | --- |
| meddelande | Felmeddelandet för undantaget. |
| executionTime | Exekveringstiden för den aktuella igenkänningssessionen. |
