## MacroCharacter

Macro Characters 05 och 06 värden används för att få en mer kompakt kodning i speciella lägen. 05 Macro‑tecken översätts till "[)>\u001E05\u001D" som avkodad dataheader och "\u001E\u0004" som avkodad datatillbehör. 06 Macro‑tecken översätts till "[)>\u001E06\u001D" som avkodad dataheader och "\u001E\u0004" som avkodad datatillbehör. Dessa exempel visar hur man kodar Macro Characters i MicroPdf417 och DataMatrix.

## Värden

| Namn | Beskrivning |
| --- | --- |
| AUTO | Bestäm automatiskt |
| TYPE_7 | 24 x 24 moduler |
| TYPE_9 | 32 x 32 moduler |
| TYPE_29 | 16 x 48 moduler |
