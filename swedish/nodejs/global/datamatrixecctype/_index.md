## DataMatrixEccType

Ange typen av ECC att koda.

## Värden

| Namn | Beskrivning |
| --- | --- |
| ECC_AUTO | Anger att den kodade Ecc-typen definieras av standard Reed-Solomon felkorrigering eller ECC 200. |
| ECC_000 | Anger att den kodade Ecc-typen definieras ECC 000. |
| ECC_050 | Anger att den kodade Ecc-typen definieras ECC 050. |
| ECC_080 | Specificerar att den kodade Ecc-typen är definierad ECC 080. |
| ECC_100 | Specificerar att den kodade Ecc-typen är definierad ECC 100. |
| ECC_140 | Specificerar att den kodade Ecc-typen är definierad ECC 140. |
| ECC_200 | Specificerar att den kodade Ecc-typen är definierad ECC 200. Rekommenderas att använda. |
