## BarCodeConfidence

Innehåller igenkänningsförtroendenivå

## Värden

| Namn | Beskrivning |
| --- | --- |
| INGEN | Upptäckningsgrad för streckkod där kodtexten inte identifierades korrekt eller streckkoden upptäcktes som möjlig falsk |
| MODERATE | Upptäckningsgrad för streckkod (mest 1D-streckkoder) med svag kontrollsumma eller utan den. Kan innehålla vissa felidentifieringar i kodtexten eller till och med falska identifieringar om den är låg. |
| STRONG | Upptäckningsgrad som bekräftats med BCH‑koder som Reed–Solomon. Det får inte finnas fel i den lästa kodtexten eller falska identifieringar. |
