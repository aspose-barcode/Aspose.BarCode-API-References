## AutoSizeMode enum


Anger de olika typerna av automatiska storlekslägen.

```cpp
enum class AutoSizeMode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Ingen | 0 | Automatisk storleksändring är inaktiverad. |
| Närmaste | 1 | Ändrar streckkodens storlek till den närmaste lägsta möjliga storleken som anges av egenskaperna ImageWidth och ImageHeight. Bevarar standardförhållandet för bildformat. |
| Interpolation | 2 | Ändrar streckkodens storlek till angiven storlek. Storleken kan anges med egenskaperna ImageWidth och ImageHeight. Genererad streckkod kan bli ogiltig (ej läsbar) efter skalning. |
