## QRErrorLevel enum


Nivå för Reed-Solomon felkorrigering. Från låg till hög: LevelL, LevelM, LevelQ, LevelH.

```cpp
enum class QRErrorLevel
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| LevelL | 0 | Felkorrigering nivå L kan tillämpas på QR- och MicroQR-streckkoder. Tillåter återställning av 7 % av kodtexten. |
| LevelM | 1 | Felkorrigering nivå M kan tillämpas på QR-streckkoder, RectMicroQR-streckkoder och MicroQR-streckkoder med versioner från M2 till M4. Tillåter återställning av 15 % av kodtexten. |
| LevelQ | 2 | Felkorrigering nivå Q kan tillämpas på QR-streckkoder och MicroQR-streckkoder med version M4. Tillåter återställning av 25 % av kodtexten. |
| LevelH | 3 | Felkorrigering nivå H kan tillämpas på QR- och RectMicroQR-streckkoder. Tillåter återställning av 30 % av kodtexten. |
