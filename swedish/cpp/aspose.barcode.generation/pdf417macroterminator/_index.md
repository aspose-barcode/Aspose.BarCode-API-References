## Pdf417MacroTerminator enum


Används för att tala om för kodaren om Macro PDF417 Terminator (kodord 922) ska läggas till i segmentet. Tillämpas endast för Macro PDF417.

```cpp
enum class Pdf417MacroTerminator
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Auto | 0 | Terminern kommer att läggas till automatiskt om antalet segment anges och det aktuella segmentet är det sista. I andra fall kommer terminern inte att läggas till. |
| Ingen | 1 | Terminern kommer inte att läggas till. |
| Ange | 2 | Terminern kommer att läggas till. |
