## MicroQRVersion enum


Version av MicroQR Code. Från M1 till M4.

```cpp
enum class MicroQRVersion
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Auto | 0 | Anger att automatiskt välja den bästa versionen för MicroQR. Detta är standardvärdet. |
| M1 | 1 | Anger version M1 för Micro QR med 11 x 11 moduler. |
| M2 | 2 | Anger version M2 för Micro QR med 13 x 13 moduler. |
| M3 | 3 | Anger version M3 för Micro QR med 15 x 15 moduler. |
| M4 | 4 | Anger version M4 för Micro QR med 17 x 17 moduler. |
