## DataMatrixEccType enum


Ange typen av ECC att koda.

```cpp
enum class DataMatrixEccType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| EccAuto | 0 | Anger att den kodade Ecc-typen definieras av standard Reed-Solomon felkorrigering eller ECC 200. |
| Ecc000 | 1 | Anger att den kodade Ecc-typen definieras som ECC 000. |
| Ecc050 | 2 | Anger att den kodade Ecc-typen definieras som ECC 050. |
| Ecc080 | 3 | Anger att den kodade Ecc-typen definieras som ECC 080. |
| Ecc100 | 4 | Anger att den kodade Ecc-typen definieras som ECC 100. |
| Ecc140 | 5 | Anger att den kodade Ecc-typen definieras som ECC 140. |
| Ecc200 | 6 | Anger att den kodade Ecc-typen är definierad som ECC 200. Rekommenderas att använda. |
