Används för att tala om för kodaren om Macro PDF417 Terminator (kodord 922) ska läggas till i segmentet. Tillämpas endast för Macro PDF417.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [AUTO](#AUTO) | Terminern kommer att läggas till automatiskt om antalet segment anges och det aktuella segmentet är det sista. |
| [NONE](#NONE) | Terminern kommer inte att läggas till. |
| [SET](#SET) | Terminern kommer att läggas till. |
