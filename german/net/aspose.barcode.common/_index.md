Das **BarCode.Common** enthält allgemeine Funktionen und Hilfswerkzeuge zur Aufrechterhaltung der Hauptfunktionalität.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [GS1Element](./gs1element/) | Stellt ein unveränderliches GS1 Application Identifier‑Wert‑Paar dar. |
| [GS1ValidationException](./gs1validationexception/) | Die Ausnahme, die bei strengen GS1-Operationen ausgelöst wird, wenn die Validierung fehlschlägt. |
| [GS1ValidationIssue](./gs1validationissue/) | Beschreibt einen GS1-Validierungsfehler. |
| [GS1ValidationResult](./gs1validationresult/) | Enthält alle unabhängig erkennbaren Fehler für eine GS1-Elementzeichenkette, Digital‑Link‑URI oder einen AI‑Wert. |
| [ProcessorSettings](./processorsettings/) | ProcessorSettings ermöglichen die Erkennung von Barcodes mit mehrthreadiger Leistungssteigerung. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [GS1ValidationErrorCode](./gs1validationerrorcode/) | Identifiziert einen GS1-Element-String, eine Digital‑Link‑URI oder einen Validierungsfehler des Werts. |
