## BarcodeGeneratorElement.ThrowExceptionWhenCodeTextIncorrect property

Nur für 1D‑Barcodes. Wenn der Codetext inkorrekt ist und der Wert auf true gesetzt wird, wird eine Ausnahme ausgelöst. Andernfalls wird der Codetext korrigiert, um der Spezifikation des Barcodes zu entsprechen.

public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
