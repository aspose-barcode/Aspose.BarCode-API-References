## Address.AddressLine2 property

Liest oder setzt die Adresszeile 2.

Die zweite Adresszeile enthält Postleitzahl und Ort.

Das Setzen dieses Feldes legt den Adresstyp auf CombinedElements fest, es sei denn, er ist bereits Structured, in welchem Fall er zu Conflicting wird.

Dieses Feld wird nur für kombinierte Elemente-Adressen verwendet. Für diesen Typ ist es obligatorisch.

```csharp
public string AddressLine2 { get; set; }
```

### Property Value

Die zweite Adresszeile.
