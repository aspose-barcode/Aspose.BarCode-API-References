## Address.AddressLine1 property

Liest oder setzt die Adresszeile 1.

Adresszeile 1 enthält Straßenname, Hausnummer oder Postfach.

Das Setzen dieses Feldes legt den Adresstyp auf CombinedElements fest, es sei denn, er ist bereits Structured, in welchem Fall er zu Conflicting wird.

Dieses Feld wird nur für Adressen mit kombinierten Elementen verwendet und ist optional.

```csharp
public string AddressLine1 { get; set; }
```

### Property Value

Die Adresszeile 1.
