## Address.Street property

Liest oder setzt die Straße.

Die Straße muss ohne Hausnummer angegeben werden.

Das Setzen dieses Feldes setzt den Adresstyp auf Structured, es sei denn, er ist bereits CombinedElements, in diesem Fall wird er zu Conflicting.

Dieses Feld wird nur für strukturierte Adressen verwendet und ist optional.

```csharp
public string Street { get; set; }
```

### Property Value

Die Straße.
