## Address.Type property

Liest den Adresstyp.

Der Adresstyp wird automatisch festgelegt, indem entweder Straße / Hausnummer oder Adresszeile 1 und 2 gesetzt werden. Vor dem Setzen der Felder ist der Adresstyp Undetermined. Wenn Felder beider Typen gesetzt werden, wird der Adresstyp Conflicting.

```csharp
public AddressType Type { get; }
```

### Property Value

Der Adresstyp.
