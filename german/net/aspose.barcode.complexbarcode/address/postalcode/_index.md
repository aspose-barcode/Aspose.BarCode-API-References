## Address.PostalCode property

Liest oder setzt die Postleitzahl.

Das Setzen dieses Feldes setzt den Adresstyp auf Structured, es sei denn, er ist bereits CombinedElements, in diesem Fall wird er zu Conflicting.

Dieses Feld wird nur für strukturierte Adressen verwendet. Für diesen Typ ist es obligatorisch.

```csharp
public string PostalCode { get; set; }
```

### Property Value

Die Postleitzahl.
