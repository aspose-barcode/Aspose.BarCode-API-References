## SwissQRBill.CreateAndSetCreditorReference method

Erstellt und setzt eine ISO11649-Gläubigerreferenz aus einem Rohstring, indem dem String das Präfix \"RF\" und die Modulo‑97-Prüfsumme vorangestellt werden.

Leerzeichen werden aus der Referenz entfernt.

```csharp
public void CreateAndSetCreditorReference(string rawReference)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| rawReference | String | Die Rohreferenz. |

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentException | `rawReference` enthält ungültige Zeichen. |
