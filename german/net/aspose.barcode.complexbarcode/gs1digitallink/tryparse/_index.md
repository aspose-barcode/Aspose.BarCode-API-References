## GS1DigitalLink.TryParse method

Versucht, einen unkomprimierten GS1 Digital Link‑URI zu parsen und gibt strukturierte Validierungsfehler zurück.

```csharp
public static bool TryParse(string value, out GS1DigitalLink result, 
    out GS1ValidationResult validationResult)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Wert | String | Zu parsender GS1 Digital Link URI. |
| Ergebnis | GS1DigitalLink& | Wenn diese Methode true zurückgibt, enthält sie den geparsten GS1 Digital Link; andernfalls null. |

True, wenn das Parsen erfolgreich ist; andernfalls false.
