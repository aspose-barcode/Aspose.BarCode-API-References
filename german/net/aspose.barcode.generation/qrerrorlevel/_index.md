## QRErrorLevel enumeration

Stufe der Reed-Solomon-Fehlerkorrektur. Von niedrig bis hoch: LevelL, LevelM, LevelQ, LevelH.

```csharp
public enum QRErrorLevel
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| LevelL | `0` | Fehlerkorrektur‑Level L kann auf QR‑ und MicroQR‑Barcodes angewendet werden. Ermöglicht die Wiederherstellung von 7 % des Codetextes. |
| LevelM | `1` | Fehlerkorrektur‑Level M kann auf QR‑Barcodes, RectMicroQR‑Barcodes und MicroQR‑Barcodes mit Versionen von M2 bis M4 angewendet werden. Ermöglicht die Wiederherstellung von 15 % des Codetextes. |
| LevelQ | `2` | Fehlerkorrektur‑Level Q kann auf QR‑Barcodes und MicroQR‑Barcodes mit Version M4 angewendet werden. Ermöglicht die Wiederherstellung von 25 % des Codetextes. |
| LevelH | `3` | Fehlerkorrektur‑Level H kann auf QR‑ und RectMicroQR‑Barcodes angewendet werden. Ermöglicht die Wiederherstellung von 30 % des Codetextes. |
