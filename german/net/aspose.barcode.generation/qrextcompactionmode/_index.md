## QrExtCompactionMode enumeration

Gibt den QR-Komprimierungsmodus für den von QrExtCodetextBuilder hinzugefügten Codetext an.

```csharp
public enum QrExtCompactionMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Der Encoder wählt den effizientesten QR-Komprimierungsmodus automatisch aus. |
| Numeric | `1` | Kodiert den Codetext im QR-Numerikmodus. Nur Ziffern 0-9 sind erlaubt. |
| AlphaNumeric | `2` | Kodiert den Codetext im QR-Alphanumerikmodus. |
| Bytes | `3` | Kodiert den Codetext im QR-Byte-Modus. |
| Kanji | `4` | Kodiert den Codetext im QR-Kanji-Modus. |
