## Pdf417Parameters.ErrorLevel property

Liest oder setzt den Pdf417‑Symboltyp des Fehlerkorrektur‑Levels von BarCode, das von level0 bis level8 reicht; level0 bedeutet keine Fehlerkorrektur‑Information, level8 bedeutet beste Fehlerkorrektur, was ein größeres Bild bedeutet.

```csharp
public Pdf417ErrorLevel ErrorLevel { get; set; }
```
