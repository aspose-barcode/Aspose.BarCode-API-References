## EncodeTypes.TryParse method

Konvertiert die Zeichenkettenrepräsentation eines BaseEncodeType in seine Instanz. Ein Rückgabewert gibt an, ob die Konvertierung erfolgreich war oder fehlgeschlagen ist.

```csharp
public static bool TryParse(string parsingType, out BaseEncodeType result)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| parsingType | String | Ein String im Format "Index:-1; Name:None", der konvertiert werden soll. |
| Ergebnis | BaseEncodeType& | Ein tatsächlicher SingleEncodeType wird zurückgegeben, wenn die Konvertierung erfolgreich abgeschlossen wurde; |

### Rückgabewert

**true** if s was converted successfully; otherwise, **false**.
