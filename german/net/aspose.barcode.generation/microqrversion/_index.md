## MicroQRVersion enumeration

Version des MicroQR-Codes. Von M1 bis M4.

```csharp
public enum MicroQRVersion
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Gibt an, automatisch die beste Version für MicroQR auszuwählen. Dies ist der Standardwert. |
| M1 | `1` | Gibt Version M1 für Micro QR mit 11 x 11 Modulen an. |
| M2 | `2` | Gibt Version M2 für Micro QR mit 13 x 13 Modulen an. |
| M3 | `3` | Gibt Version M3 für Micro QR mit 15 x 15 Modulen an. |
| M4 | `4` | Gibt Version M4 für Micro QR mit 17 x 17 Modulen an. |
