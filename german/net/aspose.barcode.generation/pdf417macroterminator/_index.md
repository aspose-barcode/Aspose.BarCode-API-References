## Pdf417MacroTerminator enumeration

Wird verwendet, um dem Encoder mitzuteilen, ob ein Macro PDF417 Terminator (Codewort 922) zum Segment hinzugefügt werden soll. Wird nur für Macro PDF417 angewendet.

```csharp
public enum Pdf417MacroTerminator
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Der Terminierer wird automatisch hinzugefügt, wenn die Anzahl der Segmente angegeben ist und das aktuelle Segment das letzte ist. In anderen Fällen wird der Terminierer nicht hinzugefügt. |
| None | `1` | Der Terminierer wird nicht hinzugefügt. |
| Set | `2` | Der Terminierer wird hinzugefügt. |
