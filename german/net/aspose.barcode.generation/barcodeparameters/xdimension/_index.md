## BarcodeParameters.XDimension property

x-dimension ist die kleinste Breite der Einheit von Barcode-Balken oder -Lücken. Eine Erhöhung erhöht die gesamte Barcode-Bildbreite. Wird ignoriert, wenn die [`AutoSizeMode`](../../basegenerationparameters/autosizemode/) Eigenschaft auf AutoSizeMode.Nearest oder AutoSizeMode.Interpolation gesetzt ist.

public Unit XDimension { get; set; }
