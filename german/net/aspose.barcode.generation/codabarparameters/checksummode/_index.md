## CodabarParameters.ChecksumMode property

Gibt den Prüfsummenalgorithmus für Codabar-Barcodes zurück oder legt ihn fest. Standardwert: CodabarChecksumMode.Mod16. Um die Prüfsummenberechnung zu aktivieren, setzen Sie den Wert EnableChecksum.Yes für die Eigenschaft EnableChecksum. Siehe `ChecksumMode`.

```csharp
public CodabarChecksumMode ChecksumMode { get; set; }
```
