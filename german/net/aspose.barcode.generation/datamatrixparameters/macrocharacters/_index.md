## DataMatrixParameters.MacroCharacters property

Macro-Zeichen 05 und 06 werden verwendet, um eine kompaktere Kodierung in speziellen Modi zu erhalten. Können nur mit DataMatrixEccType.Ecc200 oder DataMatrixEccType.EccAuto verwendet werden. Können nicht mit EncodeTypes.GS1DataMatrix verwendet werden. Standardwert: MacroCharacters.None.

public MacroCharacter MacroCharacters { get; set; }
