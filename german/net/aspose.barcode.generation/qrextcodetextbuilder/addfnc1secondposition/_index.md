## QrExtCodetextBuilder.AddFNC1SecondPosition method

Setzt FNC1 an der zweiten Position. Wenn zuvor ein anderer FNC1‑Modus gesetzt war, wird er ersetzt.

```csharp
public void AddFNC1SecondPosition(string codetext)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| codetext | String | Wert des FNC1 an zweiter Stelle. Der Wert muss ein einzelner Buchstabe von a-z oder A-Z sein oder eine zweistellige Zahl von 00 bis 99. |
