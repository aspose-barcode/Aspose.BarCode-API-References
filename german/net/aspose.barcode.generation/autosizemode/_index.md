## AutoSizeMode enumeration

Gibt die verschiedenen Typen automatischer Größeneinstellungsmodi an.

```csharp
public enum AutoSizeMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Automatisches Skalieren ist deaktiviert. |
| Nearest | `1` | Skaliert den Barcode auf die nächstkleinere mögliche Größe, die durch die Eigenschaften ImageWidth und ImageHeight angegeben ist. Bewahrt das Standardseitenverhältnis. |
| Interpolation | `2` | Skaliert den Barcode auf die angegebene Größe. Die Größe kann über die Eigenschaften ImageWidth und ImageHeight festgelegt werden. Der erzeugte Barcode kann nach dem Skalieren ungültig (nicht lesbar) sein. |
