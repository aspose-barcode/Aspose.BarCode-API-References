## BarCodeImageFormat enumeration

Gibt das Dateiformat des Bildes an.

```csharp
public enum BarCodeImageFormat
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Bmp | `0` | Gibt das Bitmap (BMP)-Bildformat an. |
| Gif | `1` | Gibt das Graphics Interchange Format (GIF)-Bildformat an. |
| Jpeg | `2` | Gibt das Joint Photographic Experts Group (JPEG)-Bildformat an. |
| Png | `3` | Gibt das W3C Portable Network Graphics (PNG)-Bildformat an. |
| Tiff | `4` | Gibt das Tagged Image File Format (TIFF)-Bildformat an. |
| TiffInCmyk | `5` | Gibt das Tagged Image File Format (TIFF)-Bildformat im CMYK-Farbmodell an. (Nur auf Windows-Plattform unterstützt, auf *nix-Plattformen wird es als Tiff gespeichert) |
| Emf | `6` | Gibt das Enhanced Metafile (EMF)-Bildformat an. (Nur auf Windows-Plattform unterstützt, auf *nix-Plattformen wird es als PNG gespeichert) |
| Svg | `7` | Gibt das Scalable Vector Graphics (SVG)-Bildformat an. |
| Pdf | `8` | Gibt das Portable Document Format (PDF)-Bildformat an. |
