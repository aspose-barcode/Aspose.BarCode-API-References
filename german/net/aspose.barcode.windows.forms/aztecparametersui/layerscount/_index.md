## AztecParametersUI.LayersCount property

Liest oder setzt die Ebenenzahl des Aztec‑Symbols. Die Ebenenzahl sollte im Bereich von 1 bis 3 für den kompakten Modus und im Bereich von 1 bis 32 für den Vollbereichsmodus liegen. Standardwert: 0 (automatisch).

public int LayersCount { get; set; }
