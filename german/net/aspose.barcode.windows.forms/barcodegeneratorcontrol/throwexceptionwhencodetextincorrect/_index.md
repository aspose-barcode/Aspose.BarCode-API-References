## BarCodeGeneratorControl.ThrowExceptionWhenCodeTextIncorrect property

Nur für 1D-Barcodes. Wenn der Codetext inkorrekt ist und der Wert auf true gesetzt wird, wird eine Ausnahme ausgelöst. Andernfalls wird der Codetext korrigiert, um der Spezifikation des Barcodes zu entsprechen. Eine Ausnahme wird immer ausgelöst für: Databar‑symbology, wenn der Codetext inkorrekt ist. Eine Ausnahme wird niemals ausgelöst für: AustraliaPost, SingapurePost, Code39Extended, Code93Extended, Code16K, Code128 symbology, wenn der Codetext inkorrekt ist.

```csharp
public bool ThrowExceptionWhenCodeTextIncorrect { get; set; }
```
