## BarCodeGeneratorControl.RotationAngle property

Drehwinkel des BarCode‑Bildes, gemessen in Grad, z. B. RotationAngle = 0 oder RotationAngle = 360 bedeutet keine Drehung. Wenn RotationAngle NICHT gleich 90, 180, 270 oder 0 ist, kann dies die Schwierigkeit für den Scanner erhöhen, das Bild zu lesen.

```csharp
public float RotationAngle { get; set; }
```
