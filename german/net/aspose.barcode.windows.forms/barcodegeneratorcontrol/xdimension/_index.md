## BarCodeGeneratorControl.XDimension property

X-dimension ist die kleinste Breite der Einheit von BarCode-Balken oder -Lücken. Eine Erhöhung davon vergrößert die gesamte Barcode-Bildbreite. Ignoriert, wenn die [`AutoSizeMode`](../../../aspose.barcode.generation/autosizemode/)‑Eigenschaft auf AutoSizeMode.Nearest oder AutoSizeMode.Interpolation gesetzt ist.

public Unit XDimension { get; }
