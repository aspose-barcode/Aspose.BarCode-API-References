### getSvgColorMode() {#getSvgColorMode--}
```
public SvgColorMode getSvgColorMode()
```


Mögliche Modi zum Füllen von Farben in einer SVG-Datei, RGB ist Standard und wird von SVG 1.1 unterstützt. RGBA, HSL, HSLA sind im SVG 2.0-Standard erlaubt. Auch bei RGB wird die Deckkraft über den Parameter "fill-opacity" gesetzt.
