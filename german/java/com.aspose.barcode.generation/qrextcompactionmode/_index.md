Gibt den QR‑Komprimierungsmodus für den von QrExtCodetextBuilder hinzugefügten Codetext an.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ALPHA_NUMERIC](#ALPHA-NUMERIC) | Kodiert den Codetext im QR-Alphanumerikmodus. |
| [AUTO](#AUTO) | Der Encoder wählt automatisch den effizientesten QR-Komprimierungsmodus aus. |
| [BYTES](#BYTES) | Kodiert den Codetext im QR-Byte-Modus. |
| [KANJI](#KANJI) | Kodiert den Codetext im QR-Kanji-Modus. |
| [NUMERIC](#NUMERIC) | Kodiert den Codetext im QR-Numerikmodus. |
