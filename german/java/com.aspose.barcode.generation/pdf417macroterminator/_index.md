Wird verwendet, um dem Encoder mitzuteilen, ob der Macro PDF417 Terminator (Codewort 922) zum Segment hinzugefügt werden soll. Nur für Macro PDF417 anwendbar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [AUTO](#AUTO) | Der Terminator wird automatisch hinzugefügt, wenn die Anzahl der Segmente angegeben ist und das aktuelle Segment das letzte ist. |
| [NONE](#NONE) | Der Terminator wird nicht hinzugefügt. |
| [SET](#SET) | Der Terminator wird hinzugefügt. |
