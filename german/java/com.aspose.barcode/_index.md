| [BuildVersionInfo](../com.aspose.barcode/buildversioninfo) | Stellt Informationen über den aktuellen Produktnamen und die Version bereit. |
| [InvalidCodeException](../com.aspose.barcode/invalidcodeexception) | Die Ausnahme wird ausgelöst, wenn ungültige Zeichen im Code-Text enthalten sind. |
