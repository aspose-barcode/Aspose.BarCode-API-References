## MailmarkCodetext::set_DestinationPostCodePlusDPS method


PC und DP müssen dem PAF-Format entsprechen. Neunstelliges Zeichenkette, die den internationalen "XY11     " (beachten Sie die 5 nachfolgenden Leerzeichen) bezeichnet, oder ein Muster von Zeichen, das einen inländischen Sortiercode bezeichnet. Ein inländischer Sortiercode besteht aus einer äußeren Postleitzahl, einer inneren Postleitzahl und einem Delivery Point Suffix.
