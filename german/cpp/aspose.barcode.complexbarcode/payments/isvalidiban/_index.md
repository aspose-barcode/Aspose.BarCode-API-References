## Payments::IsValidIban method


Validiert, ob die Zeichenkette eine gültige IBAN-Nummer ist.

```cpp
static bool Aspose::BarCode::ComplexBarcode::Payments::IsValidIban(System::String iban)
```


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| IBAN | System::String | Die zu validierende IBAN. |

### ReturnValue

**true** if the IBAN is valid, **false** otherwise.
## Hinweise


Die Zeichenkette wird auf gültige Zeichen, gültige Länge und eine gültige Prüfziffer geprüft. Leerzeichen werden ignoriert.
