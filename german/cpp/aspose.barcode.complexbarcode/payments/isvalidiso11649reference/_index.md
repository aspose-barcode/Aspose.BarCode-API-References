## Payments::IsValidIso11649Reference method


Validiert, ob die Zeichenkette eine gültige ISO-11649-Referenznummer ist.

```cpp
static bool Aspose::BarCode::ComplexBarcode::Payments::IsValidIso11649Reference(System::String reference)
```


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Referenz | System::String | Die ISO 11649 Gläubigerreferenz zum Validieren. |

### ReturnValue

**true** if the creditor reference is valid, **false** otherwise.
## Hinweise


Die Zeichenkette wird auf gültige Zeichen, gültige Länge und eine gültige Prüfziffer geprüft. Leerzeichen werden ignoriert.
