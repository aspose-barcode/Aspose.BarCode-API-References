## HIBCLICDateFormat enum


Gibt die verschiedenen Arten von Datumsformaten für HIBC‑LIC an.

```cpp
enum class HIBCLICDateFormat
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| YYYYMMDD | 0 | YYYYMMDD-Format. Wird in zusätzlichen Ergänzungsdaten codiert. |
| MMYY | 1 | MMYY-Format. |
| MMDDYY | 2 | MMDDYY-Format. |
| YYMMDD | 3 | YYMMDD-Format. |
| YYMMDDHH | 4 | YYMMDDHH-Format. |
| YYJJJ | 5 | Julianisches Datumsformat. |
| YYJJJHH | 6 | Julianisches Datumsformat mit Stunden. |
| Keine | 7 | Verfallsdatum nicht codieren. |
