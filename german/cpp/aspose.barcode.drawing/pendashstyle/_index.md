## PenDashStyle enum


Gibt den Stil von gestrichelten Rahmenlinien an.

```cpp
enum class PenDashStyle
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Durchgezogen | 0 | Gibt eine durchgezogene Linie an. |
| Strich | 1 | Gibt eine Linie aus Strichen an. |
| Punkt | 2 | Gibt eine Linie aus Punkten an. |
| DashDot | 3 | Gibt eine Linie mit einem wiederholenden Muster aus Strich-Punkt an. |
| DashDotDot | 4 | Gibt eine Zeile an, die aus einem wiederholenden Muster von Strich-Punkt-Punkt besteht. |
