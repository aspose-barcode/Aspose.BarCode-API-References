## BarcodeParameters::set_IsChecksumEnabled method

```cpp
void Aspose::BarCode::Generation::BarcodeParameters::set_IsChecksumEnabled(EnableChecksum value)
```

## Hinweise


Prüfsumme während der Erzeugung von 1D-Barcodes aktivieren.

Standardmäßig wird Yes für Symbologien verwendet, die eine Prüfsumme enthalten müssen, und No, wo eine Prüfsumme nur optional ist.

Prüfsumme ist möglich: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN, Codabar

Prüfsumme wird immer verwendet: Restliche Symbologien
