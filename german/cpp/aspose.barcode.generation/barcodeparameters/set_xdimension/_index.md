## BarcodeParameters::set_XDimension method


x-Dimension ist die kleinste Breite der Einheit von [BarCode](../../../aspose.barcode/) Balken oder Lücken. Eine Erhöhung davon vergrößert die gesamte Barcode-Bildbreite. Ignoriert, wenn die [BaseGenerationParameters::AutoSizeMode](../)-Eigenschaft auf [AutoSizeMode.Nearest](../../autosizemode/) oder [AutoSizeMode.Interpolation](../../autosizemode/) gesetzt ist.
