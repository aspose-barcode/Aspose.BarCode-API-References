## BarcodeParameters::get_WideNarrowRatio method


Verhältnis von breiten zu schmalen Balken. Standardwert: 3, das heißt, breite Balken sind dreimal so breit wie schmale Balken. Verwendet für ITF, PZN, PharmaCode, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, IATA2of5, VIN, DeutschePost, OPC, Code32, DataLogic2of5, PatchCode, Code39, Code39FullASCII.

```cpp
float Aspose::BarCode::Generation::BarcodeParameters::get_WideNarrowRatio() const
```

## Hinweise



Der **WideNarrowRatio** Parameterwert ist kleiner oder gleich 0.
