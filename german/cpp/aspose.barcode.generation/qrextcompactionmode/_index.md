## QrExtCompactionMode enum


Gibt den QR-Komprimierungsmodus für Codetext an, der von [QrExtCodetextBuilder](../qrextcodetextbuilder/) hinzugefügt wird.

```cpp
enum class QrExtCompactionMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | 0 | Der Encoder wählt den effizientesten QR-Komprimierungsmodus automatisch aus. |
| Numeric | 1 | Kodiert den Codetext im QR-Numeric-Modus. Nur Ziffern 0-9 sind erlaubt. |
| AlphaNumeric | 2 | Kodiert den Codetext im QR-Alphanumeric-Modus. |
| Bytes | 3 | Kodiert den Codetext im QR-Byte-Modus. |
| Kanji | 4 | Kodiert den Codetext im QR-Kanji-Modus. |
