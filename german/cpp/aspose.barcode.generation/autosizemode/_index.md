## AutoSizeMode enum


Gibt die verschiedenen Typen automatischer Größenmodi an.

```cpp
enum class AutoSizeMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Keine | 0 | Automatisches Ändern der Größe ist deaktiviert. |
| Nearest | 1 | Skaliert den Barcode auf die nächstkleinere mögliche Größe, die durch die Eigenschaften ImageWidth und ImageHeight angegeben ist. Bewahrt das Standard‑Seitenverhältnis. |
| Interpolation | 2 | Skaliert den Barcode auf die angegebene Größe. Die Größe kann über die Eigenschaften ImageWidth und ImageHeight festgelegt werden. Der erzeugte Barcode kann nach dem Skalieren ungültig (nicht lesbar) sein. |
