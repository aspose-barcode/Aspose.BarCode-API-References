## Pdf417MacroTerminator enum


Wird verwendet, um dem Encoder mitzuteilen, ob dem Segment ein Macro PDF417 Terminator (Codewort 922) hinzugefügt werden soll. Wird nur für Macro PDF417 angewendet.

```cpp
enum class Pdf417MacroTerminator
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | 0 | Der Terminator wird automatisch hinzugefügt, wenn die Anzahl der Segmente angegeben ist und das aktuelle Segment das letzte ist. In anderen Fällen wird der Terminator nicht hinzugefügt. |
| Keine | 1 | Der Terminator wird nicht hinzugefügt. |
| Setzen | 2 | Der Terminator wird hinzugefügt. |
