## GS1ValidationResult class

Enthält alle unabhängig erkennbaren Fehler für einen GS1-Element-String, Digital Link URI oder einen AI-Wert.

Der Typ GS1ValidationResult stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_valid | Gibt einen Wert zurück, der angibt, ob die Validierung ohne Fehler abgeschlossen wurde. |
| Probleme | Gibt Validierungsfehler in deterministischer Reihenfolge zurück. |
