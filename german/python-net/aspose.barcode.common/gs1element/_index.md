## GS1Element class

Stellt ein unveränderliches GS1-Anwendungskennzeichen und Wertepaar dar.

Der Typ GS1Element stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| application_identifier | Gibt den genauen GS1 Application Identifier zurück. |
| Wert | Gibt den validierten Wert zurück, der dem Application Identifier zugeordnet ist. |
## Methoden
| Name | Beschreibung |
| :- | :- |
