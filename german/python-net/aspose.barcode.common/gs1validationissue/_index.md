## GS1ValidationIssue class

Beschreibt einen GS1-Validierungsfehler.

Der Typ GS1ValidationIssue stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| code | Gibt einen stabilen maschinenlesbaren Fehlercode zurück. |
| application_identifier | Gibt den mit dem Fehler verbundenen Anwendungsidentifikator zurück, oder null, wenn der Anwendungsidentifikator<br/>            aus der Eingabe nicht ermittelt werden konnte. |
| message | Gibt die menschenlesbare Fehlermeldung zurück. |
