## ProcessorSettings class

ProcessorSettings ermöglichen die Erkennung von Barcodes mit mehrthreadiger Leistungssteigerung.

Der Typ ProcessorSettings stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| use_all_cores | Wird benötigt, um alle Kerne zu verwenden. |
| use_only_this_cores_count | Geben Sie die Anzahl der zu verwendenden Kerne an. <br/>            Sie müssen die Eigenschaft "UseAllCores" auf "false" ändern. |
| max_additional_allowed_threads | Geben Sie die maximale Anzahl zusätzlicher Threads an, um Code parallel auszuführen |
