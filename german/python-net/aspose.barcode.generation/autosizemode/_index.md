## AutoSizeMode enumeration

Gibt die verschiedenen Arten automatischer Größeneinstellungsmodi an.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| NONE | Automatische Größenanpassung ist deaktiviert. |
| NEAREST | Skaliert den Barcode auf die nächstkleinere mögliche Größe, die durch die Eigenschaften ImageWidth und ImageHeight angegeben ist.<br/>            Bewahrt das Standardseitenverhältnis. |
| INTERPOLATION | Skaliert den Barcode auf die angegebene Größe.<br/>            Die Größe kann über die Eigenschaften ImageWidth und ImageHeight festgelegt werden.<br/>            Der erzeugte Barcode kann nach der Skalierung ungültig (nicht lesbar) sein. |
