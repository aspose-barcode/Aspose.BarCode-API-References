## SvgColorMode enumeration

Mögliche Modi zum Füllen von Farben in SVG‑Dateien, RGB ist Standard und wird von SVG 1.1 unterstützt.<br/>            RGBA, HSL, HSLA sind im SVG 2.0‑Standard erlaubt.<br/>            Selbst bei RGB wird die Deckkraft über den Parameter "fill-opacity" festgelegt.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| RGB | RGB‑Modus, Beispiel: fill=\"#ff5511\" fill-opacity=\"0.73\". Standardmodus. |
| RGBA | RGBA‑Modus, Beispiel: fill=\"rgba(255, 85, 17, 0.73)\" |
| HSL | HSL‑Modus, Beispiel: fill=\"hsl(17, 100%, 53%)\" fill-opacity=\"0.73\" |
| HSLA | HSLA‑Modus, Beispiel: fill=\"hsla(30, 50%, 70%, 0.8)\" |
