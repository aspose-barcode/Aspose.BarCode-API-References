## DataMatrixEccType enumeration

Geben Sie den Typ des zu codierenden ECC an.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| ECC_AUTO | Gibt an, dass der codierte ECC‑Typ standardmäßig durch Reed‑Solomon-Fehlerkorrektur oder ECC 200 definiert ist. |
| ECC000 | Gibt an, dass der codierte ECC‑Typ ECC 000 definiert ist. |
| ECC050 | Gibt an, dass der codierte ECC‑Typ ECC 050 definiert ist. |
| ECC080 | Gibt an, dass der codierte ECC‑Typ ECC 080 definiert ist. |
| ECC100 | Gibt an, dass der codierte ECC‑Typ ECC 100 definiert ist. |
| ECC140 | Gibt an, dass der codierte ECC‑Typ ECC 140 definiert ist. |
| ECC200 | Gibt an, dass der codierte Ecc-Typ als ECC 200 definiert ist. Empfohlen zu verwenden. |
