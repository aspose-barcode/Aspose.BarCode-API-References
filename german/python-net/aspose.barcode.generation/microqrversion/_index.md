## MicroQRVersion enumeration

Version des MicroQR‑Codes.<br/>            Von M1 bis M4.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| AUTO | Gibt an, automatisch die beste Version für MicroQR auszuwählen.<br/>            Dies ist der Standardwert. |
| M1 | Gibt Version M1 für Micro QR mit 11 x 11 Modulen an. |
| M2 | Gibt Version M2 für Micro QR mit 13 x 13 Modulen an. |
| M3 | Gibt Version M3 für Micro QR mit 15 x 15 Modulen an. |
| M4 | Gibt Version M4 für Micro QR mit 17 x 17 Modulen an. |
