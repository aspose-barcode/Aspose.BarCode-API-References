## Pdf417ErrorLevel enumeration

Fehlerkorrekturstufe des pdf417‑Barcodes, von Stufe 0 bis Stufe 9, Stufe 0 bedeutet keine Fehlerkorrektur, Stufe 8 bedeutet beste Fehlerkorrektur
