## QRErrorLevel enumeration

Stufe der Reed‑Solomon-Fehlerkorrektur. Von niedrig nach hoch: LevelL, LevelM, LevelQ, LevelH.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| LEVEL_L | Fehlerkorrektur Level L kann auf QR‑ und MicroQR‑Barcodes angewendet werden.<br/>            Ermöglicht die Wiederherstellung von 7 % des Code‑Texts. |
| LEVEL_M | Fehlerkorrektur Level M kann auf QR‑Barcodes, RectMicroQR‑Barcodes und MicroQR‑Barcodes mit Versionen von M2 bis M4 angewendet werden.<br/>            Ermöglicht die Wiederherstellung von 15 % des Code‑Texts. |
| LEVEL_Q | Fehlerkorrektur Level Q kann auf QR‑Barcodes und MicroQR‑Barcodes mit Version M4 angewendet werden.<br/>            Ermöglicht die Wiederherstellung von 25 % des Code‑Texts. |
| LEVEL_H | Fehlerkorrektur Level H kann auf QR‑ und RectMicroQR‑Barcodes angewendet werden.<br/>            Ermöglicht die Wiederherstellung von 30 % des Code‑Texts. |
