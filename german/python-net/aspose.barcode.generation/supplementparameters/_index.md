## SupplementParameters class

Ergänzungsparameter. Verwendet für Interleaved2of5, Standard2of5, EAN13, EAN8, UPCA, UPCE, ISBN, ISSN, ISMN.

Der Typ SupplementParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| supplement_data | Ergänzende Daten nach dem BarCode. |
| supplement_space | Abstand zwischen dem Haupt‑Barcode und dem ergänzenden Barcode im [Unit](/barcode/python-net/aspose.barcode.generation/unit/)-Wert. |
