## BorderParameters class

Parameter für den Rand von Barcode‑Bildern

Der BorderParameters-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| visible | Rand-Sichtbarkeit. Wenn false, wird der Parameter Width immer ignoriert (0).<br/>            Standardwert: false. |
| width | Randbreite.<br/>            Standardwert: 0.<br/>            Ignoriert, wenn Visible auf false gesetzt ist. |
| dash_style | Rand-Strichstil.<br/>            Standardwert: BorderDashStyle.Solid. |
| Farbe | Randfarbe.<br/>            Standardwert: Color.Black. |
