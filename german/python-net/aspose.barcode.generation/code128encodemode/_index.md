## Code128EncodeMode enumeration

Kodierungsmodus für Code128-Barcodes.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| AUTO | Codieren Sie den Codetext im klassischen ISO‑15417‑Modus. Der Modus sollte in allen üblichen Fällen verwendet werden. |
| CODE_A | Codieren Sie den Codetext ausschließlich im 128A‑Codesatz. |
| CODE_B | Codieren Sie den Codetext ausschließlich im 128B‑Codesatz. |
| CODE_C | Codieren Sie den Codetext ausschließlich im 128C‑Codesatz. |
| CODE_AB | Codieren Sie den Codetext ausschließlich in den 128A‑ und 128B‑Codesätzen. |
| CODE_AC | Codieren Sie den Codetext ausschließlich in den 128A‑ und 128C‑Codesätzen. |
| CODE_BC | Codieren Sie den Codetext ausschließlich in den 128B‑ und 128C‑Codesätzen. |
