## Unit class

Gibt den Größenwert in verschiedenen Einheiten an (Pixel, Zoll usw.).

Der Typ Unit stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Pixel | Liest oder setzt den Größenwert in Pixeln. |
| Zoll | Liest oder setzt den Größenwert in Zoll. |
| Millimeter | Liest oder setzt den Größenwert in Millimetern. |
| Punkt | Liest oder setzt den Größenwert in Punkten. |
| Dokument | Liest oder setzt den Größenwert in Dokumenteinheiten. |
| Auflösung | Auflösung |
