## PdfParameters class

PDF-Parameter.

Der PdfParameters-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| cmyk_bar_color | Nullable. CMYK-Farbwert des Barcodes. Null bedeutet, dass CMYK nicht verwendet wird, stattdessen wird die normale RGB-Farbe verwendet. |
| cmyk_back_color | Nullable. CMYK-Hintergrundfarbwert. Null bedeutet, dass CMYK nicht verwendet wird, stattdessen wird die normale RGB-Farbe verwendet. |
| cmyk_codetext_color | Nullable. CMYK-Farbwert des Codetexts. Null bedeutet, dass CMYK nicht verwendet wird, stattdessen wird die normale RGB-Farbe verwendet. |
| cmyk_caption_above_color | Nullable. CMYK-Farbwert der Beschriftung oben. Null bedeutet, dass CMYK nicht verwendet wird, stattdessen wird die normale RGB-Farbe verwendet. |
| cmyk_caption_below_color | Nullable. CMYK-Farbwert der Beschriftung unten. Null bedeutet, dass CMYK nicht verwendet wird, stattdessen wird die normale RGB-Farbe verwendet. |
| is_text_as_path | Werden Pfade anstelle von Text verwendet (verwenden Sie dies, wenn Unicode‑Zeichen nicht angezeigt werden)<br/>            Standardwert: false. |
