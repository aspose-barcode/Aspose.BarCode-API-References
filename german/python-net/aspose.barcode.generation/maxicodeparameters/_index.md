## MaxiCodeParameters class

MaxiCode-Parameter.

Der Typ MaxiCodeParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Modus | Liest oder setzt einen MaxiCode‑Kodierungsmodus. |
| encode_mode | Liest oder setzt einen MaxiCode-Codierungsmodus. <br/>            Standardwert: Auto. |
| eci_encoding | Liest oder setzt die ECI-Kodierung. Wird verwendet, wenn MaxiCodeEncodeMode auf Auto steht.<br/>            Standardwert: ISO-8859-1 |
| structured_append_mode_barcode_id | Liest oder setzt eine MaxiCode‑Barcode‑ID im strukturierten Anfügemodus. <br/>            Die ID muss ein Wert zwischen 1 und 8 sein. <br/>            Standardwert: 0 |
| structured_append_mode_barcodes_count | Liest oder setzt die Anzahl der MaxiCode‑Barcodes im strukturierten Anfügemodus. <br/>            Die Anzahl muss ein Wert zwischen 2 und 8 sein (maximale Barcode‑Anzahl).<br/>            Standardwert: -1 |
| aspect_ratio | Höhen‑/Breiten‑Verhältnis des 2D‑Barcode‑Moduls. |
