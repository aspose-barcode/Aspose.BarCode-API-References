## AztecParameters class

Aztec-Parameter.

Der Typ AztecParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| encode_mode | Liest oder setzt einen Aztec-Kodiermodus. <br/>            Standardwert: Auto. |
| eci_encoding | Liest oder setzt die ECI-Codierung. Wird verwendet, wenn AztecEncodeMode auf Auto steht.<br/>            Standardwert: ISO-8859-1 |
| structured_append_barcode_id | Barcode-ID für den Structured-Append-Modus des Aztec-Barcodes. Die Barcode-ID sollte im Bereich von 1 bis zur Anzahl der Barcodes liegen.<br/>            Standardwert: 0 |
| structured_append_barcodes_count | Anzahl der Barcodes für den Structured Append‑Modus des Aztec‑Barcodes. Die Barcode‑Anzahl sollte im Bereich von 1 bis 26 liegen.<br/>            Standardwert: 0 |
| structured_append_file_id | Datei‑ID für den Structured Append‑Modus des Aztec‑Barcodes (optional). Die Datei‑ID darf keine Leerzeichen enthalten.<br/>            Standardwert: leerer String |
| error_level | Fehlerkorrektur‑Stufe der Aztec‑Barcode‑Typen.<br/>            Der Wert sollte zwischen 5 und 95 liegen. |
| symbol_mode | Liest oder setzt den Aztec‑Symbol‑Modus.<br/>            Standardwert: AztecSymbolMode.Auto. |
| layers_count | Liest oder setzt die Ebenen‑Anzahl des Aztec‑Symbols. Die Ebenen‑Anzahl sollte im Bereich von 1 bis 3 für den kompakten Modus und<br/>            im Bereich von 1 bis 32 für den Voll‑Bereich‑Modus liegen.<br/>            Standardwert: 0 (automatisch). |
| is_reader_initialization | Wird verwendet, um den Leser anzuweisen, die im Symbol enthaltenen Daten<br/>            als Programmierung für die Leserinitialisierung zu interpretieren. |
| aspect_ratio | Höhen‑/Breiten‑Verhältnis des 2D‑Barcode‑Moduls. |
