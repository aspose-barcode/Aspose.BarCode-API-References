## AztecSymbolMode enumeration

Gibt den Aztec-Symbolmodus an.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| AUTO | Gibt an, dass automatisch das beste Symbol (Compact oder Full-range) für Aztec ausgewählt wird.<br/>            Dies ist der Standardwert. |
| COMPACT | Gibt das Compact‑Symbol für Aztec an.<br/>            Das Aztec Compact‑Symbol erlaubt nur 1, 2, 3 oder 4 Ebenen. |
| FULL_RANGE | Gibt das Full-range‑Symbol für Aztec an.<br/>            Das Aztec Full-range‑Symbol erlaubt von 1 bis 32 Ebenen. |
| RUNE | Gibt das Rune‑Symbol für Aztec an.<br/>            Aztec‑Runen sind eine Reihe kleiner, aber unterscheidbarer maschinenlesbarer Markierungen. Sie erlauben nur Zahlenwerte von 0 bis 255. |
