## CaptionParameters class

Beschriftungs‑Parameter.

Der Typ CaptionParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| text | Beschriftungstext.<br/>            Standardwert: leere Zeichenfolge. |
| font | Beschriftungsschriftart.<br/>            Standardwert: Arial 8pt normal. |
| visible | Sichtbarkeit des Beschriftungstextes.<br/>            Standardwert: false. |
| text_color | Farbe des Beschriftungstextes.<br/>            Standardwert: Color.Black. |
| padding | Abstände der Beschriftungen.<br/>            Standardwert für CaptionAbove: 5pt 5pt 0 5pt.<br/>            Standardwert für CaptionBelow: 0 5pt 5pt 5pt. |
| Ausrichtung | Horizontale Ausrichtung des Beschriftungstests.<br/>            Standardwert: StringAlignment.Center. |
| no_wrap | Gibt Wortumbrüche (Zeilenumbrüche) im Text an.<br/>            Standardwert: false. |
