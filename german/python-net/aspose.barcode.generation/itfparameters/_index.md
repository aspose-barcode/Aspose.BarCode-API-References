## ITFParameters class

ITF‑Parameter.

Der Typ ITFParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| border_thickness | Liest oder setzt die Dicke eines ITF-Rahmens (Trägerbalken) in Einheit-Wert.<br/>            Standardwert: 12pt. |
| border_type | Randtyp des ITF-Barcodes.<br/>            Standardwert: ITF14BorderType.Bar. |
| quiet_zone_coef | Größe der Ruhebereiche in xDimension.<br/>            Standardwert: 10, das bedeutet, wenn xDimension = 2px ist, betragen die Ruhebereiche 20px. |
