## SvgParameters class

SVG-Parameter.

Der SvgParameters-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_explicit_size_in_pixels | Enthält das SVG-Bild eine explizite Größe in Pixeln (empfohlen)<br/>            Standardwert: true. |
| is_text_drawn_in_text_element | Enthält das SVG-Bild Text als Textelement statt als Pfade (empfohlen)<br/>            Standardwert: true. |
| svg_color_mode | Mögliche Modi zum Füllen von Farben in SVG‑Dateien, RGB ist Standard und wird von SVG 1.1 unterstützt.<br/>            RGBA, HSL, HSLA sind im SVG 2.0‑Standard erlaubt.<br/>            Selbst bei RGB wird die Deckkraft über den Parameter "fill-opacity" festgelegt. |
