## FontUnit class

Definiert ein bestimmtes Textformat, einschließlich Schriftart, Größe und Stil‑Attribute<br/>            wobei die Größe in der Eigenschaft Unit‑Wert angegeben wird.

Der Typ FontUnit stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| family_name | Ruft den Namen der Schriftart ab oder legt ihn fest. |
| style | Ruft Stilinformationen für diese FontUnit ab oder legt sie fest. |
| size | Ruft die Größe dieser FontUnit im Einheitwert ab oder legt sie fest. |
