## Pdf417MacroTerminator enumeration

Wird verwendet, um dem Encoder mitzuteilen, ob ein Macro‑PDF417‑Terminator (Codewort 922) zum Segment hinzugefügt werden soll.<br/>            Wird nur für Macro PDF417 angewendet.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| AUTO | Der Terminator wird automatisch hinzugefügt, wenn die Anzahl der Segmente angegeben wird <br/>            und das aktuelle Segment das letzte ist. In anderen Fällen wird der Terminator nicht hinzugefügt. |
| NONE | Der Terminator wird nicht hinzugefügt. |
| SET | Der Terminator wird hinzugefügt. |
