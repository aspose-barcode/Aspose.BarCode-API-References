## BarCodeRegionParameters class

Stellt die Region und den Winkel des erkannten Barcodes dar.

Der Typ BarCodeRegionParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| quadrangle | Liefert das [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) begrenzende Barcode‑Region |
| angle | Liefert den Winkel des Barcodes (0‑360). |
| points | Liefert das Array von [Point](/barcode/python-net/aspose.drawing/point/)s, das die Barcode‑Region begrenzt |
| rectangle | Liefert die begrenzende Barcode‑Region |
