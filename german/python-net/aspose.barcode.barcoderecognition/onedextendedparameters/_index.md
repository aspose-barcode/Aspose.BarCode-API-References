## OneDExtendedParameters class

Speichert spezielle Daten des erkannten 1D‑Barcodes, wie separaten Codetext und Prüfsumme

Der Typ OneDExtendedParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_empty | Prüft, ob alle Parameter nur Standardwerte haben |
| Wert | Liefert den Codetext von 1D-Barcodes ohne Prüfsumme. |
| check_sum | Liefert die Prüfsumme für 1D-Barcodes. |
