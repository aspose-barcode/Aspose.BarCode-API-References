## BarcodeSettings class

Die Hauptparameter für die Barcode‑Dekodierung. Enthält Parameter, die Einfluss auf die erkannten Daten haben.

Der Typ BarcodeSettings stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Entfernt FNC1-, FNC2- und FNC3‑Zeichen aus dem Codetext. Standardwert ist false. |
| only_requested_types | Gibt nur Barcode‑Typen zurück, die explizit für die Erkennung angegeben wurden. <br/>            Wenn aktiviert, werden erkannte Barcodes anderer kompatibler oder gleichwertiger Typen herausgefiltert. <br/>            Standardwert ist false. |
| detect_encoding | Das Flag, das die Engine zwingt, die Codetext‑Kodierung für Unicode‑Code‑Sätze zu erkennen. Standardwert ist true. |
| australia_post | Liefert die Decodierungsparameter für AustraliaPost |
| calculate_symbol_quality | Liefert oder setzt einen Wert, der angibt, ob die Barcode‑Symbolqualität während der Erkennung berechnet werden soll. |
