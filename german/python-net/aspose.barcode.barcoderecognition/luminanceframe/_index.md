## LuminanceFrame class

Stellt einen 8‑Bit‑Graustufen‑Bildrahmen dar. Jeder Pixel wird durch ein Byte repräsentiert, das seinen Luminanzwert enthält.

Der Typ LuminanceFrame stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Initialisiert eine neue Instanz der LuminanceFrame-Klasse |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Initialisiert eine neue Instanz der LuminanceFrame-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Daten | Gibt die Luminanzdaten zurück. |
| width | Gibt die Bildbreite in Pixeln zurück. |
| height | Gibt die Bildhöhe in Pixeln zurück. |
| row_stride | Gibt den Abstand in Bytes zwischen den Anfängen<br/>            zweier benachbarter Zeilen zurück. |
| rotation_degrees | Gibt die Anzahl der Grad an, um die das Bild im Uhrzeigersinn gedreht werden muss, um die korrekte Ausrichtung zu erhalten. |
