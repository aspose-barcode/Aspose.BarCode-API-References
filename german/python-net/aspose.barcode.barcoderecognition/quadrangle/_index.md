## Quadrangle class

Speichert ein Set von vier [Point](/barcode/python-net/aspose.drawing/point/)s, die eine [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/)‑Region darstellen.

Der Quadrangle-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Quadrangle() | Initialisiert eine neue leere Instanz der Klasse [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Initialisiert eine neue Instanz der Quadrangle-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| left_top | Liefert die linke obere Ecke [Point](/barcode/python-net/aspose.drawing/point/) der [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) Region |
| right_top | Liefert die rechte obere Ecke [Point](/barcode/python-net/aspose.drawing/point/) der [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) Region |
| right_bottom | Liefert die rechte untere Ecke [Point](/barcode/python-net/aspose.drawing/point/) der [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) Region |
| left_bottom | Liefert die linke untere Ecke [Point](/barcode/python-net/aspose.drawing/point/) der [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) Region |
| is_empty | Prüft, ob alle [Point](/barcode/python-net/aspose.drawing/point/)s dieses [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) den Wert Null haben. |
| bounding_rectangle | Liefert das [Rectangle](/barcode/python-net/aspose.drawing/rectangle/), das dieses [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) umschließt |
| EMPTY | Stellt eine [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) Klasse dar, deren Eigenschaften nicht initialisiert sind. |
