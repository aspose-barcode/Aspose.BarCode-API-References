## AustraliaPostCustomerInformationDecoder class

Öffentliche Schnittstelle für die Dekodierung des Kundeninformationsfeldes, das in der AustraliaPost‑Symbolik verwendet wird. Die Implementierung sollte vom Benutzer bereitgestellt werden.

Der Typ AustraliaPostCustomerInformationDecoder stellt die folgenden Mitglieder bereit:
## Methoden
| Name | Beschreibung |
| :- | :- |
| decode(customer_information_field) | Dekodiert das Customer Information Field aus der AustraliaPost‑Symbologie. <br/>            Kann für unterschiedliche Dateninterpretationen aus NTable‑ und CTable‑Kodierung verwendet werden.<br/>            Daten werden als Reihe von Balkenwerten bereitgestellt: 0, 1, 2 oder 3. |
