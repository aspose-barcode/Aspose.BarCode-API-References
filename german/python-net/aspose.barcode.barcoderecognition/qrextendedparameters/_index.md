## QRExtendedParameters class

Speichert Structured‑Append‑Informationen des erkannten QR‑Barcodes

Der Typ QRExtendedParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_empty | Prüft, ob alle Parameter nur Standardwerte haben |
| structured_append_mode_bar_codes_quantity | Gibt die Anzahl der QR Structured Append-Mode-Barcodes zurück. Standardwert ist -1. |
| structured_append_mode_bar_code_index | Gibt den Index des QR Structured Append-Mode-Barcodes zurück. Der Index beginnt bei 0. Standardwert ist -1. |
| structured_append_mode_parity_data | Gibt die Paritätsdaten des QR Structured Append-Mode zurück. Standardwert ist -1. |
| version | Version des erkannten QR-Codes. Von Version1 bis Version40. |
| micro_qr_version | Version des erkannten MicroQR-Codes. Von M1 bis M4. |
| rect_micro_qr_version | Version des erkannten RectMicroQR-Codes. Von R7x43 bis R17x139. |
| error_level | Reed-Solomon-Fehlerkorrekturstufe des erkannten Barcodes. Von niedrig bis hoch: LevelL, LevelM, LevelQ, LevelH. |
