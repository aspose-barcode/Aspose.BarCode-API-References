## Iso15416Quality class

Speichert Barcode-Qualitätsgrade, die gemäß dem ISO/IEC‑15416‑Standard für 1D‑Barcodes berechnet wurden.

Der Typ Iso15416Quality stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| grade | Liest die Gesamtnote der Barcode-Qualität gemäß ISO/IEC 15416. |
| decode | Liest die Decode-Bewertung, die angibt, ob der Barcode mit dem Referenz-Decode-Algorithmus dekodiert werden kann. |
| symbol_contrast | Liest die Symbolkontrast-Bewertung basierend auf dem Unterschied zwischen maximaler und minimaler Reflektivität. |
| minimum_reflectance | Ermittelt den minimalen Reflexionsgrad basierend auf der dunkelsten Balkenreflexion. |
| minimum_edge_contrast | Ermittelt den minimalen Kantenkontrastgrad basierend auf dem kleinsten Reflexionsunterschied zwischen benachbarten Balken und Zwischenräumen. |
| modulation | Ermittelt den Modulationsgrad basierend auf der Gleichmäßigkeit des Kantenkonasts im gesamten Barcode. |
| defects | Ermittelt den Defektgrad basierend auf Reflexionsunregelmäßigkeiten innerhalb von Balken und Zwischenräumen. |
| decodability | Ermittelt den Dekodierbarkeitsgrad basierend auf der Genauigkeit der Balken- und Zwischenraumbreiten. |
