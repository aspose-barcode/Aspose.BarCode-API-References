## Pdf417ExtendedParameters class

Speichert Metadateninformationen von MacroPdf417 des erkannten Barcodes

Der Typ Pdf417ExtendedParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_empty | Prüft, ob alle Parameter nur Standardwerte haben |
| macro_pdf_417_file_id | Liefert die Datei-ID des Barcodes, nur verfügbar mit MacroPdf417. |
| macro_pdf_417_segment_id | Liefert die Segment-ID des Barcodes, nur verfügbar mit MacroPdf417. |
| macro_pdf_417_segments_count | Liefert die Anzahl der Macro-PDF417-Barcode-Segmente. Standardwert ist -1. |
| macro_pdf_417_file_name | Macro PDF417-Dateiname (optional). |
| macro_pdf_417_file_size | Macro PDF417-Dateigröße (optional). |
| macro_pdf_417_sender | Macro PDF417-Absendername (optional). |
| macro_pdf_417_addressee | Macro PDF417-Empfängername (optional). |
| macro_pdf_417_time_stamp | Macro PDF417 Zeitstempel (optional). |
| macro_pdf_417_checksum | Macro PDF417 Prüfsumme (optional). |
| macro_pdf_417_terminator | Gibt an, ob das Segment das letzte Segment einer Macro PDF417-Datei ist. |
| is_reader_initialization | Wird verwendet, um den Leser anzuweisen, die im Symbol enthaltenen Daten als Programmierung für die Leserinitialisierung zu interpretieren. |
| is_linked | Flag, das angibt, dass der Barcode mit einem 1D-Barcode verknüpft sein muss. |
| is_code_128_emulation | Flag, das angibt, dass der MicroPdf417-Barcode mit den Code‑128‑Emulationscodewörtern 908, 909, 910 oder 911 codiert ist. |
