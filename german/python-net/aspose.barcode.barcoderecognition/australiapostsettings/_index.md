## AustraliaPostSettings class

Dekodierungsparameter für AustraliaPost. Enthält Parameter, die Einfluss auf die erkannten Daten der AustraliaPost‑Symbolik haben.

Der Typ AustraliaPostSettings stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| customer_information_interpreting_type | Liest oder setzt den Interpretationstyp für die Kundeninformationen des AustralianPost BarCode. Standard ist CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | Das Flag, das den AustraliaPost‑Decoder zwingt, die letzten Füllmuster im Kundeninformationsfeld beim Dekodieren nach der CTable‑Methode zu ignorieren.<br/>            Die CTable‑Kodierungsmethode hat keine Lücken in der Kodierungstabelle und die Sequenz \"333\" von Füllmustern wird als Buchstabe \"z\" dekodiert. |
| customer_information_decoder | Öffentliche Schnittstelle für das Dekodieren des Kundeninformationsfeldes, das in der AustraliaPost‑Symbologie verwendet wird. |
