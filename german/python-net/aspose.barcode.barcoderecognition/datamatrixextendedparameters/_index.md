## DataMatrixExtendedParameters class

Speichert spezielle Daten des erkannten DataMatrix‑Barcodes

Der Typ DataMatrixExtendedParameters stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_empty | Prüft, ob alle Parameter nur Standardwerte haben |
| structured_append_barcodes_count | Ruft die Anzahl der DataMatrix‑Structured‑Append‑Barcodes ab. Der Standardwert ist -1. Die Anzahl muss ein Wert zwischen 1 und 35 sein. |
| structured_append_barcode_id | Ruft die ID des DataMatrix‑Structured‑Append‑Barcodes ab. Die ID beginnt bei 1 und muss kleiner oder gleich der Barcode‑Anzahl sein. Der Standardwert ist -1. |
| structured_append_file_id | Ruft die ID des DataMatrix‑Structured‑Append‑Barcodes ab. Die ID beginnt bei 1 und muss kleiner oder gleich der Barcode‑Anzahl sein. Der Standardwert ist -1. |
| is_reader_programming | Gibt an, ob der Code verwendet wird, um den Leser anzuweisen, die folgenden Daten als Anweisungen für die Initialisierung oder Neuprogrammierung des Barcodelesers zu interpretieren.<br/>            Standardwert ist false. |
