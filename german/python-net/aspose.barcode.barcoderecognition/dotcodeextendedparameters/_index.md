## DotCodeExtendedParameters class

Speichert spezielle Daten des erkannten DotCode-Barcodes

Der **DotCodeExtendedParameters**-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_empty | Prüft, ob alle Parameter nur Standardwerte haben |
| structured_append_mode_barcodes_count | Ermittelt die Anzahl der DotCode Structured Append Mode Barcodes. Standardwert ist -1. Die Anzahl muss ein Wert von 1 bis 35 sein. |
| structured_append_mode_barcode_id | Ermittelt die ID des DotCode Structured Append Mode Barcodes. Die ID beginnt bei 1 und muss kleiner oder gleich der Barcode-Anzahl sein. Standardwert ist -1. |
| is_reader_initialization | Gibt an, ob der Code verwendet wird, um den Leser anzuweisen, die folgenden Daten als Anweisungen für die Initialisierung oder Neuprogrammierung des Barcodelesers zu interpretieren.<br/>            Standardwert ist false. |
