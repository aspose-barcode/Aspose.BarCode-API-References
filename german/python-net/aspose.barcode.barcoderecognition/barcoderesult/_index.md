## BarCodeResult class

Speichert erkannte Barcode‑Daten wie den Typ [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/), den Zeichenketten‑Codetext, <br/>            die Region [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) und weitere Parameter.

Der Typ BarCodeResult stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| BarCodeResult(result) | Initialisiert eine neue Instanz der BarCodeResult-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| reading_quality | Liefert die Lesequalität. Funktioniert für 1D- und Post-Barcodes. |
| confidence | Liefert das Erkennungs‑Vertrauensniveau des erkannten Barcodes |
| code_text | Liefert den Code-Text |
| code_bytes | Liefert die codierten Code‑Bytes |
| code_type | Liefert den Barcode-Typ |
| code_type_name | Liefert den Namen des Barcode-Typs |
| Region | Liefert die Barcode-Region |
| erweitert | Liefert erweiterte Parameter des erkannten Barcodes |
| iso_symbol_quality | Liefert die ISO/IEC-Symbolqualitätsbewertungsergebnisse für den erkannten Barcode. |
