## CustomerInformationInterpretingType enumeration

Definiert den Interpretationstyp (CTable, NTable oder Other) von Kundeninformationen für den AustralianPost‑Barcode.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| C_TABLE | Verwenden Sie CTable, um Kundeninformationen zu interpretieren. Erlaubt A..Z, a..z, 1..9, Leerzeichen und das Zeichen #. |
| N_TABLE | Verwenden Sie NTable, um Kundeninformationen zu interpretieren. Erlaubt Ziffern. |
| OTHER | Interpretieren Sie die Kundeninformationen nicht. Erlaubt nur das Symbol 0, 1, 2 oder 3. |
