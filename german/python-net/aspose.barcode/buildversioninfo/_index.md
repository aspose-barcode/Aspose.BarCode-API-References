## BuildVersionInfo class

Enthält die aktuelle Build‑Versionsinformation.

Der Typ BuildVersionInfo stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| ASSEMBLY_VERSION | Die Assembly-Version. |
| FILE_VERSION | Die Dateiversion. |
| PRODUCT | Der Produkttitel. |
| PRODUCT_MAJOR | Die Hauptproduktversion. |
| PRODUCT_MINOR | Die Nebenproduktversion. |
| RELEASE_DATE | Das Produktveröffentlichungsdatum. |
