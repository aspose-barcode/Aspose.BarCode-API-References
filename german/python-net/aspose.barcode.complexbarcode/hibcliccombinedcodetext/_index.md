## HIBCLICCombinedCodetext class

Klasse zum Codieren und Decodieren des in den HIBC LIC-Code eingebetteten Textes, der primäre und sekundäre Daten speichert.

Der Typ HIBCLICCombinedCodetext stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| HIBCLICCombinedCodetext() | Initialisiert eine neue Instanz der Klasse HIBCLICCombinedCodetext. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| barcode_type | Liest oder setzt den Barcode-Typ. HIBC LIC Codetext kann mit HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC und HIBCQRLIC Kodierungstypen codiert werden.<br/>            Standardwert: HIBCCode39LIC. |
| primary_data | Identifiziert Primärdaten. |
| secondary_and_additional_data | Identifiziert sekundäre und zusätzliche ergänzende Daten. |
