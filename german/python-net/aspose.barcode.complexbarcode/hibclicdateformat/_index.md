## HIBCLICDateFormat enumeration

Gibt die verschiedenen Typen von Datumsformaten für HIBC LIC an.

## Members
| Member‑Name | Beschreibung |
| :- | :- |
| YYYYMMDD | YYYYMMDD-Format. Wird in zusätzlichen Ergänzungsdaten codiert. |
| MMYY | MMYY-Format. |
| MMDDYY | MMDDYY-Format. |
| YYMMDD | YYMMDD-Format. |
| YYMMDDHH | YYMMDDHH-Format. |
| YYJJJ | Julianisches Datumsformat. |
| YYJJJHH | Julianisches Datumsformat mit Stunden. |
| NONE | Ablaufdatum nicht codieren. |
