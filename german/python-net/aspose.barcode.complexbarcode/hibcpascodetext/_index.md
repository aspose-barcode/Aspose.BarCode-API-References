## HIBCPASCodetext class

Klasse zum Codieren und Decodieren des in den HIBC PAS-Code eingebetteten Textes.

Der Typ HIBCPASCodetext stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| HIBCPASCodetext() | Initialisiert eine neue Instanz der Klasse HIBCPASCodetext |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| barcode_type | Liest oder setzt den Barcode-Typ. HIBC PAS Codetext kann mit den Kodierungstypen HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS und HIBCQRPAS codiert werden.<br/>            Standardwert: HIBCCode39PAS. |
| data_location | Identifiziert den Datenort. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| add_record(data_type, data) | Fügt einen neuen Datensatz hinzu |
| add_record(record) | Fügt einen neuen Datensatz hinzu |
| get_records() | Liest die Datensatzliste |
| clear() | Löscht die Datensatzliste |
| get_barcode_type() | Liest den Barcode-Typ. |
| get_constructed_codetext() | Erstellt Codetext |
| init_from_string(constructed_codetext) | Initialisiert die Instanz aus dem erstellten Codetext. |
