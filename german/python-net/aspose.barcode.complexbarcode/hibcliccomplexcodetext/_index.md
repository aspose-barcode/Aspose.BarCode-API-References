## HIBCLICComplexCodetext class

Basisklasse zum Codieren und Decodieren des in den HIBC LIC-Code eingebetteten Textes.

Der Typ HIBCLICComplexCodetext stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| barcode_type | Liest oder setzt den Barcode-Typ. HIBC LIC Codetext kann mit HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC und HIBCQRLIC Kodierungstypen codiert werden.<br/>            Standardwert: HIBCCode39LIC. |

| Name | Beschreibung |
| :- | :- |
