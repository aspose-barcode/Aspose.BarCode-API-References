## MaxiCodeStandardCodetext class

Klasse zum Codieren und Decodieren des MaxiCode-Codetexts für die Modi 4, 5 und 6.

Der Typ MaxiCodeStandardCodetext stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| MaxiCodeStandardCodetext() | Initialisiert eine neue Instanz der Klasse MaxiCodeStandardCodetext |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| encode_mode | Liest oder setzt einen MaxiCode-Codierungsmodus. <br/>            Standardwert: Auto. |
| eci_encoding | Liest oder setzt die ECI-Kodierung. Wird verwendet, wenn MaxiCodeEncodeMode auf Auto steht.<br/>            Standardwert: ISO-8859-1 |
| Modus | Ruft den MaxiCode-Modus ab oder legt ihn fest. Standard-Codetext kann nur mit den Modi 4, 5 und 6 verwendet werden. |
| message | Ruft die Nachricht ab oder legt sie fest. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| get_mode() | Ermittelt den MaxiCode-Modus. |
| get_constructed_codetext() | Erstellt Codetext |
| init_from_string(constructed_codetext) | Initialisiert die Instanz aus dem erstellten Codetext. |
| get_barcode_type() | Liest den Barcode-Typ. |
