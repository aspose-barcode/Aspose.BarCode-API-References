## DataElement class

Stellt ein jurisdictionsspezifisches Datenfeld dar, das in Dokumenten verwendet wird, zum Beispiel ElementID = "ZVA" mit Wert = "01".

```js
new DataElement()
```

## Methoden

| Name | Beschreibung |

| [getValue()](#getvalue) | Der Textwert, der dem Feld zugeordnet ist, typischerweise durch jurisdictionsspezifische Regeln definiert. |
