## Code128DataPortion class

Enthält die Daten des Subtyps für den Code128-Barcode.

```js
new Code128DataPortion()
```

Erstellt eine neue Instanz der `Code128DataPortion`-Klasse mit Startcode‑Symbol und dekodiertem Codetext.

## Methoden

| Name | Beschreibung |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Gibt den Typ des Code128-Subset zurück. |
| [getData()](#getdata) | Gibt den Teil des Codetextes zurück, der sich auf den Subtyp bezieht. |
| [toString()](#tostring) | Gibt eine menschenlesbare Zeichenkettenrepräsentation dieses `Code128DataPortion` zurück. |

### getCode128SubType() {#getcode128subtype}

Gibt den Typ des Code128-Subset zurück.

**Returns:** The type of Code128 subset

### getData() {#getdata}

Gibt den Teil des Codetextes zurück, der sich auf den Subtyp bezieht.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Gibt eine menschenlesbare Zeichenkettenrepräsentation dieses `Code128DataPortion` zurück.

**Returns:** A string that represents this `Code128DataPortion`.
