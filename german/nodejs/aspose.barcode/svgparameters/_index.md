### getSvgColorMode() {#getsvgcolormode}

Mögliche Modi zum Füllen von Farben in SVG‑Dateien, RGB ist Standard und wird von SVG 1.1 unterstützt. RGBA, HSL, HSLA sind im SVG 2.0‑Standard zulässig. Selbst bei RGB wird die Deckkraft über den Parameter "fill-opacity" gesetzt

### isExplicitSizeInPixels() {#isexplicitsizeinpixels}

Enthält das SVG‑Bild eine explizite Größe in Pixeln (empfohlen). Standardwert: true.

### isTextDrawnInTextElement() {#istextdrawnintextelement}

Enthält das SVG‑Bild Text als Textelement statt Pfade (empfohlen). Standardwert: true.

### setExplicitSizeInPixels() {#setexplicitsizeinpixels}

Enthält das SVG‑Bild eine explizite Größe in Pixeln (empfohlen). Standardwert: true.

### setSvgColorMode() {#setsvgcolormode}

Mögliche Modi zum Füllen von Farben in SVG‑Dateien, RGB ist Standard und wird von SVG 1.1 unterstützt. RGBA, HSL, HSLA sind im SVG 2.0‑Standard zulässig. Selbst bei RGB wird die Deckkraft über den Parameter "fill-opacity" gesetzt

### setTextDrawnInTextElement() {#settextdrawnintextelement}

Enthält das SVG‑Bild Text als Textelement statt Pfade (empfohlen). Standardwert: true.
