## RecognitionAbortedException class

Stellt die Erkennungsabbruch‑Exception dar, die bei Überschreitung des Zeitlimits während der Erkennung mit BarCodeReader ausgelöst wird.

```js
new RecognitionAbortedException(message, executionTime)
```

Initialisiert eine neue Instanz der Klasse mit einer angegebenen Abbruchnachricht für die Erkennung.

| Parameter | Beschreibung |
| --- | --- |
| Nachricht | Die Fehlermeldung der Ausnahme. |
| executionTime | Die Ausführungszeit der aktuellen Erkennungssitzung. |
