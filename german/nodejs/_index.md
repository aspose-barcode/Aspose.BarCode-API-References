Die API stellt Klassen für die Erstellung, Erkennung und Manipulation von Barcodes bereit und ermöglicht eine nahtlose Integration in Node.js‑Anwendungen über Java‑Interop. Unterstützte Symbologien umfassen lineare, 2‑D‑ und Postcodes wie Code128, EAN‑13, QR, DataMatrix, Aztec und PDF417. Alle Funktionen sind im aspose.barcode‑Namespace organisiert, wobei Hilfs‑Utilities im Global‑Namespace zu finden sind.

## Namensräume

| Namensraum | Beschreibung |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | Der aspose.barcode‑Namespace bietet Klassen und Aufzählungen zum Erstellen, Anpassen und Dekodieren einer breiten Palette von Barcode‑Typen in Node.js über Java. |
| [Global](./global/) | Der Global‑Namespace fasst Kern‑Aufzählungen und Hilfsklassen zusammen, die in Aspose.BarCode für Node.js über Java verwendet werden. |
