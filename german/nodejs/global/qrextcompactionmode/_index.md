## QrExtCompactionMode

Gibt den QR-Komprimierungsmodus für den von QrExtCodetextBuilder hinzugefügten Codetext an.

## Werte

| Name | Beschreibung |
| --- | --- |
| AUTO | Der Encoder wählt den effizientesten QR-Komprimierungsmodus automatisch aus. |
| NUMERIC | Kodiert den Codetext im QR-Numerikmodus. Nur Ziffern 0‑9 sind erlaubt. |
| ALPHA_NUMERIC | Kodiert den Codetext im QR-Alphanumerikmodus. |
| BYTES | Kodiert den Codetext im QR-Byte‑Modus. |
| KANJI | Kodiert den Codetext im QR-Kanji‑Modus. |
