## DataMatrixEccType

Geben Sie den Typ des zu kodierenden ECC an.

## Werte

| Name | Beschreibung |
| --- | --- |
| ECC_AUTO | Gibt an, dass der codierte ECC-Typ standardmäßig durch Reed-Solomon-Fehlerkorrektur oder ECC 200 definiert ist. |
| ECC_000 | Gibt an, dass der codierte ECC-Typ ECC 000 definiert ist. |
| ECC_050 | Gibt an, dass der codierte ECC-Typ ECC 050 definiert ist. |
| ECC_080 | Gibt an, dass der codierte ECC-Typ ECC 080 definiert ist. |
| ECC_100 | Gibt an, dass der codierte ECC-Typ ECC 100 definiert ist. |
| ECC_140 | Gibt an, dass der codierte ECC-Typ ECC 140 definiert ist. |
| ECC_200 | Gibt an, dass der codierte Ecc-Typ als ECC 200 definiert ist. Empfohlen zu verwenden. |
