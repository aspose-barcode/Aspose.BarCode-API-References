## Pdf417ErrorLevel

Fehlerkorrekturstufe des pdf417-Barcodes, von Stufe 0 bis Stufe 9; Stufe 0 bedeutet keine Fehlerkorrektur, Stufe 9 bedeutet maximale Fehlerkorrektur.

## Werte

| Name | Beschreibung |
| --- | --- |
| LEVEL_0 | Ebene = 0. |
| LEVEL_1 | Ebene = 1. |
| LEVEL_2 | Ebene = 2. |
| LEVEL_3 | Ebene = 3. |
| LEVEL_4 | Ebene = 4. |
| LEVEL_5 | Ebene = 5. |
| LEVEL_6 | Ebene = 6. |
| LEVEL_7 | Ebene = 7. |
| LEVEL_8 | Ebene = 8. |
