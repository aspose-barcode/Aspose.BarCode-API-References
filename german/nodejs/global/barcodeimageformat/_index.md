## BarCodeImageFormat

Gibt das Dateiformat des Bildes an.

## Werte

| Name | Beschreibung |
| --- | --- |
| BMP | Gibt das Bitmap (BMP)-Bildformat an. |
| GIF | Gibt das Graphics Interchange Format (GIF)-Bildformat an. |
| JPEG | Gibt das Joint Photographic Experts Group (JPEG)-Bildformat an. |
| PNG | Gibt das W3C Portable Network Graphics (PNG)-Bildformat an. |
| TIFF | Gibt das Tagged Image File Format (TIFF)-Bildformat an. |
| TIFF_IN_CMYK | Gibt das Tagged Image File Format (TIFF)-Bildformat im CMYK-Farbmodell an. |
| EMF | Gibt das Enhanced Metafile (EMF)-Bildformat an. |
| SVG | Gibt das Scalable Vector Graphics (SVG)-Bildformat an. |
| PDF | Gibt das Portable Document Format (PDF)-Bildformat an. |
