## GraphicsUnit

Gibt die Maßeinheit für die angegebenen Daten an.

## Werte

| Name | Beschreibung |
| --- | --- |
| WORLD | Gibt die Einheit des Weltkoordinatensystems als Maßeinheit an. |
| DISPLAY | Gibt die Maßeinheit des Anzeigegeräts an. Typischerweise Pixel für Videodisplays und 1/100 Zoll für Drucker. |
| PIXEL | Gibt ein Geräte‑Pixel als Maßeinheit an. |
| POINT | Gibt den Punkt eines Druckers (= 1/72 Zoll) als Maßeinheit an. |
| INCH | Gibt den Zoll als Maßeinheit an. |
| DOCUMENT | Gibt die Dokumenteinheit (= 1/300 Zoll) als Maßeinheit an. |
| MILLIMETER | Gibt den Millimeter als Maßeinheit an. |
