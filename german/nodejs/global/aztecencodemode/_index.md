## AztecEncodeMode

Kodierungsmodus für Aztec-Barcodes.

## Werte

| Name | Beschreibung |
| --- | --- |
| AUTO | Gibt an, dass automatisch das beste Symbol (COMPACT oder FULL-range) für Aztec ausgewählt wird. Dies ist der Standardwert. |
| COMPACT | Gibt das COMPACT-Symbol für Aztec an. Das Aztec COMPACT-Symbol erlaubt nur 1, 2, 3 oder 4 Ebenen. |
| FULL_RANGE | Gibt das FULL-range-Symbol für Aztec an. Das Aztec FULL-range-Symbol erlaubt von 1 bis 32 Ebenen. |
| RUNE | Gibt das RUNE-Symbol für Aztec an. Aztec Runes sind eine Reihe kleiner, aber unterscheidbarer maschinenlesbarer Markierungen. Es erlaubt nur Zahlenwerte von 0 bis 255. |
