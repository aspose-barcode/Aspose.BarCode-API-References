## MacroCharacter

Macrozeichen 05 und 06 Werte werden verwendet, um in speziellen Modi eine kompaktere Kodierung zu erhalten. Das 05‑Macro‑Zeichen wird in "[)>\u001E05\u001D" als dekodierter Datenkopf und "\u001E\u0004" als dekodierter Datentrailer übersetzt. Das 06‑Macro‑Zeichen wird in "[)>\u001E06\u001D" als dekodierter Datenkopf und "\u001E\u0004" als dekodierter Datentrailer übersetzt. Diese Beispiele zeigen, wie man Macrozeichen in MicroPdf417 und DataMatrix kodiert.

## Werte

| Name | Beschreibung |
| --- | --- |
| AUTO | Automatisch bestimmen |
| TYPE_7 | 24 x 24 Module |
| TYPE_9 | 32 x 32 Module |
| TYPE_29 | 16 x 48 Module |
