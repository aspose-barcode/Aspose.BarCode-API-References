## CodabarSymbol

Gibt das Start- oder Stoppsymbol der Codabar-Barcode-Spezifikation an.

## Werte

| Name | Beschreibung |
| --- | --- |
| A | Gibt das Zeichen A als Start- oder Stoppsymbol der Codabar-Barcode-Spezifikation an. |
| B | Gibt das Zeichen B als Start- oder Stoppsymbol der Codabar-Barcode-Spezifikation an. |
| C | Gibt das Zeichen C als Start‑ oder Stoppsymbol der Codabar‑Barcode‑Spezifikation an. |
| D | Gibt das Zeichen D als Start‑ oder Stoppsymbol der Codabar‑Barcode‑Spezifikation an. |
