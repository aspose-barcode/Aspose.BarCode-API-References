## FontMode

Schriftgrößenmodus.

## Werte

| Name | Beschreibung |
| --- | --- |
| AUTO | Berechnet die Schriftgröße automatisch basierend auf der Barcode-Größe. |
| MANUAL | Verwende die vom Benutzer definierte Schriftgröße. |
