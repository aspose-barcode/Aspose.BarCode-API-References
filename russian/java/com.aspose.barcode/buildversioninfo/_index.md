Предоставляет информацию о текущем названии продукта и его версии. Показывает, как использовать BuildVersionInfo для получения информации об этом продукте. System.out.prinln(MessageFormat.format("I am currently using %s, version number %s.", BuildVersionInfo.PRODUCT, BuildVersionInfo.ASSEMBLY\_VERSION));
