### getSvgColorMode() {#getSvgColorMode--}
```
public SvgColorMode getSvgColorMode()
```


Возможные режимы заполнения цвета в файле SVG, RGB является режимом по умолчанию и поддерживается SVG 1.1. RGBA, HSL, HSLA допускаются в стандарте SVG 2.0. Даже в RGB непрозрачность будет задаваться параметром "fill-opacity".
