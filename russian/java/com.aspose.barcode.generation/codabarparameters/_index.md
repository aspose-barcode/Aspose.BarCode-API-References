### getChecksumMode() {#getChecksumMode--}
```
public final CodabarChecksumMode getChecksumMode()
```


Получите алгоритм контрольной суммы для штрихкодов Codabar. Значение по умолчанию: CodabarChecksumMode.Mod16. Чтобы включить вычисление контрольной суммы, установите значение EnableChecksum.Yes в свойство EnableChecksum. См. ChecksumMode (\#getChecksumMode.getChecksumMode/\#setChecksumMode.setChecksumMode).

**Returns:**
[CodabarChecksumMode](../../com.aspose.barcode.generation/codabarchecksummode) - the checksum algorithm for Codabar barcodes.
