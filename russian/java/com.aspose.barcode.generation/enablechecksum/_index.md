Включить контрольную сумму при генерации 1D штрихкодов.

По умолчанию считается Yes для символогий, которые обязаны содержать контрольную сумму, и No, где контрольная сумма возможна только.

Контрольная сумма никогда не используется: Codabar

Контрольная сумма возможна: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN

Контрольная сумма всегда используется: остальные символогии
## Поля

| Поле | Описание |
| --- | --- |
| [DEFAULT](#DEFAULT) | Если контрольная сумма требуется спецификацией, она будет добавлена. |
| [NO](#NO) | Не использовать контрольную сумму. |
| [YES](#YES) | Всегда использовать контрольную сумму, если возможно. |
