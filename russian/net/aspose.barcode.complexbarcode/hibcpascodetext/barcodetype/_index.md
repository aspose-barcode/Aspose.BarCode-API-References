## HIBCPASCodetext.BarcodeType property

Получает или задает тип штрихкода. Текст кода HIBC PAS может быть закодирован с использованием типов кодирования HIBCCode39PAS, HIBCCode128PAS, HIBCAztec:PAS, HIBCDataMatrixPAS и HIBCQRPAS. Значение по умолчанию: HIBCCode39PAS.

```csharp
public BaseEncodeType BarcodeType { get; set; }
```

### Возвращаемое значение

Тип штрихкода.
