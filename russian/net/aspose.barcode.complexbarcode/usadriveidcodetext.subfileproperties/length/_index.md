## USADriveIdCodetext.SubfileProperties.Length property

Эти 4 байта содержат 4‑значное числовое значение, указывающее длину подфайла в байтах. Терминатор сегмента должен быть включён при расчёте длины подфайла. Терминатор сегмента = 1. Каждый подфайл должен начинаться с двухсимвольного типа Subfile, и эти два символа также должны быть включены в длину.

public int Length { get; set; }
