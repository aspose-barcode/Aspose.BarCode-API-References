## GS1Codetext.BarcodeType property

Получает или задает тип штрихкода, используемый для кодирования этого GS1 codetext. Поддерживаемые типы: GS1Aztec, GS1CodablockF, GS1Code128, GS1DataMatrix, GS1DotCode, GS1HanXin, GS1MicroPdf417, GS1QR и типы GS1 DataBar. Значение по умолчанию — GS1Code128.

public BaseEncodeType BarcodeType { get; set; }
