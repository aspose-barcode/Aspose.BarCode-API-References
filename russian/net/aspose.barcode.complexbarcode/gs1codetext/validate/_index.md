## GS1Codetext.Validate method

Проверяет строку элемента GS1 в скобочном виде (AI)value(AI)value без создания объекта. Буквальная '(' внутри значения должна быть записана как \(. Другие последовательности экранирования не поддерживаются, а ')' экранировать не требуется.

```csharp
public static GS1ValidationResult Validate(string value)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| value | String | Строка элемента GS1 в скобках для проверки. |

### Возвращаемое значение

Структурированный результат проверки.
