## GS1Codetext.Parse method

Разбирает строку элемента GS1 в скобочном виде (AI)value(AI)value. Буквальная '(' внутри значения должна быть записана как \(. Другие последовательности экранирования не поддерживаются, а ')' экранировать не требуется.

```csharp
public static GS1Codetext Parse(string value)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| value | String | Строка элемента GS1 в скобках для разбора. |

### Возвращаемое значение

Разобранный текст GS1.
