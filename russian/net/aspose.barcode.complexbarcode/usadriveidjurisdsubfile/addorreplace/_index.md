## AddOrReplace(string, string) {#addorreplace_1}

Добавляет новый DataElement с указанным идентификатором и значением, либо заменяет существующий элемент, если запись с тем же ElementID уже присутствует.

```csharp
public DataElement AddOrReplace(string id, string value)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| ид | String | Трёхбуквенный идентификатор, который однозначно определяет связанный с юрисдикцией элемент данных. |
| value | String | Текстовое значение, присвоенное элементу данных; это значение перезапишет существующее, если элемент уже существует. |

### Возвращаемое значение

Экземпляр DataElement, который был добавлен в коллекцию или обновлён на месте.
