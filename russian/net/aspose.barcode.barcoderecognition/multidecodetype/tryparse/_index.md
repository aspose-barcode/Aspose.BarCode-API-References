## MultiDecodeType.TryParse method

Преобразует строковое представление MultiDecodeType в его экземпляр. Возвращаемое значение указывает, удалось ли преобразование или нет.

```csharp
public static bool TryParse(string parsingType, out MultiDecodeType result)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| parsingType | String | Строка в формате либо "AllSupportedTypes", либо "EAN8,EAN13,CodaBar" для преобразования. |
| result | MultiDecodeType& | Фактический MultiDecodeType возвращается, когда преобразование завершилось успешно; |

### Возвращаемое значение

**true** if s was converted successfully; otherwise, **false**.
