## DotCodeExtendedParameters.StructuredAppendModeBarcodeId property

Получает идентификатор штрих‑кода DotCode в режиме структурированного добавления. Идентификатор начинается с 1 и должен быть меньше или равен количеству штрих‑кодов. Значение по умолчанию — -1.

```csharp
public int StructuredAppendModeBarcodeId { get; }
```

### Property Value

Идентификатор штрих‑кода режима структурного добавления DotCode.
