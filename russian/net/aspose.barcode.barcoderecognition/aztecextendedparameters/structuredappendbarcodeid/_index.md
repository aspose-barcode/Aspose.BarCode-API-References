## AztecExtendedParameters.StructuredAppendBarcodeId property

Получает ID штрих‑кода Aztec в режиме структурированного добавления. ID начинается с 1 и должен быть меньше или равен количеству штрих‑кодов. Значение по умолчанию — 0.

```csharp
public int StructuredAppendBarcodeId { get; }
```

### Property Value

Идентификатор штрих‑кода режима структурного добавления Aztec.
