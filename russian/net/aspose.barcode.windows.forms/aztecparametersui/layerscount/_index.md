## AztecParametersUI.LayersCount property

Получает или задает количество слоёв символа Aztec. Количество слоёв должно быть в диапазоне от 1 до 3 для режима Compact и от 1 до 32 для режима Full Range. Значение по умолчанию: 0 (авто).

```csharp
public int LayersCount { get; set; }
```
