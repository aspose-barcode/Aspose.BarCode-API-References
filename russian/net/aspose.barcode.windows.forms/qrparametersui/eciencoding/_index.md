## QrParametersUI.ECIEncoding property

Идентификаторы расширенной интерпретации канала. Они используются для передачи считывателю штрих‑кода деталей о используемых ссылках для кодирования данных в символе. Текущая реализация включает все известные кодировки наборов символов. Не поддерживается MicroQR.

public ECIEncodings ECIEncoding { get; set; }
