## QrExtCodetextBuilder.AddCodetextWithCompactionMode method

Добавляет кодовый текст с указанным режимом сжатия QR к элементам расширенного кодового текста.

```csharp
public void AddCodetextWithCompactionMode(QrExtCompactionMode mode, string codetext)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| режим | QrExtCompactionMode | Режим сжатия QR для кодового текста. |
| codetext | String | Кодовый текст в Unicode, который следует добавить как элемент расширенного кодового текста. |

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentException | Указанный кодовый текст нельзя закодировать в выбранном режиме сжатия QR. |
