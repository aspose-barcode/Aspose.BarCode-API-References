## Pdf417MacroTerminator enumeration

Используется, чтобы указать кодировщику, следует ли добавить терминатор Macro PDF417 (кодовое слово 922) в сегмент. Применяется только для Macro PDF417.

```csharp
public enum Pdf417MacroTerminator
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Терминатор будет добавлен автоматически, если указано количество сегментов и текущий сегмент является последним. В остальных случаях терминатор не будет добавлен. |
| None | `1` | Терминатор не будет добавлен. |
| Set | `2` | Терминатор будет добавлен. |
