## GS1ValidationLevel enumeration

Указывает уровень проверки данных GS1. Более высокие уровни включают все проверки более низких уровней.

```csharp
public enum GS1ValidationLevel
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Syntax | `0` | Проверяет синтаксис GS1, включая идентификаторы приложений, длины полей и требуемые разделители. |
| Content | `1` | Проверяет синтаксис GS1 и содержимое значений идентификаторов приложений, включая наборы символов, контрольные суммы и правила, специфичные для значений. |
