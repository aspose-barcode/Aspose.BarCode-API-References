## Pdf417Parameters.ECIEncoding property

Extended Channel Interpretation Identifiers. Используется для передачи считывателю штрих‑кода деталей о используемых ссылках для кодирования данных в символе. Не применяется к текстовым полям Macro PDF417. Текущая реализация включает все известные кодировки наборов символов.

public ECIEncodings ECIEncoding { get; set; }
