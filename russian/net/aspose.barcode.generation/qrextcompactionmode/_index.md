## QrExtCompactionMode enumeration

Указывает режим сжатия QR для кодового текста, добавляемого QrExtCodetextBuilder.

```csharp
public enum QrExtCompactionMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Кодировщик автоматически выбирает наиболее эффективный режим сжатия QR. |
| Numeric | `1` | Кодирует кодовый текст в числовом режиме QR. Допустимы только цифры 0-9. |
| AlphaNumeric | `2` | Кодирует кодовый текст в альфа-цифровом режиме QR. |
| Bytes | `3` | Кодирует кодовый текст в байтовом режиме QR. |
| Kanji | `4` | Кодирует кодовый текст в режиме QR Kanji. |
