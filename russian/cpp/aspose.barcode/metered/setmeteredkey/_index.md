## Metered::SetMeteredKey method


Устанавливает публичный и приватный счётный ключ. Если вы покупаете счётную лицензию, при запуске приложения этот API должен быть вызван, обычно этого достаточно. Однако, если постоянно не удаётся загрузить данные потребления и прошло более 24 часов, лицензия будет переведена в статус оценки; чтобы избежать этого, следует регулярно проверять статус лицензии, и если он находится в статусе оценки, вызвать этот API снова.

```cpp
void Aspose::BarCode::Metered::SetMeteredKey(System::String publicKey, System::String privateKey)
```


| Parameter | Type | Описание |
| --- | --- | --- |
| publicKey | System::String | публичный ключ |
| privateKey | System::String | приватный ключ |
