## HIBCLICDateFormat enum


Указывает различные типы форматов дат для HIBC LIC.

```cpp
enum class HIBCLICDateFormat
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| YYYYMMDD | 0 | Формат YYYYMMDD. Будет закодирован в дополнительных вспомогательных данных. |
| MMYY | 1 | Формат MMYY. |
| MMDDYY | 2 | Формат MMDDYY. |
| YYMMDD | 3 | Формат YYMMDD. |
| YYMMDDHH | 4 | Формат YYMMDDHH. |
| YYJJJ | 5 | Формат юлианской даты. |
| YYJJJHH | 6 | Формат юлианской даты с часами. |
| Нет | 7 | Не кодировать дату истечения срока. |
