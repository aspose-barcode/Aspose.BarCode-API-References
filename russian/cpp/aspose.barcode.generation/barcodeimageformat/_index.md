## BarCodeImageFormat enum


Указывает формат файла изображения.

```cpp
enum class BarCodeImageFormat
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Bmp | 0 | Указывает формат изображения bitmap (BMP). |
| Gif | 1 | Указывает формат изображения Graphics Interchange Format (GIF). |
| Jpeg | 2 | Указывает формат изображения Joint Photographic Experts Group (JPEG). |
| Png | 3 | Указывает формат изображения W3C Portable Network Graphics (PNG). |
| Tiff | 4 | Указывает формат изображения Tagged Image File Format (TIFF). |
| TiffInCmyk | 5 | Указывает формат изображения Tagged Image File Format (TIFF) в цветовой модели CMYK. (Поддерживается только на платформе [Windows](../../aspose.barcode.windows/), на платформах *nix сохраняется как Tiff) |
| Emf | 6 | Указывает формат изображения Enhanced Metafile (EMF). (Поддерживается только на платформе [Windows](../../aspose.barcode.windows/), на платформах *nix сохраняется как PNG) |
| Svg | 7 | Указывает формат изображения Scalable Vector Graphics (SVG). |
| Pdf | 8 | Указывает формат изображения Portable Document Format (PDF). |
