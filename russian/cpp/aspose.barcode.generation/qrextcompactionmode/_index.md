## QrExtCompactionMode enum


Указывает режим сжатия QR для текста кода, добавляемого [QrExtCodetextBuilder](../qrextcodetextbuilder/).

```cpp
enum class QrExtCompactionMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Авто | 0 | Кодировщик автоматически выбирает наиболее эффективный режим сжатия QR. |
| Числовой | 1 | Кодирует текст кода в числовом режиме QR. Допустимы только цифры 0-9. |
| Алфавитно-цифровой | 2 | Кодирует текст кода в алфавитно-цифровом режиме QR. |
| Bytes | 3 | Кодирует текст кода в байтовом режиме QR. |
| Кандзи | 4 | Кодирует текст кода в режиме QR Kanji. |
