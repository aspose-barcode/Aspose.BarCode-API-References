## BorderDashStyle enum


Указывает стиль пунктирных линий границы.

```cpp
enum class BorderDashStyle
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Сплошная | 0 | Указывает сплошную линию. |
| Пунктир | 1 | Указывает линию, состоящую из пунктиров. |
| Точка | 2 | Указывает линию, состоящую из точек. |
| DashDot | 3 | Указывает линию, состоящую из повторяющегося шаблона dash-dot. |
| DashDotDot | 4 | Указывает строку, состоящую из повторяющегося шаблона тире-точка-точка. |
