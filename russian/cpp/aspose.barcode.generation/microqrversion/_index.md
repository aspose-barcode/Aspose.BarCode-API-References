## MicroQRVersion enum


Версия MicroQR Code. От M1 до M4.

```cpp
enum class MicroQRVersion
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Авто | 0 | Указывает автоматически выбирать лучшую версию для MicroQR. Это значение по умолчанию. |
| M1 | 1 | Указывает версию M1 для Micro QR с 11 x 11 модулями. |
| M2 | 2 | Указывает версию M2 для Micro QR с 13 x 13 модулями. |
| M3 | 3 | Указывает версию M3 для Micro QR с 15 x 15 модулями. |
| M4 | 4 | Указывает версию M4 для Micro QR с 17 x 17 модулями. |
