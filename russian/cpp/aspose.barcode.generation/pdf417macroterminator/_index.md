## Pdf417MacroTerminator enum


Используется, чтобы указать кодировщику, добавлять ли терминатор Macro PDF417 (кодовое слово 922) к сегменту. Применяется только для Macro PDF417.

```cpp
enum class Pdf417MacroTerminator
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Авто | 0 | Терминатор будет добавлен автоматически, если указано количество сегментов и текущий сегмент является последним. В остальных случаях терминатор не будет добавлен. |
| Нет | 1 | Терминатор не будет добавлен. |
| Set | 2 | Терминатор будет добавлен. |
