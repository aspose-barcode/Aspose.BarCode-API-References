## CodetextParameters::set_FontMode method


Укажите FontMode. Если FontMode установлен в Auto, размер шрифта будет рассчитываться автоматически на основе значения xDimension. Рекомендуется использовать [FontMode.Auto](../../aztecencodemode/), особенно в [AutoSizeMode.Nearest](../../autosizemode/) или [AutoSizeMode.Interpolation](../../autosizemode/). Значение по умолчанию: [FontMode.Auto](../../aztecencodemode/).
