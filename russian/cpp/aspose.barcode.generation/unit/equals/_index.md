## Unit::Equals method


Определяет, имеют ли данный экземпляр и указанный объект, который также должен быть объектом [Unit](../), одинаковое значение.

```cpp
bool Aspose::BarCode::Generation::Unit::Equals(System::SharedPtr<System::Object> obj) override
```


| Parameter | Type | Описание |
| --- | --- | --- |
| obj | System::SharedPtr\<System::Object\> | Объект [Unit](../), с которым сравнивается данный экземпляр. |

### ReturnValue

true, если obj является [Unit](../) и его значение совпадает с этим экземпляром; иначе — false. Если obj равен null, метод возвращает false.
