## GS1ValidationLevel enum


Указывает уровень проверки данных GS1. Более высокие уровни проверки включают все проверки более низких уровней.

```cpp
enum class GS1ValidationLevel
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Синтаксис | 0 | Проверяет синтаксис GS1, включая идентификаторы приложений, длину полей и обязательные разделители. |
| Содержание | 1 | Проверяет синтаксис GS1 и содержание значений идентификаторов приложений, включая наборы символов, контрольные суммы и правила, специфичные для значений. |
