API предоставляет классы для создания, распознавания и обработки штрихкодов, обеспечивая бесшовную интеграцию в приложения Node.js через Java‑interop. Поддерживаемые симболологии включают линейные, 2‑D и почтовые коды, такие как Code128, EAN‑13, QR, DataMatrix, Aztec и PDF417. Вся функциональность организована в пространстве имён aspose.barcode, а вспомогательные утилиты находятся в пространстве имён Global.

## Пространства имён

| Пространство имён | Описание |
| --- | --- |
| [aspose.barcode](./aspose.barcode/) | Пространство имён aspose.barcode предоставляет классы и перечисления для создания, настройки и декодирования широкого спектра типов штрихкодов в Node.js через Java. |
| [Global](./global/) | Пространство имён Global объединяет основные перечисления и вспомогательные классы, используемые в Aspose.BarCode для Node.js через Java. |
