## PdfParameters class

Обёртка параметров PDF. Ожидает базовый экземпляр `mwObject`, который предоставляет соответствующие методы getter/setter, возвращающие/принимающие строки CMYK, такие как "30_100_0_30" или `null`.

```js
new PdfParameters(mwObject)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| mwObject | объект | – экземпляр класса Java PdfParameters |
