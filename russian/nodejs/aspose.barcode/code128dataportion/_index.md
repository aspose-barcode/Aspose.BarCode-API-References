## Code128DataPortion class

Содержит данные подтипа для штрих‑кода типа Code128

```js
new Code128DataPortion()
```

Создаёт новый экземпляр класса `Code128DataPortion` с символом стартового кода и декодированным текстом кода.

## Методы

| Имя | Описание |
| --- | --- |
| [getCode128SubType()](#getcode128subtype) | Получает тип подмножества Code128 |
| [getData()](#getdata) | Получает часть текста кода, относящуюся к подтипу. |
| [toString()](#tostring) | Возвращает человекочитаемое строковое представление этого `Code128DataPortion`. |

### getCode128SubType() {#getcode128subtype}

Получает тип подмножества Code128

**Returns:** The type of Code128 subset

### getData() {#getdata}

Получает часть текста кода, относящуюся к подтипу.

**Returns:** The part of code text related to subtype

### toString() {#tostring}

Возвращает человекочитаемое строковое представление этого `Code128DataPortion`.

**Returns:** A string that represents this `Code128DataPortion`.
