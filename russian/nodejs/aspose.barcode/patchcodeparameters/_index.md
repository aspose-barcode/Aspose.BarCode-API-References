### getExtraBarcodeText() {#getextrabarcodetext}

Указывает текст кода для дополнительного QR‑штрихкода, когда PatchCode генерируется в режиме страницы.

### getFormat() {#getformat}

Формат PatchCode. Выберите PatchOnly для генерации одиночного PatchCode. Используйте формат страницы для создания страницы Patch с PatchCodes в качестве границ. Значение по умолчанию: PatchFormat.PatchOnly

### getPatchFormat() {#getpatchformat}

> **Deprecated.** See method description for replacement.

**Returns:** PatchFormat

### setExtraBarcodeText() {#setextrabarcodetext}

Указывает текст кода для дополнительного QR‑штрихкода, когда PatchCode генерируется в режиме страницы.
