## SwissQRCodetext class

Класс для кодирования и декодирования текста, встроенного в код SwissQR.

```js
new SwissQRCodetext(bill)
```

Создаёт экземпляр SwissQRCodetext.

| Параметр | Описание |
| --- | --- |
| bill | Данные счета SwissQR |

**Throws:** BarcodeException
