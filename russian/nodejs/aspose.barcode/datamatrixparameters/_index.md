### getMacroCharacters() {#getmacrocharacters}

ISO/IEC 16022 5.2.4.7 Макросимволы 11.3 Протокол для макросимволов в первой позиции (только ECC 200) Значения Macro Characters 05 и 06 используются для получения более компактного кодирования в специальных режимах. Может использоваться только с DataMatrixEccType.ECC_200 или DataMatrixEccType.ECC_AUTO. Не может использоваться с EncodeTypes.GS_1_DATA_MATRIX. Значение по умолчанию: MacroCharacter.NONE.
