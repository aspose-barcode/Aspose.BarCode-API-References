### getSvgColorMode() {#getsvgcolormode}

Возможные режимы заполнения цвета в файле SVG, RGB является значением по умолчанию и поддерживается SVG 1.1. RGBA, HSL, HSLA допускаются в стандарте SVG 2.0. Даже в RGB непрозрачность будет задаваться параметром "fill-opacity"

### isExplicitSizeInPixels() {#isexplicitsizeinpixels}

Содержит ли изображение SVG явный размер в пикселях (рекомендовано). Значение по умолчанию: true.

### isTextDrawnInTextElement() {#istextdrawnintextelement}

Содержит ли изображение SVG текст как элемент текста, а не пути (рекомендовано). Значение по умолчанию: true.

### setExplicitSizeInPixels() {#setexplicitsizeinpixels}

Содержит ли изображение SVG явный размер в пикселях (рекомендовано). Значение по умолчанию: true.

### setSvgColorMode() {#setsvgcolormode}

Возможные режимы заполнения цвета в файле SVG, RGB является значением по умолчанию и поддерживается SVG 1.1. RGBA, HSL, HSLA допускаются в стандарте SVG 2.0. Даже в RGB непрозрачность будет задаваться параметром "fill-opacity"

### setTextDrawnInTextElement() {#settextdrawnintextelement}

Содержит ли изображение SVG текст как элемент текста, а не пути (рекомендовано). Значение по умолчанию: true.
