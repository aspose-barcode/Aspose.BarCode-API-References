### getChecksumMode() {#getchecksummode}

Получить алгоритм контрольной суммы для штрихкодов Codabar. Значение по умолчанию: CodabarChecksumMode.Mod16. Чтобы включить вычисление контрольной суммы, установите значение EnableChecksum.Yes в свойство EnableChecksum. См. `ChecksumMode`(#getChecksumMode/#setChecksumMode).

**Returns:** the checksum algorithm for Codabar barcodes.
