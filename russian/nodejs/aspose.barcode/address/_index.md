## Address class

Адрес кредитора или должника. Вы можете задать либо улицу, номер дома, почтовый индекс и город (тип «структурированный адрес»), либо строку адреса 1 и 2 (тип «комбинированные элементы адреса»). Тип автоматически устанавливается, как только заполняется любое из этих полей. До заполнения полей тип адреса не определён. Если заполнены поля обоих типов, тип адреса становится конфликтующим. Имя и код страны должны всегда указываться, если только все поля не пусты.

```js
new Address()
```

### getAddressLine1() {#getaddressline1}

Получает первую строку адреса. Первая строка адреса содержит название улицы, номер дома или абонентский ящик. Установка этого поля задает тип адреса как AddressType.COMBINED_ELEMENTS, если он еще не является AddressType.STRUCTURED, в этом случае он становится AddressType.CONFLICTING. Это поле используется только для адресов с комбинированными элементами и является необязательным.

**Returns:** The address line 1.

### getAddressLine2() {#getaddressline2}

Получает вторую строку адреса. Вторая строка адреса содержит почтовый индекс и город. Установка этого поля задает тип адреса как AddressType.COMBINED_ELEMENTS, если он еще не является AddressType.STRUCTURED, в этом случае он становится AddressType.CONFLICTING. Это поле используется только для адресов с комбинированными элементами. Для этого типа оно обязательно.

**Returns:** The address line 2.

### getCountryCode() {#getcountrycode}

Получает двухбуквенный ISO-код страны. Код страны обязателен, если только весь адрес не содержит null или emtpy values.

**Returns:** The ISO country code.

### getHouseNo() {#gethouseno}

Получает номер дома. Установка этого поля задает тип адреса как AddressType.STRUCTURED, если он еще не является AddressType.COMBINED_ELEMENTS, в этом случае он становится AddressType.CONFLICTING. Это поле используется только для структурированных адресов и является необязательным.

**Returns:** The house number.

Получает тип адреса. Тип адреса автоматически устанавливается при указании либо улицы/номера дома, либо первой и второй строки адреса. До установки полей тип адреса — Undetermined. Если заданы поля обоих типов, тип адреса становится Conflicting.

**Returns:** The address type.
