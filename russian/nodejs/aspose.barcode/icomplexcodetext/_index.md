## IComplexCodetext class

Интерфейс для сложного кодового текста, используемого с ComplexBarcodeGenerator.

```js
new IComplexCodetext()
```

## Методы

| Имя | Описание |
| --- | --- |
| [getBarcodeType()](#getbarcodetype) | Получает тип штрих‑кода. |
| [getConstructedCodetext()](#getconstructedcodetext) | Создаёт текст кода для сложного штрихкода |
| [initFromString(constructedCodetext)](#initfromstring) | Инициализирует экземпляр с построенным текстом кода. |

### getBarcodeType() {#getbarcodetype}

Получает тип штрих‑кода.

**Returns:** Barcode type.

### getConstructedCodetext() {#getconstructedcodetext}

Создаёт текст кода для сложного штрихкода

**Returns:** Constructed codetext

### initFromString(constructedCodetext) {#initfromstring}

Инициализирует экземпляр с построенным текстом кода.

| Параметр | Описание |
| --- | --- |
| constructedCodetext | Построенный codetext. |
