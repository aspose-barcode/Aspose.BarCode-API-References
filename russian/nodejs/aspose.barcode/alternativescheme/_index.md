### equals(obj) {#equals}

Определяет, равен ли указанный объект текущему объекту.

| Параметр | Описание |
| --- | --- |
| obj | Объект для сравнения с текущим объектом. |

**Returns:** true if the specified object is equal to the current object; otherwise, false.

### getInstruction() {#getinstruction}

Получает инструкцию по оплате для заданного счета. Инструкция состоит из двухбуквенного сокращения схемы, символа-разделителя и последовательности параметров (разделённых символом с индексом 2).

### hashCode() {#hashcode}

**Returns:** hash code for the current object.
