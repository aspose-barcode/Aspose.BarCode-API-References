## CouponParameters class

Параметры купона. Используется для UpcaGs1DatabarCoupon, UpcaGs1Code128Coupon.

```js
new CouponParameters()
```

### getSupplementSpace() {#getsupplementspace}

Пространство между основным BarCode и дополнительным BarCode в единицах измерения.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

### setSupplementSpace() {#setsupplementspace}

Пространство между основным BarCode и дополнительным BarCode в единицах измерения.

**Throws:** IllegalArgumentExceptionThe Space parameter value is less than 0.

Возвращает человекочитаемое строковое представление этого CouponParameters.
