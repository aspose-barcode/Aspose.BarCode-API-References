## DataMatrixEccType

Укажите тип ECC для кодирования.

## Значения

| Имя | Описание |
| --- | --- |
| ECC_AUTO | Указывает, что тип закодированного ECC определяется по умолчанию коррекцией ошибок Reed-Solomon или ECC 200. |
| ECC_000 | Указывает, что тип закодированного ECC определяется ECC 000. |
| ECC_050 | Указывает, что тип закодированного ECC определяется ECC 050. |
| ECC_080 | Указывает, что тип закодированного ECC определяется ECC 080. |
| ECC_100 | Указывает, что тип закодированного ECC определяется ECC 100. |
| ECC_140 | Указывает, что тип закодированного ECC определён как ECC 140. |
| ECC_200 | Указывает, что тип закодированного ECC определён как ECC 200. Рекомендуется использовать. |
