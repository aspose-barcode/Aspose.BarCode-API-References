## BarCodeImageFormat

Указывает формат файла изображения.

## Значения

| Имя | Описание |
| --- | --- |
| BMP | Указывает формат изображения bitmap (BMP). |
| GIF | Указывает формат изображения Graphics Interchange Format (GIF). |
| JPEG | Указывает формат изображения Joint Photographic Experts Group (JPEG). |
| PNG | Указывает формат изображения W3C Portable Network Graphics (PNG). |
| TIFF | Указывает формат изображения Tagged Image File Format (TIFF). |
| TIFF_IN_CMYK | Указывает формат изображения Tagged Image File Format (TIFF) в цветовой модели CMYK. |
| EMF | Указывает формат изображения Enhanced Metafile (EMF). |
| SVG | Указывает формат изображения Scalable Vector Graphics (SVG). |
| PDF | Указывает формат изображения Portable Document Format (PDF). |
