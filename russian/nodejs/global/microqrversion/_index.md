## MicroQRVersion

Версия MicroQR Code. От M1 до M4.

## Значения

| Имя | Описание |
| --- | --- |
| AUTO | Указывает автоматически выбирать лучшую версию для MicroQR. Это значение по умолчанию. |
| M1 | Указывает версию M1 для Micro QR с 11 x 11 модулями. |
| M2 | Указывает версию M2 для Micro QR с 13 x 13 модулями. |
| M3 | Указывает версию M3 для Micro QR с 15 x 15 модулями. |
| M4 | Указывает версию M4 для Micro QR с 17 x 17 модулями. |
