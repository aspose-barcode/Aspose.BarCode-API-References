## Pdf417CompactionMode

Режим сжатия штрихкода Pdf417.

## Значения

| Имя | Описание |
| --- | --- |
| AUTO | автоматически определять режим сжатия |
| ТЕКСТ | сжатие текста |
| ЧИСЛОВОЙ | режим числового сжатия |
| БИНАРНЫЙ | режим бинарного сжатия |
