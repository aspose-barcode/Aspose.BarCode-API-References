## ECIEncodings

Идентификаторы расширенной интерпретации канала. Они используются, чтобы сообщить считывателю штрихкода детали о используемых ссылках для кодирования данных в символе. Текущая реализация включает все известные кодировки наборов символов. В настоящее время она используется только для QR‑2D штрихкода.
