## AztecSymbolMode

Указывает режим символов Aztec.

## Значения

| Имя | Описание |
| --- | --- |
| AUTO | Указывает автоматически выбирать лучший символ (COMPACT или FULL-range) для Aztec. Это значение по умолчанию. |
| COMPACT | Указывает символ COMPACT для Aztec. Символ COMPACT в Aztec допускает только 1, 2, 3 или 4 слоя. |
| FULL_RANGE | Указывает символ FULL-range для Aztec. Символ FULL-range в Aztec допускает от 1 до 32 слоёв. |
| RUNE | Указывает символ RUNE для Aztec. Runes в Aztec представляют собой серию небольших, но отличимых машинно‑читаемых меток. Он допускает только числовые значения от 0 до 255. |
