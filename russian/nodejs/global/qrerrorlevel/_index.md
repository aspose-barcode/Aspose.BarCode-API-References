## QRErrorLevel

Уровень коррекции ошибок Рида‑Соломона. От низкого к высокому: LEVEL_L, LEVEL_M, LEVEL_Q, LEVEL_H.

## Значения

| Имя | Описание |
| --- | --- |
| LEVEL_L | Позволяет восстановить 7 % текста кода |
| LEVEL_M | Позволяет восстановить 15 % текста кода |
| LEVEL_Q | Позволяет восстановить 25 % текста кода |
| LEVEL_H | Позволяет восстановить 30 % текста кода |
