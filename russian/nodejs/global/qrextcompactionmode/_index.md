## QrExtCompactionMode

Указывает режим сжатия QR для текста кода, добавляемого QrExtCodetextBuilder.

## Значения

| Имя | Описание |
| --- | --- |
| AUTO | Кодировщик автоматически выбирает наиболее эффективный режим сжатия QR. |
| ЧИСЛОВОЙ | Кодирует текст кода в числовом режиме QR. Допускаются только цифры 0-9. |
| ALPHA_NUMERIC | Кодирует текст кода в алфавитно-цифровом режиме QR. |
| BYTES | Кодирует текст кода в байтовом режиме QR. |
| KANJI | Кодирует текст кода в режиме QR Kanji. |
