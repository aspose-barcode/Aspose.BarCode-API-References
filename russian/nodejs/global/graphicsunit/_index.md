## GraphicsUnit

Указывает единицу измерения для заданных данных.

## Значения

| Имя | Описание |
| --- | --- |
| WORLD | Указывает единицу измерения системы мировых координат. |
| DISPLAY | Указывает единицу измерения устройства отображения. Обычно пиксели для видеодисплеев и 1/100 дюйма для принтеров. |
| PIXEL | Указывает пиксель устройства как единицу измерения. |
| POINT | Указывает точку принтера (1/72 дюйма) как единицу измерения. |
| INCH | Указывает дюйм как единицу измерения. |
| DOCUMENT | Указывает единицу документа (1/300 дюйма) как единицу измерения. |
| MILLIMETER | Указывает миллиметр как единицу измерения. |
