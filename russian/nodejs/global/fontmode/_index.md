## FontMode

Режим размера шрифта.

## Значения

| Имя | Описание |
| --- | --- |
| AUTO | Автоматически вычислять размер шрифта на основе размера штрих‑кода. |
| MANUAL | Использовать размер шрифта, определённый пользователем. |
