## EnableChecksum

Включить контрольную сумму при генерации для 1‑мерных штрих‑кодов. По умолчанию считается «Да» для символогий, которым обязательна контрольная сумма, и «Нет» там, где контрольная сумма только возможна. Контрольная сумма никогда не используется: Codabar. Возможна контрольная сумма: Code39 Standard/Extended, Standard2of5, Interleaved2of5, Matrix2of5, ItalianPost25, DeutschePostIdentcode, DeutschePostLeitcode, VIN. Контрольная сумма всегда используется: остальные символогии.

## Значения

| Имя | Описание |
| --- | --- |
| DEFAULT | Если контрольная сумма требуется спецификацией, она будет добавлена. |
| ДА | Всегда используйте контрольную сумму, если это возможно. |
| НЕТ | Не используйте контрольную сумму. |
