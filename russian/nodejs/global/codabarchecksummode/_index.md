## CodabarChecksumMode

Указывает алгоритм контрольной суммы для Codabar

## Значения

| Имя | Описание |
| --- | --- |
| MOD_10 | Указывает алгоритм Mod 10 для Codabar. |
| MOD_16 | Указывает алгоритм Mod 16 для Codabar (рекомендовано AIIM). |
