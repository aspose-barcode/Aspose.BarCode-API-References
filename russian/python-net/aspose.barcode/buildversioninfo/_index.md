## BuildVersionInfo class

Содержит информацию о текущей версии сборки.

Тип BuildVersionInfo раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| ASSEMBLY_VERSION | Версия сборки. |
| FILE_VERSION | Версия файла. |
| PRODUCT | Заголовок продукта. |
| PRODUCT_MAJOR | Основная версия продукта. |
| PRODUCT_MINOR | Вторичная версия продукта. |
| RELEASE_DATE | Дата выпуска продукта. |
