Содержит инструменты для генерации и рисования 1D/2D штрих‑кодов.

## Классы
| Класс | Описание |
| :- | :- |
| [BuildVersionInfo](/barcode/python-net/aspose.barcode/buildversioninfo/) | Содержит информацию о текущей версии сборки. |
| [License](/barcode/python-net/aspose.barcode/license/) | Предоставляет методы для лицензирования компонента. |
| [Metered](/barcode/python-net/aspose.barcode/metered/) | Предоставляет методы для установки измеряемого ключа. |
| [XmlSerializationAttribute](/barcode/python-net/aspose.barcode/xmlserializationattribute/) | Представляет атрибут для генератора XML‑сущностей. |
