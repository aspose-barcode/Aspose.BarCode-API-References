## CustomerInformationInterpretingType enumeration

Определяет тип интерпретации (CTable, NTable или Other) клиентской информации для штрихкода AustralianPost.

## Members
| Имя члена | Описание |
| :- | :- |
| C_TABLE | Используйте CTable для интерпретации информации о клиенте. Разрешены A..Z, a..z, 1..9, пробел и символ #. |
| N_TABLE | Используйте NTable для интерпретации информации о клиенте. Разрешены цифры. |
| OTHER | Не интерпретировать информацию о клиенте. Разрешены только символы 0, 1, 2 или 3. |
