## ProcessorSettings class

ProcessorSettings позволяют распознавать штрих‑коды с многопоточным повышением производительности.

Тип ProcessorSettings раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| use_all_cores | Необходимо для использования всех ядер. |
| use_only_this_cores_count | Укажите количество ядер для использования. <br/>            Необходимо изменить свойство "UseAllCores" на "false". |
| max_additional_allowed_threads | Укажите максимальное количество дополнительных потоков для параллельного выполнения кода |
