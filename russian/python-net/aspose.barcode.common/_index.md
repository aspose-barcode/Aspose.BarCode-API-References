Содержит общие функции и вспомогательные инструменты для поддержания основной функциональности.

## Классы
| Класс | Описание |
| :- | :- |
| [GS1Element](/barcode/python-net/aspose.barcode.common/gs1element/) | Представляет одну неизменяемую пару идентификатора приложения GS1 и значения. |
| [GS1ValidationIssue](/barcode/python-net/aspose.barcode.common/gs1validationissue/) | Описывает одну ошибку проверки GS1. |
| [GS1ValidationResult](/barcode/python-net/aspose.barcode.common/gs1validationresult/) | Содержит все независимо обнаруживаемые ошибки для строки элемента GS1, URI Digital Link или одного значения AI. |
| [ProcessorSettings](/barcode/python-net/aspose.barcode.common/processorsettings/) | ProcessorSettings позволяют распознавать штрих‑коды с многопоточным повышением производительности. |
## Перечисления
| Перечисление | Описание |
| :- | :- |
| [GS1ValidationErrorCode](/barcode/python-net/aspose.barcode.common/gs1validationerrorcode/) | Определяет ошибку проверки строки элемента GS1, URI Digital Link или значения. |
