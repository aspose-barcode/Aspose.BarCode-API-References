## HIBCLICDateFormat enumeration

Указывает различные типы форматов даты для HIBC LIC.

## Members
| Имя члена | Описание |
| :- | :- |
| YYYYMMDD | Формат YYYYMMDD. Будет закодирован в дополнительных вспомогательных данных. |
| MMYY | Формат MMYY. |
| MMDDYY | Формат MMDDYY. |
| YYMMDD | Формат YYMMDD. |
| YYMMDDHH | Формат YYMMDDHH. |
| YYJJJ | Формат юлианской даты. |
| YYJJJHH | Формат юлианской даты с часами. |
| NONE | Не кодировать дату истечения срока. |
