## HIBCLICPrimaryDataCodetext class

Класс для кодирования и декодирования текста, встроенного в код HIBC LIC, который хранит первичные данные.

Тип HIBCLICPrimaryDataCodetext раскрывает следующие члены:

| Name | Описание |
| :- | :- |
| HIBCLICPrimaryDataCodetext() | Инициализирует новый экземпляр класса HIBCLICPrimaryDataCodetext |
## Properties
| Name | Описание |
| :- | :- |
| barcode_type | Возвращает или задает тип штрихкода. Текст кода HIBC LIC может быть закодирован с использованием HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC и HIBCQRLIC типов кодирования.<br/>            Значение по умолчанию: HIBCCode39LIC. |
