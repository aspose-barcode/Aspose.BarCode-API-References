## MaxiCodeStandardCodetext class

Класс для кодирования и декодирования кодового текста MaxiCode для режимов 4, 5 и 6.

Тип MaxiCodeStandardCodetext содержит следующие члены:
## Конструкторы
| Name | Описание |
| :- | :- |
| MaxiCodeStandardCodetext() | Инициализирует новый экземпляр класса MaxiCodeStandardCodetext |
## Properties
| Name | Описание |
| :- | :- |
| encode_mode | Получает или задает режим кодирования MaxiCode. <br/>            Значение по умолчанию: Auto. |
| eci_encoding | Получает или задает кодировку ECI. Используется, когда MaxiCodeEncodeMode установлен в Auto.<br/>            Значение по умолчанию: ISO-8859-1 |
| режим | Получает или задает режим MaxiCode. Стандартный кодтекст может использоваться только с режимами 4, 5 и 6. |
| message | Получает или задает сообщение. |
## Methods
| Name | Описание |
| :- | :- |
| get_mode() | Получает режим MaxiCode. |
| get_constructed_codetext() | Создаёт кодовый текст |
| init_from_string(constructed_codetext) | Инициализирует экземпляр из построенного кодового текста. |
| get_barcode_type() | Получает тип штрихкода. |
