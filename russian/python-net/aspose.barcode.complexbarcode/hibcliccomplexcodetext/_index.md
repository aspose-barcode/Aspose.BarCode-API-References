## HIBCLICComplexCodetext class

Базовый класс для кодирования и декодирования текста, встроенного в код HIBC LIC.

Тип HIBCLICComplexCodetext раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| barcode_type | Возвращает или задает тип штрихкода. Текст кода HIBC LIC может быть закодирован с использованием HIBCCode39LIC, HIBCCode128LIC, HIBCAztecLIC, HIBCDataMatrixLIC и HIBCQRLIC типов кодирования.<br/>            Значение по умолчанию: HIBCCode39LIC. |
## Methods
| Name | Описание |
| :- | :- |
| get_constructed_codetext() | Создаёт кодовый текст |
| init_from_string(constructed_codetext) | Инициализирует экземпляр из построенного кодового текста. |
| get_barcode_type() | Получает тип штрихкода. |
