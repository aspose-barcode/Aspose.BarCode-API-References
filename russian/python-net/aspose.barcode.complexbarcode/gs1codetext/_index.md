## GS1Codetext class

Представляет кодовый текст GS1 для кодирования и декодирования в виде упорядоченной последовательности<br/>            элементов идентификатора приложения. Порядок источника и повторяющиеся идентификаторы приложения<br/>            сохраняются. Скобочная запись имеет форму (AI)value(AI)value.<br/>            Буквальная открывающая скобка '(' внутри значения должна записываться как \(; это единственная поддерживаемая последовательность экранирования. Закрывающая скобка ')' внутри значения не требует экранирования.
