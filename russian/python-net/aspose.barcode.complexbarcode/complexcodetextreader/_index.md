## ComplexCodetextReader class

ComplexCodetextReader декодирует кодовый текст в указанный тип сложного штрих‑кода.

Тип ComplexCodetextReader раскрывает следующие члены:
## Methods
| Name | Описание |
| :- | :- |
| try_decode_swiss_qr(encoded_codetext) | Декодирует кодовый текст SwissQR. |
| try_decode_mailmark_2d(encoded_codetext) | Декодирует 2D кодовый текст Royal Mail Mailmark. |
| try_decode_mailmark(encoded_codetext) | Декодирует 2D кодовый текст Royal Mail Mailmark. |
| try_decode_maxi_code(maxi_code_mode, encoded_codetext) | Декодирует кодовый текст MaxiCode. |
| try_decode_hibclic(encoded_codetext) | Декодирует кодовый текст HIBC LIC. |
| try_decode_hibcpas(encoded_codetext) | Декодирует HIBC PAS codetext. |
| try_decode_usa_drive_id(encoded_codetext) | Декодирует USADriveId codetext. |
| try_decode_gs1_codetext(encoded_codetext) | Декодирует GS1 codetext. |
| try_decode_gs1_digital_link(encoded_codetext) | Декодирует GS1 Digital Link. |
