## Address class

Адрес кредитора или должника.

Тип Address раскрывает следующие члены:
## Конструкторы
| Name | Описание |
| :- | :- |
| Address() | Создает экземпляр Address |
## Properties
| Name | Описание |
| :- | :- |
| type | Получает тип адреса. |
| name | Получает или задает имя, либо имя и фамилию физического лица, либо<br/>            название компании юридического лица. |
| address_line1 | Получает или задает строку адреса 1. |
| address_line2 | Получает или задает строку адреса 2. |
| street | Получает или задает улицу. |
| house_no | Получает или задает номер дома. |
| postal_code | Получает или задает почтовый индекс. |
| town | Получает или задает город или населённый пункт. |
| country_code | Получает или задает двухбуквенный код страны ISO. |
## Methods
| Name | Описание |
| :- | :- |
| clear() | Очищает все поля и устанавливает тип в [UNDETERMINED](/barcode/python-net/aspose.barcode.complexbarcode/addresstype/). |
| equals(other) | Определяет, равен ли указанный объект текущему объекту. |
