## PrimaryData class

Класс для хранения первичных данных HIBC LIC.

Тип PrimaryData раскрывает следующие члены:
## Конструкторы
| Name | Описание |
| :- | :- |
| PrimaryData() | Инициализирует новый экземпляр класса PrimaryData |
## Properties
| Name | Описание |
| :- | :- |
| labeler_identification_code | Определяет дату кода идентификации маркировщика.<br/>            Код идентификации маркировщика должен быть буквенно-цифровой строкой из 4 символов, при этом первый символ всегда должен быть буквенным. |
| product_or_catalog_number | Определяет номер продукта или каталога. Номер продукта или каталога должен быть буквенно-цифровой строкой длиной до 18 символов. |
| unit_of_measure_id | Определяет идентификатор единицы измерения. Идентификатор единицы измерения должен быть целым числом от 0 до 9. |
## Methods
| Name | Описание |
| :- | :- |
| parse_from_string(primary_data_codetext) | Создаёт основные данные из строкового формата в соответствии со спецификацией HIBC LIC. |
