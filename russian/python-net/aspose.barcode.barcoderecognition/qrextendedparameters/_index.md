## QRExtendedParameters class

Сохраняет информацию QR Structured Append распознанного штрихкода

Тип QRExtendedParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| is_empty | Проверяет, имеют ли все параметры только значения по умолчанию |
| structured_append_mode_bar_codes_quantity | Получает количество штрихкодов в режиме структурированного добавления QR. Значение по умолчанию — -1. |
| structured_append_mode_bar_code_index | Получает индекс штрихкода в режиме структурированного добавления QR. Индекс начинается с 0. Значение по умолчанию — -1. |
| structured_append_mode_parity_data | Получает данные четности режима структурированного добавления QR. Значение по умолчанию — -1. |
| version | Версия распознанного QR‑кода. От Version1 до Version40. |
| micro_qr_version | Версия распознанного MicroQR‑кода. От M1 до M4. |
| rect_micro_qr_version | Версия распознанного RectMicroQR‑кода. От R7x43 до R17x139. |
| error_level | Уровень коррекции ошибок Reed‑Solomon распознанного штрихкода. От низкого к высокому: LevelL, LevelM, LevelQ, LevelH. |
