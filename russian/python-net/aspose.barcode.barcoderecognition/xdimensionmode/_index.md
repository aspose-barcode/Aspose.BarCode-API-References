## XDimensionMode enumeration



## Members
| Имя члена | Описание |
| :- | :- |
| AUTO | Значение XDimension определяется ИИ (SVM). В настоящее время оно совпадает с Normal. |
| SMALL | Обнаруживает штрихкоды с небольшим XDimension от 1 пикселя и более с качеством из BarcodeQuality. |
| NORMAL | Обнаруживает штрихкоды с классическим XDimension от 2 пикселей и более с качеством из BarcodeQuality или штрихкоды высокого качества. |
| LARGE | Обнаруживает штрихкоды с большим XDimension с качеством из BarcodeQuality, полученным с помощью камер высокого разрешения. |
| USE_MINIMAL_X_DIMENSION | Обнаруживает штрихкоды размером, установленным в MinimalXDimension, с качеством из BarcodeQuality. |
