## LuminanceFrame class

Представляет 8‑битный кадр в градациях серого. Каждый пиксель представлен одним байтом, содержащим значение яркости.

Тип LuminanceFrame раскрывает следующие члены:
## Конструкторы
| Name | Описание |
| :- | :- |
| LuminanceFrame(data, width, height, rotation_degrees) | Инициализирует новый экземпляр класса LuminanceFrame |
| LuminanceFrame(data, width, height, row_stride, rotation_degrees) | Инициализирует новый экземпляр класса LuminanceFrame |
## Properties
| Name | Описание |
| :- | :- |
| data | Получает данные яркости. |
| width | Получает ширину кадра в пикселях. |
| height | Получает высоту кадра в пикселях. |
| row_stride | Получает расстояние в байтах между начала<br/>            двух соседних строк. |
| rotation_degrees | Получает количество градусов, на которое кадр должен быть повернут по часовой стрелке для получения правильной ориентации. |
