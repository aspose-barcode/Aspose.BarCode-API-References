## DataMatrixExtendedParameters class

Сохраняет специальные данные распознанного штрихкода DataMatrix.

Тип DataMatrixExtendedParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| is_empty | Проверяет, имеют ли все параметры только значения по умолчанию |
| structured_append_barcodes_count | Получает количество штрихкодов в режиме структурного добавления DataMatrix. Значение по умолчанию — -1. Количество должно быть от 1 до 35. |
| structured_append_barcode_id | Получает идентификатор штрихкода в режиме структурного добавления DataMatrix. Идентификатор начинается с 1 и не может превышать количество штрихкодов. Значение по умолчанию — -1. |
| structured_append_file_id | Получает идентификатор штрихкода в режиме структурного добавления DataMatrix. Идентификатор начинается с 1 и не может превышать количество штрихкодов. Значение по умолчанию — -1. |
| is_reader_programming | Указывает, используется ли код для инструкций считывателя, чтобы интерпретировать последующие данные как команды инициализации или перепрограммирования считывателя штрихкода.<br/>            Значение по умолчанию — false. |
