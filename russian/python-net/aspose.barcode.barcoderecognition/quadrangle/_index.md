## Quadrangle class

Сохраняет набор из четырёх [Point](/barcode/python-net/aspose.drawing/point/)s, представляющих регион [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/).

Тип Quadrangle раскрывает следующие члены:
## Конструкторы
| Name | Описание |
| :- | :- |
| Quadrangle() | Инициализирует новый пустой экземпляр класса [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/). |
| Quadrangle(left_top, right_top, right_bottom, left_bottom) | Инициализирует новый экземпляр класса Quadrangle |
## Properties
| Name | Описание |
| :- | :- |
| left_top | Получает левый верхний угол [Point](/barcode/python-net/aspose.drawing/point/) области [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| right_top | Получает правый верхний угол [Point](/barcode/python-net/aspose.drawing/point/) области [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| right_bottom | Получает правый нижний угол [Point](/barcode/python-net/aspose.drawing/point/) области [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| left_bottom | Получает левый нижний угол [Point](/barcode/python-net/aspose.drawing/point/) области [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| is_empty | Проверяет, имеют ли все [Point](/barcode/python-net/aspose.drawing/point/) данного [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) нулевые значения. |
| bounding_rectangle | Получает [Rectangle](/barcode/python-net/aspose.drawing/rectangle/), ограничивающий этот [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) |
| EMPTY | Представляет класс [Quadrangle](/barcode/python-net/aspose.barcode.barcoderecognition/quadrangle/) с неинициализированными свойствами. |
