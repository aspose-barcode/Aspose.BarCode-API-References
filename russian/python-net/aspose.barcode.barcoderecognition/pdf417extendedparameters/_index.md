## Pdf417ExtendedParameters class

Сохраняет метаданные MacroPdf417 распознанного штрихкода

Тип Pdf417ExtendedParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| is_empty | Проверяет, имеют ли все параметры только значения по умолчанию |
| macro_pdf_417_file_id | Получает идентификатор файла штрих‑кода, доступен только с MacroPdf417. |
| macro_pdf_417_segment_id | Получает идентификатор сегмента штрих‑кода, доступен только с MacroPdf417. |
| macro_pdf_417_segments_count | Получает количество сегментов штрих‑кода macro pdf417. Значение по умолчанию — -1. |
| macro_pdf_417_file_name | Имя файла Macro PDF417 (необязательно). |
| macro_pdf_417_file_size | Размер файла Macro PDF417 (необязательно). |
| macro_pdf_417_sender | Имя отправителя Macro PDF417 (необязательно). |
| macro_pdf_417_addressee | Имя получателя Macro PDF417 (необязательно). |
| macro_pdf_417_time_stamp | Метка времени Macro PDF417 (необязательно). |
| macro_pdf_417_checksum | Контрольная сумма Macro PDF417 (необязательно). |
| macro_pdf_417_terminator | Указывает, является ли сегмент последним сегментом файла Macro PDF417. |
| is_reader_initialization | Используется для указания считывателю интерпретировать данные, содержащиеся в символе, как программу для инициализации считывателя. |
| is_linked | Флаг, указывающий, что штрих-код должен быть связан с 1D штрих-кодом. |
| is_code_128_emulation | Флаг, указывающий, что штрих-код MicroPdf417 закодирован кодовыми словами эмуляции Code 128 908, 909, 910 или 911. |
