## BarcodeSettings class

Основные параметры декодирования BarCode. Содержит параметры, влияющие на распознанные данные.

Тип BarcodeSettings раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| checksum_validation |  |
| strip_fnc | Удалять символы FNC1, FNC2, FNC3 из кода текста. Значение по умолчанию — false. |
| only_requested_types | Возвращает только типы штрих-кодов, явно указанные для распознавания. <br/>            Когда включено, распознанные штрих-коды других совместимых или эквивалентных типов отфильтровываются. <br/>            Значение по умолчанию — false. |
| detect_encoding | Флаг, заставляющий движок определять кодировку кода текста для наборов Unicode. Значение по умолчанию — true. |
| australia_post | Получает параметры декодирования AustraliaPost |
| calculate_symbol_quality | Получает или задает значение, указывающее, следует ли рассчитывать качество символа штрих-кода во время распознавания. |
