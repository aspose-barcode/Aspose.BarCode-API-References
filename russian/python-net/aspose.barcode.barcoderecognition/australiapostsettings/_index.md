## AustraliaPostSettings class

Параметры декодирования AustraliaPost. Содержит параметры, влияющие на распознанные данные символьной системы AustraliaPost.

Тип AustraliaPostSettings раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| customer_information_interpreting_type | Получает или задает тип интерпретации для клиентской информации штрихкода AustralianPost BarCode. Значение по умолчанию — CustomerInformationInterpretingType.Other. |
| ignore_ending_filling_patterns_for_c_table | Флаг, заставляющий декодер AustraliaPost игнорировать последние шаблоны заполнения в поле клиентской информации при декодировании методом CTable.<br/>            Метод кодирования CTable не имеет пробелов в таблице кодов, и последовательность "333" шаблонов заполнения декодируется как буква "z". |
| customer_information_decoder | Публичный интерфейс для декодирования поля клиентской информации, используемый в символьной системе AustraliaPost. |
