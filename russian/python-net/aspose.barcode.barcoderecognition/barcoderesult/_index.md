## BarCodeResult class

Сохраняет данные распознанного штрихкода, такие как тип [SingleDecodeType](/barcode/python-net/aspose.barcode.barcoderecognition/singledecodetype/), строка codetext, <br/>            регион [BarCodeRegionParameters](/barcode/python-net/aspose.barcode.barcoderecognition/barcoderegionparameters/) и другие параметры.

Тип BarCodeResult раскрывает следующие члены:
## Конструкторы
| Name | Описание |
| :- | :- |
| BarCodeResult(result) | Инициализирует новый экземпляр класса BarCodeResult |
## Properties
| Name | Описание |
| :- | :- |
| reading_quality | Получает качество чтения. Работает с 1D и почтовыми штрихкодами. |
| confidence | Получает уровень уверенности распознавания распознанного штрихкода |
| code_text | Получает текст кода |
| code_bytes | Получает закодированные байты кода |
| code_type | Получает тип штрихкода |
| code_type_name | Получает название типа штрихкода |
| регион | Получает регион штрих‑кода |
| расширенный | Получает расширенные параметры распознанного штрих‑кода |
| iso_symbol_quality | Получает результаты оценки качества символа ISO/IEC для распознанного штрих‑кода. |
