## AztecExtendedParameters class

Сохраняет специальные данные распознанного штрихкода Aztec.

Тип AztecExtendedParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| is_empty | Проверяет, имеют ли все параметры только значения по умолчанию |
| structured_append_barcodes_count | Возвращает количество штрих-кодов режима структурированного добавления Aztec. Значение по умолчанию — 0. Значение должно быть от 1 до 26. |
| structured_append_barcode_id | Возвращает идентификатор штрих‑кода режима структурированного добавления Aztec. Идентификатор начинается с 1 и должен быть не больше количества штрих‑кодов. Значение по умолчанию — 0. |
| structured_append_file_id | Возвращает идентификатор файла режима структурированного добавления Aztec. Значение по умолчанию — пустая строка. |
| is_reader_initialization | Указывает, используется ли код для инструкций считывателя, чтобы интерпретировать последующие данные как команды инициализации или перепрограммирования считывателя штрихкода.<br/>            Значение по умолчанию — false. |
