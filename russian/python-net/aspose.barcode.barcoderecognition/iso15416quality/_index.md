## Iso15416Quality class

Сохраняет оценки качества штрихкода, рассчитанные в соответствии со стандартом ISO/IEC 15416 для 1‑мерных штрихкодов.

Тип Iso15416Quality раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| grade | Получает общий рейтинг качества штрихкода согласно ISO/IEC 15416. |
| decode | Получает рейтинг декодирования, указывающий, может ли штрихкод быть декодирован с использованием эталонного алгоритма декодирования. |
| symbol_contrast | Получает рейтинг контраста символа, основанный на разнице между максимальной и минимальной отражательной способностью. |
| minimum_reflectance | Получает минимальную оценку отражения на основе отражения самого тёмного штриха. |
| minimum_edge_contrast | Получает минимальную оценку контраста кромки на основе наименьшей разницы отражения между соседними штрихами и пробелами. |
| modulation | Получает оценку модуляции на основе однородности контраста кромки по всему штрихкоду. |
| defects | Получает оценку дефектов на основе нерегулярностей отражения внутри штрихов и пробелов. |
| decodability | Получает оценку декодируемости на основе точности ширины штрихов и пробелов. |
