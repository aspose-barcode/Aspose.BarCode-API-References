## QualitySettings class

QualitySettings позволяет вручную настраивать качество и скорость распознавания.<br/>            Вы можете быстро настроить QualitySettings с помощью встроенных предустановок: HighPerformance, NormalQuality, HighQuality, MaxQuality, либо вручную настроить отдельные параметры.<br/>            Значение по умолчанию для QualitySettings — NormalQuality.

Тип QualitySettings раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| high_performance | Предустановка качества распознавания HighPerformance. Штрихкоды высокого качества хорошо распознаются в этом режиме. |
| normal_quality | Preset качества распознавания NormalQuality. Подходит для большинства штрихкодов |
| high_quality | Preset качества распознавания HighQuality. Этот preset разработан для штрихкодов низкого качества. Позволяет обнаруживать сильно повреждённые штрихкоды. |
| max_quality | Preset качества распознавания MaxQuality. Этот preset разработан для распознавания всех возможных штрихкодов, включая некорректные штрихкоды. |
| x_dimension | Режим распознавания, который задаёт размер (от 1 до бесконечности) минимального элемента штрихкода: ячейки матрицы или полосы. |
| minimal_x_dimension | Минимальный размер XDimension в пикселях, используемый с UseMinimalXDimension. |
| barcode_quality | Режим, который включает методы распознавания элементов штрихкода с выбранным качеством. Элемент штрихкода с более низким качеством требует более сложных методов, что замедляет распознавание. |
| deconvolution | Режим деконволюции (восстановление изображения), который определяет уровень деградации изображения. Изначально деконволюция — это функция, способная восстановить ухудшенное <br/>            (свёрнутое) изображение любой естественной функцией, такой как размытие, при получении изображения камерой. Поскольку мы не можем определить функцию, ухудшающую изображение, <br/>            нам приходится проверять наиболее известные функции, такие как резкость или математическая морфология. |
| inverse_image | Режим, который включает или отключает дополнительное распознавание штрихкодов на изображениях с инвертированными цветами (яркость). |
| complex_background | Режим, который включает или отключает дополнительное распознавание цветных штрихкодов на цветных изображениях. |
| allow_incorrect_barcodes | Позволяет движку распознавать штрихкоды с некорректной контрольной суммой или неверными значениями. Этот режим можно использовать для распознавания повреждённых штрихкодов с неправильным текстом. |
