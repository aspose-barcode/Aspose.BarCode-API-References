## DotCodeExtendedParameters class

Сохраняет специальные данные распознанного штрихкода DotCode

Тип DotCodeExtendedParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| is_empty | Проверяет, имеют ли все параметры только значения по умолчанию |
| structured_append_mode_barcodes_count | Получает количество штрихкодов в режиме структурного добавления DotCode. Значение по умолчанию — -1. Количество должно быть от 1 до 35. |
| structured_append_mode_barcode_id | Получает идентификатор штрихкода в режиме структурного добавления DotCode. Идентификатор начинается с 1 и должен быть меньше или равен количеству штрихкодов. Значение по умолчанию — -1. |
| is_reader_initialization | Указывает, используется ли код для инструкций считывателя, чтобы интерпретировать последующие данные как команды инициализации или перепрограммирования считывателя штрихкода.<br/>            Значение по умолчанию — false. |
