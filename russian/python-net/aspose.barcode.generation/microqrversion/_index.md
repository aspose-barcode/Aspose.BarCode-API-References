## MicroQRVersion enumeration

Версия MicroQR Code.<br/>            От M1 до M4.

## Members
| Имя члена | Описание |
| :- | :- |
| AUTO | Указывает автоматически выбирать лучшую версию для MicroQR.<br/>            Это значение по умолчанию. |
| M1 | Указывает версию M1 для Micro QR с 11 × 11 модулями. |
| M2 | Указывает версию M2 для Micro QR с 13 × 13 модулями. |
| M3 | Указывает версию M3 для Micro QR с 15 × 15 модулями. |
| M4 | Указывает версию M4 для Micro QR с 17 × 17 модулями. |
