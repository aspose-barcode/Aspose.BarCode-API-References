## MaxiCodeMode enumeration

Режим кодирования для штрих‑кодов MaxiCode.

## Members
| Имя члена | Описание |
| :- | :- |
| MODE2 | Mode 2 кодирует почтовую информацию в первом сообщении и данные во втором сообщении. <br/>            Имеет 9‑значный почтовый индекс (используется только в США). |
| MODE3 | Режим 3 кодирует почтовую информацию в первом сообщении и данные во втором сообщении. <br/>            Имеет 6-символьный буквенно-цифровой почтовый код, используемый в мире. |
| MODE4 | Режим 4 кодирует данные в первом и втором сообщении, с короткой коррекцией ECC. |
| MODE5 | Режим 5 кодирует данные в первом и втором сообщении, с длинной коррекцией ECC. |
| MODE6 | Режим 6 кодирует данные в первом и втором сообщении, с короткой коррекцией ECC.<br/>            Используется для кодирования устройства. |
