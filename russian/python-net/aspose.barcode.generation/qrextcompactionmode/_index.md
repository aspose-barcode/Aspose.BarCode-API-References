## QrExtCompactionMode enumeration

Указывает режим уплотнения QR для текста кода, добавленного QrExtCodetextBuilder.

## Members
| Имя члена | Описание |
| :- | :- |
| AUTO | Кодировщик автоматически выбирает наиболее эффективный режим сжатия QR. |
| NUMERIC | Кодирует текст кода в режиме QR Numeric. Допустимы только цифры 0-9. |
| ALPHA_NUMERIC | Кодирует текст кода в режиме QR Alphanumeric. |
| BYTES | Кодирует текст кода в режиме QR Byte. |
| KANJI | Кодирует текст кода в режиме QR Kanji. |
