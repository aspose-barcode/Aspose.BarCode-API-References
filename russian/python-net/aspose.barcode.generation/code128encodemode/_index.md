## Code128EncodeMode enumeration

Режим кодирования для штрихкодов Code128.

## Members
| Имя члена | Описание |
| :- | :- |
| AUTO | Кодировать текст кода в классическом режиме ISO 15417. Этот режим следует использовать во всех обычных случаях. |
| CODE_A | Кодировать текст кода только в наборе 128A. |
| CODE_B | Кодировать текст кода только в наборе 128B. |
| CODE_C | Кодировать текст кода только в наборе 128C. |
| CODE_AB | Кодировать текст кода только в наборах 128A и 128B. |
| CODE_AC | Кодировать текст кода только в наборах 128A и 128C. |
| CODE_BC | Кодировать текст кода только в наборах 128B и 128C. |
