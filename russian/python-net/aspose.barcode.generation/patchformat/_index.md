## PatchFormat enumeration

Формат PatchCode. Выберите PatchOnly для создания отдельного PatchCode. Используйте формат страницы для создания страницы Patch с PatchCode в качестве границ.

## Members
| Имя члена | Описание |
| :- | :- |
| Только_ПАТЧ | Создаёт только PatchCode |
| A4 | Создаёт страницу формата A4 с PatchCodes в качестве границ и необязательным QR в центре |
| A4_ЛАНДШАФТ | Создаёт страницу формата A4 в ландшафтной ориентации с PatchCodes в качестве границ и необязательным QR в центре |
| US_ЛЕТТЕР | Создаёт страницу формата US letter с PatchCodes в качестве границ и необязательным QR в центре |
| US_LETTER_ЛАНДШАФТ | Создаёт страницу формата US letter в ландшафтной ориентации с PatchCodes в качестве границ и необязательным QR в центре |
