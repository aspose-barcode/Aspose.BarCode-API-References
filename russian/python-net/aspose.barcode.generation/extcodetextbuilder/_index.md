## ExtCodetextBuilder class

Вспомогательный класс для автоматической генерации codetext в расширенном режиме Codetext

Тип ExtCodetextBuilder раскрывает следующие члены:
## Methods
| Name | Описание |
| :- | :- |
| clear() | Очищает элементы расширенного текста кода |
| add_plain_codetext(codetext) | Добавляет простой текст кода в элементы расширенного текста кода |
| add_eci_codetext(eci_encoding, codetext) | Добавляет текст кода с расширенным идентификатором канала |
| get_extended_codetext() | Генерировать расширенный код текста из списка элементов генерации |
