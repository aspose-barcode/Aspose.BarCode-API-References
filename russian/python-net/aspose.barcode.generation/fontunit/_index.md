## FontUnit class

Определяет определённый формат текста, включая тип шрифта, размер и атрибуты стиля<br/>            где размер задаётся в свойстве Unit value.

Тип FontUnit раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| family_name | Получает или задает название гарнитуры этого шрифта. |
| style | Получает или задает информацию о стиле для этого FontUnit. |
| size | Получает или задает размер этого FontUnit в значении Unit. |
