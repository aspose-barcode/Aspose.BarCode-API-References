## BorderParameters class

Параметры границы изображения штрихкода

Тип BorderParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| visible | Видимость границы. Если false, то параметр Width всегда игнорируется (0).<br/>            Значение по умолчанию: false. |
| width | Ширина границы.<br/>            Значение по умолчанию: 0.<br/>            Игнорируется, если Visible установлено в false. |
| dash_style | Стиль штриха границы.<br/>            Значение по умолчанию: BorderDashStyle.Solid. |
| цвет | Цвет границы.<br/>            Значение по умолчанию: Color.Black. |
