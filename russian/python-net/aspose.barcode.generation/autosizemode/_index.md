## AutoSizeMode enumeration

Указывает различные типы режимов автоматического масштабирования.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Автоматическое изменение размера отключено. |
| NEAREST | Изменяет размер штрихкода до ближайшего наименьшего возможного размера, указанного свойствами ImageWidth и ImageHeight.<br/>            Сохраняет соотношение сторон по умолчанию. |
| INTERPOLATION | Изменяет размер штрихкода до указанного размера.<br/>            Размер может быть задан свойствами ImageWidth и ImageHeight.<br/>            Сгенерированный штрихкод может стать недействительным (нечитаемым) после масштабирования. |
