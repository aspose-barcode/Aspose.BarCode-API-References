## ITFParameters class

Параметры ITF.

Тип ITFParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| border_thickness | Получает или задает толщину границы ITF (полосы‑несущей) в единицах.<br/>            Значение по умолчанию: 12pt. |
| border_type | Тип границы штрих‑кода ITF.<br/>            Значение по умолчанию: ITF14BorderType.Bar. |
| quiet_zone_coef | Размер тихих зон в xDimension.<br/>            Значение по умолчанию: 10, что означает, что если xDimension = 2px, то тихие зоны будут 20px. |
