## CaptionParameters class

Параметры подписи.

Тип CaptionParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| text | Текст подписи.<br/>            Значение по умолчанию: пустая строка. |
| font | Шрифт подписи.<br/>            Значение по умолчанию: Arial 8pt regular. |
| visible | Видимость текста подписи.<br/>            Значение по умолчанию: false. |
| text_color | Цвет текста подписи.<br/>            Значение по умолчанию: Color.Black. |
| padding | Отступы подписи.<br/>            Значение по умолчанию для CaptionAbove: 5pt 5pt 0 5pt.<br/>            Значение по умолчанию для CaptionBelow: 0 5pt 5pt 5pt. |
| выравнивание | Горизонтальное выравнивание текста подписи.<br/>            Значение по умолчанию: StringAlignment.Center. |
| no_wrap | Укажите переносы слов (разрывы строк) в тексте.<br/>            Значение по умолчанию: false. |
