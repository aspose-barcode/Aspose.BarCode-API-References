## SvgColorMode enumeration

Возможные режимы заполнения цвета в файле svg, по умолчанию RGB, поддерживается SVG 1.1.<br/>            RGBA, HSL, HSLA допускаются в стандарте SVG 2.0.<br/>            Даже в RGB непрозрачность задаётся параметром "fill-opacity".

## Members
| Имя члена | Описание |
| :- | :- |
| RGB | Режим RGB, пример: fill="#ff5511" fill-opacity="0.73". Режим по умолчанию. |
| RGBA | Режим RGBA, пример: fill="rgba(255, 85, 17, 0.73)" |
| HSL | Режим HSL, пример: fill="hsl(17, 100%, 53%)" fill-opacity="0.73" |
| HSLA | Режим HSLA, пример: fill="hsla(30, 50%, 70%, 0.8)" |
