## AztecSymbolMode enumeration

Указывает режим символов Aztec.

## Members
| Имя члена | Описание |
| :- | :- |
| AUTO | Указывает автоматически выбирать лучший символ (Compact или Full-range) для Aztec.<br/>            Это значение по умолчанию. |
| COMPACT | Указывает символ Compact для Aztec.<br/>            Символ Compact Aztec допускает только 1, 2, 3 или 4 слоя. |
| FULL_RANGE | Указывает символ Full-range для Aztec.<br/>            Символ Full-range Aztec допускает от 1 до 32 слоёв. |
| RUNE | Указывает символ Rune для Aztec.<br/>            Руна Aztec представляет собой серию небольших, но отличимых машинно‑читаемых меток. Она допускает только числовые значения от 0 до 255. |
