## Pdf417MacroTerminator enumeration

Используется, чтобы указать кодировщику, добавлять ли терминатор Macro PDF417 (кодовое слово 922) к сегменту.<br/>            Применяется только для Macro PDF417.

## Members
| Имя члена | Описание |
| :- | :- |
| AUTO | Терминатор будет добавлен автоматически, если указано количество сегментов <br/>            и текущий сегмент является последним. В остальных случаях терминатор не будет добавлен. |
| NONE | Терминатор не будет добавлен. |
| SET | Терминатор будет добавлен. |
