## GS1ValidationLevel enumeration

Указывает уровень проверки данных GS1.<br/>            Более высокие уровни проверки включают все проверки более низких уровней.

## Members
| Имя члена | Описание |
| :- | :- |
| SYNTAX | Проверяет синтаксис GS1, включая идентификаторы приложений,<br/>            длину полей и обязательные разделители. |
| CONTENT | Проверяет синтаксис GS1 и содержимое значений идентификаторов приложений,<br/>            включая наборы символов, контрольные суммы и правила, специфичные для значений. |
