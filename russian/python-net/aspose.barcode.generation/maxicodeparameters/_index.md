## MaxiCodeParameters class

Параметры MaxiCode.

Тип MaxiCodeParameters раскрывает следующие члены:
## Properties
| Name | Описание |
| :- | :- |
| режим | Получает или задает режим кодирования MaxiCode. |
| encode_mode | Получает или задает режим кодирования MaxiCode. <br/>            Значение по умолчанию: Auto. |
| eci_encoding | Получает или задает кодировку ECI. Используется, когда MaxiCodeEncodeMode установлен в Auto.<br/>            Значение по умолчанию: ISO-8859-1 |
| structured_append_mode_barcode_id | Получает или задает идентификатор штрих‑кода MaxiCode в режиме структурированного добавления. <br/>            ID должно быть значением от 1 до 8. <br/>            Значение по умолчанию: 0 |
| structured_append_mode_barcodes_count | Получает или задает количество штрих‑кодов MaxiCode в режиме структурированного добавления. <br/>            Число должно быть значением от 2 до 8 (максимальное количество штрих‑кодов).<br/>            Значение по умолчанию: -1 |
| aspect_ratio | Соотношение высоты к ширине модуля 2D BarCode. |
