## QrExtCodetextBuilder class



Тип QrExtCodetextBuilder раскрывает следующие члены:
## Конструкторы
| Name | Описание |
| :- | :- |
| QrExtCodetextBuilder() | Инициализирует новый экземпляр класса QrExtCodetextBuilder |
## Methods
| Name | Описание |
| :- | :- |
| clear() | Очищает элементы расширенного текста кода |
| add_plain_codetext(codetext) | Добавляет простой текст кода в элементы расширенного текста кода |
| add_eci_codetext(eci_encoding, codetext) | Добавляет текст кода с расширенным идентификатором канала |
| get_extended_codetext() | Генерирует расширенный текст кода из списка расширенного текста кода. |
| add_fnc1_first_position() | Устанавливает FNC1 в первой позиции. Если ранее был установлен другой режим FNC1, он заменяется. |
| add_fnc1_second_position(codetext) | Устанавливает FNC1 во второй позиции. Если ранее был установлен другой режим FNC1, он заменяется. |
| add_fnc1_group_separator() | Добавляет разделитель группы (GS - '\\u001D') к элементам расширенного кода текста |
| add_codetext_with_compaction_mode(mode, codetext) | Добавляет код текста с указанным режимом сжатия QR к элементам расширенного кода текста. |
